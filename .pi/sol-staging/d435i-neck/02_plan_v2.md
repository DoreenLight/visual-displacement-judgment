# 颈部/头部 Z 轴位移测量方案（讨论稿 v2）

> **状态**：`proposed` —— 待讨论确认
> **日期**：2026-09-22
> **相机**：Intel RealSense D435i（`244222076984`，固件 5.15.1.55），macOS / Apple M5
> **v1 → v2 变更**：被测对象从「通用结构件」明确为「**人的颈部/头部**」，需求性质发生根本变化

---

## 第一部分：已确认的需求

| 项 | 用户确认 |
|---|---|
| **被测对象** | 人的颈部/头部 |
| **测量内容** | 头部/颈部**整体移动**（非呼吸起伏、非颈椎角度） |
| **Z 轴幅值** | **±100mm 以内** |
| **工作距离** | **300–500mm** |
| **几何布置** | 相机固定（三脚架），人不动 |
| **输出方式** | **离线分析** |
| **验收标准** | **分辨力/重复性**（相对位移），非绝对准确度 |
| **精度目标** | 2–5mm |

### 由实测数据导出的可行性判断

| 检查项 | 结果 |
|---|---|
| 工作距离 300–500mm 是否可行 | ✅ **正好落在实测最优区间**（MDR 1.38–3.39mm） |
| ±100mm 跨度是否可行 | ⚠️ **需核实**（基准 400mm 时实际距离变 300–500mm，刚好占满区间） |
| 2–5mm 分辨力能否达成 | ✅ 300–500mm 区间实测 MDR 1.38–3.75mm，有富余 |
| 离线分析是否有利 | ✅ 可用 16–64 帧强平均，MDR 可到 0.87mm |

## 第二部分：颈部目标带来的 6 个新约束

被测对象是人体，而非刚性平面。这改变了方案性质。

### C1. 表面是曲面（最大技术风险）

颈部近似圆柱面。固定 ROI 内像素深度**天然有分布**，这个「ROI 内 σ」会直接抬高 ROI 均值噪声。

实测参考：桌面（平面）ROI 内 σ 可低到 0.5–1.5mm；弯曲表面会大得多。

**影响**：必须实测「ROI 内 σ」与「ROI 内有效像素数」的权衡，找到最优 ROI 尺寸。
**应对**：`rs_neck_probe.py` 提供 ROI 尺寸扫描（0.25/0.5/0.75/1.0 倍）。

### C2. 呼吸运动混入

颈/锁骨区随呼吸有 2–20mm 起伏（频率 0.1–0.6 Hz）。

**影响**：若测的不是呼吸，它是干扰信号，会与目标运动叠加。
**应对**：`rs_neck_probe.py --decompose` 做 FFT 分离。离线分析时可对特定频段滤波。

### C3. 遮挡物：头发、衣领、下颌

头发是黑色丝状 → 深度大面积空洞；衣领会挡视线。

**影响**：ROI 必须精确避开这些区域，否则有效像素率骤降。
**应对**：探索模式按 4×4 网格给出各区域有效率，直接指出可用区域。

### C4. 肤色与汗液影响红外反射

D435i 依赖红外纹理匹配。深色皮肤反射率显著更低；汗液镜面反射产生空洞。

**影响**：有效像素率可能明显低于桌面测试。
**应对**：方案 C（边界扫描）必须包含不同肤色的测试，或至少记录实际有效率。

### C5. 活体不自主运动

人的姿态抖动是 cm 级，远超 mm 级测量目标。

**影响**：这是**根本性的物理限制**。如果被测者无法保持不动，cm 级抖动会淹没 mm 级信号。
**应对**：
- 若测的是「相对位移」（如从 A 位置移动到 B 位置的平均位移），可用多帧平均压制抖动
- 若测的是「连续微小运动」，需要被测者配合保持静止

### C6. 安全与伦理

相机使用 850nm 红外激光投射器（Laser Power 150）。

**影响**：Class 1 激光，通常认为对眼睛安全，但**长时间近距离直射眼睛应避免**。
**应对**：ROI 应避开眼睛区域；不要让人长时间盯着投射器。

## 第三部分：方案（v2 修订）

### 阶段 1：环境与目标标定（新增，P0）

**目的**：确认目标可用、ROI 可选。

**步骤**：
1. 相机固定于三脚架，人体摆位，距离调到 400mm（区间中心）
2. 运行 `rs_neck_probe.py --explore`
3. 检查：
   - 整体有效率是否 >30%
   - 前景包围盒是否稳定
   - 4×4 网格里是否存在有效率 >90% 的连续区域
4. 在该区域选取 ROI，运行 `--roi` 模式验证

**验收**：找到至少一个 ROI，其有效像素率 >80% 且 ROI 内 σ < 5mm

### 阶段 2：ROI 优化与基线（P0）

**目的**：确定最优 ROI 与噪声底。

**步骤**：
1. 用 `--roi` 扫描不同尺寸（脚本自动做 0.25/0.5/0.75/1.0 倍）
2. 找「ROI 内 σ」与「时间噪声」的平衡点
3. 连续采集 5 轮 × 30s，记录 MDR、漂移

**关键**：同时对比 `roi_mean_z` 与 `roi_median_z` 两种统计量。
中位数对空洞和离群值更稳健，曲面场景可能更优。

**产出**：`neck_baseline.json`（噪声底、漂移率、推荐 ROI）

### 阶段 3：行程标定（核心，P0）

**目的**：验证 ±100mm 跨度上的分辨力一致性。

**步骤**：
1. 被测者（或替代的刚性靶标）沿 Z 轴移动到 300/350/400/450/500mm
2. 每个位置停留 ≥1s，采 16 帧平均
3. 记录各位置的 MDR

**为什么必须做**：难度不在单点精度，而在**跨度上的精度一致性**。
若 500mm 端 MDR 突破 5mm，则 ±100mm 不可行。

**产出**：`neck_span_curve.csv`（位置 vs MDR）

### 阶段 4：运动分离（P1）

**目的**：区分「目标整体移动」与「呼吸/抖动」。

**步骤**：
1. 长采集（≥60s，1800 帧）
2. FFT 分解：呼吸频段（0.1–0.6Hz）vs 低频漂移 vs 目标运动
3. 验证能否用频域滤波分离

**产出**：`neck_decompose.npz`（含各分量）

### 阶段 5：边界扫描（P1，针对人体定制）

| 变量 | 扫描范围 | 为什么重要 |
|---|---|---|
| 距离 | 300/350/400/450/500mm | 跨度一致性 |
| ROI 位置 | 颈前 / 颈侧 / 锁骨上 / 后颈 | 哪个位置最稳 |
| ROI 尺寸 | 20×20 / 40×40 / 80×80 / 120×120 px | 曲面 vs 平均的权衡 |
| 光照 | 关灯 / 常亮 / 侧光 | 红外抗干扰 |
| 着装 | 高领 / 低领 / 无领 | 遮挡影响 |
| 头发 | 束起 / 披散 | 空洞影响 |
| 被测者状态 | 屏息 / 正常呼吸 | 呼吸干扰量化 |
| 肤色（若有条件） | 不同被测者 | 反射率影响 |

### 阶段 6：数据规格与输出（P0）

**每帧记录**：
```
timestamp       帧时间戳 (ms)
frame_id        帧序号
roi_mean_z      ROI 平均深度 (mm, float)
roi_median_z    ROI 中位深度 (mm)
roi_p25_z       ROI 25 分位 (mm)
roi_p75_z       ROI 75 分位 (mm)
roi_valid_ratio ROI 内有效像素比例
n_valid_px      ROI 内有效像素数
```

**位移计算**：
```
displacement[t] = roi_median_z[t] - roi_median_z[0]
uncertainty[t]  = ±MDR   (来自阶段 2 基线)
```

**必须同时输出不确定度**，不能只给数值。

## 第六部分：待讨论的关键问题

### Q1. 「头部/颈部整体移动」的物理含义

需要明确是哪种：

| 类型 | 描述 | 幅度 | 测量特点 |
|---|---|---|---|
| **定点位移** | 人从位置 A 移动到位置 B | 50–100mm | 两个静止态之差，最容易 |
| **连续轨迹** | 记录移动过程 | 50–100mm | 需连续采样 + 去抖 |
| **往复运动** | 点头/摇头的周期性 | 视情况 | 需频谱分离 |

> 如果是**定点位移**，实测分辨力 1.4–3.4mm 完全够用。
> 如果是**连续轨迹**，人体抖动会成为主要误差源。

### Q2. 被测者能否保持静止？

这是**最关键的物理限制**。头部静止时仍有约 1–3mm 的自然抖动（心跳、微颤）。

- 若能保持静止 → mm 级可达
- 若无法 → 需要明确「运动」的定义频率范围，用滤波分离

### Q3. 是否需要「替代靶标」做标定？

人体不能精确沿 Z 轴移动已知量。所以标定「绝对准确度」很困难。

**建议**：在颈部佩戴一个刚性漫反射标记（如白色贴片），用标记的深度做基准，
可减少衣服/皮肤表面变化带来的干扰。

**是否需要**？

### Q4. 实时性确认

已确认「离线分析」。但需明确**采集时长**：
- 短时（<10s）：数据量小，可强平均
- 长时（分钟级）：需考虑漂移累积与 USB 稳定性

### Q5. 是否有多个被测者？

若需跨人使用，必须验证不同肤色/颈型的适用性。
