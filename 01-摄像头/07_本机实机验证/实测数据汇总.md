## ⚠️ 重要：本文部分结论已作废

2026-09-22 晚间发现一个**根本性的方法错误**，影响本文多项结论：

> **本文的 ROI 是「按深度值筛选像素」，拿到的是散布在画面各处的
> 深度碎片，不是物理上的连续表面。**

实测对比（同一「300–500mm」区间）：

| | 像素数 | 空间 σ | 跨度 |

| 其中最大**深度一致连块** | 787 | **4.4 mm** | 45×27px |

用碎片逐帧平均会产生**假噪声**。影响范围：

| 本文结论 | 状态 |
|---|---|
| §2 精度-距离基线 | ⚠️ **数值偏悲观**，需用连通域方法重测 |
| §2 N_eff=1–4 | ❌ **作废**。低 N_eff 是碎片造成，非传感器特性 |
| §3 MDR 距离曲线（500mm 后崩溃） | ⚠️ **部分作废**，不同距离碎片化程度不同 |
| §5 滤波器收益 27× | ❌ **作废**。分母是污染值，真实约 1.7× |
| §5 HighDensity/高帧率结论 | ⚠️ 待复核 |

**修正后的实测值见 [`杆边界测试报告.md`](杆边界测试报告.md)**：
20cm 处 3mm 贴白纸杆，MDR = **0.307mm**（旧方法报 199mm）。

其它实测参数：
- `stereo_baseline = 49.99 mm`
- `visual_preset` 可选：Default(0) / MediumDensity(2) / HighAccuracy(3) / HighDensity(4)
- `depth_units = 0.001`（可调）
- K = 深度内参：`fx=428.0 fy=428.0 ppx=425.8 ppy=236.8`，畸变 `brown_conrady`
- K = 彩色内参：`fx=606.7 fy=606.5 ppx=327.3 ppy=259.0`，畸变 `inverse_brown_conrady`
- 深度→彩色外参平移：`[0.0148, -0.0, 0.0]` **米** = **[14.76, -0.02, 0.45] mm**

> ⚠️ **单位陷阱（已修正）**：`rs2_extrinsics.translation` 的单位是**米**，
> 不是毫米。此文档初版误写为 `[0.015, ...] mm`，错 1000 倍。
> 源码确认（`rs_sensor.h`）：`float translation[3]; /**< ... in meters */`。
> 实测 14.76mm 与 D435i 已知的 RGB-深度基线 ~15mm 吻合。
> 纯深度测试不受影响，但坐标系融合会产生三个数量级的错误。

## 3. 最小可检测位移 MDR（无滤波，848x480@30，900 帧 = 30s）

MDR 定义为帧间差分噪声的 3σ（差分含两帧噪声，已换算到单帧）。

| 距离箱 | 中位 Z | 帧间Δ σ | **MDR(3σ)** | 静置漂移 |
|---|---|---|---|---|
| 0-300mm | 234.0 | 0.919 | **2.756** | 0.933 |
| 300-500mm | 377.6 | 1.040 | **3.119** | 1.063 |
| 500-800mm | 714.6 | 6.543 | 19.630 | 6.519 |
| 0.8-1.2m | 1059.1 | 6.318 | 18.954 | 4.330 |
| 1.2-1.8m | 1606.1 | 8.390 | 25.169 | 7.826 |
| 1.8-2.8m | 2335.1 | 13.665 | 40.995 | 11.256 |
| 2.8-5.0m | 3718.4 | 6.153 | 18.459 | 6.152 |
| 5.0-9.0m | 6389.1 | 30.283 | 90.849 | 26.772 |

### 误差来源判定：不是相机振动

**箱间相关系数：均值 +0.015，中位 +0.005，范围 [−0.122, +0.199]**

最大相关对：
```
2.8-5.0m ↔ 5.0-9.0m   r = +0.199
1.8-2.8m ↔ 2.8-5.0m   r = +0.177
1.8-2.8m ↔ 5.0-9.0m   r = +0.164
```

→ 不同距离表面**互不相关地波动**，说明误差来自深度信号本身，**不是整机振动**。

## 4. 高帧率对比（反直觉结果）

| 配置 | 0-300mm MDR | 300-500mm MDR |
|---|---|---|
| 848x480 @ 30fps | 2.756 | 3.119 |
| 848x480 @ 90fps | 2.578 | 2.897 |
| 256x144 @ 300fps | **6.892** | 2.180 |

**90fps 与 30fps 基本持平；300fps 明显劣化。** 高帧率不是杠杆。

5 轮重复性的直接对比（temporal 开启）：

| 配置 | 0-300mm σ 均值 | 300-500mm σ 均值 |
|---|---|---|
| 30fps | **1.799** | **1.252** |
| 90fps | 1.906 | 1.423 |

→ 90fps 反而略差。

**推测机制**：帧率越高，单帧积分时间越短，信噪比下降，抵消了采样数优势。

## 8. 数据质量已知问题（必须声明）

### 8.1 未解释的 16 倍异常

同一个「30fps 848x480 无滤波」配置，两次独立运行的 0-300mm MDR：

```
运行 A（rs_filter_compare）: 45.015 mm  漂移 30.807 mm
运行 B（rs_mdr_probe）:       2.756 mm  漂移  0.933 mm
```

相差 **16 倍**，且运行 A 的漂移（30.8mm）异常大。

**推测**：无滤波时自动曝光跳变，或场景中有运动物体污染 ROI 均值。
**尚未验证**。这是方案中优先级最高的待排除项。

### 8.2 一次测试因相机被遮挡而作废

`rs_resolution_curve.py` 的第一次运行中，相机被近距离物体挡住：
- 有效像素只剩 4.9%（正常 50%+）
- ROI 内标准差 92-232mm（正常 <1.5mm）
- 倾角代理 33-45°（伪像）
- 关键箱 `300-325mm` 直接消失

**该次数据全部作废**，未用于任何结论。

### 8.3 所有数据均为「重复性」而非「准确度」

以上全部是**重复性/噪声**测量（相机与目标都不动的条件下，测量的自洽程度）。

**准确度从未验证。** 存在已知的系统性来源：
- 1mm 量化步长
- 距离相关的尺度误差（未标定）
- 可能的深度非线性

验证准确度需要**已知真值的位移标定**（精密平移台或厚度量块），尚未进行。

## 9. 由数据导出的结论

| 结论 | 依据 |
|---|---|
| 2-5mm 分辨力只在 ≤500mm 成立 | §2 §3：500mm 后 MDR 从 ~3mm 跳到 11-20mm |
| 300-500mm 是最优区间 | §5：该区间 MDR 1.38-3.39mm |
| temporal 滤波是必需项而非可选 | §5：不开滤波差 27 倍且不稳定 |
| 高帧率无用甚至有害 | §4：90fps 与 30fps 持平，300fps 劣化 |
| 时间平均超过 32 帧收益锐减 | §6：128 帧仅比 32 帧好 20% |
| 误差是传感器噪声而非振动 | §3：箱间相关系数 +0.015 |
| 空间平均收益远低于理论 | §2：N_eff 仅 1-4 |
| 测量重复性可信 | §7：轮间波动 1.2-1.7× |
| **准确度未知** | §8.3：从未标定 |
