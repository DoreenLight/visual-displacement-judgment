### 1.3 ⚠️ 一个必须先讲清的几何风险：俯仰串扰

在编写本计划时做的量级估算揭示了一个**高风险项**：

> **白纸面倾斜 θ 角时，相机测的是沿光轴的距离，因此**
> **`Z_read = Z_true / cos(θ)`**

代入实际工作距离 220mm：

| 倾角 | Z 偏大比例 | @220mm 偏大量 | 占 2mm 判据 |
|---|---|---|---|
| 2° | 0.06% | 0.13 mm | 7% |
| 5° | 0.38% | 0.84 mm | 42% |
| **10°** | **1.54%** | **3.39 mm** | **170%** ❌ |
| 15° | 3.53% | 7.76 mm | 388% ❌ |
| 20° | 6.42% | 14.12 mm | 706% ❌ |

**三个关键结论**：

1. **10° 倾斜就造成 3.4mm 偏差，已超出 2mm 判据**
2. 这是**几何效应，不是噪声** —— 多帧平均无法消除
3. **颈部牵引时目标必然会转动**，所以这不是理论担忧，而是实际威胁

**这意味着**：
- 阶段 A3（俯仰串扰）从「P0」升级为**最高优先级的阻塞项**
- 若实测确认这个量级，则必须二选一：
  - **(a) 约束倾角**：设计机械限位，保证转动 <3°
  - **(b) 角度修正**：同时估计倾角并做除法修正
  - **(c) 改用多标记点**：用 3 个以上标记点解算平面法线，进而修正

**同时这也解释了 Sol 的建议为什么重要**：
> Sol 曾说「头部稍微 Pitch 一下，没有真正向 Z 平移，ROI 所在表面离摄像头却
> 改变了几毫米，你就会把旋转当成 Z 平移。」

**当时的量级估算（几毫米）与本次计算（3.4mm @10°）完全吻合。**

## 2. 分阶段实验设计

### 阶段 A：跨度与串扰（P0，必须先做）

**目的**：确认系统的**适用范围**，这是后续所有实验的前提。

#### A1. 跨度扩展测试

**方法**：把已知物理距离序列扩到更大范围。

| 项 | 设计 |
|---|---|
| 距离点 | 160 / 180 / 200 / 220 / 250 / 300 / 350 mm（7 点） |
| 每点重复 | 3 次（看重复性） |
| 真值来源 | 钢尺（±0.5mm） |
| 关键指标 | MDR 随距离变化、尺度系数是否恒定 |

**预期发现**：
- MDR 会随距离**增大**（光斑尺寸变大）
- 尺度系数可能**偏离 1**（远距离非线性）

**验收**：给出「MDR ≤ 2mm 的最大工作距离」。

#### A2. 横向串扰测试

**目的**：验证「目标横向移动是否影响 Z 读数」。

**方法**：
```
固定目标 Z 位置（约 220mm）
沿 X 方向移动目标：-40 / -20 / 0 / +20 / +40 mm（5 个位置）
每位置记录：ROI 内 Z 读数 + ROI 质心 x 坐标
```

**关键指标**：
- Z 读数随横向位置的变化量（串扰系数）
- ROI 质心是否跟随（用于判断 ROI 是否需重新定位）

**验收**：横向移动 ±40mm 时，Z 读数变化 < 0.2mm（则为无显著串扰）。

**为什么重要**：颈部牵引时很难保证纯 Z 轴移动。如果横向 ±20mm 就造成 Z 读数变 1mm，那 2mm 判据会被污染。

#### A3. 俯仰串扰测试

**目的**：验证「目标倾斜是否影响 Z 读数」。

**方法**：
```
固定目标位置，绕水平轴旋转：0° / 5° / 10° / 15° / 20°
（用垫片垫高底部来实现小角度倾斜）
每角度记录：ROI 内 Z 读数
```

**关键指标**：
- Z 读数随倾角的变化
- 有效像素率随倾角的变化（大倾角会掉像素）

**验收**：倾角 10° 内 Z 读数变化 < 0.3mm。

**为什么重要**：见 §1.3 的几何分析 —— 10° 倾斜造成 3.4mm 偏大，
**已超出 2mm 判据 170%**。这是本次计划中**风险最高的项**。

**补充测量设计**（在 A3 基础上扩展）：
```
倾角点: 0° / 2° / 5° / 10° / 15° / 20°
每点额外记录:
  - ROI 内的「深度梯度」（沿竖直方向的 dZ/dy）
    → 可反推倾角：tan(θ) ≈ (dZ/dy) × (Z/fy)
  - 有效像素率（大倾角会掉像素）
```

**关键产出**：验证「用深度梯度反推倾角」这个方法是否可行。
若可行，则可做**在线角度修正**，从而放宽机械约束。

### 阶段 B：时间与环境（P1）

#### B1. 长时漂移测试

**方法**：
```
目标与相机完全静止
连续采集 30 分钟
每分钟统计窗口均值
```

**关键指标**：
- 漂移率（mm/min）
- 漂移是否有方向性（单调 vs 随机）
- 是否有阶跃（温漂跳变）

**验收**：给出「调零有效期」——即漂移超过 0.1mm 所需时间。

**为什么重要**：离线分析若采集 5 分钟，漂移 0.5mm 就会占据 2mm 判据的 25%。

#### B2. 温度影响

**方法**：记录环境温度 + 相机内部温度（若有 API）与 Z 读数的关系。

**实测参考**：D435i 的 `temperature` 选项可用（如有）。

**验收**：给出温度系数（mm/°C），或确认无显著相关。

### 阶段 C：真实目标（P1）

#### C1. 材质对比

**目的**：3mm 金属杆 + 白纸 的结果能否外推到其他表面。

| 目标 | 预期 |
|---|---|
| 哑光白纸（当前基准） | 最优 |
| 普通打印纸 | 相近 |
| 浅色皮肤（模拟） | 待测 |
| 深色衣物 | 可能失效 |
| 反光材质 | 可能失效 |

**关键指标**：有效像素率 + MDR

#### C2. 真实颈部实测

**方法**（采纳 Sol 的建议）：
```
在颈部贴一块平整的白纸/哑光标靶（临时）
与金属杆同时测量，对比两者的 MDR 与尺度
```

**关键指标**：
- 颈部的有效像素率
- 是否受呼吸/微动影响
- 与刚性杆的精度差距

**注意**：Sol 指出「颈部是曲面，与刚性平面不同」，需实测确认差距。

#### C3. 人体微动基线

**方法**：
```
被测者保持静止（不施力）
连续采集 60s，重复 3 次
```

**关键指标**：人体自然微动的幅度与频谱

**为什么重要**：如果人体微动是 2–3mm，那 2mm 判据会被淹没。

## 3. 执行顺序与依赖

```
阶段 A（P0）—— 必须最先做
  A1 跨度 ──┐
  A2 横向 ──┼─→ 确定「适用范围」
  A3 俯仰 ──┘

      ↓ 依赖 A 的结论

阶段 B（P1）—— 与 A 可并行
  B1 长时漂移 ──┐
  B2 温度 ──────┴─→ 确定「调零周期」

阶段 C（P1）—— 需要 A、B 完成后
  C1 材质 ──┐
  C2 颈部 ──┼─→ 确定「能否外推到真实目标」
  C3 微动 ──┘

阶段 D（P2）—— 视需求
```

**关键依赖**：
- C2（真实颈部）**必须在 A2/A3 之后** —— 否则不知道读数变化是「真实位移」还是「横向/俯仰串扰」
- B1（长时漂移）**建议在 C2 之前** —— 人体实验需要较长时间

## 4. 需要先解决的工具缺口

从首次实验的经验看，有 4 个工具问题会影响后续实验：

| # | 问题 | 影响 | 建议修复 |
|---|---|---|---|
| 1 | **真值来源精度不足** | 钢尺 ±0.5mm 限制了标定精度 | 需平移台或塞尺（可到 ±0.05mm） |
| 2 | **ROI 横向漂移** | 目标横向移动超过几十像素就失效 | 需自动跟随 ROI（用彩色图质心） |
| 3 | **坐标系数错风险** | 未开彩色流时 align 静默失效（已修） | 已有 `check_aligned()` 保护 |
| 4 | **缺乏自动记录** | 每次手动跑脚本，易漏记录 | 可做一个「连续记录」模式 |

**关于第 1 点的具体建议**：

| 方案 | 精度 | 成本 | 推荐度 |
|---|---|---|---|
| 钢尺 | ±0.5 mm | 已有 | ⭐⭐ |
| 塞尺叠加 | ±0.05 mm | 约 50 元 | **⭐⭐⭐⭐⭐** |
| 千分尺推杆 | ±0.01 mm | 约 200–500 元 | ⭐⭐⭐⭐⭐ |
| 精密平移台 | ±0.01 mm | 约 1000+ 元 | ⭐⭐⭐⭐ |

**塞尺是最佳性价比方案** —— 用 0.05mm 步进的塞尺组，可以把标定精度从 ±2.4% 提到 ±0.2%。

## 6. 风险与应对

| # | 风险 | 影响 | 应对 |
|---|---|---|---|
| R1 | **俯仰串扰超预期** | 若 10° 倾斜造成 >1mm 偏差，2mm 判据在有转动时失效 | 加装「角度约束」或改用刚性 marker |

## 7. 建议的近期执行顺序（最小可行）

如果要**只做三件事**就最大化信息量：

```
第 1 件：A3 俯仰串扰  ← 【最高优先】10° 就超判据 170%，且最容易做（垫片垫高）
第 2 件：A2 横向串扰  ← 与 A3 一起做，用同一个装置
第 3 件：A1 跨度扩展  ← 决定后续实验的距离范围

做完这三项，就能回答：「这套系统在什么条件下可靠？」
再决定是否投入真实颈部实验。
```

**A3 的紧迫性**：颈部牵引时目标会转动。如果 10° 倾斜造成 3.4mm 偏差，
那么「测出 2mm 位移」这件事在**有转动的情况下根本无法成立** ——
除非加机械约束或做角度修正。这个问题必须先解决。

**预计工作量**：
- A3 俯仰：1–2 小时（含装置调整）
- A2 横向：1–2 小时
- A1 跨度：2–3 小时（需反复移动相机/杆）

**建议先买塞尺**（约 50 元），它能让上述三项的精度从 ±2.4% 提到 ±0.2%。
