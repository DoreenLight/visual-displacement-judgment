## 第一部分：对你计划的评价

### 1.1 你的计划

> 将三维坍缩为两维，在单一平面内将 y 轴转换成 x 轴，进而实现在 x 平面、x 轴线上实现扰动极限测试。

### 1.2 我的判断：**方法论内核认可，但有一个致命前提需先修正**

**认可的部分（这是对的）：**

| 你的设计 | 为什么是对的 |
|---|---|
| 三维 → 二维 | D435i 的深度是**单轴测量**（沿光轴 Z）。把它约束在一个平面内，就把「3D 位姿估计」退化成「1D 标量测量」，这是让精度可控的关键 |
| y 轴转成 x 轴 | 用**机械约束**（导轨/槽）替代**程序约束**，把自由度从 2 个降到 1 个。机械约束不会引入算法误差 |
| 单轴线上做极限测试 | 一维扫描可以密集取样，得到完整的 MDR-位移曲线，这是唯一能定出「极限」的方法 |

**但有一个必须先解决的问题：**

> ⚠️ **「20cm 距离」与我实测的数据矛盾。**

我实测（刚完成，修正方法后）：

| 距离 | MDR(3σ) | 状态 |
|---|---|---|
| 174mm | 0.39mm | ✅ |
| 209mm | 0.20mm | ✅ |
| 290mm | 0.05mm | ✅ |
| 300mm | 0.03mm | ✅ |

**20cm 处精度非常好（0.2mm 级），远优于你的 2–5mm 要求。所以「20cm 是极限」这个预设可能不成立。**

这说明两种可能：

- **可能 A**：20cm 不是「精度极限」，而是「**视场极限**」——太近时小棍会超出画面/被遮挡
- **可能 B**：你说的「20cm 为 0」是指**位置基准**，不是精度极限

**这是本计划需要你确认的第一个问题。**

### 1.3 「扰动」需要定义

「扰动」有四种完全不同的含义，测量方法差别很大：

| 类型 | 物理含义 | 测量方式 | 难度 |
|---|---|---|---|
| **T1 位置扰动** | 棍从位置 A 移到 B | 两点深度差 | 最容易 |
| **T2 振动扰动** | 棍在原地小幅快速抖动 | 时间序列 + 频谱 | 中 |
| **T3 外力扰动** | 施加已知外力，看位移响应 | 需力传感器同步 | 难 |
| **T4 环境扰动** | 气流/声波/热等引起 | 需环境激励源 | 难 |

**我推测你要的是 T1 或 T2，但必须确认。**

## 第二部分：测试计划（如果你认可内核）

### 阶段 0：前置条件（P0，必做）

**目的**：确定系统基线，否则后面所有数据无参照。

| 项 | 内容 | 验收 |
|---|---|---|
| 0.1 | 相机固定（三脚架 + 锁紧，避免触碰） | 30 分钟静止漂移 < 1mm |
| 0.2 | 小棍固定方式确定（见 §2.1） | 重复装夹 5 次，位置重复性 < 0.5mm |
| 0.3 | **标定 20cm 基准**（不是假设，是实测） | 用卷尺/卡尺量出真实距离并记录 |
| 0.4 | 曝光锁定（AE 稳定后读值再关 AE 写回） | 采集期曝光不变 |

**关于 0.3**：你说「当前认定 20cm 距离为 0」——**建议不要「认定」，要「测量」**。
用钢尺量出相机前壳到棍的精确距离，记为 `z0`。因为：
- 这个数字后面要用来算尺度校准
- 「认定」的值和「实测」的值可能差 5–20mm，会污染所有结论

### 阶段 1：平面约束与坐标降维（P0）

**1.1 建立坐标体系**

```
相机坐标系 (Xc, Yc, Zc)   Zc = 光轴（深度方向）
        ↓  机械约束
测试坐标系 (X, Z)          X = 水平横向（画面 x）
                          Z = 深度方向（深度值）

约束：目标只允许沿 Z 轴移动（用小槽/导轨限制 X、Y 自由度）
      → 但保留 X 自由度用于「把 y 轴转成 x 轴」的验证
```

**1.2 「y 轴转换成 x 轴」的实现**

你的想法是：在平面内，让原本的 y（垂直）运动通过某种方式表现为 x（水平）方向。

实现方式有两种：

| 方式 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 旋转相机 90°** | 把相机转 90°，使画面 x 轴对齐垂直运动方向 | 简单，零算法改动 | 需要机械重新安装 |
| **B. 交换坐标轴** | 采集后把深度图的 y 当 x 用 | 零机械改动 | 需要改代码，且深度图其实是对称的，意义有限 |

**我的建议：方式 A**。因为：
- D435i 的深度图 848×480，水平分辨率比垂直高（848 > 480）
- 旋转后，**垂直方向的运动落在 848 这个高分辨率轴上**，精度更好
- 这也是「把 y 转成 x」的真正价值 —— **用高分辨率轴测运动**

**验证实验**：同一个位移，分别在「未旋转」和「旋转 90°」下各测 10 次，比较 MDR。

**1.3 降维的验证**

如何确认「真的只剩 1 个自由度」？

- 采集时同时记录 ROI 在画面中的 x、y 位置
- 若棍只沿 Z 移动，则 ROI 的 x、y 应保持**亚像素稳定**
- 若 x、y 有明显漂移，说明机械约束不足

**验收**：主轴移动 ±20mm 期间，ROI 质心 x、y 漂移 < 2px。

### 阶段 2：单轴扰动极限扫描（P0，核心）

**2.1 实验设计**

用**精密平移台**（千分尺推杆）沿 Z 轴步进，每个位置采 16 帧平均：

| 步进量 | 重复次数 | 目的 |
|---|---|---|
| 0.2mm | 20 次 | 找**绝对下限** |
| 0.5mm | 20 次 | 找下限 |
| **1mm** | 20 次 | **关键**：能否分辨 1mm |
| **2mm** | 20 次 | **关键**：你的指标下限 |
| **5mm** | 20 次 | **关键**：你的指标上限 |
| 10mm | 10 次 | 线性度 |
| 20mm | 10 次 | 线性度 |
| 回程 20→0 | 全程 | **迟滞** |

**2.2 「扰动极限」的三种可能定义（都要算）**

| 定义 | 判据 | 意义 |
|---|---|---|
| **检出极限** | 位移能被判定为「非零」的最小值（3σ 判据） | 灵敏度下限 |
| **分辨极限** | 能区分相邻两个位移量的最小间隔 | 分辨率 |
| **可靠极限** | 连续 30 次测量中，始终正确判定方向的最大位移 | 工程可用下限 |

**2.3 概率化输出（你要的「判断极限概率」）**

对每个位移量 Δ，重复 30 次，记录：

```
Δ  = 2mm
正确检出次数      : 30/30   → P_detect = 1.00
方向判断正确次数  : 29/30   → P_correct = 0.97
测量值分布        : 2.03 ± 0.31 mm
误报（Δ=0 时判为有位移）: 1/30 → P_false = 0.033
```

**输出曲线**：
- `P_detect(Δ)` —— 检出概率 vs 位移量（S 形曲线）
- 从曲线上读出 **P=0.5 / 0.9 / 0.99** 对应的位移量，这就是「极限」的三种定义

**这是本计划最有价值的部分** —— 它把「精度」从单一数字变成可决策的概率曲线。

**3.4 一个反直觉的预期**

根据我已完成的数据：


**这意味着「越近越准」的直觉是错的**，你的 20cm 基准可能不是最优工作点。这个必须实测确认。

### 阶段 4：调零实现（P0，你特别问的）

**4.1 「调零」的准确含义**

「调零」有两种：

| 类型 | 定义 | 实现 |
|---|---|---|
| **硬件调零** | 定义某个物理位置为 z=0 | 测量该位置的深度值 `z_ref`，后续都减去它 |
| **软件调零** | 让读数在初始时刻显示 0 | 采集首帧 `z0`，输出 `z[t] - z0` |

**你要的应该是后者，但前者更重要。**

**4.2 推荐的双层调零方案**

```python
z_ref = median(第一批 60 帧的 roi_median_z)     # 实测，不假设
#   同时用钢尺测量物理距离 d_ref，用于后续尺度校准
#   标定系数：k = d_ref / z_ref   （若 k 显著偏离 1，说明有系统偏差）

# 第 2 层：软件零点（每段数据开始时做一次）
z_base = median(前 30 帧)                        # 静置基线
displacement[t] = (roi_median_z[t] - z_base) * k
```

**4.3 关键问题：调零的有效期**

零点是会漂移的。必须回答：

- **调零后多久需要重新调零？**（漂移率）
- **漂移是随机的还是单调的？**（决定能否用线性补偿）

**测量方法**：
静置 10 分钟，每分钟算一次窗口均值，画出漂移曲线。

**实测参考**（我已完成的数据）：
```
300mm 处：漂移 0.05mm（30s 内窗口）
209mm 处：漂移 1.90mm（无滤波）/ 0.38mm（有滤波）
```

漂移在 0.05–1.9mm 量级 —— 对 2–5mm 目标**不可忽略**，必须处理。

**4.4 三种调零策略对比**

| 策略 | 做法 | 适用 |
|---|---|---|
| **绝对零点** | 只用实验开始时的 z_base | 短实验（<1min） |
| **滑动零点** | 用最近 N 帧的中位数作零点 | 连续监测，能跟上慢漂移 |
| **参考物零点** | 画面里固定一个参考块，用它的变化补偿 | 最稳，能消共模漂移 |

**建议方案：参考物零点**。因为：
- 我实测过「箱间相关系数 +0.015」说明不同距离的漂移**基本独立**，所以参考物补偿可能收益有限
- **但**如果参考物与目标在同一距离区间（比如都在 20cm），它们的共模漂移就相关了，补偿有效

**这需要专门实验验证**：同时测「目标块」与「同距离参考块」，看两者漂移的相关性。

## 第三部分：需要你确认的问题

### Q1. 「20cm」的含义

- 是**位置基准**（实验起点），还是**精度极限**（认为这是能测的最近距离）？
- 实测 209mm 处 MDR = 0.20mm，远优于 2–5mm。**所以 20cm 不是精度瓶颈**。
- 那么真正的瓶颈是什么？视场？遮挡？

### Q2. 「扰动」的定义

是 T1（位置移动）、T2（振动）、T3（外力响应）还是 T4（环境扰动）？

### Q3. 「丢掉的 y 轴」怎么处理

- 相机旋转 90°（方式 A），还是软件交换轴（方式 B）？
- 我推荐 A，因为能用 848 高分辨率轴测垂直运动 —— 这是「y 转 x」的真正价值。

### Q4. 「极限」的判定标准

- 检出极限（3σ）、分辨极限、还是可靠极限（连续 N 次正确）？
- 我建议**三个都算**，用 `P_detect(Δ)` 曲线统一表达。

### Q5. 有没有精密平移台？

- 若有：阶段 2 可以做到 0.2mm 步进，能测出绝对下限
- 若无：只能用垫片叠加，最小步进约 0.5–1mm，测不到真正的下限

### Q6. 小棍规格

- 直径、长度、材质、表面（哑光/反光）？
- 这直接决定 A1、A2 的结果
