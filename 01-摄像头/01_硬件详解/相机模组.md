# D435i 相机模组详解

> D435i 的相机模组由 4 个硬件单元组成：左红外相机 + 右红外相机 + RGB 相机 + 红外投射器。

## 1. 模组布局

```
                 ┌─────────────────────────────────────┐
                 │          D435i 正面（俯视示意）       │
                 │                                     │
                 │   ┌─────┐                ┌─────┐    │
                 │   │ IR  │  ◀──基线 50mm─▶  │ IR  │    │
                 │   │ 左  │                │ 右  │    │
                 │   └─────┘                └─────┘    │
                 │   ┌─────┐                ┌─────┐    │
                 │   │ 投  │                │ RGB │    │
                 │   │ 射  │                │ 全  │    │
                 │   │ 器  │                │ 局  │    │
                 │   └─────┘                └─────┘    │
                 │                                     │
                 └─────────────────────────────────────┘
```

## 2. 单元拆解

### 2.1 左右红外相机（IR Stereo Pair）

| 项 | 规格 |
|----|------|
| 用途 | 双目立体匹配（基础深度） |
| 传感器 | OmniVision OV9282（全局快门） |
| 分辨率 | 1280 × 800（有效深度 1280 × 720） |
| 帧率 | 90 fps / 60 fps / 30 fps |
| 像元尺寸 | 3 μm |
| 基线 | 50 mm（精确值，厂家校准） |

> **为什么全局快门**：移动机器人场景下，运动模糊会让双目匹配失败率上升。全局快门 OV9282 是 D435i 适合 SLAM 的关键。

### 2.2 红外投射器（IR Projector）

| 项 | 规格 |
|----|------|
| 用途 | 投射静态随机红外图案，提高低纹理场景匹配成功率 |
| 类型 | 激光二极管 + DOE（衍射光学元件） |
| 波长 | 850 nm（近红外，肉眼微红） |
| 功率 | Class 1 激光（人眼安全） |
| 图案 | 21×21 静态点阵（自由许可证专利） |

**关键事实**：

- 投射器是**静态**图案，不消耗额外算力
- **不影响深度计算精度**，只是提高匹配成功率
- 在黑暗或低纹理环境下是必须的
- **户外强日光会被淹没**，投射器失效

### 2.3 RGB 相机

| 项 | 规格 |
|----|------|
| 用途 | 采集彩色图像，做纹理/检测 |
| 传感器 | OmniVision OV9281（注意：与 IR 模组同代不同型号） |
| 分辨率 | 1920 × 1080 |
| 帧率 | 30 fps |
| 视场角 | 69° × 42°（**比深度窄**） |
| 编码 | MJPEG / YUYV |

**RGB vs 深度视场角不匹配**：RGB 69° < 深度 87°，做 RGB-D 对齐后只能裁切到 69° × 42° 区域。

### 2.4 图像信号处理器（ISP）

D435i 内部有 ASIC 处理：

- IR 立体匹配 → 深度图
- RGB → YUV 转换
- IMU 时戳同步

深度图分辨率 = 左右 IR 共同区域（1280×720 最大）

## 3. 接口与连线

| 信号 | 引脚 |
|------|------|
| USB 3.0 Type-C | 电源 + 数据 |
| 1/4-20 UNC | 标准相机螺纹 |
| 2× M3 | 板级固定 |
| 状态 LED | 蓝色（运行）/黄色（待机）|

### 3.1 USB 带宽

| 分辨率 | 帧率 | 所需带宽 |
|--------|------|---------|
| 1280×720 depth + 1920×1080 RGB | 30 | ~1.4 Gbps |
| 848×480 depth + 640×480 RGB | 60 | ~0.7 Gbps |
| 单 1280×720 depth | 90 | ~1.2 Gbps |

USB 2.0（480 Mbps）**仅能跑 640×480@30 fps 左右**，所以 **必须 USB 3.0**。

## 4. 深度计算原理

```
左 IR 图像 ──┐
             ├──立体匹配算法 (ASIC)──→ 视差图 ──→ 深度图
右 IR 图像 ──┘                         (disparity)  (depth = f*B/d)

IR 投射器 ──┘（在低纹理场景补特征）
```

公式：

```
Z = f * B / d
```

- Z：深度（米）
- f：焦距（像素）
- B：基线 50mm = 0.05 m
- d：视差（像素，d = x_left - x_right）

## 5. 精度与误差源

### 5.1 量化误差

深度被量化为 1mm 步长（Z16 格式）。近距离精度高，远距离变粗：

| 距离 | 量化误差 |
|------|---------|
| 0.3 m | ~0.05 mm |
| 1.0 m | ~0.5 mm |
| 3.0 m | ~5 mm |

### 5.2 主要误差源

| 误差源 | 影响 |
|-------|------|
| 立体匹配歧义 | 远距离 / 反光 / 透明 |
| 多路径反射 | 凹角 / V 形结构 |
| 温度漂移 | 长时间工作后焦距变化 |
| IR 投射器饱和 | 强光下失效 |
| 像素量化 | Z16 格式量化 |
| 镜头畸变 | 边缘偏移，需去畸变 |

### 5.3 视场角盲区

D435i 在相机正前方有一个**最小测量距离 ~ 0.3m**的盲区，更近的物体测不出来。

## 6. 功耗与散热

| 工作模式 | 功耗 |
|---------|------|
| 仅深度 | ~1.5 W |
| 深度 + RGB | ~2.0 W |
| 深度 + RGB + IMU | ~2.3 W |

D435i **无主动散热**，连续运行时机身会发热（外壳温度 ~40°C），**长时间工作建议留散热余量**。

## 7. 物理防护

| 防护 | 等级 |
|-----|------|
| 防尘 | 无（开口式镜头） |
| 防水 | ❌ 无 |
| 抗震 | 一般（无减震设计） |
| 工作温度 | 0 - 50 °C |

⚠️ **工业场景**需要自己加外壳（如 IP65 防水盒）。

## 8. 维护建议

1. **红外镜头勿触**：投射器与 IR 镜头都怕油污，指纹会让深度图像出现黑斑
2. **避开强日光**：户外需要遮阳罩
3. **避免高温**：> 50°C 环境可能触发热降频
4. **USB 线质量**：劣质线会导致丢帧 / 反复重连
5. **定期标定**：相机-IMU 外参建议半年复测一次（机械结构松动）

## 9. 选配配件

| 配件 | 推荐 |
|-----|------|
| USB-C 数据线 | 官方 1m / 3m 主动式线缆 |
| 支架 | Intel 三脚架适配器 |
| 散热 | 自粘散热片 + 风扇（可选） |
| 防水 | 第三方 GoPro 外壳改造 |

## 10. 对比 D455

| 维度 | D435i | D455 |
|------|-------|------|
| 基线 | 50 mm | 95 mm |
| 深度距离 | 0.3-3 m | 0.6-6 m |
| RGB 视场 | 69° | 90°（与深度对齐）|
| IMU | BMI055 | BMI055 |
| 远距离精度 | 一般 | 优秀 |
| 推荐 | 室内 SLAM | 户外 / 远距 |
