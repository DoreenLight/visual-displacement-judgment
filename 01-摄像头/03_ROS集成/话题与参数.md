# ROS2 话题与参数速查

> realsense2_camera 包的话题、参数、launch 完整速查表。

## 1. 话题速查

完整启动 `rs_launch.py` 后的话题（默认 `/camera/` 前缀）：

### 1.1 图像类（sensor_msgs/Image）

| 话题 | 分辨率（默认） | 编码 | 用途 |
|------|--------------|------|------|
| `/camera/color/image_raw` | 640×480 | bgr8 | RGB 原始 |
| `/camera/depth/image_rect_raw` | 640×480 | 16UC1（mm） | 深度图 |
| `/camera/depth_registered/image_rect_raw` | 640×480 | 16UC1 | 对齐深度 |
| `/camera/stereo/left/image_raw` | 640×480 | mono8 | 左 IR |
| `/camera/stereo/right/image_raw` | 640×480 | mono8 | 右 IR |
| `/camera/infra1/image_raw` | 640×480 | mono8 | IR1 |
| `/camera/infra2/image_raw` | 640×480 | mono8 | IR2 |

### 1.2 点云（sensor_msgs/PointCloud2）

| 话题 | 来源 | 启用参数 |
|------|------|---------|
| `/camera/depth/color/points` | 深度对齐到 RGB | `pointcloud.enable:=true` |
| `/camera/depth/points` | 深度原始 | `pointcloud.enable:=true` |

### 1.3 IMU（sensor_msgs/Imu）

| 话题 | 频率 | 类型 | 启用 |
|------|------|------|------|
| `/camera/imu` | 200 Hz | Imu | `enable_gyro:=true enable_accel:=true` |
| `/camera/accel/sample` | 200 Hz | Imu | `enable_accel:=true` |
| `/camera/gyro/sample` | 200 Hz | Imu | `enable_gyro:=true` |

> 注意：`/camera/imu` 是 accel+gyro 合并的单一话题。

### 1.4 元数据

| 话题 | 频率 | 类型 | 用途 |
|------|------|------|------|
| `/camera/color/metadata` | 每帧 | Metadata | RGB 元数据 |
| `/camera/depth/metadata` | 每帧 | Metadata | 深度元数据 |
| `/camera/extrinsics/depth_to_color` | 30 Hz | Extrinsics | 深度→RGB 外参 |
| `/camera/extrinsics/depth_to_infra1` | 30 Hz | Extrinsics | 深度→IR1 外参 |
| `/camera/extrinsics/depth_to_infra2` | 30 Hz | Extrinsics | 深度→IR2 外参 |
| `/camera/extrinsics/depth_to_imu` | 30 Hz | Extrinsics | 深度→IMU 外参 |

### 1.5 相机信息

| 话题 | 类型 | 用途 |
|------|------|------|
| `/camera/color/camera_info` | CameraInfo | RGB 内参 |
| `/camera/depth/camera_info` | CameraInfo | 深度内参 |
| `/camera/stereo/camera_info` | CameraInfo | IR 内参 |
| `/camera/infra1/camera_info` | CameraInfo | IR1 内参 |
| `/camera/infra2/camera_info` | CameraInfo | IR2 内参 |

## 2. launch 参数

`rs_launch.py` 支持的所有参数（按分组）：

### 2.1 全局参数

```yaml
# 相机命名空间
camera_namespace: "/camera/"

# 相机名称
camera_name: "camera"

# 是否连接真实设备（false 时从 bag 回放）
realsense_config:

# 多相机序列号
serial_no: ""               # 空 = 自动选第一台

# USB 端口
usb_port_id: ""             # 空 = 自动

# 设备 ID（Bag 模式用）
device_type: ""

# Bag 回放
rosbag_filename: ""
```

### 2.2 RGB 相机参数

```yaml
rgb_camera.enable: true
rgb_camera.color_profile: "640x480x30"   # 分辨率x帧率
rgb_camera.color_format: "bgr8"          # bgr8 / rgb8 / yuyv / y16
rgb_camera.exposure: 100                 # 曝光（1-10000）
rgb_camera.gain: 64                     # 增益
rgb_camera.auto_exposure: true          # 自动曝光
rgb_camera.auto_white_balance: true
```

### 2.3 深度模块参数

```yaml
depth_module.enable: true
depth_module.depth_profile: "640x480x30"
depth_module.infra_profile: "640x480x30"
depth_module.infra_format: "mono8"
depth_module.infra1_format: "mono8"
depth_module.infra2_format: "mono8"

# 投射器
depth_module.emitter_enabled: 1          # 0=关闭 1=开启 2=交替
depth_module.laser_pulse: 0              # 0=自动
depth_module.depth_units: 0.001         # 深度单位（米）

# 对齐
align_depth.enable: true                # 深度对齐到 RGB
```

### 2.4 IMU 参数

```yaml
enable_gyro: true
enable_accel: true
enable_infra1: true
enable_infra2: true

imu_method: "linear_interpolation"      # 线性插值模式

# 话题拆/合
unite_imu_method: "linear_interpolation" # imu 话题合并度

publish_rosbag_timestamps: false
```

### 2.5 点云参数

```yaml
pointcloud.enable: false                 # 是否发布点云

# 点云选项
pointcloud.stream_filter: 0             # 0=任意流 1=深度 2=彩色
pointcloud.stream_index_filter: 0
pointcloud.ordered_pc: false             # 是否有序点云
```

### 2.6 滤波参数

```yaml
# 空间滤波
spatial_filter.enable: false
spatial_filter.holes_fill: 0
spatial_filter.magnitude: 2
spatial_filter.smooth_alpha: 0.5
spatial_filter.smooth_delta: 20

# 时序滤波
temporal_filter.enable: false
temporal_filter.smooth_alpha: 0.4
temporal_filter.smooth_delta: 20
temporal_filter.persistency_mode: 3

# 空洞填充
hole_filling_filter.enable: false
hole_filling_filter.holes_fill: 1

# 下采样
decimation_filter.enable: false
decimation_filter.magnitude: 2.0
```

### 2.7 同步参数

```yaml
inter_cam_sync_mode: 0                   # 0=关闭 1=主 2=从

# ROS 同步
sync_param:
  sync_mode: 0                           # 0=ApproximateTime 1=ExactTime
  approx_sync_max_interval: 0.05         # 秒
```

### 2.8 TF 参数

```yaml
publish_tf: true                         # 是否发布 TF
tf_publish_rate: 0.0                     # 0=每帧
```

### 2.9 调试参数

```yaml
# 调试
enable_logging: false
log_level: "info"                        # debug/info/warn/error

# 重置
reset_defaults: false
```

## 3. 常用 launch 组合

### 3.1 基础流（默认）

```bash
ros2 launch realsense2_camera rs_launch.py
```

### 3.2 高分辨率 RGB + 对齐 + 点云

```bash
ros2 launch realsense2_camera rs_launch.py \
    rgb_camera.color_profile:=1280x720x30 \
    depth_module.depth_profile:=848x480x30 \
    align_depth.enable:=true \
    pointcloud.enable:=true
```

### 3.3 全流 + 滤波

```bash
ros2 launch realsense2_camera rs_launch.py \
    pointcloud.enable:=true \
    align_depth.enable:=true \
    spatial_filter.enable:=true \
    temporal_filter.enable:=true \
    hole_filling_filter.enable:=true \
    decimation_filter.enable:=true
```

### 3.4 D435i IMU 专用

```bash
ros2 launch realsense2_camera rs_d435i_examples/rs_d435i_depth_and_color_and_IMU_launch.py
```

### 3.5 多相机

```bash
ros2 launch realsense2_camera rs_multi_camera_launch.py \
    camera_name1:=cam_left \
    camera_name2:=cam_right \
    camera1.serial_no:=213722067000 \
    camera2.serial_no:=213722068000
```

### 3.6 Bag 回放

```bash
ros2 launch realsense2_camera rs_from_file.py \
    rosbag_filename:=/path/to/recording.mcap
```

## 4. service 与 action

### 4.1 服务列表

```bash
ros2 service list | grep /camera
```

主要服务：

| 服务 | 类型 | 用途 |
|------|------|------|
| `/camera/device_info` | DeviceInfo | 设备元信息 |
| `/camera/hardware_monitor` | HardwareMonitor | 硬件状态 |
| `/camera/calib_config` | CalibConfig | 校准参数 |
| `/camera/application_config` | ApplicationConfig | 应用参数 |

### 4.2 调试用 service 调用

```bash
# 看温度
ros2 topic echo /camera/hardware_monitor

# 查看设备能力
ros2 service call /camera/device_info \
    realsense2_camera_msgs/srv/DeviceInfo
```

## 5. 时间戳注意事项

### 5.1 device_time vs ROS time

- ROS2 默认使用 host 时间戳（相机把 device time 同步到 host time）
- 但 `/camera/metadata` 里仍包含 device time
- 多机方案需要保证 host 时间同步（NTP）

### 5.2 IMU 与图像时间戳对齐

`realsense2_camera` 用 `linear_interpolation` 把 IMU 数据**对齐**到相机帧时间戳。这意味着：
- `/camera/imu` 的时间戳是 ROS2 /clock
- 同一相机内，IMU 与帧同步到同一时基
- 跨相机需要 ROS2 同步机制

## 6. 工具链

### 6.1 ros2 topic 工具

```bash
# 看所有话题
ros2 topic list

# 看一个话题的频率
ros2 topic hz /camera/depth/image_rect_raw

# 看一个话题的延迟
ros2 topic delay /camera/depth/image_rect_raw

# 看话题带宽
ros2 topic bw /camera/depth/image_rect_raw

# 回显话题
ros2 topic echo /camera/imu
```

### 6.2 Rviz 可视化

```bash
ros2 launch realsense2_examples rs_launch.py &
rviz2
```

在 Rviz 里：
- 添加 `PointCloud2` → topic `/camera/depth/color/points`
- 添加 `Image` → topic `/camera/color/image_raw`
- 添加 `TF`

### 6.3 rqt_graph 看节点关系

```bash
rqt_graph
```

会看到 `camera/camera` 节点发布所有话题。

## 7. 性能调优

### 7.1 帧率上不去

| 原因 | 解决 |
|------|------|
| USB 带宽不够 | 换 USB 3.0 端口 |
| CPU 饱和 | 关闭不用的流 |
| 点云计算慢 | `decimation_filter.enable:=true` |
| 后处理滤波慢 | 关闭 `hole_filling_filter` |

### 7.2 减少话题带宽

```bash
# 关闭不需要的元数据
# （无专门参数，需源码改）

# 降低图像分辨率
rgb_camera.color_profile:=640x480x30

# 关闭立体 IR（如果不需要）
enable_infra1:=false
enable_infra2:=false
```

### 7.3 加速点云

```bash
# 用 decimation（2x 下采样）
decimation_filter.enable:=true
decimation_filter.magnitude:=2.0
```

## 8. 完整 launch YAML 示例

写 `my_camera_launch.yaml`：

```yaml
# /camera1
camera1:
  ros__parameters:
    depth_module:
      depth_profile: "640x480x30"
      emitter_enabled: 1
    rgb_camera:
      color_profile: "1280x720x30"
    align_depth:
      enable: true
    pointcloud:
      enable: true
    spatial_filter:
      enable: true
    temporal_filter:
      enable: true
```

用：

```bash
ros2 launch realsense2_camera rs_launch.py \
    --params-file my_camera_launch.yaml
```
