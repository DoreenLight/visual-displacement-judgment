# 相机内外参标定

> 相机-相机、相机-IMU、相机-机械臂的标定方法汇总。

## 1. 标定类型总览

| 类型 | 标定什么 | 工具 | 用途 |
|------|---------|------|------|
| **相机内参** | 焦距 / 主点 / 畸变 | OpenCV / Kalibr | 图像去畸变、3D 重建 |
| **RGB-D 深度内参** | 深度内参 | OpenCV | 像素 → 3D 转换 |
| **相机-相机外参** | 两相机刚体变换 | Kalibr | 多机立体 |
| **相机-IMU 外参** | 旋转 + 平移 + 时延 | Kalibr | VIO/SLAM |
| **手眼标定** | 相机-机械臂变换 | easy_handeye / OpenCV | 机械臂抓取 |

## 2. 相机内参标定

### 2.1 D435i 出厂内参

D435i 出厂已烧录内参到 EEPROM，可直接使用：

```python
import pyrealsense2 as rs

pipe = rs.pipeline()
pipe.start()

# 读内参
profile = pipe.get_active_profile()
depth_intr = profile.get_stream(rs.stream.depth).as_video_stream_profile().get_intrinsics()
color_intr = profile.get_stream(rs.stream.color).as_video_stream_profile().get_intrinsics()

print(f"深度内参: fx={depth_intr.fx} fy={depth_intr.fy} cx={depth_intr.ppx} cy={depth_intr.ppy}")
print(f"畸变系数: k1={depth_intr.coeffs[0]} k2={depth_intr.coeffs[1]}")
```

### 2.2 用 OpenCV 重新标定

如果出厂内参不够准（机械应力、温度影响），可用棋盘格重新标定：

```python
import cv2
import numpy as np
import glob

# 准备 10-20 张不同角度的棋盘格图像
images = glob.glob('calib_*.png')

# 棋盘格参数
pattern_size = (8, 6)  # 内角点
square_size = 0.025    # 实际格子尺寸（米）

# 准备 object points
objp = np.zeros((pattern_size[0] * pattern_size[1], 3), np.float32)
objp[:, :2] = np.mgrid[0:pattern_size[0], 0:pattern_size[1]].T.reshape(-1, 2)
objp *= square_size

objpoints = []  # 3D
imgpoints = []  # 2D

for fname in images:
    img = cv2.imread(fname)
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    
    ret, corners = cv2.findChessboardCorners(gray, pattern_size, None)
    if ret:
        objpoints.append(objp)
        corners2 = cv2.cornerSubPix(gray, corners, (11, 11), (-1, -1), 
                                     (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001))
        imgpoints.append(corners2)

# 标定
ret, K, dist, rvecs, tvecs = cv2.calibrateCamera(
    objpoints, imgpoints, gray.shape[::-1], None, None
)

print(f"内参矩阵 K:\n{K}")
print(f"畸变系数: {dist}")
print(f"重投影误差: {ret}")
```

### 2.3 Kalibr 标定（推荐）

Kalibr 是 ETH ASL 出品的工具，支持 camera + IMU + 多相机联合标定。

```bash
sudo apt install ros-<dist>-kalibr
```

```bash
# 1. 准备 AprilTag board 标定板（推荐 6x6 或 5x5）
# 2. 录制 bag：相机对着标定板晃动 30s

# 3. 标定单相机
ros2 run kalibr kalibr_calibrate_cameras \
    --target april_6x6.yaml \
    --bag cam_calib.bag \
    --models pinhole-radtan \
    --topics /cam/color/image_raw

# 输出 camchain.yaml：
#   cam0:
#     intrinsics: [fx, fy, cx, cy]
#     distortion: [k1, k2, t1, t2]
```

## 3. 相机-IMU 联合标定（Kalibr）

### 4.1 为什么需要

VIO/SLAM 系统需要：

- IMU 噪声密度（gyro/acc noise density）
- IMU 随机游走（random walk）
- 相机-IMU 旋转 R_b_c
- 相机-IMU 平移 T_b_c
- 相机-IMU 时延 t_d

### 4.2 录制 bag

```bash
# 启动相机（确保 IMU 启用）
ros2 launch realsense2_camera rs_launch.py \
    enable_gyro:=true enable_accel:=true \
    rgb_camera.color_profile:=640x480x30

# 录制（30-60 秒，相机对着 AprilTag 板做激励运动）
ros2 bag record \
    /camera/color/image_raw \
    /camera/imu \
    -o cam_imu_calib.bag
```

### 4.3 录制注意事项

- **激励充分**：相机需要做 6 自由度运动（前后、左右、上下、俯仰、偏航、翻滚）
- **运动不能太快**：避免运动模糊
- **AprilTag 全程可见**：不要让标定板出画
- **时长 60-120 秒**：Kalibr 收敛需要足够数据

### 4.4 运行 Kalibr

```bash
# 1. 准备 IMU 噪声参数（参考值）
cat > imu.yaml << 'EOF'
rostopic: /camera/imu
update_rate: 200.0  # Hz

accelerometer_noise_density: 0.01    # m/s^2/√Hz
accelerometer_random_walk: 0.0002   # m/s^3/√Hz
gyroscope_noise_density: 0.005      # rad/s/√Hz
gyroscope_random_walk: 4.0e-6       # rad/s^2/√Hz
EOF

# 2. 标定
ros2 run kalibr kalibr_calibrate_imu_camera \
    --target april_6x6.yaml \
    --bag cam_imu_calib.bag \
    --cam camchain.yaml \
    --imu imu.yaml \
    --show-extraction
```

### 4.5 输出 camchain-imu.yaml

```yaml
cam0:
  T_BS:
    - [0.9999, -0.0034, -0.0005, 0.0076]   # 旋转 + 平移
    - [0.0034, 0.9999, 0.0017, -0.0017]
    - [0.0005, -0.0017, 0.9999, 0.0099]
    - [0.0, 0.0, 0.0, 1.0]
  time_offset: 0.001                          # 相机-IMU 时延（秒）
  intrinsics: [386.738, 386.738, 320.0, 240.0]
  distortion: [-0.001, 0.002, 0.0, 0.0]
  rostopic: /camera/color/image_raw
  resolution: [640, 480]
```

### 4.6 在 ORB-SLAM3 中使用

```yaml
# ORB-SLAM3 D435i.yaml
TBC:
  - [0.9999, -0.0034, -0.0005, 0.0076]
  - [0.0034, 0.9999, 0.0017, -0.0017]
  - [0.0005, -0.0017, 0.9999, 0.0099]
  - [0.0, 0.0, 0.0, 1.0]

# IMU 噪声（Kalibr 输出）
IMU.NoiseGyro: 1.7e-4
IMU.NoiseAcc: 2.0e-3
IMU.GyroWalk: 1.9e-5
IMU.AccWalk: 3.0e-3
IMU.Frequency: 200
TBC: [-0.00764, -0.00173, 0.00990]  # 1x3 平移
```

## 6. 手眼标定

### 6.1 Eye-in-Hand（眼在手上）

相机装在机械臂末端：

```
[TCP] ── T_handeye ── [Camera]
```

工具：[easy_handeye](https://github.com/IFL-CAMP/easy_handeye2)

```bash
sudo apt install ros-<dist>-easy-handeye2
```

```bash
# 启动标定
ros2 launch easy_handeye2 calibrate.launch.py \
    eye_in_hand:=true \
    robot_base_frame:=base_link \
    robot_effector_frame:=tool0 \
    camera_base_frame:=camera_link \
    marker_frame:=ar_marker_0

# 在 Rviz 里移动机械臂到不同位置
# 标定完成：
ros2 service call /calibrate std_srvs/srv/Trigger
```

### 6.2 Eye-to-Hand（眼在手外）

相机装在工作台：

```
[Base] ── T_handeye ── [Camera]
```

```bash
ros2 launch easy_handeye2 calibrate.launch.py \
    eye_in_hand:=false \
    robot_base_frame:=base_link \
    robot_effector_frame:=tool0 \
    camera_base_frame:=camera_link \
    marker_frame:=ar_marker_0
```

### 6.3 OpenCV 方式

```python
import cv2
import numpy as np

# OpenCV 手眼标定 API（cv2 >= 4.0）
# 注意 OpenCV API 命名不同
R_cam_to_hand, t_cam_to_hand = cv2.calibrateHandEye(
    R_gripper_to_base,    # 机械臂多个姿态的旋转
    t_gripper_to_base,    # 机械臂多个姿态的平移
    R_target_to_cam,       # 每个姿态下标定板→相机的旋转
    t_target_to_cam        # 每个姿态下标定板→相机的平移
)
```

参数说明：
- `R_gripper_to_base, t_gripper_to_base`：从正向运动学获取
- `R_target_to_cam, t_target_to_cam`：从相机标定（ArUco / AprilTag）获取

## 7. 标定精度验证

### 7.1 重投影误差

```python
# OpenCV 标定后看 ret
# ret 应 < 1.0（像素单位），越小越好
print(f"重投影误差: {ret:.4f}")
```

### 7.2 Kalibr 输出

```bash
# 查看 reprojection error
#   应 < 0.5 pixel
#   IMU 误差：重力方向应 < 5°

# Kalibr 输出 result-cam-imu.txt 含详细分析
cat result-imu-cam.txt
```

### 7.3 实测验证

```bash
# 用标定结果启动 SLAM，看初始化是否成功
ros2 run orbslam3_ros2 mono_inertial \
    ORBvoc.txt D435i.yaml

# 如果初始化失败：
# - 重投影误差大 → 重做相机标定
# - IMU 漂移大 → 重做 IMU 校准
# - 时延大 → 重新校准 / 加时延补偿
```

## 8. 标定文件管理

```
calibrations/
├── cam_intrinsics.yaml           # 相机内参
├── cam_imu_calib/               # 相机-IMU
│   ├── camchain-imu.yaml
│   └── imu.yaml
├── stereo_calib/                # 双机
│   ├── camchain.yaml
│   └── imu.yaml
└── handeye/
    ├── handeye_result.yaml
    └── eye_in_hand_pose.yaml
```

版本控制建议：

- 内参变化小 → 一次标定长期使用
- 外参变化中 → 季度复测
- 手眼变换 → 每次机械臂维护后重测

## 9. 常见问题

| 问题 | 排查 |
|------|------|
| 重投影误差 > 1 | 标定板模糊 / 角度不够 |
| Kalibr 初始化失败 | AprilTag 没全部看见 / bag 录制问题 |
| IMU 噪声参数不在范围 | 用 datasheet 默认值 |
| 手眼标定不准 | 机械臂姿态变化太少（< 5） |
| ORB-SLAM3 初始化失败 | TBC 顺序错（Kalibr 输出 quaternion vs Cameta 3x4） |
