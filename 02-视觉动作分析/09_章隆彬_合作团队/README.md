## 证据边界

力矩预测准确、肌电下降或辅助省力不等于患者更主动或训练强度更高。上肢无标记动捕设备/招聘方向不等于已有署名上肢患者闭环论文；下肢研究可作方法迁移参照，不是上肢临床有效性证据。

链路索引只是标题、摘要和已读方法片段的初筛，不是全语料精读或创新定案。后续补齐原件再提取验证对象、输入输出、主动贡献/强度指标和缺失接口；宋教授资料本轮仅修正因迁移而受影响的章教授画像路径，不改其研究内容。
