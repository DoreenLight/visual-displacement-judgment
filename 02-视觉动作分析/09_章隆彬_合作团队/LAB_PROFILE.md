## 6. 与 ViKiT 项目的 3 个交叉点（关键整合）

### 6.1 交叉点 ①：markerless motion capture + 临床步态评估 ⭐⭐⭐⭐⭐

**章隆彬 2025 JBHI**：「Towards clinical application of enhanced timed up and go with **markerless motion capture** and **machine learning** for balance and gait assessment」

→ **直接对应 ViKiT 项目的核心方法**（视觉 → 关节角）。
→ 同样是 markerless + ML，但目标不同：
- 章隆彬：用 markerless + ML 做 **TUG 临床评估**
- ViKiT：用 RGB + 结构化翻译做 **关节角精确预测**
→ **可作为相关工作 / 可能的 baseline**（同领域、同方法路线、不同任务）

### 6.2 交叉点 ②：sEMG → 神经肌肉骨骼 (NMS) 模型

章隆彬的核心是 **NMS + ML 混合模型**实时预测运动意图/关节扭矩：
- sEMG → NMS 模型 → 关节扭矩/运动意图

**ViKiT 是 RGB → 关节角**——**输入信号不同**，**输出表征不同**。

→ 章隆彬的 NMS 思路可以**借鉴为 biomechanical grammar loss 的一部分**（NMS 提供的 forward kinematics / 肌肉张力约束，正好可以作为我们 grammar 中的 FK 项）。

### 6.3 交叉点 ③：跨学科合作潜力

- **章隆彬有 sEMG + EEG + 无标记动捕 + 肌骨建模** 全套设备 → 与 ViKiT 项目互补
- **湖南大学是国家工程研究中心**（机器人视觉感知与控制）→ 学术资源丰富
- **合作可能性**：
  - 数据集共享（markerless motion capture 数据 + 临床 ground truth）
  - NMS 模型集成（把 NMS 作为 FK constraint）
  - 双向验证（ViKiT 在男性，章隆彬在步态评估）
