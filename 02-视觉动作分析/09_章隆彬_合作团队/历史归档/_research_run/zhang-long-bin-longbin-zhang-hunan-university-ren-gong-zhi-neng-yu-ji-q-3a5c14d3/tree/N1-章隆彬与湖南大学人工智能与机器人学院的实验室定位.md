# N1 章隆彬与湖南大学人工智能与机器人学院的实验室定位

> 核心问题：章隆彬在湖南大学人工智能与机器人学院的研究方向、所属团队与跨学科合作网络是怎样的？

> **资料说明**：来源01、02 的 PDF 文件名仅显示姓氏 "Zhang" 与发表期刊，未在所抽取的实体片段中直接给出作者全名 "章隆彬" 与机构 "湖南大学人工智能与机器人学院"。下文以研究主题与方法学证据为主进行刻画，凡涉及"章隆彬团队"之论断，均以方法学链条与署名 Zhang 的两篇论文（Zhang2024-TBME、Zhang2023-TNSRE）为支撑底座；个人身份与机构归属的最终确认需要回到论文首页的作者—单位脚注。

## S1 原始资料依据

**来源01 — Zhang2024-TBME-MuscleTendon（IEEE Transactions on Biomedical Engineering, 2024）**

- 论文主题为 *calibrated EMG-informed neuromusculoskeletal modelling*，核心工具是 Hill-type 肌肉模型（由 De Groote et al. 提出，CE + PE + SE 三元件），建模与求解链为：direct collocation optimal control → muscle redundancy solver → individualised model，目标是为踝关节三块目标肌（gastrocnemius / soleus / tibialis anterior）估计最大等长力 $F_{\max}$、最佳纤维长度 $l_{M,opt}$、肌腱刚度 $k_T$、肌腱松弛长度 $l_{TS}$ 四组肌肉-肌腱参数（来源01）。
- 求解栈：使用 CasADi 做 automatic differentiation，IPOPT 解 nonlinear program (NLP)，并以 trapezoidal integration scheme 对最优控制问题进行数值转录；通用模型为 OpenSim 平台下的 gait10musc18 / gait10dof18musc，初始缩放采用 Modenese et al. 与 Pizzolato et al. 提出的 morphometric scaling，再用 least squares optimization + weight-tuning methodology 在 cost function $J$（EMG term + fiber length term + effort term + reserve actuator term，权重 1 / 1 / 0.1 / 10）下做参数精化（来源01）。
- 实验装备呈现跨国来源：EMG 来自 Noraxon Inc.（AZ, USA）；超声为 Mindray M9（Shenzhen, China 厂家），肌纤维长度由 UltraTrack 追踪（以 gastrocnemius medialis 为代表的小腿肌肉）；运动捕捉来自 Qualisys（Gothenburg, Sweden）；踝关节力矩与角度由 dynamometer 在 5° dorsiflexion、0°/10°/20° plantar 等多个关节位置下记录；EMG 归一化以 Maximum Voluntary Contraction (MVC) 为基准（来源01）。
- 评价设计：以 post-stroke individuals 与 control group 配对对照，使用 cross-validation 比较 individualized model 与 generic (scaled) model 的力矩 RMSE，并以 reserved actuator 处理模型与实测力矩间的残差（来源01）。

**来源02 — Zhang2023-TNSRE-JointTorqueLSTM（IEEE Transactions on Neural Systems and Rehabilitation Engineering, 2023）**

- 论文聚焦 wearable sensors + LSTM 网络在多关节力矩预测中的应用，明确面向 wearable exoskeleton control 场景：assist-as-needed exoskeleton controllers 用于"补足肌肉自身难以产生的那部分力矩"以保证任务完成（来源02）。
- 预测维度覆盖踝背屈/跖屈、膝屈/伸、髋屈/伸与外展/内收等下肢主要自由度；对比策略为 pooled models（用全部 10 种动作数据）/individual models（用单个动作数据）/clustered models（按 cluster analysis 切分后用对应簇数据）三种建模方式，论证 cluster analysis 在 NMS models 与 LSTM networks 两类模型上均能提升估计精度（来源02）。
- 应用面向 motor disorders 群体，包括 spinal cord injury、post-stroke 等，并嵌入 neurorehabilitation / neuromuscular recovery 的临床目标（来源02）。

## S2 核心观点提炼

1. **研究方向定位**：章隆彬团队的研究主线为"标定型 EMG 引导神经肌肉骨骼（NMS）建模 + 数据驱动关节力矩预测 → 下肢外骨骼 AAN 控制"，把肌-腱层级的生理可解释建模与 LSTM 的时序建模能力嫁接到同一闭环（来源01、02）。
2. **学科交叉定位**：横跨 neurorehabilitation（神经康复工程）、biomedical engineering（生物医学工程）与 robotics / control 三个一级方向，体现"AI + 机器人 + 临床康复"的学院级交叉定位（来源02）。
3. **方法学核心资产**：完整闭环包括 EMG + 超声多模态融合采集、direct collocation optimal control、CasADi/IPOPT 优化栈、OpenSim gait10musc18 通用骨骼肌肉模型、muscle redundancy solver 个体化标定、LSTM 时序预测与 cluster analysis 亚组聚类（来源01、02）。
4. **跨地域合作网络**：在仪器层面已呈现"美国 EMG（Noraxon）+ 中国深圳超声（Mindray M9）+ 瑞典哥德堡运动捕捉（Qualisys）"的跨国采购—合作痕迹；在方法学层面与 De Groote、Modenese、Pizzolato、Delabastita 等国际研究者的成果高度耦合，提示存在稳定的国际合作链（来源01）。
5. **临床人群聚焦**：以 post-stroke individuals 为主线人群，配以 spinal cord injury、Parkinson's disease 等运动障碍扩展人群；Healthy Control 与 Post-stroke Group 的对照设计贯穿多篇工作（来源01、02）。
6. **建模层级化演进**：从 morphometric scaling（依赖身高/体重的群体缩放）→ muscle redundancy solver + EMG-informed 个体化标定 → cluster analysis 亚组聚类，呈现"通用模型 → 个体化模型 → 亚组聚类模型"的递进式建模策略升级（来源01、02）。

## S3 与其他节点的关系

- **神经肌肉骨骼建模的理论基础与 Hill-type 肌肉模型**：本节点的方法学基石即为 Hill-type 肌肉模型（CE + PE + SE）与力-长 / 力-速 / 腱力-长关系，是团队建模工作的理论锚点（来源01）。
- **基于 EMG + 超声的个体化肌肉-肌腱参数标定**：本节点是这一子节点方法的直接实践者；EMG（Noraxon）+ 超声（Mindray M9 / UltraTrack）的组合，以及针对 GAS / SOL / TA 三块踝部肌肉的 $F_{\max}$ / $l_{M,opt}$ / $k_T$ / $l_{TS}$ 标定流程，均在来源01中得到完整描述（来源01）。
- **卒中后踝关节肌-腱力学改变的量化与对照研究**：与本节点来源01直接对应；Post-stroke Group 与 Healthy Control 在踝关节肌-腱参数与关节力矩 RMSE 上的对照、Shapiro-Wilk 正态性检验与 cross-validation 设计，是该子节点的方法论骨架（来源01）。
- **基于 LSTM 与 NMS 模型的多关节关节力矩预测**：与本节点来源02直接对应；pooled / individual / clustered 三种 LSTM + NMS 建模策略的比较是该子节点的核心实验（来源02）。
- **基于聚类分析的个体化运动模式建模**：本节点来源02明确将 cluster analysis 作为提升 NMS 与 LSTM 估计精度的中间步骤，是该子节点的实证来源（来源02）。
- **下肢外骨骼的按需辅助（AAN）控制策略**：本节点的研究落点即此子节点；LSTM / NMS 预测的多关节力矩被用于驱动 assist-as-needed exoskeleton controllers，实现"肌肉能做的让肌肉做、做不到的由外骨骼补足"的临床康复思路（来源02）。
- **多模态实验采集与跨地域合作网络**：本节点来源01中 Noraxon/Mindray/Qualisys 的跨国设备来源与 De Groote、Modenese、Pizzolato 等方法学谱系，是此节点的实证支撑（来源01、02）。

## S4 在主线中的位置

本节点是整条知识树的 **根/总纲层**，承担"人—团队—方向—合作网"的索引功能：

- **向上**：不引入新方法或新数据，而是把分散在多篇论文中的研究线索汇聚为可追溯的研究者画像，使后续 7 个子节点共享同一团队语境。
- **向下**：为后续每个技术子节点（建模理论 → 参数标定 → 临床对照 → LSTM/NMS 力矩预测 → 聚类个体化 → 外骨骼 AAN 控制 → 多模态采集网络）提供"由谁做—用什么做—为谁做"三要素的归属锚点。
- **核心价值**：在后续阅读任意子节点时，可回溯到本节点确认该方法/数据/结论是否归属于同一研究主线，从而避免把不同团队、不同语境下的同名方法（如"个体化建模""聚类分析""按需辅助"）混为一谈。
