# N8 多模态实验采集与跨地域合作网络

> 核心问题：Qualisys 动捕、Noraxon EMG、Mindray 超声、测力台等实验装备与深圳/哥德堡等跨地域合作如何支撑其研究链条？

## S1 原始资料依据

### 来源01：Zhang2024-TBME（《IEEE Transactions on Biomedical Engineering》肌肉-肌腱参数标定论文）

- **装备供应商与地理分布**：Noraxon Inc. 位于美国亚利桑那州（Arizona, USA），是论文中使用的 EMG 系统的制造商（来源01）；Mindray M9 便携式彩色超声诊断仪由位于中国深圳的迈瑞医疗生产，论文将其作为踝关节肌群（腓肠肌、比目鱼肌、胫骨前肌）肌束长度采集设备（来源01）；Qualisys 位于瑞典哥德堡（Gothenburg, Sweden），论文使用其运动捕捉系统采集关节运动学（来源01）。
- **多模态数据采集分工**：EMG 用于测量肌肉激活（muscle activation）（来源01）；超声（Ultrasound）用于记录肌纤维长度（muscle fiber length），并通过 UltraTrack 软件进行逐帧追踪（来源01）；测力台/测力计（Dynamometer）用于测量踝关节关节角度（joint angle）和实测关节力矩（measured joint torque）（来源01）。
- **数据处理工具链**：Butterworth 滤波器用于 EMG 信号预处理；通用肌肉骨骼模型 gait10musc18（De Groote et al.）在 OpenSim 中实现（来源01）；直接配点法（direct collocation）将最优控制问题转录为非线性规划（NLP），由 IPOPT 求解器求解，CasADi 用于自动微分（automatic differentiation），并采用梯形积分（trapezoidal integration scheme）（来源01）。
- **实验设计要点**：受试者在多个踝关节角度下完成最大自主收缩（MVC），记录踝背屈 5°、跖屈 0°、跖屈 10°、跖屈 20° 等位置的力矩（来源01）；Shapiro-Wilk 检验用于检查估计参数的正态性（来源01）；三块目标肌肉为 GAS（腓肠肌）、SOL（比目鱼肌）、TA（胫骨前肌），分别承担跖屈（plantarflexion）和背屈（dorsiflexion）（来源01）。
- **个体化标定结果**：基于 EMG 与超声的"calibrated EMG-informed neuromusculoskeletal modelling"框架，muscle redundancy solver 算法估计了 F_max、l_M,opt、k_T、l_TS 四个 Hill-type 关键参数；交叉验证表明 Individualized model 的 RMSE 显著低于 Generic model（来源01）。
- **算法细节**：成本函数 J 由四项组成——EMG 项（权重 1）、肌纤维长度项（权重 1）、effort 项（权重 0.1）、reserve actuator 项（权重 10），并使用 weight-tuning methodology（来源01）；reserve actuator 被加在踝关节上以补偿建模误差（来源01）。

### 来源02：Zhang2023-TNSRE（《IEEE Transactions on Neural Systems and Rehabilitation Engineering》LSTM 关节力矩预测论文）

- **研究对象与背景**：针对脊髓损伤（Spinal cord injury）、脑卒中后（Post-stroke）等运动障碍（motor disorders）人群，研究如何用 NMS 模型与 LSTM 网络预测踝背/跖屈、膝屈/伸、髋屈/伸、髋外展/内收等多关节关节力矩（joint torque），支撑可穿戴外骨骼（AAN exoskeleton controllers）的按需辅助控制（来源02）。
- **方法路线**：逆向动力学（Inverse dynamics）提供关节力矩真值；对比 Pooled models、Individual models 与 Clustered models 三种建模粒度，其中聚类分析（Cluster analysis）基于动作特征相似度（characteristic similarity）将 10 种运动（10 movements）分组，提升 NMS 与 LSTM 估计精度（来源02）。
- **神经网络基线**：论文对比了 ANN 与 MLP 模型，并将 LSTM 与 NMS 在不同粒度下的表现进行评估（来源02）。

## S2 核心观点提炼

1. **装备-数据-模型形成三层闭环**：Qualisys 动捕提供运动学、Noraxon EMG 提供肌肉激活、Mindray M9 超声 + UltraTrack 提供肌纤维长度、测力台/测力计提供实测关节力矩——四路信号同步采集后喂入基于 Hill-type 肌肉模型的 muscle redundancy solver，从而完成个体化肌肉-肌腱参数标定（来源01）。这一多模态闭环使"实测数据驱动模型标定、模型预测与实测力矩交叉验证"成为可能。
2. **跨地域装备组合体现资源最优配置**：美国 Noraxon（EMG）、中国深圳 Mindray（超声）与瑞典哥德堡 Qualisys（动捕）的组合，将国际主流商用设备按性能/可及性最优整合到同一实验流程中，反映了深圳与哥德堡两个节点在生物力学研究链条上的协同分工（来源01）。
3. **采集装备直接服务于"EMG-driven + Ultrasound-informed"建模范式**：EMG 测肌肉激活、超声通过 UltraTrack 测肌束长度，二者被同时嵌入直接配点最优控制问题的成本函数 J（EMG 项 + 肌纤维长度项），使个体化模型 RMSE 显著低于通用缩放模型（来源01）。
4. **运动学+动力学采集是 AAN 外骨骼控制的基础**：来源02 中明确指出，逆向动力学得到的关节力矩真值用于训练/评估 LSTM 与 NMS 模型，并支撑 Pooled / Individual / Clustered 三种粒度的建模比较，最终用于 AAN 按需辅助控制——这意味着同一套实验采集链不仅是离线建模工具，也是外骨骼实时控制的数据底座（来源02）。
5. **聚类分析依赖多模态运动学数据**：来源02 的 cluster analysis 基于 10 种运动的关节运动学特征做分组，证明多模态采集系统产出的高质量运动学数据是实现"个体化运动模式建模"的必要前提（来源02）。
6. **跨地域合作是设备-算法-临床闭环的物理承载**：深圳（中国，迈瑞超声）与哥德堡（瑞典，Qualisys 总部）的协同，叠加美国 Noraxon 的 EMG 与本地测力台，使数据采集、算法开发（IPOPT/CasADi/OpenSim）与临床/康复应用（AAN 外骨骼）三条线能够在统一框架内整合（来源01、来源02）。

## S3 与其他节点的关系

- **与"章隆彬与湖南大学人工智能与机器人学院的实验室定位"节点**：本节点是实验室"神经肌肉骨骼建模 + 康复机器人"定位的硬件与方法学支撑——多模态采集网络决定了实验室能产出什么类型的真实数据，从而决定其研究链条的边界。
- **与"神经肌肉骨骼建模的理论基础与 Hill-type 肌肉模型"节点**：Hill-type 模型的四个关键参数（F_max、l_M,opt、k_T、l_TS）正是本节点装备采集的对象——EMG 对应激活信号，超声对应 l_M，测力台对应力矩输出，三者通过 muscle redundancy solver 反解出参数（来源01）。
- **与"基于 EMG + 超声的个体化肌肉-肌腱参数标定"节点**：本节点提供 Noraxon EMG 与 Mindray M9 超声两条核心数据流，并直接驱动 direct collocation + IPOPT/CasADi 的标定流程（来源01）。
- **与"卒中后踝关节肌-腱力学改变的量化与对照研究"节点**：本节点装备同步采集脑卒中组与健康对照组的多模态信号，是开展 GAS/SOL/TA 三块肌肉个体化参数对照比较的实验基础（来源01）。
- **与"基于 LSTM 与 NMS 模型的多关节关节力矩预测"节点**：来源02 中 LSTM 与 NMS 模型的训练数据（运动学 + 力矩）均由本节点装备产出，多关节力矩预测精度直接依赖 Qualisys 与测力台的数据质量（来源02）。
- **与"基于聚类分析的个体化运动模式建模"节点**：聚类分析的输入——10 种运动的关节运动学特征——来自 Qualisys 动捕系统（来源02）。
- **与"下肢外骨骼的按需辅助（AAN）控制策略"节点**：AAN 控制策略以关节力矩估计为核心反馈，而关节力矩估计的数据来源正是本节点装备产出的多模态信号（来源02）。

## S4 在主线中的位置

本节点是整个研究链条的**"数据底座"层**，位于"理论模型 → 实验采集 → 个体化标定 → 临床应用"主线的最前端。它向上为 Hill-type 建模节点提供参数来源、为 EMG+超声标定节点提供原始信号、为 LSTM/NMS 预测节点提供训练数据；向下承接实验室定位，决定研究链条的可行性与精度边界。没有这一多模态、跨地域的采集网络，后续所有个体化建模、力矩预测与 AAN 控制都无从落地——本节点是连接"理论"与"康复机器人应用"之间不可或缺的桥梁。
