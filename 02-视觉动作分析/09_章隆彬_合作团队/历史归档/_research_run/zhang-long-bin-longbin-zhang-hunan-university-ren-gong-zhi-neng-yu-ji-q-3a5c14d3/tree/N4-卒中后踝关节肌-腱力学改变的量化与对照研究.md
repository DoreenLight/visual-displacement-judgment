# N4 卒中后踝关节肌-腱力学改变的量化与对照研究

> 核心问题：脑卒中患者与健康对照相比，在 GAS/SOL/TA 三块踝部肌肉的最大等长力、肌腱刚度、最佳纤维长度等参数上有何系统改变？

## S1 原始资料依据

### 来源01：Zhang et al., IEEE Trans. Biomed. Eng., 2024（个体化 EMG 标定的卒中后踝关节肌-腱参数估计）

**1) 研究目的与对照设计**：该研究聚焦踝关节 muscle-tendon unit（肌-腱单元）的力学参数，招募 post-stroke individuals（脑卒中患者）与 able-bodied individuals（健康对照）进行量化对比，是当前少数在**同一标定流程**下对两组人群 GAS / SOL / TA 三块肌肉参数做系统对照的工作。（来源01）

**2) Hill-type 肌肉模型与待估计参数**：研究采用 De Groote et al. 提出的 Hill-type muscle model，由 contractile element (CE)、series elastic element (SE)、parallel elastic element (PE) 三部分组成，分别由 force-length、force-velocity、tendon force-length 关系描述肌肉与肌腱力学行为。（来源01）
研究估计的目标参数集为：
- 最大等长力 **F_max**（maximum isometric force）；
- 最佳纤维长度 **l_M,opt**（optimal fiber length）；
- 肌腱刚度 **k_T**（tendon stiffness）；
- 肌腱松弛长度 **l_TS**（tendon slack length）。（来源01）

**3) 肌肉冗余求解器与直接配点法（direct collocation）**：通过 muscle redundancy solver 算法把肌力分配（muscle redundancy）问题表达为 optimal control problem，状态量为肌肉激活 a(t) 与肌腱力 F_MT(t)，控制量为肌肉激发 u(t) 与踝关节 reserve actuator 力矩 τ_r(t)；用 trapezoidal integration scheme 离散，并用 IPOPT + automatic differentiation (CasADi) 解 NLP 问题。（来源01）

**4) 代价函数 J 设计**：J 由四项加权构成：
- EMG 项：度量模拟肌肉激发与归一化 EMG 信号的差异；
- Fiber length 项：度量模拟肌纤维长度与超声测得肌纤维长度的差异；
- Effort 项：对控制量正则化；
- Reserve actuator 项：惩罚踝关节冗余执行器力矩。
四项权重通过 weight-tuning methodology 设置为（1, 1, 0.1, 10），其中 reserve actuator 项被赋予最大权重以约束非肌肉源力矩尽量小。（来源01）

**5) 个体化标定流程**：使用 OpenSim 中的 gait10musc18（generic musculoskeletal model, 10 DoF / 18 muscles）作为骨架，先做 anthropometric scaling 得到 scaled model，再用 EMG、ultrasound、motion capture、dynamometer 等多模态数据驱动 muscle redundancy solver，得到 individualized model。流程中使用 UltraTrack 跟踪超声序列中的肌纤维长度。（来源01）

**6) 实验设置与设备**：
- EMG：Noraxon Inc.（AZ, USA）系统（来源01）
- 超声：Mindray M9（深圳），用于在踝关节 5° dorsiflexion、0° plantar、10° plantar、20° plantar 等角度下记录肌纤维长度及最大肌纤维长度（来源01）
- 运动捕捉：Qualisys（Gothenburg, Sweden）系统（来源01）
- 力矩测量：Dynamometer 测量 ankle joint angle 和 measured joint torque；（来源01）
- Butterworth filter 用于信号预处理；（来源01）
- 通过 MVC（Maximum voluntary contraction）归一化 EMG，幅值以 m-unit 度量。（来源01）

**7) 跨地域实验网络**：深圳（超声）+ Gothenburg（动捕）+ AZ USA（EMG）的多模态跨地域实验采集网络支撑个体化标定。（来源01）

**8) 评估方法**：用 cross-validation method 在 generic model 与 individualized model 之间对比，并用 Shapiro-Wilk test 检查参数估计的正态性，以 RMSE 作为主要误差指标。（来源01）

**9) 主要量化发现（与本节点直接相关）**：关系三元组明确指出：
- post-stroke individuals → have lower → maximum isometric force（来源01）
- post-stroke individuals → have lower → tendon stiffness（来源01）
- post-stroke individuals → have lower → optimal fiber length（来源01）
- individualized model → has lower → RMSE（特别是在 Post-stroke group 中相对于 generic model）（来源01）
- post-stroke group → is compared with → control group（来源01）

**10) 解剖与生理背景**：
- 卒中影响 central nervous system，并引起 skeletal muscles 的二次改变；（来源01）
- ankle plantarflexors（含 GAS、soleus）于 stance phase 活动，对抗 external dorsiflexion moment；（来源01）
- ankle dorsiflexors（含 TA）于 swing phase 活动，实现 foot clearance；（来源01）
- GAS 与 SOL 同属 triceps surae muscle complex，通过 achilles tendon 串联（shares_tendon_with），因此它们的 tendon stiffness 实际是同一根 Achilles tendon 的刚度；（来源01）
- Gastrocnemius / Soleus 作用于 Ankle plantarflexion，TA 作用于 Ankle dorsiflexion。（来源01）

### 来源02：Zhang et al., IEEE Trans. Neural Syst. Rehabil. Eng., 2023（LSTM + NMS 关节力矩预测与聚类建模）

- 同一研究组在康复工程层面把 NMS 模型与 LSTM 网络用于下肢多关节力矩预测，包括 ankle dorsiflexion/plantarflexion、knee flexion/extension、hip flexion/extension、hip abduction/adduction，覆盖 post-stroke 与 spinal cord injury 等 motor disorders 人群。（来源02）
- 在 joint torque 预测层面对 NMS 模型与 inverse dynamics 做基准比较，并发现 individual NMS models 与 clustered NMS models 均具良好估计精度，而 pooled model 对个别动作模式过于 generic。（来源02）
- Cluster analysis 基于 characteristic similarity 对踝背屈/跖屈等动作分组，用于在 NMS / LSTM 框架下提高估计精度，是 post-stroke 个体化建模的辅助手段。（来源02）
- 该研究同时服务于 wearable exoskeleton 控制中的 Assist-as-needed（AAN）需求，强调 joint torque 的精确估计是实现"按需辅助"的前提。（来源02）

## S2 核心观点提炼

**1) GAS/SOL/TA 三块踝部肌肉的 MTU 参数在卒中后呈现"系统性下调"**：根据 Zhang2024-TBME 的对照研究，post-stroke 个体相对健康对照在 GAS、soleus、TA 上普遍表现为 **F_max 降低、tendon stiffness 降低、optimal fiber length 降低**——这是本节点关于"系统改变"的最核心定量结论。（来源01）

**2) 这种下调同时具有"机制性"和"功能性"含义**：
- 机制上：卒中首先损伤 central nervous system，然后通过废用、痉挛、运动单元丢失等通路引发 skeletal muscles 的 secondary alterations，表现为肌力产生能力和肌腱力学传递能力的整体退化；（来源01）
- 功能上：plantarflexors（PF）力矩能力下降会损害 stance phase 推进与 tibial advancement 控制；dorsiflexors（DF）能力下降会损害 swing phase 的 foot clearance，二者共同导致 post-stroke gait 的 PF_GAS / PF_SOL / DF 力矩曲线异常。（来源01）

**3) GAS 与 SOL 共享 Achilles tendon，使 MTU 参数估计必须考虑肌腱共享**：triceps surae muscle complex 中 GAS 与 SOL 通过 achilles tendon 串联，二者的 tendon stiffness 实质上是同一根肌腱的刚度；因此跨肌肉对照需特别小心"同一根肌腱 vs 不同肌肉" 的混淆，Zhang2024 在模型中显式建立了这一耦合。（来源01）

**4) 个体化 EMG-informed 标定在卒中组提升尤为显著**：individualized model 的 RMSE 显著低于 generic model，且 post-stroke group 的提升幅度大于健康组（其原文表达为 individualized model has lower RMSE，特别体现在 Post-stroke group），说明卒中群体的参数漂移更严重，更需要个体化标定而非 anthropometric scaling。（来源01）

**5) 直接配点 + EMG/超声多模态数据是把肌-腱参数"可观测化"的关键**：
- 通过 dynamic optimization（direct collocation）将 muscle redundancy 写为含 EMG 项、fiber length 项、effort 项、reserve actuator 项的多目标优化（权重 1/1/0.1/10）；（来源01）
- 用 normalized EMG 信号约束 u(t)、用超声测得的 muscle fiber length 约束 l_M(t)，从而把不可直接测的 F_max、l_M,opt、k_T、l_TS 变为可估计量；（来源01）
- ultrasound（Mindray M9）记录 maximal measured fiber length，UltraTrack 离线跟踪肌纤维束长；（来源01）

**6) 节点 N4 是后续 NMS / LSTM / 聚类 / AAN 控制链条的"参数层根基"**：Zhang2023-TNSRE 表明，joint torque 预测、clustered NMS/LSTM 模型以及 AAN 外骨骼控制都依赖于可靠的 subject-specific muscle-tendon parameters；N4 给出的 GAS/SOL/TA 参数集直接成为这些下游任务（关节力矩预测、按需辅助力矩补偿）的输入。（来源02）

## S3 与其他节点的关系

- **与"神经肌肉骨骼建模的理论基础与 Hill-type 肌肉模型"节点**：Hill-type muscle model（CE + SE + PE）是 N4 估计 F_max、l_M,opt、k_T、l_TS 的统一数学载体；N4 通过 De Groote 的 Hill-type 实现把肌肉激发→肌纤维动力学→肌腱力→关节力矩的链条打通，因此本节点是"理论基础"在踝关节三块肌肉上的实证落地。（来源01）

- **与"基于 EMG + 超声的个体化肌肉-肌腱参数标定"节点**：N4 直接采用了该节点所述方法——EMG（Noraxon）+ 超声（Mindray M9，UltraTrack 后处理）+ motion capture（Qualisys）+ 力矩计（Dynamometer）+ MVC 归一化，且通过 optimal control problem 中的 EMG 项和 fiber length 项同时拟合两类信号，从而得到 individualized model。（来源01）

- **与"基于 LSTM 与 NMS 模型的多关节关节力矩预测"节点**：Zhang2023 在 NMS 与 LSTM 框架中预测包括 ankle dorsiflexion/plantarflexion 在内的多关节力矩；其精度受输入 MTU 参数质量直接影响。N4 输出的 GAS/SOL/TA 参数即 LSTM/NMS 前向预测的"先验"输入，二者构成"参数标定→力矩预测"上下游。（来源02）

- **与"基于聚类分析的个体化运动模式建模"节点**：Zhang2023 显示 clustered models 在 joint torque 估计中优于 pooled model；而能否可靠聚类，又取决于每个 subject 的 MTU 参数是否能被 N4 区分清楚。若 GFM 与 IFM 的 RMSE 在卒中组仍很大，聚类的前提就会动摇。（来源02）

- **与"下肢外骨骼的按需辅助（AAN）控制策略"节点**：AAN 的目标是"只补足患者自身不足的那部分肌力矩"，因此需要先知道 patient-specific 的 F_max、k_T 等。N4 给出的"post-stroke 患者 F_max 显著低于健康对照"是 AAN 控制律设定的关键边界条件。（来源01，来源02）

- **与"多模态实验采集与跨地域合作网络"节点**：N4 的数据采集依赖深圳（超声）、Gothenburg（Qualisys 动捕）、AZ USA（Noraxon EMG）的跨地域设备协同；这一实验网络是 N4 得以同时拿到 EMG、超声纤维长度、关节运动学和关节力矩的前提。（来源01）

- **与"章隆彬与湖南大学人工智能与机器人学院的实验室定位"节点**：上述两篇 TBME / TNSRE 论文均来自同一研究组（湖南大学人工智能与机器人学院），N4 是其在 post-stroke 肌-腱参数标定方向的核心实证产出，奠定了该实验室在"个体化神经肌肉骨骼建模 + 外骨骼辅助"研究主线中的关键节点位置。（来源01，来源02）

## S4 在主线中的位置

本节点处于**"建模 → 标定 → 估计 → 控制"主线中的"标定层"**，是连接"理论模型"与"下游应用"的桥梁：

```
[理论基础：Hill-type 肌肉模型 + NMS 框架]    ── 来源01，来源02
        │
        ▼
[N4 卒中后踝关节肌-腱力学改变的量化与对照研究]    ← 当前节点
        │  → 输出：patient-specific F_max, l_M,opt, k_T, l_TS (GAS/SOL/TA)
        ▼
[LSTM + NMS 关节力矩预测]                    ── 来源02
        │
        ▼
[聚类分析的个体化运动模式建模]                ── 来源02
        │
        ▼
[AAN 下肢外骨骼按需辅助控制]                  ── 来源02
```

在整条研究主线上，N4 的不可替代性体现在三点：
1. **填补"卒中后踝关节 GAS/SOL/TA 的 MTU 参数到底如何变"的定量空白**——明确给出三块肌肉 F_max ↓、k_T ↓、l_M,opt ↓ 的系统性下调结论（来源01）；
2. **打通"EMG + 超声 + 运动学 + 力矩"四模态到 Hill-type 参数的求解路径**——以 direct collocation + muscle redundancy solver 给出可复现的个体化标定流程（来源01）；
3. **为下游 joint torque 估计与 AAN 控制提供 subject-specific 的真实参数边界**——使得基于 LSTM/NMS 的力矩预测与按需辅助成为可校准、可验证的工程方案，而不是停留在群体平均或缩放层面（来源01，来源02）。
