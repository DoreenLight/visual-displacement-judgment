## A R T I C L E I N F O

关键词：儿童 柔韧性扁平足 步态模式恢复 足底压力分布 压力中心 队列研究

## A B S T R A C T

儿童时期的柔韧性扁平足通常会自发恢复正常。然而，在此过程中，步态模式是否会同步调整以及这种调整的机制尚不明确。我们通过一项为期两年的随访研究，从足底负荷和步态稳定性的角度，探讨了扁平足自然恢复后儿童步态模式改变的潜在机制。经过广泛的样本筛选，共纳入恢复组的 15 名扁平足儿童和对照组的 17 名正常发育儿童。使用 Footscan® 压力板每隔 12 个月进行一次足底压力和压力中心（Center Of Pressure, COP）的数据采集，共采集三次。采用独立样本 t 检验和统计参数图（statistical parametric mapping）分析探讨每次测量时恢复组与对照组之间的差异。在基线时，恢复组表现出较高的中足负荷和更向外侧偏移的 COP。在第 12 个月时，恢复组在外侧前足表现出显著更低的负荷比例，但标准化最大受力更高。在第 24 个月时，恢复组转变为在第二跖骨头下方表现出明显更高的负荷比例，并在支撑相末期伴有更向外侧和后方的 COP 位移。在儿童期柔韧性扁平足形态的恢复过程中，步态模式最终表现出显著改善，同时在不同阶段呈现出不同特征。本研究揭示了儿童扁平足自然恢复后的生物力学适应机制，有助于全面理解儿童扁平足的影响。

## 1. 引言

柔韧性扁平足在儿童中普遍存在，并表现出独特的步态模式特征（Salinas-Torres et al., 2023; Xu et al., 2022）。足弓塌陷会导致足底压力分布异常，从而增加拇外翻和跖骨痛等损伤的风险（Bohm ¨ et al., 2024）。大量研究已从动力学、运动学及其他相关特征的角度评估了扁平足干预方法的有效性（Kanatli, Aktas and Yetkin, 2016; Zhang et al., 2022; Cherni et al., 2022; Hu et al., 2024; Utsahachant et al., 2023; Persiane et al., 2023）。

儿童柔韧性扁平足的一个显著特征是，大多数患儿的足弓会随着年龄的增长而自发恢复（Yin et al., 2018）。鉴于现有研究尚未证实干预治疗比自然矫正更为有效，一些研究人员认为，对儿童柔韧性扁平足进行过度干预是没有必要的（Pfeiffer et al., 2006; Sutherland, 1977）。然而，大多数关于儿童柔韧性扁平足自发恢复的研究主要从人口统计学和影像学角度开展。极少有研究关注该群体在恢复前后步态功能和特征的变化。其原因之一在于，在足弓恢复前很难识别出这些儿童；第二个原因则源于一种普遍观念，即一旦塌陷的足弓自然恢复正常，其步态模式特征也会随之恢复，无需额外的监测和干预。然而，这一观点缺乏坚实的生物力学证据支持。对于可自愈的儿童柔韧性扁平足，干预真的毫无必要吗？随着足弓的自然恢复，步态模式会自动恢复正常吗？步态异常是否仍会带来潜在风险？这些未解决的问题阻碍了儿童扁平足科学预后管理措施的制定，并可能使儿童在扁平足恢复后仍面临足部损伤的风险。

据我们所知，目前尚无研究评估柔韧性扁平足儿童恢复后的步态模式。足底压力分布和压力中心（Center Of Pressure, COP）是评估扁平足步态模式及潜在损伤风险的关键指标（Panaet et al., 2023; Khan et al., 2023; Zhang et al., 2022）。因此，本研究旨在通过评估足底负荷和步态稳定性，探究扁平足儿童在为期两年的随访期内自然恢复后步态模式的变化机制。我们重点探讨在没有临床或物理干预的情况下，步态模式如何随着足弓随年龄的自然发育而演变。了解足弓恢复后步态模式的变化将为柔韧性扁平足儿童的生物力学适应提供新的见解。

## 2. 材料与方法

## 2.1. 参与者

参与者选自一项关于儿童足部生物力学的大型纵向研究，该研究已获得四川大学伦理委员会（Ethics Committee of Sichuan University）的批准。最初，从当地一所小学招募了 1285 名儿童。所有参与者均健康且年龄在 7 至 10 岁之间。本研究的受试者纳入标准如下：（1）年龄为 7–8 岁；（2）健康且体重正常的儿童，无任何肌肉骨骼疾病、足部疼痛或下肢手术史；（3）在获得家长同意后自愿参与。具体而言，本研究包括恢复组（recovery group, RG）和对照组（control group, CG）。对于 RG，采用了进一步的纳入标准：参与者在基线时表现为扁平足姿态，并且在第二次和第三次测量时，其足部姿态在没有任何临床或物理干预的情况下自然发育为正常足弓。关于 CG，补充纳入标准是在整个随访期间始终表现为正常的足部姿态。此外，为了尽量减少潜在混杂因素的影响，我们控制了年龄、身高、体重、BMI、穿鞋习惯和体力活动水平等变量。受试者筛选过程如图 1（Fig. 1）所示。正常体重的定义基于世界卫生组织（World-Health-Organization, 2024）建议的 BMI 范围。扁平足的判定基于 Cavanagh 等人提出的足弓指数（Arch Index, AI）（Cavanagh and Rodgers, 1987），其中 AI 通过以下公式计算：

$$
A I = \frac {\text { midfootcontactarea }}{(\text { forefoot } + \text { midfoot } + \text { rearfoot }) \text { contactarea }}
$$

具体而言，AI 值小于 0.21 表示高足弓，介于 0.21 和 0.26 之间表示正常足弓，大于 0.26 则表示扁平足。

## 2.2. 实验步骤

实验持续了两年，分别在基线、12个月和24个月进行了三次测量。步态生物力学在扁平足恢复前的基线期进行评估。采用一块 1-m Footscan® 足底压力板（RSscan International, Belgium）采集受试者赤足自然行走时的动态足底压力数据，采样频率为 250 Hz。该平台嵌入在一条 7 m 长的步道中央。在适应期内，指导受试者采用两步起步方案（two-step initiation protocol）（Meyers-Rice et al., 1994; Taylor, Menz and Keenan, 2004）以轻松的步速走过步道。凡是受试者因刻意瞄准压力板而改变步态、导致临时换脚或拖步的测试，均视为无效。每位受试者均需完成五次有效测试，以确保实验数据的准确性和可靠性。在首次实验前，我们向每位受试者及其家长详细解释了实验流程，并获得了知情同意。

## 2.3. 数据处理与统计分析

在 Footscan® 软件中将足部分为十个区域，如图 2 所示：拇趾（T1）、其余脚趾（T2-5）、第1至第5跖骨（M1、M2、M3、M4、M5）、中足（MF）、足跟内侧（HM）以及足跟外侧（HL）。提取了最大力、力-时间积分和压力中心（Center Of Pressure, COP）。最大力根据体重进行了归一化，作为标准化最大力（SMaxF）。相对力-时间积分（RFTI）是指各足底区域与全足负荷的比值，用于评估足底负荷分布。

对于压力中心（COP）坐标，y轴定义为从足跟中部穿过第二跖骨中部延伸至前足的连线，代表前后方向。x轴与y轴垂直，代表内侧-外侧方向。x轴和y轴上的正值分别代表内侧和前向。导出的COP坐标首先使用截止频率为 50 Hz 的四阶低通巴特沃斯滤波器（Butterworth filter）进行滤波（Cheng et al., 2022）。端点通过镜像反射技术进行填充（De Cock et al., 2008）。滤波后，使用 MATLAB 2023b（MathWorks Inc., 美国）通过多项式插值计算内侧-外侧（COPx）和前后（COPy）方向的COP位移，并且所有数据均针对支撑相时间进行了归一化处理。COP速度（COPvx、COPvy）通过微分计算得出。此外，支撑相被划分为四个子时相：初始触地相（ICP）、前足触地相（FFCP）、全足着地相（FFP）和前足蹬地相（FFPOP）（Perry and Burnfield, 2011）。ICP是指从足跟初始触地到前足初始触地的时间间隔。FFCP紧随ICP之后，在前足全部接触测力板时结束。FFP接续FFCP，在足跟离地时结束。FFPOP跟随FFP，在足部完全离地时终止。针对各子时相计算了x和y方向上COP位移和速度的平均值。

每位受试者优势足的三个测试试验被纳入分析并取平均值。采用柯尔莫哥洛夫-斯米尔诺夫检验（Kolmogorov-Smirnov test）验证数据的正态性。首先，使用皮尔逊相关系数（Pearson correlation coefficient）检验步态动力学与足弓指数之间的关系。然后采用 $\textbf { a } 2 \times \textbf { 3 }$ 重复测量方差分析（ANOVA）来确定组内（基线、12个月和24个月时的重复测量）和组间（RG组和CG组）的差异。通过在每个时间点进行独立样本t检验开展成对比较，以评估各测试点的组间差异，从而进一步探讨显著的交互作用。应用Bonferroni校正对多重比较进行调整。显著性水平设定为 $p <$ 0.05。采用偏eta平方 $( \eta _ { p } ^ { 2 } )$ 估计所有ANOVA分析的效应量，并解释为小（0.01）、中（0.06）和大（0.14）（Cohen, 1988）。利用一维统计参数映射方法（SPM）对支撑相期间的COP位移曲线进行分析，以比较康复组与对照组（Pataky, 2008）。

## 4. 讨论

本研究旨在探讨儿童柔韧性扁平足自愈后步态模式特征的变化。相关性分析表明，足弓指数（arch index, AI）是影响儿童步态特征的关键参数。具体而言，不同足部区域的足底压力参数与 AI 呈中度至强相关，其中中足和前足区域的影响尤为显著。重复测量方差分析（repeated ANOVA）表明，恢复组与对照组的步态特征随时间发生的变化存在差异，尤其是在𧿹趾、前足和中足区域。进一步的两两比较显示，在扁平足恢复后的两年内，足底负荷模式和步态稳定性得到改善，并逐渐趋于正常化。然而，实验组的步态模式尚未完全恢复到正常发育儿童的水平，并在不同阶段表现出不同的特征。这表明步态模式的恢复滞后于足弓结构的恢复。这项纵向研究为柔韧性扁平足儿童步态的自然恢复提供了见解，突显了步态模式随时间的逐步适应。这些发现有助于理解步态发育成熟及其自然演变过程。

在基线时，$\mathsf { R G } _ { 0 }$ 组儿童的足弓仍处于扁平状态。$\mathsf { R G } _ { 0 }$ 组的中足负荷显著高于 $\mathbf { C G } _ { 0 }$ 组，这与我们对扁平足的普遍认知一致。此外，康复组在 T1 区域显示出较低的峰值压力和相对负荷。相比之下，Buldt 等人（Buldt et al., 2018）对成人扁平足足底负荷的研究发现，T1 区域承受了显著更高的负荷，在推进相（propulsion phase）中发挥了更大作用。本研究中观察到的拇趾区负荷减少表明，其在该阶段产生的蹬地力较小。这种减少主要归因于扁平足儿童在蹬地离地阶段（push-off stage）的功能受损（Kothari et al., 2016; Kim et al., $2 0 1 7 )$。我们推测，当经历足弓塌陷时，儿童和成人在推进相期间的拇趾反应存在差异。此外，$\operatorname { R G } _ { 0 }$ 组在蹬地阶段纵向 COP（压力中心）位移更快，且呈现出更偏向外侧的取向（占支撑相的 60 %–80 %）。这意味着扁平足儿童在足跟离地后处于不稳定状态。该发现与 Panaet 等人（Panaet et al., 2022）的研究一致，该研究表明距下关节的过度外翻会导致距骨向内侧移位，从而影响整个下肢的运动学特征。我们的研究结果进一步表明，扁平足儿童在蹬地阶段的 COP 外侧偏移是对关节排列不齐的一种代偿性反应。

另一个出乎意料的发现是，前足负荷的结果与以往的研究不同（Pauk, Ihnatouski and Najafi, 2014; Yan et al., 2020），以往研究表明扁平足塌陷的足弓无法有效分布负荷，从而导致前足压力和冲量显著降低。在我们的研究中，康复组的足弓后来恢复了正常形态，这表明在扁平足足弓形态完全恢复之前，其负荷模式可能就已经向正常方向发展。与忽视扁平足后期发展的横断面研究相比，我们的研究针对基线期扁平足儿童的步态模式提供了更具针对性和独特的见解。然而，要进一步验证这些发现，还需要对扁平足儿童开展大量的数据分析。针对这一特定群体的额外研究，可以为识别自发缓解型扁平足病例提供有价值的见解。

在足弓形态恢复的第一年内，恢复组的足部受力模式表现出显著变化，中足下方的集中压力得到有效缓解。随着足弓结构的持续恢复，足底负荷分布变得更加均匀。然而，在这一阶段，步态特征仍与扁平足儿童中通常观察到的特征相似。值得注意的是，与 $\mathbf { C G } _ { 1 }$ 相比，$\mathsf { R G } _ { 1 }$ 的前足外侧相对负荷显著更低。这可以从两个角度来解释。从下肢适应的角度来看，这可归因于扁平足距下关节的外旋，从而将前足负荷从外侧转移到内侧（Buldt et al., 2018; Chuckpaiwong et al., 2008）。从近端体段适应的角度来看，青少年的腰椎前凸角往往随着足弓高度的增加而减小（Jankowicz-Szymanska et al., 2021），这可能会导致前足相对负荷减少（Zurawski et al., 2022）。需要进一步的关节运动学数据和更广泛的统计分析来评估潜在体段适应对步态特征改变的贡献。

尽管有这些改善，在

$\mathsf { R G } _ { 1 }$ 中前足外侧的标准化最大作用力仍显著偏高。这一增加与触地时的缓冲密切相关（Perry and Burnfield, 2011）。这表明在此期间 $\mathrm { R G } _ { 1 }$ 的胫骨前肌肌力尚未恢复到正常水平。因此，前足触地期间的显著晃动导致前足外侧的作用力骤增。同时，$\mathsf { R G } _ { 1 }$ 在 FFCP 期间表现出较小的外侧向 COP 速度。这表明 $\mathsf { R G } _ { 1 }$ 下意识地采用了这种运动策略，以增强前足触地时的步态控制。

到第三次测试时，RG<sub>2</sub> 的步态模式表现出显著改善，逐渐趋近于正常发育儿童的常见水平。两组之间在标准化最大力和平均 COP 数据上的所有差异均已完全消失。然而，仍存在一些差异性结果，特别是在相对负荷和 COP 曲线方面。研究发现 RG2 在 M2 区域的相对负荷较高，并在 FFPOP 期间表现出更偏向外侧且较少向前移动的 COP 轨迹。在典型的步态周期中，足跟离地后，胫骨前肌的离心收缩促进了压力中心从前足外侧向内侧转移，从而收紧跖筋膜并辅助向前推进 (Perry and Burnfield, 2011)。在本研究中，$\mathsf { R G } _ { 2 }$ 的 COP 特征表明其正常的前足旋前和向前推进功能受到了部分限制。因此，足底负荷似乎“滞留”在 M2 区域，而 RFTI 的显著增加也支持了这一结论。由于 M2 在日常身体活动中的负重和功能方面至关重要，过度重复的负荷可能会增加跖骨痛及其他相关疾病的风险 (Kaipel, Krapf and Wyss, 2011; Lee et al., 2024)。在足弓恢复的第二年中，步态模式较第一年持续改善，接近正常发育儿童的水平。然而，仍应关注 M2 区域冲量的分散情况，特别是在长跑和徒步等重复性活动中，负荷会随着时间的推移而不断累积。

本研究存在一些局限性需要指出。虽然本研究的重点是分析从扁平足恢复到正常足弓后的足底负荷和步态稳定性，但仍需要更全面地了解步态功能随足弓恢复而发生的变化，特别是在肌肉活动和关节运动方面。此外，还需要进行更长期的随访研究，以证实本研究中提出的推测性发现。关于扁平足儿童步态运动学和动力学的系统性基础研究的缺乏，进一步凸显了开展更广泛研究的必要性。就此而言，未来结合下肢和躯干运动学分析的研究可以为代偿运动的消除提供更深入的见解，并有助于明确这些代偿调整在恢复过程中何时完全消退。

## 5. 结论

在关键发育期，扁平足儿童的步态特征在足弓结构恢复后往往会有所改善，尽管存在时间滞后。扁平足恢复后，足部高负荷区从足弓区域先转移至前足外侧，进而转移至前足中部。压力中心（COP）轨迹与正常儿童存在差异，尤其是在承重反应期、末期站立期和摆动前期。这些发现突出了扁平足恢复过程中的生物力学适应机制。未来的研究应纳入全身运动学分析，并为步态正常化和临床应用提供更全面的参考。
