## 一、方向判定

属于「生物力学 + 物理信息机器学习」交叉：以 EMG 驱动的神经肌肉骨骼（NMS）模型作为「物理求解器」，把其内部信息特征（各肌肉力、关节力矩）注入标准 ANN 构建 hybrid-ANN，再用迁移学习解决跨受试者泛化问题。**不是** RGB 视觉输入，**也不是**关节角度输出，而是位于「关节力矩预测」这一下游环节，与 ViKiT 上游的视觉→角度建模形成上下游互补关系。

## 二、解决什么问题

- 外骨骼辅助控制需要实时、鲁棒地估计使用者主动关节力矩（torque），以提供匹配的辅助力矩并鼓励主动参与；
- 纯物理 NMS 模型校准繁琐、泛化差；纯数据驱动 ANN 黑箱、跨被试泛化弱、训练数据有限时性能下降；
- 如何在**数据有限**、**跨被试**场景下获得高精度的踝关节力矩预测？

## 三、使用方法

- **NMS 求解器（CEINMS）**：基于 Hill 型肌肉模型的 EMG 驱动神经肌肉骨骼模型，提供肌肉力、关节力矩等物理特征作为「信息特征」。
- **标准 ANN**：输入为 EMG（GM/TA/SOL）+ 踝关节角度，输出踝关节力矩。
- **Hybrid-ANN**：在标准 ANN 输入基础上，**额外**拼接 NMS 求解器计算的肌肉力与关节力矩（共 8 个特征）→ 把物理信息作为额外 token 注入网络。
- **迁移学习（Transfer Learning, TL）**：留一交叉验证框架下，先用 N-1 个被试者的数据预训练网络，再迁移到新被试 Sₜ（冻结前层，新增隐层 + 输出层，仅微调新增层权重）。
- **超参调优**：粗到细随机搜索；受试者内 2 隐层，跨受试者 4 隐层；每隐层 10 神经元、tanh 激活、Adam 优化（1e-3）、微调学习率 1e-5；早停 + 4000 epoch。
- **评估**：NRMSE（归一化均方根误差）；Wilcoxon 符号秩检验 + Bonferroni 校正；七种场景（Gait_{fast/self/slow}, Isok_{P60/P90/D60/D90}）。

## 四、核心内容概述

**数据**：10 名健康受试者（4 女 / 6 男），完成 3 种步速行走 + 60°/s、90°/s 等速踝背屈/跖屈；采集 GM/TA/SOL 三块肌肉表面 EMG（3000 Hz）、3D 运动捕捉（Qualisys, 200 Hz, Plug-in Gait）、GRF（Kistler 3000 Hz）、等速测力计（IsoMed 2000, 5000 Hz）。

**流水线**：EMG 滤波整流归一化 → OpenSim Gait2354 缩放 + IK + ID 重建关节角度与实测力矩 → CEINMS 校准 MTU 参数 → ANN/Hybrid-ANN 训练 → 七场景评估。

**关键结果**：
- **受试者内**：Hybrid-ANN 在所有校准动作上 NRMSE 显著低于 NMS（p=0.02–0.05）；测试动作上多数场景 Hybrid-ANN > NMS > Standard ANN，仅少数反向。NMS 在周期起点常出现估计力矩偏移，ANN 类模型无此问题。
- **跨被试（无 TL）**：标准 ANN 精度显著低于 NMS；Hybrid-ANN 优于标准 ANN，但仍逊于个性化 NMS。
- **跨被试（**有 TL**）**：Hybrid-ANN + TL 取得最大提升，**超过**留一交叉验证下的 NMS 模型，是论文最重要结论。
- Hybrid-ANN 在 NMS **未校准**情境下仍优于标准 ANN（附录），降低了部署门槛。

**结论**：将基于物理的 NMS 特征注入标准 ANN 并配合迁移学习，可构建高精度、强泛化的踝关节力矩预测器，适用于外骨骼按需辅助控制。

## 五、与 ViKiT（视觉位移判断）项目的关联

| 关联点 | 具体启发 |

| **Hybrid 范式** | Hybrid-ANN = "物理求解器特征 + 数据驱动网络"，与 ViKiT 的「biomechanical grammar 融入 decoder 与 loss」在哲学上同构——ViKiT 可把 OpenSim/简易 FK 算出的关节链约束、ROM 上界、速度上限当作"信息特征 token"拼入视觉翻译模型的解码器，或作为辅助 loss |
| **跨被试泛化** | 腕关节康复场景同样面临患者间解剖差异巨大、标注数据稀缺；本文 TL 的「冻结前层 + 新增 1 隐层微调」是值得借鉴的 few-shot 个性化范式 |
| **下游闭环** | 本文目标输出是 torque（用于外骨骼），ViKiT 目标输出是 joint angle（用于临床评估）。两者构成完整康复反馈链：ViKiT 输出角度 → 可送入 NMS 模型 → 输出 torque → 指导辅助策略。本论文可视为 ViKiT 下游模块的算法原型 |
