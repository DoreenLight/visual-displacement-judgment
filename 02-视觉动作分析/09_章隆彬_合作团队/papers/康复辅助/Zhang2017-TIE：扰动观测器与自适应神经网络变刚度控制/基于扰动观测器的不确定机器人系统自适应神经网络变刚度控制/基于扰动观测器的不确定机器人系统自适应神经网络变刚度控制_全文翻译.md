# 基于扰动观测器的不确定机器人系统自适应神经网络变刚度控制

Longbin Zhang, Zhijun Li, Senior Member, IEEE, and Chenguang Yang, Senior Member, IEEE

摘要—变刚度执行器（Variable Stiffness Actuator, VSA）因其在安全性、鲁棒性和灵活性方面的优越性能，已被装备在许多新一代机器人上。然而，由于其固有的高度非线性动力学特性，控制由变刚度执行器驱动关节的机器人极具挑战性。在本文中，针对具有变刚度关节且存在模型不确定性的机器人系统，提出了一种基于扰动观测器的新型自适应神经网络控制方法。通过利用高维积分型 Lyapunov 函数，设计了自适应神经网络控制来逼近模型不确定性，并结合扰动观测器来补偿非线性 VSA 动力学、神经网络逼近误差以及外部扰动。理论上证明了闭环控制系统的半全局一致最终有界性。仿真和广泛的实验研究也验证了所提方法的有效性。

索引词—变刚度执行器；自适应神经网络；高维积分 Lyapunov；扰动观测器

## I. 引言

尽管自动化技术取得了进步，但在需要灵巧性、安全性和效率的任务中，机器人与人类相比仍有不足。在机器人需要与环境或人进行物理交互的场景中，如果执行器刚度过大，在交互过程中可能会发生不稳定现象。这会进一步导致机器人受损甚至人员受伤。然而，人类即使在非结构化或未知的环境中，也可以通过将关节的肌肉刚度适当地调节至适合任务与环境的水平，从而很好地完成这些交互任务。考虑到类人性能将使机器人在医疗手术 [1]、搜寻 [2]、救援 [3] 以及社交活动等交互任务中表现得更好，因此期望采用类似人类肌肉的可变刚度执行器（variable stiffness actuator）来同时确保安全性和性能。它在关节驱动中引入了可通过控制动作进行调节的机械顺应性。已有许多重要工作致力于开发可变刚度驱动的机械系统 [4]-[8]。在文献 [6] 中，提出并实现了一种节能型可变刚度执行器的概念设计。在文献 [7] 中，提出了一种混合可变刚度执行器，通过控制混合控制模块中齿轮的相对运动，可以同时控制关节的位置和刚度。文献 [8] 针对一种可变刚度机构，深入探讨了影响其刚度特性的具体细节。

如前所述，可变刚度执行器中有意引入了可变关节弹性，从而为我们在机械层面上提供了调节机器人柔性以适应特定任务的手段。然而，由于非线性因素（例如输入非线性），可变刚度机器人关节的控制面临着巨大的挑战，这可能导致不良的不精确性或振荡加剧，从而严重限制机器人系统的性能，甚至导致系统不稳定。

为了有效减少或消除变刚度对系统性能的负面影响，近几十年来学者们提出了若干方法 [9]–[17]。在 [9] 中，提出了一种用于机器人辅助人手臂运动的无传感器力控制方法。该方法开发了一种带有钢丝绳的双直接驱动电机系统，为人机交互提供精确的力感和安全性；通过考虑人手臂运动中的刚度，提高了力控制系统的效率，并实现了舒适的人机交互力。在 [11] 中，提出了一种具有可调谐振频率的变刚度执行器方法，基于压电堆叠执行器的蜂窝式人工肌肉执行器同时实现了变刚度和变共振功能。在 [12] 中，提出了一种具有可调刚度的新型执行器设计。所提出的执行器设计通过一个小型电机，以最低的能耗在大范围内调节关节刚度。在 [13] 中，设计了一种用于机器人机械臂的变刚度关节（VSJ），并在非线性控制设计中采用奇异摄动模型来确立闭环系统的稳定性。

本工作中的控制设计同时考虑了机器人动力学和执行器动力学。正如 [18] 中所示，执行器动力学实际上构成了

完整机器人动力学的重要组成部分。通常，诸如变刚度、死区、侧隙和迟滞等非光滑非线性特性是执行器中最常见的非线性现象。获取机器人动力学的精确知识是不可行的，对变刚度执行器进行建模也极为困难。因此，在本工作中，我们采用神经网络（NNs）技术来补偿机器人系统中所涉及的未知非线性和未知动力学，因为神经网络具备处理未知动力学系统和非结构化不确定性的能力 [19], [20], [21], [22] 和 [23]。众所周知，在控制不确定机器人系统时，神经网络对于保证稳定性、鲁棒性以及整体性能尤为有效。

值得注意的是，针对具有可变刚度的不确定机器人系统的研究工作较少，而大多数针对配备可变刚度关节的机器人的控制设计都是基于已知的机器人模型 [10]–[16]，这些方法无法直接应用于不确定机器人系统。在本文中，我们旨在为具有 VSA（可变刚度执行器）驱动关节的不确定机器人开发新的控制技术。首先，我们提出了一种高维积分 Lyapunov 函数以构建基于 Lyapunov 的自适应控制结构，然后使用自适应神经网络逼近未知非线性函数以实现期望的跟踪性能。同时还采用了一个扰动观测器来处理 VSA 非线性、神经网络逼近误差以及外部扰动。所提出高维积分 Lyapunov 函数使控制设计避免了控制器奇异性问题。与以往的工作 [10]、[14] 和 [15] 相比，我们避免使用投影法或传统的反步法 [16]，后者通常涉及对虚拟控制律时间导数的反复计算。我们开发的新型控制方法保证了半全局一致最终有界稳定性，使得闭环控制系统中的所有信号都是有界的，并且跟踪误差收敛到原点。仿真和实验结果均证明了所提出控制方法的有效性。

## II. 问题描述与预备知识

考虑在电机和连杆之间安装有弹性元件的可变刚度关节，机器人机械臂的动力学模型如下 [16]

$$
M (q) \ddot {q} + C (q, \dot {q}) \dot {q} + G (q) + f _ {d i s} = \mathbf {u}\tag{1}
$$

$$
A \ddot {\theta} + \mathbf {u} = \tau\tag{2}
$$

其中 $q \in R ^ { m }$ 是关节角向量，$M ( q ) \in R ^ { m \times m }$ 是惯性矩阵，$C ( q , \dot { q } ) \in R ^ { m \times m }$ 是向心力和科里奥利力矩，$G ( q ) \in R ^ { m }$ 是重力，$f _ { d i s } \in R ^ { m }$ 是外部扰动，$\mathbf{u}$ 是由弹性关节引起的输入非线性，而 $\theta , \tau \in R ^ { m }$ 和 $A \in R ^ { m \times m }$ 分别是电机坐标、电机力矩和电机转动惯量。在本文中，假设 $M ( q ) , \thinspace C ( q , \dot { q } )$、$G ( q )$ 和 $f _ { d i s }$ 均为未知的。

上述机器人机械臂动力学可以表示为以下形式

$$
\left\{ \begin{array}{l} \dot {\mathbf {x}} _ {1} = \mathbf {x} _ {2}, \\ \dot {\mathbf {x}} _ {2} = \mathbf {B} ^ {- 1} (\mathbf {x}) [ \mathbf {F} (\mathbf {x}) + \mathbf {d} (t) + \mathbf {u} ] \\ \mathbf {y} = \mathbf {x} _ {1} \end{array} \right.\tag{3}
$$

其中 $\begin{array} { l l l l l } { \mathbf { x } _ { 1 } } & { = } & { [ q _ { 1 } , q _ { 2 } , \ldots , q _ { m } ] ^ { T } , } & { \mathbf { x } _ { 2 } } & { = } & { [ \dot { q } _ { 1 } , \dot { q } _ { 2 } , \ldots , \dot { q } _ { m } ] ^ { T } } \end{array}$，${ \bf B } ( { \bf x } ) = M ( q ), ~ { \bf F } ( { \bf x } ) = - C ( q , \dot { q } ) \dot { q } - G ( q ), ~ { \bf d } ( t ) = - f _ { d i s }$，且 $\mathbf { u } = [ \mathbf { u } _ { 1 } , \hdots , \mathbf { u } _ { m } ] ^ { T } \in R ^ { m }$ 表示由弹性关节引起的输入非线性。

具有非线性和变刚度力矩函数的弹性关节特性可由下式描述 [25]：

$$
\mathbf {u} = f (\varphi , \sigma)\tag{4}
$$

其中 u 为关节力矩，$\varphi$ 为关节挠度，$\sigma$ 为刚度变化参数，且 $\varphi = \theta - q$ 为关节挠度。一般而言，力矩-挠度曲线可以是任意形状，而线性变刚度分布特性 $\mathbf { u } = k ( \sigma ) \varphi$ 应用最为广泛，其中 $k ( \sigma )$ 为刚度。坐标 σ 表示用于刚度调节的附加输入。刚度特性可描述为 $k = 2 k _ { s } r ^ { 2 } ( 2 \cos ^ { 2 } \varphi - 1 ) =$ $\begin{array} { r l r } {  { 2 k _ { s } \big ( \frac { \varrho } { 2 \pi } \sigma \big ) ^ { 2 } \big ( 2 \cos ^ { 2 } \varphi - 1 \big ) } } \end{array}$ [26]，其中 $k _ { s }$ 为弹簧刚度，r 为力臂，ϱ 为滚珠丝杠驱动的导程。

在本研究中，不考虑动态特性，并将 $\sigma$ 视为准静态，所考虑的变刚度表示为以下连续时间动态模型 [16]：

$$
\frac {d \mathbf {u}}{d t} = k \dot {\theta} - k \dot {q}\tag{5}
$$

其中 k 为刚度。

符号说明：给定向量 $\mathbf { a } \in R ^ { n }$ 和矩阵 $\mathbf { B } \in R ^ { m \times m }$，$\| \mathbf { a } \| ^ { 2 } = \mathbf { a } ^ { T } \mathbf { a }$ 且 $\| { \bf B } \| ^ { 2 } = t r ( B ^ { T } B )$。

在本研究中，我们的目标是设计一个控制器，以确保在输入非线性和模型不确定性下，系统输出能够以满意的精度跟踪期望轨迹 $\mathbf { y } _ { d } \in$ $R ^ { m }$。同时，控制系统中的所有信号均有界。

令 $\mathbf { B } _ { d } ( \mathbf { x } ) \in \ R ^ { m \times m }$ 为对角元素满足 $b _ { d i i } ( \bar { \mathbf { x } } , \mathbf { x } _ { i } ) \neq 0 \in R ^ { m } ( \bar { \mathbf { x } } = \mathbf { x } _ { 1 } , i = 1 , 2 , \ldots , m )$ 的对角矩阵，则 $\mathbf { B } ( \mathbf { x } )$ 可分为两部分：

$$
\mathbf {B} (\mathbf {x}) = \mathbf {B} _ {d} (\mathbf {x}) + \Delta_ {\mathbf {B}},\tag{6}
$$

其中矩阵 $\Delta _ { \mathbf { B } }$ 是未知的。因此，我们得到

$$
\mathbf {B} (\mathbf {x}) \dot {\mathbf {x}} _ {2} = \mathbf {F} (\mathbf {x}) + \mathbf {d} (t) + \mathbf {u}.\tag{7}
$$

将 (6) 代入 (8)，可得

$$
(\mathbf {B} _ {d} (\mathbf {x}) + \Delta_ {\mathbf {B}}) \dot {\mathbf {x}} _ {2} = \mathbf {F} (\mathbf {x}) + \mathbf {d} (t) + \mathbf {u}.\tag{8}
$$

考虑到 (2)，我们可以得到

$$

## III. 控制系统设计与稳定性分析 A. 积分 Lyapunov 分析

控制设计目标是综合一个控制器，该控制器能够在保证稳定性的前提下跟踪期望轨迹，并能够衰减由变刚度驱动的非线性所引起的影响。

为了便于控制设计，考虑以下积分 Lyapunov 候选函数：

$$
\mathbf {V} _ {1} = \mathbf {s} ^ {T} \mathbf {B} _ {\vartheta} \mathbf {s},\tag{15}
$$

其中

$$
\mathbf {B} _ {\vartheta} = \int_ {0} ^ {1} \vartheta \mathbf {B} _ {\alpha} d \vartheta = \operatorname{diag} \left[ \int_ {0} ^ {1} \vartheta \mathbf {B} _ {\alpha i i} (\bar {\mathbf {x}}, \vartheta \mathbf {s} _ {i} + \mathbf {v} _ {i}) d \vartheta \right],\tag{16}
$$

其中 $\begin{array} { r c l } { { \bf B } _ { \alpha } } & { = } & { { \bf B } _ { d } ( \bar { \bf x } , \vartheta { \bf s } _ { i } ~ + ~ { \bf v } _ { i } ) \alpha ~ = ~ \mathrm { d i a g } [ b _ { d i i } ( \bar { \bf x } , \vartheta { \bf s } _ { i } ~ + } \end{array}$ $\mathbf v _ { i } ) \alpha _ { i i } \big ] _ { m \times m } , i = 1 , 2 , \dots , m , \bar { \mathbf { x } } = \mathbf { x } _ { 1 }$，且矩阵 $\alpha \in R ^ { m \times m }$。为了便于分析，我们选取 $\alpha _ { 1 1 } = \ldots = \alpha _ { m m \cdot } { \bf v } = { \dot { \bf y } } _ { d } - \xi$，其中 $\xi ~ = ~ [ \xi _ { 1 } , \xi _ { 2 } , \ldots , \xi _ { m } ] ^ { T } ~ \in ~ R ^ { m }$ 且 $\xi _ { i } ~ = ~ \lambda _ { i } \mathbf { e } _ { i } , i ~ =$ $1 , 2 , \ldots , m$。常数 $\lambda _ { i }$ 为适当选取的待定设计系数，使得当 $\textbf { v } \to 0$ 时 $\mathbf e  0$，且 ϑ 为独立于 s 和 v 的标量。我们选择合适的 $\mathbf { B } _ { d } ( \mathbf { x } )$ 和 $\alpha ,$ 使得 $b _ { d i i } \alpha _ { i i } > 0$。

根据 (16)，(15) 可以重写为

$$
\mathbf {V} _ {1} = \sum_ {i = 1} ^ {m} \mathbf {s} _ {i} ^ {2} \int_ {0} ^ {1} \vartheta \mathbf {B} _ {\alpha i i} (\bar {\mathbf {x}}, \vartheta \mathbf {s} _ {i} + \mathbf {v} _ {i}) d \vartheta .
$$

随后，我们导出了一个针对机器人机械系统提出的新型高维 Lyapunov 候选函数，该函数能够有效处理后文将详细阐述的机器人非线性系统中通常在自适应反馈线性化控制中出现的所谓控制奇异性问题。

根据 $\mathbf { B } _ { \alpha }$ 的定义，存在 $\mathbf { B } _ { \alpha }$ 的最小特征值 $\lambda _ { \operatorname* { m i n } } ( \mathbf { B } _ { \alpha } )$ 和最大特征值 $\lambda _ { \operatorname* { m a x } } ( \mathbf { B } _ { \alpha } )$，使得

$$
0 \leq \lambda_ {\mathrm{min}} (\mathbf {B} _ {\alpha}) \mathbf {s} ^ {T} \mathbf {s} \leq \mathbf {s} ^ {T} \mathbf {B} _ {\alpha} \mathbf {s} \leq \lambda_ {\mathrm{max}} (\mathbf {B} _ {\alpha}) \mathbf {s} ^ {T} \mathbf {s}.\tag{17}
$$

注意到 ϑ 是独立于 s、¯x 和 v 的标量，将上述不等式两边对 ϑ 进行积分，可得

$$
0 \leq \mathbf {s} ^ {T} \left(\int_ {0} ^ {1} \vartheta \mathbf {B} _ {\alpha} d \vartheta\right) \mathbf {s} \leq \left(\int_ {0} ^ {1} \vartheta \lambda_ {\max} (\mathbf {B} _ {\alpha}) d \vartheta\right) \mathbf {s} ^ {T} \mathbf {s},\tag{18}
$$

从而使得我们始终有 $\mathbf { V } _ { 1 } \geq 0 .$

对 (15) 关于时间 t 求导，并考虑到 $\mathbf { B } _ { \alpha }$ 和 $\mathbf { B } _ { \vartheta }$ 是对称的，我们有

$$
\begin{array}{r c l} \dot {\mathbf {V}} _ {1} & = & 2 \mathbf {s} ^ {T} \mathbf {B} _ {\vartheta} \dot {\mathbf {s}} + \mathbf {s} ^ {T} \left(\frac {\partial \mathbf {B} _ {\vartheta}}{\partial \mathbf {s}} \dot {\mathbf {s}}\right) \mathbf {s} \\ & & + \mathbf {s} ^ {T} \left(\frac {\partial \mathbf {B} _ {\vartheta}}{\partial \bar {\mathbf {x}}} \dot {\bar {\mathbf {x}}}\right) \mathbf {s} + \mathbf {s} ^ {T} \left(\frac {\partial \mathbf {B} _ {\vartheta}}{\partial \mathbf {v}} \dot {\mathbf {v}}\right) \mathbf {s}, \end{array}\tag{19}
$$

其中

$$
\frac {\partial \mathbf {B} _ {\vartheta}}{\partial \mathbf {s}} \dot {\mathbf {s}} = \mathrm{diag} \left[ \int_ {0} ^ {1} \vartheta \frac {\partial \mathbf {B} _ {\alpha i i}}{\partial \mathbf {s} _ {i}} \dot {\mathbf {s}} _ {i} d \vartheta \right],\tag{20}
$$

$$
\frac {\partial \mathbf {B} _ {\vartheta}}{\partial \bar {\mathbf {x}}} \dot {\bar {\mathbf {x}}} = \mathrm{diag} \left[ \int_ {0} ^ {1} \vartheta \sum_ {j = 1} ^ {m} \frac {\partial \mathbf {B} _ {\alpha i i}}{\partial \bar {\mathbf {x}} _ {j}} \dot {\bar {\mathbf {x}}} _ {j} d \vartheta \right],\tag{21}

## B. 基于模型的控制器

我们定义 $D = r ( d ) + g ( \tau ) + \eta ( \theta )$，然后可以将 (10) 表示为

然后，考虑到引理 2.1（Lemma 2.1）、假设 2.1（Assumption 2.1）和假设 2.2（Assumption 2.2），我们可以得到

我们定义一个辅助变量 z 以便于设计非线性扰动观测器。其定义为

$$
\dot {z} = \dot {D} - K \mathbf {B} _ {d} ^ {- 1} (\mathbf {x}) [ (\mathcal {F} (\mathbf {x}) + \tau + D ]\tag{37}
$$

为了实现对系统扰动 D 的估计，我们必须首先获得中间变量 z 的估计；

因此，基于 (35) 和 (37)，提出以下方程：

$$
\dot {\hat {z}} = - K \mathbf {B} _ {d} ^ {- 1} (\mathbf {x}) [ (\mathcal {F} (\mathbf {x}) + \tau + \hat {D} ],\tag{38}

其中 $\hat { D }$ 是 D 的估计值。

受 (36) 的启发，我们可以得到扰动 D 的估计如下：

扰动的估计误差定义为 ${ \tilde { D } } = D -$ $\hat { D } .$。考虑到 (36) 和 (39)，我们有

对 (40) 关于时间 t 求导，然后结合 (37) 和 (38)，我们得到

\dot {\tilde {D}} = \dot {\tilde {z}} = \dot {z} - \dot {\hat {z}} = \dot {D} - K \mathbf {B} _ {d} ^ {- 1} (\mathbf {x}) \tilde {D},\tag{41}

其中常数矩阵 $K _ { 1 } ~ = ~ K _ { 1 } ^ { T } ~ > ~ 0$ 将被适当地选取。

结合 (35)、(41) 以及以下事实

## C. 自适应神经网络控制器

然而，由于很难获取机器人系统的完整且准确的信息，我们在 (42) 中提出的控制器可能无法实现。在这种情况下，我们可能无法精确得知 $\mathcal { F } ( \mathbf { x } )$。在未知 $\mathcal F ( \mathbf x )$ 精确值的情况下，所提出的基于模型的控制器几乎无法实现。为了克服该控制器面临的实际问题，采用 RBFNN（径向基函数神经网络，Radial Basis Function Neural Network）来估计与模型相关的参数。

在我们的控制设计中，选择径向基函数神经网络（RBFNN）来逼近机器人动力学中的未知函数。通常，RBFNN 可以在紧集 $\Omega _ { z } \in R ^ { q }$ 上以任意精度平滑地逼近任意连续函数 $H ( Z )$，表示为

$$
H (Z) = W ^ {* T} S (Z) + \mu ,\tag{51}
$$

其中，对于 $i = 1 , 2 , \ldots , l$，$S _ { i } ( Z )$ 为如下定义的高斯函数：

$$
S _ {i} (Z) = \exp [ \frac {- (Z - c _ {i}) ^ {T} (Z - c _ {i})}{b _ {i} ^ {2}} ],\tag{52}
$$

且 $c _ { i } = [ c _ { i 1 } , c _ { i 2 } , . . . , c _ { i q } ]$ 为感受野中心，$b _ { i }$ 为高斯函数的宽度。根据其定义可知，存在一个正常数 $\delta > 0$ 使得 $\| S ( Z ) \| \le \delta$。$W ^ { * }$ 为最优常数权重，$\mu$ 为 RBFNN 的最小逼近误差。根据 RBFNN 逼近理论，显然逼近误差存在上界 $\mu ^ { * }$，即存在正常数 $\mu ^ { * } > 0$ 满足 $| \mu | \ \leq \ \mu ^ { * }$。

我们可以进一步利用 RBFNN 来逼近未知函数向量 $\mathcal { F } ( \mathbf { x } )$，形式为

$$
\mathcal {F} (\mathbf {x}) = - W ^ {* T} S (Z) - \varepsilon ,\tag{53}
$$

其中 $W ^ { * } : = \mathrm { \ b l o c k d i a g } [ W _ { i } ^ { * } ] , i = 1 , 2 , . . . , l$ 为最优神经网络权重，$S ( Z ) \stackrel { } { = } [ S _ { 1 } ^ { T } ( Z ) , S _ { 2 } ^ { T } ( Z ) , \ldots , S _ { l } ^ { T } ( Z ) ] ^ { T }$ 为径向基函数，$\bar { Z } = [ \mathbf { x } _ { 1 } ^ { T } , \mathbf { x } _ { 2 } ^ { T } ] ^ { T }$，且 $\varepsilon = [ \varepsilon _ { 1 } , \varepsilon _ { 2 } , \ldots , \varepsilon _ { m } ] ^ { T }$。容易证明存在常数 $\varepsilon ^ { * } > 0$ 使得 $\| \varepsilon \| \leq \varepsilon ^ { * }$。

在 (10) 中，未知非线性函数向量 $\mathcal { F } ( \mathbf { x } )$ 由 RBFNN 逼近。结合 (53)，我们有

$$
\mathbf {B} _ {d} (\mathbf {x}) \dot {\mathbf {x}} _ {2} = \tau + g (\tau) - W ^ {* T} S (Z) - \varepsilon + \eta (\theta) + r (d).\tag{54}
$$

为了有效解决未知逼近误差 $\varepsilon$ 的问题，我们可以将其视为系统外部扰动的一部分。定义 $D = r ( d ) + g ( \tau ) + \eta ( \theta ) - \varepsilon$，则 (54) 可以表示为

$$
\mathbf {B} _ {d} (\mathbf {x}) \dot {\mathbf {x}} _ {2} = \tau + D - W ^ {* T} S (Z).\tag{55}
$$

然后，根据径向基函数神经网络（RBFNN）的逼近理论，未知逼近误差 $\varepsilon$ 满足 $\| \varepsilon \| \leq \rho _ { 1 }$，其中 $\rho _ { 1 }$ 为未知的正常数。因此，与 (35) 类似，我们同样有

$$
\| \dot {D} \| \leq \rho ,\tag{56}
$$

其中 $\rho > 0$ 为未知常数。

我们定义一个辅助变量 $z$ 以便于设计非线性扰动观测器。其定义为

$$

$$

结合 (55)，$z$ 对时间的导数为

$$
\begin{array}{r c l} \dot {z} & = & \dot {D} - K \dot {\mathbf {x}} _ {n} \\ & = & \dot {D} - K \mathbf {B} _ {d} ^ {- 1} (\mathbf {x}) [ \tau + D - W ^ {* T} S (Z) ] \end{array}\tag{58}

$$

其中我们使用了以下事实：$\tilde { D } ^ { T } K { \bf B } _ { d } ^ { - 1 } \tilde { W } ^ { T } S ( Z ) \ \le$ $\begin{array} { r } { \frac { \| \tilde { D } \| ^ { 2 } } { 2 } ~ + ~ \frac { K \mathbf { B } _ { d } ^ { - 1 } S ( Z ) \| \tilde { W } \| ^ { 2 } } { 2 } } \end{array}$，以及 $- \varsigma \tilde { W } _ { i } ^ { T } \hat { W } _ { i } = - \varsigma \| \tilde { W } _ { i } \| ^ { 2 } \ - \quad$ $\begin{array} { r } { \varsigma \tilde { \tilde { W } } _ { i } ^ { T } W _ { i } ^ { * } \leq - \frac { \varsigma \| \tilde { \tilde { W } } _ { i } \| ^ { 2 } } { 2 } + \frac { \varsigma \| W _ { i } ^ { * } \| ^ { 2 } } { 2 } } \end{array}$

当我们选取正定矩阵 $K _ { 1 }$ 和 $K$ 以及正常数 $\zeta \ 1 0$ 使得 $\lambda _ { \operatorname* { m i n } } \left( \alpha ( K _ { 1 } - 0 . 5 I _ { m \times m } ) \alpha \right) ~ \geq$ $\begin{array} { r } { \int _ { 0 } ^ { 1 } \vartheta \lambda _ { \mathrm { m a x } } ( \mathbf { B } _ { \alpha } ) d \vartheta , K \mathbf { B } _ { d } ^ { - 1 } - 2 I _ { m \times m } > 0 \mathrm { a n d } \varsigma - K \mathbf { B } _ { d } ^ { - 1 } \delta > 0 } \end{array}$ 时，可以建立以下不等式

$$
{\dot {\mathbf {V}} _ {2}} \leq {- \kappa \mathbf {V} _ {2} + C,}\tag{72}
$$

其中

$$
\kappa = \min \binom{\lambda_ {m i n} (K \mathbf {B} _ {d} ^ {- 1} - 2 I _ {m \times m})}{\frac {\varsigma - K \mathbf {B} _ {d} ^ {- 1} \delta}{\lambda_ {m a x} (\sum_ {i = 1} ^ {m} \Gamma_ {i} ^ {- 1})}, 1},\tag{73}
$$

$$
C = \frac {\varsigma \| W ^ {*} \| ^ {2}}{2} + \frac {\rho^ {2}}{2}.\tag{74}
$$

通过将上述不等式两边乘以 $e ^ { \kappa t }$ 并对时间积分，我们可以得到以下不等式：

$$
\mathbf {V} _ {2} \leq \big (\mathbf {V} _ {2} (0) - \frac {C}{\kappa} \big) e ^ {- \kappa t} + \frac {C}{\kappa} \leq \mathbf {V} _ {2} (0) + \frac {C}{\kappa}.\tag{75}
$$

从上述不等式可以看出，当 $t \to \infty$ 时 $\mathbf { V } _ { 2 }$ 是最终有界的。因此，$s$、$\tilde { D }$ 和 W<sup>˜</sup> 也是有界的。证明完毕。■

## B. Baxter 机器人系统描述

为了验证所提出的控制技术，我们在 Baxter 机器人上进行了实验。如图 7 所示，Baxter 机器人是一款半人形机器人，由分别安装在左/右臂支架上的两条 7DOF（自由度）手臂以及基于可移动底座的躯干组成。在 Baxter 机器人中，电机轴并没有直接连接到关节上（通常是通过齿轮箱），而是采用弹性弹簧来减少与环境交互时可能发生碰撞的冲击力。这使得 Baxter 机器人在手臂撞击障碍物时能够减小冲击力。在 Baxter 机器人手臂的每个关节中，每个电机都通过弹簧与关节耦合，从而由弹簧扭曲产生的扭矩而非电机直接输出的扭矩来驱动连杆。这使得机器人能够表现出类似人类的弹性行为方式。得益于弹簧的弹性特性，可以提高抗冲击容限并降低碰撞时的危险。此外，Baxter 机器人能够在严重撞击物体之前的极早时刻感知到碰撞。Baxter 机器人的内部控制系统运行在机器人操作系统（ROS，Robot Operating System）上。关节位置和速度由 ROS 以 100 Hz 的频率发布。

## V. 结论

在本文中，我们设计了一种基于非线性扰动观测器的新型自适应神经网络控制，以处理不确定机器人系统的变刚度问题。通过采用李雅普诺夫（Lyapunov）直接法，确立了闭环系统的有界性。给出的仿真和实验结果均表明，所提出的控制器具有令人满意的性能。更重要的是，表明变刚度所产生的影响在我们的控制器作用下得到了抑制。

Chenguang Yang（M'10-SM'16）于 2005 年在中国西安的 Northwestern Polytechnical University（西北工业大学）获得测控工学学士学位，并于 2010 年在新加坡的 National University of Singapore（新加坡国立大学）获得控制工程博士学位。他曾在英国 Imperial College London（帝国理工学院）进行博士后研究。他目前任职于英国 Swansea University（斯旺西大学）Zienkiewicz Centre for Computational Engineering（辛克维奇计算工程中心），担任高级讲师。他的研究兴趣包括机器人学、自动化以及计算智能。
