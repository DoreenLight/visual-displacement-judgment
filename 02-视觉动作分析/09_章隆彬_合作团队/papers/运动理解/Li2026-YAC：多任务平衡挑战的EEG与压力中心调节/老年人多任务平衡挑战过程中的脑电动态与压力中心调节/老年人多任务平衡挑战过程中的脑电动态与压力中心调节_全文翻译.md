摘要—姿势控制能力的下降是导致老年人跌倒的主要原因，这凸显了理解其潜在神经机制对于风险评估和干预的重要性。本研究旨在通过同步记录脑电图（EEG）和压力中心（CoP）信号，探讨老年人在不同难度站立任务中的皮层活动和姿势动力学。参与者完成了四项任务：双腿站立（DS）、串联站立（TS）、附加认知任务的串联站立（TSC）以及附加认知和运动结合任务的串联站立（TSCM）。结果表明，随着任务难度的增加，感觉运动区和顶叶皮层区域的 theta 频段功率显著增加，且在 TSCM 期间中央电极（C3、Cz、C4）的激活最强，突显了它们在双重任务调节中的关键作用。相比之下，alpha 频段功率在各条件间保持稳定。CoP 分析显示，随着任务复杂性的增加，前后方向晃动的幅度、速度和频率显著增加，而频率离散度保持不变。这些发现表明，双重任务干扰需要老年人投入更多的皮层参与来进行姿势调节，为跌倒风险预测和个性化康复策略提供了见解。

索引词—姿势控制（Postural control），老龄化（Aging），双重任务（Dual-task），脑电图（EEG），压力中心（Center-of-pressure），Theta 功率（Theta power），跌倒风险（Fall risk），感觉运动皮层（Sensorimotor cortex）

## I. 引言

姿势控制是一项复杂的功能，涉及在支撑基底内调节身体重心，以确保在静态和动态活动中的稳定性 [1]。跌倒是姿势控制受损的最严重后果，对老年人的独立生活构成了重大威胁，并已成为一个日益严重的公共卫生问题 [2]– [4]。最近的全球指南强调机会性跌倒风险筛查以及个体化、多因素的预防策略 [5]。与此一致的是，最新的循证审查继续支持以锻炼和平衡为重点的项目，将其作为在人群层面降低跌倒风险的核心有效方法 [6], [7]。

有效的姿势控制依赖于感觉输入（视觉、前庭和本体感觉）、中枢神经处理以及肌肉骨骼反应的整合运作 [8]。关键生物力学变量，如支撑面（BoS）、质心（CoM）和压力中心（CoP），常用于评估平衡能力，其中 CoP 是一项特别敏感的测量指标 [9], [10]。除了生物力学，神经生理记录（如 EEG 和 EMG）也越来越多地用于表征平衡过程中的皮层参与，包括在具有挑战性或双重任务条件下 [3], [11]–[13]。此类多模态证据可为临床评估和技术辅助康复提供参考，包括基于传感器的干预和富含认知成分的训练范式 [14], [15]。

Fig. 1. 站立稳定性评估的实验设置。在四种站立条件下同步记录脑电图（EEG）信号和压力中心（CoP）数据：双脚站立（DS）、串联站立（TS）、带有认知任务的串联站立（TSC）以及带有认知和运动复合任务的串联站立（TSCM）。

认知衰退作为老龄化的一个常见方面，通过影响记忆、注意力、执行功能和决策能力——这些对于安全行动和日常多任务处理至关重要的能力——进一步加剧了平衡控制的复杂性 [16]。特别是，双任务范式为探究认知-运动干扰提供了一种具有生态效度的方法：认知负荷的增加会破坏姿态控制的稳定性，并与老年人的跌倒风险相关联 [17]。近期的神经影像学/EEG 证据表明，双任务站立会调动额外的皮层资源，这支持了随着任务难度增加，平衡控制越来越由“皮层介导”的观点 [18], [19]。

本研究的目的是探讨在涉及平衡控制的认知和运动需求的双任务条件下，不同难度的站立任务如何影响老年人的大脑活动和姿态摇摆动态。相关的初步发现已在我们先前的会议研究中展示 [20]。

## II. 方法

## A. 实验设置

8 名久坐老年人（性别：2女/6男；年龄：$6 4 . 5 \ \pm$ 3.7 岁；体重：$6 3 . 7 \pm 1 1 . 3$ kg；身高：$1 6 5 \pm 9 . 2$ cm）在签署知情同意书后参与了本研究。该方案获得了南洋理工大学（Nanyang Technological University）机构审查委员会（IRB-2022-382）的批准，并在 Rehabilitation

新加坡研究机构（Research Institute of Singapore）。参与者以伪随机顺序完成了四项静态平衡任务——双足站立（DS）、串联站立（TS）、包含认知任务的串联站立（TSC），以及结合认知与运动任务的串联站立（TSCM）。在所有任务中，参与者均双眼睁开、注视十字标记并保持直立。双脚分别置于独立的测力台（9260AA6, Kistler Instruments AG）上，以 2000 Hz 记录压力中心（CoP）数据。所有参与者均为右利手且右腿为优势腿。EEG 数据通过 32 通道 actiCAP 系统（BrainProducts）采集，使用导电膏安装主动电极。FCz 作为参考电极，接地电极置于前额中央。使用 BrainVision Recorder 以 500 Hz 记录信号。在 DS 中，参与者安静站立 40 s。TS 要求优势脚在前呈串联姿势站立，双臂置于身体两侧。TSC 在 TS 的基础上增加了记忆任务，参与者需记忆并在随后回忆一组数字序列。在 TSCM 中，参与者在执行 TSC 的同时优势手持装有水的水杯。TS、TSC 和 TSCM 各重复两次（每次试验 40 s），并取平均值用于分析。

## B. EEG 特征

对原始连续 EEG 数据进行预处理，以提高信噪比并确保频域分析的有效性。所有步骤均排除了三轴加速度计通道。应用 1-30 Hz 带通有限冲激响应（FIR）滤波器以抑制低频漂移和高频运动伪影。根据统计标准识别坏通道并通过球面插值进行重建，以补偿电极接触不良引起的信号衰减。这些通道随后被重新参考至公共平均参考，从而减少依赖参考的偏差并提高参与者之间的数据可比性。

根据开始事件标记，EEG 数据被分割为对应于各任务条件的 40 秒数据段（epoch）。包含大量伪影（如运动相关噪声或信号丢失）的数据段通过目测识别并排除在进一步分析之外。随后使用独立成分分析（ICA）[21] 去除伪影成分，该方法能有效分离非神经源，如眼动、心电和肌肉活动。从这些净化后的数据段中，使用来自数据段前 1 秒时间间隔的平均电压进行基线校正，以最小化基线波动并提高频谱一致性。

在伪影校正后，使用 Welch 方法估计功率谱密度（PSD）以提取特定频率特征 [22]。分别计算了 theta（4-8 Hz）和 alpha（8-12 Hz）频段的功率。随后针对每个受试者跨任务条件对这些频谱特征取平均，作为后续统计比较的输入。

## C. CoP 摆动特征

前后（AP）和内外（ML）方向的 CoP 信号从力和力矩数据中提取，并使用四阶零相位巴特沃斯（Butterworth）低通滤波器在 15 Hz 处进行滤波。根据这些信号，我们计算了全身 CoP 面积和平均频率，以及在 AP 和 ML 两个方向上的平均距离、最大范围、平均速度和功率频率离散度 [10]。在所有任务条件下对这些特征进行了比较。使用 Shapiro-Wilk 检验评估正态性。对于正态分布的变量采用配对 t 检验；否则应用 Wilcoxon 符号秩检验。所有比较均采用 Bonferroni 校正后的显著性阈值 $p < 0 . 0 5$。

## III. 结果

## A. EEG 动态

图 2 展示了在不同平衡任务条件下，五个关键电极（C3、Cz、C4、P3、P4）在 theta 和 alpha 频段的平均功率变化。其中，电极 C3、Cz 和 C4 主要位于躯体感觉和运动相关的皮层区域，而 P3 和 P4 则与知觉处理和注意力调节相关。这五个电极共同构成了本研究的感兴趣区（ROI）。

在最基础的任务 DS 中，所有五个电极在两个频段的功率水平均保持在较低水平。在 TS 中，ROI 内的 theta 功率有所增加。在 TSC 中，电极 P3 和 P4 的 theta 功率平均增加了 49.33%，而 C3、Cz 和 C4 则平均增加了 19.28%。

在 TSCM 中，P3 和 P4 的 theta 功率与 TSC 条件下观察到的结果相当。然而，电极 C3、Cz 和 C4 显示出更显著的功率增加，其中 Cz 和 C4 平均增加了 58.69%，而 C3 的增幅最大，达到 163.22%。

综上所述，ROI 电极上的 theta 功率随着任务难度的增加而逐步提高。相比之下，alpha 频段的功率在所有任务条件下保持相对稳定，振幅较低且波动极小。

## B. CoP 摇摆测量指标

与 DS 相比，在 ML 和 AP 两个方向上，TS (ML: $p < 0 . 0 1 , \mathrm { A P } ; p = 0 . 0 1 )$ 、TSC (ML: $p < 0 . 0 1$ AP: $p < 0 . 0 1 )$ 和 TSCM (ML: $p < 0 . 0 1$ , AP: $p = 0 . 0 1 )$ 的平均距离均显著更高。此外，在 TS、TSC 和 TSCM 中，AP 方向的平均距离值始终大于 ML 方向。

范围（定义为最大偏差之间的距离）呈现出类似的趋势，与 DS 相比，TS $( p ~ < ~ 0 . 0 1 )$ 、TSC (ML: $p \ = \ 0 . 0 5$ , AP: $p ~ < ~ 0 . 0 1 )$ 和 TSCM $( p < 0 . 0 1 )$ 在 ML 和 AP 两个方向上的值均显著更大。类似地，在 ML 和 AP 两个方向上，TS、TSC 和 TSCM 的平均速度与功率均显著高于 DS，且 AP 方向的值始终高于 ML 方向。

尽管面积仅在 TS 和 DS 之间存在显著差异 $( p \ : = \ : 0 . 0 5 )$ ，但与 DS 相比，TSC 和 TSCM 的面积也更大。与 DS 相比，TS $( p ~ < ~ 0 . 0 1 )$ 、TSC $( p ~ < ~ 0 . 0 1 )$ 和 TSCM $( p = 0 . 0 1 )$ 的姿势摇摆平均频率显著更高。此外，平均频率呈现递增趋势，表现为 TSC 高于 TS，TSCM 高于 TSC。在所有条件下均未观察到频率离散度存在显著差异。

## IV. 讨论

在本研究中，我们通过分析四种站立姿态条件（DS、TS、TSC 和 TSCM）下的脑电（EEG）活动和压力中心（CoP）动力学，探讨了老年人姿势控制背后的神经机制。我们的研究结果表明，随着任务难度的增加，感兴趣区（ROI）电极上的 theta 频段功率呈渐进性增加。相比之下，alpha 频段功率在所有任务条件下保持相对稳定，始终表现出较低的振幅和极小的波动。姿势摇摆的测量指标——包括平均距离、范围、平均速度、摇摆面积和平均频率——与 DS 相比，在 TS、TSC 和 TSCM 条件下通常普遍升高，这表明在较窄的支撑基底上维持平衡面临更大的挑战。这些发现为不同脑区在不同任务需求水平下的姿势稳定作用提供了重要见解。此类认知通过确定平衡的关键神经肌肉影响因素，特别是在窄步态或双任务情境等复杂条件下，可能有助于制定具有针对性的损伤预防策略和康复计划。这些结果与近期的跌倒预防框架相一致，该框架强调了在现实认知-运动需求下评估平衡以及设计明确训练双任务平衡控制的干预措施的重要性 [23]。

在难度递增的站立姿态条件下观察到的 theta 功率渐进性增加，可能反映了认知控制和姿势调节机制的更深度参与。具体而言，在 TSC 期间顶叶电极（P3 和 P4）处 theta 活动的显著升高，表明顶叶皮层区域在应对升高的认知负荷时被更多地募集 [24], [25]。此外，在兼具认知与运动成分的最严苛条件 TSCM 下，中央区电极 $( \mathbf { C } 3 , \mathbf { C } \mathbf { Z } ,$ and C4) 处的 theta 功率表现出进一步放大。值得注意的是，C3 表现出最高的增幅，这可能是由于右手执行运动任务，从而导致对侧（左半球）运动皮层出现更强的激活 [26]。这些发现支持了这样一种观点，即复杂的姿势控制需要顶叶联络区与运动皮层之间更紧密的协调 [27], [28]。相对不变的 alpha 活动可能表明，alpha 频段对姿势挑战的敏感度较低，并在静态平衡维持过程中保持持续调节。

在这些神经学发现的基础上，对 CoP 动力学的分析进一步表明，任务复杂度和站立类型显著影响姿势控制，导致不稳定性增加和更频繁的调整——尤其是在 AP 轴上。平均距离、范围和速度在 TS 中上升，并在增加认知（TSC）和运动（TSCM）任务后进一步增加。AP 功率在 TS、TSC 和 TSCM 中显著升高，反映出更高的平衡需求。平均摇摆频率从 TS 到 TSC 再到 TSCM 逐渐增加，而频率离散度保持一致，这表明尽管调整更加频繁，但摇摆变异性保持稳定。总体而言，附加额外任务的串联站立对姿势稳定性构成了最大的挑战，尤其是在 AP 方向上。

## V. 结论

本研究通过整合 EEG 和 CoP 数据，系统地研究了老年人在复杂度不断增加的平衡任务中的皮层活动模式和姿势稳定性。随着任务难度的增加，顶叶和中央运动相关皮层区域的 theta 频段功率逐渐上升，在包含认知和运动需求的双任务条件（TSCM）下，中央电极（特别是 C3）处观察到的增强最为显著，表明皮层参与度提高。这可能反映了多任务处理过程中对感觉整合和运动协调需求的增加。相比之下，alpha 频段功率在所有条件下保持相对稳定，这表明 alpha 活动可能在静态姿势维持中发挥着一致的作用，受任务难度的影响较小。在行为层面上，CoP 分析显示，随着任务复杂度的增加，特别是在 TSC 和 TSCM 条件下，沿 AP 轴的摇摆幅度、速度和功率显著增加，表明对姿势控制提出了更高的要求。摇摆频率也逐渐增加，而频率离散度保持不变，表明姿势调整更为频繁但依然稳定。总的来说，这些研究结果突出了中央和顶叶皮层在认知-运动双任务条件下介导姿势控制的关键作用。该结果提供了神经生理学证据，可为老年人群的跌倒风险评估、针对性康复策略以及神经自适应辅助技术的开发提供参考。
