# 基于神经肌肉骨骼求解器引导高斯过程模型的带不确定性膝关节力矩预测

Longbin Zhang, Xiaochen Zhang, Xueyu Zhu, Ruoli Wang, and Elena M. Gutierrez-Farewik

摘要— 结合用户力矩能力的外骨骼助力策略正受到日益增长的研究关注，然而预测力矩能力中的不确定性会显著影响用户-外骨骼界面的安全性。在本文中，我们使用以肌肉肌电（electromyography, EMG）信号和关节运动学为模型输入的神经肌肉骨骼（neuromusculoskeletal, NMS）求解器引导高斯过程（NMS-GP）模型估计了膝关节屈/伸力矩。NMS-GP模型通过将来自NMS求解器的重要特征整合到GP模型中，实现了NMS与GP模型的结合。NMS-GP模型被用于日常活动中膝关节力矩的预测及不确定性量化。这些活动包括慢速行走、自选速度行走、快速行走、坐立转换（sit-to-stand）和立坐转换（stand-to-sit）。我们对NMS-GP模型和NMS模型的性能（定义为模型预测力矩与逆向动力学计算所得实测力矩之间的低预测误差）进行了分析。结果发现，NMS-GP模型的预测误差显著低于NMS模型。我们在每个动作开始时观察到预测膝关节力矩存在相对较高的不确定性，尤其是在自选速度行走中。在自选速度行走的支撑末期和摆动期也发现了较高的不确定性。与其他力矩预测方法相比，所提出的NMS-GP模型不仅能够提供准确的关节力矩预测，还能提供不确定性度量。我们的研究表明，NMS-GP模型在康复外骨骼控制策略设计以及改善用户整体体验方面具有巨大潜力。

## I. 引言

机器人外骨骼越来越广泛地应用于中风（stroke）、脑瘫（cerebral palsy）和脊髓损伤（spinal cord injury）等运动障碍患者的康复中 [1]–[7]。这些病症通常会导致肌肉无力、协调障碍和活动受限，使患者在进行日常活动时面临挑战。机器人外骨骼可以在康复训练过程中提供辅助，使运动障碍患者能够完成原本困难或无法实现的日常活动和/或锻炼 [8]–[10]。在外骨骼辅助康复训练中，将肌电图（electromyography, EMG）等用户的生物信号融入控制策略已受到广泛关注，因为这能让用户主动参与其中，从而激发运动再学习 [11], [12]。这种被称为按需辅助（assistance-as-needed）控制策略的康复训练方法，其核心在于仅在需要的时间和部位提供辅助，从而提升患者执行特定任务和动作的能力，并已展现出改善康复效果的潜力 [13]–[16]。一种常见的按需辅助策略是根据 EMG 信号估计用户的生理关节力矩，并将其作为控制器的输入。

基于肌电（EMG）驱动的神经肌肉骨骼（neuromusculoskeletal, NMS）模型方法和机器学习是基于来自 EMG 传感器的肌肉兴奋信号预测用户生理关节力矩的两种常用技术 [17]–[19]。通常，NMS 模型需要领域专业知识来建立各种变量之间的关系，例如肌肉兴奋与激活度、肌力与肌长、肌力与肌速以及肌腱运动学，并且可能涉及复杂的校准流程 [19]–[22]。相反，机器学习可以在无需显式描述变量之间复杂关系的情况下估算关节力矩。然而，机器学习通常被视为一种黑盒方法，因为它无法提供对物理系统底层机制的理解。这可能导致其在预测训练分布之外的数据时变得不可靠，尤其是在训练数据有限的情况下 [23]。基于物理的 NMS 方法和机器学习方法各有其优缺点。我们最近提出了一种混合模型，该模型将来自 NMS 求解器的物理特征与标准人工神经网络（artificial neural network, ANN）相结合 [24]，以提高单独使用 ANN 预测步态和等速运动期间踝关节力矩的准确性。我们发现，与 NMS 和 ANN 模型相比，该混合模型表现出更优异的性能，从而凸显了将 NMS 模型中的有效特征融入 ANN 所带来的优势。然而，这一结论存在一个例外；我们观察到，在自选速度行走过程中，我们的混合 ANN 模型的表现逊于标准 ANN。这可能是由于校准和测试运动之间的肌肉协调模式差异或 EMG 输入信号的不确定性，导致从 NMS 模型引入的输入特征具有代表性甚至具有误导性。因此，量化模型预测的不确定性至关重要，特别是当其用于外骨骼控制时。

高斯过程（Gaussian processes, GPs）已被证明是在各种应用中进行包含不确定性预测的强大工具，例如关节运动学预测 [25]、天气预报 [26] 和机器人运动规划 [27]。GP 是一种概率模型，能够为其预测提供不确定性度量 [28]。Liang et al.

[25] 提出了一种基于 EMG 信号预测行走和跑步过程中膝关节角度的 GP 模型。他们证明了 GP 模型在提供不确定性信息的同时准确预测膝关节角度的能力。类似地，Yun 等人 [29] 仅使用人体参数作为输入，应用 GP 模型预测人类步态模式。他们发现 GP 模型是一种用于估计步态运动学的经济高效且针对特定受试者的方法。GP 模型有助于全面理解人体测量参数与步态运动学之间的相关性及不确定性。据我们所知，高斯过程（Gaussian processes）尚未被应用于以实测 EMG 信号为输入来预测膝关节力矩。然而，这似乎是一种用于量化与关节力矩预测相关的不确定性的很有前景的技术。

我们的目标是通过使用一种结合了实测肌肉肌电信号和膝关节角度作为模型输入的 NMS 解算器引导的高斯过程（NMS solver-informed Gaussian process, NMS-GP）模型，来估计不同日常运动过程中的膝关节屈曲/伸展（F/E）力矩。我们假设 NMS-GP 模型比单独的 NMS 模型能产生更准确的膝关节力矩预测。次要目标是量化模型在不同运动过程中预测膝关节力矩的不确定性。

## II. 方法

## A. 数据采集与处理

招募了 8 名身体健全的受试者（性别：4 女/4 男；身高：168.1±9.4 cm；体重：65.2±17.8 kg；年龄：29±4 岁）。瑞典伦理审查委员会（Swedish Ethical Review Authority）批准了本研究（Dnr. 2020-02311），所有受试者均提供了书面知情同意书。所有参与者均佩戴了用于 3D 运动捕捉的传感器，并被要求完成五种不同的日常运动，具体包括慢速行走、以自选步速正常行走、快速行走、从坐到站以及从站到坐。每种记录的运动至少重复 10 次。

在 1000 Hz 下测量了每位参与者随机选定的一侧腿部的股直肌（rectus femoris, RF）、股内侧肌（vastus medialis, VM）、股外侧肌（vastus lateralis, VL）、股二头肌（biceps femoris, BF）、半腱肌（semitendinosus, ST）、腓肠肌内侧头（gastrocnemius medialis, GM）和腓肠肌外侧头（gastrocnemius lateralis, GL）的表面 EMG 信号（Myon aktos/Cometa systems, Milan, Italy）。原始 EMG 信号的后处理过程如下：进行带通滤波（30- 300 Hz）、整流、低通滤波（6 Hz），并根据所有运动试验中的最大 EMG 值进行归一化 [2], [20], [30]。

使用三维运动捕捉系统（100 Hz，V16，Vicon，Oxford，UK）记录标记点轨迹，标记点粘贴方案遵循 CGM2.3 模型 [31]。地面反作用力通过三块测力台（1000 Hz，AMTI，MA，USA）进行测量。运动学参数（关节角度）通过逆运动学方法获得，该方法旨在最小化模型预测标记点轨迹与实测标记点轨迹之间的差异。采用逆动力学计算满足动力学运动方程的关节力矩 [32], [33]。使用四阶零滞后巴特沃斯低通滤波器（6 Hz）对关节运动学和动力学数据进行滤波处理 [34]–[36]。

## B. 神经肌肉骨骼求解器引导的高斯过程回归模型

在本研究中，我们使用了 Pizzolato 等人 [21] 开发的开源肌电引导 NMS 模型，该模型由四个单元组成（Fig. 1）：肌肉激活度动力学、肌肉肌腱运动学、肌肉收缩动力学以及关节动力学 [37]。肌肉激活度动力学单元基于 EMG 信号（肌肉兴奋度）计算肌肉激活度。肌肉肌腱运动学单元计算肌肉肌腱长度和力臂。肌肉收缩动力学单元使用 Hill 型肌肉模型，以肌肉激活度和肌肉肌腱长度为输入计算肌肉肌腱力。最后，关节动力学单元以肌肉肌腱力和力臂为输入计算关节力矩。

NMS知情高斯过程（NMS-informed GP）模型的输入 $\mathbf { x } ~ = ~ [ x _ { 1 } , x _ { 2 } , \ldots , x _ { n } ] ^ { T } ( n ~ = ~ 2 1 )$ 通过两类特征进行了扩充 (Fig. 1)：(1) 来自 3D 动作捕捉系统实验测量的肌肉信号和关节运动学，以及 (2) 来自底层 NMS 求解器的物理特征——肌肉力和基于 NMS 的力矩。这些特征通过提供有关建模系统的更多信息，用于提高模型性能的精度。NMS-GP 模型 $f ( \mathbf { x } )$ 由均值函数 $\mu ( \mathbf { x } )$ 和协方差函数 $k ( \mathbf { x } , \mathbf { x ^ { ' } } )$ 表征，如公式 (1) 所示 [38]。

$$
f (\mathbf {x}) \sim G P (\mu (\mathbf {x}), k (\mathbf {x}, \mathbf {x} ^ {\prime}))\tag{1}
$$

均值函数 $\mu ( \mathbf { x } )$ 用于估计函数在给定输入下的期望值，可定义为公式 (2)：

$$
\mu (\mathbf {x}) = E [ f (\mathbf {x}) ]\tag{2}
$$

协方差函数（又称核函数）表示两个输入变量之间的相似性。它用于估计预测的不确定性，定义如公式 (3) 所示 [39]：

$$
k (\mathbf {x}, \mathbf {x} ^ {\prime}) = E [ (f (\mathbf {x}) - \mu (\mathbf {x})) (f (\mathbf {x} ^ {\prime}) - \mu (\mathbf {x} ^ {\prime})) ]\tag{3}
$$

高斯过程模型中有多种可用的核函数。最常用的函数之一是径向基函数（RBF）核，它是一种平滑且无限可微的函数，能够很好地捕捉数据的底层结构。其定义如公式 (4) 所示：

$$
k (\mathbf {x}, \mathbf {x} ^ {\prime}) = \exp (- \frac {| \mathbf {x} - \mathbf {x} ^ {\prime} | ^ {2}}{2 l ^ {2}})\tag{4}
$$

其中 $l$ 是控制核长度尺度（length-scale）的超参数，$| { \bf x } - { \bf x } ^ { \prime } |$ 是两个输入 $\mathbf{x}$ 与 $\mathbf { x } ^ { \prime }$ 之间的欧几里得距离。

另一种常用的核函数是 Matern 核，它是 RBF 核的推广，定义如公式 (5) 所示：

$$
k (\mathbf {x}, \mathbf {x} ^ {\prime}) = \frac {2 ^ {1 - \nu}}{\Gamma (\nu)} \left(\frac {\sqrt {2 \nu}}{l} | \mathbf {x} - \mathbf {x} ^ {\prime} |\right) ^ {\nu} K _ {\nu} \left(\frac {\sqrt {2 \nu}}{l} | \mathbf {x} - \mathbf {x} ^ {\prime} |\right)\tag{5}
$$

其中 $\nu$ 是决定核平滑度的正参数，$K _ { \nu }$ 是修正贝塞尔函数，$\Gamma ( \nu )$ 是 Gamma 函数，$l$ 是控制核尺度的长度尺度参数。

白噪声核（White Noise Kernel）是另一种常用核，在此用于对数据中的噪声进行建模，如公式 (6) 所示：

$$
k (\mathbf {x}, \mathbf {x} ^ {\prime}) = \sigma^ {2} \delta (\mathbf {x} - \mathbf {x} ^ {\prime})\tag{6}
$$

其中 $\sigma ^ { 2 }$ 是控制噪声幅度的噪声方差参数，而 $\delta \big ( \mathbf { x } - \mathbf { x } ^ { \prime } \big )$ 是狄拉克 $\delta$ 函数（Dirac delta function），当 $\textbf { x } = \textbf { x } ^ { \prime }$ 时等于 1，否则为 0。它确保了核函数仅在输入空间的对角线处（即 $\mathbf { x } = \mathbf { x } ^ { \prime }$ 时）非零。

线性核（Linear kernel）是另一种常用的核函数，用于建模输入与输出之间的线性关系，如公式 (7) 所示：

$$
k (\mathbf {x}, \mathbf {x} ^ {\prime}) = \sigma^ {2} \mathbf {x} ^ {T} \mathbf {x} ^ {\prime}\tag{7}
$$

其中 $\sigma ^ { 2 }$ 为方差参数。

在实践中，通常会将不同的核函数进行组合以提升高斯过程模型的性能。这被称为核组合（kernel composition），可以通过将不同核函数相加或相乘来实现。这使得模型能够捕捉数据中的各种潜在结构，并提高预测的整体精度。在对多种核函数进行实验后，基于试错测试，我们在 GP（高斯过程）模型中采用了 Matern 核、白噪声核（White Noise kernel）和线性核的组合；该组合在数据集上产生了最准确的预测结果。Matern 核使我们能够捕捉数据中潜在的任何非线性模式，而白噪声核有助于解释任何测量误差或其他不确定性来源。另一方面，线性核则有助于建模输入与输出之间的线性关系。

高斯过程回归在 Python 中使用 scikit-learn 软件包中 gaussian process 模块的 GaussianProcessRegressor 库和核函数完成。在训练过程中，对与 GP 模型相关的超参数（包括长度尺度 length scale、信号方差、噪声方差等）进行了调整以优化其性能。具体而言，在 Matern 核中，正参数 ν 被设置为 3/2。长度尺度的取值范围限定在 (0.01, 200) 之间，方差限定在 $( 1 0 ^ { - 3 } , 1 0 ^ { 5 } )$ 之间。对于白噪声核，噪声方差限定在 (0.03, 100) 之间；对于线性核，方差限定在 $( 1 0 ^ { - 3 } , 1 0 ^ { 5 } )$ 之间）。

## C. 评估协议 (Evaluation Protocol)

我们研究了基于 NMS 和 NMS-GP 模型的膝关节力矩预测精度（在此定义为预测力矩与逆向动力学测量力矩之间的误差），并分析了 NMS-GP 模型的不确定性量化。在五种情况下评估了包含不确定性量化的预测精度：$G a i t _ { s l o w } , \ G a i t _ { s e l f } , \ G a i t _ { f a s t } ,$ $\mathit { S i t T o S t a }$ 和 $S t a T o S i t$；其中针对每种运动分别训练了一个独立的 NMS-GP 模型。在所有情况下，NMS-GP 模型均使用 80% 的记录数据进行训练，随后使用剩余数据进行评估，而 NMS 模型则使用每种运动的三个试验进行校准，并在与 NMS-GP 测试数据相同的试验上进行测试。

每个模型的力矩估计误差使用归一化均方根误差（NRMSE）$E _ { N R M S }$ 进行评估，其中较低的估计误差意味着较高的预测精度。NRMSE 定义为（预测力矩与测量力矩之间的）均方根误差 $E _ { R M S }$ 除以相应动作中逆向动力学观察到的关节力矩范围：

$$
E _ {R M S} = \sqrt {\frac {1}{N} \sum_ {n = 1} ^ {N} (y _ {p , n} - y _ {n}) ^ {2}}\tag{8}
$$

$$
E _ {N R M S} = \frac {E _ {R M S}}{(y _ {m a x} - y _ {m i n})} \times 100\%\tag{9}
$$

## IV. 讨论

我们提出了一种 NMS-GP 模型，利用测得的肌肉肌电（EMG）信号和关节运动学数据来估计膝关节屈曲/伸展力矩。我们的结果表明，NMS-GP 模型的预测误差显著低于传统 NMS 模型，这支持了将 NMS 模型的特征整合到机器学习模型中能够发挥各模型优势的假设。此外，NMS-GP 模型量化了力矩预测中的不确定性。在每次运动开始时，力矩预测的不确定性相对较高，尤其是在自选速度行走中。在自选速度行走的站立末期和摆动期也观察到了较高的不确定性。不仅能够准确预测关节力矩，而且能够计算这些预测的不确定性，这种能力在某些应用中具有非常重要的潜在意义，例如同时确保外骨骼的有效性和安全性。通过将这些不确定性纳入控制策略，我们可以更好地管理风险，并确保安全舒适的人机交互界面。

研究发现，具备不确定性量化功能的 NMS-GP 模型能够以相对较低的误差（RMSE ≤ 0.05 Nm/kg, $\mathrm { N R M S E } \leq 5 . 9 \% )$ 准确预测膝关节力矩，且表现优于传统 NMS 模型（RMSE ≤ 0.14 Nm/kg, NRMSE ≤ 18.3%）。这些发现证实了我们先前研究 [22] 的结果，在该研究中，我们应用了混合 NMS-ANN 模型来预测步态和等速运动期间的踝关节力矩。在那项研究中，我们将 NMS 模型的物理特征与标准 ANN 相结合，发现 NMS-ANN 模型在大多数情况下表现良好，仅有少数例外。然而，混合 NMS-ANN 模型仅在踝关节进行了评估。在本研究中，我们进一步探索了其他机器学习模型，特别是包含预测不确定性量化的高斯过程（Gaussian process）模型。我们观察到 NMS-GP 模型在每次运动开始时往往具有较高的预测不确定性。这可能是由于在每次运动开始时采用了来自 NMS 模型的物理特征，在此处也观察到了较大的偏差。NMS 模型需要前两个时间步长的神经激活度来计算每个肌腱单元（MTU）的肌肉神经激活度 [22]。然而，这些数据在一个周期的开始时是不可用的，而是使用前两个时间步长的 EMG 进行近似估计。这种近似可能会在预测力矩中引入初始偏差。此外，在自选速度行走的站立末期和摆动末期观察到了相对较高的不确定性。这可能是由于步态的站立相和摆动相之间的转换所致，在此期间可能存在不同的肌肉协同模式。在外骨骼控制器设计中应当考虑这些高不确定性阶段。

在本研究中，我们仅使用了一种机器学习模型和 NMS 模型；有必要开展涉及其他机器学习方法和 NMS 模型的研究，以推广我们的研究结果。此外，未来的研究应侧重于将具有不确定性量化的关节力矩预测应用于外骨骼控制，这对于实现实际应用至关重要。我们的方法在不同速度的步态、坐立转换和立坐转换动作中进行了测试；需要进一步的测试和验证以确定其在更广泛活动范围内的适用性。本研究的另一个局限性在于，所招募的受试者在年龄和整体健康状况方面相对同质。为了将这些发现推广到其他研究群体，开展涉及具有更广泛年龄段和神经肌肉功能的多样化受试者群体的进一步研究至关重要。

## V. 结论

在本研究中，我们提出了一种 NMS-GP 模型，利用测得的肌肉肌电信号和关节运动学来估计膝关节屈曲/伸展力矩。NMS-GP 模型将传统 NMS 模型与包含不确定性量化的现代机器学习技术相结合。所提出的 NMS-GP 模型不仅提供了更高的预测精度，而且还提供了预测不确定性的度量。该方法可用于提升康复外骨骼的性能，并在外骨骼控制和干预的实时评估等多种应用中展示出巨大潜力。
