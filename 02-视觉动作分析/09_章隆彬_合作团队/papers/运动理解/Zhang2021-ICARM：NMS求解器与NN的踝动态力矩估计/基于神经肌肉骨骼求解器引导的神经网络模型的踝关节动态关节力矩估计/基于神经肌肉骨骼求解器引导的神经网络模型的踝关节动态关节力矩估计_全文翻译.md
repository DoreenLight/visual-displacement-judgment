# 基于神经肌肉骨骼求解器引导的神经网络模型的踝关节动态关节力矩估计

Longbin Zhang, Xueyu Zhu, Elena M. Gutierrez Farewik, and Ruoli Wang

摘要— 本文提出了一种神经肌肉骨骼（neuromusculoskeletal, NMS）求解器引导的人工神经网络（artificial neural network, ANN），用于估计七种运动中的踝关节力矩，包括快速、慢速和自选速度的行走，以及在 60 和 90°/s 下的踝关节等速背屈和跖屈运动。该 NMS 求解器引导的 ANN 模型是标准 ANN 模型的扩展，结合了来自 NMS 求解器的附加特征，即踝关节力矩和肌肉力。标准 ANN、NMS 求解器引导的 ANN 以及肌肉驱动的 NMS 模型被用于预测踝关节力矩。基于从 10 名受试者采集的数据，对各模型的预测精度进行了比较。在所有方法中，我们均使用测量的踝关节角度和肌电图（electromyography, EMG）信号作为输入来训练模型。研究了七种不同的工况，利用三种运动类型（行走、等速跖屈和背屈）下不同速度的试验数据来校准/训练相同运动类型下的模型。NMS 求解器引导的 ANN 模型在预测踝关节力矩方面的表现优于 NMS 模型和标准 ANN 模型，这表明将 NMS 特征集成到标准 ANN 模型中带来了显著优势。因此，所提出的 NMS 求解器引导的 ANN 模型在按需辅助康复外骨骼控制器的设计中展现出良好的应用前景。

## I. 引言

机器人辅助设备（如外骨骼）经常被研究用于为运动障碍患者提供康复和功能替代 [1]–[5]。动力外骨骼是可穿戴的人机一体化设备，能够为肌力不足或患有运动障碍的用户提供辅助。例如，Li 等人 [6] 提出了一种用于动力行走外骨骼的混合控制策略，以增强爬楼梯运动中的运动能力。该混合策略将脑机接口与肌电图（EMG）信号相结合作为控制器输入，其实验结果表明所提出的控制策略能够增强用户的运动能力。近几十年来，融合了运动期间生理参数的控制策略（例如用于外骨骼控制器的所需生理关节力矩）在康复外骨骼中变得流行起来，其旨在鼓励患者主动参与以促进运动功能的恢复 [7]–[10]。

在所需的生理关节力矩预测中，以肌电（EMG）信号作为输入的肌电驱动神经肌骨（NMS）模型方法得到了广泛研究。通常，NMS 模型需要复杂的校准程序并在不同变量之间构建关联 [11]。此外，基于物理的模型只能提供关节动力学的粗略估计 [12]–[14]。近年来，机器学习技术已成功应用于分类、回归和模式识别任务等多个应用领域，并展现出了强大的学习能力 [15]–[20]。在机器学习方法中，人工神经网络（ANN）已被广泛用作预测肢体关节力矩的替代方案，无需显式地对变量之间的复杂关系进行建模。在我们前期的工作中 [21]，我们通过基于 NMS 和基于 ANN 的方法预测了行走以及踝关节等速跖屈和背屈运动中的踝关节力矩。我们评估了力矩预测的效率以及准确性。我们发现，当在模型中通过显式数学方程包含一些物理约束时，NMS 的踝关节力矩预测一致性更加可靠。与 NMS 在不同特征之间构建复杂且显式的关系相比，ANN 模型在大型数据集上进行训练时，能够以更少的工作量和计算资源更好地预测力矩。

识别对神经网络（NN）模型有信息量的特征对于提高 NN 的预测能力至关重要 [22]。例如，Zhang 等人 [23] 提出了一种求解器引导的 NN（solver-informed NNs），通过从现有光谱重建求解器中添加更多信息量丰富的特征来重建胶体量子点光谱仪的光谱。他们的结果表明，由于新添加的特征，重建的准确性和鲁棒性得到了提高，这也与机器学习界的传统认知相一致——即提取对 NN 模型有信息量的特征对于增强 NN 的预测能力至关重要。鉴于基于肌电驱动模型的方法和基于 ANN 的方法在肢体关节力矩预测中各有优势，一个自然产生的问题是：结合来自物理模型的信息特征来训练 ANN 模型是否有益。

## II. 方法

## A. 数据采集与处理

招募了由 10 名健全受试者（年龄：$2 6 ~ \pm ~ 2 . 8 6$ 岁）组成的方便样本。实验测试包括三种运动类型——行走（慢速、自选速度和快速）以及等速踝关节背屈与等速踝关节跖屈（60°/s 和 90°/s 两种不同速度，Fig. 1）。在步态实验中，每位参与者首先以自选速度行走至少三次试验，随后在节拍器定拍下分别以 100 步/分钟和 120 步/分钟行走。在等速运动任务中，受试者被要求采取俯卧位，右脚固定于与测力计（IsoMed 2000, Hemau, Germany）相连的踏板上。该测力计用于以 5000 Hz 记录踝关节力矩和角度。每位参与者被要求在 15° 背屈至 20° 跖屈的活动度范围内，尽最大努力连续进行五次跖屈和背屈。所有受试者均自愿参与并签署了知情同意书。该研究已获得瑞典斯德哥尔摩地区伦理委员会的批准。

通过三维动作分析系统（Qualisys, Gothenburg, Sweden）以 200 Hz 记录受试者的运动，该系统基于 Plug-in Gait 标记点集方案 [24], [25] 追踪贴在参与者身上的反光标记点。地面反作用力（GRF）由两块测力台（Kistler, Winterthur, Switzerland）以 3000 Hz 采集。每位受试者右腿的胫骨前肌（TA）、比目鱼肌（SOL）和腓肠肌内侧头（GM）的表面肌电（EMG）信号通过表面肌电电极以 3000 Hz 记录。

EMG 信号经带通滤波（30- 300 Hz）、整流、低通滤波（6 Hz）处理，并通过各试验处理后 EMG 所获得的最大 EMG 值进行归一化 [26]–[28]。EMG、标记点和 GRF 数据由 MOtoNMS 工具箱 [29] 处理，该工具箱可处理以 C3D 格式存储的实验数据，并生成用于 OpenSim (SimTK, Stanford, USA) 等 NMS 建模软件的输入数据。我们使用开源肌肉骨骼建模软件（OpenSim 3.3）以及包括缩放、逆运动学和逆动力学在内的既定流程计算了踝关节角度和力矩 [26]。

## B. 关节力矩预测模型

1) EMG 驱动的 NMS 模型：我们采用了由 Pizzolato 等人 [30] 开发的开源 EMG 信息驱动 NMS 模型，该模型由四个要素组成：肌肉激活力学、肌肉收缩力学、肌腱运动学和关节动力学 [31]。

肌肉激活动力学单元用于以采集到的 EMG 信号作为输入来计算肌肉激活度。在时间 t 域内，采集到的 EMG 信号 $e ( t )$ 与神经激活度 u(t) 的关系如公式 (1) 所示 [32]。

$$
u (t) = \alpha e (t - d) - \beta_ {1} u (t - 1) - \beta_ {2} u (t - 2)\tag{1}
$$

其中 α 为肌肉增益系数；d 为机电延迟；$\beta _ { 1 }$ 和 $\beta _ { 2 }$ 为递归系数。神经激活度与肌肉激活度 a(t) 相关，其关系表述如公式 (2) 所示：

$$
a (t) = \frac {e ^ {A u (t)} - 1}{e ^ {A} - 1}\tag{2}
$$

其中 A 为非线性形状因子 [28], [33]。

肌肉收缩动力学单元用于使用 Hill 型肌肉模型计算肌腱力。每个肌腱单元（MTU）中的力 $F ^ { m t }$ 与肌肉激活度及运动学之间的关系定义为公式 (3)，

$$
F ^ {m t} = F _ {0} ^ {m} [ f _ {a} (\tilde {l} _ {m}) f _ {v} (\tilde {v} _ {m}) a + f _ {p} (\tilde {l} _ {m}) + d _ {m} \tilde {v} _ {m} ] c o s (\phi)\tag{3}
$$

其中 $F _ { 0 } ^ { m }$ 为最大等长肌力，$\tilde { l } _ { m }$ 为肌纤维长度，$f _ { a } ( \tilde { l } _ { m } )$ 描述主动力-长度关系，$\tilde { v } _ { m }$ 为肌纤维收缩速度，$f _ { v } ( \tilde { v } _ { m } )$ 描述力-速度关系，$f _ { p } ( \tilde { l } _ { m } )$ 为被动力-长度关系，φ 为肌纤维羽状角，$d _ { m }$ 为肌肉阻尼参数。

肌腱运动学单元用于利用肌肉骨骼几何模型计算每个 MTU 的力臂和肌腱长度。最后，关节动力学单元通过肌腱力 $F _ { m t }$ 与其力臂 $r _ { m t }$ 的乘积来预测关节力矩。

2) 人工神经网络模型：我们研究了两种用于预测踝关节力矩的 ANN 模型——标准 ANN 和混合 ANN 模型（Fig. 2）。两种 ANN 模型均由一个输入神经层、两个隐藏层和一个输出神经层组成。在输入层中，标准 ANN 模型包含 4 个神经元：来自三块肌肉的实验测量 EMG 数据以及踝关节角度。除这些输入变量外，混合 ANN 还包含了由 NMS 求解器提供的踝关节力矩和三块肌肉的肌力，共计 8 个神经元。每个隐藏层包含 10 个神经元。估计的踝关节力矩在输出层中确定。

## C. 评估方案

在 7 种不同工况下，使用所采集的 7 种不同运动类型和速度对模型进行校准（在 NMS 模型中）或训练（在 ANN 中），研究了 NMS、标准 ANN 和混合 ANN（hybrid-ANN）模型的踝关节力矩预测性能。我们针对每种速度和运动类型分别对每个受试者校准/训练模型，并在相同运动类型的不同速度试验中对其进行测试。换言之，对于行走，模型针对一种行走速度进行训练，然后在所有行走速度下进行测试；对于等速踝关节运动亦是如此。

7 种工况的校准/训练数据为：

• <sup>工况 1（Case 1）：</sup><sup>120</sup> <sup>步/分钟快速行走下的三次试验；</sup>

工况 2（Case 2）：自选行走速度下的三次试验；

工况 3（Case 3）：100 步/分钟慢速行走下的三次试验；

工况 4（Case 4）：$9 0 ^ { \circ } / s ;$ 下的跖屈三次试验；

工况 5（Case 5）：$6 0 ^ { \circ } / s ;$ 下的跖屈三次试验；

工况 6（Case 6）：$9 0 ^ { \circ } / \mathrm { s } ;$ 下的背屈三次试验；

工况 7（Case 7）：$6 0 \%$ 下的背屈三次试验

在 NMS 模型的校准过程中，我们校准了每个 MTU（肌腱单元）的参数，包括最大等长肌力、最佳肌纤维长度、肌腱松弛长度和肌肉激活力学参数。在 ANN 模型的训练过程中，ANN 模型的超参数通过“由粗到精”（coarse-to-fine）的随机搜索确定 [34]。权重采用 Xavier 初始化且偏置初始化为零，批次大小（batch size）设置为 20。包含两个隐藏层，每层 10 个神经元，并采用 tanh 激活函数。采用了 Adam 优化器，学习率为 $1 0 ^ { - 3 }$。最优模型训练了 4000 个周期（epochs），若预测性能在连续 200 个周期内未提升则提前停止（early stop）。

三种模型各自的预测精度计算为测量值（通过逆动力学计算）与估计的踝关节力矩之间的均方根误差（RMSE），并按体重进行了归一化。采用 Wilcoxon 符号秩检验 [35] 来探究通过这三种模型估计的 RMSE 之间的差异（显著性水平 $p < 0 . 0 5$）。

## IV. 讨论

我们使用 NMS 求解器指导的 ANN 模型（NMS solver-informed ANN model）预测了踝关节力矩，该模型是标准 ANN 模型的扩展，纳入了额外的特征，即由 NMS 求解器计算得出的踝关节力矩和肌肉力。因此，我们能够兼取两种模型的优势。总体而言，我们观察到 NMS 求解器指导的 ANN 模型在力矩预测性能上优于 NMS 和标准 ANN 模型，从而证实了我们的假设，即将 NMS 的特征整合到标准 ANN 模型中可以带来性能提升。

肌电驱动的神经肌肉骨骼（NMS）模型和人工神经网络（ANN）模型是关节力矩预测中两种常用的方法 [36], [37]。然而，鲜有研究针对日常活动中关节力矩预测的基于 NMS 和基于 NN 的方法进行对比。在我们前期的工作 [21] 中，我们探讨了它们各自的优势，并发现 NMS 模型在踝关节力矩预测中更为可靠，因为它利用领域知识重现了从 EMG 信号和关节角度到肌腱力及关节力矩的转换过程。相比于 NMS 中复杂的校准流程以及不同变量和参数之间的复杂关系，我们前期研究中的标准 ANN 模型通过在大量试验数据上进行训练，能够以更少的代价更好地预测踝关节力矩。然而，由于 ANN 模型仅学习输入与输出之间的关系，在面对未见动作（unseen movements）时其可靠性会有所下降。在本研究中，混合人工神经网络（hybrid-ANN）模型包含一个步骤：首先采用 NMS 求解器估计单块肌肉力和关节力矩，然后将其用作标准 ANN 模型的额外输入特征。这使得整合这两种模型的优势成为可能，因此，hybrid-ANN 模型能够改进当前的按需辅助（assistance-as-needed）康复外骨骼控制器设计策略。

总体而言，hybrid-ANN 模型的预测比 NMS 模型和标准 ANN 模型都更加可靠和准确，这推测得益于 NMS 模型所获得的额外特征，即本研究中来自 NMS 求解器的各单块肌肉力和关节力矩。在基于肌肉骨骼模型的关节力矩计算中，单块肌肉力是起主导作用的中间参数。此外，NMS 求解器计算出的关节力矩能够提供更多与物理相关的特征来训练 hybrid-ANN 模型。这些特征可以弥补标准 ANN 模型在遇到未见动作时可能变得不可靠的缺陷。例如，在测试的（未见）动作——Case 5 中的 90°/s 跖屈（Fig. 4 底部）过程中，与其他两种模型相比，标准 ANN 预测的力矩与测量值发生了较大偏离。hybrid-ANN 预测的力矩与测量值具有更好的一致性，这主要归功于其结合了 NMS 模型的可靠性以及神经网络的逼近能力。

需要指出的是，我们仅使用了一种 NMS 模型求解器来测试基于求解器信息的 ANN 模型的性能。需要使用其他 NMS 和神经网络模型进行进一步分析，以便能够推广我们的观察结果。另一个局限性在于，仅使用了 SOL、GM 以及 TA 的 EMG 信号和踝关节角度来预测踝关节力矩。其他关节，例如髋关节和膝关节，在日常生活中也起着至关重要的作用。未来，如果在更多运动类型中能够获取更多下肢肌肉的 EMG 信号，我们计划研究提出的 NMS 求解器信息引导 ANN（NMS solver informed-ANN）模型在膝关节和髋关节力矩预测中的性能。

## V. 结论

我们提出了一种基于角度和 EMG 输入预测踝关节力矩的标准 ANN 模型的扩展，即 NMS 求解器信息引导 ANN（NMS solver informed-ANN）模型。这是传统 NMS 模型与现代 ANN 技术的结合模型。该混合 ANN 模型旨在估计七种运动中的踝关节力矩，并分别与使用 EMG 驱动的 NMS 模型和标准 ANN 预测的力矩结果进行了对比。我们发现，NMS 求解器信息引导 ANN 模型比 NMS 和标准 ANN 模型都具有更好的力矩预测性能，这表明将 NMS 模型的特征整合到标准 ANN 模型中具有潜在优势。所提出的混合模型的泛化能力将在未来的工作中进行进一步研究。
