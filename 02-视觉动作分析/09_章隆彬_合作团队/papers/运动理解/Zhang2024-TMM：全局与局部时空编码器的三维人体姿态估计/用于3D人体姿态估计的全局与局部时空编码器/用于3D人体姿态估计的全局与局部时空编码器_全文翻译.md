# 用于3D人体姿态估计的全局与局部时空编码器

Yong Wang , Hongbo Kang , Doudou Wu , Wenming Yang , Senior Member, IEEE, and Longbin Zhang , Member, IEEE

摘要—Transformer 已被应用于3D人体姿态估计并取得了优异的性能；然而，大多数 Transformer 侧重于编码人体所有关节点的全局时空相关性，而对人体每个关节点的局部时空相关性的研究较少。在本文中，我们提出了一种全局与局部时空编码器（Global and Local Spatio-Temporal Encoder，GLSTE）来对时空相关性进行建模。具体而言，分别构建了全局空间编码器（Global Spatial Encoder，GSE）和全局时间编码器（Global Temporal Encoder，GTE），用以捕获单帧中所有关节点的全局空间信息以及所有帧的全局时间信息。构建了局部时空编码器（Local Spatio-Temporal Encoder，LSTE），用以捕获局部 $N$ 帧中每个关节点的空间和时间信息。此外，我们提出了一种具有权重共享的并行注意力模块，以更好地同时将空间和时间信息融合到每个节点中。大量实验表明，在两个极具挑战性的数据集 Human3.6 M 和 MPI-INF-3DHP 上，GLSTE 以更少的参数量和更低的计算开销超越了现有最先进的方法。特别是在 Human3.6 M 数据集的评估中，我们以 27 帧作为输入的方法所取得的结果，优于绝大多数以 81 帧和 243 帧作为输入的近期 SOTA（最先进）方法，这表明该模型能够从更小的输入中学习到更多有用的信息。

关键词—3D人体姿态估计，Transformer，时空编码器，并行注意力。

## I. 引言

单目3D人体姿态估计旨在通过图像或视频估计人体的3D关节点位置。与2D人体姿态估计 [1], [2] 和行人重识别 [3], [4], [5] 等任务类似，这是计算机视觉领域长期存在且极具挑战性的任务。其应用包括人机交互 [6]、动作识别 [7], [8], [9]、增强现实（AR）、虚拟现实（VR） [10] 以及医疗辅助，近年来引起了广泛关注。现有的工作通常分为：1）直接从2D图像或视频帧推断3D人体姿态；2）通过任意现成的2D姿态估计器从单目图像或视频中推断2D姿态，然后通过2D到3D提升流程（2D-to-3D lifting pipeline）从估计的2D姿态推断3D人体姿态。最先进的2D姿态检测器的优异性能使得2D到3D提升方法 [11], [12], [13] 表现更为出色。然而，由于多个3D姿态可能对应几乎相同的2D投影，在这种情况下，关节点位置和外观的哪怕最细微的变化都会影响预测结果。

为了缓解这一问题，相比于从单目图像估计 3D 人体姿态，视频可以提供时间信息以提高 3D 人体姿态估计（3D human pose estimation, 3DHPE）的精度和鲁棒性。最近提出的一些方法 [12], [14], [15], [16] 通过聚合多帧的 2D 姿态序列信息来改进当前（中间）帧的 3D 姿态预测，从而能够获得更准确的 3D 表征并减少从 2D 到 3D 的不确定性。我们的工作便属于此类方法。Transformer [17] 旨在发掘长程依赖关系，并在自然语言处理 [18], [19] 和计算机视觉 [20], [21], [22], [23] 领域取得了巨大的成功。借助 Transformer 的自注意力机制，可以清晰地捕获长输入序列的全局相关性。它是一种特别适用于序列数据问题的架构，也是对 3DHPE 这一基础视觉任务的自然拓展。

本文对 Transformer 在 3DHPE 中的近期工作 [14], [15], [16] 进行了调研。Zheng 等人 [14] 提出的 PoseFormer 利用 Transformer 的自注意力机制来描述每帧中关节点之间的空间依赖关系以及序列中帧之间的时间依赖关系。然而，由于视频中相邻帧的人体姿态具有相似性，整个时间序列中存在大量的冗余信息，并且需要巨大的计算资源。此外，PoseFormer 忽略了局部上下文，但局部信息的利用在计算机视觉任务中至关重要。为了解决上述问题，Li 等人 [15] 提出通过 VTE [17] 对人体所有关节点的长期依赖关系（全局时间相关性）进行建模，然后通过 STE 建模局部时间相关性以逐步缩短序列长度。但他们仅通过单个全连接（fc）层获取空间信息，其表征能力不足。鉴于此，Shan 等人 [16] 提出了 P-STMO，通过 MLP 块来捕获单帧中所有关节点的全局空间信息。同时，它采用时间下采样策略和预训练技术来降低模型的训练难度。由于人体关节点之间相互连接，且躯干的运动会影响其他关节点，因此有必要结合人体的全局运动信息和各个关节点的局部运动信息来对人体姿态进行建模。然而，上述方法将所有关节点聚合在一起并捕获全身的时间上下文，而未考虑每个关节点的运动差异，导致对局部时空相关性的学习不够充分（参见图 1）。为了改善这一点，我们认为对全局和局部时空相关性进行建模更适用于视频中的 2D 到 3D 提升（lifting）任务。

![](images/8a66d00ab2ef6596853118abab8ff0ad3b0257d9ff6abfe550e190022a4118a1.jpg)  
Fig. 1. 局部时空相关性示意图。在骨架序列的时空图中，灰色节点是融合了局部时空信息的人体关节点。时间相关性是指局部帧之间（例如 3 帧）同一关节点的时间信息，空间相关性是指每帧中各关节点之间的空间信息。

受上述启发，在本文中，我们提出了一种新的 3D 姿态估计方法，称为全局与局部时空编码器（Global and Local Spatio-Temporal Encoder，GLSTE），如图 Fig. 2 所示。该模型从单目视频中估计的 2D 姿态序列预测中间帧的 3D 关节点位置。我们采用了与 [16] 相同的两阶段训练方法：1）在预训练阶段，训练全局部分，即全局空间编码器（Global Spatial Encoder，GSE）和全局时间编码器（Global Temporal Encoder，GTE），通过重构随机掩码部分帧和部分 2D 关节点的 2D 姿态来学习 2D 时空相关性和固有的全局特征，从而为模型提供良好的初始化。2）在微调阶段，我们将预训练权重加载到 GSE 和 GTE 中，然后训练整个模型，并在全序列尺度和单目标帧尺度上输出 3D 关节点位置。此外，为了缓解数据冗余问题并扩大时间感受野，两个阶段中作为输入的 2D 姿态均采用了时间下采样策略（temporal downsampling strategy，TDS）[16]。

所提出的 GLSTE 是一种由全局到局部（global-to-local）的架构，通过不同模块分别捕获全局和局部信息。本文中的全局信息是指人体所有关节点在所有帧中的时空相关性。根据 [14]、[16]，我们还利用 GSE 和 GTE 模块按从空间到时间的顺序进行建模。对于 GSE，我们使用简单但有效的全连接残差网络来整合每帧中所有关节点的信息，以模拟全局空间相关性。对于 GTE，我们使用标准的 Transformer 编码器 [17]，将每帧的空间信息作为一个 patch 来模拟全局时间相关性。根据我们的观察，人体各个关节点的运动是不同的，并且同一关节点在局部若干帧中的关系更为明显。因此，本文中的局部信息是指同一关节点在局部 N 帧中的时空相关性。为了更好地捕获局部信息，在 LSTE 中，我们提出了带并行注意力模块的多头时空自注意力（MSA-ST）来模拟局部时空相关性，并设计了时空注意力融合块（STAF）以融合这两种注意力。由于该任务是预测中间帧的 3D 人体姿态，我们设计了一个时间聚合器（TA），通过多层信息学习持续聚合局部信息以获得最终的 3D 姿态。

我们的贡献总结如下：

\- 我们提出的新型由全局到局部的 3D 人体姿态估计架构（命名为 GLSTE），通过对全局和局部时空相关性建模，高效地从 2D 关节点位置推断 3D 姿态。

\- 在我们的 LSTE 中，我们创新性地提出了具有权重共享并行注意力的 MSA-ST 模块来建模局部时空相关性，其中空间和时间注意力通过 STAF 模块进行融合。

与其他方法相比，我们的方法以更少的参数量和更小的计算预算在两个基准数据集上取得了最先进的性能，并且模型能够通过更小的输入学习到更有用的信息。

## II. 相关工作

## A. 3D人体姿态估计

3D 人体姿态估计可分为直接估计方法和 2D 到 3D 提升方法。直接估计方法无需中间估计 2D 人体姿态表示，即可直接从 2D 图像中推断 3D 人体姿态，例如 [24], [25], [26], [27]。2D 到 3D 提升方法首先估计 2D 人体姿态，然后从中间估计的 2D 人体姿态中推断出 3D 人体姿态。得益于 2D 人体姿态估计算法 [1], [2] 的快速发展，第二种方法也带来了更优的性能。Martinez 等人 [11] 提出了一种全连接残差网络来完成 2D 到 3D HPE 任务。一些后续工作 [28], [29], [30] 也尝试从底层 2D 关键点生成准确的 3D 姿态估计。尽管如此，从单张图像生成准确的 3D 姿态仍然是一个病态问题。近期的一些工作 [31], [32], [33] 利用来自视频的时序信息来提高 3D HPE 的准确性和鲁棒性。

![](images/6e62181e1ef4ba9bcca49a0ead646d0dfd0be83583cbd83f026cffc6c9b4219a.jpg)  
Fig. 2. 我们提出的全局与局部时空编码器（GLSTE）概览，输入是经过时序下采样策略（TDS）处理后的 2D 姿态序列，输出是全序列尺度和单目标帧尺度的 3D 关节位置。在微调之前，模型需要加载预训练权重。在我们的模型中，全局特征通过全局空间编码器（GSE）获取所有关节的空间信息，然后通过全局时序编码器（GTE）获取整个帧序列的时序信息。局部特征通过局部时空编码器（LSTE）获取每个关节在局部帧中的时空信息，局部特征由时序聚合器（TA）进行聚合并生成新的局部特征。

Hossain 等人 [34] 提出了一种由带有层归一化的长短期记忆（LSTM）单元组成的 seq-to-seq 网络。Pavllo 等人 [12] 提出了一种基于空洞时序卷积的网络，用于从连续 2D 序列中回归 3D 姿态。Chen 等人 [35] 提出了一种用于预测骨骼方向和骨骼长度的网络，以确保视频中人体解剖结构的时序一致性。Liu 等人 [36] 提出了一种注意力机制，用于自适应地识别每个深度神经网络层的重要帧和张量输出，以获得更好的估计结果。Wang 等人 [33] 提出了一种 U 型图卷积网络（GCN），用于同时捕获短期和长期运动信息。Hu 等人 [37] 进一步提出了一种时空条件有向图卷积，通过将人体骨骼表示为有向图来利用不同姿态的不同非局部依赖性。

这些工作大多基于 LSTM、CNN 和 GCN 等传统神经网络结构。然而，这些方法在捕获长期依赖关系方面仍存在一定局限性。在本文中，我们提出使用具有更好全局相关性的 Transformer 来建模全局时间相关性。此外，我们还改进了 Transformer 的自注意力机制，以更好地捕获局部时空相关性。

## B. 自注意力与 Transformer

近来，Transformer [17] 在各个领域受到了广泛关注。因此，许多方法 [38], [39], [40], [41] 被提出来利用自注意力机制解决视觉任务。开创性工作 Vision Transformer (ViT) [21] 将 Transformer [17] 架构直接应用于图像分类。DeiT [42] 通过采用一种新颖的蒸馏方法进一步扩展了 ViT。DETR [22] 则被提出用于目标检测和全景分割。在 3D 人体姿态估计领域，也有许多基于 Transformer 的工作 [43], [44], [45]。Poseforme [14] 使用纯 ViT 模型来捕获人体关节之间的关系以及整个时间序列中跨帧的全局依赖关系，但它忽略了时间的局部信息。Strided Transformer [15] 将局部时间上下文融入到标准 Transformer 中。在前者的基础上，P-STMO [16] 加强了全局空间信息的建模，并提出了一种时间下采样策略以缓解数据冗余，以及一种两阶段训练方法以降低模型训练难度，这也取得了更好的效果。然而，上述方法将所有关节聚合在一起并捕获全身的时间上下文，而没有考虑每个关节的运动差异。这导致在学习局部时空信息方面存在不足。通过结合我们设计的不同自注意力机制，我们的方法能够同时兼顾人体内部的全局时空关系以及每个关节在多个局部帧内的局部时空关系。由于我们考虑了每个关节的运动，因此能够更全面地捕获信息，并实现更好的性能和泛化能力。

## III. 提出的方法

所提出的 GLSTE 的总览如图 Fig. 2 所示。这是一种具有双通道输入和输出的由全局到局部（global-to-local）架构，并且根据 [16] 的建议，我们采用预训练和微调两个阶段来优化模型。在第一阶段中，GLSTE 模型的全局部分（GSE 和 GTE）通过以自监督方式解决掩码姿态建模任务来进行预训练，其主要目的是从损坏的 2D 姿态中恢复 2D 姿态序列，以学习 2D 时空相关性和内在的全局特征。在第二阶段中，我们通过加载全局部分的预训练权重来微调整个模型。在该阶段中，全局部分首先用于对全局时空信息进行建模，并在全序列尺度上进行监督以强化时间平滑性。随后，局部嵌入模块引导从全局到局部的投影。最后，通过局部部分（LSTE 和 TA）获得中间帧的输出，该部分在单个目标帧尺度上进行监督，以产生更准确的估计。在两个阶段中，经 TDS 进行时间下采样后的 2D 人体姿态坐标均用作输入序列 $\hat { P } \in \overset { \star } { \mathbb { R } } ^ { T \times N \times 2 }$，其中 T 是帧数，N 是每个 2D 姿态的关节点数，2 表示 2D 空间中的关节点坐标 (x,y)。GLSTE 的详细架构如图 Fig. 3 所示。输入序列将依次经过 GSE、GTE、LSTE 和 TA 以获得最终输出。这些模块的细节将在以下各小节中详细描述。

## A. 预备知识

在本节中，我们介绍有关 Transformer [17] 的一些背景知识，包括多头自注意力（multi-head self-attention, MSA）和多层感知机（multi-layer perceptron, MLP）。

MSA：缩放点积注意力（scaled dot-product attention）是 MSA 的单个注意力头。它以注意力分数的形式隐式关联输入补丁（patches）。输入为一个查询矩阵 Q、键矩阵 K 和值矩阵 $V . ~ Q , K , V \in \mathbb { R } ^ { n \times d _ { m } }$，其中 n 是输入补丁的数量，$d _ { m }$ 是每个补丁的维度。缩放点积注意力定义如下：

$$
A t t e n t i o n (Q, K, V) = s o f t m a x \left(\frac {Q K ^ {T}}{\sqrt {d _ {m}}}\right) V\tag{1}
$$

MSA 将查询、键和值分割为多个头，然后对每个头应用缩放点积注意力。MSA 的输出经过拼接和投影以获得最终输出。

MLP：MLP 由两个线性变换以及夹在它们之间的 ReLU 激活函数组成，定义如下：

$$
M L P (x) = R e L U \left(x W _ {1} + b _ {1}\right) W _ {2} + b _ {2}\tag{2}
$$

其中 $W _ { 1 } \in \mathbb { R } ^ { d _ { m } \times d _ { f } } , W _ { 2 } \in \mathbb { R } ^ { d _ { f } \times d _ { m } } , b _ { 1 } \in \mathbb { R } ^ { d _ { f } }$ 以及 $b _ { 2 } \in \mathbb { R } ^ { d _ { m } }$ 为参数矩阵。$d _ { f }$ 是中间层的维度。

## B. 全局空间编码器

GSE（全局空间编码器）的目的是将人体所有关节点的空间信息融合到单帧中，这需要从 2D 姿态中学习足够的空间信息并映射到更高维度。Martinez 等人 [11] 提出使用全连接残差网络来建模单个姿态的空间信息，这也适用于本文中全局空间信息的融合。如图 3(a) 所示，通过独立输入序列中的每个 2D 姿态，可以获得每帧的全局空间信息。同时，GSE 还起到了全局嵌入（Global embedding）的作用。将 2D 姿态序列 P 中每帧所有关节点的 2 维坐标合并作为输入 $\hat { X } \in \mathbb { R } ^ { T \times ( N . 2 ) }$，并通过 GSE 的线性层，将每帧的空间信息嵌入到高维特征 $Z _ { 0 } \in \mathbb { R } ^ { T \times d _ { g } }$ 中，其中 $d _ { g }$ 是全局模块的中间维度，从而获得一组潜在特征作为 GTE 的输入。每一帧的特征都被视为一个单独的 token。

## C. 全局时序编码器

我们通过 GSE 模拟了每帧的全局空间信息，但整个序列的长期时序信息仍然缺失。因此，我们设计了一个全局时序编码器，如图 3(b) 所示。全局时序编码器是一个 Transformer 编码器 [17]，由 M 层组成。在编码器的第一层之前使用可训练的时序位置嵌入 $\mathbf { \bar { \mathcal { E } } } _ { t } ^ { 0 } \in \mathbb { R } ^ { T \times d _ { g } }$，其公式可表示如下：

$$
Z _ {g} ^ {0} = Z _ {0} + E _ {t} ^ {0}\tag{3}
$$

将全局时序编码器应用于输入 $Z _ { g } ^ { 0 } \in$ $\mathbb { R } ^ { T \times d _ { g } }$，以获得输出 $Z _ { g } ^ { \mathcal { M } } \in \mathbb { R } ^ { T \times d _ { g } }$，公式如下：

$$
\hat {Z} _ {g} ^ {m} = M S A (L N (Z _ {g} ^ {m - 1})) + Z _ {g} ^ {m - 1}\tag{4}
$$

$$
Z _ {g} ^ {m} = M L P (L N (\hat {Z} _ {g} ^ {m})) + \hat {Z} _ {g} ^ {m}\tag{5}
$$

其中 $m = 1 , 2 , \ldots , M$，$L N ( \cdot )$ 表示层归一化 [46]。GTE 中的 $M S A$ 如图 4(a) 所示，其注意力图的矩阵尺寸为 $T \times T$。上述公式可以使用函数 $G T E ( \cdot )$ 表示如下：

$$
Z _ {g} ^ {m} = G T E (Z _ {g} ^ {m - 1})\tag{6}
$$

## D. 全局到局部

由于全局部分（GSE 和 GTE）的输出无法直接用于局部部分（LSTE 和 TA），我们提出了一个全局到局部模块（Global-to-Local Block，GLB）来处理全局特征 $Z _ { g } ^ { \mathcal { M } } \in$ $\mathbb { R } ^ { N \times d _ { g } }$。鉴于全局特征是融合了所有节点的特征，而局部特征是单个节点的特征，我们的 GLB 通过投影和切分来实现从全局到局部的操作，其定义如下：

$$
Z _ {g} ^ {\mathcal {M}} \stackrel {{P r o j \& S p l i t}} {{\longrightarrow}} \hat {Z} _ {1} \in \mathbb {R} ^ {N \times T \times d _ {l}}\tag{7}
$$

交换 2D 姿态序列 $P$ 的时空通道以获取局部嵌入的输入 $\boldsymbol { X } \in \mathbb { R } ^ { N \times T \times 2 }$。随后，局部嵌入模块通过线性投影将每个节点的二维特征映射到更高维度 $d$。该过程还通过与 $\hat { Z } _ { 1 }$ 相结合来指导 GLB 从全局到局部的投影，其定义如下：

$$
Z _ {1} = [ \dots ; x _ {i, j} E; \dots ] + \hat {Z} _ {1}\tag{8}
$$

其中 $x _ { i , j }$ 表示 $X$ 的第 $j$ 帧中的第 $i$ 个节点，且 $i = 1 , 2 , \ldots , N , \ j = 1 , 2 , \ldots , T , \ E \in \mathbb { R } ^ { 2 \times d _ { l } }$ 是局部嵌入的参数矩阵。

## E. Local Spatio-Temporal Encoder

根据我们的观察，人体各关节的运动是不同的，局部帧内同一关节的关系更加明显。因此，我们设计了 LSTE（见 Fig. 3(c)）来建模局部帧中每个关节的时空相关性。在 $\mathrm { L S T E }$ 中，我们创新性地提出了一个带有并行注意力模块的 MSA-ST 来模拟局部时空相关性，并设计了一个时空注意力融合块（Spatial and Temporal Attention Fusion block，STAF）来融合这两种注意力。在本节中，$d _ { l }$ 是局部模块（LSTE 和 TA）的中间维度。

多头时空自注意力（Multi-head Spatio-Temporal Self-Attention，MSA-ST）：在 MSA-ST 中，核心是权重共享的级联注意力模块，如 Fig. 4(b) 所示，它包含空间注意力 $( A t t n _ { s } )$ 和时间注意力 $( A t t n _ { t } )$。三个映射的可学习矩阵 $\bar { Q _ { * } } , K , V \in \mathbb { R } ^ { N \times T \times d _ { l } }$ 被这两种注意力共享，但需要进行相应的变换：$Q _ { s } , K _ { s } , V _ { s }$ 通过交换空间和时间维度获得，而 $Q _ { t } , K _ { t } , V _ { t }$ 通过将完整序列 $T$ 分割为局部帧数为 ${ \bar { T } }$ 的 $S$ 个序列获得，具体如下：

$$
\{Q, K, V \} \stackrel {{R e s h a p e}} {{\longrightarrow}} \left\{Q _ {s}, K _ {s}, V _ {s} \right\} \in \mathbb {R} ^ {T \times N \times d _ {l}}\tag{9}
$$

$$
\{Q, K, V \} \stackrel {S p l i t} {\longrightarrow} \{Q _ {t}, K _ {t}, V _ {t} \} \in \mathbb {R} ^ {N \times S \times \bar {T} \times d _ {l}}\tag{10}
$$

空间注意力 $A t t n _ { s }$ 用于模拟单帧中各个关节之间的空间关系，而时间注意力 $A t t n _ { t }$ 用于模拟局部 T<sup>¯</sup> 帧中相同关节之间的时间关系。$A t t n _ { s }$ 和 $A t t n _ { t }$ 的计算如下：

$$
\operatorname{Attn} _ {s} (Q, K, V) = \text { Reshape } (\text { Attention } (Q _ {s}, K _ {s}, V _ {s}))\tag{11}
$$

$$
A t t n _ {t} (Q, K, V) = C o n c a t (A t t e n t i o n (Q _ {t}, K _ {t}, V _ {t}))\tag{12}
$$

其中 Attention(·) 是式 (1) 中的缩放点积注意力（scaled dot-product attention）。Attn<sub>s</sub> 和 Attn<sub>t</sub> 的注意力图矩阵尺寸分别为 $T \times N \times N$ 和 $N \times S \times { \bar { T } } \times { \bar { T } }$。假设 MSA-ST 具有 $h$ 个头，MSA-ST 操作通过简单拼接所有头来实现，具体如下：

![](images/2521c7dec61b63f1a6b4d90e53a6a49c82794147ff7108db74f7eb868e84659d.jpg)  
Fig. 5. 所提出的时空注意力融合（STAF）模块，用于融合空间和时间注意力。

$$
M S A - S T = \mathcal {F} (C o n c a t (A t t n _ {s} ^ {i} (\cdot), C o n c a t (A t t n _ {t} ^ {i} (\cdot))) \cdot W\tag{13}
$$

其中 $i = 1 , 2 , . . . , h$，$W \in \mathbb { R } ^ { d _ { l } \times d _ { l } }$ 是可学习矩阵，$\mathcal F ( \cdot )$ 是式 $( 1 7 )$ 中的融合函数，且 $A t t n _ { s } ^ { i } ( \cdot ) , A t t n _ { t } ^ { i } ( \cdot )$ 分别是 $A t t n _ { s } ( \cdot ) , A t t n _ { t } ( \cdot )$ 的第 $i$ 个头。

时空注意力融合（STAF）：为了更好地整合 $A t t n _ { s }$ 和 $A t t n _ { t }$ 的两个分支信息，我们没有采用简单的求和，而是设计了 STAF 来动态调整空间和时间注意力信息，如 Fig. 5 所示。我们首先在特征通道上拼接 $A t t n _ { s }$ 和 $A t t n _ { t }$，所得维度为 $\mathbb { R } ^ { N \times T \times ( 2 \cdot d _ { l } ) }$ <sup>)</sup>。使用平均池化（Average pooling）和最大池化（Max pooling）操作来压缩输入特征的时间维度。该过程生成了两个维度为 $\mathbb { R } ^ { \mathbf { \lambda } _ { N \times 1 \times ( 2 \cdot d _ { l } ) } ^ { \mathbf { \lambda } _ { N \times 1 } ^ { \star } \times ( 2 \cdot d _ { l } ) } }$ 的特征，并通过相加将平均特征和最大特征结合起来。最后，通过全连接网络和 Sigmoid 操作生成权重 $\alpha _ { s } , \alpha _ { t } \in \overline { { \mathbb { R } ^ { N \times 1 \times \bar { d } _ { l } } } }$。Attn<sub>s</sub> 和 $A t t n _ { t }$ 的融合定义如下：

$$
f _ {c a t} = C o n c a t (A t t n _ {s}, A t t n _ {t})\tag{14}
$$

$$
f _ {a v g + m a x} = F C (A v g P o o l (f _ {c a t}) + M a x P o o l (f _ {c a t}))\tag{15}
$$

$$
\alpha_ {s}, \alpha_ {t} = S p l i t (S i g m o i d (f _ {a v g + m a x}))\tag{16}
$$

$$
\mathcal {F} (A t t n _ {s}, A t t n _ {t}) = \alpha_ {s} \cdot A t t n _ {s} + \alpha_ {t} \cdot A t t n _ {t}\tag{17}
$$

LSTE 的网络结构：LSTE 的输入 $Z _ { 1 }$ 是通过式 (7) 和 (8) 中的全局到局部投影获得的。为了定位 patch 的空间位置，我们添加位置编码以将序列信息注入输入中，即空间位置编码 $E _ { s } \in \mathbb { R } ^ { N \times 1 \times d _ { l } }$。它是一个可训练的序列矩阵，加到输入中，可以表示如下：

$$
Z _ {l} ^ {0} = Z _ {1} + E _ {s}\tag{18}
$$

LSTE 的网络结构如图 3(c) 所示。局部时空编码器和时间聚合器（见 III-F 节）结合以建模局部特征，共由 $\mathcal { N }$ 层组成。由于每一层的时间维度都会改变，因此模型在每一层之前都添加了可训练的时间位置嵌入，第一个时间位置嵌入为 $E _ { t } ^ { 1 } \in \mathbb { R } ^ { 1 \times T \times d _ { l } }$，此后每一层的时间嵌入随着时间维度的改变而改变 T。该过程应用于输入 $Z _ { l } ^ { 0 } \in \mathbb { R } ^ { N \times T \times d _ { l } }$ 以获得输出 $Z _ { l } ^ { \mathcal { N } } \in \mathbb { R } ^ { N \times 1 \times d _ { l } }$，具体如下：

$$
\hat {Z} _ {l} ^ {n} = Z _ {l} ^ {n - 1} + E _ {t} ^ {n}\tag{19}
$$

$$
\hat {Z} _ {l} ^ {n} = M S A - S T (L N (\hat {Z} _ {l} ^ {n})) + \hat {Z} _ {l} ^ {n}\tag{20}
$$

$$
\hat {Z} _ {l} ^ {n} = M L P (L N (\hat {Z} _ {l} ^ {n})) + \hat {Z} _ {l} ^ {n}\tag{21}
$$

$$
Z _ {l} ^ {n} = T A (\hat {Z} _ {l} ^ {n}, \bar {T} _ {n})\tag{22}
$$

其中 $n = 1 , 2 , . . . , \mathcal { N }$，$T A ( \cdot )$ 是时间聚合器，$\bar { T } _ { n }$ 是第 n 层的局部帧数，$E _ { t } ^ { n }$ 表示第 n 层之前的时间位置嵌入。上述公式可以表示如下：

$$
Z _ {l} ^ {n} = T A (L S T E (Z _ {l} ^ {n - 1} + E _ {t} ^ {n}), \bar {T} _ {n})\tag{23}
$$

## F. 时间聚合器 (Temporal Aggregator)

这项工作是从整个序列回归单帧（中间帧）的任务。如果仅对时间序列进行学习而不进行聚合，模型将获得大量冗余信息并增加计算开销。因此，我们提出了一个时间聚合器，以便更好地回归中间帧的 3D 姿态并聚合局部信息。具体而言，我们通过一维卷积分别聚合每个节点的时间信息，输入的时序从 $T$ 变为 $S _ { \ i }$，其中 $T$ 和 S 分别表示当前层的完整序列数量以及当前层划分后的序列数量。上述方法可以表示为一个函数 $T \bar { A ( \cdot , T ) } , \bar { \bar { T } }$ 是当前层划分序列的局部帧数，我们需要将其与 LSTE 结合使用，如 (23) 所示。

## G. 回归头

由于我们使用多帧序列来预测中心帧的 3D 姿态，仅监督单个姿态将会丢失时间平滑性。因此，我们在训练期间通过在 GTE 的输出后添加一个回归头来施加额外的时间平滑性约束，并获得 3D 姿态序列的全序列预测输出 $\hat { Y } \in \breve { \mathbb { R } ^ { T \times N \times 3 } }$。最后，在 LSTE 的输出后添加一个回归头，以获得中间帧 3D 关节点位置的预测输出 $\boldsymbol { Y } \in \mathbb { R } ^ { N \times 3 }$。

## H. 损失函数

由于 GTE 的输出是所有帧的特征信息，我们需要在全序列尺度上进行监督以实现序列上的时间一致性。因此，我们采用序列损失（sequence loss）[15] 来最小化预测值与真实值之间的误差：

$$
\mathcal {L} _ {\text { global }} = \frac {1}{N \cdot T} \sum_ {i = 1} ^ {N} \sum_ {j = 1} ^ {T} \| P _ {i, j} - \hat {Y} _ {i, j} \| _ {2}\tag{24}
$$

其中 $\hat { Y } _ { i , j }$ 和 $P _ { i , j }$ 分别表示在第 j 帧处关节点 i 的估计 3D 位置序列与真实 3D 位置序列。

鉴于 LSTE 对局部帧进行建模，且 TA 聚合时间信息以最终获得中间帧的特征，我们必须监督单个姿态。我们应用标准的每关节点平均位置误差（Mean Per Joint Position Error，MPJPE）损失来最小化预测姿态与真实姿态之间的误差：

$$
\mathcal {L} _ {\text { local }} = \frac {1}{N} \sum_ {i = 1} ^ {N} \| P _ {i} - Y _ {i} \| _ {2}\tag{25}
$$

其中 $Y _ { i }$ 和 $P _ { i }$ 分别是当前姿态中第 i 个关节点的中间帧估计 3D 位置和真实 3D 位置。

网络以端到端的方式进行训练，最终的损失函数 $\mathcal { L }$ 定义为：

$$
\mathcal {L} = \lambda_ {g} \mathcal {L} _ {g l o b a l} + \lambda_ {l} \mathcal {L} _ {l o c a l}\tag{26}
$$

其中 $\lambda _ { g }$ 和 $\lambda _ { l }$ 为权重因子。

## IV. 实验

## A. 数据集和评估协议

我们在两个三维人体姿态估计数据集上评估所提出的模型：Human3.6M [47] 和 MPI-INF-3DHP [48]。

Human3.6 M 是一个广泛用于三维人体姿态估计的数据集。它包含 360 万个视频帧及其对应的三维人体姿态标注。该数据集由 4 个不同视角的摄像机采集的 11 位演员的 15 种不同活动组成。遵循先前方法 [12], [14], [16], [44] 的相同策略，模型在 17 个关节点骨骼上针对 5 个受试者（S1, S5, S6, S7, S8）进行训练，并在 2 个受试者（S9, S11）上进行评估。我们采用最常用的评估指标（MPJPE 和 P-MPJPE）。MPJPE（即协议 1，Protocol 1）用于衡量预测关节点位置与真实标注关节点位置之间在没有任何变换情况下的平均欧氏距离。P-MPJPE（即协议 2，Protocol 2）是使用刚性变换将预测的三维姿态与真实标注对齐后的 MPJPE。

MPI-INF-3DHP 是一个涵盖室内和室外场景的具有挑战性的数据集。它记录了 8 位演员在 14 个摄像机视角下进行的 8 种活动，包含三个场景：绿幕、非绿幕和室外。遵循 [14], [33] 中的设置，我们在实验中报告 MPJPE、150 mm 范围内的正确关键点百分比（PCK，Percentage of Correct Keypoint）以及一系列 PCK 阈值下的曲线下面积（AUC，Area Under Curve）作为评估指标。

## B. 实现细节

我们使用 PyTorch [52] 实现了所提出的方法。训练和测试均在单张 GeForce GTX 3090 GPU 上进行。我们采用预训练 [16] 和微调两个阶段来训练模型。在两个阶段中，我们均使用 Adam 优化器 [53] 训练模型 80 个轮次，初始学习率分别为 1e-4 和 7e-4，每个轮次的衰减因子为 0.97。批次大小设置为 256。我们在训练和测试中采用水平翻转作为数据增强。遵循 [12]，针对 Human3.6 M 使用级联金字塔网络（CPN，cascaded pyramid network）[1]，针对 MPI-INF-3DHP 则使用二维真实标注姿态。

## D. 消融实验

为了验证所提出模型的有效性，我们进行了多项消融实验。消融实验是在 Human3.6 M 数据集上的协议 1 下进行的，我们选择 27 帧作为输入。在实验中我们同时采用了预训练和下采样策略，其中下采样率为 9。

模型组件：如 Table V 所示，我们验证了 GLSTE 模型中不同模块的贡献。仅由 GSE 组成的网络在 MPJPE 下达到 51.8 mm。为了评估 GTE 的效果，我们使用 Transformer 作为骨干网络，得到了 47.0 mm 的结果。在结合 GSE 和 GTE 后，MPJPE 降低至 45.1 mm。然而，在组合了 GSE、GTE 和 LSTE 后，最终的 MPJPE 反而增加到了 47.5 mm。可能的原因是网络学习了大量冗余的时序信息，导致模型无法很好地获取中间帧。因此，我们在每层的 LSTE 之后添加了 TA 模块以获得所提出的 GLSTE 模型，并在 MPJPE 下达到了 43.7 mm，同时我们的计算成本也降低了（FLOPs 从 76.55 降至 70.78）。

我们还评估了全局到局部连接的不同方法。如表中所示，与简单的直接投影方法（GLSTE∗）相比，我们的 GLSTE 可以通过 Local Embedding 模块引导全局到局部的投影来获得更小的 MPJPE，这表明我们的连接方法是有效的。

模型超参数：我们在 Table VI 中探索了多种超参数组合，以寻找最佳的网络架构。$d _ { g }$ 表示全局空间编码器（GSE）和全局时间编码器（GTE）的中间维度，而 d 表示局部时空编码器（LSTE）的中间维度。随着 $d _ { g }$ 的增加，参数量和计算量也呈指数级增加，且 MPJPE 并未取得更好的结果。然而，$d _ { l }$ 的增加对参数量和计算量影响甚微。在我们的模型中，$d _ { g } = 2 5 6$ 和 $d _ { l } = 3 2$ 是最佳的超参数设置，此时参数量和计算成本也相对较低。

LSTE 的不同 MSA 设计（Different MSA Designs of LSTE）：在表 VIII 中，我们进行了实验以验证不同 MSA 设计对所提出模型的影响。在没有时空注意力融合模块（STAF）的情况下，模型的参数量和计算量保持不变，因为空间注意力 $( A t t n _ { s } )$ 和时间注意力 $( A t t n _ { t } )$ 的权重是共享的，即权重的大小不会改变。当多头注意力模块中仅存在空间注意力时，模型的 MPJPE 为 44.0 mm；当仅存在时间注意力时，模型的 MPJPE 为 45.0 mm。这两种策略均已优于 [16] 的结果，证明了这两个模块的有效性。为了获得更好的结果，我们提出了两种融合方法。第一种方法直接对 $A t t n _ { s }$ 和 $A t t n _ { t }$ 的元素进行相加，其 MPJPE 为 44.1 mm，不如仅使用空间注意力的模块。第二种方法使用 STAF 模块进行融合，其 MPJPE 为 43.7 mm，在参数量和计算量略微增加的情况下，比前一种方法提升了 0.4 mm。这是因为 STAF 能够通过时间序列中每个关节点的最大值特征和平均值特征动态调整时空注意力信息。

## V. 结论

在本文中，我们提出了一种用于单目视频 3D 人体姿态估计的全局与局部时空编码器（Global and Local Spatio-Temporal Encoder），该编码器配备了并行注意力模块。实验结果表明，在两个广泛使用的公开 3D 姿态数据集 Human3.6 M 和 MPI-INF-3DHP 上，所提出的编码器能够以更少的参数量和更低的计算开销，更好地捕获人体所有关节的全局时空信息以及不同身体关节的局部时空信息。具体而言，我们的模型在以更少的输入帧数获取更多有用信息的同时，达到了最先进的（state-of the-art）性能。所提出的算法在人机交互和虚拟现实等应用领域具有广阔的前景。
