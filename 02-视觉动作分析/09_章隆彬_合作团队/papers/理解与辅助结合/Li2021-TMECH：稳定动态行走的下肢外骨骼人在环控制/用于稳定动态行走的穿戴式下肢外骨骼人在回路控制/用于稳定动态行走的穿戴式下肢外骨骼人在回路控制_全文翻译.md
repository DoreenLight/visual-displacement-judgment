# 用于稳定动态行走的穿戴式下肢外骨骼人在回路控制

Zhijun Li, Senior Member, IEEE, Kuankuan Zhao, Longbin Zhang, Xinyu Wu, Tao Zhang, Qinjian Li, Xiang Li, and Chun-Yi Su, Senior Member, IEEE

摘要—外骨骼越来越多地用于在军事、工业和医疗应用中辅助人类，从而使个人获得更强的力量和耐力。本文针对具有高自由度（DoFs）的全驱动下肢外骨骼，提出了一种新颖的人在回路（human-in-the-loop）控制框架，允许用户在不使用拐杖或其他外部稳定工具的情况下行走。为了模仿用户自然的下肢运动，控制策略的设计采用了一种新颖的障碍能量函数，其中人机协同操作空间被重新构建为人类自主区域和机器人约束区域。障碍能量函数的变化基于行走外骨骼的质心（COM）与零力矩点（ZMP）之间的距离，从而将用户的下肢运动约束在各种期望轨迹周围的顺应区域内。基于变化的区域函数，所提出的策略旨在控制外骨骼遵循合适的人体工学轨迹。为此，同时考虑人类意图付出与机器人能力的功能，开发了一种自适应控制器，并在人类区域与机器人区域之间实现了平滑的运动过渡。最后，在十自由度行走外骨骼上进行了物理实验，通过受试者进行平地行走、转弯和避障运动，验证了所提出控制框架的稳定性和鲁棒性。

关键词：人在回路（Human-in-the-loop），外骨骼，动态行走

## I. 引言

外骨骼可以为人体运动提供极具前景的支持，特别是在行走、就座、跨越障碍物和爬楼梯等不同场景中增强截瘫患者的能力 [1], [2], [3] 和 [4]。通常，为了实现外骨骼更符合人体工学的能力，预编程的运动模式被设计用于根据用户的指令驱动外骨骼。例如，Ekso Bionics 公司开发了“EksoGT”外骨骼系统，主要设计用于中风和脊髓损伤（SCI）患者在临床环境中的康复和步态训练 [5]。ReWalk 公司也设计了一款能够支持患者行走的下肢外骨骼 [6]。

对于外骨骼的运动规划，已有多种规划算法被深入研究用于生成步态轨迹。Kajita 等人 [7] 和 Vanderborght 等人 [8] 利用线性倒立摆模型（linear inverted pendulum model, LIPM）生成了动态稳定的步态；然而，步行机器人的步态模式在平滑度和效率上不如人类的自然步态。由于在许多下肢外骨骼的机械设计中缺乏髋关节外展/内收运动，维持行走步态的平衡以及转弯步态中的内旋/外旋通常需要额外的支撑设备。为了实现动态平衡，此前开发的大多数外骨骼都必须依赖拐杖等辅助设备 [9], [10], [11]。在文献 [12], [13] 中，作者发现被动行走运动只能保证矢状面平衡，而无法实现侧向平衡。Donelan 等人 [14] 和 Hof 等人 [15] 证明了改变落脚位置和步幅可以在被动行走中产生不同的侧向平衡表现。因此，为了实现自平衡行走，动力外骨骼应引入髋关节外展/内收助力。通过利用髋关节外展/内收以及内旋/外旋运动，可以规划预定义轨迹，从而在无需辅助支撑设备的情况下实现动态活动（例如行走、跨越障碍物、转弯）。传统的高自由度（DoFs）外骨骼通常在髋关节、膝关节和踝关节安装多个执行器，以期为人类的各种运动提供足够的工作空间。然而，此类外骨骼的主要缺点是需要拐杖和手杖等外部辅助设备来在行走过程中保持平衡。Harib 等人 [16] 利用 REX Bionics 下肢外骨骼实现了该功能；然而，它仅支持速度受限在 0.05 m/s 的缓慢静态步态，无法完成多样化的行走任务。因此，在本文中，我们致力于为具有高自由度的全驱动下肢外骨骼设计一种新型控制策略，使用户无需拐杖或其他外部稳定工具即可实现行走。

大多数现有的外骨骼研究仅以预定义轨迹驱动人体运动，传统的位置控制方法已被广泛应用于医疗康复领域。然而，这些传统方法并未考虑用户的个性化需求，可能无法适应不同的任务场景。此外，机器人无法为人类的主动运动提供理想的训练。例如，当人体处于被动状态时，外骨骼往往通过执行动作来降低用户的肌肉活动度和新陈代谢；而当人体主动参与运动时，用户会对抗外骨骼的阻力，并可能导致异常的肌肉活动。Felt 等人 [17] 提出了一种身体在环（body-in-the-loop）策略，并通过在线优化方法估计用户的生理参数。Zhang 等人 [18] 提出了人在回路（human-in-the-loop）框架下的优化方法，根据代谢率调节力矩。Ding 等人 [19] 和 Kim 等人 [20] 在人在回路策略中应用了贝叶斯优化算法，以利用穿戴式机器人降低用户的行走能耗。因此，设计让人参与其中而非依赖预定义轨迹的外骨骼控制算法具有迫切的需求。

人在回路控制允许人类主动参与运动，并能同时为外骨骼提供支撑和引导，从而确保人机系统沿着期望轨迹行走。在人在回路框架内，用户参与到控制回路中并执行共享控制，以驱动机器人完成给定任务；因此，人类并不一定需要与机器人产生物理接触。成功的范例可见于 [21]、[22]。在 [21] 中，开发了一种利用人在回路的助力策略，以适应生物力学变化和用户需求。在 [22] 中，在线评估的用户运动功能和可操作性特性被集成到辅助机器人的混合方法中。这些研究总是试图利用人在回路框架获得自主控制器，从而使人类最终能够脱离该控制回路。然而，对于外骨骼机器人的助力功能，人与机器人都被设想为持续参与任务；在这种情况下，需要构建一个协同的人机耦合系统来执行期望任务，外骨骼接管部分控制并协助人类更轻松、更顺畅地完成给定任务。

生物机电外骨骼设备能够同时解决双足机器人运动与人机交互的经典控制问题，这是一项具有挑战性的课题 [23]。Rifai 等人 [24] 研究了一种用于膝关节外骨骼的有界控制算法，以确保人体膝关节在助力和康复运动中的运动安全。Farris 等人 [25] 为瘫痪患者开发了一种下肢外骨骼，用于评估使用者的下肢运动。Cao 等人 [26] 研究了一种用于康复外骨骼的滑模控制方法，以实现对使用者膝关节角轨迹的顺应性控制。Lee 等人 [27] 开发了一种脑机接口框架，根据使用者的脑电图（EEG）信号高效控制外骨骼向三个不同方向运动 [28]。这些因素（包括非线性、高自由度、工作空间限制以及人机交互中的未知扰动）对控制方法的设计提出了极高的要求。

在本文中，针对一种具有高自由度（DoFs）的全驱动下肢外骨骼，开发了一种人在回路（human-in-the-loop）控制方案，使其能够在不使用拐杖或其他外部稳定工具的情况下实现行走。

本文的主要贡献如下：

(i) 为模仿使用者的自然下肢运动，在控制策略中引入了一种新颖的障碍能量函数，其中人机操作空间被重构为人类自主区域和机器人约束区域。障碍能量函数的变化基于行走外骨骼的质心（COM）与零力矩点（ZMP）之间的距离，从而将使用者的下肢运动约束在围绕各种期望轨迹的顺应区域内，使用者无需拐杖或其他外部稳定工具即可调整行走状态以保持稳定性。

(ii) 考虑到未知的时变因素，将系统中的不确定性表述为动力学模型中的未知参数。为消除未知参数产生的影响，引入了自适应控制方法，可提高外骨骼系统在行走任务中的鲁棒性。

(iii) 此外，人在回路控制方案还可以通过在外骨骼约束区域与人类约束区域之间实现平滑过渡，来平衡人类与外骨骼的能力。

最后，在物理实验中采用了包括平地行走、转弯和避障功能在内的若干案例，以验证所提出控制方法的稳定性和鲁棒性。

## II. 开发的外骨骼系统

## A. 机电一体化设计

在我们具有八个自由度（DoF）的上一代外骨骼中，我们开发了一种机器人外骨骼的人机协同控制方法，用于增强人体爬楼梯能力 [3], [29]。新一代研发的助行外骨骼包含 10 个自由度，其中有 8 个主动自由度和 2 个被动自由度。Table 1 列出了该外骨骼的详细信息。该助行外骨骼的总重量约为 35.4 kg。侧向平面在两个髋关节处具有两个用于内收/外展的主动自由度（右髋翻滚角 Right-Hip Roll 和左髋翻滚角 Left-Hip Roll）；水平面在两个髋关节处配置了两个用于内旋/外旋运动的主动自由度（右髋偏航角 Right-Hip Yaw 和左髋偏航角 Left-Hip Yaw）；矢状面在两个髋关节和膝关节处配置了四个用于屈曲/伸展的主动自由度（右髋俯仰角 Right-Hip Pitch、左髋俯仰角 Left-Hip Pitch、右膝俯仰角 Right-Knee Pitch 和左膝俯仰角 Left-Knee Pitch）。最后，在踝关节处有两个用于背屈/跖屈的被动自由度（左踝俯仰角 Left-Ankle Pitch 和右踝俯仰角 Right-Ankle Pitch），其中拮抗弹簧对安装在踝关节的中立位。

从骨盆到足部，外骨骼的每个关节均对应于人体关节，包括髋关节的内收/外展、髋关节的屈曲/伸展、髋关节的内旋/外旋、膝关节的屈曲/伸展以及踝关节的背屈/跖屈。髋关节的运动可基于以下三个原则进行设计：i）髋关节的运动旋转轴（内收/外展、屈曲/伸展以及内旋/外旋）始终相交于髋关节中心以形成共线；ii）外骨骼与人体在各种运动中均不存在干涉；iii）尽量使总重量最小化。Fig. 1 展示了所研发的外骨骼，受试者通过绑带、足底板、小腿、大腿、骨盆和躯干佩戴该外骨骼。为了适应不同受试者之间的解剖学差异，在机械设计中采用了若干可调节机构，例如大腿和小腿的伸缩结构以及骨盆滑轨。大腿和小腿连杆的长度可针对个性化受试者进行调节，适配身高范围为 150 至 185 cm，骨盆宽度范围为 32 至 42 cm。每个驱动关节均配备一台 Maxon 直流伺服电机（最大转速为 5000 r/min，额定扭矩为 0.46 Nm）以及 160:1 的谐波减速器，从而具备 73.6 Nm 的额定扭矩以驱动负载。

## III. 步态目标与行走轨迹生成

## A. 步态设计目标

由于我们需要考虑用户的运动方向与速度，以及外骨骼的物理约束（例如关节位置、速度和力矩的限制），并保持足部与地面的平稳接触（避免剧烈冲击），同时在无滑动的情况下维持地面接触约束。我们将行走速度设计在 0 至 1.2 m/s 之间，转向行走和跨越障碍物时的轻松步速约为 0.9 m/s。根据我们的实验，若单步时间小于 0.5 s，受试者会感到不适；因此，我们选择 0.7 s 作为单步时间。为了消除摆动相中外骨骼给用户带来的振动，我们将足部的前向和侧向速度降至接近零。在实际实施中，足部的下落速度可调节在 0.3 m/s 至 0.1 m/s 之间。为了保持受试者的直立姿态，我们选择将左右摇摆运动控制在 $2 ^ { \circ }$ 以内，并将前倾角调节在 $2 ^ { \circ }$ 至 $6 ^ { \circ }$ 之间。考虑到受试者的舒适度与安全性，我们将膝关节角度限制在距伸直状态 $5 ^ { \circ }$ 以内，踝关节角度限制在 $\pm 2 3 ^ { \circ }$ 以内。

## B. ZMP 和 COM

我们应用 ZMP 来生成机器人外骨骼的行走和转向轨迹，从而在行走和转向模式下保持下肢外骨骼机器人的稳定性。首先，我们将单质点 COM 模型的 ZMP 表示为 [30]

$$
x _ {p} = x - \frac {z _ {m} - z _ {p}}{\ddot {z} _ {m} + g} \ddot {x} _ {m}, y _ {p} = y - \frac {z _ {m} - z _ {p}}{\ddot {z} _ {m} + g} \ddot {y} _ {m}\tag{1}
$$

其中 ${ \boldsymbol { g } } , X _ { z m p } = [ x _ { p } , y _ { p } , z _ { p } ] ^ { T }$ 和 $X _ { c o m } = [ x _ { m } , y _ { m } , z _ { m } ] ^ { T }$ 分别表示重力加速度、ZMP 位置和 COM 位置。COM 与 ZMP 之间的关系由 ZMP 方程 (1) 描述。COM 轨迹可以基于 ZMP 生成。

当考虑平地上的 ZMP 时，我们可以将平地行走的条件描述为

$$
z _ {m} = z _ {c}, \quad z _ {p} = 0\tag{2}
$$

其中 $z _ { c }$ 是 COM 的固定高度，且 ZMP 定义在地面上。将 (2) 代入 (1)，我们得到平地上的 ZMP 方程

$$
x _ {p} = x - \frac {z _ {c}}{g} \ddot {x} _ {m}, y _ {p} = y - \frac {z _ {c}}{g} \ddot {y} _ {m}\tag{3}
$$

## C. 平地行走轨迹

一个完整的步态周期包括两个单支撑相和两个双支撑相。由于下肢外骨骼步态的周期性，下文仅规划了一个单腿支撑相（SSP）和一个双足支撑相（DSP），其余阶段按照相同规则切换支撑足（如图 Fig. 3(a) 所示）。将 SSP 中 COM 的初始位置记为 $[ x _ { m } ( 0 ) , y _ { m } ( 0 ) ] ^ { T }$，速度记为 $[ v _ { x } ( 0 ) , v _ { y } ( 0 ) ] ^ { T }$ 如下：

$$
{v _ {x} (0)} = {x _ {m} (0) (C - 1) / (T _ {c} S)}\tag{4}
$$

$$
{v _ {y} (0)} = {y _ {m} (0) (C + 1) / (T _ {c} S)}\tag{5}
$$

其中 $\begin{array} { r } { T _ { c } = \sqrt { \frac { z _ { c } } { g } } , C = \cosh ( T _ { s } / T _ { c } ) , S = \sinh ( T _ { s } / T _ { c } ) , T _ { s } = } \end{array}$ $( 1 - r _ { d } ) T _ { s t e p } .$，r<sub>d</sub> 为双支撑期（DSP）的比例，$T _ { s t e p }$ 为步长周期。对于双支撑期（DSP），质心（COM）轨迹可描述为四次多项式

$$
P (t) = \sum_ {i = 0} ^ {4} p _ {i} t ^ {i}\tag{6}
$$

其中 $p _ { i }$ 表示多项式的系数。

冠状面（CP）内的解耦质心（COM）轨迹可描述为

$$
\begin{array}{r c l} x _ {m} ^ {s} (t) & = & x _ {m} ^ {s} (0) \cosh (t / T _ {c}) + T _ {c} \dot {x} _ {m} ^ {s} (0) \\ & & + \sinh (t / T _ {c}) + X _ {m} ^ {s} \end{array}\tag{7}
$$

$$
{x _ {m} ^ {d} (t)} = {\sum_ {i = 0} ^ {4} a _ {i} t ^ {i}}\tag{8}
$$

其中 $x _ { m } ^ { s } ( t )$ 和 $x _ { m } ^ { d } ( t )$ 分别为单支撑期（SSP）和双支撑期（DSP）期间 x 方向上的质心（COM）轨迹；$x _ { m } ^ { s } ( 0 )$ 为单支撑期（SSP）期间 x 方向上的质心初始位置，$X _ { m } ^ { s }$ 为常数。

在矢状面（SP）内，解耦的质心（CoM）轨迹可表示为

$$
\begin{array}{r c l} {y _ {m} ^ {s} (t)} & = & {x _ {m} ^ {s} (0) \cosh (t / T _ {c}) + T _ {c} \dot {y} _ {m} ^ {s} (0)} \\ & & {+ \sinh (t / T _ {c}) + Y _ {m} ^ {s}} \end{array}\tag{9}
$$

$$
{y _ {m} ^ {d} (t)} = {\sum_ {i = 0} ^ {4} b _ {i} t ^ {i}}\tag{10}
$$

$$
z _ {S} (t) = z _ {c}\tag{11}
$$

其中 $y _ { m } ^ { s } ( t )$ 和 $y _ { m } ^ { d } ( t )$ 分别为单支撑期（SSP）和双支撑期（DSP）期间 y 方向上的质心（COM）轨迹，$y _ { m } ^ { s } ( 0 )$ 为单支撑期（SSP）期间 y 方向上的质心初始位置，z<sub>S</sub>(t) 为 z 方向上的质心高度，$z _ { c }$ 和 $Y _ { m } ^ { s }$ 为常数。

## E. 跨越障碍物

## B. 结果与讨论

平地行走的快照如图 Fig. 6 所示，行走速度为 0.8m/s。受试者在行走过程中不允许使用任何支撑辅助设备。实验结果如图 Fig. 7 和 Fig. 8 所示，其中 L-H-P、R-H-P、L-H-R、R-H-R、L-K-R 和 R-K-R 分别表示图 Fig. 1 中所示的左髋俯仰（Left-Hip Pitch）、右髋俯仰（Right-Hip Pitch）、左髋滚转（Left-Hip Row）、右髋滚转（Right-Hip Row）、左膝俯仰（Left-Knee Pitch）和右膝俯仰（Right-Knee Pitch）。蓝色虚线表示人体自主运动区域的边界。一旦误差超过 $r ,$ 机器人便进入主导区域并发挥主导作用，以强制系统误差收敛至人体自主区域内预定义的合理范围。因此，受试者能够主动进行运动，并通过在每一步中调整足部来保持身体平衡。

在越障行走任务中，受试者被要求在有障碍物的环境中连续行走，且不使用任何支撑辅助设备。障碍物的尺寸为 $2 0 . 0 \times 1 5 . 0 \times 1 2 . 0 c m$。由于障碍物尺寸较小，受试者可以跨越它而不是绕行。与平地行走相比，膝关节屈曲和髋关节屈曲的角度有所增加，这有助于受试者抬起腿以跨越障碍物。实验快照如图 Fig. 9 所示。实验结果如图 Fig. 10 和 Fig. 11 所示。图 Fig. 10 中的跟踪误差是有界的，并且由于双足行走是一种周期性运动而表现出一定的周期性，从而达到了我们的设计目标。在图 Fig. 10 中，R-H-R 和 L-H-R 周期性摆动以实现行走平衡。因此，通过我们提出的控制方案，受试者能够主动执行动作，并通过在每一步中调整足部来保持身体平衡，从而在没有支撑设备的情况下实现动态行走。

为了完成外骨骼的转向动作，机器上安装了两个主动关节。它们是右髋偏航（Right-Hip-Yaw，R-H-Y）和左髋偏航（Left-Hip-Yaw，L-H-Y）（如图 Fig. 1 所示）。在行走转向任务中，转向角为 $1 8 ^ { \circ }$。考虑到 R-H-Y 和 L-H-Y 关节需要辅助力矩来实现转向，我们在腰部关节上选择了较窄的人体自主区域。实验视频截图如图 Fig. 12 所示。图 Fig. 13 和图 Fig. 14 给出了实验的位置跟踪和跟踪误差。图 Fig. 15 显示了转向运动中各关节的控制输入。

实验结果表明跟踪误差是有界的。此外，如果跟踪误差超过 $r ,$，外骨骼将进入主导区域并发挥主导作用，从而迅速增加控制输入，使误差快速收敛在合理定义的范围内。由于双足行走是一种周期性运动，输入电流和跟踪误差表现出一定的周期性。当外骨骼处于人类主导区域时，用户将主动引导机器人运动。通过将合理的步态轨迹规划与控制算法相结合，我们实现了人机系统的动态行走模式。为了将我们提出的控制器与传统控制器进行比较，我们还使用传统 PD 控制器进行了并行实验。Fig. 16 展示了传统 PD 控制器与所提出控制器的对比，在步态和跨越障碍物任务中，PD 控制器的控制参数为 $\begin{array} { r l r } { K _ { p } } & { { } = } & { \mathrm { d i a g } [ 1 5 0 . 0 , 1 0 0 . 0 , 1 5 0 . 0 , 1 0 0 . 0 , 8 0 . 0 , 8 0 . 0 ] } \end{array}$ $K _ { d } ~ = ~ \mathrm { d i a g } [ 1 . 0 , 0 . 5 , 1 . 0 , 0 . 5 , 0 . 5 , 0 . 5 ]$。在转弯步态任务中，PD 控制器的控制参数为 $\begin{array} { r l } { K _ { p } } & { { } = } \end{array}$ $\mathrm { d i a g } [ 1 5 0 . 0 , 1 0 0 . 0 , 1 5 0 . 0 , 1 0 0 . 0 , 8 0 . 0 , 8 0 . 0 , 1 2 0 . 0 , 1 2 0 . 0 ]$ ${ K _ { d } } ~ = ~ \mathrm { d i a g } [ 1 . 0 , 0 . 5 , 1 . 0 , 0 . 5 , 0 . 5 , 0 . 5 , 0 . 8 , 0 . 8 ] .$。由于工作空间被划分为人类自主区域和机器人约束区域，所提出的人在回路（human-in-the-loop）控制器的控制输入小于传统控制器。当机器人处于人类主导区域时，受试者可以主动进行运动，从而减少了控制输入。

## VI. 结论

在本文中，针对具有高自由度（DoFs）的全驱动下肢外骨骼，提出了一种基于新型障碍李雅普诺夫函数（Barrier Lyapunov Function）的新颖人机在环控制方案，使人在无需拐杖或其他外部稳定工具的情况下，能够沿着具有生理意义的路径影响下肢运动。通过新型障碍能量函数，人机操作的任务工作空间被划分为人类自主区域和机器人约束区域，从而将用户的下肢运动约束在各种期望轨迹周围的顺应区域内。针对不同场景设计了几种活动轨迹，包括平地行走、转向和越障。在无需拐杖或其他外部稳定工具的情况下，在一台已开发的十自由度下肢外骨骼上对所提出的控制结构的稳定性和鲁棒性进行了广泛的实验验证。实验结果表明，该外骨骼具有在无需拐杖或其他外部稳定手段辅助的情况下协助用户的能力。
