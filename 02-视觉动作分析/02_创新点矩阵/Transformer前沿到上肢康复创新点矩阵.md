## 0. 先说三条约束（比创新点本身更重要）

| # | 约束 | 依据 | 后果 |
|---|---|---|---|
| **MTR-C1** | **代偿识别不是天然的 Transformer 战场** | Gabler et al. 2026（`2604.12591`，ETH Zurich）用**两个 IMU + XGBoost** 取得代偿性躯干运动 macro-F1 0.80；Pavlikov et al. 2026（Sensors, `10.3390/s26165054`）在**无独显笔记本 22–30 fps** 完成上肢代偿检测 | 若我方在 TP-03（肩肘代偿）上主张 Transformer，**必须先证明它优于"强特征+树模型"**，否则该方向应退回传统管线 |
| **MTR-C2** | **跨被试泛化是已知会失败** | Unger et al. 2025（Front Neurol, `10.3389/fmed.2025.1645369`）：个体内 >90%，**跨被试仅约 50–70%**；KIST 团队自 2022 年即采用跨被试划分（本项目 STATUS §3.3） | 跨被试协议是**硬门槛**，不是加分项；所有创新点都必须报告跨被试数字 |

## 1. 候选创新点（按「影响 × 可行性」排序）

### P0-1 · 约束投影解码：把 6 项软惩罚升级为硬保证

| 项 | 内容 |
|---|---|
| **语料证据**【一手】 | PhysPT `2404.04430`（物理感知预训练）、PhysDiff `2212.02500`（把动力学可行性写进扩散**生成过程**） |
| **冲突点** | `03_方法设计/Kinematic_Tokens_与_Grammar.md` §3.3 自述：ROM/FK 是"既有解剖事实，不是 ML 创新"，"创新在于如何组合成可审计的 grammar"——**这是防守性表述**。§4 已记录 KTG-F4（$L_{ROM}$ 与 $L_{angle}$ 对抗）说明软惩罚确实不稳。 |
| **方案** | 训练期维持 6 项软 loss 不变；**推理期追加一步投影**：$\hat\theta \leftarrow \Pi_{\mathcal{F}}(\hat\theta)$，其中 $\mathcal{F} = \{\text{ROM 盒约束}\} \cap \{\text{FK 一致性}\}$。等价于"只允许解码出物理可行的角度序列" |
| **证伪判据** | ① 投影后 ROM violation rate **恒等于 0**；② 投影前后 MAE 差值需在**预登记阈值**内（建议 ≤5% 相对退化）；③ **必须同时报告投影前后两组数字**——只报投影后等于作弊 |
| **审稿人质疑** | "这不就是把输出裁剪到合法区间吗？" → **应答**：是，但裁剪只保证逐帧合法，不保证 **FK 一致**（骨长不被扭曲）与**时序可行**；本方案的约束集是 ROM ∩ FK ∩ 时序速度上限，且与投影算法（交替投影/可行集优化）绑定，可独立审计 |
| **优先级理由** | 直接把最防守的一段论证翻成主动贡献；实现成本低（后处理模块）；消融 A2 已有现成对照 |

### P0-2 · 时间感知 token 粒度：替代固定 256 桶

| 项 | 内容 |
|---|---|
| **语料证据**【一手】 | **T2M = CVPR 2022《Generating Diverse and Natural 3D Human Motions From Text》（已入库）**；T2M-GPT `2301.06052`、MotionGPT `2306.14795`、UDE（CVPR 2023）均已核验。⚠️ 原拟引的 **TATS 检索不到，出处已撤回** |
| **冲突点** | `Kinematic_Tokens_与_Grammar.md` §2.1：**K=256 固定**、U1 均匀网格为**基线且主方案**、分辨率 0.94°；KTG-F1 已预警"高频运动段量化误差被放大"，但对策只提到"提高 K / 残差 VQ"，**未触及"粒度应随时序自适应"** |
| **方案** | 按局部角速度（或帧间角度变化率）动态选择 token 粒度：高速段用细粒度、慢速段用粗粒度。实现上等价于**每自由度、每相位条件化的码本**（可做成条件 VQ，条件量=角速度分档） |
| **证伪判据** | ① 在**变速 + 长时长**子集上，时间感知版 MAE 显著优于固定 256 桶；② 整体 MAE 不劣；③ 码本利用率 > 80% |
| **审稿人质疑** | "这不就是自适应分桶吗？" → **应答**：与动态分桶的区别在于 token 落在**共享码本**上（可跨序列组合、支撑"语言"论述），而分桶是每条序列各自阈值（不可组合）。这个区别必须用**零样本关节组合**实验证明，否则质疑成立 |
| **优先级理由** | 直接回应本项目自述的"最脆弱一环"。⚠️ 但**该条目前无已核验外部出处**（TATS 撤回），必须先在自己的数据上分速度段实测出误差证据，才能立住 |

### P1-3 · 变量维注意力（iTransformer 式）建模 6 个自由度

| 项 | 内容 |
|---|---|
| **语料证据**【一手】 | iTransformer `2310.06625`（把注意力建在变量维而非时间维）；MDPI Machines 2025 `10.3390/machines13100953`（iTransformer-DTL 做 sEMG/IMU 坐立起身解码）**——该文是可学习 query + 非自回归直接解码整段轨迹** |
| **冲突点** | `03_方法设计/Spatio_Temporal_Encoder.md` 采用"分解式时空注意力"（帧内关节关系 + 跨帧动态），本质是 PoseFormer 路线，**没有考虑把注意力主轴换成变量维** |
| **方案** | 保留时空编码器作为基线，新增一路**变量维注意力**分支：把 6 个自由度当作 6 个 token 序列，注意力学"关节间耦合"，与现有"帧间动态"互补 |
| **证伪判据** | 同等 MAE 下参数量/推理延迟显著更低；**且必须在长时序子集上不退化**（若只在短序列有效则价值有限） |
| **竞争风险** | ⚠️ MDPI iTransformer-DTL 已经把 iTransformer 用于 sEMG/IMU 关节轨迹解码，且**明确用非自回归替代自回归**。这**同时**威胁本项目创新点 ①（Seq2Seq 翻译）与 ④（自回归）。**必须在查重中正面处理**：我方差异在于 anatomy-aware 视觉 token 与 6 项 grammar，而不在"用不用 iTransformer"。 |

### P1-4 · 参数高效个体化（LoRA 路线）

| 项 | 内容 |
|---|---|
| **语料证据**【一手】 | LoRA `2106.09685`；Titans `2501.00663`（测试时记忆）；章隆彬团队 JBHI 2025 markerless MoCap 路线亦强调跨被试迁移 |
| **冲突点** | 现有设计**无个体化模块**；而 MTR-C2 表明跨被试泛化本就脆弱 |
| **方案** | 冻结预训练视觉骨干 + 解码器主干，仅用 LoRA 适配 anatomy tokenizer 与 kinematic 码本；逐被试用极少数据（目标 ≤1 分钟）适配 |
| **证伪判据** | 每被试 ≤1 分钟适配数据即可显著降低误差；**且原始权重不被污染**（必须验证，否则等于在线过拟合） |
| **优先级理由** | 康复个体差异是领域公认难题；这是少数"低成本、直接回应临床现实"的创新点 |

### P2-5 · 多模态异构融合：RGB-D + IMU + sEMG

| 项 | 内容 |
|---|---|
| **语料证据**【一手】 | Flamingo（冻结专家 + 交错块注意力）、ImageBind `2305.05665`（跨模态共享嵌入空间）、Daryakenari 2025 `2506.04577`（sEMG+IMU Transformer 预测下肢关节角与力矩） |
| **冲突点** | 现有设计是**纯视觉单模态**；D435i 的 IMU 测的是**相机本体**而非人体（Agent.md §5 明文约束），不能直接当人体惯性数据用 |
| **方案** | **先单模态可用，再逐步融合**：各模态独立编码器 + 交错块 cross-attention；sEMG 通道需另采（章隆彬团队路线），D435i 内置 IMU 只能作为相机姿态参考 |
| **证伪判据** | 单模态子模型各自可用；融合后**至少不比单模态最差者差** |
| **优先级理由** | 视野大但工程量最大，且触碰 D435i 的科学边界；建议作为 MTR-P0/MTR-P1 全部验证后的**第二篇论文**方向，不进第一篇 |

### P2-6 · 硬约束的解法：约束投影 vs 约束生成

> 该项与 P0-1 是同一问题的两种解法，**只选一个**：
> - **投影派**（P0-1）：训练不变，推理后处理 —— 实现简单、可审计，但"承认模型本身会出错"
> - **生成派**（PhysDiff 式）：把可行性写进解码过程 —— 更强，但需要改动 decoder 主体，风险高
>
> **建议第一篇走投影派**，把生成派留给后续。理由：第一篇的核心矛盾是"翻译范式是否成立"，
> 不应同时引入"解码器重构"这一第二个不确定量。

## 2. 优先级与建议推进顺序

| 优先级 | 创新点 | 影响 | 可行性 | 建议 |
|---|---|---|---|---|
| **MTR-P0** | 约束投影解码 | 高（把防守变进攻） | 高（后处理模块） | **第一篇就做**，可独立成实验 |
| **MTR-P0** | 时间感知 token 粒度 | 高（救最脆弱一环） | 中（需改码本） | **第一篇就做**，与既有 A3 消融合并 |
| **MTR-P1** | 变量维注意力 | 中高 | 中 | 视 MTR-P0 结果，作为 encoder 替代方案做对照 |
| **MTR-P1** | LoRA 个体化 | 中高 | 高 | 独立实验，对应 MTR-C2 硬门槛 |
| **MTR-P2** | 多模态融合 | 高 | 低 | **第二篇**，不进第一篇 |
| **MTR-P2** | 约束生成（解码器重构） | 高 | 低 | 后续工作 |

**建议的第一篇范围**：既有 4 创新点 + P0-1 + P0-2。理由：
MTR-P0 两项都**不需要重构主干**，可在现有代码上叠加，且都有"能证伪"的判据；
而 MTR-P1/MTR-P2 都要求改架构，会让"结构性差异清晰可审计"这一卖点被稀释。

## 3. 与既有 4 个创新点的关系（不撤销，只加固）

| 既有创新点 | 本文的处置 | 依据 |
|---|---|---|
| ① Visual–Kinematic Translation | **加固 + 明确威胁源** | 结构出处是 S0（1706.03762），须显式承认；⚠️ 新发现威胁：MDPI iTransformer-DTL（可学习 query + 非自回归）正在削弱"Seq2Seq/自回归"的独占性 |
| ② Anatomy-aware Region Encoding | **维持** | 语料中「anatomy-aware **视觉** token」仍无占位者；HMR 2.0/TokenHMR 是普通 patch，无解剖结构 |

## 5. 本文的证据边界

| 断言 | 证据等级 | 说明 |
|---|---|---|
| 论文存在性、arXiv ID、标题、年份 | **官方一手** | 由 arXiv 官方 API 逐条检索核验（相似度阈值 0.90） |

| 竞品指标（macro-F1、fps、跨被试比例等） | **论文摘要原文自述** | 本项目**未复现**；引用时必须标明"原文自述，未复现" |
