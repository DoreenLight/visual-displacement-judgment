### 1.1 矩阵读出来的三件事

1. **S6 是全链路最拥挤的一格，S9 是最空的一格。** 三条线全部把「估计→辅助」做透了，
   争的是控制律；而「有效主动练习量是否真的增加了」几乎无人把它当**被解释变量**而不是附带记录。
   这与纪律 1 一致：拥挤处不能投，空格处必须先证明不是「没数据只是没人写」。
2. **S4 的缺口不是"没有努力估计"，而是"没有独立参照"。**
   章隆彬线的 NMS+LSTM+GP 与宋嵘线的 TBME 力矩模型都是 `model_torque`——
   **它是模型自己的输出**，不能同时当这个模型的真值。这是 C1 的实质。
3. **S2 整格近乎空白，而它决定了 S4/S6 的结论能不能成立。**
   三条线都默认「多模态时间对齐」成立；一旦缺失或漂移，S4 的努力估计与 S6 的门禁都会静默失效。

## 2. 反例矩阵：谁已经做过「结合」

> 这一节的作用是**主动找反例**。下表每一条都是「我们的候选方向不能宣称新颖」的证据。

| 反例 | 做到哪一步 | 对本文的约束 |
|---|---|---|
| Song_wrist（2013，EMG 连续控制腕康复） | EMG → 辅助/抵抗，**卒中患者真实训练** | 「EMG 驱动上肢康复闭环」已存在，不能当创新 |
| Song_impedance（2022，目标/误差阻抗） | 表现驱动辅助，**明确区分"动作表现"与"主动努力"** | 「用表现调辅助」已存在；候选必须超越表现层 |
| Song_TRO / TBCAS（肌协同 / 臂手导纳） | 上肢 + 肌电 + 反算力标签 | 「肌电+上肢+反算力」已存在（但**反算力 ≠ 独立参照**） |
| TFS2025（神经模糊 + 虚拟肌骨模型 AAN） | 肌骨模型 → 力矩估计 → 可变阻抗，**最近整合反例** | 「加肌骨模型」不是新意；候选必须核其被动性条件与人群 |
| ALP2025（ML + 阻抗，含 isotonic/Brier） | 多模态参与估计 → 执行时间调整 | 「加概率校准」不是新意；isotonic 针对的是**活动类别**，不是活动水平/可靠度 |
| RL2026（个性化自适应辅助 + RL） | 参与/表现/留存三目标联合优化 | 「RL 联合难度」不是新意；须核其 Eq11–12 的符号歧义与代理物理量 |
| Z11（NMS-ML 膝外骨骼）+ Z14（膝辅助策略仿真） | **章隆彬线内已把理解接到辅助** | 「我们的组合同样新」不成立；Z14 是建模仿真，不是患者试验 |
| Z09 / Z10 / Z05（力矩理解、迁移、不确定性） | 明确问「输出能否作为辅助决策输入」 | 力矩输出**已被设想**为决策输入，缺口在可观测性与校准 |
| Z04（ICORR 任务复杂度）+ Z12（随访队列） | 任务复杂度下肌电/摇摆；长期随访 | 「任务复杂度影响参与」与「长期结果」分开，**没有一篇把两者闭环** |
| Song_TMRB 2026 多模型无扰切换解码 / Song_HBMEhybrid | 该团队**最新**的意图解码基线 | 影响「运动理解」段基线选择与查新，必须取全文 |
| 自有语料：Transformer 线 T4/T5、TokenHMR | 姿态 token 化、离散运动 token | 「离散 token 建模运动」在通用人体领域已成熟；**差异化只能在康复闭环的约束上** |

**结论**：把 §2 的每一条反向检查到 §4 的每个候选，**任何候选若只能靠「我们更综合」立论，直接删除**。

| **G2** | 不确定性 → 辅助决策 | GP/ICARM 不确定性（09）、TFS2025 肌骨驱动 AAN、ALP2025 isotonic、JEV 线 D4 | **降级语义**：不可信时是减助力、加阻力，还是交还责任方？安全包络由谁定义 | **C2**：校准与可观测性是否在**匹配覆盖率**下减少错误调整？（一般 confidence gating 已有，须核具体差异） | 变成「加个阈值」；或低分被误当 slacking 而自动增阻 |
| **G3** | 个体化参数 → 上肢任务 | 卒中踝肌个体化（09）、静动态校准（Song_TIE） | 上肢多自由度、共收缩、代偿下的参数可标定性；在线适应成本 | 上肢肌参数在病理后能否可靠标定？标定成本能否落在训练时段内？ | 下肢踝参数不可直接迁移；标定成本吃掉训练强度 |
| **G4** | 辅助控制 → 主动参与/训练强度 | 三线都有闭环（Song 系列、FES、外骨骼） | **把「主动贡献」设为显式目标**而非结果观测；双构念分别验证 | **C3**：在可比训练暴露下，联合反馈能否增加**有效主动练习**而不恶化质量/症状？ | 增加次数但质量下降；设备代做被记成有效练习 |
| **G5** | 即时状态 → 累积训练收益 | 剂量综述、Lang2016 数量≠强度、Z12 随访 | 有效主动重复/剂量的可记录定义；短时负荷能否预测长期收益 | 短时状态变化是否能预测康复收益？预测有效，还是只在健康人成立？ | 相关当因果；过程指标改善被写成疗效 |

**S2 缺口单列**（上表未含）：多模态同步与标定的统一门禁，三线皆弱。
它是 G1/G2 的**前置条件**——若不先立 S2 门禁，G1 的混杂分离与 G2 的覆盖率都不可信。

## 4. 候选方向比较表

> **本表不是新颖性打分，也不是发表价值排名。**「裁定状态」一列中 `候选（未核）` ≠ `可写`。
> 每个候选都必须同时满足三件事才有资格升级：**①无 §2 反例冲突 ②假设可被实验否掉 ③数据条件已具备**。

### D1 · 把「主动贡献」变成闭环的显式被解释变量

| 项 | 内容 |
|---|---|
| **研究问题** | 能否构造一个**不依赖被测模型**的主动贡献参照，并用它驱动辅助决策，使训练块内的有效主动练习量上升而不恶化运动质量？ |
| **填补的缺口** | G1 + G4（部分 C1/C3） |
| **最近已有工作** | Z11 NMS-ML 膝外骨骼；Z04 ICORR 任务复杂度；TFS2025 肌骨驱动 AAN；Song 系列 EMG 辅助 |
| **差异在哪** | 上述工作以**力矩/EMG 为输入、以运动表现为结果**；无人把「独立参照下的主动贡献量」同时作为**决策依据**和**主要终点**。差异是**参照的独立性**，不是模型精度 |
| **可证伪假设** | 若独立参照下的主动贡献量与模型估计无显著差异（或差异不随辅助量变化），则「模型力矩可当主动贡献」成立，G1 不构成缺口 → **本候选作废** |
| **评价指标** | 物理：独立参照下的主动贡献覆盖率、有效参与时长占比、辅助代做率；质量：任务分层 QOM/代偿；心理：独立分量表（**不合成总分**）；安全：症状事件与漏报 |
| **所需数据/条件** | 机器人交互力或等效力学参照 + sEMG + 视觉 + 患者授权；**双参与参照**；可比训练暴露 |
| **失败风险** | 高。找不到不依赖模型的独立参照 → 整个方向退回「自证」；下肢→上肢迁移失效 |
| **裁定状态** | **候选（未核）**。解锁条件：12_ P0-3（TBME HD-sEMG 力矩）全文核「预测力矩≠主动贡献」的边界 |

### D2 · 校准后的「不知道」作为一等公民参与决策

| 项 | 内容 |
|---|---|
| **研究问题** | 当努力估计不可观测或超出校准域时，把决策降级为**责任方接管/观察**而非默认加力，是否降低错误调整且不损失有效训练？ |
| **填补的缺口** | G2（部分 C2）+ S2 |
| **最近已有工作** | TFS2025 肌骨模型驱动 AAN；ALP2025 isotonic+Brier；JEV 线 D4；通用 confidence gating |
| **差异在哪** | 通用 gating 只处理「置信度低→不动作」；本候选处理**校准域外**与**参照类型错配**（用 `emg_proxy` 的校准去许可 `model_torque` 的决策），并规定降级后的**责任归属** |
| **可证伪假设** | 若「降级观察」与「保持原增益」在错误调整率与有效训练量上无差异，则降级语义无价值 → **本候选作废** |
| **评价指标** | 风险—覆盖率曲线（**不以平均预测误差为唯一指标**）；错误调整率；有效练习量损失；越权请求次数 |
| **所需数据/条件** | 离线回放 + 可比训练暴露；校准域标注；负样本集（缺失/漂移/OOD/疼痛） |
| **失败风险** | 中。可做但**必须先有 C1 的参照**，否则「降级」无从判断对错 |
| **裁定状态** | **候选（未核）**。解锁条件：12_ P1-3（GMM 上肢自适应增量）全文，核「重标定触发条件」的真实定义 |

### D3 · 上肢多自由度下的共收缩与代偿混杂分离

| 项 | 内容 |
|---|---|
| **研究问题** | 在上肢多关节任务中，能否把「主动贡献」与「共收缩/代偿造成的表面力矩上升」分离，并给出可核的分离判据？ |
| **填补的缺口** | G1 + G3（部分 C1） |
| **最近已有工作** | 上肢代偿检测综述（自有语料 B3/Wang2022）、疲劳诱发代偿（Mei2026）、NMS 模型（09）、肌间耦合系列（12 题录 N14/N15/N16） |
| **差异在哪** | 现有代偿研究用**运动学**判代偿，现有 NMS 用**单块肌肉**建模；把两者放在一起做**混杂分离**的工作在上肢尚缺 |
| **可证伪假设** | 若共收缩与主动贡献在肌电+运动学联合特征上不可分（如分离 AUC 不显著优于单模态），则该候选不成立 |
| **评价指标** | 分离后的贡献估计误差；与独立参照的区间覆盖；跨患者/跨任务一致性 |
| **所需数据/条件** | 多通道 sEMG（含协同肌对）+ 视觉 + 独立力学参照；共收缩条件设计 |
| **失败风险** | 中高。肌间耦合系列全是**题录级**，须先核其是否已含共收缩分离 |
| **裁定状态** | **候选（未核）**。解锁条件：12_ P3 的 N14/N15/N16 全文（肌间耦合） |

### D4 · 有效主动练习量的可记录定义与剂量口径

| 项 | 内容 |
|---|---|
| **研究问题** | 在机器人/电刺激辅助下，「有效主动重复/有效主动时长」应如何定义与记录，使其在跨设备、跨辅助策略间可比？ |
| **填补的缺口** | G5 + S9（部分 C3） |
| **最近已有工作** | 剂量综述（PMC12989500）；Lang2016（数量≠强度）；Psy2022（精度/平滑 vs 速度/偏好）；Z04/Z12 |
| **差异在哪** | 现有剂量文献以**次数与时长**为主；缺一个在**辅助存在**时仍成立的「有效主动练习」分母定义。这是**测量学**问题，不是算法问题 |
| **可证伪假设** | 若该定义在不同辅助策略下给出的「有效练习量」排序与独立参照给出的排序一致（即定义不敏感），则它没有价值 → 作废；反之若排序随辅助策略翻转，即证明现有剂量口径失效 |
| **评价指标** | 定义与独立参照的排序一致性（Kendall τ）；跨策略稳健性；分母可重复性 |
| **所需数据/条件** | 有真实辅助暴露与交互力记录的训练块；**不需新算法**，故最易启动 |
| **失败风险** | 低（工程量小），但**发表价值取决于它是否揭示了实质结论**，不能停在口径论文 |
| **裁定状态** | **候选（未核）**。解锁条件：12_ P0-1（自适应 FES 强度调整，10 例卒中 + 对照）全文——它是**目前唯一**同时具备「患者 / 真实辅助 / 强度自适应」的题录 |

### D5 · 跨团队方法的迁移边界（方法论贡献）

| 项 | 内容 |
|---|---|
| **研究问题** | 章隆彬线的下肢 EMG→NMS→力矩方法，在上肢任务中哪些部分可迁移、哪些参数必须重标？迁移失效能否被**事先预测**？ |
| **填补的缺口** | G3 + G5 |
| **最近已有工作** | Z10 TNSRE 迁移学习下肢力矩；Z02 JBHI 踝力矩迁移；Song_TIE 静动态校准 |
| **差异在哪** | 迁移学习本身已有；缺的是**可事先预测的迁移失效判据**（在无患者数据时就能判断该不该迁移） |
| **可证伪假设** | 若迁移失效无法由病程/任务/参数可观测量预测（预测器不优于随机），则该候选作废 |
| **评价指标** | 预测失效的 AUROC；迁移前后误差差；所需标定样本量 |
| **所需数据/条件** | 至少含下肢+上肢的双部位对照数据；这是**当前最缺的数据形态** |
| **失败风险** | 高。数据要求高，且是方法论贡献，与「提高主动参与度」的目标距离最远 |
| **裁定状态** | **候选（未核，优先级最低）** |
