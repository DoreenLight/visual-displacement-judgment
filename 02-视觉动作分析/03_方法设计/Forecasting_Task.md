# 05 · Forecasting Task（因果未来运动学翻译）

> **所属**：ViKiT 组件 ⑥（可选加分项 4，见 `../02_创新点矩阵/ViKiT_方法概览.md` §1）
> **上游**：`Cross_Modal_Decoder.md`
> **一致性基准**：`ViKiT_方法概览.md` §1「可选加分项 4：Causal Future Kinematic Translation」
> **本文档定位**：Phase 2 方法设计的**实质设计文档**，含结构 / 超参 / 选型依据 / 失败模式

---

## 1. 任务定义

$$\text{Visual}_{t-k:t} \longrightarrow \text{Kinematics}_{t:t+h}$$

| 符号 | 含义 | 取值 |
|---|---|---|
| $k$ | 观测窗口（过去） | 与 `Spatio_Temporal_Encoder.md` 的 $T$ 相同（**81 帧** ≈ 2.7 s @30fps） |
| $h$ | 预测视界（未来） | **100 / 200 / 300 ms** → **3 / 6 / 9 帧** @30fps |

**两个子任务**（必须分开报告，不可混淆）：

| 子任务 | 定义 | 难度 |
|---|---|---|
| **F-Sync · 同步翻译** | $\text{Visual}_{t-k:t} \to \text{Kinematics}_{t-k:t}$ | 低（主任务） |
| **F-Fore · 因果预测** | $\text{Visual}_{t-k:t} \to \text{Kinematics}_{t:t+h}$ | **高** |

> **"Causal" 的含义**：预测 $t+h$ 时刻的运动学，**只能使用 $t$ 及之前的视觉信息**。
> 这是**严格的因果约束**，必须用单元测试保证（见 §6 交付物 4）。

---

## 2. ⚠️ 诚实定位：300 ms 不是我方首创

**这是本文档最重要的一节。** 必须明确：

| 事实 | 来源 |
|---|---|
| **Wei 2026 JBHI（种子论文）已在 sEMG 域实现 300 ms 提前预测且不牺牲精度** | 官方摘要原文：*"can predict joint angles up to **300 ms in advance without compromising accuracy**, which is critical for real-time AAN control"* |
| 其动机是**康复机器人 AAN 控制** | 同上 |

> 🔴 **因此**：
> 1. **300 ms 这个数字本身不是我方的创新**，是**移植对标**。
> 2. 我方若声称"首次实现 300 ms 预测"会被直接击穿（`README.md` 也已把"避免换名字"列为核心风险）。
> 3. **我方的正当主张**只能是：**把 300 ms 预测的范式从 sEMG 域迁移到纯视觉域**，
>    并**证明视觉域的信息带宽是否足够支撑同样的视界**（见 §3 的可行性约束）。

---

## 3. 可行性约束：为什么视觉域的 $h=300$ ms 可能做不到

### 3.1 信息带宽的根本差异

| 模态 | 采样 | 信息性质 | 对预测的价值 |
|---|---|---|---|
| **sEMG** | 1–2 kHz，多通道 | **直接测肌肉激活（运动的原因）** | ✅ 高——接近"意图"层 |
| **RGB 视频** | 30 fps | **观测运动的结果** | ⚠️ 低——是结果而非原因 |

> **sEMG 观测的是"因果链的上游"，RGB 观测的是"因果链的下游"。**
> 因此，**相同视界下，视觉的可预测性上限低于 sEMG**——这是物理事实，不是工程调优能弥补的。

### 3.2 由此产生的方法论要求

| # | 要求 | 理由 |
|---|---|---|
| 1 | **必须报告"预测精度 vs 视界"的衰减曲线**，而非只报单点 | 证明趋势合理，而非挑选最好看的 $h$ |
| 2 | **必须设一个"物理上限参照"** | 例如：用**真值过去**预测未来的精度（oracle baseline），界定任务的可达上限 |
| 3 | **必须明确报告 $h=300$ 是否达成** | 若未达成，如实报告最大可达视界（如 200 ms）——**诚实报告比强行凑数更可能通过审稿** |
| 4 | **在讨论中显式写入 threat to validity** | 说明 RGB vs sEMG 的信息带宽差异（见 `../../04_实验设计/对比方案.md`） |

> **这一节本身就是一个可发表的方法论贡献**：指出"300 ms 可达"是**模态依赖的**，
> 不能跨模态直接迁移——这比声称"我们也做到了 300 ms"更有学术价值。

## 4. 两种实现路径

### 4.1 路径 F1 · 统一解码（**主方案**）

把同步与预测**合并为一个任务**：让 decoder 输出长度为 $k+h$ 的运动学序列，
但**前 $k$ 帧监督用真值、后 $h$ 帧监督用未来真值**。

```
Visual_{t-k:t}  ──►  Encoder  ──►  Decoder  ──►  Kinematics_{t-k : t+h}
                                                    ├─ 前 k 帧：同步翻译（有真值监督）
                                                    └─ 后 h 帧：因果预测（有真值监督）
```

| 优点 | 缺点 |
|---|---|
| 单一模型，参数共享 | 同步与预测的难度不同，可能互相牵制 |
| 同步任务充当**辅助监督**，有利于表征学习 | 需要处理"预测部分梯度过强"的问题 |
| 只需一次训练 | — |

> **这是主方案**，因为它符合"一个模型翻译一整段语言"的叙事，
> 且同步任务提供的密集监督对预测任务有益。

### 4.2 路径 F2 · 独立预测头（对照）

同步用主模型，预测用**独立 head**（或多任务学习的两个 head）。

| 优点 | 缺点 |
|---|---|
| 两个任务互不干扰 | 参数更多；预测头数据量要求高 |
| 易于分别调参 | 失去共享表征的收益 |

**用途**：消融对照，回答"共享表征是否有助于预测"。

### 4.3 路径 F3 · 自回归展开（仅在 P2 解码器下）

用 `Cross_Modal_Decoder.md` 的 P2（自回归）**递归生成未来帧**：
预测 $t+1$ → 把预测值喂回作为输入 → 预测 $t+2$ ……

| 优点 | 缺点 |
|---|---|
| 视界可任意延长 | **误差累积**严重 |
| 与语言模型生成完全同构 | 需要对预测部分做专门的 exposure 调度 |

**用途**：仅在 F1 的短视界表现良好、需要验证"能否进一步外推"时启用。

## 5. 超参汇总

| 超参 | 基线值 | 搜索范围 | 说明 |
|---|---|---|---|
| 观测窗口 $k$ | **81**（2.7 s） | 27 / 45 / 81 / 121 | 与 encoder 的 $T$ 绑定 |
| **预测视界 $h$** | **300 ms（9 帧）** | 100 / 200 / 300 ms | 主报告 300，但必须有 100/200 曲线 |
| 实现路径 | **F1（统一解码）** | F1 / F2 / F3 | F2 作消融 |
| 预测部分的损失权重 | **0.5** | 0.1–1.0 | 防止预测部分主导梯度 |
| 预测部分的损失类型 | 与同步相同（含 grammar） | — | **grammar 在预测段同样生效**（这是差异化点） |
| 预测段是否用 autoregressive | ❌（F1 下并行） | 是 / 否 | 与 decoder 方案绑定 |

### 5.1 一个必须明确的细节：预测段的 grammar 约束

$$L_{\text{forecast}} = L_{\text{angle}}^{(t:t+h)} + \lambda_1 L_{\text{vel}}^{(t:t+h)} + \lambda_3 L_{\text{ROM}}^{(t:t+h)} + \lambda_4 L_{\text{FK}}^{(t:t+h)}$$

**含义**：预测出的未来运动学**同样必须满足生物力学约束**——
不能出现关节瞬移、ROM 越界或骨长失真。

> 💡 **这可能是本项目最有价值的差异点**：
> 竞品（Chao 2026 / KIST 系列）**都没有 forecasting 能力**，
> 更不用说"预测段的物理合法性约束"。
> **"预测的未来也必须物理合法"是一个新的、未被占据的问题设定。**

## 6. 评估协议

### 6.1 指标

| 指标 | 定义 | 说明 |
|---|---|---|
| **MAE°@h** | 仅在未来段 $[t, t+h]$ 上计算的角度 MAE | 主指标 |
| **RMSE°@h** | 同上 | — |
| **$\Delta$MAE = MAE@h − MAE@sync** | 预测相对同步的**退化量** | **核心指标**：退化越小越好 |
| **Jerk@h** | 未来段的时序抖动 | 检验预测是否平滑 |
| **ROM violation@h** | 未来段越界率 | 检验物理合法性 |
| **随机基线** | 用 $t$ 时刻姿态**保持不变**（persistence）作为未来预测 | **必备下限** |
| **Oracle 上限** | 用**真值过去**预测未来 | 界定任务可达上限 |

> ⚠️ **Persistence baseline 是必需项**：若不报告它，审稿人会怀疑"你的预测模型是否只是学会了保持不动"。
> **上肢代偿的慢速动作尤其容易被 persistence 基线追平**——必须正视。

### 6.2 分视界报告模板

| $h$ | MAE° | RMSE° | $\Delta$MAE vs sync | Jerk | ROM viol. | Persistence MAE° | Oracle MAE° |
|---|---|---|---|---|---|---|---|
| 100 ms | | | | | | | |
| 200 ms | | | | | | | |
| 300 ms | | | | | | | |

> **报告要求**：三个视界必须**全部**报告，即使 300 ms 表现差也必须写出来。
> **禁止**只报告最好的视界。

### 6.3 数据划分的额外要求

预测任务对**数据泄漏**极其敏感：

| 要求 | 理由 |
|---|---|
| **严格按时间切分测试段** | 预测段不得与训练段在时间上重叠 |
| **按被试划分** | 与主任务一致（KIST 从 2022 年起即采用按受试者划分） |
| **禁止在同一动作片段内同时取训练与测试窗口** | 否则相邻帧的相似性会虚高预测精度 |

> ⚠️ **这是预测任务最常见的作弊方式**：同一段连续视频里随机切窗口 → 训练窗口与测试窗口相邻 →
> 模型只需"记忆邻帧"就能拿到高分。**必须在协议中显式禁止并留证。**

## 7. 失败模式与对策

| # | 失败模式 | 症状 | 根因 | 对策 |
|---|---|---|---|---|
| **F1** | **预测段精度崩塌** | $h=300$ 的 MAE 是同步的 3–5 倍 | 视觉信息不足以支撑 300 ms | ① **降级为 200/100 ms 并如实报告**；② 见 §3 的 threat to validity 论证 |
| **F2** | **被 persistence 基线追平** | 预测模型 ≈ "保持不动" | 动作太慢 / 视界太短 | ① 报告 persistence 基线并说明差异；② 在**快速动作段**单独评估；③ 选更难的视界 |
| **F3** | **数据泄漏导致虚高** | 验证指标异常好 | 训练/测试窗口相邻 | §6.3 的协议 + 单元测试断言窗口不重叠 |
| **F4** | **误差累积（F3 路径）** | 自回归几步后崩坏 | 预测值回灌的分布漂移 | ① 用 scheduled sampling 训练；② 限制自回归步数；③ 优先用 F1 |
| **F5** | **预测段主导梯度** | 同步任务精度下降 | 预测损失量级更大（误差大） | ① 预测损失权重 0.5；② 按部分归一化损失；③ 分阶段训练（先同步后预测） |
| **F6** | **grammar 在预测段引发不稳定** | 训练震荡 | 预测值偏差大时 ROM/FK 惩罚剧烈 | ① 预测段先只开 $L_{\text{angle}}$，后加入 grammar；② 梯度裁剪 |
| **F7** | **300 ms 与 30 fps 的帧数不整** | 实现困惑 | 300 ms @30fps = 9 帧（整除）；但若帧率不是 30 则非整 | 显式声明帧率，并将其作为超参记录 |

## 8. 交付与验收

| # | 交付物 | 验收标准 |
|---|---|---|
| 1 | F1 统一解码实现 | 一次前向输出 $k+h$ 长度序列 |
| 2 | 三视界完整报告 | 100/200/300 ms 全部有数据，**含 persistence 与 oracle 基线** |
| 3 | 衰减曲线 | MAE° vs $h$ 的曲线（至少 6 个 $h$ 值） |
| 4 | **因果性单元测试** | 断言：修改 $t'>t$ 的输入不影响 $t+h$ 的输出；无未来信息泄漏 |
| 5 | **反数据泄漏测试** | 断言：训练窗口与测试窗口无重叠；重叠时测试应失败 |
| 6 | 预测段物理合法性报告 | ROM violation@h 与 FK 一致性@h |
| 7 | F2 消融 | 共享表征 vs 独立 head 的对比 |

## 9. 风险登记

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| **R1** | **视觉域根本做不到 300 ms** | 加分项失效 | **已预先规划**：如实报告最大可达视界，并把"视觉 vs sEMG 的信息带宽差异"本身写成方法论贡献（§3） |
| **R2** | 被指为"300 ms 是 Wei 2026 做过的" | novelty 被削弱 | 已在 §2 **主动承认**；主张锚定在**视觉域迁移 + 模态可达性分析** |
| **R3** | persistence 基线追平 | 预测任务无意义 | 在快速动作段单独评估；或改用更长视界 |
| **R4** | 预测任务分散精力，拖累主任务 | 主任务（同步翻译）质量下降 | **Forecasting 是"可选加分项"**——若资源紧张，**优先保主任务**，forecasting 降级为"未来工作" |
| **R5** | 数据泄漏未被发现 | 结论不可信 | §6.3 协议 + §8 交付物 5 的自动化测试 |
