## 一、发现这条路的过程：一次误判逼出来的

2026-10-02，`缺口台账.md` 的 **V9g** 被判为「**须人工取件**」。当时的理由有两条，
**两条都是对的，但都不是结论**：

| 试过的 | 结果 | 判断 |
|---|---|---|
| Europe PMC 的 JATS 全文 XML | **确实不含** supplementary | ✅ 对 |
| `preprints.jmir.org` 直连 | **HTTP 202 空响应**（反爬） | ✅ 对 |
| **Europe PMC 的独立补充材料接口** | 🚨 **根本没试** | ❌ **漏了** |

真正的通路是**独立于全文接口**的另一条：

```bash
curl -sS -L -o epmc_supp.zip \
  "https://www.ebi.ac.uk/europepmc/webservices/rest/PMC13293569/supplementaryFiles"
# → HTTP 200 / application-zip / 805,093 bytes    无反爬、无需订阅、无 cookie
```

**同期另一条官方通道**（结论不同，**两条都要记**）：

```bash
curl -sS "https://www.ncbi.nlm.nih.gov/pmc/utils/oa/oa.fcgi?id=PMC13293569"
# → HTTP 404（不是反爬）
```

📌 **可复用的教训**：「某条通路走不通」和「这条路不存在」是两件事。
**把一个接口的失败当成通路不存在，就会把可取的东西登记成「须人工取件」，并让它一直挂着。**
本项目这条 V9g 挂了整整一轮，**而它从头到尾都是公开可取的**。

## 二、🚨🚨 最重要的实测教训：**HTTP 200 ≠ 有补充材料**

接口名叫 `supplementaryFiles`，但它对**每一个** PMCID 都返回 `HTTP 200 + zip`
—— 包括**根本没有补充材料**的条目。因为它把文章的**配图**和**公式图**一并打包了。

**语料三全库实测（13 个 PMCID）**：

| 指标 | 数值 | 说明 |
|---|---|---|
| 接口返回 `HTTP 200 + zip` | **13 / 13** | 🚨 **这个数毫无区分度** |
| 其中**真补充件** ≥1 件 | **5 / 12**（12 个已落盘的 PMCID） | ✅ **这个才是准数** |
| 只有正文插图、无补充件 | **7 / 12** | |

**判据（按文件名，不看 HTTP 状态）**：

| 类别 | 文件名特征 | 例子 |
|---|---|---|
| ✅ **真补充件** | `-s00N.` / `MOESM*` / `*_ESM.` / `Data_Sheet*` / `Table_*.DOCX` | `rehab-v13-e87339-s002.pdf` |
| ❌ **正文插图**（XML 里已有，不必重复存） | `-g00N.` / `*_FigN_HTML.` / `*_Article_[IE]EqN.` | `sensors-24-03686-g002.gif` |

`fetch_epmc_supp.py` 已实现这个分类（`classify()`），并在落盘时生成
**分好类的 `_清单.txt`**，让人**不逐个打开**也能确认拿到的是不是要的东西。

## 三、🚨 取件时最容易踩的第二个坑：**文件名编号 ≠ 表号编号**

Pohl 那篇正文引用的「补充表 **S2** / **S3**」，**全部在 `s002.pdf` 这一份文件里**；
打开会看到表号从 **S1** 开始。

> 📌 **这很可能就是上一轮判「取不到」的真实原因** ——
> 按「文件名 = 表号」的直觉去找，看到不对就以为不是这份材料。
> → **取件后必须逐份打开核对表号，不要按文件名推断。**

## 五、🚨 为什么不入语料三

语料三的口径是**论文条目**（当前 **106 篇（A 77 / B 29）/ 全文 52 = PDF 40 + XML 12 / 定位卡 106**）。
补充材料是**已入库论文的附件**，不是独立论文条目。把它们塞进去会同时踩三个坑：

1. **K8（定位卡绕过链路直接落盘）** —— 手工为补充 PDF 造 `_Abstract_Card.md` 正是这个错；
2. **自检 Case 7** 要求语料三每个 PDF 都有 `_Abstract_Card.md` 孪生，**不造就 FAIL**；
3. **自检 Case 6.5** 会拿 `bm_pdf` 计数块和磁盘复算对账，**多出 PDF 而索引里没有 → FAIL**。

✅ **所以**：原始件存这里（`06_附录/补充材料/`），
**知识另行提炼进 `00_研究背景/`**，**语料三的条目口径一个字都不动**。
