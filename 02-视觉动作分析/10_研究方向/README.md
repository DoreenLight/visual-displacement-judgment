现行候选入口是[主动参与与训练强度_候选方向总表](../02_创新点矩阵/主动参与与训练强度_候选方向总表.md)：K01–K16 共 16 项条件性候选，当前 **0 条定案方向**。候选总表包含 S0–S10 覆盖摘要、代表论文、可证伪假设、数据条件、风险和去重关系；不把 16 项解释成 16 篇彼此独立的论文。下方 R1–R5 仅作既有研究方向历史视图，不替代现行候选池。

## 文献要覆盖什么

- **运动理解**：判断患者在做什么、想做什么、做得怎样。意图、动作表现、代偿与主动努力的测量应分别记录，不能把角度估计准确直接当成主动参与度高。
- **康复辅助**：何时、如何、提供多少辅助，以及如何调整训练要求。辅助方式和控制策略需按具体论文归类，不预先限定为某一种模型或 AAN。
- **两部分的交集**：运动理解结果是否真正影响辅助和训练安排？辅助后是否有新的观察、评价与调整？是否测量目标收益及安全性？

“结合两部分的人很少”是**老师提出的待检验判断**，不是已经证实的文献空白。检索必须主动寻找反例。参与度、强度各自的操作定义与测量指标从文献提取，不只凭题名或摘要下结论。

“所有有意义的论文”通过可追溯检索、筛选和引用追踪逼近覆盖；报告范围与局限，不承诺穷尽整个康复领域。时间范围、患者群体、训练部位与辅助设备目前未指定，列为待确认，不自动收窄成既有上肢或视觉方案。

## 旧建议中的核心判断（待按新目标复核）

| 方向 | 一句话结论 |
|---|---|
| **R1** | **值得做**。Wei 2026 只把 AAN 当动机，**完全没碰介入决策**。但 AAN 本身可能没有临床增益（Frullo 2017 RCT 阴性），必须预设主要终点并接受阴性结果 |
| **R2** | **不要动**。nRMSE 6.2% / 训练 <2 分钟已经很硬，改动门槛极高。值得做一次「单层 vs 多层 vs 非自回归」的消融 |
| **R3** | **先量预算再选架构**。「Transformer 太重」是部署问题不是能力问题（BSPC 2026 里 Transformer 精度最高）。**我上午基于单篇论文得出的「该走 TCN」是错的** |
| **R4** | **最大短板**。个体内 >90% 但跨被试 50–70%；而一个 2×IMU + XGBoost 在代偿识别上打到 macro-F1 0.80，**比多个深度方案都高** |
| **R5** | **一天内栽了三次**（T2M 题名错 / TATS 论文不存在 / Jev-Omni 张冠李戴）。现有脚本防线查不出「题名是否真实存在」，这一类必须人工核 |

## 重建方式

软链与成员关系由脚本生成，**不要手改 `语料/` 目录下的链接**：

```bash
cd 06_附录/决策模型工具
python3 build_directions.py     # 重建方向视图与软链
python3 build_jev.py            # 重建语料四 index.json / LIST.md
python3 gen_jev_cards.py        # 重建语料四定位卡
python3 gen_download_list.py    # 重建需下载清单
```

**注意**：`build_directions.py` 里的 `MEMBERSHIP` 决定「哪篇文献属于哪个方向」。
新增文献入库后，若它属于某个既有方向，记得把它加进 `MEMBERSHIP` 再重跑。
