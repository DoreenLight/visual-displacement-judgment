# 链路接口定义：有效性、可观测性和实际执行必须随数据走

## 合同状态

这是[完整链路方案](完整链路方案.md)的**DESIGN合同**，不是代码API或已运行软件。每条接口须携带版本、条件及来源；未知量为`null`加明确状态，不填零、沿用上一帧或隐藏缺失。

不传可识别人像/姓名；`participant_ref`仅是受控材料中的去标识化代号。标定、归一化和模型引用均指向原有材料或将来获准的实现，不由本文自动创建采集计划。

## 所有动态消息共有的字段

| 字段 | 合同与门禁 |
|---|---|
| `schema_version`、`message_id`、`parent_ids` | 每次处理可追溯；同一输入/策略/上下文版本可核对，不把估计覆写为原始值 |
| `participant_ref`、`session_ref`、`task_context_ref` | 适用患者/任务不可跨版本混接；哈希不是隐私授权的替代品 |
| `source_refs`、`model_ref`、`calibration_ref` | 保留数据/模型/校准来源、校准目标定义/单位/独立性与静态/动态适用域；原始测量无模型可为空并注明类型 |
| `acquisition_time`、`clock_ref`、`window`、`processing_time` | 采集时间与处理时间分开，含时钟映射/偏差证据；实际设备延迟预算未给定 |
| `units`、`coordinate_frame_ref`、`joint_convention_ref` | 角度/力/力矩单位、左右侧、坐标及关节约定明确；像素或归一化模型坐标不能冒称标定毫米 |
| `validity`、`invalid_reasons`、`coverage` | 各通道/关节分别报告有效、过期、缺失/失配；缺失不成为努力为零 |
| `uncertainty_kind`、`uncertainty_value`、`calibration_domain_ref` | 关键点得分、分类概率、预测区间与模糊隶属度不可混用；未校准值不具备决策许可 |
| `authorization_ref`、`risk_envelope_ref` | 设备/患者许可及安全界限必须可核对；缺失时仅限文献/离线设计讨论 |

## 消息、发送方、接收方与拒绝条件

| 消息 | 最小内容 | 发送 → 接收 | 必须拒绝/保留未知的情形 |
|---|---|---|---|
| `TaskContext` / `RiskEnvelope` | 人群/病程/关节/任务、能力参照、获准参数包络、停止和设备安全模式、版本 | S0 → S1–S10 | 没有真实授权或限值不能下发设备请求；不从健康论文抄患者阈值 |
| `ObservationPacket` | 原始/派生类型、信号引用及时间窗、单位/坐标、传感器元数据、心理量表/独立行为记录的版本与任务窗、实际辅助状态及事件 | S1 → S2 | 未同步、漂移、缺通道、原始与模型重建身份不明 |
| `ValidityPacket` | 每通道的有效期、校准版本、丢失/延迟、允许估计范围 | S2 → S3/S4/S5/S6 | 同一视觉流有效不代表EMG/力流有效；失效不能靠插值恢复“实测”身份 |
| `KinematicQualityState` | 可验证角度/轨迹、任务阶段、质量/代偿及其参考定义；观测覆盖 | S3 → S6/S9 | 无独立三维/角度参照；标签与任务/病程不符；不能从角度填努力 |
| `EffortEstimate` | 代理类型、估计/区间、目标与单位、静/动态归一化/校准参照、力学混杂、参考独立性、`observable` | S4 → S6/S9 | 视觉单流或缺患者校准/混杂分离时可以不可观测；共收缩不能直接变成净主动功 |
| `PsychologicalEngagementState` | 构念、量表/行为参照、版本/语言、分量表及方向、回答者/条件、任务或训练块时间窗、有效/缺失状态 | S4 → S6/S9/S10 | 量表非每帧测量；按钮/计数/肩肘运动不是心理真值；IMI自报effort不是物理力矩；缺记录不填零 |
| `ConstraintState` | 疼痛/退出、安全事件、能力变化、疲劳代理及不确定、事件时间 | S5 → S6及独立安全路径 | 主观报告应保留原意；未知疲劳不当“无疲劳”，急停不等待ML判断 |
| `DecisionRequest` | 请求类别、理由/证据、候选参数引用、适用上下文/有效期、允许包络、不可用项 | S6 → S7 | 不直接含设备力矩/未批准增益；低质量/不确定不触发更高强度 |
| `AppliedPolicyReceipt` | 接受/拒绝、实际策略/参数及其物理类型、执行时间、实际辅助反馈/不可得状态、责任控制器、拒绝原因、安全事件 | S7/S8 → S1/S9 | 请求不是执行；无回执不能把候选干预当实际暴露 |
| `TrainingBlockOutcome` | 总时间/次数、质量有效部分、物理可观测覆盖/贡献、心理参照/分量表/时间窗及缺失率、相对挑战、真实辅助/事件 | S9 → S10 | 分母、失效时长、设备代做和丢失窗口不明；指标不能未经验证合成总参与分 |
| `PlanRevision` | 下一任务候选、能力/风险依据、审批、上下文新版本及回滚参照 | S10 → S0 | 不静默改变安全包络、处方或在线模型；临床审批不是算法自批 |

## 双参与与不确定性的分型

用户已确认物理贡献与心理参与分别评价。心理通道的依据见[心理原文补核](心理参与补核.md)：版本/语言/回答能力与时间窗必须核对；自评/独立行为是参照，不宣称无误真值或自动力矩许可。心理低分不诊断原因，不直接触发增阻/减助力；慢尺度候选仍经临床/设备边界批准。

- `effort_type`至少区分`emg_proxy`、`interaction_force_proxy`、`model_torque`、`unobservable`，不能统称“真实参与”。参照另标静态传感器MVC、运动学反算、动态加入辅助估计、模型期望力矩或指令类别；静态校准不自动赋予动态/域外许可，参考自身也有误差。
- 概率只适用于明确的概率目标与校准域；连续力矩需要合适的区间/误差验证。ALP2025的isotonic校准针对指令生成的活动类别，活动水平阈值不是可靠度阈值；TFS的JTCR/模糊隶属度、关键点分数不直接当概率，详见[方法深核](已取得最近工作_方法参照深核.md)。
- [七篇原件补核](补取七篇_原件机制与候选裁剪.md)证明上述目标区别必要：TRO/TBCAS反算力、TIE静动态目标、VAAN传感器MVC/Rh、Shoulder期望力矩和RL误差/g代理不能互换。Rh表中可超过1而符号约定未明，不默默截断成概率；g/β/隶属度不是实际辅助功或风险概率。
- 运动意图、心理投入、主动机械贡献分别保存；不能由动作完成自动补成“有意愿且努力充分”。
- 测量/模型适用域不覆盖患者、病程、任务或负荷时，保留OOD/未知状态；不能靠高softmax消除域外问题。

## 决策表：安全退化不是默认加力或硬锁关节

| 情形 | 允许的设计行为 | 明确不允许 |
|---|---|---|
| 缺真实上下文/授权/设备合同 | 只做资料核对、估计验证设计或离线观察 | 发送真实控制命令 |
| 信号过期/失效/坐标版本失配 | 输出无效、暂停新适配；若已在实际设备运行，由其已验证失效安全合同接管 | 用上一帧冒充实测、自动加负荷/辅助或硬位置锁定 |
| 几何有效、努力不可观测 | 可评价几何/质量；保留已批准训练方案的责任方决策 | 宣称患者贡献提高，或努力驱动加难度 |
| 努力代理低、原因未分辨 | 不诊断slacking；复核疼痛/疲劳/能力/传感及主动贡献参照 | 因“偷懒”自动增阻或减助力 |
| 疼痛/退出/设备异常 | 独立停止/设备安全路径优先，记录真实事件；具体模式由设备和临床合同规定 | 让参与优化、平滑滤波或模型多数投票覆盖退出/急停 |
| 质量变差但完成率变高 | 分开报告有效练习和机器人代做；请求临床复核 | 因总次数增加就判目标达成 |
| 模型高分但未校准/OOD | 不授予基于该分数的适配权限 | 把softmax/隶属度直接当临床风险概率 |
| 换任务/病程/负荷 | 更新上下文，重新检查参照/校准适用性，保留版本 | 继续沿用原阈值且隐去条件变化 |

这里的“安全退化”只是接口责任定义，不是已验证安全功能。不存在本方案通用的安全助力、阻尼或关节锁定数值；设备责任方未提供合同则物理执行为MISSING。

补充负场景：肩肘“参与提示”是运动学规则；开始按钮若由操作者或计时器触发，不是患者自主发起。两个通道分别未知，不补作心理/物理参与证据。

## 衔接核验清单

1. S3/S4的输出有来源、时间、单位、有效期及适用域，S6不会混用分数类型。
2. S6仅提出请求；S7有独立拒绝权，实际回执才进入S8/S9。
3. S8新观察可按执行时间与原请求关联，估计错误与未执行能分开归因。
4. S9保留缺失/可观测覆盖和多目标，不把量表、角度误差、次数混成同一尺度。
5. S10改变任务须回到S0形成新上下文；不能跳过授权和安全边界。
6. 当前这些条件均是DESIGN检查项；接口格式一致不代表设备或患者链路验收。
