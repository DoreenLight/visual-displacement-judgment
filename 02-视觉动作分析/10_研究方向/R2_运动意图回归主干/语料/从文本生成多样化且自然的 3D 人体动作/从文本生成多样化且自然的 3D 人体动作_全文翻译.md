## 摘要

从文本自动生成 3D 人体动作是一个极具挑战性的问题。生成的动作既需要具备足够的多样性以探索基于文本的动作空间，更重要的是，还要准确刻画指定文本描述中的内容。在本文中，我们采用两阶段方法来解决这一问题：text2length（文本到长度）采样和 text2motion（文本到动作）生成。text2length 涉及在以输入文本为条件的已学习动作长度分布函数中进行采样。随后，我们的 text2motion 模块利用时间变分自动编码器（temporal variational autoencoder）合成一组采样长度下多样化的人体动作。我们没有直接处理姿态序列，而是提出了动作片段编码（motion snippet code）作为我们的内部动作表示，它捕获了局部语义动作上下文，并经经验证明有助于生成忠实于输入文本的合理动作。此外，我们构建了一个大规模的脚本化 3D 人体动作数据集 HumanML3D，包含 14,616 个动作片段和 44,970 条文本描述。

## 1. 引言

给定一段关于角色动作的简短文本描述（例如小说或剧本的摘录），我们能够在脑海中甚至通过绘画将这些动作具象化。问题在于，如何通过机器使这一过程自动化，换句话说，如何从文本生成逼真的 3D 人体动作？这正是我们在本文中所要解决的问题。如图 1 所示，给定输入“该人物从平躺姿势起身，按逆时针方向绕圈行走，然后再次躺回地面”，我们的目标是生成一组多样化且合理的 3D 人体动作动态，精确遵循文本所指定的动作类型、方向、速度、时序和风格。这一自动化过程可以在 AR/VR 内容创作、游戏、机器人技术以及人机交互等诸多领域带来广泛的应用影响。

与此同时，现有的基于描述生成 3D 人体动作的研究 [1, 4, 21, 32, 44] 较为零星，且结果远不能令人满意。我们观察到了几个常见的不足：输入的文本通常是一句简短的话；该任务无一例外地被形式化为确定性的序列到序列（sequence-to-sequence）生成，导致合成的动作往往显得呆板且缺乏生气；此外，生成的动作被限制为具有相同的长度；最后，现有方法所依赖的唯一数据集 KIT Motion-Language (KIT-ML) [31] 仅包含 3,010 个动作序列，且主要集中在位移动作（locomotion actions）上。具体而言，仍有三个固有挑战尚待解决。

第一，由同一模型根据文本生成的动作理应具备可变长度。第二，根据相同的文本描述，角色的表现方式通常有多种可能。第三，从自然语言的角度来看，输入的描述形式可能极为多样，从简短单一到极其冗长复杂不等。

为了解决上述不足和挑战，我们提出了一个由 text2length 采样和 text2motion 生成组成的两阶段流程。Text2length 用于估计基于输入文本的视觉动作长度的分布函数。Text2motion 的作用则是根据输入文本和采样得到的动作长度生成多样的 3D 动作；这是通过采用先验、后验和生成器网络三元组形式的时序变分自编码器（VAE）框架来实现的；此外，我们在 VAE 编码及整个流程中引入了动作片段编码（motion snippet code）作为内部表示，以表征时序动作语义，其作用在后文的消融实验中得到了实证检验。最后，我们构建了一个专用数据集（HumanML3D），包含针对 14,616 个 3D 人体动作的 44,970 条文本描述。它涵盖了广泛的动作类型，包括但不限于位移动作。在 HumanML3D 和 KIT-ML 数据集上的实证评估表明，我们的方法优于现有方法。

我们的主要贡献总结如下。第一，据我们所知，我们的工作首次实现了从文本中随机生成 3D 动作，能够生成具有可变长度、外观逼真且忠实于文本输入的多样化 3D 人体动作。第二，我们的方法具有高度灵活性，能够处理从简单到复杂各种形式的输入文本。这得益于 text2length 和 text2motion 模块，以及后文将详述的动作片段编码。最后，我们构建了一个大规模的人体动作数据集。它包含丰富的动作类型，每个动作序列均配有三条文本描述。

## 2. 相关工作

3D人体动作生成。在基于动作类别，或基于包括音频和文本在内的模态来合成2D或3D人体动作方面，已有若干先前的研究工作。在基于动作类别时，通常会采用one-hot条件向量来合成姿态序列。在该领域中，[5, 43] 均应用两阶段生成对抗网络（GAN）框架，利用新生成的姿态逐步扩展部分动作序列；[45] 的工作则使用基于 GCN 的 GAN 来建模人体动态的时空结构；同时，[11, 12, 29] 提倡采用 VAE 建模和 Transformer 架构来引入时间依赖性。在音频信号输入方面，由于音频与其动作输出在时间上是对齐的，一种常见的策略是采用时间滑动窗口，利用循环神经网络（RNN）将声学特征表示（例如 MFCC）转换为单个人体姿态。在 [35] 中，采用双向 LSTM（Bi-Directional LSTM）网络从语音输入生成上半身手势。[34] 也研究了类似的 LSTM 类模型，用于根据钢琴和小提琴独奏音频预测上半身动态；[36] 则用其来捕获音乐到舞蹈的映射。最近的研究开始解决基于音频信号的人体动态的随机性问题。[17] 采用 VAE 和 GAN 的混合模型，从音乐中生成非确定性的人体舞蹈动作。[14] 的工作通过课程训练（curriculum training）进一步支持了长时期的音乐到舞蹈生成。

将文本描述转换为人体动作是一个新兴课题。先前的研究（如 [10, 21, 32, 44]）求助于经典的编码器-解码器 RNN 模型，而 [1] 则提出学习自然语言与 3D 人体动态之间的联合嵌入空间。[10] 考虑了分层姿态结构，并利用了姿态判别器。然而，这些方法存在一些不理想的问题，即它们是具有固定动作长度的确定性一对一过程。相反，针对这些问题，我们训练的模型被证明能够生成可变长度的随机一对多序列映射。

视频生成与基于文本的视频生成。在生成视频方面，诸如 GAN 和 VAE 等深度生成模型一直是最受欢迎的选择。例如，MoCo-GAN [38] 提出了一种循环结构的 GAN，用于分别对静止像素和动态运动进行建模。随后 [37] 引入了对比学习。[8] 利用带有 RNN 架构的 VAE，根据历史视频序列随机预测未来帧，[42] 进一步将其扩展为合成具有指定起始帧和结束帧的视频。

文本到视频生成是一个相对较新的领域。为解决这一任务，包括 [20] 和 [25] 在内的多项工作采用了 GAN 框架。随后 [6] 进一步引入了注意力机制，以将局部视频区域与文本中的词语对齐。此外，[24] 将短时和长期的跨域注意力向量同时用作 VAE 框架的输入。

视频描述（Video Captioning）。本文的主题可以被视为动作描述（motion captioning）或更广泛意义上的视频描述的逆问题。因此，提及这一研究脉络也是合理的。早期的研究（如 [16]）通常借助于包含手工设计语言规则的预定义句子模板，涉及有限的动作和物体类别。在深度学习时代，这种情况发生了根本性的转变；通过采用包括 RNN [30,40]、transformer [18]、注意力上下文建模 [41]、记忆网络（memory network）[28, 46]、GAN [26] 和强化学习 [19, 27] 在内的多种强大技术，我们见证了性能的显著提升。

语言与 3D 人体动作数据。KIT Motion-Language Dataset [31] 是迄今为止唯一一个同时包含 3D 人体动作及其文本描述的可用数据集，它由 3,911 个动作序列和 6,278 个句子组成，主要聚焦于位移动作。此外，还有许多现有的 3D 动作捕捉人体动作数据集，例如 CMU Mocap [7]、Human3.6M [15]、MoVi [9] 和 BABEL [33]，形式为日常动作和体育运动。然而，它们都不包含动作的语言描述。

## 3. 我们的方法

给定一个由 M 个单词组成的文本描述 $X = ( x _ { 1 } , . . . , x _ { M } ) .$，我们的目标是生成一个 3D 姿态序列 $\begin{array} { r l } { P } & { { } = } \end{array}$ $\left( \mathbf { p } _ { 1 } , . . . , \mathbf { p } _ { T ^ { \prime } } \right)$，其长度 $T ^ { \prime }$ 在测试时确定。如图 2 所示，我们首先通过一个预处理步骤来训练一个动作自编码器（motion autoencoder）。随后，通过引入一种内部动作表征——动作片段编码（motion snippet codes，第 3.1 节），从文本中确定一个合理的动作长度（第 3.2 节），进而以输入文本和采样的动作长度为条件合成动作（第 3.3 节）。

## 3.1. 动作自编码器

如 Fig. 2(a) 中所述的预处理步骤，编码器 E 通过在时间线上应用一维卷积，将姿态序列 $P = \left( \mathbf { p } _ { 1 } , . . . , \mathbf { p } _ { T ^ { \prime } } \right)$ 转换为动作片段编码序列 $C _ { s } ~ = ~ \left( \mathbf { c } _ { s } ^ { 1 } , . . . , \mathbf { c } _ { s } ^ { T } \right)$；然后使用反卷积解码器 D 重建出 $\hat { P }$。在数学上，该过程公式化为

$$
C _ {s} = \mathrm{E} (P), \hat {P} = \mathrm{D} (C _ {s}).\tag{1}
$$

为了避免脚部滑动（foot sliding），我们的解码器 D 额外预测了未提供给编码器 E 的每一帧脚部接触。同时，也有必要对片段编码值以及相邻编码之间的差异进行约束，以促进稀疏性和时序平滑性。最终的目标函数为

$$
\mathcal {L} _ {E, D} = \sum_ {t ^ {\prime}} \| \hat {\mathbf {p}} _ {t ^ {\prime}} - \mathbf {p} _ {t ^ {\prime}} \| _ {1} + \lambda_ {s p r} \sum_ {t} \| \mathbf {c} _ {s} ^ {t} \| _ {1} + \lambda_ {s m t} \sum_ {t} \| \mathbf {c} _ {s} ^ {t} - \mathbf {c} _ {s} ^ {t - 1} \| _ {1}.\tag{2}
$$

该自编码器由两层卷积核大小为 4、步长为 2 的卷积层组成，其结构详见补充文件。因此，一个动作片段编码（motion snippet code）$\mathbf { c } _ { s } ^ { t }$ 具有 8 帧的感受野，对于 20 帧每秒（fps）的姿态流而言相当于约 0.5 秒；它还产生了一个更紧凑的内部编码序列，满足 $\begin{array} { r l } { T } & { { } = } & { \frac { T ^ { \prime } } { 4 } } \end{array}$。与单个姿态相比，片段编码捕获了对于平滑且逼真的动作生成至关重要的时序语义信息。

## 3.2. 文本到长度采样（Text2length Sampling）

如图 2(c) 所示，我们的 text2length 采样模块旨在近似以文本为条件的离散动作长度 T 的概率分布，以便在推理阶段，可以通过从给定输入文本的该学习分布函数 $p ( T | x _ { 1 } , . . . , x _ { M } )$ 中进行采样来获得离散时间长度 $T$。因此，该模块使我们的方法能够生成不同长度的动作。

这是一个典型的密度估计问题，具有多种可行的选择，在其中我们采用了 PixelCNN [39] 的神经网络方案。由于在我们的工作中，动作序列在内部被表示为一系列片段编码，因此我们的目标具体归结为确定片段编码的长度。在推理时，文本编码器从输入文本中提取句子级特征，然后将其输入到带有 softmax 激活函数的 MLP 层中，生成离散长度索引 $\{ 1 , 2 , . . . , T _ { m a x } \}$ 上的多项分布。在此，增量 1 对应 4 个姿态帧，设置 $T _ { m a x } = 5 0$ 对应 200 帧，对于 20 fps 的视频相当于 10 秒。其训练目标由交叉熵损失定义。

## 3.3. 文本到动作生成（Text2motion Generation）

我们的 text2motion 生成器包含一个文本编码器，以及一个由生成器 ${ \mathrm { ~ } } \operatorname { F } _ { \theta } .$、后验网络 $\mathrm { F } _ { \phi }$ 和先验网络 $\mathrm { F } _ { \psi } ,$ 的三元组网络构成的时序 VAE 模型，如图 2(b) 所示。文本编码器从输入文本中提取词级特征 $\mathbf { w } _ { 1 : M }$ 和句子级特征 $\mathbf { s }$；我们的 VAE 通过循环架构逐个生成动作片段代码 $\mathbf { c } _ { s } ^ { 1 : T }$：在时间 $t$，我们的后验网络 $\mathrm { F } _ { \phi }$ 在部分代码序列 $\mathbf { c } _ { s } ^ { 1 : t }$ 以及词和句子特征 $\mathbf { c } ~ = ~ ( \mathbf { w } _ { 1 : M } , \mathbf { s } , \ldots )$ 的条件下近似后验分布 $q _ { \phi } \left( \mathbf { z } _ { t } | \mathbf { c } _ { s } ^ { 1 : t } , \mathbf { c } \right)$。与文献中将后验分布与先验正态分布 $\mathsf { \bar { N } } ( 0 , \bar { I } )$ 相关联不同，本文将其与一个学习到的先验分布 $p _ { \psi } ( \mathbf { z } _ { t } | \mathbf { c } _ { s } ^ { 1 : t - 1 } , \mathbf { c } )$ 相关联，该分布由我们的先验网络 $\mathrm { F } _ { \psi }$ 基于先前的状态 $\mathbf { c } _ { s } ^ { 1 : t - \bar { 1 } }$ 和条件 $\mathbf{c}$ 获得。总体而言，我们的 VAE 通过最大化以下变分下界来进行训练：

$$
\begin{array}{l} \log p (C _ {s}) \geq \sum_ {t = 1} ^ {T} \left[ \mathbb {E} _ {q _ {\phi} (\mathbf {z} _ {t} | \mathbf {c} _ {s} ^ {1: t}, \mathbf {c})} \log p _ {\theta} (\mathbf {c} _ {s} ^ {t} | \mathbf {c} _ {s} ^ {1: t - 1}, \mathbf {z} _ {1: t}, \mathbf {c}) \right. \\ \left. - \lambda_ {K L} D _ {\mathrm{KL}} \left(q _ {\phi} (\mathbf {z} _ {t} | \mathbf {c} _ {s} ^ {1: t}, \mathbf {c}) \| p _ {\psi} (\mathbf {z} _ {t} | \mathbf {c} _ {s} ^ {1: t - 1}, \mathbf {c})\right) \right]. \end{array}\tag{3}
$$

第一项用于降低重构误差 $\mathcal { L } _ { r e c } { , }$，而第二项则惩罚后验分布与先验分布之间的 KL 散度 $\mathcal { L } _ { K L }$。

文本编码器（Text Encoder）。除词嵌入外，我们提出将词的词性（POS）标签融入文本编码器中。POS 标签显式地指明了词的类别，从而有助于定位句子中的关键重要词。此外，如图 2(b) 所示，我们手动构建了一个外部词典，用于收集与动作相关的词汇并将其归为四类：方向、身体部位、物体和动作。这些独热（one-hot）词标签被输入到一个嵌入层中，并加到词嵌入向量上。我们的文本编码器采用双向 GRU 的形式实现，它以这些嵌入向量作为输入，并生成句子特征 s 以及词特征 $\mathbb { W } 1 { : } M$。前者提供全局上下文信息，并用于初始化 VAE 的隐藏单元；后者则以局部词注意力的形式作为每个时间步的部分输入，这将在下文进行讨论。文本编码器的具体结构详见补充材料。

局部词注意力 $( \mathrm { F } _ { a t t } )$。在根据文本预测动作的过程中，分配给每个词的注意力可能会有所不同。如图 3 所示，我们的局部词注意力单元 $\mathrm { F } _ { a t t }$ 解决了这一问题，该单元使词特征 $\mathrm { w } _ { 1 : M }$ 与动作上下文记忆 h<sub>θ</sub>（即生成器隐藏单元）进行结合与交互。局部词注意力的过程可以描述为

$$
\begin{array}{c} \mathbf {Q} = \mathbf {h} _ {\theta} ^ {t - 1} \mathbf {W} ^ {Q}, \mathbf {K} = \mathbf {w} _ {1: M} \mathbf {W} ^ {K}, \mathbf {V} = \mathbf {w} _ {1: M} \mathbf {W} ^ {V}, \\ \mathbf {w} _ {a t t} ^ {t} = \text {softmax} \left(\frac {\mathbf {Q K} ^ {T}}{\sqrt {d _ {a t t}}}\right) \mathbf {V}, \end{array}\tag{4}
$$

其中 $\mathbf { W } ^ { K } , \mathbf { W } ^ { V } \in \mathbb { R } ^ { d _ { w } \times d _ { a t t } }$ 和 $\mathbf { W } ^ { Q } \in \mathbb { R } ^ { d _ { h } \times d _ { a t t } }$ 为可训练权重，$d _ { h } , d _ { w }$ 和 $d _ { a t t }$ 分别表示生成器隐藏单元 $\mathbf { h } _ { \theta } ^ { t - 1 }$、词特征 $\mathrm { w } _ { 1 : M }$ 以及注意力层的通道数。$\mathbf { w } _ { a t t } ^ { t }$ 为在时间步 t 获得的多模态注意力向量。

到达时间位置编码（Time-to-Arrival Positional Encoding）。在生成可变长度的动作时，感知当前所处的位置以及距离结束还有多远至关重要。这促使我们在每个时间步使用位置编码对到达时间信息 T−t 进行编码，如图 3 所示。其公式表示为

$$
\begin{array}{c} \mathrm{PE} _ {T - t, 2 i} = \sin \left(\frac {T - t}{1 0 0 0 0 ^ {\frac {2 i}{d}}}\right), \\ \mathrm{PE} _ {T - t, 2 i + 1} = \cos \left(\frac {T - t}{1 0 0 0 0 ^ {\frac {2 i}{d}}}\right), \end{array}\tag{5}
$$

其中向量 PE 的第二个下标表示维度索引；d 是输入嵌入的维度。时序 VAE 的架构。Fig. 2(b) 展示了我们用于 text2motion（文本生成动作）生成的时序 VAE 的总体架构；随后是 Fig. 3，它给出了生成器和后验网络结构的局部放大图。

在时间 t，词特征首先与生成器记忆单元 $h _ { \theta } ^ { t - 1 }$ 交互以产生注意力向量 $\mathbf { w } _ { a t t } ^ { t } .$。接着将当前和前一个片段编码 $( \mathbf { c } _ { s } ^ { t }$ 与 $\mathbf { c } _ { s } ^ { t - 1 } )$ 以及注意力向量 $\mathbf { w } _ { a t t } ^ { t }$ 拼接以形成输入向量，该向量被送入多层感知机（MLP）；其输出与到达时间位置编码 $\mathrm { P E } _ { T - t }$ 相加，随后通过 GRU 层生成后验分布 $\mathcal { N } ( \mu _ { \phi } ( t ) , \sigma _ { \phi } ( t ) )$。产生先验分布 $\mathcal { N } ( \mu _ { \psi } ( t ) , \sigma _ { \psi } ( t ) )$ 的过程相同，不同之处在于不将 $\mathbf { c } _ { s } ^ { t }$ 作为输入。在训练阶段，生成器学习从输入 $\mathbf { c } _ { s } ^ { t - 1 }$、$\mathbf { w } _ { a t t } ^ { t } .$ 以及从后验分布中采样的噪声向量 $\mathbf { z } _ { t }$ 中重构当前片段编码 $\hat { \mathbf { c } } _ { s } ^ { t }$。在测试阶段，由于来自真实数据的 $\mathbf { c } _ { s } ^ { t }$ 不可用，$\mathbf { z } _ { t }$ 改为从估计的先验分布 $p _ { \psi } ( \mathbf { z } _ { t } | \mathbf { c } _ { s } ^ { 1 : t - 1 }$ , c) 中采样（Fig. 2(c)）。最后，通过预训练的动作解码器 D（Sec. 3.1）解码内部片段编码序列 $\mathbf { c } _ { s } ^ { 1 : T }$，从而生成输出姿态序列 $\hat { \bf p } _ { 1 : T ^ { \prime } }$。在 text2motion 中，动作解码器 D 与其余网络一起进行微调。网络的详细结构见补充文件。

最终目标。我们用于 text2motion 生成的最终目标函数为

$$
\begin{array}{c} \mathcal {L} = \mathcal {L} _ {r e c} ^ {c o d e} + \lambda_ {m o t} \mathcal {L} _ {r e c} ^ {m o t} + \lambda_ {K L} \mathcal {L} _ {K L}, \quad \text { with } \\ \mathcal {L} _ {r e c} ^ {c o d e} = \sum_ {t} \| \hat {\mathbf {c}} _ {s} ^ {t} - \mathbf {c} _ {s} ^ {t} \| _ {1}, \\ \mathcal {L} _ {r e c} ^ {m o t} = \sum_ {t ^ {\prime}} \| \hat {\mathbf {p}} _ {t ^ {\prime}} - \mathbf {p} _ {t ^ {\prime}} \| _ {1}, \\ \mathcal {L} _ {K L} = \sum_ {t} \mathrm{KL} (\mathcal {N} (\mu_ {\phi} (t), \sigma_ {\phi} (t)) \| \mathcal {N} (\mu_ {\psi} (t), \sigma_ {\psi} (t))) \end{array}\tag{6}
$$

训练方案。为应对变长序列到序列（sequence-to-sequence）生成任务，我们的训练过程同时采用了课程学习（curriculum learning）[3]和计划采样（scheduled sampling）[2]策略，具体如下。从旨在按顺序生成前 $T _ { c u r }$ 个片段代码开始，我们在片段代码长度等于或长于 $T _ { c u r }$ 的训练数据上优化模型。一旦验证集上的重建损失开始上升，我们便通过在目标序列中再追加一个片段代码进入下一阶段；任务的复杂度在每个阶段逐步增加，直至达到预测的最大时间步 $T _ { m a x }$（即 $T _ { c u r } = T _ { m a x }$）。此外，为了弥合序列预测中训练与推理之间的差距，针对整个目标片段代码序列 $\mathbf { c } _ { s } ^ { 1 : T }$ 以概率 $p _ { t f }$ 应用教师强制（teacher forcing），这意味着真实（ground-truth）片段代码将被作为下一步生成的输入。

## 4. 我们的 HumanML3D 数据集

我们的 HumanML3D 数据集源于 HumanAct12 [12] 和 AMASS [23] 数据集中动作序列的整合，这两个数据集是公开可访问的大规模 3D 人体动作捕捉数据集。它们包含了来自各种人体动作的运动，例如日常活动（如“行走”、“跳跃”）、体育运动（如“游泳”、“空手道”）、杂技（如“侧手翻”）和艺术表现（如“跳舞”）。遗憾的是，这些数据集并未附带动作的文本描述。

为了进行数据归一化，进行了以下几个处理步骤。动作被调整为 20 FPS，且时长超过 10 秒的动作被随机裁剪至 10 秒；随后将它们重定向到默认的人体骨骼模板，并在初始状态下适度旋转以面向 $Z +$ 方向。随后是通过 Amazon Mechanical Turk (AMT) 进行的文本标注过程，在该过程中雇用了平均工作批准率超过 92% 的以英语为母语的众包人员，并要求他们用至少 5 个单词来描述一个动作。我们为每个动作片段从不同的标注人员处收集 3 条文本描述。随后进行人工后处理步骤以过滤掉异常的文本描述。

因此，据我们所知，我们的 HumanML3D 数据集成为了规模最大、最多样化的带文本描述人体动作集合，包含 14,616 个动作以及由 5,371 个不同词汇构成的 44,970 条描述。动作总时长达 28.59 小时，其中动作的平均时长为 7.1 秒。最短和最长时长分别为 2s 和 10s。在文本描述方面，其平均长度和中位数长度分别为 12 和 10。Table 1 中给出了我们的 HumanML3D 与目前唯一现存的动作-文本数据集 KIT Motion-Language [31] 的表格对比。

## 5.1.2 定量评估

Table 2 和 Table 3 分别展示了在 HumanML3D 和 KIT-ML 数据集上的定量结果。为了公平比较，每个实验重复 20 次，并报告具有 95% 置信度的统计区间。由于所有基线方法在生成新动作时都直接使用真实（ground-truth）动作长度，为了公平比较，我们还考虑了我们方法的一个变体，即移除了 text2length 采样模块（即 ours w/ real length）。

真实动作的高 R-precision 证明了所提出的 R-precision 指标的可靠性，该指标为所有方法设定了性能上限。总体而言，从 Table 2 和 Table 3 中我们可以得出以下观察结果。首先，在两个数据集的所有指标上，我们的方法均明显且大幅优于所有对比方法。Seq2Seq [21] 和 Text2Gesture [4] 通过其编码器-解码器和 Transformer 的神经机器翻译架构，直接将文本数据映射到人体动力学；然而，它们在这一过程中难以保持动作的逼真感。这导致了较低的基于动作的文本检索精度以及较高的 FID 值。Language2Pose [1] 通过引入协同嵌入空间（co-embedding space）在生成质量上表现更好，但其结果与真实动作相比仍有很大差距。非确定性方法 MoCoGAN [38] 和 Dance2Music [36] 生成的动作质量极其低下，这体现在它们极低的多样性（diversity）和多模态（multimodality）得分上——这是由于未能忠实于输入文本所致。相反，直接使用真实动作长度的本方法变体（Ours w/ real length）在几乎所有指标上都取得了最优性能。我们使用 text2length 采样的默认方法（Ours）在 R-precision 和 FID 得分上具有相媲美的性能，同时更擅长合成多样化的动作，这尤其体现在多样性与多模态得分上。

## 5.1.3 Qualitative Evaluation

Fig. 4 展示了我们的方法与表现最好的基线方法 Language2Pose [1] 的定性对比。其他对比方法生成的动作失真过于严重，无法使用 SMPL 人体模型 [22] 进行渲染。Language2Pose 有时能捕捉到输入文本中的部分概念（例如，坐下）。然而，它未能理解全局文本信息。此外，生成的动作在短时间后往往会停滞不动。相比之下，我们的方法能够生成视觉上吸引人的动作，在手势、动作、身体部位和时序方面准确反映文本描述中的精细细节。此外，对于相同的输入文本，我们生成的动作具有足够的多样性。更多结果见附录。

## 6. 结论与展望

本文探讨了一个新兴的研究问题，即基于自然语言描述生成 3D 人体动作，其中我们特别强调生成多样化且自然的动作。为此我们提出了一个两阶段流程：text2length 模块根据给定的文本描述从估计的动作长度分布中进行采样；text2motion 模块则通过我们的时序 VAE（temporal VAE）根据输入文本生成所采样长度的动作。我们构建了一个大规模的人体动作-语言数据集，期望能够促进该领域新方法的发展与评估。广泛的定量和定性实验证明了我们方法的有效性。未来的研究计划包括探索简化评估指标集的方法，以及我们任务的逆向任务——动作描述（motion captioning）。
