# R2 · 运动意图回归主干 —— 编者建议

> **一句话**：Wei 2026 的 3DCNN-TF 已经是很强的主干。**这一轮不要动它。**
> **本方向 3 篇语料在 `语料/`（软链，非副本）**

---

## 1. ★ 必须诚实面对的点

### 1.1 主干已经很硬，改动要有理由

Wei 2026 JBHI（`语料/Wei2026_JBHI_种子论文.pdf`）的实际表现：

| 指标 | IRASS 腕关节 | EPIC 膝关节 |
|---|---|---|
| nRMSE | **6.2%** | **5.5%** |
| R² | 95.5% | 96.2% |
| 训练时间 | 平均 < 2 分钟（T4） | 同 |
| 提前预测 | **最多 300 ms** | 同 |

它比 8 个基线中的每一个都显著更好（`p < 0.05`，Holm-Bonferroni 校正）。

**第一篇论文不要动主干。** 任何改动都必须能回答：「为什么改之后比 6.2% 更好？」—— 而这个门槛很高。

### 1.2 但它的两个设计值得质疑

| 设计 | 质疑 |
|---|---|
| **自回归生成** | 逐 token 生成有误差累积。作者用 scheduled sampling 缓解，但这是治标。R1 的决策层思路（非自回归 + 并行打分）恰好绕开这个结构 —— **但只能用于决策，不能用于连续角度回归**（见 R1 §1） |
| **单层 TFE + 单层 TFD** | 作者称「显著降低计算复杂度」，但单层 Transformer 的表达能力上限也低。**这里存在精度-容量的权衡，值得做一次消融** |

### 1.3 离散 token 路线是另一条路，但要先证明它更适合

T2M（CVPR 2022）与 T2M-GPT（`语料/`）证明动作可以被量化成离散码。这对**生成**任务很自然（文本翻译范式），但对**回归**任务是另一种损失：

- 量化误差的地板 = 分箱宽度
- 要达到 nRMSE 6.2%，分箱得极细 → token 序列极长 → 违背「轻量化」初衷

**除非同时满足「token 少 + 精度高」，否则这条路对回归不划算。** 这也是 R1 里 JEV 替代不了的同一个原因。

---

## 2. 建议怎么做

### 2.1 主干保持原样

```
3DCNN（肌肉协同特征）→ 单层 TFE + 单层 TFD（因果掩码 + 段编码 + scheduled sampling）
```

一个字节都不改。**新工作全部叠在上面。**

### 2.2 值得做的一次消融

在保持 3DCNN 不变的前提下，只动 Transformer 部分：

| 变体 | 检验什么 |
|---|---|
| 单层 TFE/TFD（原论文） | 基线 |
| 两层 / 三层 | 表达能力是否被单层限制 |
| 非自回归（并行打分 + 可学习 query） | 误差累积能否消除；参考 iTransformer-DTL 的结构 |

**这三个变体可以放进同一篇论文的 ablation 章节**，成本低、结论明确。

### 2.3 离散 token 什么时候才值得试

只有当同时满足以下两条：

1. 需要**生成**而非回归（比如动作预测、多动作序列规划）
2. 能证明 token 序列长度可控

**对「从 sEMG 连续预测当前关节角」这个任务，不建议走 token 化。** 这也是 T2M/T2M-GPT 在本项目里只作背景、不作主线的原因。
