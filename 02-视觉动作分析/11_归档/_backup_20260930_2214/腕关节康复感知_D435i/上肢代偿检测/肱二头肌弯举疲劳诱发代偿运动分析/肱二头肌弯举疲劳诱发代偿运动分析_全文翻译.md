# 肱二头肌弯举中疲劳诱发代偿运动的分析：面向可穿戴传感器部署的洞见

Ming Xuan Chua、Yoshiro Okubo、Shuhua Peng、Thanh Nho Do、Chun Hui Wang，以及 Liao Wu，IEEE 会员

摘要——肱二头肌弯举康复中一个常见的挑战是肌肉代偿现象，即当主要肌群因受伤或疲劳而无法正常发力时，患者会采用替代性的运动模式，这显著降低了康复训练的效果。随着康复模式从临床逐步转向家庭化的趋势日益明显，该问题愈发突出，因为在家庭场景下物理治疗师难以进行持续的监测与纠正。因此，开发能够检测肌肉代偿的可穿戴传感器显得至关重要。本研究旨在通过对肱二头肌弯举中肌肉代偿现象的全面研究，为可穿戴传感器的优化部署提供洞见。我们在标准阶段与疲劳阶段下采集了 12 名健康受试者的上肢关节运动学数据以及八块肌肉的表面肌电信号（sEMG）。从 sEMG 信号中提取了两组肌肉协同（muscle synergy），并与关节运动学数据进行了综合分析。研究结果显示，在疲劳状态下，前臂肌相对于肩部肌的贡献比例发生转变，同时两组协同的激活幅值均显著增加。此外，疲劳状态下肩关节的运动幅度也更为显著。上述结果表明，在部署可穿戴传感器时，应聚焦于肩部肌肉活动与关节运动，以有效检测代偿运动。

关键词——疲劳诱发代偿运动、肌肉协同、康复、肱二头肌弯举、可穿戴传感器

## I. 引言

肱二头肌弯举（B<sup>ICEP</sup> <sup>Curl</sup> <sup>exercise</sup> ）常被用于上肢疾病的康复，例如肱二头肌肌腱炎 [1]，即由重复性过头动作或年龄相关的磨损等原因引起的肱二头肌肌腱炎症。其治疗通常包括高重复次数、低负重的弯举练习，在炎症缓解后用于强化肱二头肌（肱肌）。整个康复流程包含四个步骤：1）疼痛管理；2）增加柔韧性与关节活动度（ROM）；3）恢复肌肉力量；4）针对运动项目的功能性训练 [2]。肱二头肌肌腱炎的康复是一个长期的治疗过程，要求患者首先在医院或诊所接受监督下的治疗（通常在急性期），随后在家庭环境中持续进行较长时间的训练，直至完全康复。

肌肉代偿是康复治疗中频繁出现的突出问题，包括涉及二头肌弯举的上肢康复训练。该术语描述了这样一种患者行为：由于肌肉疲劳或疼痛，患者在完成特定动作时会有意识地避开目标肌群，无意识地选择其他肌肉来执行所要求的动作。因此，康复治疗的有效性会显著下降，并可能造成进一步的损伤。如果康复治疗持续较长时间，不正确的肌肉使用甚至可能导致永久性的姿势偏差 [3]。

当患者在医院或诊所接受康复治疗时，物理治疗师可以通过直接观察和指导来识别并纠正肌肉代偿。然而，由于缺乏监督，在患者在家中进行康复训练时检测肌肉代偿具有很大挑战性。随着人口老龄化带来的康复需求急剧增长，康复模式从诊所向家庭转移的趋势日益明显，这一问题也愈发严重。多项研究表明，医院之外的延续性支持十分有限 [4]。Moksnes 等人 [5] 也证明，患者居住地中心性的降低（即患者在地其居住地远离医疗中心）会显著增加遭受严重损伤的可能性。

虚拟现实 [6]、远程医疗 [7]、可穿戴传感器 [8]、机械臂 [9] 以及外骨骼 [10]、[11] 等技术的最新进展在一定程度上缓解了上述难题。具体而言，可穿戴传感器的进步为这一问题提供了一种替代解决方案。尽管目前针对二头肌弯举中肌肉代偿识别的研究尚少，但已有学者提出了一些用于其他类似动作场景的传感器，例如够取物体 [12]、行走 [13]、坐姿 [14] 以及坐起动作 [15]。总体而言，这些传感器可以分为两大类。第一类传感器用于采集与人体运动相关的物理参数。该类典型设备包括无标记摄像头 [16]、动作捕捉系统 [17]、惯性测量单元 [18]–[20]、应变传感器 [21] 以及压力传感器 [12]、[22]。第二类传感器则主要基于表面肌电信号（surface electromyography, sEMG），直接检测患者的肌肉活动 [23]–[31]。

肌肉协同分析已被广泛用于比较不同阶段之间的肌肉协调性。其主要通过数据降维算法——非负矩阵分解（Non Negative Matrix Factorization, NNMF）来提取。Dupuis 等人 [32] 利用表面肌电（sEMG）传感器进行肌肉协同分析，研究疲劳状态下伸手任务中肩部运动的变化。Hajiloo 等人 [26] 研究了疲劳前后跑步过程中下肢肌肉协同模式的变化，发现各肌肉的相对权重和激活程度存在显著差异。Thomas 等人 [33] 开展了类似的工作，用于识别肩关节在推动手柄过程中的肌肉协同模式。Matsunaga 等人 [34] 也发现，在单腿落地过程中，臀大肌疲劳需要腘绳肌进行代偿。上述研究表明，肌肉协同分析能够反映受试者状态的变化，包括疲劳状态。然而，这些研究均未涉及弯举动作中的代偿运动。这些工作提供了丰富的肌肉贡献特征，可用于区分运动过程中的不同状态。然而，将肌肉协同模式的变化与传感器开发相结合的研究仍然有限。

虽然弯举（Bicep Curl）主要包含肘关节的屈伸运动，但其代偿运动可能涉及肩部上抬-下沉、肩部屈伸以及腕关节屈伸 [35]、[36]。在此过程中，多块肌肉可能被激活，包括：

• 原动肌：肱二头肌（Biceps Brachii, BIC）；

• 协同肌：肱肌（Brachialis, BR）和肱桡肌（Brachioradialis, BRA）；

• 稳定肌：三角肌前束（Anterior Deltoid, AD）、三角肌后束（Posterior Deltoid, PD）、上斜方肌（Upper Trapezius, UT）、尺侧腕屈肌（Flexor Carpi Ulnaris, FCU）和桡侧腕屈肌（Flexor Carpi Radialis, FCR）；以及

• 拮抗肌：肱三头肌（Triceps, TRI）。

因此，为了全面捕捉和分析弯举运动，需要部署机械传感器和表面肌电（sEMG）传感器阵列，以观测上述所有关节和肌肉的活动情况。可以预见的是，所开发的可穿戴传感器将较为复杂且成本较高 [37]。因此，有必要对弯举动作中的代偿运动进行系统分析，以降低标准弯举运动与疲劳弯举运动之间特征维度，从而简化传感器的设计与部署。据作者所知，这一方面的研究在现有文献中尚属空白。

为此，本研究使用运动捕捉系统采集肩部和手臂关节的运动学数据，包括肩部上抬-下压、肩部屈曲-伸展、肘部屈曲-伸展以及腕部屈曲-伸展，涵盖标准弯举与疲劳状态下的弯举动作。尽管此处采用运动捕捉系统进行分析，但需指出，相关结果同样适用于其他能够测量关节运动的机械传感器。此外，我们使用 sEMG（表面肌电）传感器测量八块肌肉，包括 BIC（肱二头肌）、BRA（肱肌）、UT（斜方肌）、TRI（肱三头肌）、FCU（尺侧腕屈肌）、FCR（桡侧腕屈肌）、AD（旋前圆肌）和 PD（旋后肌）。BR（肱桡肌）被排除在外，因为它不是一块表浅肌肉，因此无法通过 sEMG 进行恰当的测量。选择运动捕捉系统和 sEMG 传感器的依据在于两者均具有较高的精度，并被广泛应用于运动分析领域 [8]。考虑到本研究旨在识别标准弯举与疲劳弯举之间的真实差异（ground truth），这些传感器是最为合适的。为了比较哪些肌肉子集对代偿运动的贡献最大，我们采用 NNMF（非负矩阵分解）算法从 sEMG 信号中提取肌肉协同模式（muscle synergy）。

本文的贡献主要体现在以下两个方面：

• 识别无负重、标准及疲劳三种弯举状态之间在肌肉协同模式和关节运动学方面的显著差异。

• 基于 sEMG 数据与关节运动学的比较，提出一种用于检测弯举中疲劳诱发代偿运动的最优指标。

本文所提出的结果有望为可穿戴传感器在家居康复中自动检测弯举代偿运动的优化开发与部署提供指导。

## C. 实验方案

1) 弯举方案：本研究选用标准弯举动作作为锻炼项目，并在实验前对受试者进行训练，以确保他们能够正确完成同一变式的弯举动作。指示受试者旋前（supinate）右肘关节使掌心朝上。然后，要求受试者在保持上臂贴近躯干的情况下屈曲肘关节。当手腕到达肩部高度时，指示受试者将肘关节伸展回到起始位置。实验过程中，受试者需使用 5 kg 哑铃跟随节拍器以每分钟 30 拍的节奏完成五次弯举。在本研究中，一次弯举周期定义为从受试者开始屈曲肘关节到其肘关节回到起始位置所经历的时间。

![](images/34f1957e1d611be1ef86183f631ac2411c8967a29671b329a8acf3f24c8d822e.jpg)  
图 2：本研究中弯举过程中的四个关节角度。（a）矢状面视图。（b）冠状面视图。红色虚线表示参考线；紫色线条连接锁骨与肩锁关节；蓝色、绿色和黄色线条分别表示上臂、前臂和腕部。箭头指示正方向。

2) 疲劳方案：本研究在数据采集阶段使用 Borg CR-10 量表 [23] 来判定疲劳状态。要求受试者在运动过程中进行自我评估。疲劳阶段定义为当受试者的自感用力量表（Rated Perceived Exertion, RPE）等级达到七级时（即受试者无法完成一个完整周期，或受试者口头表示无法完成该任务时）。多项文献 [40] 已证明 sEMG 信号能够很好地反映肌肉的疲劳程度。当肌肉出现疲劳时，sEMG 信号的幅值会增加，而其中值频率会下降。考虑到 RPE 是一种主观的、由受试者自我评定的量表，本研究在数据采集完成后提取了 sEMG 信号的均方根（RMS）最大幅值和中值频率，以验证受试者关于自身疲劳状态的陈述。

3) 实验流程：研究者在当天检查受试者，以确保他们满足所有纳入标准（inclusion criteria）。随后收集受试者的数据，如体重、身高和运动习惯，并向受试者解释二头肌弯举方案和疲劳方案。sEMG传感器和VICON标志点按照图3所示的位置进行粘贴。然后，指导受试者在无负重条件下进行五次二头肌弯举，在标准条件下使用5kg哑铃进行五次弯举，以及在疲劳条件下使用5kg哑铃进行五次弯举。

## III. 方法

## A. 数据预处理

对二头肌弯举测量数据进行分析，取五个周期并取平均值，以减少差异。采集到的sEMG数据首先使用带通滤波器（30Hz-80Hz）进行滤波以去除噪声[40]。随后使用MATLAB的`'envelope'`函数获取信号的包络。

![](images/ef0e9ed446cc54eb03892dc8511d985d8f109eb4e24b7a21beb45c9c729e2ae1.jpg)  
图3：sEMG传感器和VICON标志点在受试者身上的放置位置。(a) sEMG传感器 (b) VICON标志点

1) 疲劳分析：为了验证疲劳的存在，从标准和疲劳两种条件下采集的原始sEMG信号$E_{raw}$中提取了均方根振幅$E_{RMS}$和中位频率$E_{freq}$。信号的中位频率使用MATLAB的`'medfreq'`函数计算。

$$
E_{RMS} = \sqrt{\frac{1}{n} \sum_{i} E_{i}^{2}} \tag{1}
$$

$$
E_{freq} = \mathrm{medfreq}(E_{raw}) \tag{2}
$$

## B. 肌肉协同

肌肉协同（muscle synergy）是由单个神经命令信号招募的肌肉协同激活模式。它反映了我们的肌肉如何协同工作以完成涉及时间序列和肌肉贡献的任何动作。本研究使用MATLAB默认的`'nnmf'`函数将滤波后的sEMG包络$\boldsymbol{E} \in \mathbb{R}^{m \times t}$分解为协同向量$W \in \mathbb{R}^{m \times n}$和激活系数$C \in \mathbb{R}^{n \times t}$，如下式所示

$$
W, C = \tt{nnmf}(\it{E}), \quad \operatorname*{min}_{W,C} |W \times C - E| \tag{3}
$$

其中$m$、$n$和$t$分别表示观测的肌肉数量、协同数量和数据点数量。关于此方法的更多细节，请读者参考文献[41]。

1) 相对肌肉协同：在提取所有受试者的肌肉协同后，使用L2归一化（L2 Normalization）[41]将数据归一化到[0 1]之间，以便进行受试者间的比较。随后将归一化系数$D$的逆整合到激活中。L2归一化的数学模型以及相对肌肉协同$w$和激活模式$c$的计算公式如下所示

$$
w = W \times D^{-1}, \quad c = D \times C \tag{4}
$$

其中

$$
D = \sqrt { \sum _ { i = 1 } ^ { n } \lVert W _ { i } \rVert }\tag{5}
$$

2) 方差解释率（VAF）：肌肉协同的数量由权重协同系数、激活系数与 sEMG 包络三者乘积之间的 VAF 值确定。协同数量的定义为：在 $\mathrm { V A F } \geq 0 . 9$ 的前提下，使 VAF 达到该阈值的最小协同数量，且增长率小于 3%。VAF 的数学模型如下所示。

$$
V A F = 1 - \frac { ( E - w \times c ) ^ { 2 } } { E ^ { 2 } }\tag{6}
$$

3) 余弦相似度：余弦相似度通过衡量两个向量之间的余弦夹角，用于协同效应的比较与匹配。其计算公式如下所示。

$$
\cos ( V _ { 1 } , V _ { 2 } ) = \frac { V _ { 1 } \cdot V _ { 2 } } { \Vert V _ { 1 } \Vert \Vert V _ { 2 } \Vert }\tag{7}
$$

4) 单块肌肉疲劳识别：在计算不同条件下弯举动作的肌肉协同后，可以识别所选肌肉之间相对贡献的变化。这些变化可被解释为中枢神经系统为维持运动表现而调整肌肉募集策略的改变。因此，我们选取了在肌肉协同模型中变化最为显著的肌肉子集，并对其 RMS 幅值的增量进行了列表统计。

## C. 运动学

VICON 软件基于 VICON 标记点的坐标以及 VICON 上肢模型，输出多种关节运动学参数，包括肩关节屈伸、外展-内收、上提-下压、内旋-外旋，以及肘关节屈伸和腕关节屈伸。随后，采用滑动均值算法对这些关节角度轨迹进行滤波处理，窗口大小设为总数据长度的 1%。

1) 时间尺度归一化：研究中所观察到的关节运动学数据 $\textbf { \textit { J } } \in \textbf { \textit { R } } ^ { j \times d }$ 采用样条插值方法进行分割与归一化，其中 j 和 d 分别表示所观察的关节运动学数量和数据长度。根据第 II-C1 节中对弯举动作的定义，关节运动学 J 被归一化为 ℓ 个数据点，以便进行比较。弯举动作被划分为上举阶段和下放阶段：上举阶段为 0% 至 50%，下放阶段为 50% 至 100%。归一化过程通过 MATLAB 中的 'interp1' 函数实现。

$$
\| J \| _ { t } : = \operatorname { i n t e r p } 1 ( J , \ell )\tag{8}
$$

2) 受试者间的相似性与差异性：在对所有受试者执行的弯举动作进行时间尺度归一化之后，得到平均归一化关节运动学 $\bar{J} \in \mathbb{R}^{j \times \ell}$，其计算公式如下：

$$
\bar { J } = \frac { 1 } { s } \sum _ { i = 1 } ^ { s } \| J _ { i } \| _ { t } .\tag{9}
$$

其中，s 表示受试者的总人数。

然后，所有数据点 $\mathcal { I } \in \mathbb { R } ^ { j \times \ell }$ 在平均关节运动学 $\bar{J}$ 与每个受试者的个体关节运动学 $\| J \| _ { t }$ 之间的平均差异由下式给出：

$$
\mathcal { I } = \omega ( \bar { J } , \lVert J \rVert )\tag{10}
$$

其中 $\omega ( \cdot , \cdot )$ 是一个辅助函数，定义如下：

$$
\omega ( x , y ) : = \frac { 1 } { n } \sum _ { i = 1 } ^ { n } ( x _ { i } - y _ { i } ) , \quad \forall x , y \in \mathbb { R } ^ { n } .\tag{11}
$$

然后，通过计算 $\mathcal { I }$ 的均值和标准差，评估关节运动学相对于其平均关节运动学的相似性 $\overline { { \mathcal { I } } }$ 与差异性 $\sigma _ { \mathcal { I } }$，如下所示：

$$
\overline { { \mathcal { T } } } = \frac { 1 } { s } \sum _ { i = 1 } ^ { s } \mathcal { T } _ { i }\tag{12}
$$

$$
\sigma _ { \mathcal { T } } = \sqrt { \frac { 1 } { s - 1 } \sum _ { i = 1 } ^ { s } ( \mathcal { T } _ { i } - \overline { { \mathcal { T } } } ) ^ { 2 } }\tag{13}
$$

## D. 统计分析

统计分析使用 MATLAB 进行，p 值设定为 5%。数据的正态性采用 Shapiro-Wilk 检验进行检验，方差齐性采用 Levene 检验进行检验。若上述两个条件均满足，配对 t 检验是最合适的检验方法；否则，应使用 Wilcoxon 符号秩检验（Wilcoxon signed rank test）进行此检验。由于本研究的样本量较小（12 个），低于满足中心极限定理（Central Limit Theorem）所需的最小样本量（30 个）的一般标准，因此采用 Wilcoxon 符号秩检验，因为所比较的数据是配对的，并且不需要数据服从正态分布。

## IV. 结果

本研究展示了在无负重、标准以及疲劳条件下弯举动作的肌肉协同与运动学特征。我们还提供了这些模式下的关节运动学数据。此外，我们讨论了这些状态下弯举动作之间的一般性差异，以及观察和捕捉这些状态间变化所需的肌肉。

## A. EMG 的中位频率与均方根（RMS）分析

本节概述了在标准弯举和疲劳状态弯举之间所有肌肉信号的中位频率和均方根（RMS）幅值的变化，如图 4 所示。结果显示，AD、FCU、PD 和 TRI 肌肉的中位频率显著降低。相较于标准条件，所有肌肉在疲劳条件下的中位频率下降了 0.50% 至 7.01%。在两种条件下，半数肌肉的中位频率经 Wilcoxon 符号秩检验（Wibcoxon signed rank test）显示出统计学显著差异（p 值 < 0.05），这支持了在所有受试者中，标准状态与疲劳状态下肌肉的中位频率之间存在可测量差异的结论。BIC 肌肉的 p 值为 0.054，较为接近显著性阈值。值得注意的是，拮抗肌 TRI 和协同肌 BRA 均表现出疲劳，这符合 Boyas 等人 [42] 和 Wang 等人 [43] 关于重复运动诱发疲劳过程中协同肌和拮抗肌在频域变化方面的研究结果。因此，我们可以认为受试者已达到疲劳状态。

结果表明，所有肌肉 sEMG 信号的 RMS 幅值在标准条件与疲劳条件之间均显著增加，增幅范围为 17.2% 至 127.2%。经 Wilcoxon 符号秩检验，所有肌肉 RMS 幅值的增加均具有统计学显著性（p 值 < 0.05）。从理论上讲，sEMG 信号的 RMS 会受到疲劳和肌肉施加力大小的影响。考虑到运动强度、活动范围（ROM）和负荷保持不变，我们可以得出结论：RMS 的变化既包含疲劳因素的影响，也包含了为维持运动表现而发生的肌肉募集策略变化的因素。

对于 Synergy II（协同模式 II），我们观察到在无负重条件下的激活模式与 Synergy I 类似。在标准条件下，RMS 幅值增加至约 0.88，并呈现出从起始到二头肌弯举约 20% 处的上升趋势，随后保持恒定直至约 50% 处，之后开始下降。最后，在疲劳条件下，激活的 RMS 幅值增加至约 1.3。曲线呈正弦波形，在二头肌弯举约 30% 处达到第一个峰值，在约 60% 处到达第一个波谷，随后形成第二个峰值，其幅值为第一个峰值的一半。

在本研究中，采集了肘关节屈伸、肩关节屈伸、肩部升降以及腕关节屈伸等关节运动学数据。与此同时，受试者在不同条件下进行二头肌弯举练习。结果如图 7 所示，每位受试者的运动学数据与平均运动学数据之间的差异列于表 II 中。

1) 肘关节屈伸（Elbow Flexion - Extension）：我们注意到肘关节屈伸的活动范围相似，均在 50 至 150 度之间。无负重和负重条件下的运动轨迹无明显差异。对于疲劳条件，我们观察到在举起阶段的峰值出现位置存在右移，从二头肌弯举约 30% 处移至约 40% 处。各受试者间的准确性和相似度在无负重条件下最低，其次是疲劳条件，然后是标准条件。

2) **肩部屈伸**：对比三个阶段，肩部屈曲呈现相似的运动轨迹。在无负重条件下，肩部保持稳定，几乎不发生屈曲。在标准条件下，我们注意到起始位置降低至约 -10 度，表明受试者由于手持哑铃而略微屈曲于躯干中心后方。肩部在二头肌弯举周期的约 30% 处轻微屈曲约 10 度，并在约 60% 处返回。在疲劳条件下，我们注意到肩部屈曲幅度较标准条件更为显著，在约 20% 处屈曲约 20 度，并在二头肌弯举周期的约 80% 处返回。受试者间的准确性和相似性在疲劳条件下最低，其次为无负重条件，最后为标准条件。

3) **肩部上提-下压**：在无负重条件下，肩部起始角度约为 15 度，在二头肌弯举的约 30% 处上提，于约 40% 处达到 25 度，并在约 70% 处返回至约 15 度。在标准条件下，肩部在整个周期内保持稳定，起始角度约为 16 度，于二头肌弯举的约 25% 处达到峰值 20 度。在疲劳条件下，我们注意到其模式与无负重条件相似。区别在于肩部上提更为显著，于二头肌弯举周期的约 20% 处达到 30 度，并在约 70% 处返回至初始水平。就受试者间的准确性和相似性而言，无负重条件下最低，其次为标准条件，最后为疲劳条件。

4) **腕部屈伸**：与肩关节不同，三种条件下的腕部屈曲角度在整个过程中保持恒定。唯一区别在于三种阶段的起始角度依次递减。无负重条件、标准条件和疲劳条件下的腕部屈伸起始角度分别约为 -17 度、-21 度和 -29 度。关于受试者间的准确性和相似性，无负重条件下最高，其次为标准条件和疲劳条件。

## V. 讨论（DISCUSSION）

本研究首次探讨了受试者在无负重、标准以及疲劳条件下进行二头肌弯举时，肩部与肢体肌肉协调的差异。从结果中我们观察到受试者的 RMS（均方根值）与中位频率与受试者的 RPE（主观用力感觉）量表呈正相关。通过中位频率分析，我们注意到二头肌弯举运动的协同肌、部分固定肌以及拮抗肌均出现了疲劳。

## A. 肌肉协同（Muscle Synergy）

在所有条件下发现的协同数量均为两个，表明肌肉协调的复杂度没有显著变化。从结果来看，不同条件下协同 I（Synergy I）之间没有显著差异，因此讨论将聚焦于协同 II（Synergy II）。在我们的研究中，当受试者进行二头肌弯举时，肌肉贡献从肩部肌肉向前臂肌肉发生了转移，且具有统计学显著性。负重的存在降低了腕关节的稳定性，需要更多的力量来适应不断加大的运动强度。当受试者在疲劳条件下进行二头肌弯举时，我们注意到肌肉贡献从前臂肌肉转向了肩部肌肉。与 Liu 等人 [23] 的研究结果——其表明 FCU（尺侧腕屈肌）、FCR（桡侧腕屈肌）和 BRA（肱肌）肌肉在疲劳过程中的协同性增加——相反，我们发现负荷从前臂肌肉转移向了肩部肌肉。然而，他们的研究未涉及肩部肌肉，这可能导致得出了上述结论。

## B. 激活模式

与协同模式（synergy patterns）相比，激活模式（activation patterns）提供了更具洞察力的信息。在所有条件下，激活幅值曲线均有所增加。这种变化是由于在不同条件下完成弯举动作所需努力程度增加所致。对于协同模式 I，肌肉在弯举动作开始时被激活，表明这是弯举动作的向心收缩（concentric）阶段。在等长阶段（约弯举动作的 50% 处），激活值急剧下降，随后在离心收缩（eccentric）阶段保持恒定。对于协同模式 II，由于在哑铃远离躯干时需要逐渐增加努力来稳定握姿，肌肉在向心收缩阶段逐渐被激活。在等长阶段（约弯举动作的 50% 处），激活值在离心收缩阶段保持恒定。在疲劳条件下，协同模式 I 最初被高度激活，以补偿下降的力生成能力。一旦运动启动，激活值随即下降，并在等长阶段出现第一个最低值。在离心收缩阶段，激活值逐渐增加以控制哑铃的下落。在协同模式 II 中，激活值逐渐增加，并在弯举动作约 25% 和 75% 处达到峰值，这分别对应向心收缩和离心收缩阶段中哑铃与躯干距离最远的时刻，从而提供额外的握力。

## C. 运动学（Kinematics）

结果表明，弯举动作（肘关节屈曲）的运动学测量并未显著改变关节活动范围。然而，无负重条件下的平均角度差异最大，这可能是由于在执行弯举动作时难以保持稳定的节奏所致。另外，我们注意到在不同条件下肩关节发生了明显变化。结果显示，肩关节屈伸和肩关节升降运动发生了显著变化。中枢神经系统通过调节肩关节来辅助弯举动作。有趣的是，与其他条件相比，疲劳条件下肩关节升降运动的角度差异和偏差最小，这表明受试者倾向于通过抬高肩部来补偿疲劳。另一方面，与其他条件相比，疲劳条件下肩关节屈伸的角度差异和偏差最大，这表明疲劳状态下过度引入肩关节屈曲是不稳定且不一致的。最后，结果表明，在不同条件下腕关节变得更加不稳定。

## D. 传感器开发启示（Insights for Sensor Development）

从结果中，我们注意到在标准和疲劳两种条件下，肩部肌肉（特别是 UT）的相对贡献出现了统计学上显著的增量。另一方面，我们注意到前臂肌肉（特别是 FCU）的相对贡献出现了统计学上显著的减量。将这些信息与图 4 中的 RMS 幅值图和平均频率图结合起来，我们可以得出结论：当受试者出现疲劳时，UT 和 FCU 的 sEMG 信号的 RMS 幅值相较于标准状态将分别增加 127% 和 17.2%。然而，两块肌肉的平均频率变化在统计学上并不显著，因此不能断定这两块肌肉都处于疲劳状态。RMS 的变化主要应归因于肌肉力贡献的变化。但我们不建议将 FCU 作为最优指标，因为其 RMS 的变化并不显著。

类似地，我们观察到肩部出现了明显的运动变化。肩部升降运动（elevation-depression）的活动范围从 [16, 20] 度增加至 [20, 30] 度，增幅约为 6 度；而肩部屈伸运动（flexion-extension）的活动范围从 [-10, 0] 度增加至 [0, 20] 度，增幅约为 10 度。两组数据对于捕捉从标准到疲劳状态的转变都具有显著意义。简而言之，我们的研究发现，当疲劳发生时：

• UT 肌肉的相对贡献增加了约 62.5%，UT 肌肉的 sEMG 信号 RMS 幅值增加了 127%。

• 肩关节的运动更为剧烈，包括肩部升降运动和肩部屈伸运动的幅度均有所增加。

从生物力学角度而言，上斜方肌是肩部升降运动的主要驱动肌肉。我们可以将这些发现结合起来，得出结论：中枢神经系统（central nervous system）募集上斜方肌以执行肱二头肌弯举（Bicep Curl）动作，从而导致肩部升降运动幅度过大。基于上述发现，我们可以为在肱二头肌弯举过程中检测疲劳提供以下建议。已知受试者正在执行肱二头肌弯举动作，在不改变负荷并保持恒定活动范围（ROM）的前提下，未来研究可以通过以下方式检测疲劳：

• 采集 UT 肌肉的 sEMG 信号或监测其肌肉力。预计在疲劳发生时可观察到显著的增量；或者

• 采集肩关节运动学的 ROM。预计在疲劳发生时可观察到显著的增量。

## E. 局限性

本研究聚焦于与弯举（Bicep Curls）直接相关的上肢肌肉和关节。直接由本研究拓展而来的未来工作包括利用不同的传感器开发可穿戴传感器以识别患者的状态。相关传感器包括惯性测量单元、摄像头、表面肌电（sEMG）传感器、机械肌图（MMG）传感器以及弯曲传感器 [44]。在实验过程中，我们要求受试者保持站立不动并将动作局限于上肢，以尽量分离其他肌肉的贡献。然而，其他肌肉（例如核心躯干肌肉）也可能参与弯举中的代偿动作。进一步研究这些肌肉在弯举代偿中的作用可能是值得的。此外，未来研究可以利用生物力学建模软件（例如 OpenSim 和 Anybody）来探索不同条件（如速度、握法和负重）下弯举练习的肌肉贡献。另外，肌电传感器非常敏感；其在肌肉上的放置位置尤为关键。鉴于我们提出的可穿戴传感器开发建议（即使用 sEMG 传感器检测 UT 肌肉），由于患者未经过专业培训，很可能放置不当，而本研究并未考虑传感器放置不当对结果的影响。未来研究可以设计可穿戴传感器以减少或研究放置不当带来的影响。

## VI. 结论

本研究考察了无负重、标准以及疲劳三种状态下的肌肉协同关系和关节运动学。与标准阶段相比，本研究的结果显示相对贡献从前臂肌肉向肩部肌肉转移，并且两种协同的激活幅度显著增加。此外，在疲劳状态下，肩关节上检测到了更为明显的运动。本工作为运动科学和康复领域中识别疲劳诱发的肌肉代偿提供了有价值的见解，并为可捕获疲劳阶段的可穿戴传感器开发建立了数值基准。基于本工作的发现，团队正在研究新型基于应变的可穿戴传感器，将其部署于肩部周围，以自动检测弯举时的疲劳诱发性代偿动作。
