## 摘要（中文译文）

> **背景**：康复**外骨骼机器人**正越来越多地被用于上肢（UL）运动的**客观、定量评估**。一套在 **Armeo®Spring** 机器人辅助够取任务中计算得到的**仪器化指标**，已被证明可用于评估上肢功能。本研究的目的是**检验这套基于指标的上肢评估在卒中患者中的结构效度（construct validity）**。
>
> **方法**：纳入 **44 名卒中患者**，年龄 **45–79 岁**，**Wolf 运动功能测试能力分（WMFT-FAS）10–75**、肩与肘的**运动指数（Motricity Index, MI）14–33**，因而覆盖了**很宽的损伤范围**。残余上肢功能由 **WMFT-FAS** 与 **WMFT-TIME** 评估，同时由一套 **9 项数值指标**评估——这些指标衡量**运动准确性（accuracy）、速度（velocity）与平滑度（smoothness）**，从 Armeo®Spring 设备的「**Vertical Capture**」任务中获取的 **3D 末端轨迹**计算得到。为探究哪些变量更能代表运动控制缺陷，使用 **Mann-Whitney U 检验**将患者指标与 **25 名健康人**的指标对比；为探究指标之间的内在关系及其在准确性/速度/平滑度上的结构效度，进行了**因子分析**；为验证**并行效度（concurrent validity）**，将指标与 WMFT-FAS 及 WMFT-TIME 用 **Spearman 相关系数**比较。
>
> **结果**：**7 项指标**在卒中患者与健康对照间有显著差异，**效应量（effect size）范围 0.35–0.74**。因子分析确认**特定的指标子集分属准确性、速度与平滑度三个域**（区分效度）。**1 项准确性指标、2 项速度指标与 2 项平滑度指标**与 WMFT-FAS 及 WMFT-TIME 显著相关（**|rho| = 0.31–0.50**）（并行效度）。**每个运动域各有 1 项指标**被证明具备结构效度（区分与并行），并被选出。此外，这些指标**能够检测出 WMFT 水平相同的患者之间在准确性、速度与/或平滑度上的差异**。
>
> **结论**：所提出的**基于指标的上肢评估可用于整合并支持卒中患者上肢功能的临床评估**。

## 一、方法骨架

```
Armeo®Spring 康复外骨骼（带前臂/手部支撑的 3D 末端执行器）
        │
        ▼
「Vertical Capture」任务（最大难度档，共 4 档中按患者能力选最高可完成档）
   每名受试者练习约 5 分钟后，执行 3 次重复
        │
        ▼
3D 末端轨迹
        │
        ▼
┌──────────────────────────────────────────────────────┐
│  9 项数值指标，分三个运动域：                          │
│    · 准确性（accuracy）                                │
│    · 速度（velocity）                                  │
│    · 平滑度（smoothness）                              │
│  例：NVelPeak（速度峰值个数）、NormJerk（归一化抖动）  │
└──────────────────────────────────────────────────────┘
        │
        ▼
效度检验三条路：
  ① 区分效度：患者 vs 25 名健康人（Mann-Whitney U，效应量）
  ② 结构效度：因子分析（指标是否真的分属三个域）
  ③ 并行效度：与 WMFT-FAS / WMFT-TIME 的 Spearman 相关
```

> 💡 **「最大难度档（但按患者能力选最高可完成档）」是个关键设计细节**：
> 原文明确其目的——**让数据始终代表每名受试者按其残余能力所能达到的最好表现**，
> 从而使不同损伤程度的患者**可以分组并与 WMFT 评估的表现相比较**。
> **这是「难度自适应」以消除天花板/地板效应的做法，我方 D435i 任务设计可直接借鉴。**

## 二、关键定量结果

| 项 | 值 |
|---|---|
| 卒中患者 | **44 名**（**32 男 / 12 女**；年龄 **62 ± 9 岁**，范围 **45–79**） |
| 病因 | **脑缺血 27 例 / 脑出血 17 例** |
| 健康对照 | **25 名** |
| 入组损伤范围 | **WMFT-FAS 10–75**；**MI 14–33**（肩与肘）—— 覆盖**很宽的损伤谱** |
| 任务 | ARMEO®Spring「**Vertical Capture**」，3 次重复，最高可完成难度档 |
| **显著区分患者的指标数** | **7 / 9** |
| **效应量范围** | **0.35 – 0.74** |
| **与临床量表的显著相关** | **1 项准确性 + 2 项速度 + 2 项平滑度**，**|rho| = 0.31 – 0.50** |
| **最终选出指标** | **3 项**（准确性 / 速度 / 平滑度 **各 1 项**） |
| 平滑度指标最佳表现 | **NVelPeak |ES| = 0.74**；**NormJerk |ES| = 0.63**；两者与 WMFT 相关 **rho = 0.50 – 0.56（p < 0.001）** |

### 2.1 对本库最重要的两条结论

1. **「同一 WMFT 水平的患者之间，指标仍能检出准确性/速度/平滑度差异」**
   → **这是本库主张「仪器化指标能提供临床量表给不了的增量信息」的直接证据。**
   临床量表（WMFT-FAS）是**粗粒度的等级评分**，而仪器化指标是**连续量**，可在同一等级内分辨差异。

2. **平滑度指标（NVelPeak / NormJerk）区分能力最强（ES 0.74 / 0.63）**
   → 原文解释：**速度峰值个数反映"子运动（sub-movements）"或"运动单元（movement units）"的存在，平滑度改善时该数下降**。
   → **这是「用平滑度衡量运动控制缺陷」的机理依据**，可直接支撑我方的 `temporal jerk` 类指标。

### 2.2 原文给出的机理解释（可直接引用）

> **NVelPeak（够取运动中的速度峰值个数）** 反映「子运动」或「运动单元」的存在，**当平滑度改善时它趋于减少**。
> 本研究在**三维上肢运动**上，这两项指标对**区分患者与健康人**表现出高能力（|ES| = 0.74 与 0.63），
> 且与临床参考标准呈**统计显著（p < 0.001）的中到大相关（rho = 0.50–0.56）**，
> **在描述卒中患者跨全部指标的表现上给出了最好的结果**。
