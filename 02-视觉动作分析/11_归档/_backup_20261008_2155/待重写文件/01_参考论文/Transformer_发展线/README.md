# Transformer 发展线语料库（双轴：时间阶段 × 技术线程）

> **定位**：为 ViKiT 研究主线提供「Transformer 领域发展线」的可核验依据，用于推演康复领域（重点：上肢腕–肘–肩）可用的后续方向与创新点。
> **工件性质**：本目录是**参考资料库**，不是已完成精读的论文精读库。
> **生成方式**：全部条目由 `06_附录/Transformer语料工具/` 的脚本从 arXiv 官方 API 解析生成，标题相似度 ≥ 0.90 才自动采信。

## 2. 双轴定义

**横轴 · 时间阶段**

| 阶段 | 区间 | 主题 |
|---|---|---|
| `S0` | 奠基期 | 2017-2018（原始架构与通用化） |
| `S1` | 效率与规模化 | 2019-2020（预训练语言模型 + 稀疏/线性注意力） |
| `S2` | 多模态与长序列 | 2021-2022（视觉/语言多模态 + 长上下文外推 + 视频） |
| `S3` | 生成式与效率革命 | 2023（动作生成扩散 + 状态空间模型兴起） |
| `S4` | 具身·世界模型·物理 | 2024-2025（物理约束人体运动 + 世界模型） |
| `S5` | 混合架构与测试时学习 | 2025-2026（线性注意力复兴 + 测试时记忆） |

**纵轴 · 技术线程**

| 线程 | 名称 | 迁移价值「高」的篇数 |
|---|---|---|
| `T1` | 架构与注意力机制 | 2 |
| `T2` | 效率与长序列 | 0 |
| `T3` | 位置编码与长度外推 | 1 |
| `T4` | 视觉·多模态·人体 | 5 |
| `T5` | 动作生成与离散 token | 8 |
| `T6` | 物理约束·世界模型 | 4 |

## 4. 工件类型说明（重要）

| 工件 | 含义 | 是否等同全文翻译 |
|---|---|---|
| `<paper>.pdf` | arXiv 开放获取原文 | — |
| `<paper>_Abstract_Card.md` | **摘要级定位卡**：官方摘要原文 + 人工一句话定位 + 发展线坐标 | ❌ 不是 |
| `<paper>_全文翻译.md` | 全文中文翻译 | ✅ 是（本目录**暂无**此类文件） |

> 本目录的卡片只到摘要级，**不得**在论文或汇报中表述为「已精读/已全文翻译」。

## 5. 证据分级

| 级别 | 含义 | 本目录中的用法 |
|---|---|---|
| **官方一手** | arXiv 官方 API 记录、作者自述原文 | 标题、作者、日期、摘要、分类、期刊参考 |
| **人工判断** | 由本项目编者依据全文/摘要做出的分类与评价 | 阶段归属、线程归属、迁移价值、note |
| **推断** | 尚无实验支撑的前瞻推演 | 康复创新点方向（见 `02_创新点矩阵/`） |
| **未核验** | 第三方转述、媒体说法、无法确认的数字 | **不入库**；确有需要时单列并标注 |

## 7. 复现方式

```bash
cd 06_附录/Transformer语料工具
python3 resolve_corpus.py     # 标题 → arXiv 规范元数据（增量）
python3 download_pdfs.py     # 下载 OA PDF，输出需人工补件清单
python3 gen_cards.py         # 生成摘要级定位卡
python3 build_index.py       # 生成 index.json / README / 各线程 LIST.md
python3 build_page.py        # 生成可视化页面
```
