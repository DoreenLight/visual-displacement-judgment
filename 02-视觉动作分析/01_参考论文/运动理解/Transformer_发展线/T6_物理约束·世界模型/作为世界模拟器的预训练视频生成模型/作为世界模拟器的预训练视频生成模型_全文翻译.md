## 摘要

在大规模互联网数据集上预训练的视频生成模型取得了显著的成功，尤其擅长生成逼真的合成视频。然而，它们通常基于静态提示（例如文本或图像）生成视频片段，这限制了它们对交互式和动态场景建模的能力。在本文中，我们提出了动态世界模拟（Dynamic World Simulation, DWS），这是一种将预训练视频生成模型转化为可执行指定动作轨迹的可控世界模拟器的新方法。为了实现条件动作与生成的视觉变化之间的精确对齐，我们引入了一个轻量级且通用的动作条件模块，该模块能够无缝集成到任何现有模型中。我们证明，构建强大的世界模拟器的关键在于一致的动态转换建模，而非专注于复杂的视觉细节。基于这一洞见，我们进一步引入了一种运动强化损失（motion-reinforced loss），通过迫使模型更有效地捕捉动态变化来增强动作可控性。实验表明，DWS 可以通用地应用于扩散模型和自回归 Transformer 模型，在游戏和机器人领域中生成动作可控、动态一致的视频方面取得了显著改进。此外，为了促进所学世界模拟器在诸如基于模型的强化学习等下游任务中的应用，我们提出了优先想象（prioritized imagination）以提高样本效率，展示了与最先进方法相比具有竞争力的性能。

## 1 引言

近年来，视频生成领域取得了显著进展，诸如 Brooks et al. (2024)、Polyak et al. (2024)、Sharma et al. (2024)、Yang et al. (2024c)、Zheng et al. (2024) 等模型展示了在以各种输入（最显著的是文本和初始帧）为条件时生成高保真度且时间一致性视频的出色能力。然而，这些模型难以支持交互式模拟场景，因为它们是针对带有静态提示的单次生成进行训练的，缺乏帧级交互性和帧间动态建模。为了填补这一空白，学术界和工业界正越来越关注于构建动作条件化的视频模型 Bruce et al. (2024)、Che et al. (2025)、Decart et al. (2024)、Valevski et al. (2024)、Wu et al. (2024)、Xiang et al. (2024)、Yang et al. (2023, 2024a)。

这些基于动作条件的模型实际上充当了交互式环境模拟器（“世界模型”或“世界模拟器”），它们利用先进的 Transformer 或扩散模型架构，根据智能体的动作来预测未来的视觉结果。它们的目标是封装对底层动态转移以及世界运转常识知识的理解，从而实现类似于人类认知过程的动作驱动想象。

这些世界模型开辟了令人兴奋的前景，特别是在基于模型的强化学习（Model-Based Reinforcement Learning，MBRL）中，智能体可以通过与世界模型交互来更高效地学习新技能，从而避免在现实世界试错所带来的风险与成本。

在这项工作中，我们回顾了交互式世界模拟器的最新进展，重点阐述了当前限制其更广泛应用的关键挑战。(i) 这些模型从头开始训练通常需要庞大的计算资源。例如，Genie Bruce et al. (2024) 需要在 256 个 TPUv5p 核心（大致相当于 226 块 NVIDIA A100 GPU）上训练 125k 步，才能学习一个相对简单的平台跳跃（Platformer）游戏模拟器。类似地，GameNGen Valevski et al. (2024) 使用 128 个 TPU-v5e 核心消耗了 700k 步。(ii) 尽管微调预训练视频生成模型提供了一种更高效的替代方案，但现有方法（Rigter et al., 2024, Yu et al., 2025）在本质上依赖于特定架构。由于每种新的模型架构都需要大量的工程适配工作，这给跨不同模型架构调整这些方法以受益于视频生成架构的快速发展带来了挑战。(iii) 与通用视频生成任务不同，动作条件世界模拟器需要精确捕捉细粒度的动态变化（Yang et al., 2023, Zhu et al., 2024），这需要帧级别的动作对齐。这一要求对于基于模型的强化学习应用至关重要，因为在此类应用中，捕捉帧与帧之间的动态/运动变化要优先于建模静态视觉元素（例如背景、物体细节）。

为了应对上述挑战，我们提出了一种新颖的框架——动态世界模拟（Dynamic World Simulation, DWS），这是一种通用的、与架构无关的方法，能够将预训练的视频生成模型高效地转化为世界模拟器。通过利用从互联网规模数据集中学习到的预训练先验，微调后的世界模拟器能够展现出对物理规则和常识性知识的基本理解。然而，它们本质上并不具备交互式模拟的能力，且缺乏用于精确帧级动作条件化的关键机制。DWS 引入了一个极简但功能强大的附加动作条件化模块，在保持架构灵活性的同时提升了帧级动作感知能力。该模块仅由两个线性层组成，可以通过精心设计的缩放和平移操作集成到任何网络架构中。它还加强了预测的视觉变化与条件动作之间的对齐。此外，我们观

察到传统的监督学习损失函数会导致视频模型均匀地关注所有视觉元素和复杂细节，包括静态背景和无关细节，从而削弱了它们捕获对构建世界模拟器至关重要的帧间动态/运动变化的能力。DWS 提出了一种运动增强损失来应对动态建模的挑战，这是一种简单而有效的方法，可以在训练期间显式地优先建模帧间变化，从而显著提高时间一致性并实现更可靠的动态预测。如图 1 所示，DWS 学习到的世界模拟器可以与不同领域的多种策略进行交互，同时保持准确的动态预测和动作响应性。最后，为了增强世界模拟器在基于模型的强化学习中的实用价值，我们引入了优先想象（prioritized imagination），这是一种新颖的采样策略，它专注于最具信息量的状态转移，而不是将计算资源浪费在已被充分理解的状态转移上，从而提高了智能体与世界模型交互过程中的样本效率。

我们将本文的贡献总结如下：(i) 我们提出了 DWS，这是一个新颖且与架构无关的框架，它利用预训练先验知识进行物理规律扎根（physics grounding），能以较低的训练成本有效地将预训练视频生成模型转换为世界模拟器（world simulators）。(ii) 我们引入了两种简单而有效的技术：一种是轻量级的动作条件模块，可实现精确的帧级控制并提高动作遵循能力；另一种是运动强化训练（motion-reinforced training），它将模型的注意力从静态视觉细节重定向到由动作引起的动态变化上，从而提高时间与动态一致性。(iii) 我们通过优先想象（prioritized imagination）提升了世界模拟器在基于模型的强化学习（model-based reinforcement learning, MBRL）中的实用价值，在将训练好的世界模拟器应用于下游基于模型的 RL 时，提高了样本效率和策略性能。(iv) 通过在具有挑战性的游戏和机器人任务中进行的全面评估，我们证明了 DWS 显著提高了生成的动作条件视频的质量和动态一致性。与先前的最新 MBRL 方法（Alonso et al., 2024, Hafner et al., 2023）相比，我们结合优先想象且经由 DWS 训练的世界模拟器还实现了更高效、更有效的学习。

## 2 相关工作

视频世界模型（Video World Models）。随着互联网规模数据集（Bain et al., 2021, Chen et al., 2024）和先进模型架构（Brooks et al., 2024, Peebles and Xie, 2023）的发展，以文本描述和初始帧为条件的逼真视频生成取得了显著进展（Blattmann et al., 2023, Lin et al., 2024, Ma et al., 2024, Yang et al., 2024c, Zheng et al., 2024）。在此基础上，当前的研究越来越聚焦于动作可控的视频生成，旨在开发能够有效建模物理动力学和动作后果的通用世界模拟器（Bruce et al., 2024, Che et al., 2025, Feng et al., 2024, Parker-Holder et al., 2024, Valevski et al., 2024, Xiang et al., 2024, Yang et al., 2023, Zhu et al., 2024）。然而，这些模型通常需要在海量数据集上从头开始训练，并涉及数百万（或数十亿）参数，从而导致巨大的计算开销和缓慢的推理速度。与之相反，我们提出将公开可用的预训练视频生成模型（Wu et al., 2024, Zheng et al., 2024）适配为动作驱动的世界模拟器。我们提出的微调方法 DWS 实现了高效的模型适配，同时仅需极小的计算开销，大幅降低了训练成本和推理延迟。同期工作（Rigter et al., 2024, Yu et al., 2025）也探索了利用预训练模型进行动作条件视频生成。然而，他们的研究局限于基于扩散的模型，且两项工作均未验证其方法在促进下游任务（例如基于模型的强化学习，model-based RL）方面的有效性。

基于模型的强化学习（Model-Based RL） 基于模型的强化学习旨在构建世界模型，使得试错过程可以在无需实际成本的情况下进行。凭借足够精确的世界模型，智能体能够发展出想象能力，从而模拟交互并生成合成经验数据。随后，这些模拟数据可用于为各种决策任务学习最优策略，从而有效减少对真实世界交互的需求。Sutton (1991) 提出了基于模型的强化学习的首个通用框架，强调了估计的动力学模型在促进价值函数和策略训练方面的效用 (Sutton and Barto, 1998)。近年来，用于学习复杂环境动力学（如视频游戏和视觉控制任务）的基于模型的方法取得了显著进展，其表现始终优于对应的无模型（model-free）方法。例如，基于显式解耦环境动力学中确定性与随机性成分的循环状态空间模型（Recurrent State Space Models, RSSM）(Hafner et al., 2019)，Dreamer 系列在包括 Atari 游戏 (Machado et al., 2018)、DeepMind Control Suite (Tassa et al., 2018) 以及 Minecraft 在内的多个领域均展示了令人瞩目的性能。为了解决 RNN 在表达复杂模式方面的局限性，近期的研究探索了利用 Transformer 模型来增强序列建模和长期依赖捕获能力 (Micheli et al., 2023a, Robine et al., 2023, Zhang et al., 2023, 2024)，并引入扩散模型（diffusion models）以在动力学学习中更好地表征多模态分布 (Alonso et al., 2024, Ding et al., 2024)。然而，尽管这些工作也采用了 Transformer 或扩散模型进行世界模型学习，但它们主要依赖于从头训练（training from scratch），未能利用预训练知识来增强对动力学的理解，导致它们过度针对特定任务，限制了在多样化任务间的泛化能力。此外，现有方法在训练期间对所有想象样本均一视同仁，而我们提出的 DWS 则引入了一种新颖的优先级机制，能够有选择地聚焦于重要样本，从而提升了样本效率。

## 3 预备知识

## 3.1 问题形式化

条件视频生成框架可适用于实例化世界模拟器（或世界模型）（Yang et al., 2023）。世界模型将某种动作作为输入，并输出该动作所产生的视觉结果，旨在对环境进行模拟。该环境可表示为部分可观测马尔可夫决策过程（POMDP），封装于元组 $( S , \mathcal { O } , \phi , \mathcal { A } , p , r , \gamma )$ 中。此处，$S$ 为状态空间，$\mathcal{O}$ 为仅提供 $S$ 的不完全信息的观测空间。在每个时间步 $t ,$ 智能体根据策略 $\pi : \mathcal { O }  \Delta _ { \mathcal { A } } ,$ 选择动作 $a _ { t }$，环境根据动态特性更新状态 $s _ { t + 1 } \sim p ( s _ { t + 1 } | s _ { t } , a + t )$，接收到下一个观测 $o _ { t + 1 } = \phi ( s _ { t + 1 } )$，并计算出标量奖励 $r _ { t }$ 为 $R ( s _ { t } , a _ { t } , s _ { t + 1 } )$。智能体的目标是通过最大化 $\gamma$ 折扣累积奖励来学习策略 $\begin{array} { r } { \pi ^ { * } = \arg \operatorname* { m a x } _ { \pi } \mathbb { E } _ { a _ { t } \sim \pi } \big [ \sum _ { t = 0 } ^ { \infty } \gamma ^ { t } r _ { t } \big ] } \end{array}$。

训练良好的世界模型可以替代环境与智能体进行交互，从而通过提供无限经验来有益于下游策略学习。具体而言，给定历史观测 ${ \mathit { o } } _ { T _ { 0 } } ,$ 在每个时间步 $t = T _ { 0 } , \cdots , T - 1$，智能体根据其策略和先前想象的观测采取动作 $a _ { t }$，随后世界模型预测转移 $p ( o _ { t + 1 } , r _ { t + 1 } | o _ { t } , a _ { t } )$ 反馈给智能体。

## 3.2 预训练视频生成模型

通过将用于视觉控制的世界模型学习形式化为交互式视频生成问题，我们可以充分利用广泛可用的视频数据，这些数据蕴含着可在不同领域间泛化的广泛知识（Yang et al., 2024b）。视频数据不仅包含语义视觉细节，还包括捕捉物理世界动态规则的运动变化。然而，在互联网规模的视频数据集上从头训练此类视频世界模型是昂贵且耗时的。我们提出对预训练的先进视频模型进行微调，以使其能够模拟交互。具体而言，我们采用两种不同的预训练视频生成模型作为我们的基础模型，即扩散模型 Open-Sora（Zheng et al., 2024）和自回归 Transformer 模型 iVideoGPT（Wu et al., 2024）。Open-Sora 是一种基于整流流（rectified flow）的扩散模型，完全开源且在数百万个互联网视频上进行了预训练。我们考虑使用它是因为得益于流匹配（flow-matching）训练，它只需要极少的采样步数。近期一项名为 iVideoGPT 的工作是一个基于 LLaMA（Touvron et al., 2023）架构构建的自回归 Transformer。它将来自不同模态（例如，包括视觉结果、动作和奖励）的训练数据压缩为一个 token 序列，用于交互式视频预测。

## 4 方法

在本节中，我们首先在 §4.1 中介绍我们提出的动作条件模块（action-conditioned module），并在 §4.2 中介绍用于增强动力学建模的运动强化损失（motion-reinforced loss）。在展示了将通用视频生成模型微调为世界模拟器的方法之后，我们在 §4.3 中介绍了用于提升基于模型的强化学习性能的优先级想象（prioritized imagination）技术。

## 4.1 动作条件模块

近期的视频生成模型在根据条件文本提示词（text prompts）或初始帧生成逼真视频方面取得了显著成功。这些文本到视频任务在运行时采用静态提示词，全局性地描述整个视频，而未指明后续帧具体应为何内容。这种设计范式虽然对通用视频生成行之有效，但在将其改造为旨在模拟动作丰富型交互的世界模型（world models）时，面临着根本性的挑战，因为后者的条件是帧级（frame-level）、细粒度的动作轨迹。为了满足这一需求并确保生成的每一帧都与轨迹中对应的动作相匹配，我们利用了一个动作条件模块，通过每一帧所对应的动作分别对该帧的生成进行条件化控制。与以往将整个动作轨迹压缩为单一嵌入的文本到视频模型不同，我们的方法类似于 IRASim (Zhu et al., 2024)，实现了一种更细粒度的动作编码机制。我们在每个 Transformer 块内引入了一个由两个线性层组成的轻量级附加模块，用于分别对各个动作进行独立编码。这种设计确保了每一帧的内容都直接受到其对应动作的调制，而不是受全局描述的引导，从而建立了动作与生成帧之间的直接对应关系。

动作表征。将视频生成模型应用于基于动作的控制时，一个关键挑战在于动作的表征。在离散动作空间中，动作通常表示为整数值，缺乏传统文本到视频模型中使用的文本提示词所具备的丰富语义上下文。这种语义鸿沟可能会限制模型有效理解和响应不同动作的能力。为了弥合这一鸿沟，我们提出使用描述动作含义的语言模板来表征动作。具体而言，给定一个动作轨迹 $y = \{ a _ { t } , a _ { t + 1 } , \cdot \cdot \cdot , a _ { t + H - 1 } \}$，其中 H 为轨迹的时间跨度（horizon），我们构建了一个映射函数 ψ，将抽象的动作整数转换为有意义的语言，即 $\psi : { \mathcal { A } }  L ,$，其中 L 为语言空间。该映射使我们能够利用预训练视频生成模型中的文本编码器来获取丰富的特征嵌入 $c \in \mathbb { R } ^ { n _ { H } \times n _ { d } }$，其中 $n _ { H }$ 和 $n _ { d }$ 分别表示时间跨度和每个 token 的维度。对于连续动作空间，遵循 Wu et al. (2024)、Zhu et al. (2024) 的方法，我们使用一个可训练的线性动作嵌入器直接生成特征嵌入 c，无需进行语言转换。

帧级条件（Frame-Level Condition）。在视频生成模型用作世界模拟器的背景下，精确的时间控制至关重要，因为每个动作都应直接调节其后续帧的视觉内容。为了显式建模并增强这种动作-帧对应关系，我们受 IRASim (Zhu et al., 2024) 的启发，在每个 transformer 块中集成了一个帧级动作条件模块（frame-level action-conditioning module）。尽管 IRASim 的实现局限于具有时空 transformer 架构的特定扩散模型，但我们通过开发一个通用的附加模块显著扩展了这一概念，该模块可泛化到不同的模型架构中，包括基于扩散（diffusion-based）和基于 transformer（transformer-based）的框架。因此，我们的设计提供了更高的架构灵活性和更广泛的适用性。我们仅用两个线性层实现的极简架构，以极小的计算开销实现了轻量化集成和高效微调。

具体而言，对于每个视频嵌入 $x \in \mathbb { R } ^ { T \times C \times H \times W }$，在将其输入 transformer 块之前，我们按如下方式进行处理：

$$
x ^ {i} = x ^ {i} + \mathrm{FFN} (\mathrm{LayerNorm} (x ^ {i}) \times (1 + \alpha^ {i}) + \beta^ {i}),\tag{1}
$$

其中 $\alpha ^ { i }$ 和 $\beta ^ { i }$ 表示第 $i$ 帧的缩放和位移参数。它们由动作嵌入 $c ^ { i }$ 回归得到。我们在图 2 中展示了所提出的模块，该模块可以无缝集成到任何网络块（例如，注意力块）中。

## 4.2 运动强化损失（Motion-Reinforced Loss）

传统的视频生成模型通常采用平方 $l _ { 2 }$ 距离（用于连续空间中的整流流 (rectified flow) (Liu et al., 2022, Zheng et al., 2024)）或交叉熵损失（用于离散空间中的下一个标记预测 (next-token-prediction) transformer (Vaswani et al., 2017, Wu et al., 2024)）作为其训练目标。虽然这些训练目标在通用视频生成任务中表现出有效性 (Brooks et al., 2024, Lin et al., 2024, Tian et al., 2024, Yan et al., 2021, Zheng et al., 2024)，但它们通常同等地对待每个像素，这可能会削弱模型捕获依赖于动作的状态变化的能力。因此，它们难以有效地充当强化学习（RL）智能体的世界模拟器，因为对于学习而言，准确建模动

为了解决这一问题并实现更精确的动力学建模，我们引入了一种新的运动增强损失（motion-reinforced loss），以提高视频模型的动作依从能力。在每个训练步骤中，我们随机采样一批真实视频嵌入 $\boldsymbol { x } = \{ x ^ { 0 } , \cdot \cdot \cdot , x ^ { k } , \cdot \cdot \cdot , x ^ { j } , x ^ { H - 1 } \}$，其中 $H$ 表示视频剪辑的时间跨度（horizon）。然后，我们计算连续帧之间的差异 $\omega = \cup _ { i = 0 } ^ { H - 1 } \omega _ { i }$，表示为

$$
\omega_ {i + 1} = c ^ {\mathrm{Softmax} (| x _ {i + 1} - x _ {i} |)},\tag{2}
$$

其中 $\omega _ { i } ~  ~ [ 1 , c ]$，对于初始帧 $x ^ { 0 }$，由于其作为条件帧，我们设置 $\omega _ { 0 } ~ = ~ 1$。在此，$c$ 表示调节运动增强强度的超参数。在获得 $\omega$ 之后，我们将其作为逐像素权重集成到监督训练损失中。由此得到的运动增强损失函数可表示为：

$$
\mathcal {L} _ {\mathrm{motion}} = \mathcal {L} _ {\mathrm{prev}} * \omega ,\tag{3}
$$

其中 $\mathcal { L } _ { \mathrm { p r e v } }$ 表示在扩散模型（diffusion models）中使用的原始 MSE 损失，或在基于 Transformer 的架构中使用的交叉熵损失函数。我们在附录 B.2（Appendix B.2）中包含了更多实现细节。通过该公式，帧间发生变化的像素将在损失反向传播中产生更大的影响。这些像素通常对应于视频中与运动相关的元素，它们经历着持续的变化，而保持稳定的背景在训练期间的影响则较小。该机制从本质上减弱了对动作条件预测贡献极小的静态背景元素的影响。

因此，通过 ${ \mathcal { L } } _ { \mathrm { m o t i o n } }$ 微调的视频生成模型将更加关注动态/运动预测，而不是难以学习的复杂视觉细节。此外，对于世界模拟器而言，动态/运动一致性比静态背景细节更为重要，因为模拟器需要根据动作来预测视觉结果。

## 4.3 基于模型的强化学习

基于从预训练视频生成模型微调得到的基于视频的世界模拟器，最有前景的应用之一是将它们用作基于模型的强化学习（Model-Based Reinforcement Learning，MBRL）中策略学习的世界模型。在 MBRL 中，智能体通过与训练好的世界模型进行交互来优化策略以最大化累积奖励，从而提高样本效率。

为了在 MBRL 中实现有效的策略训练，世界模型应同时预测状态转移动态和奖励。我们现在通过一个奖励预测模型来完善我们的世界模型。由于估计奖励是一个标量预测问题，我们引入了一个由线性层、自注意力块和交叉注意力块组成的独立模型 $R _ { \psi }$，以在给定历史观测和动作的情况下来估计奖励。RL 智能体包含一个 Actor-Critic 网络，该网络由一个共享的 CNN 主干参数化，并分支为独立的策略头和价值头。基于 MBPO 框架 (Janner et al., 2019b, Wu et al., 2024)，我们通过合成预演（synthetic rollouts）来扩充经验回放池（replay buffer），以训练标准的 Actor-Critic RL 算法。我们采用 PPO (Schulman et al., 2017) 作为基础算法，并遵循 Huang et al. (2022) 进行实现。我们在附录 B.3 中提供了更多实现细节。

优先想象（Prioritized Imagination）。基于世界模型的想象需要从初始观测出发，这些初始观测是从与环境交互收集的经验中采样的。这些初始状态作为世界模型生成合成轨迹的起点。先前的 MBRL 方法（Alonso et al., 2024, Hafner et al., 2020a,b, 2023, Micheli et al., 2023b）采用均匀采样初始观测来进行想象。然而，这种策略忽略了不同状态对策略学习重要性的差异，从而导致学习效率低下。我们强调，源自不同初始观测的想象转移在 MBRL 策略优化的重要性和任务相关性方面表现出显著的异质性。为了更好地释放微调后视频生成模型的世界模拟能力，我们提出了一种优先想象方法，选择性地聚焦于更有价值的转移。我们的核心见解是，导致具有更高学习潜力和可学习性转移的初始观测应当被更频繁地采样。我们维护一个缓冲区 $B$ 来存储与环境交互过程中遇到的观测，并优先考虑具有高预期学习进展的初始观测，该进展通过其 TD 损失（TD loss）的量级来衡量。这种优先级机制通过将想象资源集中在对策略学习贡献更大的状态上，确保了对世界模型更高效的利用。整体伪代码如 Algorithm 1 所示。

## 5.2 基于模型的强化学习

为了验证经 DWS 微调的模型在世界模拟器中的实际效用，我们通过将其用作 MBRL（基于模型的强化学习）策略学习中的世界模型来评估其性能。

基准与基线（Benchmarks and Baselines）。我们在 Procgen 基准中的 CoinRun 和 Ninja 平台跳跃类游戏，以及 Atari 基准中的 Breakout 和 Battle Zone 游戏上进行了实验。这些环境采用 RGB 图像作为观测，并使用离散动作进行控制。Procgen 采用 15 维动作空间，Breakout 在 4 维空间下运行，而 Battle Zone 则使用 18 维动作空间。我们将提出的结合优先想象（prioritized imagination）的 MBRL 方法与以下基线进行了对比：1) PPO (Schulman et al., 2017) 是一种被广泛使用的无模型强化学习（Model-Free RL）方法。我们的方法建立在 PPO 之上。2) Dreamerv3 (Hafner et al., 2023) 是一种 SOTA 基于模型的强化学习（Model-Based RL）方法，它采用循环网络进行动力学预测，并采用 Actor-Critic RL 进行策略学习，能有效处理具有离散动作空间的环境任务。对于 Procgen 环境，我们额外引入了 PPG (Cobbe et al., 2021) 作为对比，因为它是 Procgen 上极具竞争力的算法。

结果分析（Results Analysis）。图 6（Fig. 6）展示的实验结果表明，我们通过 DWS 训练的世界模型在与简单的 PPO 算法结合时，显著优于原生 PPO 以及最先进的基于模型的强化学习方法（即 Dreamerv3）。在 Procgen 环境中，DWS 相比于 PPO 和 PPG 等无模型方法展现出了大幅度的性能提升。尽管由于 Procgen 固有的在不同回合间背景和物体细节的变化，DWS 训练的世界模型在 MBRL 策略训练期间需要进行微调，但与现有的基于模型的方法相比，它仍然保持了具有竞争力的性能。在 Atari 环境中，DWS 展现出了相比现有方法的实质性性能提升，这归因于其世界模型已经获得了用于动作模拟的全面动力学知识。具体而言，在 Breakout 中，DWS 相比 SOTA 方法实现了惊人的 7 倍性能提升。这种优越的性能，尤其是在样本效率方面的提升，可以归功于我们提出的优先想象技术。我们通过在 Procgen 环境上进行的消融实验验证了这一贡献，结果如图 7（Figure 7）所示。

## 6 结论与局限性

在本文中，我们提出了 DWS，这是一种新颖的方法，通过利用预训练视频生成模型从大规模数据集中学习到的丰富先验知识，将其高效适配为世界模拟器，用于下游的动作条件模拟。我们的框架引入了一个轻量级的动作条件模块，该模块实现了动作与帧的对齐，并且可以无缝集成到各种模型架构中；同时还引入了一种运动强化损失，专门用于建模对精确世界模拟至关重要的帧间像素动态。大量的实验结果表明，DWS 显著提高了视频预测质量和 MBRL 性能，带来了有意义的应用。然而，DWS 目前在建模具有长时域或高空间分辨率的视频方面存在局限性。我们将其留待未来工作中解决。

## A 数据集收集细节

## A.1 Atari

在我们针对两款 Atari 游戏——Breakout 和 Battle Zone 的实验中，我们使用了一个经典的 Atari 基线模型——深度 Q 学习（Deep Q-Learning，DQN）智能体（Mnih et al., 2013）来收集用于微调的离线数据集。具体而言，我们采用了 https://github.com/vwxyzjn/cleanrl 提供的开源 DQN 实现，训练智能体进行 100 万个环境步（environment steps），并将经验回放缓冲区（replay buffer）保存为离线数据集。由于我们的工作重点在于开发更精确的世界模型，我们在初始化这两个游戏环境时特意没有启用随机粘滞动作（sticky actions）。这确保了所收集的轨迹能够准确捕捉环境的真实状态转移。此外，我们通过应用跳帧步数为 4 的 FrameSkipping 包装器以及 ResizingObservation 包装器来处理初始化后的环境，该包装器将输出的 RGB 观测尺寸调整为 (84, 84) 的分辨率，以用于 DQN 智能体的训练。在 DQN 的超参数方面，我们遵循了 https://github.com/vwxyzjn/cleanrl/blob/master/cleanrl/dqn\_atari.py 提供的默认设置。

## A.2 Procgen

按照与 Atari 收集实验类似的方法，我们从两款 Procgen 游戏（Coinrun 和 Ninja）中收集了回放数据集。数据收集过程使用了公开可用的近端策略优化（Proximal Policy Optimization，PPO）实现（Huang et al., 2022），可通过 https://github.com/vwxyzjn/cleanrl/blob/master/cleanrl/ppo\_procgen.py 获取。对于每款游戏，我们在 Procgen 默认的 64 × 64 像素分辨率下收集了 100 万次状态转移，用于 DWS 训练。

## B 实现细节

## B.1 基础模型细节

Open-Sora。Open-Sora 基于 rectified-flow (Liu et al., 2022) 和时空 Transformer (Chen et al., 2023, Ma et al., 2024) 架构，是一种以文本和帧为条件的视频生成模型。在我们对 DWS 的实现中，我们使用 Open-Sora 1.2 版本作为基础模型。为了与原始架构保持一致，我们采用了 Open-Sora 库中提供的相同变分自编码器（Variational Autoencoder, VAE）。然而，为了优化计算效率，我们采用 T5-small 进行文本编码，而不是原始的文本编码器。鉴于原始 Open-Sora 模型包含 11 亿参数，这给推理和下游应用带来了显著的计算限制，我们策略性地仅使用 Open-Sora 架构的前 12 层来初始化我们的模型。这一修改在保留基本生成能力的同时，大幅减少了模型的计算开销。我们提出的动作条件模块被集成到 Open-Sora 的每一层中，以提高动作-帧对齐能力。

iVideoGPT。iVideoGPT 是一种基于自回归 Transformer 的架构，构建在 LLaMA 架构（Touvron et al., 2023）之上。该模型通过整合专门的奖励预测头层来扩展基础架构，使其能够同时执行视频生成和奖励估计任务。iVideoGPT 的一个显著特点是其上下文感知分词器（tokenizer），它通过压缩分词实现高效的视频预测。我们使用来自 https://huggingface.co/thuml/ivideogpt-oxe-64-act-free 的权重初始化模型，包括一个

114M 大小的分词器和一个 138M 大小的 Transformer。我们提出的动作条件模块被集成到每个 Transformer 块中。

## B.2 运动增强损失的实现

对于使用平方 $l _ { 2 }$ 距离计算损失函数并进行梯度更新的基于扩散的模型，其原始损失函数可以表示如下：

$$
\mathcal {L} _ {\mathrm{prev}} = \mathbb {E} [ \| g - p _ {\theta} (x _ {t}, t, y) \| _ {2} ^ {2} ],\tag{4}
$$

其中 $y$ 为条件，$g$ 表示要估计的目标信号，根据模型架构的不同采取不同的形式：对于 DDPM 风格的扩散模型（Ho et al., 2020），它对应于真实噪声（ground-truth noise），而对于基于流匹配（flow-matching）的模型（Liu et al., 2022），它表示速度。鉴于 $p _ { \theta }$ 的输出与视频嵌入 $x _ { t }$ 具有相同的维度，因此我们可以将基于运动的权重 $\omega$ 纳入 $\mathcal { L } _ { \mathrm { p r e v } }$ 中，如下所示：

$$
\mathcal {L} _ {\mathrm{motion}} = \mathbb {E} [ \omega \| g - p _ {\theta} (x _ {t}, t, y) \| _ {2} ^ {2} ].\tag{5}
$$

对于使用交叉熵损失进行训练的基于自回归 Transformer 的模型，其原始损失函数可以表示如下：

$$
\mathcal {L} _ {\mathrm{prev}} = - \sum_ {i = t} ^ {L} \log p (x _ {i} | x _ {<   i}),\tag{6}
$$

其中 $x _ { i }$ 表示嵌入在 Transformer 中的离散 token，$L$ 为序列长度。在这种情况下，我们按如下方式计算 $\omega$：

$$
\omega_ {i + 1} = c ^ {\mathbb {I} (x _ {i + 1} = x _ {i})},\tag{7}
$$

其中 $c = e$，且 $\mathbb{I}$ 表示指示函数。因此，我们获得了基于 Transformer 模型最终的 $\mathcal {L} _ {\mathrm{motion}}$：

$$
\mathcal {L} _ {\mathrm{motion}} = - \sum_ {i = t} ^ {L} \omega \log p (x _ {i} | x _ {<   i}),\tag{8}
$$

## B.3 MBRL 算法的实现

我们在 MBPO 框架（Janner et al., 2019a; Wu et al., 2024）内，使用经 DWS 训练的世界模型开发了一个简单的基于模型的强化学习（Model-Based RL, MBRL）算法，并以 PPO（Schulman et al., 2017）作为基础 Actor-Critic RL 算法。我们在算法 1 中提供了伪代码。针对 Procgen 环境，我们的代码基于 https://github.com/vwxyzjn/cleanrl/blob/master/cleanrl/ppo\_procgen.py 的实现构建；针对 Atari 环境，基于 https://github.com/vwxyzjn/cleanrl/blob/master/cleanrl/ppo\_atari.py 构建，并在 Actor-Critic 学习中使用相同的超参数和架构。MBRL 特有的超参数列于表 4 中。遵循 Dreamerv3（Hafner et al., 2023），我们使用 symlog 变换进行奖励预测。
