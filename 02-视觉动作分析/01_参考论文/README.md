## 一、为什么是三分法

研究主线是「**运动理解 → 康复辅助 → 两者结合**」。三分法按这个主线切分，
而不是按年份、期刊或取件批次切分——这样从任一缺口回溯证据时，
证据一定落在同一层的同一线程里。

| 组 | 回答的问题 | 与研究主线的对应 |
|---|---|---|
| [`运动理解/`](运动理解/) | 怎么从图像/信号里读出运动学与肌肉状态 | 看懂 |
| [`康复辅助/`](康复辅助/) | 怎么用这些读数决定辅助、挑战与反馈 | 帮到 |
| [`整合系统/`](整合系统/) | 两段之间缺什么接口、决策模型与桥接方法 | 接上 |

**边界纪律**：`整合系统/` 里的语料不是「另两类」的边角料，而是**跨两段的接口与裁定依据**。
例如 `生物力学线` 既是视觉运动学的验证方法学（B1），也是肌骨动力学（B2）与上肢代偿临床评估（B3）——
把它放进任何单一组都会失真。

## 七、口径纪律

1. **本文件的 PDF/XML 数字是 2026-10-08 的磁盘复算快照**，仅供导航定位。
   全库权威计数以 `bash ../06_附录/自检脚本/verify_kb.sh` 的「附加统计」块为准
   （其中语料二/三/四与康复整合链路各自独立口径，**不可相加**）。
2. **本文件不含任何方法学结论**。语料线的口径表、证据等级、已知限制一律以各语料
   自己的 `README.md` 为准，本文件不复制、不转述，避免出现第二份规范原文。
3. 语料线之间有重叠条目时，以**条目主归属线**为准，不在本目录做去重裁决；
   去重口径见 [`../11_归档/归档机制.md`](../11_归档/归档机制.md)。
4. 移动本目录任一子目录，必须同批更新 `verify_kb.sh` 的路径常量与全库引用，
   否则 Case 1（相对链接）与 Case 6.5（计数块）会 FAIL。
