# 何时采取行动：用于辅助机器人中可靠人类意图预测的校准置信度

Johannes A. Gaus<sup>1</sup>, Winfried Ilg<sup>1†</sup> 和 Daniel Haeufle<sup>1†</sup>

摘要— 辅助设备在提供支持之前，必须同时确定用户的意图以及该预测的可靠程度。我们提出了一种基于校准概率的安全关键触发框架，用于日常生活活动（Activities of Daily Living, ADL）中的多模态下一步动作预测。模型的原始置信度往往无法反映真实的正确率，从而带来安全风险。事后校准（Post-hoc calibration）将预测置信度与经验可靠性对齐，在不影响准确率的前提下将错误校准程度降低约一个数量级。校准后的置信度驱动一个简单的执行/保持（ACT/HOLD）规则，该规则仅在可靠性高时采取行动，否则暂缓辅助。这使得置信度阈值转变为辅助动作的定量安全参数，并在辅助控制回路中实现了可验证的行为。

## I. 引言

错误的辅助可能比没有辅助更糟糕。在辅助机器人领域，预测系统不仅必须决定用户的意图是什么，还必须决定该预测何时足够可靠以触发支持。这在日常生活活动（ADL）中尤为关键，因为错误的辅助可能会使混淆用户、加重症状，甚至在最坏的情况下导致伤害。例如，将不自主的震颤误判为伸手意图可能会错误地激活运动辅助，从而使用户失去平衡。现代深度网络输出的 softmax 概率通常被解释为置信度，然而这些数值往往与真实的正确概率不一致 [1]。这种错误校准意味着数值上的高置信度并不一定代表高可靠性，当置信度被直接用于驱动执行机构时就会产生安全风险。因此，ACT/HOLD 门控必须考虑人体生理约束，区分有目的的运动与诸如共济失调或震颤等病理性信号固有的不可预测性。

在本研究中，意图（intention）指的是短视界、动词级别的动作，例如伸手、抓取、倾倒或切割。该模型基于短暂的多模态观察窗口，预测将在接下来的数百毫秒内开始的下一个有意义的动作。这种抽象层次介于长期任务目标与底层运动预测之间，并与 iAssistADL 设备 [2] 所使用的辅助原语直接对应。动词级别的意图也是触发辅助的合适粒度，因为该设备是在这一级别而非细粒度运动或高层任务尺度上执行支持方案。该设备旨在抑制震颤或共济失调等病症患者的病理性运动，同时保留其预期的自主运动。为了安全地实现这一点，它必须检测用户何时正在发起有目的的动作，并避免在不自主或不稳定的运动期间进行干预。在许多必须在不确定性下决定何时干预的辅助系统和共享控制系统中，也存在类似的要求。

因此，需要一个具备置信度感知能力的意图预测器，它能够在不确定性较高时弃权，并在置信度值得信赖时迅速采取行动。我们将此构建为一个选择性预测问题，其中模型同时输出标签和校准后的置信度，并且下游的 ACT/HOLD 门控在辅助覆盖率与可靠性之间进行权衡 [3]。

自我中心 ADL 数据集（如 EGTEA Gaze+）将第一人称视频与注视点及手部线索相结合，从而能够在动作发生前预测下一个动作 [4]。先前的研究提高了准确性和时序建模能力，但预测概率的可靠性及其在显式辅助决策规则中的应用仍未得到充分探索。由于神经网络往往过于自信，未校准的分数可能会触发非预期的辅助。校准通过使预测置信度与经验正确性保持一致来解决这一问题。Figure 1 总结了所构建的校准辅助流程。我们通过预测用户的下一个动作，并结合支持安全决策的校准不确定性度量，填补了可靠辅助触发方面的这一空白。

**贡献。** 我们提出了一个由多模态 GRU、事后校准（post-hoc calibration）和基于迟滞的安全门控组成的轻量级流水线。首先，我们表明像温度缩放（Temperature Scaling）、Platt 缩放（Platt Scaling）和等度回归（Isotonic Regression）等标准校准方法，在不牺牲准确率的情况下，将 EGTEA Gaze+ 上的预期校准误差（Expected Calibration Error, ECE）从 $\approx ~ 0 . 4 0$ 降低到 0.04。其次，我们利用这一校准信号驱动面向安全的 ACT/HOLD（执行/保持）控制器，将置信度阈值转化为可解释、可调节的安全参数。最后，我们验证了该流水线对模态缺失具有鲁棒性，并满足 iAssistADL 控制回路的实时性约束，弥合了辅助机器人学中概率感知与可验证安全性之间的鸿沟。

## II. 相关工作

a) ADL 中的意图与下一步动作预测：理解用户的意图以及该意图何时可付诸行动，是辅助人机交互中的一个核心问题。近期的综述回顾了跨不同领域和任务的动作预测深度学习技术 [5]。第一人称（Egocentric）ADL 数据集将第一人称视频与注视和手部线索相结合，从而能够在动作发生之前预测即将进行的动作。EGTEA Gaze+ 在自然厨房场景中提供了同步的注视、手部和动作标注 [4]，而像 EPIC-Kitchens 及其预测挑战赛等大规模语料库则将这一范式扩展到了更广泛的环境中 [6], [7]。先前的工作使用基于循环神经网络和 Transformer 的模型来捕捉时间上下文 [8], [9]。人-物交互中的互补方法（如 HOIMotion）侧重于利用第一人称物体信息预测人体运动 [10]。然而，大多数研究关注准确率或预测延迟，并隐式地将网络得分视为已校准的概率。少数工作显式地对不确定性进行建模，或在为第一人称预测设计损失函数和评估指标时加以利用 [11], [12]，但它们均未研究将校准后的置信度作为辅助触发的安全信号。

b) 不确定性、校准与选择性预测：深度网络通常存在过度自信的问题，当其评分在安全关键系统中触发动作时，这种过度自信是极其危险的 [1]。关于不确定性的研究将来自数据模糊性的偶然不确定性（aleatoric uncertainty）与源于训练覆盖范围有限的认知不确定性（epistemic uncertainty）区分开来 [13], [14]，并提出了诸如蒙特卡洛（Monte Carlo, MC）Dropout、深度集成（deep ensembles）以及轻量级事后校准方案等工具 [1], [15], [16]。选择性预测（selective prediction）通过置信度阈值在覆盖率与准确率之间进行权衡，从而形式化了对不确定输入的弃权决策 [3], [17]。选择性预测已在可穿戴设备和人类活动识别中得到探索 [18]，但在辅助机器人领域的应用仍然有限。共享控制需要可靠的意图估计 [19], [20]，然而用于辅助触发的置信度校准仍未被探索。我们的工作通过将校准后的置信度估计与定量安全保证相结合，填补了这一空白，以实现安全的辅助触发。

## III. 方法

a) 目标：给定动作发生前的一段简短的多模态时间窗口，我们预测下一个动作，并为具备安全意识的“执行/保持（ACT/HOLD）”决策提供可靠的置信度信号。该流水线专为实时运行而设计，由嵌入式友好的时序编码器、事后概率校准以及置信度门控组成。

b) 输入与编码器：我们在提取的 EGTEA Gaze+ 特征包上进行操作，该特征包将每个时间步的视线、手部和场景线索聚合为单个向量 $\boldsymbol { x } _ { t } ~ \in ~ \mathbb { R } ^ { D _ { \mathrm { f e a l } } }$。视线通道提供归一化的像平面坐标、有效性标志和有限差分。手部通道提供多达两个带有速度的 MediaPipe 手部轨迹。场景通道编码紧凑的 HSV 直方图。所有特征均使用训练统计数据进行 Z-score 标准化，无效时间步通过 $u _ { t } \in \{ 0 , 1 \}$ 进行掩码。

给定隐藏特征 $h _ { t }$ 和掩码 $u _ { t } .$，我们应用掩码均值池化

$$
\bar {h} = \frac {\sum_ {t = 1} ^ {T} u _ {t} h _ {t}}{\sum_ {t = 1} ^ {T} u _ {t} + \varepsilon}, \qquad \ell = W \bar {h} + b,
$$

随后在 $K$ 个动词类别上进行 softmax 操作。

为确保在嵌入式设备上的可行性，我们使用了一个紧凑的多模态 GRU 编码器。在每个时间步，拼接后的视线、手部和场景特征穿过一个小型全连接层，然后输入到一个隐藏层大小为 256 的单层 GRU 中。池化后的隐藏状态被送入线性分类器，生成 $\mathbb { R } ^ { K }$ 中的对数几率（logits），其中包含 $K { = } 2 1$ 个动词。该多模态 GRU 是所有实验中的主要模型，并且在第四节（Section IV）中评估了一个使用相同输入的微型 Transformer 作为架构消融实验。

c) 训练目标：我们在包含 $K { = } 2 1$ 个类别的简化 EGTEA 标签空间（20 个高频动词加上一个“其他”类别）上训练了一个单头动词分类器。给定 logits $\boldsymbol { \ell } \in \mathbb { R } ^ { K }$ 和类别概率 $p = \operatorname { s o f t m a x } ( \ell )$，网络使用类别加权交叉熵和可选的标签平滑（label smoothing）$\epsilon$ 进行优化。标签平滑将每个硬目标 $y _ { k }$ 替换为独热标签与均匀分布的混合：

$$
\tilde {y} _ {k} = (1 - \epsilon) y _ {k} + \frac {\epsilon}{K}.
$$

事实证明，较小的平滑因子有助于稳定长尾动词分布上的训练，且不会损害校准性能，因为它能防止模型对高频类别过度自信。我们最小化类别加权交叉熵：

$$
\mathcal {L} _ {\mathrm{CE}} = - \sum_ {k = 1} ^ {K} w _ {k} \tilde {y} _ {k} \log p _ {k}, \quad w _ {k} \propto \frac {1}{\operatorname{freq} (k)}.
$$

其中 $y _ { k }$ 为独热动词标签，$w _ { k }$ 对稀有类别进行加权以对抗类别不平衡。我们使用 AdamW [21]，学习率为 $1 0 ^ { - 3 }$，权重衰减为 $1 0 ^ { - 2 }$，采用余弦衰减、批次大小为 128、梯度裁剪，并根据验证集上的负对数似然进行早停。为了提高对偶发传感器故障的鲁棒性，我们应用了模态丢弃（modality dropout）[22]，即在子批次上随机将注视或手部特征等整个模态置零，从而使编码器在个别特征流缺失时能够平稳恢复。

d) 校准：多模态 GRU 产生 logits $\ell \in \mathbb { R } ^ { K }$ 和 softmax 概率 $p = \operatorname { s o f t m a x } ( \ell )$。这些原始概率通常过于自信，与真实的正确概率不匹配，从而带来了安全风险。事后校准（post hoc calibration）在留出的验证集上学习一个映射 $\mathcal { C } ( \cdot )$，使得转换后的置信度 ${ \hat { p } } = { \mathcal { C } } ( p )$ 1 能够更好地反映经验准确率。

为了保持与实时嵌入式部署的兼容性，我们将不确定性量化（uncertainty quantification）限制在轻量级的事后（post-hoc）方法上，从而避免了像 MC Dropout [15] 或深度集成（deep ensembles）[16] 这类需要多次前向传播的方法所带来的极高运行时开销。我们对比了三种标准的事后校准方法。温度缩放（Temperature Scaling, TS）通过单个标量 T>0 对完整的 logit 向量进行重新缩放 $( \ell ^ { \prime } = \ell / T )$ 并重新计算概率 $p ^ { \prime } = \operatorname { s o f t m a x } ( \ell ^ { \prime } )$，从而调整分布的尖锐程度，使置信度更好地匹配经验精度 [1]。普拉特缩放（Platt Scaling）在最高 logit 上学习一维逻辑回归，输出在验证集上拟合的调整后概率 $\hat { c } = \sigma ( a \cdot \ell _ { \mathrm { m a x } } + b )$ [23]。最后，保序回归（Isotonic Regression）在不假设参数形式的情况下，拟合一条非参数单调曲线，将原始置信度映射到其经验精度 [24]。由于选择性预测仅取决于最大类别概率，我们仅对最高类别的置信度进行校准，这样既避免了对完整分布的不必要失真，又保留了用于动作执行的信号。在所有情况下，预测类别 $\hat { y }$ 均保持不变；仅有数值置信度发生变化，该置信度随后用于驱动第 III 节（面向安全性的执行/保持门控）中的 ACT/HOLD 门控。

e) 面向安全性的执行/保持门控：在部署时，我们使用校准后的概率 $\hat { p }$ 来驱动二元 ACT/HOLD 决策。设 $\hat { c } \_ =$ max $\hat { p } _ { k }$ 为校准后的最高类别置信度。基本规则为

$$
\boxed {\mathrm{ACT} \Leftrightarrow \hat {c} \geq \tau}\tag{1}
$$

其中阈值 $\tau \in [ 0 , 1 ]$。增大 τ 会减少系统执行动作的时间窗口比例（覆盖率），并提高处于 ACT 状态时正确预测的比例（仅执行精度，act only precision, AOP），因此 τ 是主要的安全调节旋钮。

f) 稳定性：为了防止置信度边界区域出现快速切换或“抖动”（chattering），我们实现了一个小型迟滞带和一个不应期（Figure 1）。仅当校准置信度 cˆ 越过上限阈值 $\tau _ { \mathrm { o n } } ,$ 时才会触发辅助（ACT），且仅当 $\hat { c }$ 降至下限阈值 τ<sub>of</sub> $( \tau _ { \mathrm { o n } } > \tau _ { \mathrm { o f f } } )$ 以下时才会保持或关闭辅助（HOLD）。在发生任何切换后，门控将在短暂的不应期 R ms 内忽略进一步的变化。在 iAssistADL 控制回路中，该机制对于稳定性至关重要，并能防止短暂的意外辅助突发。

g) 校准与安全边界：如果校准后的置信度在决策区域 $\{ \hat { c } \geq \tau \}$ 上是准确的，即该区域的校准误差以 ε 为界（分箱置信度与经验精度之间的差异最多为 ε），则仅执行精度满足

$$
\begin{array}{l} \text {AOP} (\tau) = \mathbb {E} [ \mathbf {1} \{\hat {y} = y ^ {\star} \} \mid \hat {c} \geq \tau ] \\ \quad \geq \mathbb {E} [ \hat {c} \mid \hat {c} \geq \tau ] - \varepsilon \\ \quad \geq \tau - \varepsilon . \end{array}
$$

该不等式表明，当系统仅在置信度至少为 $\tau$ 的窗口上采取行动时，这些窗口上的正确概率不会远低于 $\tau$ 本身（相差不超过校准误差）。因此，更好的校准（更小的 $\varepsilon$）增强了这一保证，并将 $\tau$ 转化为所有辅助动作可靠性的有效下界，为触发辅助提供了简便的定量安全控制。

h) 数据集、任务、划分与预处理：我们在 EGTEA Gaze+ [4] 上进行评估，这是一个包含 32 名受试者的第一人称日常生活活动（Activities of Daily Living, ADL）数据集，带有厨房环境下的同步视频、注视点和动作标注。遵循标准预测协议，该任务为下一个动作预测：在标注动作开始前给定一个简短的多模态窗口，模型预测下一个动作标签 $y$ 以及能够驱动安全门控的置信度信号。

原始标注包含数百个动词-名词字符串。我们专注于动词层面的意图，这与诸如伸展（reach）、倒（pour）或切（cut）等辅助控制原语更为直接地契合。动词经过归一化处理（小写转换、拼写纠错、词形变化合并），并归并为 20 个高频动词外加一个剩余的“其他”（other）类别，从而得到 $K { = } 2 1$ 个类别。“其他”类别聚合了许多罕见动词，因此比大多数单独类别更大，反映了 EGTEA 动作的长尾分布。该动词词表一致用于训练、校准和评估。

我们在三个折（fold）中使用受试者不相交的 24/4/4 训练/验证/测试划分。序列被切割为 2 s 的窗口，并在动作开始前 0.5 s 结束。我们选择该窗口时长是因为它能够在不泄露动作开始帧的情况下捕获准备性动作，这与先前的 ADL 预测协议 [8] 保持一致。每个窗口包含重采样至 25 Hz 并按每折归一化的预提取注视、手部和场景特征；在训练期间，有效样本不足的窗口将被丢弃。动词标签遵循相同的 21 类空间。

## IV. 实验与结果

我们在第 III 节（数据集、任务、划分与预处理）的跨受试者协议下，于 EGTEA Gaze+ 上评估校准的多模态意图预测器。除非另有说明，输入均为注视+手部+场景，默认编码器为第 III 节（输入与编码器）的多模态 GRU，结果取三个受试者不相交折的平均值。

A. 动词级 EGTEA Gaze+ 预测的基线准确率

在分析校准和选择性预测之前，我们首先建立多模态模型在动词级 EGTEA Gaze+ 预测任务上的基线准确率。这为后续所有校准和安全结果的解释提供了参考性能。

在 EGTEA Gaze+ 数据集上，Furnari 等人报告称，当在完整的 106 类动词-名词（verb–noun）空间中观察到整个动作片段时，使用具有模态注意机制的高容量 RGB、光流和目标特征的 RU-LSTM 在两个官方测试集上实现了 33.06% 和 19.49% 的 Top-1 动作识别准确率 [8]。由于动作粒度（106 类对 21 类）、观察窗口（完整动作对 2 秒预测）以及特征类型（端到端 RGB 对多模态）的不同，直接与我们的工作进行比较较为困难。仅基于部分观察进行预测要困难得多 [8]，准确率也相应下降。

在我们的预测设置中，我们仅观察动作开始前 0.5 秒结束的 2.0 秒多模态窗口，并使用紧凑的预计算注视点（gaze）、手部和场景特征，而不是端到端的 RGB 编码器。这特意牺牲了一定的绝对识别性能，以换取嵌入式可行性和更可预测的校准，避免了大型视觉骨干网络在辅助设备上带来的计算和内存开销。

在此配置下，多模态 GRU 基线在三个跨受试者折（subject-disjoint folds）上取得了 $0 . 4 0 2 \pm 0 . 0 0 4$ 的平均测试 Top-1 准确率以及 $0 . 6 9 9 { \pm } 0 . 0 0 6$ 的 Top-5 准确率。在相同输入下的 Transformer 编码器获得了相当的 Top-1 准确率 $( 0 . 3 9 4 \pm 0 . 0 0 9 )$ 和略高的 Top-5 准确率 $( 0 . 7 0 9 \pm 0 . 0 2 8 )$，这证实了该任务的瓶颈不在于时间建模能力，而在于短时程第一视角预测的内在模糊性。

这些基线为我们的主要目标提供了切合实际的基础，即研究如何通过校准后的置信度和选择性预测，使此类前瞻预测模型能够应用于注重安全性的辅助场景中。

## C. E2: 模态消融与鲁棒性快照

为了评估在传感退化情况下的鲁棒性，我们在测试时移除单个输入流来评估多模态 GRU。移除手部或场景特征都会导致准确率跌落至接近随机水平，这证实了这两种模态承载了动词级别预测的大部分判别信号。

我们还计算了轻量级的对角 Laplace 近似 [25] 以获得参数敏感性的粗略估计。曲率几乎完全集中在最后的特征投影器和分类头中，而大多数循环参数则位于平坦区域。这表明对分类头进行简单的贝叶斯后处理即可捕获大部分认知不确定性，而无需额外的运行时开销。

总体而言，该模型在模态缺失下表现出可预测的性能退化，并在高信息量通道（手部、场景）与低信息量通道（光流、语义）之间呈现出明显的区分。这种可预测的特性对于现实世界的辅助感知流程至关重要，因为在此类场景中间歇性感知故障十分常见，而跨模态冗余有助于维持稳定的性能与安全运行。

## D. E3: 安全决策分析

我们通过扫描校准后的最高类别概率上的置信度阈值 τ，并衡量仅执行精度（act only precision, AOP）与覆盖率之间的关系来研究选择性预测。在 $\tau = 0$ 时，多模态 GRU 会对每个时间窗都采取动作，此时恢复出基线约 40% 的 Top-1 准确率。增大 τ 会迫使系统仅在其置信度较高时才采取动作。这虽然降低了覆盖率，但提高了 AOP，因为模型在其最笃定的时间窗子集上往往表现更准确。

与漏检会导致灾难性后果的安全攸关型自主系统不同，在这一共享控制辅助设定中，我们严格将“仅执行精度”置于“覆盖率”之上；假阳性（误报）会施加主动力，可能导致用户身体失衡，而漏掉一次辅助则仅会使设备默认处于安全、透明的“跟随”模式。

这正是将置信度用作安全过滤器的核心思想。较低的阈值 τ 对应于高可用性模式，而较高的阈值则对应于保守模式，后者中几乎每一次触发的辅助都是正确的。校准改善了这种权衡：在任何给定的覆盖率水平下，经过校准的模型都能实现更高的 AOP，这表明表现良好的概率能够直接转化为 ACT/HOLD 门控更安全的运行机制。

这一实证趋势与第 III 节（面向安全性的 Act/Hold 门控）中的理论界限相吻合。当决策区域上的校准误差较小时，阈值 τ 能保证辅助动作的精度至少达到 τ 减去一个微小的裕度。因此，更好的校准强化了这一保证，并使该阈值成为一个可解释的安全参数，而非单纯的经验启发式参数。

## E. E4: 运行时与嵌入式可行性

所有实验均使用预先提取的多模态特征，因此测试时的推理只需运行多模态 GRU 和一个小型线性头。对于典型时间步长为 T≈50 的时间窗，在 CPU 上的前向传播约需 2–3 ms，这完全处于包括 iAssistADL 在内的实时辅助设备典型的 40 ms 感知与控制周期之内。由注视解析、MediaPipe Hands 和 HSV 直方图组成的特征提取流水线可以在性能一般的嵌入式硬件上以 25 Hz 实时运行，使得整套流程非常适合在一系列辅助平台中进行设备端部署。

在运行过程中，意图预测器以 25 Hz 的频率处理滑动窗口，并输出校准后的最大置信度 cˆ。该置信度直接驱动运动控制器所使用的二进制 ACT/HOLD（执行/保持）信号。在 HOLD 状态下，系统跟随用户而不提供辅助，而在 ACT 状态下，它将相应的辅助曲线融合到当前运动中。为了防止频繁切换，门控机制采用了一个具有阈值 $\tau _ { \mathrm { o n } }$ 和 $\tau _ { \mathrm { o f f } }$ 的小型迟滞带，并在每次状态转换后应用一个短暂的不应期。这稳定了闭环系统，并抑制了短暂的非预期辅助。由于校准将 cˆ 与经验正确率对齐，阈值 $\tau$ 成为一个可解释的安全参数，用于在可用性与可靠性之间进行权衡，并可在任何使用置信度信号的辅助控制器中进行调优。

## F. E5：采用平滑置信度门控的在线数据流仿真

![](images/cf7584d9f25ee52ba91606230255a3412e5908da63c682773a93047bdbe22c1d.jpg)  
Fig. 4: 闭环仅执行精度与置信度阈值 τ 的函数关系。校准将阈值转变为有意义的安全参数：校准后的门控在中等范围的 τ 下即可实现高精度，而未校准的分数直到极端阈值时仍保持平缓。

为了近似辅助设备在实际运行中内部意图模块的行为，我们通过沿着记录的 EGTEA Gaze+ 序列重放每个窗口的预测，并驱动离散的 ACT/HOLD 状态机来进行离线闭环仿真。该仿真所使用的校准置信度信号、迟滞带以及不应期 ACT/HOLD 逻辑，与我们计划在 iAssistADL 控制器上运行的完全相同，因此实验中唯一缺失的组件仅为物理执行器。对于每个折（fold），我们加载验证集的 logits 和目标标签，应用温度缩放（temperature scaling）或保持分数未校准，并运行此闭环仿真，设置包括：(i) 平滑因子为 $\alpha { = } 0 . 2$ 的类别概率指数平滑，(ii) k=3 的 top-k 滤波器，仅考虑辅助动词位于三个最可能类别之内的窗口，以及 (iii) 在 ACT / HOLD 之间切换门控的置信度阈值 τ。

对于每个 τ，我们测量处于 ACT 状态的时间比例（覆盖率，coverage）以及处于 ACT 状态时的正确动作比例（仅执行精度，act-only precision）。在 $\mathrm { A t } \tau { = } 0 ,$ 时，系统对所有窗口均执行操作，并恢复出约 0.40 的基线 Top-1 准确率。随着 τ 的增加，覆盖率下降，而仅执行精度上升。

Figure 4 表明校准将置信度阈值转化为了一个可用的安全调节旋钮：在 $\tau = 0 . 5$ 时，仅执行精度从 0.62（未校准）提升到 0.80（校准后），在不到一半的覆盖率下实现了 47% 的相对提升。

使用未校准的分数时，低阈值区间几乎是平坦的，若干个不同的截断值会产生相同的行为，因此该阈值并不是一个可解释的安全参数。典型的工作点包括：覆盖率约为 0.5 且精确率约为 0.65 的平衡模式，以及覆盖率约为 0.25 且精确率接近 0.80 的保守模式。

这些仿真表明，事后校准（post-hoc calibration）虽然不会提高原始准确率，但对于使置信度阈值在闭环环境中表现为有意义且跨折稳定（fold-stable）的安全参数而言至关重要。

## V. 结论

本文的核心主张是，对于安全的辅助触发而言，概率可靠性比原始准确率更为关键。在 EGTEA Gaze+ 数据集上，我们的轻量级多模态 GRU 达到了约 40% 的 Top 1 准确率，与用于对比的 Transformer 相似，这表明数据中的短时域模糊性而非模型容量才是主要瓶颈。模态消融实验进一步表明，手部和场景特征在预测中起主导作用，而视线通道则提供了适度的性能提升，并在被移除时平缓退化。

然而，原始模型的置信度存在严重的过度自信（ECE ≈ 0.40）。采用保序回归（Isotonic Regression）进行事后校准可在不影响准确率的情况下将这种错误校准降低至 0.04，从而将置信度分数转化为值得信赖的控制信号。由该校准置信度驱动的选择性预测持续改善了准确率-覆盖率曲线，验证了置信度驱动的 ACT/HOLD 门控的有效性。

从安全性角度来看，校准后的门控直接解决了错误辅助与遗漏辅助之间的权衡平衡。将数值分数与经验正确性相对齐，使得阈值 $\tau$ 成为一个明确且可解释的安全调节旋钮：增大 $\tau$ 会产生保守的高精确率行为，而减小 $\tau$ 则会提高可用性，从而实现针对特定患者的个性化调节。这种对齐还契合了既定的风险管理实践，使阈值能够作为风险控制措施发挥作用，并加强了概率感知与设备安全要求之间的联系。

局限性与展望：我们的评估基于录制序列的离线重放，因此有必要在闭环环境中与真实用户（例如使用 iAssistADL 设备）进行前瞻性验证，以检验实际部署中的安全性。EGTEA Gaze+ 中的平滑运动学特征也与我们目标人群的病理性运动（例如共济失调或震颤）存在差异，这促使我们进一步测试在此类领域偏移（domain shifts）下的校准稳定性，并探索潜在的针对特定患者的在线重新校准机制。尽管我们专注于动词级别的意图以简化动作空间并提高校准稳定性，但未来的工作应将该方法扩展至细粒度的动词-名词预测，并引入在线重新校准，以在新的环境和人群中保持可靠性。尽管存在这些局限性，研究结果证实，经过校准的置信度为辅助触发提供了一个实用、安全的边界，且在带来极小计算开销的同时满足了实时性约束。
