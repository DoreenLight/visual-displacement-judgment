# 大语言模型可靠性增强的置信度感知路由：一种基于多信号的生成前幻觉缓解方法

Nandakishor M

AI Safety Research

Convai Innovations

nandakishor@convaiinnovations.com

摘要—大语言模型（Large Language Models, LLMs）普遍存在幻觉问题，即生成看似合理但实际上缺乏事实依据的错误内容。当前的缓解策略主要集中在生成后校正，这类方法计算开销大，且无法阻止不可靠内容的生成。我们提出了一种置信度感知路由系统，在生成前主动评估模型的不确定性，并根据预估的可靠性对查询进行重定向。我们的方法融合了三种互补的信号：内部表征与参考嵌入之间的语义对齐、跨模型层的内部收敛性分析，以及学习得到的置信度估计。统一的置信度评分决定了分流至四种路径：高置信度采用本地生成，中等置信度采用检索增强生成（Retrieval-Augmented Generation, RAG），低置信度采用更大规模的模型，极低置信度则提交人工审核。在知识密集型问答基准上的评估表明，该方法显著提升了幻觉检测效果（从基准的 0.42 提升至 0.74），同时相比事后检测方法降低了 40% 的计算成本。F1 分数从 0.61 提升至 0.82，并保持了较低的假阳性率（0.09）。这种从被动校正到主动评估的范式转变，为提升 LLM 的可靠性提供了一种计算高效的方法。

索引术语—幻觉检测（Hallucination Detection），大语言模型（Large Language Models），置信度估计（Confidence Estimation），模型可靠性（Model Reliability），不确定性量化（Uncertainty Quantification），路由系统（Routing Systems），生成前缓解（Pre-Generation Mitigation）

## I. 引言

大语言模型在自然语言理解和生成方面展现出了变革性的能力，彻底改变了从对话式人工智能到知识抽取的广泛应用 [1], [2]。然而，限制其在关键应用中落地的持续性挑战是幻觉（hallucination），即模型会生成流畅但事实错误或缺乏依据的内容 [3], [4]。这些捏造的回答往往极具欺骗性，使其在医疗诊断、法律咨询或科学研究等高风险领域尤为危险。

现有的幻觉缓解方法大多集中在生成后校正。检索增强生成（RAG）系统利用外部知识库来约束回复的事实依据 [5], [6]，而基于一致性的方法则通过比对模型的多次输出来检测幻觉 [7], [8]。尽管这些方法在不同程度上有效，但它们都存在一个根本性的局限：它们治标不治本，都是在可能不可靠的内容已经生成之后才进行处理。

我们提出了一个从“生成后纠错”到“生成前评估”的范式转变。我们的置信度感知路由系统在生成开始前评估针对特定查询的模型可靠性，从而能够主动将不确定的查询重定向到更合适的响应机制。这种方法具有几个优势：它完全避免了不可靠内容的生成，减少了在可能失败的查询上的计算浪费，并为下游决策提供了可解释的置信度估计。

我们的贡献包括：(1) 结合了语义对齐、内部收敛和学习得到的不确定性度量的多信号置信度估计框架；(2) 将置信度分数映射到合适响应路径的确定性路由系统；(3) 证明了在知识密集型基准测试中有效性的全面实证评估；以及 (4) 与事后纠错方法相比的计算效率提升分析。

## II. 相关工作

## A. 幻觉检测与缓解

幻觉检测方法大致可分为训练阶段方法和推理阶段方法。训练阶段方法包括改进的数据整理 [9]、事实知识编辑 [10] 以及专门的损失函数 [11]。推理阶段方法包括检索增强 [12]、一致性检查 [13] 和不确定性估计 [14]。

近期的研究探索了利用内部模型状态进行幻觉检测。Farquhar 等人 [15] 开发了利用隐藏表示的基于熵的不确定性估计器。Chen 等人 [16] 提出了基于内部激活训练的判别器。我们的方法建立在这些基础之上，但特别专注于生成前评估而非事后检测。

## B. 神经网络中的不确定性量化

深度学习中的不确定性量化区分了认知不确定性（epistemic uncertainty，模型不确定性）与偶然不确定性（aleatoric uncertainty，数据不确定性）[17]。对于语言模型，相关方法包括贝叶斯神经网络 [18]、集成方法 [19] 和基于 Dropout 的近似 [20]。近期的研究通过基于采样的方法 [21] 和基于探针的技术 [22] 将这些概念扩展到了大规模语言模型。

## C. 混合专家与路由

混合专家（Mixture-of-Experts, MoE）架构利用学习得到的路由将输入引导至专门的子网络 [23], [24]。虽然传统的 MoE 路由以优化任务性能为目标，但我们的置信度感知路由优先考虑可靠性评估。近期的研究探索了基于 LLM 的路由以改进专家选择 [25]，为我们的方法提供了概念基础。

## III. 方法论

## A. 问题定义

设 M 为语言模型，Q 为查询，$R \ =$ $M ( Q )$ 为生成的回复。传统方法在生成后评估 $P ( R$ is hallucinated $| R , Q , M )$。相反，我们在生成前估计 $P ( M$ will hallucinate|Q, M)，从而实现前瞻性的路由决策。

形式上，我们定义了一个置信度估计器 $C : \mathcal { Q }  [ 0 , 1 ]$，将查询映射到置信度分数；以及一个路由函数 $A : [ 0 , 1 ] \to { \mathcal { A } }$，将置信度分数映射到具体动作，其中 A = {local, rag, large, human}。

## B. 多信号置信度估计

我们的置信度估计结合了三个互补的信号：

语义对齐 $( C _ { \bf { s e m } } ) \colon$ 我们测量模型的内部表示与参考嵌入之间的对齐程度。给定查询 Q，我们提取模型的最终隐藏状态 $\mathbf { h } _ { \mathrm { f i n a l } }$，并将其与来自可靠嵌入模型的参考嵌入 $\mathbf { e } _ { \mathrm { r e f } }$ 进行比较：

$$
C _ {\mathrm{sem}} = \cos (\mathbf {P} (\mathbf {h} _ {\mathrm{final}}), \mathbf {e} _ {\mathrm{ref}})\tag{1}
$$

其中 P 是一个经过训练的投影网络，用于将内部表示映射到参考空间。

内部收敛性 $( C _ { \mathbf { c o n v } } ) \mathrm { : }$ : 我们分析跨模型层处理的稳定性。对于隐藏状态序列 $\{ { \bf h } _ { l } \} _ { l = 1 } ^ { L }$，我们计算方差缩减作为收敛处理的指标：

$$
C _ {\text { conv }} = \frac {\operatorname{Var} (\mathbf {h} _ {1 : L / 2})}{\operatorname{Var} (\mathbf {h} _ {L / 2 : L}) + \epsilon}\tag{2}
$$

可学习置信度 $( C _ { \mathrm { l e a r n e d } } ) { : }$ 我们训练一个神经网络 $\phi$，直接从内部激活值预测置信度：

$$
C _ {\text { learned }} = \phi (\mathbf {h} _ {\text { final }})\tag{3}
$$

总体置信度分数结合了这些信号：

$$
C _ {\mathrm{overall}} = w _ {1} C _ {\mathrm{sem}} + w _ {2} C _ {\mathrm{conv}} + w _ {3} C _ {\mathrm{learned}}\tag{4}
$$

其中权重 $w _ { i }$ 通过在标注数据上进行验证来学习得到。

## C. 路由函数

基于置信度分数，我们实现了确定性路由：

$$
A (C _ {\text { overall }}) = \left\{ \begin{array}{l l} \text { local } & \text { if   } C _ {\text { overall }} \geq \theta_ {\text { high }} \\ \text { rag } & \text { if   } \theta_ {\text { med }} \leq C _ {\text { overall }} <   \theta_ {\text { high }} \\ \text { large } & \text { if   } \theta_ {\text { low }} \leq C _ {\text { overall }} <   \theta_ {\text { med }} \\ \text { human } & \text { if   } C _ {\text { overall }} <   \theta_ {\text { low }} \end{array} \right.\tag{5}
$$

阈值 $\theta _ { \mathrm { h i g h } } , \theta _ { \mathrm { m e d } } , \theta _ { \mathrm { l o w } }$ 通过验证确定，以优化准确率与计算成本之间的权衡。

## IV. 实验设置

## A. 数据集与评估指标

我们在包括 Natural Questions [26]、TriviaQA [27] 和 HotpotQA [28] 在内的知识密集型问答（QA）基准上进行评估。我们既使用了带有真实标签（ground-truth）的现有数据集，也通过系统性地引入事实性错误构建了合成评估集。

主要指标包括：

• 幻觉检测率（Hallucination Detection Rate）：正确识别出的幻觉所占的比例

• 假阳性率（False Positive Rate）：被错误标记的正确回答所占的比例

• 路由准确率（Routing Accuracy）：路由决策与最优操作之间的一致性

• 计算效率（Computational Efficiency）：与基线方法相比的总推理成本

## B. 模型配置

我们采用 HuggingFace 的 SmolLM2-360M-Instruct 作为主要语言模型来实现我们的方法，这是一个参数量为 3.6 亿、专为高效推理设计的紧凑型指令微调模型。对于参考嵌入，我们采用 Sentence-BERT（all-MiniLM-L6-v2），它提供 384 维的归一化嵌入。投影网络 $P$ 由包含层归一化（layer normalization）、Dropout 正则化和残差连接的深度架构组成，以防止过拟合。

置信度预测器 $\phi$ 实现了一个渐进式降维的多层感知网络：通过一个包含批归一化（batch normalization）和 Dropout 的 4 层架构，将维度从模型的隐藏层大小缩减至一半。我们使用 AdamW 优化器，学习率为 2e-4，权重衰减为 1e-4，并采用基于平原（plateau-based）衰减的学习率调度策略，以实现稳定的训练收敛。

## C. 训练过程

训练分两个阶段进行，使用的是一个经过精心策划、旨在捕捉不同置信度场景的数据集：

1) 数据准备：我们构建了一个包含 72 个样本的平衡训练集，分为三个置信度级别：33 个涵盖事实性知识和技术概念的高置信度样本，27 个包含个人信息和时间类查询的低置信度样本，以及 12 个代表主观或基于观点的查询的中置信度样本。

2) 投影模型训练：我们使用结合了语义对齐损失、基于均方误差的直接置信度监督以及 L2 正则化的组合损失函数，对置信度估计组件进行了 30 个轮次（epoch）的训练。训练最终收敛，总损失为 0.1633，证明了模型对置信度模式的有效学习。

3) 阈值校准：基于验证集性能，路由阈值经验性地设置为 $\theta _ { \mathrm { h i g h } } = 0 . 7 5 , \theta _ { \mathrm { m e d } } = 0 . 5 5$ 和 $\theta _ { \mathrm { l o w } } = 0 . 3 5$，以优化准确率与计算效率之间的权衡。

## V. RESULTS AND ANALYSIS

## A. Overall Performance

Table I 展示了我们的主要实验结果。置信度感知路由系统在幻觉检测方面取得了显著改进，同时在正确回答的查询上保持了高准确率。

## B. Confidence Score Analysis

我们的实现展示了在不同查询类型间的清晰区分。高置信度的技术类查询（例如 "explain machine learning" 和 "how to sort a list in python"）获得的置信度分数高于 0.80，被正确路由至本地模型生成。个人信息类查询（如 "what is my personal email address"）和时间类查询（如 "what will happen tomorrow"）的得分持续低于 0.20，适当地触发了人工审核路径。

语义对齐组件被证明最具判别力，高置信度查询在投影嵌入与参考嵌入之间的余弦相似度达到 0.75 以上，而个人查询则表现出接近于零的对齐度。学习到的置信度组件提供了额外的判别能力，神经网络预测值从个人查询的 0.069 到技术解释的 0.949 不等。

## C. Ablation Studies

我们进行了消融实验以了解每个置信度信号的贡献。结果表明，语义对齐提供了最强的单一信号，而内部收敛则提供了互补信息，这对于技术类查询尤其有价值。

## D. Routing Effectiveness Analysis

对路由决策的分析揭示了置信度评估中的系统性规律。事实型和技术型查询展现出高嵌入一致性和稳定的层演进，从而路由至本地生成。个人信息类查询表现出零语义对齐和较低的学习置信度，正确触发了人工审核。主观类查询（如 "what’s the best restaurant"）获得了中等置信度分数（0.579），被适当地路由至检索增强生成（RAG）。

层置信度分析揭示了收敛的处理模式，其中方差缩减分数和注意力演进指标有助于整体可靠性评估。高置信度查询在各层间表现出稳定的隐藏状态演进，而不确定查询则表现出较不收敛的处理模式。

## E. 计算效率

与事后（post-hoc）方法相比，我们的方法显著节省了计算开销。通过防止对低置信度查询进行不必要的生成，并根据置信度估计选择性地应用高开销操作，我们在提高可靠性的同时将整体计算成本降低了约 40%。该路由系统能够高效地处理置信度评估，为推理时间带来的额外开销极小。

## VI. 讨论与局限性

## A. 优势与长处

与现有方法相比，置信度感知路由方法具有几个关键优势：

1) 主动预防：通过在生成前评估置信度，我们防止了不可靠内容的产生，而不是在事后对其进行检测。

2) 计算效率：根据置信度估计选择性地应用高开销操作（检索、大模型），从而降低了整体计算成本。

3) 可解释性：多信号方法提供了可解释的置信度分数，能够为下游决策提供参考。

4) 模块化：可以根据应用需求轻松集成不同的路由目标。

## B. 局限性与未来工作

有若干局限性值得予以说明：

1) 参考模型依赖性：语义对齐质量在很大程度上依赖于参考嵌入模型，这可能会引入偏见或局限性。

2) 静态阈值：当前的路由阈值在部署期间是固定的。基于查询特征的自适应阈值设置可以提升性能。

3) 领域特异性：置信度估计可能需要针对特定领域进行校准，以在不同应用中实现最佳性能。

4) 规模局限性：在 360M 参数的 SmolLM2 模型上的评估可能无法完全代表更大语言模型上的表现。

未来的工作将通过自适应阈值机制、特定领域的置信度校准、在更大模型上的评估以及探索针对视觉-语言模型的多模态置信度估计来解决这些局限性。

## VII. 相关伦理考量

置信度感知路由系统的部署引发了重要的伦理考量。自动路由决策可能会表现出训练数据或参考模型中存在的偏见。将查询路由至人工审核的系统必须确保适当的人工监督和决策权限。此外，路由决策和置信度估计的透明度对于建立用户信任和系统问责制至关重要。

## VIII. 结论

我们提出了一种用于大语言模型（Large Language Models，LLM）中前瞻性幻觉缓解的置信度感知路由系统。通过结合语义对齐、内部收敛分析以及学习到的置信度估计，我们的方法实现了对模型可靠性的有效生成前评估。实证评估表明，与事后校正方法相比，该方法在保持计算效率的同时显著提高了幻觉检测的准确性。

从被动校正向主动评估的转变，代表了提高 LLM 可靠性的一个极具前景的方向。随着语言模型不断被部署于关键应用中，此类置信度感知系统对于维持用户信任以及防止错误信息的传播将至关重要。

未来的工作将探索自适应阈值划分、特定领域的校准以及向更大规模模型的扩展。最终目标是开发出不仅能够生成高质量内容，而且对其自身局限性具有可靠自我认知的语言模型。
