# 基于脑机接口与视觉压缩感知的外骨骼机器人遥操作控制

Shiyuan Qiu, Zhijun Li, Senior Member, IEEE, Wei He, Senior Member, IEEE, Longbin Zhang, Chenguang Yang, Senior Member, IEEE, and Chun-Yi Su, Senior Member, IEEE

摘要—本文提出了一种基于脑机接口（BMI）和视觉反馈的外骨骼机器人系统遥操作控制方法。视觉压缩感知、脑机参考指令以及关节空间自适应模糊控制器得到了有效集成，使机器人能够在人类操作员意念的引导下执行操作任务。首先，通过摄像机捕获的视频构建视觉反馈链路，使用户能够直观观察机械臂的工作空间及正在执行的运动。然后，将压缩图像用作非向量空间中的反馈误差以产生稳态视觉诱发电位（SSVEP）脑电（EEG）信号，与传统的视觉伺服相比，该方法不需要任何关于特征的先验信息。所提出的脑电解码算法利用从神经活动中提取的特征生成外骨骼机器人的控制信号。考虑到机器人操作过程中的耦合动力学和执行器输入约束，基于李雅普诺夫（Lyapunov）综合方法设计了一种局部自适应模糊控制器，以驱动外骨骼跟踪人类操作员意念中的预期轨迹，并在对外骨骼机器人动力学参数了解极少的情况下提供了一种便捷的动力学补偿途径。采用三名受试者进行了广泛的实验研究，验证了所提出方法的有效性。

关键词：模糊逻辑系统，脑电遥操作，视觉压缩感知，脑机接口，外骨骼

## I. 引言

近年来，外骨骼机器人在人机交互领域引起了广泛关注 [1]-[8]。为了使神经损伤和疾病患者能够使用意念控制设备执行特定任务，脑机接口（BMI）技术应运而生。所建立的 BMI 功能通常是检测用户的运动意图 [9]。基于 BMI 控制的近期研究已取得显著进展，例如基于脑电控制的假肢装置 [10], [11], [12], [13]。

BMI（脑机接口）系统的核心是在人或动物大脑（或脑细胞培养物）与外部设备之间建立直接连接通路，而不是使用外周神经和肌肉的常规输出途径。它将可从头皮表面采集的脑电（EEG）信号转换为执行用户需求的命令。在大多数 BMI 系统中，多种脑电信号可用于提取控制信号，例如稳态视觉诱发电位（SSVEPs）、P300 诱发电位、感觉运动节律、运动起始视觉诱发电位以及慢皮层电位。SSVEPs 是一种由快速重复的视觉刺激诱发的周期性诱发电位，尤其是在频率高于 6 Hz 时。对视觉刺激的最强响应包含 5 至 20 Hz 范围内的刺激频率。SSVEPs 通常发生在枕叶和顶叶，其频率与频率编码刺激的基频及谐波一致。在 SSVEP-BCI 系统中，通过提取 SSVEPs 信号中的频率信息，可以检测用户的意图命令（例如在计算机屏幕上移动光标或控制机械臂）。在 [29] 中，提出了一种基于运动想象的开关，用于开启或关闭基于 SSVEP 的 BCI。在 [30] 中，运动想象和 SSVEP 信号分别用于轮椅方向和速度的连续控制。

在视觉伺服中，图像用于定位与坐标变换相关的特征或地标，使视觉伺服系统能够获取闭环系统的位置或速度反馈。该系统不需要传感器来监测运动。然而，传统视觉伺服的性能严重依赖于特征提取。然而，完美的特征可能不易提取，并且在操作过程中可能会发生改变 [22]。一些研究人员还研究了无需特征提取过程的视觉伺服。在 [23] 中，利用两幅图像的相似度来定义互信息，并将其用于设计控制器。在 [24] 中，完整的图像强度被用作特征向量以执行反馈控制。尽管这些方法效果良好，但本文开发的方法与它们有着根本的不同。在本文提出的方法中，图像被视为非向量空间中的一个集合（集合中的每个元素没有先后顺序），正是基于这一优势，随机压缩数据可以用作传感反馈。

在本文中，通过利用图像/压缩数据所产生的压缩感知，开发了一种新颖的基于 SSVEP（稳态视觉诱发电位）的 BMI（脑机接口）策略。由于图像或压缩感知是一个集合而非向量，因此使用了“非向量空间感知”这一术语。此外，感知误差可以是一个完整的局部图像，也可以是可被视为压缩数据的部分图像，即“压缩感知”这一术语。在该控制系统内部，针对 SSVEP EEG（脑电）信号，感知误差是在非向量空间中进行描述的。该策略包含三个关键步骤：i) 在非向量空间中设计感知误差，其中局部图像直接用作反馈；ii) 利用压缩扫描对样本进行压缩并重构局部图像；以及 iii) 直接用压缩数据替代完整反馈（局部图像）以生成压缩反馈。

所设计的闭环自适应控制用于在线估计系统动力学参数，以使外骨骼的输出更加精确地反映受试者的意图。然而，外骨骼机器人需要考虑的一个挑战是复杂的动力学不确定性和输入饱和。学习控制可用于提升系统性能，既可以在固定的有限时间区间内重复进行，也可以在无限时间区间内反复（周期性）进行 [40]。近来，已有部分工作 [38]–[39] 和 [41]–[44] 将自适应模糊与学习控制技术相结合，以解决机器人模型中的时变不确定性。自适应模糊控制器能够将模糊 if-then 控制规则直接融入控制器中，所构建的控制器能在所有相关信号均一致有界的意义下保证最终闭环系统的全局稳定性。由于自适应模糊控制器在设计和应用两方面都十分简便，我们利用自适应模糊来逼近外骨骼动力学，以达到稳定的性能指标。

众所周知，饱和是各种机器人和机械系统中最关键的非线性特性之一，并且会严重降低系统性能 [26], [43]。机器人外骨骼面临的挑战之一是由于其饱和限制而无法提供足够的动力，从而引发诸如跟踪误差等问题。对于机器人系统而言，忽视饱和效应会使系统变得不可靠，并将使用者置于危险境地。因此，设计一种能够最小化机器人电机饱和效应并保持机器人稳定性的控制器至关重要。目前已提出了各种方法来解决与饱和相关的问题。在 [27] 中，针对车辆主动悬架系统中的不确定性，提出了一种饱和自适应鲁棒控制策略。在 [28] 中，通过将不可微饱和模型近似为 tanh 函数并将近似误差计入扰动，解决了兼具令人满意的瞬态和稳态响应的输入饱和问题。

另一方面，BMI（脑机接口）控制与手动控制截然不同，在 BMI 控制中，极少的反馈信息往往受限于视觉信号，而被控外部设备的动力学特性与自然运动控制的属性存在显著差异。在在线闭环 BMI 应用期间，所提出的 BMI 系统的行为引起了广泛关注。在许多情况下，能够快速获得良好性能的自适应控制具有显著优势。如果初始 BMI 性能较差且提升不够迅速，受试者可能会对该任务失去兴趣。而自适应控制能够在初始训练阶段迅速为受试者提供更高的 BMI 性能，从而使受试者在任务中更具积极性。自适应算法具备在初始训练后将性能提升至高水平的优势。当受试者使用周期性解码器调整来应对破坏 BMI 运行的现象（例如电极漂移和通道丢失）时，自适应算法可以减少所需的重新校准时间，从而使性能恢复得更加迅速。

考虑到上述问题，本文开发了一种基于脑机接口（BMI）和视觉反馈的外骨骼机器人系统遥操作控制方法。该方法将视觉压缩感知、脑机参考指令和自适应模糊控制有效结合，使机器人能够在人类操作员的意图引导下执行操作任务 [45]。首先，通过摄像机采集的视频构建视觉反馈链路，使操作员能够直观观察机械臂的工作空间及其实时执行的动作。然后，将压缩图像作为非向量空间中的反馈误差以产生稳态视觉诱发电位（SSVEP）脑电（EEG）信号，该过程无需传统视觉伺服中广泛使用的特征先验信息。所提出的 EEG 解码算法利用从神经活动中提取的特征生成外骨骼机器人的控制信号。针对机器人操作过程中的耦合动力学和执行器输入约束，基于李雅普诺夫综合法设计了局部自适应模糊控制器，以驱动外骨骼跟踪人类操作员意图中的期望轨迹，并在对外骨骼机器人动力学参数了解极少的情况下提供了一种便捷的动力学补偿方式。本文招募了多名受试者进行了广泛的实验研究，验证了所提方法的有效性。

实验装置和基于 BMI 的闭环遥操作控制框图如图 1（Fig. 1）所示。该系统由操作任务、基于 BMI 的双边遥操作、基于实时图像的视觉压缩感知机制，以及基于多元同步指数（MSI）的 EEG 解码算法组成。

我们实验室开发了一套用于实验的机器人外骨骼。如图 1 所示，该机械臂由实验室开发的 5 自由度（DOF）外骨骼组成，几乎呈拟人化结构。其运动链与人体上肢相似，但采用纯旋转关节的外骨骼并未包含人体上肢的所有自由度（DOF）。在开发的外骨骼中共有五个旋转关节，电机 1、2、3、4 和 5 分别为肩部外展-内收、肩部屈曲-伸展、肘部屈曲-伸展、前臂旋前-旋后以及手腕桡偏-尺偏的电机。在所开发的外骨骼机器人中，每个关节都包含一个高分辨率编码器（2048 pulse/cycle）和用于位置传感的霍尔效应传感器。该机器人外骨骼采用直流电机进行驱动，并选用 Maxon 扁平无刷直流电机 EC45 作为驱动单元。为了提高阻抗能力，嵌入了谐波传动驱动器（1 号和 2 号关节采用型号 SHD-17-100-2SH，3 号和 4 号关节采用型号 SHD-14-100-2SH，5 号关节采用型号 CSF-32-50-2A-GR）。特别地，为外骨骼选用的电机驱动器为 Elmo。由扁平直流电机与谐波传动组成的外骨骼重约 2.0 kg，能够提供 8Nm 的最大扭矩。

## III. 脑机接口

本地服务器的系统界面如图 2 所示，包括 SSVEP 刺激以及由置于远程客户端的摄像头所捕获的视频。机械臂工作站环境的实时视频通过 TCP/IP 发送至本地服务器。该系统界面属于脑机接口（BMI）刺激界面，在系统界面的左侧、右侧、上方和下方均布置有频率编码刺激。视觉反馈界面的尺寸为 360 像素宽、270 像素高。在我们的实验中，受试者需要利用脑电（EEG）信号作为控制信号，通过无线局域网（Wireless LAN）将机械臂的末端执行器移动到期望位置。

所有刺激在 BMI 界面上同时闪烁，然而受试者只需将注意力集中在与期望指令对应的那一个刺激上。例如，当受试者打算让机械臂的末端执行器向上移动时，他们需要将注意力集中在标记为“向上”的顶部刺激上。当 BMI 系统检测到 EEG 信号的频率与顶部刺激相关联时，它将通过 TCP/IP 通道向远程机械臂发送一个新的参考点。BMI 系统生成代表用户意图的控制信号，并将其发送给从机。以类似的方式，当受试者想要让机械臂末端执行器向左移动时，他/她需要将注意力集中在标记为“向左”的刺激上。随后将生成“向左移动”指令并发送至远程计算机以驱动机械臂。

## A. 视觉刺激

在我们的系统中，SSVEP 视觉刺激呈现在四个具有不同频率的矩形区域中：顶部（12 Hz）、左侧（10 Hz）、底部（8.57 Hz）、右侧（15 Hz），它们在一个 1020 像素宽、580 像素高的屏幕上闪烁。屏幕顶部标记为“Upwards”，代表向上移动指令；屏幕底部标记为“Downwards”，表示向下移动指令；屏幕左侧标记为“Left”，代表向左移动指令；屏幕右侧标记为“Right”，表示向右移动指令。

## B. 信号采集

在实验中，大脑活动的电信号成分由 NeuroScan-NuAmps 40 通道数字 EEG 记录系统进行采集，该系统负责收集和转换数据。EEG 数据以 500 Hz 的采样率在线采集，采用 0.5 至 40 Hz 范围的带通滤波器，并使用 50 Hz 陷波滤波器以消除电网噪声干扰。电极阻抗保持在 5Ω 以下。采用 Cz 作为参考电极，仅将位于运动区的四个主要电极 $( P _ { z } , O _ { 1 } , O _ { 2 } , O _ { z } , )$ 作为识别算法的输入 EEG 信号。EEG 信号使用自主开发的软件进行在线记录与处理。

## C. 基于 MSI 的频率识别算法

近年来，许多利用多通道 EEG 信号的方法得到了发展。这些算法可以利用来自多个电极的数据来提高算法的抗噪性能和频率识别精度。其中，有三种典型的方法。第一种是基于最小能量组合（Minimum Energy Combination, MEC）[20] 的方法。MEC 利用多个电极信号来减少通道数量，以尽可能消除噪声；由于其具有检测精度高、信噪比（SNR）高且无需用于噪声估计的校准数据等优势，MEC 方法是 SSVEP 系统中的合适选择。第二种是基于典型相关分析（Canonical Correlation Analysis, CCA）[18], [19] 的方法。该方法利用多元统计方法计算 EEG 信号与参考信号之间的相关系数，并将具有最大相关系数的参考信号频率作为算法的输出。与传统的 PSD 算法相比，基于 CCA 的方法具有更好的性能。第三种是基于 S-estimator 的多元同步指数（Multivariate Synchronization Index, MSI）方法 [21]，该指数用作参考信号与多通道 EEG 信号之间同步性的度量。在接下来的章节中，将详细介绍基于多元同步指数的频率检测方法。

MSI 算法计算的是多通道 EEG 信号与参考信号之间的同步指数，该指数通过 S-estimator 算法获取。频率识别过程通过寻找最大同步指数来完成。S-estimator 源于多通道信号构建的相关矩阵的归一化特征值之熵。在该方法中，计算出的同步指数与嵌入维度成反比。换句话说，对于完全不相关的数据，信号的嵌入维度最大；而对于完全同步的时间序列，嵌入维度最小。由于特征谱的方差与维度相关，因此数据嵌入维度是衡量同步性的合适度量。如前所述，S-estimator 可用于计算同步指数以进行频率识别。与基于 CCA 和基于 MEC 的频率识别算法类似，MSI 也需要根据刺激频率构建参考信号。

在本文中，EEG 信号为大小为 $N \times M$ 的矩阵 X，参考信号为大小为 $2 N _ { h } \times M$ 的矩阵 Y，其中 N 为通道数，M 为采样点数，$N _ { h }$ 为参考信号正弦和余弦分量的谐波数。参考信号 Y 设计为

$$
Y = \left[ \begin{array}{c} \sin (2 \pi f _ {k} t) \\ \cos (2 \pi f _ {k} t) \\ \cdot \\ \cdot \\ \cdot \\ \sin (2 \pi N _ {h} f _ {k} t) \\ \cos (2 \pi N _ {h} f _ {k} t) \end{array} \right], t = \frac {1}{F _ {s}}, \frac {2}{F _ {s}},..., \frac {M}{F _ {s}}\tag{1}
$$

其中 $f _ { k }$ 为刺激频率，$N _ { h }$ 为谐波次数，$M$ 为采样点数，$F _ { s }$ 为采样率。随后，计算相关矩阵 $C$ 如下：

$$
C = \left[ \begin{array}{l l} C _ {1 1} & C _ {1 2} \\ C _ {2 1} & C _ {2 2} \end{array} \right]\tag{2}
$$

其中

$$
C _ {1 1} = \frac {1}{M} X X ^ {T}\tag{3}
$$

$$
C _ {2 2} = \frac {1}{M} Y Y ^ {T}\tag{4}
$$

$$
C _ {1 2} = \frac {1}{M} X Y ^ {T}\tag{5}
$$

$$
C _ {2 1} = \frac {1}{M} Y X ^ {T}\tag{6}
$$

为了降低 $X$ 和 $Y$ 的自相关对同步计算的影响，采用如下线性变换 $U$：

$$
U = \left[ \begin{array}{c c} C _ {1 1} ^ {- (1 / 2)} & 0 \\ 0 & C _ {2 2} ^ {- (1 / 2)} \end{array} \right]\tag{7}
$$

变换后的相关矩阵为：

$$
R = U C U ^ {T}\tag{8}
$$

设 $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { P }$ 为矩阵 $R$ 的特征值。然后我们可以按如下方式计算归一化特征值 $\lambda _ { i } ^ { ' }$：

$$
\lambda_ {i} ^ {\prime} = \frac {\lambda_ {i}}{\sum_ {i = 1} ^ {P} \lambda_ {i}} = \frac {\lambda_ {i}}{t r (R)}\tag{9}
$$

其中 $P = N + 2 N _ { h }$。接着，我们可以获得两组信号之间的同步指数 $S$ 如下：

$$
S = 1 + \frac {\sum_ {i = 1} ^ {P} \lambda_ {i} ^ {\prime} \log (\lambda_ {i} ^ {\prime})}{\log (P)}\tag{10}
$$

接下来，可以计算来自多个脑电（EEG）电极的信号与每个参考信号 $Y$ 之间的同步指数，从而获得 $k$ 个指数 $S _ { 1 } , S _ { 2 } , \ldots , S _ { k }$。最后，通过最大值准则确定类别。

## B. 用于误差反馈的豪斯多夫距离与压缩感知

视觉反馈中的一个基本问题是如何定义两个集合或图像之间的差异（距离）。为了反馈期望图像与当前图像之间的差异，即两个集合之间的距离，我们应该定义一个合适的度量来进行衡量。此处采用了豪斯多夫距离（Hausdorff distance）。从点 $p \in \mathbb R ^ { n }$ 到集合 $Q \subset \mathbb { R } ^ { n }$ 的距离为 $d _ { Q } ( p ) = i n f _ { q \in Q } \lVert q - p \rVert$ ，其中 ∥.∥ 表示欧几里得范数。从集合 $P \subset \mathbb { R } ^ { n }$ 到另一个集合 $Q \subset \mathbb { R } ^ { n }$ 的距离为 $d ( P , Q ) = \operatorname* { s u p } _ { p \in P } d _ { Q } ( p )$ ，而从 Q 到 P 的距离为 $d ( Q , P ) = \mathrm { s u p } _ { q \in Q } d _ { P } ( q )$ 。最后，P 与 $Q$ 之间的豪斯多夫距离可通过下式计算：

$$
d h (P, Q) = \max \{d (P, Q), d (Q, P) \}\tag{11}
$$

据此可以计算两幅图像之间的差异，并显示在刺激界面上，以供用户做出移动机械臂的决策。

压缩感知（Compressive sensing）已成功应用于模式识别 [32] 和控制 [33], [34]，它是一个用于采集稀疏或近似稀疏信号的通用框架。压缩感知的主要成果之一是：如果高维信号本身是稀疏的，或者在某个域中是稀疏的，则可以从某些低维线性测量中将其恢复。因此，如果可以从压缩集合 $K _ { c } ( t )$ 中恢复出原始集合 $K ( t )$ ，则式 (11) 中的豪斯多夫距离仍然可以使用。对于未知稀疏信号 $x \in \mathbb { R } ^ { n }$ ，我们可以将一般的压缩感知问题描述为：

$$
y = A x\tag{12}
$$

其中 $\boldsymbol { y } ~ \in ~ \mathbb { R } ^ { m }$ 是可获得的线性观测值，x 是原始高维信号，并通过感知矩阵 $A \in \mathbb { R } ^ { m \times n }$ 映射到低维测量值 $y$。

当 $m \ < \ n ,$ 时，(12) 是欠定的，且存在无穷多个解。在压缩感知（compressive sensing）中，该问题被表述为一个最小化原始信号 x 中非零元素数量的优化问题。在这种情况下，如果感知矩阵 A 满足特定性质，能够确保 x 中的必要信息保留在 $y$ 中，则可以从 $y$ 中成功恢复出它。这一性质即为限制等距性质（restricted isometry property, RIP）。

定义 1：[14] 若存在常数 $\delta _ { S } \in ( 0 , 1 )$ 使得矩阵 $A \in \mathbb { R } ^ { m \times n }$ 满足：

$$
(1 - \delta_ {S}) \| x \| _ {2} ^ {2} \leq \| A x \| _ {2} ^ {2} \leq (1 + \delta_ {S}) \| x \| _ {2} ^ {2}\tag{13}
$$

对所有 S-稀疏向量 $x \in \mathbb { R } ^ { n }$ 成立，则称其满足 S 阶限制等距性质（RIP），S-稀疏向量意味着其至多包含 S 个非零元素。

验证一个矩阵是否满足 RIP 在计算上是复杂的，但已有研究证明高斯矩阵或随机采样的傅里叶矩阵以极高的概率满足 RIP [14]。因此，一小部分随机傅里叶系数可用于重构时域稀疏信号 [35]。同理，时域中的一小部分随机样本也可用于重构频域中的稀疏信号。

对于我们的问题，可以构造满足 RIP 的感知矩阵用于图像压缩。以图像集为例，我们可以逐行堆叠图像的像素强度值以获得信号 $x \in \mathbb { R } ^ { n }$。此外，假设其在频域中是稀疏的，即经离散余弦变换（DCT）后的系数向量 $x ^ { \prime }$ 是稀疏的。设 DCT 矩阵为 $\Psi \in \mathbb { R } ^ { n \times n }$，则 $x ^ { \prime } = \Psi x$。此外，设 $\Phi \in \mathbb { R } ^ { m \times n }$ 为具有 m 行 n 列的高斯矩阵构成的矩阵。那么如果 $y = \overset { \cdot } { \Phi } x = \Phi \Psi ^ { - 1 } x ^ { ' }$，其中 y 为压缩集合，这对应于随机均匀采样像素强度。若 m 满足以下引理，则可以从 y 中恢复原始信号 x：

## A. 动力学建模

带有饱和特性的 $n$ 连杆刚性机器人系统的动力学方程可描述为：

$$
M (q) \ddot {q} + C (q, \dot {q}) \dot {q} + G (q) + f _ {d i s} = S (\tau)\tag{15}
$$

其中 $q \in \mathbb { R } ^ { n }$ 为坐标，$\tau \in \mathbb { R } ^ { n }$ 为期望控制输入（施加的关节力矩），$S ( \tau )$ 是由于电机限制而对期望控制输入 $\tau$ 的饱和限制器。$M ( q ) \in$ $\mathbb { R } ^ { n \times n }$ 为对称正定惯性矩阵，$C ( q , \dot { q } ) \in$ R<sup>n</sup>×<sup>n</sup> 表示向心力和科里奥利力矩，$G ( q ) \in$ $\mathbb { R } ^ { n }$ 为重力，$f _ { d i s } \in \mathbb { R } ^ { n }$ 表示机械臂受到的外部扰动。

性质 1：[15] 矩阵 $\dot { M } ( q ) - 2 C ( q , \dot { q } )$ 是斜对称的。

性质 2：[15] 对于矩阵 $M$，$M = M ^ { T } > 0$ 且具有上下界，满足 $\lambda _ { \operatorname* { m i n } } ( M ) I _ { n \times n } \ \leq$ $M \leq \lambda _ { \operatorname* { m a x } } ( M ) I _ { n \times n } .$，其中 $\lambda _ { \mathrm { m i n } }$ 和 $\lambda _ { \mathrm { m a x } }$ 为 $M$ 的最小和最大特征值，$I _ { n \times n }$ 为单位矩阵。

假设 1：对于连续扰动 $f _ { d i s i } , ~ ( i =$ $1 , 2 . . . n )$，始终存在光滑、半正定函数 $\rho _ { i } ( t )$ 和正常数 $c _ { i }$，满足

$$

$$
S (\tau) = \left\{ \begin{array}{l l} S _ {\max} \text {sign} (\tau), & | \tau | \geq S _ {\max} \\ \tau , & | \tau | <   S _ {\max}. \end{array} \right.\tag{17}
$$

对于 $X \in \mathbb { R } ^ { 1 \times n }$，有 $S ( X ) = \left\lceil S ( x _ { 1 } ) , S ( x _ { 2 } ) , . . . . S ( x _ { n } ) \right\rceil$

## VI. 实验结果

## A. 实验设置

为验证所提出的遥操作系统的有效性，三名受试者参与了控制具有两个关节（肩关节和肘关节）的外骨骼机器人的实验。整个系统由三部分组成：脑电（EEG）识别、视觉压缩感知和自适应模糊运动控制。EEG 识别是整个系统的基础部分，其利用 MSI（同步指数法）来识别受试者期望发送的任务空间指令，而自适应模糊控制则在预期内完成关节空间任务。

该机器人设备基于实时底层控制器，该控制器与一台 Windows XP PC 连接，通过 CAN 总线完成非实时任务。CAN 总线可以传输力信号，作为在 XP 环境中实现的 Win XP 环境与外骨骼之间的接口。机器人中的传感器用于获取控制所需的位置和速度信号。CAN 总线的最大波特率为 1 MBit/s，用于获取位置和速度信号的传感器最大采样率为 5 MHz。这样的速度在我们的系统中已经足够。同时，为了实现所有控制组件之间的通信，我们需要使用 Visual C++ 语言编写软件来执行。

三名年龄均在 22 至 26 岁之间的参与者参加了实验，其中两人为熟手，一人为新手。在实验开始时，受试者被要求保持放松并静止不动。用于采集脑信号的电极被放置在受试者的头部表面。受试者被要求通过注视对应于不同任务指令的闪烁菱形来控制机器人操作臂。公式 1 中识别算法的参数为 $N _ { h } = 2 , F _ { s } = 5 0 0 , M = 8 0 0 , N = 4$。其中，$N _ { h } = 2$ 表示参考信号正弦和余弦分量的谐波次数。$F _ { s } ~ = ~ 5 0 0$ 表示参考信号的采样率为 500Hz。$M = 8 0 0$ 表示所选数据的长度，而 $N = 4$ 表示所选的四个通道 $( P _ { z } , O _ { 1 } , O _ { 2 }$ 和 $O _ { z } )$ 数据。在我们的实验中，公式 10 中的同步指数为 ${ \cal S } = [ S _ { 1 } , S _ { 2 } , S _ { 3 } , S _ { 4 } ]$，其中 $S _ { 1 } , S _ { 2 } , S _ { 3 }$ 和 $S _ { 4 }$ 分别是刺激频率诱发的电位信号与分别针对 $8 . 6 H z , 1 0 H z , 1 2 H z$ 和 $1 5 H z$ 刺激频率设计的参考信号 Y 之间的同步指数。对于受试者 1，同步指数 S 的平均值为 $S 1 = [ 0 . 0 0 4 2 , 0 . 0 4 6 3 , 0 . 0 0 3 8 , 0 . 0 3 3 ]$；而在受试者 2 的实验中，同步指数的值为 $S 2 = [ 0 . 0 0 3 2 , 0 . 0 0 4 1 , 0 . 0 0 4 5 , 0 . 0 2 1 5 ]$；受试者 3 的 S 指数为 $S 3 =$ [0.0028, 0.0039, 0.0327, 0.0019]。
