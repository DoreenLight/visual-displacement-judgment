# 脑卒中患者步行过程中肌肉活动与肌间耦合的时相依赖性调制

Yifan Li, Yueling Lyu, and Rong Song , Senior Member, IEEE

摘要— 许多脑卒中患者在发病后会出现运动和感觉障碍，导致步态紊乱。分析步行过程中的肌肉调制模式可为脑卒中后的神经学变化提供证据，但脑卒中如何影响特定步态子时相中的单块肌肉活动和肌肉协调仍不明确。本研究旨在全面探讨脑卒中患者踝关节肌肉活动与肌间耦合模式的时相依赖性特征。本实验招募了 10 名脑卒中患者、10 名年轻健康受试者和 10 名老年健康受试者。所有受试者均被要求在地面上以自选速度行走，同时采集表面肌电图（sEMG）和标记点轨迹数据。根据标记点轨迹数据，将每位受试者的步态周期划分为四个子阶段。在此基础上，利用模糊近似熵（fApEn）分析步行过程中踝关节肌肉活动的复杂度，并应用传递熵（TE）反映踝关节各肌肉之间的定向信息传递。结果发现，脑卒中患者踝关节肌肉活动的复杂度与健康受试者表现出相似的趋势。与健康受试者不同的是，脑卒中患者在大部分步态子时相中，踝关节肌肉活动的复杂度往往有所增加。而在整个步态周期中，脑卒中患者踝关节肌肉之间的 TE 值往往呈现下降趋势，尤其是在第二双支撑相阶段。与同龄健康受试者相比，患者在整个步态过程中招募了更多的运动单位，同时增加了肌肉耦合以实现步态功能。fApEn 与 TE 的联合应用，为深入理解脑卒中患者时相依赖性肌肉调制机制提供了更全面的视角。

关键词— 脑卒中，步态时相依赖性，肌肉活动复杂度，肌肉协调。

## I. 引言

脑卒中（Stroke）是一项全球性健康问题，也是导致长期残疾的主要原因之一 [1], [2]。许多患者在脑卒中后会出现运动障碍，进而导致步态紊乱，这直接降低了他们适应运动模式的能力，并随之影响生活质量 [3]。据报道，很大比例的患者可以重新获得行走能力，但与健康人相比，他们的步态模式发生了改变 [4]。鉴于步态分析能够为康复过程监测和疾病诊断提供重要信息，它已成为脑卒中幸存者身体康复计划中不可或缺的组成部分 [5]。

据报道，脑卒中后的慢性步态缺陷与异常的肌肉激活模式相关 [6], [7]。行走过程中对踝关节的适当控制对于正常步态模式至关重要。小腿三头肌（triceps surae, TS）和胫骨前肌（tibialis anterior, TA）作为跖屈肌和背屈肌，在行走过程中的支撑、姿势平衡和动态稳定性方面发挥着重要作用 [8]。表面肌电图（surface electromyography, sEMG）已被用作测量肌肉活动的无创方法，能够更全面地了解脑卒中后患者的步态功能 [9]。基于 sEMG 的线性和非线性动力学分析方法已被引入运动控制和步态分析中 [10]。广泛用于肌肉活动测量的参数通常与 sEMG 振幅和均方根（root mean square, RMS）等相关 [11], [12]。然而，生物系统和过程本质上是复杂且非线性的，简单线性模型的特性在表征肌肉动力学方面存在局限性 [13]。使用非线性时间序列分析方法评估行走等任务的复杂性，可能有助于更好地理解脑卒中后的康复过程。熵是衡量动力系统复杂性的有效方法。它已广泛用于通过估计生理序列的信息复杂性（即随机变量的不确定性）来评估生物系统的动态特性 [14], [15]。基于熵的方法，如近似熵（approximate entropy, ApEn）和样本熵（sample entropy, SampEn），已被用于生理信号分析 [16]。Chen 等人开发了模糊近似熵（fuzzy approximate entropy, fApEn）作为另一种复杂性分析方法，该方法将 Zadeh 模糊集（Zadeh's fuzzy sets）与基于熵的方法相结合 [17]。由于 fApEn 具有良好的鲁棒性和一致性优势，它可用于分析肌肉活动复杂性，并进一步探讨脑卒中后神经运动系统的适应性 [17], [18]。

不仅单块肌肉的活动可用于分析偏瘫引起的肌肉功能变化，肌间相互作用的量化也有助于进一步理解肌肉之间的耦合与协调机制 [19]。Park 等人研究了卒中后等速运动期间上肢肌肉的协调性，结果表明卒中后共激活系数的调节发生了改变 [20]。Clark 等人报道，卒中后患者在行走过程中下肢肌肉协调中的运动模块活动（亦称肌肉协同，muscle synergy）有所减少 [21]。Wang 等人发现，肌肉疲劳显著增加了卒中后患者拮抗肌的耦合程度，这可能与运动皮层向拮抗肌发出的共同皮质脊髓驱动增加有关 [22]。总的来说，异常的肌肉协调可能导致严重的步态缺陷，并进一步限制行走能力。Chris 等人报道，肌间耦合的改变可能提示病理性肌肉协同作用和代偿性协调策略 [23]。对肌间耦合的研究可为偏瘫步态中的神经肌肉协调提供有价值的信息。因此，有必要对卒中后患者步态中的肌肉协调进行进一步分析。信息论方法，例如互信息（mutual information, MI）和传递熵（transfer entropy, TE），为信息传递的量化提供了有效工具。由于其无模型（model-free）特性以及捕获线性和非线性关系的能力，它们具有检测和量化功能性神经生理耦合的潜力 [24], [25]。其中，传递熵（TE）作为一种具有捕获非线性耦合效应和方向性能力的有前景的指标被提出，这为进一步分析卒中后肌间耦合强度的变化提供了基础 [26], [27]。

行走需要复杂的神经肌肉骨骼控制来支撑和推进身体 [28]，同时也需要在步态周期的不同子时相进行肌肉激活和肌间协调 [29]。Den Otter 等人发现，在脑卒中患者步态能力的恢复过程中，肌肉活动的时间不对称性并未得到改善 [30]。然而，偏瘫后步态周期时间分布格局的改变可能是对患者改变的生物力学和神经生理学特征的一种响应。作为步态相关肌肉活动恢复重组的一部分，脑卒中患者在不同步态子时相的异常肌肉活动模式可能代表了一种神经肌肉代偿策略，而非肌肉活动时间分布调节方面的病理紊乱 [31]。研究还报道了肌肉之间周期性任务依赖的步态协调模式，表明肌肉之间的功能性相互作用受到肌肉骨骼系统与中枢神经系统之间动态连接的控制 [32]。由于这可能意味着脑卒中后对皮质控制依赖性的增加更可能发生在步态的特定时相，因此分别分析脑卒中偏瘫步态的每个子时相非常重要。此外，尽管已有关于步态子时相中肌肉调节模式的研究报道，但在复杂性基础上针对不同步态阶段肌肉活动和肌肉协调模式的全面研究仍较为匮乏，尤其是在脑卒中后患者中。

因此，本研究结合了 fApEn 和 TE 方法，以探讨脑卒中后患者踝关节肌肉活动复杂性和定向相互作用的步态时相依赖性调制。我们假设脑卒中引起的神经损伤对行走过程中肌肉活动和肌间耦合的影响与不同的步态子时相相关。对肌肉活动和肌间耦合的分析可以更全面地探索肌肉调节改变背后的潜在机制。

## II. 方法

## A. 参与者

本研究共招募了 10 名脑卒中后受试者（年龄：52.0±12.9 岁；6 名男性，4 名女性）。所有患者均符合以下纳入标准：(1) 不存在因认知、听力及视力障碍而难以理解和遵循实验指令的情况；(2) 能够在不佩戴踝足矫形器的情况下独立行走至少 5 m。脑卒中后患者的基本信息见 Table I。此外，还招募了 10 名年轻健康受试者（年龄：23.2±1.55 岁；7 名男性，3 名女性）和 10 名老年健康受试者（年龄：56.6±6.85 岁；6 名男性，4 名女性）作为对照组。对照组中无任何受试者有可能会影响行走能力的神经系统或骨科疾病史。本研究已获得中山大学医学院机构审查委员会（School of Medicine, Sun Yat-sen University Institutional Review Board）的批准，伦理批准文号为医学伦理 2021 年第 24 号。所有受试者在参与实验前均签署了知情同意书。

## B. 实验流程与数据记录

脑卒中后患者和对照组受试者被要求在地面上以其自选速度行走。受试者沿着一条 4 米长的走道进行一次步行试验，每位受试者进行 3 到 4 次步行试验。从脑卒中患者的偏瘫侧腿以及健康受试者的右腿采集 sEMG（表面肌电）和标记点轨迹数据。年轻健康受试者和脑卒中患者的 sEMG 信号采样频率为 1000HZ，老年健康受试者的采样频率为 2148HZ。sEMG 采用遥测肌电系统（Noraxon, Scottsdale, USA）进行记录。将 Ag/AgCl 表面电极（直径 2 cm）放置在四个踝关节肌肉上：胫骨前肌（TA）、比目鱼肌（SOL）、腓肠肌外侧头（GAL）和腓肠肌内侧头（GAM）。同时使用 6 摄像机运动捕捉系统（Motion Analysis Corporation, Santa Rosa, USA）以 100 Hz 的频率记录标记点轨迹，回射反光标记点放置在受试者的下肢上。

步态周期定义为同侧脚的两次连续初始足着地，根据标记点轨迹数据，其子阶段如下：第一双支撑相（DS1）、单支撑相（SS）、第二双支撑相（DS2）和摆动相（SW）。步态子阶段的示意图以及一个步态周期内来自踝关节肌肉的典型 sEMG 信号如图 Fig. 1 所示。

## C. 肌肉活动复杂度与肌间耦合分析

1) 预处理：采用去均值和高通巴特沃斯滤波器去除基线并衰减运动伪影。sEMG 信号通过频带为 10-300 Hz 的 4 阶带通巴特沃斯滤波器和 50 Hz 数字陷波器进行滤波。对滤波后的信号进行归一化，以避免信号和个体差异的影响。

2) fApEn 方法：fApEn 算法是一种评估生理信号复杂度的有效且稳健的算法，可用于表征系统的稳定性或规律性。详细计算步骤如下：

若给定一个序列 $N = N _ { 1 } , N _ { 2 } , \cdots , N _ { l } ,$ 其中 l 为 N 的长度，则可构建如下 m 维向量序列：

$$
N _ {i} ^ {m} = \left\{N (i), N (i + 1), \dots , N (i + m - 1) \right\} - N _ {0} (i),
$$

$$
i = 1, 2, \dots l - m + 1\tag{1}
$$

$$
N _ {0} (i) = \frac {1}{m} \sum_ {j = 0} ^ {m - 1} N (i + j)\tag{2}
$$

$N _ { i } ^ { m }$ 与 $N _ { j } ^ { m }$ 之间的最大绝对距离 $d _ { i j } ^ { m }$ 按照下式计算：

$$
\begin{array}{c} d _ {i j} ^ {m} = \max _ {p \in (0, m - 1)} \{| (N (i + p) - N _ {0} (i)) - (N (j + p) \\ - N _ {0} (j)) | \}   i, \quad j = 1, 2, \dots , N - m; i \neq j \end{array}\tag{3}
$$

$D _ { i j } ^ { m } \left( n , r \right)$ 为 $N _ { i } ^ { m }$ 与 $N _ { j } ^ { m }$ 之间的相似度

$$
D _ {i j} ^ {m} (n, r) = e x p \left(- \left(d _ {i j} ^ {m}\right) ^ {n} / r\right)\tag{4}
$$

其中 r 为指数函数中的宽度或相似性容限，n 决定了边界的梯度。

然后计算从每个向量到另一个向量的平均相似度。

$$
\emptyset^ {m} (n, r) = \frac {1}{n - m} \sum_ {i = 1} ^ {n - m} \left(\frac {1}{n - m - 1} \sum_ {j = 1, j \neq i} ^ {n - m} D _ {i j} ^ {m}\right)\tag{5}
$$

构建 $m + 1$ 维向量序列并重复 $( 2 ) – ( 5 )$，$\emptyset ^ { m + 1 } ( n , r )$ 如下：

$$
\emptyset^ {m + 1} (n, r) = \frac {1}{n - m} \sum_ {i = 1} ^ {n - m} \left(\frac {1}{n - m - 1} \sum_ {j = 1, j \neq i} ^ {n - m} D _ {i j} ^ {m + 1}\right)\tag{6}
$$

最后，FuzzyEn $\left( \mathrm { m } , \mathrm { n } , \mathrm { r } \right) = \left[ \ln \mathcal { V } ^ { \mathrm { m } } \left( \mathrm { n } , \mathrm { r } \right) - \ln \mathcal { V } ^ { \mathrm { m } + 1 } \left( \mathrm { n } , \mathrm { r } \right) \right]$ fApEn 可计算为：

$$
f A p E n (m, n, r) = \ln \emptyset^ {m} (n, r) - \ln \emptyset^ {m + 1} (n, r)\tag{7}
$$

在此，根据先前的研究 [33]，设置 $m \ : = \ : 2$ 且 $r \ : = \ : 0 . 2 5 ^ { * }$ std。

3) TE 方法（传递熵方法）：计算 TE（传递熵）以量化行走过程中踝关节肌肉之间的耦合强度和方向性信息。若给定时间序列 $M = m _ { 1 } , m _ { 2 } , \ldots , m _ { l }$ 和 $N = n _ { 1 } , n _ { 2 } , \ldots , n _ { l }$，其中 l 为时间序列的长度。M 到 N 的 TE 定义为 $T E _ { M  \acute { \mathrm { u } } N }$，表示如下：

$$
\begin{array}{l}T E _ {M \rightarrow N} = \sum_ {n _ {i}, n _ {i - t}, m _ {i - \tau}} \rho (n _ {i}, n _ {i - t}, m _ {i - \tau})\\\times \log \frac {\rho (n _ {i} | n _ {i - t} , m _ {i - \tau})}{\rho (n _ {i} | n _ {i - t})}\end{array}\tag{8}
$$

其中 $\rho \left( n _ { i } , n _ { i - t } , m _ { i - \tau } \right)$ 为 $n _ { i } , n _ { i - t }$ 和 $m _ { i - \tau }$ 出现的联合概率；$\mathrm { ~ t ~ }$ 和 τ 分别为 N 和 M 中的时间滞后。在此，假设信息的最大自动传递发生在 N 中目标值之前的数据点处，将 t 设置为 1。这适用于自相关函数的绝对值随时间滞后增加而单调减小的生物医学实验数据。

公式 (9) 可简化如下：

$$
\begin{array}{l} T E _ {M \to N} = \sum_ {n _ {i}, n _ {i - 1}, m _ {i - \tau}} p (n _ {i}, n _ {i - 1}, m _ {i - \tau}) \\ \times \log \frac {p (n _ {i} , n _ {i - 1} , m _ {i - \tau}) p (n _ {i - 1})}{p (n _ {i - 1} , m _ {i - \tau}) p (n _ {i} , n _ {i - 1})} \end{array}\tag{9}
$$

## D. 统计分析

各项指标使用 Matlab（Mathworks, USA）进行计算，并使用 SPSS（version 22.0.0.0 SPSS Inc）进行统计学研究以验证是否存在显著性差异。为了探究不同步态子时相下受试者之间肌肉活动和肌间协调的差异，我们进行了重复测量方差分析（repeated measures ANOVA），以步态子时相作为被试内因素，受试者组别作为被试间因素。对于所有重复测量方差分析，均进行了 Mauchly 球形度检验；若违背球形度假设，则采用 Greenhouse-Geisser 校正。事后分析则应用了 Bonferroni 校正。此外，采用独立样本 t 检验分析两个方向之间 TE 的差异，以进一步确定踝关节肌对在两个方向的信息传递是否存在显著差异。p<0.05 表示具有统计学显著性。

## III. 结果

图 1 展示了一名年轻健康受试者、一名老年健康受试者和一名脑卒中患者在一个步态周期内的典型肌肉激活情况以及踝部肌肉的 sEMG 信号。与年轻健康受试者和老年健康受试者相比，脑卒中患者的步态时相分布发生了显著改变。在健康受试者和脑卒中患者中，TA 的活动均主要集中在 DS1 和 SW。健康受试者的 SOL、GAL 和 GAM 肌肉活动主要集中在 SS 和 DS2，而脑卒中患者的肌肉活动则集中在 DS1、SS 和 DS2。

## IV. 讨论

本研究主要探讨了卒中后步行过程中踝关节肌肉的相位依赖性调制。分别采用 fApEn 和 TE 分析了踝关节肌肉活动的复杂度与肌间耦合。本研究的主要发现包括：(a) 卒中后患者踝关节肌肉活动的复杂度在大多数步态子相位中呈增加趋势；(b) 卒中后患者肌间信息传递普遍减少，且在 DS2 期间更为显著；(c) 尽管年龄和卒中均会导致肌肉功能异常，但偏瘫步态与老年步态之间可能存在不同的神经肌肉适应机制。

## A. 卒中后步态周期中肌肉活动的变化

卒中后步态的神经肌肉控制在肌肉活动的时间组织和复杂度方面表现出不稳定性。健康步态中肌肉活动的时间特征遵循规律的模式。步态周期初期的短暂激活以及摆动期结束前的进一步激活，已被确定为背屈肌的正常肌电活动。而跖屈肌的激活主要集中在摆动前期 [34]。在本研究中，可以观察到卒中后患者步态周期的异常时间模式。为了确保动态平衡和身体支撑，卒中后患者通过延长下肢着地时间，显著缩短了单支撑期的持续时间 [25]。此外，站立期跖屈肌出现过早的肌肉活动，阻碍了踝关节的背屈，从而妨碍了步态的推进 [29]。这些发现与以往研究的结果一致，表明紊乱的时间分布可能是由于瘫痪侧下肢肌肉功能受损和推进力减弱所致 [35], [36]。

本研究不仅分析了与时间分布紊乱相关的异常肌肉活动，还利用 fApEn（模糊近似熵）进一步评估了卒中后患者肌肉活动复杂度的改变。肌电（EMG）信号的复杂模式可归因于其产生机制以及肌肉激活过程中随肌纤维收缩发生的变化 [37]。EMG 信号复杂度的降低意味着运动系统中的自由度减少，即运动单元数量减少。Ao 等人证实了卒中后功能性运动单元的数量有所减少 [38]。纵观整个步态周期，卒中后患者踝关节肌肉活动的复杂度表现出与健康受试者相似的趋势。与年轻健康受试者和老年健康受试者相比，卒中后患者在大多数步态子时相中，踝部肌肉（尤其是跖屈肌）的肌肉活动复杂度往往呈上升趋势。肌肉活动复杂度的增加可能是由于肌肉受损的卒中后患者需要募集更多运动单元来完成步态代偿策略 [38]。这可能是神经肌肉系统调节机制的结果，该机制通过更广泛地分配肌肉负荷以避免肌肉损伤。此外，有报道指出，过大的变异性可能意味着系统无法准确实现预期目标，这对运动控制系统是不利的 [39]。

## B. 卒中后步态周期中肌间耦合的变化

肌肉之间的协调是判断运动能力和异常步态的重要因素，鉴于其参与了人体运动的调节以及关节稳定性的维持 [40]。Jonkers 等人提出，步态中可能需要多块肌肉的协调来代偿单块肌肉的无力 [41]。先前的研究发现，肌肉耦合可能起源于皮质脊髓通路（corticospinal pathway）[40]。在目前的结果中，中风患者的肌肉耦合普遍呈现下降趋势，这可能反映了运动指令的异常减少或相互抑制的脊髓回路的缺失 [42]。考虑到肌肉协调在调节关节刚度和姿势稳定性方面发挥着作用，中风患者肌间耦合的减少也可能是由于皮质脊髓通路为应对高关节刚度和降低的姿势控制自由度而进行的协调控制 [43]。另一方面，伴有步行障碍的中风患者肌肉协调性的改变，可能是由于肌肉间连接受损以及目标肌肉间信息传递能力降低所致。尽管某些肌对在两个方向上的肌间耦合有所不同，但肌肉之间的信息流并无明显的方向性。先前的研究表明，异常的肌间耦合是代偿性神经肌肉调节策略的结果 [44]。与年龄匹配的健康受试者相比，中风患者在整个步态过程中招募了更多的运动单位，同时以增加肌肉耦合的方式来实现步态功能。从结果中还可以看出，与肌肉活动复杂性的改变相比，年龄对步态肌肉调节模式的影响主要体现在肌间耦合能力上。此外，尽管年龄和中风都会导致肌肉功能异常，但在偏瘫步态与老年步态之间可能存在不同的神经肌肉适应机制。

此外，考虑到行走过程中运动模式的调节具有时相依赖性，分析脑卒中后单侧偏瘫患者步态的每个亚时相具有重要意义 [29]。在健康步态的双支撑相中，体重会迅速转移至对侧 [45]。由于肌肉协同作用与单个肌肉的激活模式之间存在依赖性，正常步态双支撑相期间肌间耦合的增强可能是由于 TA（胫骨前肌）和 TS（小腿三头肌）的爆发性活动。与年轻健康受试者和老年健康受试者相比，脑卒中患者在 DS2 期的踝关节肌肉间连接显著减弱。这可能是由于偏瘫侧跖屈肌无法产生短暂而有力的向前推进力。从这些结果可以推断，由脑卒中引起并导致肌肉协调能力下降的皮层控制障碍，更有可能发生在步态的特定时相中。Lamontagne 等人指出，踝关节跖屈肌和背屈肌的共激活调节可作为步态的一种适应机制 [46]。因此，步态时相依赖性肌间耦合强度的变化，也为神经肌肉系统在步态不同时相根据外部需求调整控制策略这一观点提供了证据。

## C. 临床意义

临床步态分析需要对偏瘫患者的异常肌肉激活模式进行定量评估。脑卒中后患者生物力学和神经生理学特征的改变会导致行走过程中肌肉活动和肌间耦合发生改变 [47]。研究表明，sEMG 信号表现出许多值得评估的复杂性特征，且复杂性测度被认为更侧重于内部随机性的表达 [48]。在本研究中，基于复杂肌肉活动和肌间协调的综合研究为脑卒中后肌肉调节模式提供了非线性和定量的评估。踝关节肌肉的时相依赖性调节是一个潜在的标志物，可以通过这些非线性指标进行表征。对脑卒中引起的各步态亚时相之间肌肉调节模式异常的评估，不仅可以提供对运动障碍或步态改善的评估，还能为物理治疗师提供更详细的指导。脑卒中后皮层控制障碍引起的异常肌肉协调更有可能发生在特定的步态亚时相中，在制定康复计划时需要对此给予特别关注。此外，这也有助于更好地理解脑卒中如何影响步态中的肌肉策略以及卒中后神经运动系统的适应过程。

然而，本研究存在一定的局限性。首先，肌电信号（EMG）的处理未包含针对基线和运动伪影的特殊处理，且每次试验的步态序列长度并不一致，这两者可能在一定程度上影响后续的 EMG 信号分析。其次，神经肌肉适应是脑卒中后步态中下肢肌肉活动模式的基础，它不仅与原发性损伤相关，还在反映运动任务需求的代偿策略中发挥着重要作用 [49], [50]。考虑到步行速度的降低会改变运动任务需求，并导致行走过程中肌肉活动模式发生改变，未来的研究应进一步探讨步行速度的影响。最后，我们仅分析了脑卒中后患侧的踝关节肌肉。未来的研究将进一步聚焦于膝关节和髋关节的肌肉调节，以及行走过程中健侧下肢的表现。

## V. 结论

本研究利用 fApEn 和 TE 计算了脑卒中后步行过程中肌肉活动的复杂度以及肌间耦合情况。结果表明，脑卒中后踝关节肌肉活动的复杂度呈上升趋势，而肌间信息传递总体减弱。从结果中还可以推断，脑卒中以一种步态相位依赖的方式影响了肌肉活动和信息传递的调节模式。这些发现有望进一步揭示与脑卒中和步态相位相关的神经肌肉机制，为改善运动控制和制定针对性的康复策略提供重要依据。
