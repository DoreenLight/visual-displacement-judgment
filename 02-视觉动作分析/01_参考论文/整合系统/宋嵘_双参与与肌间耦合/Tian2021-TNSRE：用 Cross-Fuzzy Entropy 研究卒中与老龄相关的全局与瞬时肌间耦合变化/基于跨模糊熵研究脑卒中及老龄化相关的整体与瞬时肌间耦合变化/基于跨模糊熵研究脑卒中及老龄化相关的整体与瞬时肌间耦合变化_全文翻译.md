# 基于跨模糊熵研究脑卒中及老龄化相关的整体与瞬时肌间耦合变化

Na Tian, Ying Chen, Wenbo Sun, Huihua Liu, Xiaoyun Wang, Tiebin Yan and Rong Song, Senior Member, IEEE

摘要—肌间耦合在主动肌与拮抗肌的协调中至关重要。然而，其动力学特征尚未被完全理解，尤其是脑卒中和老龄化引起的肌间耦合改变。本研究旨在探讨主动肌与拮抗肌之间整体和瞬时肌间耦合与老龄化及脑卒中相关的变化。在实验中，招募了 8 名脑卒中后患者、18 名健康青年受试者和 10 名健康中年受试者，并指导他们完成屈肘和伸肘任务。分别采用跨模糊熵（Cross-fuzzy entropy, C-FuzzyEn）和基于滑动窗口的瞬时跨模糊熵（instantaneous C-FuzzyEn, iC-FuzzyEn）来分析整体和瞬时肌间耦合。同时应用基于滑动窗口的瞬时模糊熵（instantaneous FuzzyEn, i-FuzzyEn）来研究肌电（EMG）信号段的动态复杂度。皮尔逊相关分析显示，在大多数情况下，i-FuzzyEn 值与 iC-FuzzyEn 值呈负相关，这表明肌电复杂度与肌间耦合之间存在正相关关系。脑卒中后患者在两项任务中主动肌与拮抗肌之间的 C-FuzzyEn 值均显著高于健康受试者（$p<0.05$），这可能是由于脑卒中后皮质脊髓束通路受损导致肌间耦合减弱所致。C-FuzzyEn、iC-FuzzyEn 和 i-FuzzyEn 的联合应用为整体和瞬时肌间耦合提供了更全面的认识。

索引词—脑卒中，老龄化，肌间耦合，跨模糊熵（C-FuzzyEn），整体，瞬时

## I. 引言

关节周围主动肌和拮抗肌的协调，其可以在运动过程中维持关节稳定性并防止意外损伤 [1]。关于协调运动中肌肉激活的控制，Farmer 等人和 Kattla 等人揭示了协同肌的运动神经元共享共同的皮质脊髓驱动，从而产生肌间耦合 [2, 3]。这种耦合可以反映向脊髓运动神经元的振荡性突触前驱动，从而引起运动单位（motor unit, MU）放电和肌肉活动 [4]。肌间耦合不仅能够反映协调运动中不同肌肉之间的相互作用，还能反映神经肌肉控制的机制 [5]。

运动神经元功能下降的个体通常表现出主动肌和拮抗肌活动不协调，这可能导致异常的肌间耦合。先前的研究表明，老年人表现出神经肌肉系统功能衰退，这可能会导致肌肉之间耦合的改变，尤其是主动肌和拮抗肌之间的耦合 [6, 7]。Asaka 等人应用互相关分析研究了衰老对躯干屈肌和伸肌之间耦合的影响，并发现存在一种由衰老引起的从相互激活模式到共同激活模式的转变 [8]。John 等人利用肌电-肌电相干性（EMG-EMG coherence）来反映手部肌肉的耦合，并指出老年人的 MU 相干性高于年轻人 [9]。由于皮质脊髓通路的受损，中风也可能影响主动肌与拮抗肌之间的耦合 [10]。McCrea 等人证实，中风患者的肩屈肌和肘伸肌协调性受损，导致肩外展力量不足以及手部运动表现较差 [11]。Dewald 等人基于相关分析表明，患者患侧的不同肌对之间出现了异常协调，这可能是由于对残余脑干下行通路的依赖增加所致 [12]。Fisher 等人通过测量上肢和下肢的肌间相干性来反映肌间耦合，并发现对照组受试者的肢体中存在显著的肌间相干性，而脊髓损伤患者中则没有 [13]。

由于神经肌肉活动本质上是非线性的 [14, 15]，因此引入了一些非线性方法来测量肌间耦合（intermuscular coupling）。多谱相干性（multi-spectral coherence）和互谱相干性（cross-spectral coherence）是基于频率的方法，用于量化不同频率成分之间的非线性信息交互 [16, 17]。互信息（mutual information）和基于交叉熵的度量被广泛用于评估动态系统之间基于时域的交互作用 [15, 18]。鉴于生理信号短暂且充满噪声的特性，用于表征两个信号之间模式同步（pattern synchronization, PS）的交叉熵度量被用来量化肌间耦合。PS 越高，耦合越紧密，生理系统之间的动态交互作用也就能被更好地捕捉 [19]。Pincus 等人基于近似熵（approximate entropy, ApEn）开发了交叉近似熵（cross-approximate entropy, C-ApEn），但它不包含自身匹配，并且会导致“方向依赖性” [20]。Richmann 等人基于样本熵引入了交叉样本熵（cross-sample entropy, C-SampEn），其在相对一致性方面优于 C-ApEn [21]。然而，它也没有计算自身匹配，且 C-ApEn 的定义并不总是成立 [22]。Xie 等人基于模糊熵（fuzzy entropy, FuzzyEn）开发了交叉模糊熵（cross-fuzzy entropy, C-FuzzyEn），相比于 C-SampEn，它对信号长度具有更好的独立性 [18]。Wang 等人还证明了在阿尔茨海默病（Alzheimer's disease）组和对照组的分类中，C-FuzzyEn 优于 C-SampEn [22]。Hwang 等人应用 C-FuzzyEn 表征了不同误差反馈条件下肌电（EMG）信号之间的关系 [23]。尽管以往的研究表明异常肌间耦合的全局度量可以通过 C-FuzzyEn 来表征，但在动态运动过程中的瞬时肌间耦合同样至关重要，却一直处于缺失状态。采用滑动窗口的基于熵的方法仅用于研究生理信号的动态复杂性特征，而非它们的瞬时相互作用 [24, 25]。

本研究的目的在于探讨主动肌与拮抗肌之间全局和瞬时肌间耦合与衰老和中风相关的变化。应用 C-FuzzyEn 来表征全局肌间耦合。同时，提出了基于滑动窗口的瞬时交叉模糊熵（instantaneous C-FuzzyEn, iC-FuzzyEn）和瞬时模糊熵（instantaneous FuzzyEn, i-FuzzyEn），以表征瞬时肌间耦合和动态复杂性。我们假设不同肌肉之间的肌肉激活和信息交互存在肌间关联。另一个假设是，中风和衰老引起的神经损伤会影响主动肌与拮抗肌之间的肌间耦合。

## II. 方法

## A. 参与者

本研究共招募了8名脑卒中后患者（平均年龄：$4 8 . 1 \pm 1 6 . 2 $ 岁；6名男性，2名女性），其基本信息见表I。脑卒中后患者的入选标准如下：(1) 无明显的视力和听力丧失；(2) 发病至少1个月；(3) 认知功能正常（简易精神状态检查，MMSE>23）；(4) 无明显肌张力障碍（改良Ashworth量表，MAS>2）。此外，18名右利手健康青年受试者（年龄：$2 3 . 7 \pm 1 . 8$ 岁；10名男性，8名女性）和10名右利手健康中年受试者（年龄：50.0 ± 6.4 岁；5名男性，5名女性）自愿参与了本实验。所有受试者在实验前均签署了知情同意书，本研究已获得广东省工伤康复中心伦理委员会的批准。

## C. 瞬时模糊熵

给定 $N$ 点时间序列 $\{ \mu ( \tilde { n } )  { : } 1 \leq \tilde { n } \leq N \}$ 的瞬时模糊熵（instantaneous FuzzyEn, i-FuzzyEn）计算如下 [28]：

首先，长度为 $L$ 的无重叠滑动窗口沿着整个序列从第一个点移动到末尾。然后，我们构成一个序列 $y ( \tilde { k } ) =$ $\{ \mu ( \widetilde K + 1 ) , \mu ( \widetilde K + 2 ) , \dots , \mu ( \widetilde K + L ) \}$，其中 $\widetilde { K } = L \big ( \widetilde { k } -$ $1 ) , 1 \le \tilde { k } \le N / L$

$$
y (\tilde {k})
$$

$$
\begin{array}{c} X _ {i} ^ {m} = \bigl \{\mu \bigl (\widetilde {K} + i \bigr), \mu \bigl (\widetilde {K} + i + 1 \bigr), \ldots , \mu \bigl (\widetilde {K} + i + m - 1 \bigr) \bigr \} \\ - \mu_ {0} \bigl (\widetilde {K} + i \bigr) \end{array}\tag{1}
$$

其中，$\begin{array} { r } { \mu _ { 0 } ( i ) = 1 / m \sum _ { j = 0 } ^ { m - 1 } \mu \bigl ( \widetilde { K } + i + j \bigr ) } \end{array}$

我们将 $X _ { i } ^ { m }$ 与 $X _ { j } ^ { m } \ ( 1 \leq i , j \leq$ $N - m + 1 ; i \neq j )$ 之间的距离定义为：

$$
\begin{array}{c} d _ {i j} ^ {m} = \max _ {k \in (0, m - 1)} \bigl | \mu \bigl (\widetilde {K} + i + k \bigr) - \mu \bigl (\widetilde {K} + j + k \bigr) \\ - \mu_ {0} \bigl (\widetilde {K} + i \bigr) + \mu_ {0} \bigl (\widetilde {K} + j \bigr) \bigr | \end{array}\tag{2}
$$

向量 $X _ { i } ^ { m }$ 与 $X _ { j } ^ { m }$ 之间的相似度计算如下：

$$
D _ {i j} ^ {m} = e x p \bigl (- \bigl (d _ {i j} ^ {m} / r \bigr) ^ {n} \bigr),\tag{3}
$$

其中，r 为边界宽度，n 为边界梯度。然后，我们将函数 $\varphi ^ { m }$ 定义为：

$$
\varphi^ {m} (n, r)
$$

$$
= \frac {1}{N - m + 1} \sum_ {i = 1} ^ {N - m + 1} \ln \left(\frac {1}{N - m + 1} \sum_ {j = 1, j \neq i} ^ {N - m + 1} D _ {i j} ^ {m}\right)\tag{4}
$$

最后，i-FuzzyEn 计算如下：

$$
i - \text { FuzzyEn } (m, n, r, N, L) = \varphi^ {m} (n, r) - \varphi^ {m + 1} (n, r)\tag{5}
$$

在本研究中，我们设置 $\mathrm { m } { = } 2$，$r = 0.15 \times \text{std}$（EMG 信号的标准差），且 L=500 [29]。

## D. 交叉模糊熵与瞬时交叉模糊熵

C-FuzzyEn 是由 FuzzyEn 发展而来的，其计算过程如下 [18]：

对于给定的两个 N 样本时间序列 $\{ \mu ( i ) \colon 1 \leq i \leq N \}$ 和 $\left\{ v ( j ) \colon 1 \leq j \leq N \right\}$，可以定义两个长度为 m 的向量：

$$
X _ {i} ^ {m} = \{\mu (i), \mu (i + 1), \dots , \mu (i + m - 1) \} - \mu_ {0} (i)\tag{6}
$$

$$
Y _ {j} ^ {m} = \{v (j), v (j + 1), \dots , v (j + m - 1) \} - v _ {0} (j)\tag{7}
$$

此处，$\begin{array} { r } { \mu _ { 0 } ( i ) = 1 / m \sum _ { k = 0 } ^ { m - 1 } \mu ( i + k ) } \end{array}$ $v _ { 0 } ( j ) =$ 1⁄ ∑ ( + )<sup>−1</sup><sub>=0</sub> 。

然后，$X _ { i } ^ { m }$ 与 $Y _ { j } ^ { m }$ 之间的距离 $d _ { i j } ^ { m }$ 计算如下：

$$
\begin{array}{c} d _ {i j} ^ {m} = m a x _ {k \in (0, m - 1)} | \mu (i + k) - v (j + k) \\ - \mu_ {0} (i) + v _ {0} (j) | \end{array}\tag{8}
$$

$X _ { i } ^ { m }$ 与 $Y _ { j } ^ { m }$ 之间的相似度 $D _ { i j } { } ^ { m }$ 以及函数 $\varphi ^ { m }$ 分别通过式 (3) 和式 (4) 定义。

最后，C-FuzzyEn 的计算公式为：

$$
\mathrm{C-FuzzyEn} (m, n, r, N) = \varphi^ {m} (n, r) - \varphi^ {m + 1} (n, r)\tag{9}
$$

在本研究中，我们设置 m=2 且 r=0.2。基于两个给定时间序列的整个序列计算 C-FuzzyEn 值，可用于表征全局耦合。同时，结合 C-FuzzyEn 和滑动窗口可以计算耦合随时间的变化，这被称为瞬时 C-FuzzyEn（instantaneous C-FuzzyEn, iC-FuzzyEn）。计算步骤如下：使长度为 500 个数据点的无重叠滑动窗口沿整个序列从第一个点移动到最后一个点 [29]。然后，计算每个窗口内的 C-FuzzyEn 值，以获得反映耦合随时间变化的 iC-FuzzyEn 序列。

## E. 信号处理与统计分析

实验中采集的原始 EMG 信号通过 20-300 Hz 的 4 阶 Butterworth（巴特沃斯）带通滤波器和 50-Hz 陷波滤波器进行滤波。为避免信号幅度和个体差异对熵参数的影响，对滤波后的信号进行了归一化处理。对于给定的序列 $\mathbf { x } ( i )$，归一化序列 $x ^ { * } ( i )$ 通过 $x ^ { * } ( i ) =$ $[ x ( i ) - m e a n ( x ) ] / S D ( x )$ 进行计算 [30]。然后，计算主动肌和拮抗肌整个 EMG 序列之间的 C-FuzzyEn 值，以表征全局肌间耦合。同时，为了表征动态跟踪任务期间的瞬时肌间耦合，通过应用长度为 500 个点（0.5s）且步长为 500 个点（0.5s）的滑动窗口，计算了主动肌和拮抗肌随肌肉激活的 iC-FuzzyEn 和 i-FuzzyEn。

## IV. 讨论

在本研究中，C-FuzzyEn 和 iC-FuzzyEn 分别用于分析全局和瞬时肌间耦合。结果展示了中风和衰老对动态跟踪任务中主动肌与拮抗肌之间肌间耦合的影响。同时，应用 i-FuzzyEn 分析了肌电信号（EMG）的动态复杂度，并探讨了 i-FuzzyEn 值与 iC-FuzzyEn 值之间的相关性。

## A. i-FuzzyEn 与 iC-FuzzyEn 的对比

本研究应用了 i-FuzzyEn 和 iC-FuzzyEn 来评估屈肘和伸肘过程中瞬时肌间耦合中的肌肉动态活动。与我们的研究类似，Pincus 等人指出信号复杂度的降低表明运动系统各组成部分之间的耦合减弱 [31]。Istenic 等人发现，随着肱二头肌收缩水平的增加，健康组和患者组在各个尺度上的多尺度熵值均有所增加 [32]。Zhu 等人报道，在握力控制实验中，四块前臂肌肉的 FuzzyEn 值随肌肉收缩水平的增加而增加 [33]。Ao 等人证实了 FuzzyEn 值的降低可能是由 MU 数量及其放电率的减少引起的 [34]。此外，Sun 等人报道了肌间耦合的降低，表明拮抗肌的激活与主动肌激活的相关性变小，这意味着交互激活减弱或共同激活增加 [35]。共同激活的存在表明神经系统以统一的方式控制两块肌肉的 MU 放电率 [36]。Flood 等人观察到肌间相干性的增加与 MU 同步性的增强相关，进而影响了 MU 的放电模式 [37]。因此，i-FuzzyEn 值与 iC-FuzzyEn 值之间的负相关表明 EMG 复杂度与肌间耦合之间存在正相关，这可能是由 MU 放电模式的改变引起的。

i-FuzzyEn 值与 iC-FuzzyEn 值之间的相关性呈现以下顺序：年轻受试者 > 中年受试者 > 中风后患者。中年受试者与年轻受试者之间相关性的差异表明，在伸肘过程中中年受试者控制拮抗肌的能力更优。先前的研究表明，与年轻人相比，老年人的力量控制能力较低，神经肌肉收缩特性较慢，这可能是由于衰老引起的神经退行性改变和神经化学改变所致 [38, 39]。中风后患者与健康受试者之间相关性的差异可能反映了患者在动态跟踪任务中较差的跟踪能力和肌肉控制能力。Canning 等人指出，中风患者神经通路的受损会导致异常的肌肉激活，使得患者在运动任务中无法协调肌肉活动 [40]。其他研究结果表明，中风降低了患侧 MU（运动单位）的放电率，并往往导致患者的神经肌肉效率降低 [41, 42]。此外，在伸肘过程中拮抗肌的 i-FuzzyEn 与 iC-FuzzyEn 之间不存在相关性，这可能是由于中风后中枢或周围神经系统的改变导致肱二头肌的 MU 池持续激活，从而引起痉挛并导致肱二头肌无法放松 [43]。

## B. 全局肌间耦合中与衰老和中风相关的变化

在伸肘过程中，中年受试者的 C-FuzzyEn 值显著小于年轻受试者，这通常代表着更紧密的肌间耦合。与我们的结果一致，先前的研究发现老年人的 MU 相干性高于年轻成年人，但这并不一定会改善老年人的运动表现 [9, 44]。Watanabe 等人证实，在单足站立期间，老年人的腓肠肌内侧-外侧相干性大于年轻成年人 [45]。这似乎是因为老年人选择性地增加了对这些肌肉的皮质脊髓驱动。皮质脊髓活动的增加可能是由于衰老引起的功能障碍，从而导致了相对更多的噪声输入 [46]。因此，老年人不得不增加皮质脊髓活动，或尝试更广泛地整合这些肌肉的感觉信息，以应对协调这些肌肉时所产生的噪声。另一项研究表明，衰老可能导致大脑运动皮质的结构损伤，从而促使中枢神经系统募集其他代偿性神经通路 [47]。本研究的结果可能是由于衰老引起的皮质脊髓活动增加，进而导致了更紧密的肌间耦合。

在中风后患者中观察到了显著更高的 C-FuzzyEn 值，表明与健康受试者相比，其肌间耦合（intermuscular coupling）有所减弱。这一结果与以往研究的发现一致，先前的研究指出，中风患者肱二头肌和肱三头肌之间的互信息少于健康受试者，反映出中风后肌间耦合的削弱 [48]。Fisher et al. 报道称，伴有上运动神经元功能障碍的中风患者在 $\beta$ 频段的肌间耦合降低，这表明肌间耦合依赖于完整的皮质脊髓束 [13]。Kisielsajewicz et al. 也证实，中风患者在执行伸手任务期间低频段的肌间耦合降低，这可能是皮质脊髓通路通讯中断所致 [49]。以往的研究发现，肌间耦合与皮质-肌肉耦合具有相似的模式，表明这两种耦合均起源于皮质脊髓通路 [50-52]。此外，肌间耦合还与运动单位（MUs）相关，甚至可能受到运动单位动作电位（MUAP）和发放率变化的影响 [53-55]。Li et al. 和 Mcnulty et al. 证实，中风不仅会导致 MUAP 和发放率的改变，还会引起 MUs 数量的变化 [41, 56]。

## C. 临床意义

尽管 FuzzyEn（模糊熵）在小参数下的鲁棒性和有效性方面表现更优，但它只能用于分析和表征单模态信号。C-FuzzyEn（交叉模糊熵）提供了一种非线性方法，用于观察两个独立但相互关联的 EMG（肌电）信号之间的全局肌间耦合 [18]。在本研究中，i-FuzzyEn 和 iC-FuzzyEn 也被用于研究瞬时肌间耦合中肌肉的动态活动。上述方法的联合应用，使得对动态过程中全局和瞬时肌间耦合的理解更加全面。根据 Pearson 相关分析，C-FuzzyEn 值与 FMA-UE 之间的相关性并不显著，这可能表明 C-FuzzyEn 分析能够以一种不同于临床量表的方式来反映卒中后的肌间变化。由于肌间耦合有助于理解神经肌肉控制的特征，因此 iC-FuzzyEn 和 C-FuzzyEn 有潜力应用于卒中和衰老引起的神经学变化的临床诊断与评估中。特别是对于动态康复任务，这两种指标有潜力为医生实时调整康复方案提供指导，从而优化治疗效果。本研究也存在若干局限性。首先，未考虑本研究招募的卒中后患者的疾病分期。其次，我们仅要求卒中后患者使用患侧手臂执行任务。未来应招募更多中度和重度卒中受试者，并要求受试者使用双臂执行任务，以进一步证实这些发现。

## V. 结论

在本研究中，C-FuzzyEn 和 iC-FuzzyEn 是分别用于表征与卒中及衰老相关的全局和瞬时肌间耦合的两个主要指标。这些发现具有揭示卒中和衰老相关神经肌肉机制的潜力，并可用于临床评估肌间耦合的变化。
