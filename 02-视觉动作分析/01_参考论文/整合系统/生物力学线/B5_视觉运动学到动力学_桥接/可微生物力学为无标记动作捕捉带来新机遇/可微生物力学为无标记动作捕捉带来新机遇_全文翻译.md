# 可微生物力学为无标记动作捕捉带来新机遇

R. James Cotton <sup>1,2</sup>

摘要— 近期的技术进展构建了专为机器学习流程设计的可微物理模拟器，并可在 GPU 上实现加速。尽管这些模拟器能够对生物力学模型进行仿真，但此类机遇尚未在生物力学研究或无标记动作捕捉中得到充分发掘。我们展示了这些模拟器可用于将逆运动学拟合到无标记动作捕捉数据中，包括对模型进行缩放以适应个体的人体测量尺寸。该过程借助运动轨迹的隐式表示端到端地完成，该轨迹通过正向运动学模型进行传播，以最小化 3D 标记点重投影到图像中的误差。该微分优化器还带来了其他机遇，例如在轨迹优化期间加入光束法平差（bundle adjustment）以优化相机外参，或进行元优化（meta-optimization）以结合多名参与者的轨迹联合改进基础模型。与以往的方法相比，该方法改善了无标记动作捕捉的重投影误差，并且与对照组和临床人群的仪器化步道测量相比，产生了准确的空间步态参数。

## I. 引言

无标记动作捕捉（Markerless motion capture, MMC）利用多台同步相机，通过计算机视觉捕捉并重建运动，能够极大地拓宽运动分析在康复、运动科学研究及临床实践中的应用范围。近年来，已有多款用于此目的的开源及专有系统问世并得到了验证 [1]–[4]。然而，现有方法受限于缺乏专为集成到机器学习流程而设计的生物力学人体模型。OpenSim 是一个被广泛应用的开源生物力学建模框架 [5], [6]，拥有包括全身及针对手臂的局部模型在内的众多模型 [7]–[9]。然而，该环境下的仿真速度较慢，且不易集成到 GPU 加速框架中。NimblePhysics 模拟器速度更快且支持生物力学模型，但仍不易集成到 GPU 中 [10]。

Mujoco [11] 是另一个支持生物力学模型（包括肌肉驱动模型）的模拟器。最近，基于 Brax [12] 的物理模拟器，GPU 加速以 Mujoco-MJX 的形式集成到了 Mujoco 中，尽管它目前尚不支持加速肌肉驱动模型。Mujoco 推动了多个旨在与机器学习和强化学习集成的生物力学框架的开发，包括 MyoSuite [13], [14]（包含将 OpenSim 模型转换为 Mujoco 的工具）以及 LocoMujoco [15]（一个运动模仿基准套件）。

除了性能优势之外，像 Brax 和 Mujoco-MJX 这样的仿真器的一个好处是它们是可微的，这为我们在本项工作中探索的方法创造了机会。我们此前展示了运动轨迹的隐式表示（implicit representations）——即学习一个将时间映射到坐标空间的函数 $f : t \to x$ ——可以从无标记动作捕捉中恢复出更平滑且更符合解剖学一致性的轨迹，同时具有更好的收敛特性 [16]。为了恢复关节角度轨迹，我们随后在 [17] 中使用生物力学模型将逆运动学（inverse kinematics）单独拟合到这些轨迹上。这是通过一种双层优化（bilevel optimization）方法完成的，该方法在多个轨迹上联合估计骨骼缩放和逆运动学 [18]。我们之所以被迫采用这种两阶段方法，是因为我们无法将重投影标记点位置误差的梯度通过运动学模型传播到学习到的隐式表示中，而这在使用可微且 GPU 加速的仿真器时是很容易实现的。

然而，实现这一点的障碍在于，据我们所知，当前使用 Mujoco 的平台并不支持缩放模型以适应个体的拟人测量尺寸。此外，存在许多用于从图像中检测关键点的人体姿态估计（HPE）算法，它们在各种不同的数据集上进行训练，每个算法都具有不同的特性。为了获得准确的拟合，模型必须具备针对所使用关键点集进行过优化的标记点位置。可微生物力学模型允许基础模型上的标记点位置与来自具有不同拟人测量尺寸的人群的重建结果进行端到端优化。可微性还允许将每个个体的标记点偏移和骨骼缩放自然地集成到优化过程中。在这项工作中，我们选择了 MetrABs-ACAE 算法 [19] 输出的 MOVI 关键点，我们先前的研究发现这些关键点在视角变化时属于最准确且解剖学一致性最高的关键点之一。完全可微性还意味着我们可以通过计算对相机外参的导数来执行光束法平差（bundle adjustment）[20]。因此，受生物力学约束的运动观测有助于提高标定精度。

简而言之，我们的贡献如下：

• 我们利用基于 Mujoco 的 GPU 加速、完全可微的生物力学模型，通过双层优化实现了个性化模型缩放和逆运动学拟合。

• 通过端到端可微双层优化实现该流程，将姿态轨迹的隐式表示通过正运动学生物力学模型进行传播，以最小化 3D 标记点重投影到图像中的误差。

• 在此优化过程中执行光束法平差，以优化相机外参。

• 实现一个三层优化过程，在来自多个受试者的轨迹数据集上对基础生物力学模型的标记点位置进行元优化（meta-optimize）。

## II. 方法

## A. 受试者

本研究已获得 Northwestern University 机构审查委员会（Institutional Review Board）的批准。受试者进行了多项活动，其中大多数人进行了多次步行试验，通常采用不同的速度或使用不同的辅助设备。这些试验是在受试者沿着一条可记录足部着地和离地时间和位置的仪器化走道步行时进行的 [21], [22]。部分受试者还完成了其他任务，如起立-行走计时测试（timed-up-and-go）和四步方形测试（four-square-step-test），这些任务也包含在拟合过程中。我们的数据集包含混合人群，包括身体健全的对照组和具有神经系统疾病史的受试者（主要是中风，但也包含部分创伤性脑损伤、脊髓损伤、周围神经病变患者），以及下肢假肢使用者。此外，还有若干名具有膝骨关节炎病史的受试者和儿童受试者。为了量化和比较性能，我们重点关注使用我们先前描述的生物力学流程 [16], [17] 进行拟合的一组试验。

## B. 无标记动作捕捉

多相机数据是通过我们定制开发的系统采集的，该系统采用了 8 至 12 台配备 F1.4/6mm 镜头的 FLIR BlackFly S GigE 相机 [16], [17]。该系统以 30 fps 的帧率采集 2048 × 1536 的图像，并使用 IEEE1558 进行同步。外参和内参标定是使用 anipose 库 [23] 通过棋盘格完成的。这些拟合参数为每个相机 i 生成一个投影函数，将采集空间中 3D 空间内的点投影到每个相机的 2D 图像平面上：

$$
\Pi_ {i}: \mathbf {x} \to y, \mathbf {x} \in \mathbb {R} ^ {3}, y \in \mathbb {R} ^ {2}\tag{1}
$$

我们使用前述的用户界面从初始场景重建中选择目标人物，该界面用于在所有相机和帧中计算该个体的边界框。我们使用一种在大量 3D 数据集上训练且输出所有这些格式超集的算法（MeTRAbs-ACAE）[19]，独立估计每一帧的关键点。我们使用了该输出的一个子集，即来自 MOVI 数据集 [24] 的 87 个关键点，这些关键点对应于生物力学分析中常用的关键点，也是我们在先前的重建方法中使用的关键点 [16], [17]。MeTRAbs-ACAE 还可以直接输出每个相机的 3D 关节位置，但我们仅使用了 2D 输出。在我们先前的研究中，我们发现该算法提取的关键点在不同视角下比其他算法更具几何一致性 [17]，这很可能是由于其在大量 3D 数据集上进行的独特训练。该算法不提供每个关键点的置信区间，因此我们通过测量每个视频帧的 10 个不同增强版本估计出的每个 3D 关节位置的标准差来进行近似估计。随后，使用半极大值为 30mm、宽度为 10mm 的 sigmoid 函数将其转换为置信度估计。这与我们之前使用的数值（分别为 200 和 50）不同 [16]，因为我们发现先前的数值提供的是更接近二值的“已检测到”信号，而非连续得分。

## C. 隐式表示

在从多台同步相机重建生物力学特征时，我们此前发现，使用一个将时间映射到虚拟标记点位置的函数 $f _ { \phi } ( t ) \to \mathbf { x }$（其中 $\mathbf { x } \in J \times 3 ,$）的隐式表示，其性能优于优化 ${ \bf x } ( t )$ 的显式轨迹或使用鲁棒三角测量 [16]。该可学习函数被实例化为多层感知机（MLP），在将时间输入从 0 缩放到 π 以防止编码中的混叠后，使用正弦位置编码输入时间 [25]。在这项工作中，我们修改了隐式表示，从直接输出 3D 关节位置改为输出姿态参数，这些参数被输入到在 Mujoco 中实现的正向运动学模型中。对应于关节角度的姿态参数通过 tanh 非线性函数被约束在关节运动范围极限之内。

## D. Mujoco 模型

我们使用了在 Mujoco [11] 中实现的基于生物力学的正向运动学。我们的模型基于 LocoMujoco [15] 在 Mujoco 中实现的力矩驱动模型，而该模型又基于 Hamner, Seth, and Delp [8] 的 OpenSim 模型。该力矩驱动模型可以使用 Mujoco 的 GPU 加速引擎 MJX 运行。MJX 目前不支持肌肉驱动模型，但这正在开发中。我们通过移除脚部以外的碰撞修改了 LocoMujoco 模型，这显著加速了正向运动学计算，并且我们还添加了一个具有 3 个自由度的颈部关节。在我们之前的工作中，我们使用 nimblephysics 仿真器 [10] 在 OpenSim 格式的类似生物力学模型上优化了与 MOVI 关键点兼容的标记点位置。我们使用 site Mujoco 元素将这些标记点位置移植到本工作所使用的模型中，该元素对应于刚性附着在模型部件上的虚拟标记点。

据我们所知，使用 Mujoco 和 MJX 尚未实现模型缩放和标记点偏移量计算。LocoMujoco 通过在实例化之前修改 XML 中的模型规范来实现类似的过程，但这不允许在 GPU 中动态更改这些参数，也不允许计算关于缩放和偏移量的导数或轨迹。我们为正向运动学实现了一个包装器，除了关节角度之外，还允许传入缩放参数以及标记点偏移量。然后在计算正向运动学之前在内存中修改基础模型。缩放是通过一个矩阵实现的，该矩阵将一组缩放参数映射到各向同性地缩放单个身体部位。我们包含了 8 个缩放参数：整体大小、骨盆、左大腿、左小腿和脚、右大腿、右小腿和脚、左臂以及左腿。这可以很自然地扩展为允许在更多身体部位上进行单独缩放或各向异性缩放，但我们在本工作中未对此进行探讨。遵循流行的蒙皮多人线性模型（SMPL）[26] 所使用的符号体系，我们可以将我们的 GPU 加速生物力学正向运动学方程表示为：

$$
\mathbf {x} = \mathcal {M} (\theta , \beta)\tag{2}
$$

其中 $\theta ~ \in ~ \mathbb { R } ^ { 4 0 }$ 是骨架模型的输入，$\beta \in \mathbb { R } ^ { 8 + 8 7 * 3 }$ 是 8 个缩放参数以及每个标记点位置的偏移量集合，而 $\ S \in \mathbb { R } ^ { 8 7 \times 3 }$ 是预测的标记点位置。正向运动学模型还可以提供沿运动学树的 21 个身体部件中每一个的位置和朝向，以及网格几何体的位置和朝向，我们在本工作中均未使用这两项。最后，该模型包含动力学特性，每个部件都具有响应来自关节力矩的线速度和角速度，这在本工作中同样未使用。

## E. MyoSkeleton 模型

我们还获准提前使用正在为 MyoSuite [13], [14] 开发的新模型，称为 MyoSkeleton。该模型具有更多的自由度（152 个），例如多个椎骨水平上脊柱的所有自由度、完全铰接的手部，甚至铰接的髌骨。这些额外的自由度由对应于典型运动的 66 个等式约束所控制，例如 L4-5 处的屈曲应如何与 L3-4 处的屈曲相关联。MJX 允许计算这些约束被违反程度的误差函数 [11]，$\epsilon = \operatorname { e r r } ( \pmb { \theta } )$。在拟合 MyoSkeleton 模型时，除了让隐式函数输出 152 个自由度外，我们还加入了一个额外的损失项来惩罚对这些约束的违反，$\begin{array} { r } { \mathcal { L } _ { \epsilon } = \lambda _ { \epsilon } \frac { 1 } { 6 6 } \sum _ { i } \epsilon _ { i } ^ { 2 } } \end{array}$。基于初步实验表明该设置可将约束违反降至极低水平，我们采用了 $\lambda _ { \epsilon } = 0 . 0 1$，并将其进一步优化留待未来工作。

## F. 双层优化

我们遵循了 Werling, Raitor, Stingel, et al. [18] 的双层优化（bilevel optimization）方法，联合求解多个运动序列上的骨骼缩放、标记点偏移以及关节角度轨迹。该方法最初是为预先计算的 3D 标记点轨迹开发的，这些轨迹要么来自传统的基于光学标记点的动作捕捉，随后在我们最近的研究中被应用于来自无标记动作捕捉的虚拟 3D 标记点轨迹 [17]。在这项工作中，我们进行了两项关键改进：1) 我们用隐式表示来表示随时间变化的姿态轨迹 $\theta _ { t }$，而不是使用该函数来预测虚拟标记点位置 $\mathbf { x } _ { t } ,$；2) 在通过相机 i 的标定相机函数 $\Pi _ { i } .$ 重投影坐标后，我们最小化图像平面中检测到的关节位置与 3D 空间中标记点位置之间的误差。因此，该方法直接优化控制生物力学模型的关节角度，以生成与图像平面中检测到的关键点相一致的标记点位置。这之所以可行，是因为我们的整个模型都是端到端可微的，并在 GPU 上进行了加速。

更形式化地，我们有一组包含 N 个记录的集合，每个记录在每个时间步 $t$ 和每个相机 $c$ 下都检测到了每个关节 $j$ 的关键点：$\left\{ y _ { t , j , c } ^ { ( n ) } \right\} _ { n = 1 \ldots N }$。建模的 3D 虚拟标记点位置由为每个轨迹单独学习的隐式函数生成，然后使用所有轨迹通用的 $\beta$ 参数输入前向运动学模型：

$$
\mathbf {x} _ {t} ^ {(n)} = \mathcal {M} (f _ {\phi_ {n}} (t), \beta)\tag{3}
$$

轨迹集合的参数 $\big \{ \phi _ { 0 } , . . . , \phi _ { N } , \beta \big \}$ 通过最小化检测到的 2D 关键点与重投影的 3D 标记点位置之间的重投影损失来进行联合优化：

$$
\mathcal {L} _ {\Pi} = \frac {1}{T \cdot J \cdot C} \sum_ {T, J, c \in C} w _ {c, t, j} g \left(\left| \left| \Pi_ {c} \mathbf {x} _ {t, j} - y _ {t, j, c} \right| \right|\right)\tag{4}
$$

其中 $g ( \cdot )$ 为 Huber 损失，$w _ { c , t , j }$ 为检测到的关键点的置信度。我们还对 $\beta$ 中对应于位点标记点的分量添加了 L2 正则化，以防止它们偏离默认位置过远：

$$
\mathcal {L} _ {\beta} = \frac {1}{8 7 \times 3} \sum_ {i = 8 \dots 8 + 8 7 * 3} \beta_ {i} ^ {2}\tag{5}
$$

因此，总损失为：

$$
\mathcal {L} = \mathcal {L} _ {\Pi} + \lambda_ {\beta} \mathcal {L} _ {\beta} + \lambda_ {\epsilon} \mathcal {L} _ {\epsilon}\tag{6}
$$

我们发现不需要针对时间平滑度施加额外的正则化，尽管这可以作为未来改进的一个方向。我们仅在拟合 MyoSkeleton 模型时才引入了约束违反损失 $\mathcal { L } _ { \epsilon }$。

1) 光束法平差（Bundle adjustment）：由于包括相机参数在内的整个系统都是端到端可微的，我们还可以执行光束法平差来进一步细化标定参数。具体而言，我们在进行优化时，允许将式 (4) 中 $\Pi _ { c }$ 的平移和旋转参数作为可学习参数。我们采用了一种学习率调度策略，仅允许这些参数在优化过程的后期才开始调整。

2) 实现与优化细节：我们的隐式表示使用 Equinox 框架 [27] 在 Jax 中实现。我们使用了一个层大小分别为 128、256、512、1024、2048、2048、4096 的 MLP。时间被缩放至不超过 $\pi$ 并进行了位置编码，使用的编码维度为 29。我们使用来自 Optax [28], [29] 的 AdamW 优化器进行优化，其中 $\beta _ { 1 } = 0 . 8$，权重衰减为 $1 e - 5$。所使用的学习率包含从初始值 $1 e - 4$ 到终值 $1 e - 7$ 的指数衰减。我们进行了 40k 步优化，并在第 30k 步启用光束法平差，使用的是一个学习率为 $1 e - 5$ 的独立 Adam 优化器。我们通常在 A6000 上运行此项任务，发现对于单条 10 秒的轨迹，它每秒可以执行超过 500 次迭代。对于包含 10 次试验的典型会话，该优化耗时数分钟。由于 Jax 在固定数组大小下的运行效率更高（新的数组大小会触发代码的追踪与重新编译），因此在对不同长度的多条轨迹进行训练时，我们在每次迭代中会从每条轨迹中随机采样一个包含 300 个时间点的集合。

## G. 三级优化

一个挑战是将生物力学模型上的所有标记点（marker）放置在与模型生成的标记点位置一致的位置。在使用 nimblephysics 开发我们先前的方案时，我们迭代优化了多次独立运行，然后将平均标记点偏移量应用于原始未缩放的模型。该流程的数轮迭代确实改善了我们的结果 [17]。然而，这一过程需要反复校正某些偏移过大的标记点位置，且不一定能产生最优位置。

我们利用本框架完全可微且运行极快的优势，通过将模型拟合到数据集中 31 位不同个体（每位个体 2 次试验）的数据，联合优化默认标记点位置；我们发现这一优化可以在单张 80GB A100 上完成。该优化包含了类似于双层优化（bilevel optimization）中所述的 31 个独立模型。然而，基础模型的标记点偏移量也被设为可学习的，来自 31 个个体的模型各自被独立缩放，且 $\mathcal { L } _ { \beta }$ 被应用于各自独立的附着点偏移量。为了防止我们在初期观察到的标记点向内收缩的现象，我们冻结了基础模型上双侧足跟标记点的位置。我们在本工作开始时执行了一次此过程，然后使用这个优化后的基础模型，通过双层优化方法拟合每个个体的所有轨迹，进而对模型进行缩放并学习个体化的标记点偏移量，同时使用公式 (5) 进行正则化以防止标记点发生过大偏移。

## H. 生物力学基线

我们将生物力学结果与我们先前的方案进行对比，后者将其分解为与典型生物力学流程等效的两个步骤 [16], [17]。具体而言，它使用隐式表示来重构随时间变化的 3D 标记点轨迹，我们发现这种方法比直接优化显式标记点轨迹或鲁棒三角测量能产生更好的效果。然后，它使用 nimblephysics 库进行双层优化，在为每次试验执行逆运动学的同时拟合模型缩放和标记点偏移量。然而，与本文提出的方法相反，这种先前的方法并非端到端可微的，因此 nimblephysics 模型的结果是针对重构的标记点轨迹进行优化的，而非针对原始图像观测值。我们推测这种分解会限制性能。

## I. 性能评估指标

1) 几何一致性：我们基于重投影的模型标记点与检测到的关键点之间的距离，衡量了基于模型的标记点轨迹与检测到的关键点之间的几何一致性。为了量化这一点，我们在置信度大于指定区间的条件下，计算了误差低于设定像素阈值的点所占的比例。

$$
\delta_ {t, j, c} = | | \Pi_ {c} \mathbf {x} _ {t, j} - y _ {t, j, c} | |\tag{7}
$$

$$
q (d, \lambda) = \frac {\sum (\delta_ {t , j , c} <   d) (w _ {t , j , c} > \lambda)}{\sum w _ {t , j , c} > \lambda}\tag{8}
$$

在下文中，我们报告了 $d = 5$ 像素时的 $G C _ { d } = q ( d , 0 . 5 )$。

2) GaitRite 对比：我们将正向运动学计算出的足跟标记点位置与 GaitRite 测得的位置进行对比，以测量每个步长（step length）、跨步长（stride length）和步宽（step width）的误差。我们以归一化四分位距（normalized IQR）来报告误差分布的宽度，即 $\sigma _ { I Q R } = 0 . 7 4 1 3 \cdot I Q R ( x )$。我们用其代替标准差，是因为它对我们观察到的少数离群值更具鲁棒性，并且我们还在结果中展示了误差直方图。

## IV. 讨论

拥有一个可在 GPU 上加速的完全可微生物力学模型，是康复和运动科学研究极其强大的工具。在此，我们展示了可以通过运动轨迹的隐式表示来驱动该正向运动学，从而获得准确的运动重建。来自多次试验的轨迹可以与骨骼缩放和标记点偏移在一致的端到端框架中进行联合优化，为双层优化（bilevel optimization）[18] 提供了一种直接的实现途径。

我们的模型还支持三级优化（trilevel optimization），即在优化基础模型标记点偏移量（base model marker offsets）的同时，拟合多个个体的轨迹和骨骼缩放。这是将生物力学整合到不同计算机视觉流程中的强大工具，因为根据我们的经验，标记点约定之间的不一致是误差的一个来源。现在，这些标记点可以被粗略初始化并附加到正确的身体部位上，然后在整个数据集上进行微调。这将便于为新的 HPE（人体姿态估计）算法创建新模型，例如精细的手部追踪或其他常用的标记点集（markersets）。我们确实注意到了三级方法存在的一些局限性。第一个局限性在于，受限于 GPU 显存，仅使用了 31 位受试者（每人 2 次试验），这样的人数可能代表性不足。产生该局限性的原因在于每次迭代都会处理所有试验。未来，我们将在子集上实现小批量处理（mini-batching），以便在更多参与者之间联合优化参数。除了脚后跟之外，我们还在尝试手动设置并锚定解剖学上定义明确的其他标记点，因为我们发现肘部位置向前侧移位的程度超出了我们认为合理的范围。因此，与真实值（ground truth）相比，当前模型存在在关节角度中引入有偏偏移的风险。复现我们先前工作 [17] 中的叠加可视化，也将有助于确认模型是否引入了任何系统误差。

我们的结果表明，通过重投影拟合结果的 $G C _ { x }$ 进行衡量，端到端优化所产生的拟合在几何上比两阶段优化方法与检测到的关键点更为一致。这并不令人意外，因为将问题分解并不能让初始轨迹直接受到生物力学模型的约束。我们先前关于隐式表征的工作包含了显式正则化，以在轨迹上保持某些关键点的骨骼长度一致 [16]，但对于许多关键点（例如足部或肢体中间的关键点），如何构建这些约束则不太明确。在我们完全可微的隐式重建方法中，这些约束以及诸如关节限位等其他约束，都是通过在多次试验中对每个个体拟合生物力学模型而自然产生的。在 MyoSkeleton 的情况下，这还扩展到了关节等式约束，从而能够以解剖学上有效的值来拟合脊柱上的多个自由度。

我们利用了相机模型的可微性，将光束法平差（bundle adjustment）融入到后期的优化迭代中，以微调相机的外参。尽管我们在每次实验前已经使用 anipose [23] 进行了严格的标定，这一步仍然对重投影误差和步态参数误差带来了小幅但显著的改善。尽管我们目前还无法完全跳过标定步骤，但最终免除这一需求将是使 MMC 更易于使用的又一实用举措。这也为优化单次采集中的其他可微元参数（meta-parameters）指明了方向，例如我们如何考量关键点的置信度得分。

优化我们考量关键点不确定性的方式，是提升重建效果的另一个尚未探索的方向。至关重要的是，我们当前的方法并不能给出关节角度的置信区间，尽管在单次试验中，这些角度的不确定性会因能够观测到特定标记点的相机数量及其相对几何构型而有所波动。可靠的置信度估计对于更广泛的应用（尤其是在临床环境中）至关重要，因为明确何时可以信任数据是不可或缺的。在从 2D 提升至 3D 关键点的背景下，我们已经证明，拟合概率模型并优化负对数似然（negative log-likelihood, NLL），而非仅仅最小化误差的点估计，可以产生这些经过校准的不确定性估计 [31]。一个极具前景的未来方向是将轨迹表征扩展为概率表征并最小化 NLL，以获取 MCC 的置信度。这将使我们能够兼顾关键点中的噪声及其内部一致性，并为关节角度估计生成校准后的置信区间。这也将要求我们开发经过验证的评价指标（metrics-of-merit）来评估模型拟合的内部一致性和不确定性估计，因为真实真值（ground truth）通常是无法获取的。我们预计，对同时拟合多个个体的模型进行三层优化（trilevel optimization），将使我们能够极高效次元优化其中的某些参数。

计算关节角度的置信度，对于难以获取真值信息的方法也将大有裨益。这包括针对具有代表性的临床人群开展的大规模数据采集（正如我们当前的工作），也包括手部追踪——在手部各个关节上放置标记点是不切实际的，并且会改变手部的外观与功能。MyoSkeleton [13], [14] 包含一个完全铰接的手部模型，我们还移植了 MoBL-ARMS 生物力学模型 [32]。我们的初步结果表明，该端到端模型在追踪单个手指方面表现良好。

令人欣慰的是，我们的模型能够为多种临床人群提供高质量的拟合，包括下肢假肢使用者、神经系统疾病患者、儿科患者以及肌肉骨骼疾病患者。在某些人群中步态参数的误差确实有所增加，例如对于通常有治疗师陪同同行的神经系统疾病患者，步长的噪声可能高达 2cm，在此类情况下，可能会错误关联来自非目标个体的关键点。这表明可以通过改进几何场景理解以及利用多人跟踪来进一步提升结果。在这种情况下跨步长（stride length）仍保持在 1cm，这可能也表明该现象与测量足底压力位置和计算机视觉之间的系统性差异有关。在这些情况下显式建模不确定性可能会进一步提供帮助。

除了将生物力学模型拟合到 MMC 数据的这些改进之外，我们更广泛地对在不同研究方向上一致使用 GPU 加速的生物力学模型感到兴奋。例如，我们最近表明，使用强化学习（RL）训练由单目计算机视觉驱动的模仿学习策略可以改善单视角摄像头的步态分析 [33]，但如果将简单的类人模型替换为本文描述的模型，该研究将从中受益。最近的研究表明，在大规模运动数据集上通过模仿学习训练的 RL 策略可以被蒸馏用于生成建模，其中生成的运动受学习到的潜在代码（latent codes）所调控 [34]。这可以与我们关于基于步态的生物标志物自监督学习的工作 [35] 相结合，以学习表征某些步态模式的潜在代码（即生物标志物），进而生成代表这些代码的运动，甚至可能预测不同任务中的运动。最后，MyoSuite 正在围绕使用 Mujoco 进行神经肌肉和生物力学建模构建社区和工具集，而我们在本文中描述的工作将能够创建与其工具兼容的真实人体运动的大规模数据集 [13]。这与最近的进展（例如 SKEL 和 OSSO 模型 [36], [37]）能够很好地结合，这些模型将生物力学模型映射到计算机视觉研究中更常用的身体模型（如 SMPL [26]）。

## V. 结论

可在 GPU 上加速的全可微生物力学模型是康复和运动科学领域中极具前景的工具。在此，我们展示了该方法自然地使我们能够实现一种端到端的双层优化算法，用于缩放生物力学模型并拟合多次试验的逆向运动学，同时直接最小化重投影回相机平面的误差。它甚至支持执行光束法平差（bundle adjustment）以优化相机外参，并进行三层优化以在一组个体上元优化（meta-optimize）模型。这项工作将使一致且具有生物力学基础的模型能够跨越计算机视觉、机器学习和生物力学等交叉研究领域得到应用。
