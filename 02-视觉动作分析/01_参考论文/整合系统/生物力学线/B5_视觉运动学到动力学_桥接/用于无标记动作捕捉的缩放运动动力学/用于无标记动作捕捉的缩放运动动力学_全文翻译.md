## 摘要

本研究提出了一种在无标记人体动作捕捉（MoCap）中利用运动动力学先验知识的方法。具体而言，我们将追踪到的运动模式与训练模式进行匹配，以预测连续帧中的状态。在此过程中，通过旋量（twists）对运动进行建模使得先验能够实现适当的缩放。因此，无需针对不同帧率或速度准备训练数据。此外，该方法还允许结合截然不同的运动模式。在室内和室外场景中的实验表明，在人为丢帧或图像数据约束不足的情况下，该方法均能对熟悉的运动模式进行连续跟踪。

## 1. 引言

在本文中，我们致力于解决人体姿态跟踪任务，该任务也被称为动作捕捉（MoCap）。对于该任务，已知人体的三维模型以及至少一个经过标定的摄像机视角。我们所关注的是人体的三维刚体运动，即其相对于摄像机的姿态以及通过运动链建模的肢体关节角度。在文献中可以找到许多极具前景的方法来应对这一挑战，综述参见 [11]。其他近期的研究工作可参见 [3, 10, 7, 18]。这些技术基于不同的模型表征（例如骨架模型或椭球模型）或图像特征（例如深度图、光流、轮廓）来将模型与图像数据拟合。

我们建立在一种生成式、基于轮廓的技术之上，正如 [13] 中所介绍的方法。在这种情况下，人体模型以自由曲面形式给出，姿态参数通过将投影曲面与图像中的人体轮廓进行匹配来确定。通过将投影曲面模型作为形状先验纳入考量，人体轮廓的提取与姿态估计问题相互耦合。前景目标和背景的灰度/色彩强度通过局部高斯分布建模，人们基本上是在寻找姿态参数，使得模型轮廓能够最佳地分离人体和背景的强度分布。我们将在第 2.5、2.6 和 3 节中简要回顾该技术的部分内容。

在该跟踪系统（以及许多其他系统）中，可能姿态构型的搜索空间并未受到限制，即假设所有刚体运动和关节角度构型具有同等的可能性。事实上，这种假设并不成立，例如身体各部位之间是不允许相互穿透交叉的。利用关于常见姿态构型的额外先验信息能够约束搜索空间，并极大地有助于应对包含部分遮挡、背景杂乱或损坏图像数据等更为复杂的场景。

将此类先验知识应用于人体跟踪有几种途径。一种可行的方法是显式地防止自遮挡并施加固定的关节角度限制，如 [18, 8] 中所建议的那样。另一种选择是直接学习从图像或轮廓空间到姿态构型空间的映射 [15, 1]。在 [4] 中，建议通过核密度来建模静态姿态先验。它独立于先前的状态，倾向于选择熟悉的姿态构型。限制搜索空间的一种非常流行策略是降维，无论是通过线性还是非线性投影方法。在 [16] 中，低维空间是通过 PCA（主成分分析）获得的，并且该空间中的运动模式被组织在一个二叉树中。与我们的方法类似，该方法将跟踪运动的历史与训练模式进行比较。然而，该方法在线性子空间中运作，并且与我们的技术相反，它对运动速度不具备不变性。因此，训练模式集合必须包含具有不同速度的相同模式。在 [17] 中，建议在非线性子空间中学习姿态构型的高斯混合模型。在 [19] 中，高斯过程被用于建模子空间投影和运动动力学。

降维的背景思想在于，像行走这样的典型运动模式应当是低维流形上的一条相当简单的轨迹，因为所有肢体运动主要是耦合的，因此可以通过原始的高维空间与低维空间之间的映射来建模。该映射是从训练样本中学习得到的。

尽管降维在特定运动模式的情况下表现良好，但只要训练集中出现两种截然不同的运动模式，它就可能会出现问题。例如，行走和空手道踢腿时的肢体运动耦合方式将大不相同。因此，学习单一映射并不适用，而是需要采用回归器混合模型 [9]，而这种模型的估计难度很大。

出于这个原因，我们在原始姿态参数空间中对运动模式进行建模。具体而言，我们利用先前帧的姿态历史记录在训练数据中检索最相似的对应模式。该匹配随后会告知我们下一帧中最可能的构型。尽管我们在更高维的空间中工作，但我们只需比较模式。此外，我们的方法具有两个优势。首先，得益于运动的旋量（twist）表示以及保留在原始姿态参数空间中，我们可以利用先前帧的速度来缩放训练数据的动力学特性。这使得相同的运动模式可以应用于不同的速度。其次，与许多其他方法相比，它允许训练数据包含完全不同的运动模式（例如跑步、侧手翻、小翻）。我们在几项实验中展示了这些优势，包括与基于标记点的跟踪系统的定量比较。

## 2. 刚体运动与速度

本节回顾了运动动力学建模（特别是运动模式缩放）所需的数学基础。我们建议使用指数形式的刚体运动旋量表示 [12]，而不是使用级联的欧拉角和平移向量：

$$
M = \exp (\theta \hat {\xi}) = \exp \left( \begin{array}{c c} \hat {\omega} & \boldsymbol {v} \\ 0 _ {3 \times 1} & 0 \end{array} \right)\tag{1}
$$

其中 $\theta \hat { \xi }$ 是旋量 $\xi \in s e ( 3 ) =$ $\{ ( \pmb { v } , \hat { \omega } ) | \bar { \pmb { v } } \in \mathbb { R } ^ { 3 } , \hat { \omega } \in \hat { \textbf { \ } } s o ( 3 ) \}$ 的矩阵表示，且 $s o ( 3 ) ~ = ~ \{ A ^ { ' } ~ \in$ $\mathbb { R } ^ { 3 \times 3 } | \pmb { A } = - \pmb { A } ^ { T } \}$。李代数（Lie algebra）$s o ( 3 )$ 是所有 3D 旋转的切空间。其元素是（缩放后的）旋转轴，既可以表示为 3D 向量，也可以表示为

反对称矩阵：

$$
\theta \omega = \theta \left( \begin{array}{c} \omega_ {1} \\ \omega_ {2} \\ \omega_ {3} \end{array} \right), \text {with} \| \omega \| _ {2} = 1\tag{2}
$$

$$
\theta \hat {\omega} = \theta \left( \begin{array}{c c c} 0 & - \omega_ {3} & \omega_ {2} \\ \omega_ {3} & 0 & - \omega_ {1} \\ - \omega_ {2} & \omega_ {1} & 0 \end{array} \right).\tag{3}
$$

旋量 ξ 包含六个参数，对于单位向量 $\omega$，可以缩放为 θξ。参数 $\theta \in \mathbb { R }$ 对应于运动速度（即旋转速度和螺距）。对于变化的 θ，该运动可被视为绕空间中某一轴线的螺旋运动。这六个旋量分量既可以表示为 6D 向量，也可以表示为 4 × 4 矩阵：

$$
{\theta \xi} = {\theta (\omega_ {1}, \omega_ {2}, \omega_ {3}, v _ {1}, v _ {2}, v _ {3}) ^ {T}, \| \omega \| _ {2} = 1,}\tag{4}
$$

$$
\theta \hat {\xi} = \theta \left( \begin{array}{c c c c} 0 & - \omega_ {3} & \omega_ {2} & v _ {1} \\ \omega_ {3} & 0 & - \omega_ {1} & v _ {2} \\ - \omega_ {2} & \omega_ {1} & 0 & v _ {3} \\ 0 & 0 & 0 & 0 \end{array} \right).\tag{5}
$$

## 2.1. 从 se(3) 到 SE(3)

为了从给定的旋量（twist）重建群作用 $\textbf { \textit { M } } \in \textbf { \textit { S E } } ( 3 )$，必须计算指数函数 $M = \exp ( \theta \hat { \xi } ) = $ $\textstyle \sum _ { k = 0 } ^ { \infty } { \frac { ( \theta \hat { \xi } ) ^ { k } } { k ! } }$。这可以通过以下公式高效完成：

$$
\exp (\theta \hat {\xi}) = \left( \begin{array}{c c} \exp (\theta \hat {\omega}) & (I - \exp (\theta \hat {\omega})) (\omega \times v) + \omega \omega^ {T} \boldsymbol {v} \theta \\ 0 & 1 \end{array} \right)
$$

并应用罗德里格斯公式（Rodriguez formula）：

$$
\exp (\theta \hat {\omega}) = I + \hat {\omega} \sin (\theta) + \omega^ {2} (1 - \cos (\theta)).\tag{6}
$$

这意味着，该计算可以通过简单的矩阵运算以及实数的正弦和余弦计算来实现。文献 [3] 利用了这一性质来计算正交相机设置中的位姿和运动链配置。

## 2.2. 从 SE(3) 到 se(3)

在 [12] 中，给出了一种构造性方法来计算生成给定刚体运动的旋量。设 $R \in S O ( 3 )$ 为旋转矩阵，$\scriptstyle t \ \in \ \mathbb { R } ^ { 3 }$ 为刚体运动的平移向量：

$$
M = \left( \begin{array}{c c} R & t \\ 0 & 1 \end{array} \right).\tag{7}
$$

对于 $\mathbf { { \boldsymbol { R } } } = { \boldsymbol { I } } ,$ 的情况，旋量由下式给出：

$$
\theta \xi = \theta (0, 0, 0, \frac {\pmb {t}}{\| \pmb {t} \|}), \qquad \theta = \| \pmb {t} \|.\tag{8}
$$

对于其他情况，运动速度 $\theta$ 和旋转轴 ω 由下式给出：

$$
\theta = \cos^ {- 1} \left(\frac {t r a c e (\boldsymbol {R}) - 1}{2}\right), \omega = \frac {1}{2 \sin (\theta)} \left( \begin{array}{c} r _ {3 2} - r _ {3 2} \\ r _ {1 3} - r _ {3 1} \\ r _ {2 1} - r _ {1 2} \end{array} \right).
$$

为了求得 v，需要对从罗德里格斯公式得到的矩阵

$$
{\boldsymbol {A}} = {(I - \exp (\theta \hat {\omega})) \hat {\omega} + \omega \omega^ {T} \theta}\tag{9}
$$

求逆，并乘以平移向量 $\mathbf { \Delta } _ { t , \tiny { \begin{array} { r l } \end{array} } } t ,$：

$$
\boldsymbol {v} = \boldsymbol {A} ^ {- 1} \boldsymbol {t}.\tag{10}
$$

这是由构成 A 的两个矩阵在 θ $^ { \prime } \neq$ 0 时具有相互正交的零空间这一事实所决定的。因此，$A v = 0 \Leftrightarrow v = 0 .$

我们将从 $S E ( 3 )$ 到 $s e ( 3 )$ 的变换称为对数映射 l<sub>og</sub>(M)。

## 2.3. RBM 的坐标变换与缩放

刚体运动（RBM）的效果取决于其各自的世界坐标系。因此，为了将相对运动从先前的位姿转换到当前的世界坐标系，需要进行适当的坐标变换。例如，假设存在两个位姿 $P _ { 1 }$ 和 $P _ { 2 } \in S E ( 3 )$。从 $P _ { 1 }$ 到 $P _ { 2 }$ 的相对运动由 $P _ { 2 } P _ { 1 } ^ { - 1 }$ 给出，对应的旋量（twist）为 $\xi _ { 1 } = \log ( P _ { 2 } P _ { 1 } ^ { - 1 } )$，见 Figure 1。位于另一个坐标系 $M _ { 1 }$ 中的点 $x _ { i }$ 现在可以用 $x _ { i } ^ { \prime } = \exp ( \xi _ { 1 } ) x _ { i }$ 进行变换，但这（通常）不会产生相同的相对运动。相反，点 $x _ { i }$ 必须先转换到世界坐标系 $P _ { 1 }$，用 <sub>exp</sub>(ξ1) 进行变换，然后再转换回来以得到 $M _ { 2 }$。

该坐标变换可以通过借助所谓的伴随变换（adjoint transformation）[12] 调整旋量 $\xi _ { 1 }$ 来表示：若 $\xi _ { 1 } ~ \in ~ s e ( 3 )$ 是坐标系 $P _ { 1 }$ 中的旋量，则对于将坐标从 $P _ { 1 }$ 转换到 $M _ { 1 }$ 的变换 $g \in S E ( 3 )$，$\xi _ { 1 } ^ { \prime } = g \hat { \xi } g ^ { - 1 }$ 即为坐标系 $M _ { 1 }$ 中的对应旋量。这源于对所有可逆矩阵 $g \in \mathbb { R } ^ { 4 \times 4 }$ 均成立的等式 g <sub>exp</sub> $\left( { \hat { \xi } } \right) g ^ { - 1 } = \exp \left( g { \hat { \xi } } g ^ { - 1 } \right)$。

在我们给出的示例中，$\xi _ { 1 } = \log ( P _ { 2 } P _ { 1 } ^ { - 1 } )$，且坐标变换由 $\pmb { g } = \pmb { M } _ { 1 } \pmb { P } _ { 1 } ^ { - 1 }$ <sup>1</sup> 给出。因此，坐标系 $M _ { 1 }$ 中的旋量为

$$
\xi_ {1} ^ {\prime} = g \xi_ {1} g ^ {- 1} = M _ {1} P _ {1} ^ {- 1} \xi_ {1} P _ {1} M _ {1} ^ {- 1}\tag{11}
$$

除了改变坐标系外，我们稍后还会关注对运动进行缩放。旋量表示的优势在于这种缩放非常直接：为了将由 $\dot { \xi ^ { \prime } }$ 描述的运动缩放因子 $\nu \in \mathbb { R }$，只需简单地计算 $\xi ^ { \prime \prime } = \nu \xi ^ { \prime }$。

这进一步允许通过连续求值这些 RBM 来计算来自 $N$ 个局部 RBM 的平均运动，每个局部 RBM 都按 $\dot { \nu } = \textstyle { \frac { 1 } { N } }$ 进行缩放。通过将此平均运动应用于当前位姿对运动进行线性外推，就是我们稍后所称的标准预测（例如 Figure 7 中间的左侧图像）。

## 2.4. 运动学链

运动学链被建模为指数函数的连续求值，并且旋量 $\xi _ { i }$ 用于对（已知的）关节位置进行建模。末端执行器上的一个点经刚体运动附加变换后表示为

$$
X _ {i} ^ {\prime} = \exp (\theta \hat {\xi}) (\exp (\theta_ {1} \hat {\xi_ {1}}) \dots \exp (\theta_ {n} \hat {\xi_ {n}})) X _ {i}.\tag{12}
$$

为简便起见，在本文的后续部分中，我们将姿态配置表示为 $( 6 + n ) – \mathrm { D }$ 向量 $\chi =$ $( \xi , \theta _ { 1 } , \dots , \theta _ { n } ) = ( \xi , \Theta )$，它由刚体运动 $\xi$ 的 6 个自由度以及关节角向量 $\Theta$ 组成。在动作捕捉（MoCap）设置中，向量 $\chi$ 是未知的，必须从图像数据中确定。

## 2.5. 配准与姿态估计

假设已提取出图像轮廓以及投影表面网格的轮廓剪影，两条轮廓之间的最近点对应关系可用于定义一组对应的 3D 直线与 3D 点。随后，应用一种针对运动链的基于 3D 点-线的姿态估计算法来最小化两条轮廓之间的空间距离：对于基于点的姿态估计，每条直线均被建模为 3D Plücker 直线 $\bar { L } _ { i } = ( n _ { i } , m _ { i } )$，具有（单位）方向 $n _ { i }$ 和力矩 $m _ { i }$ <sub>i</sub> [12]。在姿态估计中，重构的 Plücker 直线与刚体运动的旋量（twist）表示相结合：变换后的 3D 点 $X _ { i }$ 与 3D 射线 $L _ { i } = ( n _ { i } , m _ { i } )$ 的关联性可以表示为

$$
(\exp (\theta \hat {\xi}) X _ {i}) _ {3 \times 1} \times n _ {i} - m _ {i} = 0.\tag{13}
$$

由于 $\exp ( \theta \hat { \xi } ) X _ { i }$ 是一个 4D 向量，为了计算与 $n _ { i }$ 的叉乘，忽略了其齐次分量（即 1）。然后对方程进行线性化并迭代求解。由于关节被表示为形式为 $\theta _ { j } \hat { \xi _ { j } }$ 且无螺距的特殊旋量，其中 $\hat { \xi _ { j } }$ 已知（旋转轴的位置是模型的一部分），而关节角 $\theta _ { j }$ 未知。第 $j$ 个关节上的第 $i$ 个点的约束方程形式为

$$
\left(\exp (\theta \hat {\xi}) \exp (\theta_ {1} \hat {\xi_ {1}}) \dots \exp (\theta_ {j} \hat {\xi_ {j}}) X _ {i}\right) _ {3 \times 1} \times n _ {i} - m _ {i} = 0.\tag{14}
$$

对该方程进行线性化可得到包含 $6 + j$ 个未知数（即 6 个姿态参数和 $j$ 个关节角）的三个线性方程。收集足够多的对应关系可构建一个超定线性方程组，从而能够在最小二乘意义下求解这些未知数。应用第 2.1 节的方法重构群作用，并对变换后的点重复该迭代过程。

## 2.6. 剪影提取

为了寻找图像中人物的轮廓，采用了水平集函数 $\Phi \in \Omega \mapsto \mathbb { R }$。它将图像域 $\Omega$ 分割为两个区域 $\Omega _ { 1 }$ 和 $\Omega _ { 2 }$，其中当 $x \in \Omega _ { 1 }$ 时 $\Phi ( x ) > 0$，当 $x \in \Omega _ { 2 }$ 时 $\Phi ( x ) < 0 \mathrm { ~ i f ~ } x \in \Omega _ { 2 }$。零水平线标记了两个区域之间所要求解的轮廓。

为了获得最优划分，我们最小化以下能量泛函，该泛函是 Chan-Vese 模型 [5] 的扩展版本：

$$
\begin{array}{l} E (\Phi , p _ {1}, p _ {2}) = - \int_ {\Omega} \big (H (\Phi (x)) \log p _ {1} (I (x)) + \\ \qquad (1 - H (\Phi (x))) \log p _ {2} (I (x)) + \nu | \nabla H (\Phi (x)) | \big)   d x \end{array}\tag{15}
$$

其中 $\nu > 0$ 为加权参数，$H ( s )$ 为 Heaviside（阶跃）函数的正则化版本（$\mathbf { a } \ \mathbf { r e g - }$ ularized version），$\mathrm { e . g . }$ 误差函数。概率密度 $p _ { 1 }$ 和 $p _ { 2 }$ 衡量了强度值 $I ( x )$ 与相应区域的拟合程度。这些密度通过局部高斯分布进行建模。区域划分和概率密度 $p _ { i }$ 根据期望最大化原理（expectation-maximization principle）进行估计。

## 3. 无标记动作捕捉 (Markerless Motion Capture)

[13] 中的动作捕捉模型可以通过以下需要最小化的能量来描述：

$$
\begin{array}{l} E (\Phi , p _ {1}, p _ {2}, \chi) = \\ \underbrace {- \int_ {\Omega} (H (\Phi) \log p _ {1} + (1 - H (\Phi)) \log p _ {2} + \nu | \nabla H (\Phi) |) d x} _ {\text { segmentation }} \\ + \underbrace {\lambda \int_ {\Omega} (\Phi - \Phi_ {0} (\chi)) ^ {2} d x} _ {\text { shape   error }} \end{array}\tag{16}
$$

它由第 2.6 节中所述的分割部分以及表述姿态估计任务的附加部分组成。通过轮廓 $\Phi$，这两个问题被耦合在一起。特别地，投影表面模型 $\Phi _ { 0 }$ 作为形状先验来辅助分割 [14]。形状先验对分割的影响由参数 $\lambda ~ = ~ 0 . 0 5$ 控制。由于优化问题的非线性，我们采用迭代最小化方案：首先保持姿态参数 $\chi$ 不变，同时关于划分最小化该泛函。

然后保持轮廓不变，同时确定姿态参数以使表面网格与轮廓相拟合（第 2.5 节）。[2] 中提出了一种使用图割（graph cuts）进行联合分割与姿态估计的类似方法。

该模型尚未将关于预期运动模式的先验知识考虑在内。因此，结果的质量取决于图像数据对解的确定程度。在存在误导的情况下，上述能量函数的极小值可能并不是真实的姿态。此外，由于我们采用的是局部极小化方案，系统在跟丢之后通常无法恢复。因此，我们现在将展示如何从训练数据中计算姿态预测，以及在图像数据具有误导性或不充分（例如由于丢帧）的情况下，如何使解保持接近该预测值。

## 3.1. 缩放运动路径

假设我们有一组训练样本

$$
\{\widetilde {\chi} _ {i} := (\widetilde {\xi} _ {i}, \widetilde {\theta} _ {1, i}, \dots \widetilde {\theta} _ {n, i}) := (\widetilde {\xi} _ {i}, \widetilde {\Theta} _ {i}) | i = 0 \dots N \}\tag{17}
$$

其中包含相对于某个原点的旋量（twists）$\widetilde { \xi } _ { i }$ 和关节角向量 $\Theta _ { i } ,$ 参见第 $2 . 4$ 节。我们进一步假设该集合是有序的，并将该有序列表记为 $\mathcal { P } = \langle \widetilde { \chi } _ { 0 } \ldots \langle \widetilde { \chi } _ { N } \rangle$。姿态 $\widetilde \chi _ { i + 1 }$ 是 $\widetilde { \chi } _ { i }$ 的后继，且 $\langle \widetilde { \chi } _ { i - m + 1 } \ldots \widetilde { \chi } _ { i } \rangle$ 表示 $\mathcal { P }$ 中长度为 m 且以位置 i 结尾的子列表。在我们的实验中，我们使用来自 CMU 数据库 [6] 的样本，或者使用我们系统先前采集的数据。

进一步假设，我们已经跟踪了一个图像序列中的 m 帧（在实验中我们使用 $m = 5$）。因此在当前帧 t，我们得到了先前计算出的姿态列表 $\left. \chi _ { t - m + 1 } \ldots \chi _ { t } \right.$。我们希望计算在 $t + 1$ 时刻的姿态预测值 $\underline { { \boldsymbol { \chi } } } = ( \underline { { \boldsymbol { \xi } } } , \underline { { \Theta } } )$。

为此，我们在 P 中定位与先前姿态 $\left. \chi _ { t - m + 1 } \ldots \chi _ { t } \right.$ 最匹配的子列表。示意图见 Figure 2。为了使匹配对于被跟踪人员的速度具有不变性，匹配比较是针对 $\mathcal { P }$ 的不同尺度缩放因子 s 进行的。重新缩放后的数据通过线性插值和重采样获得，记为 $\mathcal { P } ^ { s } = \{ \widetilde { \chi } _ { i } ^ { s } : = ( \widetilde { \xi } _ { i } ^ { s } , \widetilde { \theta } _ { 1 , i } ^ { s } , \ldots \widetilde { \theta } _ { n , i } ^ { s } ) | i = 0 \ldots \lceil s N \rceil \}$。在我们的实验中，我们以 0 1 的步长扫描区间 $[ 0 . 5 \dots 2 ]$。最佳匹配子列表通过下式获得：

$$
\operatorname{argmin} _ {s, j} \sum_ {v = 0} ^ {m - 1} \left(\sqrt {\sum_ {k = 1} ^ {n} (\theta_ {k , t - v} - \widetilde {\theta} _ {k , j - v} ^ {s}) ^ {2}}\right).\tag{18}
$$

仅考虑关节角，因为匹配应当对人体的全局位置具有不变性。

利用先验集合中的最优尺度和位置，我们可以直接获得预测的关节角构型

$$
\underline {{\Theta}} = \Theta_ {t} + \partial \widetilde {\Theta} _ {j + 1} ^ {s} = \Theta_ {t} + (\widetilde {\Theta} _ {j + 1} ^ {s} - \widetilde {\Theta} _ {j} ^ {s}).\tag{19}
$$

![](images/3d862ec5a0b0ef20e2d2216be380f3a82e1e555bf5fbe57e749cf1c36d24f493.jpg)  
Figure 2. 左：先验数据库中的 6 个（共 20 个）角度（展示了 260 个样本中的 130 个）。右：5 个估计姿态的查询。在这种情况下，查询与数据库中的位置 71 相匹配，位置 72 处的导数可用于预测。

我们可以进一步从 $\widetilde { \xi } _ { j + 1 } ^ { s }$ 预测人体的全局运动。相对运动可以通过第 2.2 节中的对数进行计算。此外，我们必须将运动从先验数据的坐标系转换到当前坐标系。该转换已在第 2.3 节中进行了解释。

如果 $g$ 描述了从先验坐标系到当前坐标系的变换，则相对运动由旋量（twist）给出

$$
\hat {\xi} ^ {\prime} = g \log \left(\exp (\hat {\tilde {\xi}} _ {j + 1} ^ {s}) \exp (\hat {\tilde {\xi}} _ {j} ^ {s}) ^ {- 1}\right) g ^ {- 1}.\tag{20}
$$

我们尚未完全完成，因为该表述仍然假设人体的空间速度与关节角速度之间存在相关性。然而，在关节角变化相同的情况下，体型较大的人比较小的人跑得更快。因此，将旋量重新缩放为以下形式至关重要：

$$
\underline {{\hat {\xi}}} := \hat {\xi} ^ {\prime} \frac {\nu}{\widetilde {\nu}},\tag{21}
$$

其中 $\nu$ 是过去 $m$ 帧的平均速度，$\widetilde {\nu}$ 是 $\hat { \xi } ^ { \prime }$ 的速度。这意味着，预测运动的类型由先验数据决定，而其速度则由先前各帧中的速度决定。

预测值 $\underline { { \boldsymbol { \chi } } } = ( \underline { { \boldsymbol { \xi } } } , \underline { { \boldsymbol { \Theta } } } )$ 现在可以通过在 (16) 中的能量函数中添加以下项，来约束 $t + 1$ 时刻 $\chi$ 的估计：

$$
E _ {\mathrm{pred}} = (\log (\exp (\underline {{\hat {\xi}}}) \exp (\hat {\xi}) ^ {- 1}), \underline {{\Theta}} - \Theta)\tag{22}
$$

它为线性系统中的每个参数提供了一个额外的约束方程，将解拉向预测值。因此，即使没有可用的图像数据，解也是良定义的。在这种情况下，$\chi = \underline { { \chi } } 。$

## 4. 实验

实验分为室内实验和室外实验。室内实验提供了受控环境，并允许同时使用基于标记（marker-based）的跟踪系统。配备 8 个摄像头的基于标记的 Motion Analysis 系统提供了一种真实基准（ground truth），并支持定量误差分析。室外实验证明了本文方法在极具挑战性的任务中的适用性：在非受控背景、变化的光照条件以及全身模型下，进行高动态体育活动的无标记动作捕捉。

## 4.1. 室内实验

在室内实验中，我们使用了一种参数化的腿部网格模型，表示为自由曲面贴片。训练数据由来自同一人但在不同序列中采集的行走样本组成。Figure 3 模拟了在跟踪行走序列时丢弃 25 帧（即在这些帧中忽略了所有图像数据）的情况。对于左下角图像中的结果，关节角度是通过应用第 2.3 节中的标准预测进行传递的。虽然速度捕捉得很好，但腿部自然的上下摆动以及前后运动未能得以保持。如第 3.1 节所述，通过将局部速度应用于训练样本可以实现这一点，参见 Figure 3 中的右下角图像。

在 Figure 4 所示的实验中，我们向序列中添加了递增的均匀噪声（从 0% 到 100%，然后再恢复）。因此，求解结果在一定程度上不再受到图像数据的约束。该方法借助预测延续了运动模式。这种延续足够精确，以至于当图像中的结构重新出现时，算法可以继续跟踪。左右膝盖的误差在 Figure 5 中进行了定量分析。黑线是基于标记的 Motion Analysis 系统的结果。蓝线显示估计的角度。在人工丢帧（无图像数据）或动态丢帧（递增噪声）的情况下，它们被标记为红色。行走模式得以保持。在存在噪声的情况下，结果没有那么平滑，因为图像数据仍然会影响结果，但粗略的运动估计得很准确。对于人工丢帧和动态丢帧，膝关节角度的平均误差分别为 2 58 和 2 83 度。

在我们的户外实验中，我们使用了一位男性和一位女性具有 26 个自由度的全身模型。序列是通过配备 Basler 灰度相机的四相机设置（60 fps）采集的。来自 CMU 数据库 [6] 的样本被用作训练数据。Figure 6 展示了取自一次跑步测试（180 帧）的两个示例。顶部图像可视化了我们估计的模型在一个相机视角下的投影，底部图像显示了虚拟环境中的姿态结果。

在 Figure 7 所示的实验中，我们丢弃了 45 帧。中间左侧的图像显示了来自 Section 2.3 的标准预测，中间右侧的图像显示了使用训练集中最佳拟合运动模式的预测。这两种输出都无法继续进行跟踪。在第一种情况下，自然的运动模式未能得以维持。在第二种情况下，预测出了良好的运动模式，但速度不正确。只有如 Section 3.1 中所提出的具有最佳拟合的缩放运动模式，才能产生足够精确的预测，以便在丢帧后继续跟踪（Figure 7 中的最后一行）。

## 5. 总结

我们提出通过将跟踪到的运动模式与训练集中的模式进行匹配，从而在人体运动估计中利用关于熟悉运动模式的先验知识。这使得对新一帧中的姿态进行预测成为可能。得益于刚体运动的运动旋量（twist）表示和尺度不变匹配，我们能够使这种预测对于坐标系的选择以及时间上的尺度缩放具有不变性。这意味着在训练集中某种运动模式只需出现一次，即可用于捕获在不同速度和姿态下的运动。实验表明，尽管存在人工丢帧（此时所有图像数据暂时缺失），我们的方法仍能继续跟踪。此外，实验还证明了将截然不同的运动模式的训练数据进行组合、并跟踪由这两种模式组成的序列是可行的。
