# 基于多视角无标记动作捕捉的带置信区间的生物力学重建

R. James Cotton<sup>1</sup> Shirley Ryan AbilityLab Northwestern University

Fabian Sinz University of Göttingen

## 摘要

多视角无标记动作捕捉（multiview markerless motion capture, MMMC）的进展有望为临床实践和研究提供高质量的运动分析。尽管先前的验证研究表明 MMMC 平均表现良好，但它们并未提供临床实践或 MMMC 大规模应用所需的内容——即针对在使用可能独特的相机配置进行分析的特定个体所给出的特定运动学估计值的置信区间。我们扩展了先前的研究，利用通过可微生物力学模型进行端到端优化的轨迹隐式表示，在给定所有检测到的关键点的情况下学习姿态的后验概率分布。该后验概率通过变分近似进行学习，并估计试验中每个时刻各个关节的置信区间，结果显示虚拟标记点位置的空间误差置信区间通常在 10-15 mm 以内，这与我们先前的验证研究相一致。关节角度的置信区间通常只有几度，并且对于更远端的关节会变宽。该后验分布还对关节角度之间的相关性结构进行了建模，例如髋关节和骨盆角度之间的相关性。通过该方法估计的置信区间使我们能够识别运动学不确定性较高的时间段和试验。

## 1 引言

精确且易于获取的人体运动分析在科研和医学领域具有广阔的前景。然而，要实现这一前景，两项能力至关重要：1）测量具有临床意义的特征，例如基于生物力学的关节角度；2）提供有效的置信区间。后者尤为重要，因为了解测量结果是否可信与了解测量值本身同样重要。

最近，我们表明可微生物力学模型可以改进基于多视角无标记动作捕捉（multiview markerless motion capture, MMC）的生物力学重构 [Cotton, 2024]。这得益于 MuJoCo 物理模拟器 [Todorov et al., 2012] 最近对生物力学模型 GPU 加速的支持，以及 MyoSuite 项目 [Caggiano et al., 2022] 在改进这些模型方面的工作。我们使用一个从时间映射到关节构型的隐式函数来拟合生物力学模型，然后将关节构型输入身体的正向运动学模型中，并通过相机模型重新投影该身体模型。通过优化隐式轨迹模型，预测的标记点位置与检测到的关键点之间的重投影误差被最小化。这种端到端方法比传统的多阶段生物力学重构管线产生了更低的重投影误差，后者首先重构虚拟标记点轨迹，然后对这些轨迹执行逆向运动学计算。

然而，无论是传统方法还是端到端方法，都无法提供其在关节角度上的置信区间度量。在无标记动作捕捉中，这种不确定性会因关键点噪声、遮挡和相机几何构型而有所变化。验证无标记动作捕捉的常用方法是表征特定相机配置在特定人群（例如，针对健全对照组的临床诊断）中进行特定测量时的平均性能。然而，这并没有提供真正需要的信息——在全新的相机配置下，对下一个当前参与者的特定测量的准确度究竟如何？

多视角几何为确定特定轨迹的不确定性提供了线索。如果一个标记点位置被超过 2 台校准相机观测到，则用于描述该映射的直接线性变换（Direct Linear Transform, DLT）方程是超定的 [Hartley and Zisserman, 2003]。三角化 3D 位置后的任何不一致性（即重投影误差）都可能源于关键点检测误差，关键点检测器的置信度得分也可以指示出这一点。这些误差应反映在推断出的 3D 位置周围更大的空间置信区间中，并最终导致通过逆向运动学推断出的关节角度具有更大的不确定性。生物力学还提供了额外的约束条件，例如关节角度限制、恒定的骨骼长度，以及给定身体节段上不同虚拟标记点的相对构型保持不变。这些约束中的任何不一致性都应导致具有更大不确定性的轨迹。然而，这些信息源尚未被用于推断生物力学轨迹的不确定性。

在本工作中，我们展示了如何将轨迹上的隐式表示扩展为概率表示。接着，我们展示了如何利用变分推断将其拟合到同步的多视角视频中。由于关键点检测器在设计上并非概率性的，因此对其检测结果缺乏特征明确的似然函数，这使得该任务更具挑战性。然而，这可以在推断过程中进行联合学习。最后，我们证明了这些置信区间具有良好的校准性。该算法可以在试验的每个时刻为各个关节生成针对单次试验的置信区间，从而在遮挡或相机几何结构导致数据片段不可靠时将其剔除。Figure 1 展示了我们方法的概览。

本项工作通过以下主要贡献解决了这些问题：

• 我们为运动学关节角轨迹上的概率分布拟合了一个隐式表示至无标记动作捕捉数据，该表示包含低秩相关结构。

• 我们使用快速、可微的生物力学模型对其进行端到端优化，以匹配检测到的关键点。

• 我们表明该方法能产生良好校准的不确定性估计，同时为关节角度提供紧凑的置信区间。

## 2 方法

## 2.1 运动学轨迹不确定性的变分推断

## 2.1.1 预备知识

多视角无标记动作捕捉系统在每个时间点为每个相机生成一系列图像。这些图像由关键点检测器处理，为每张图像输出一组关键点和置信度得分：$( \mathbf { Y } _ { t } , \mathbf { S } _ { t } ) = \{ ( \mathbf { y } _ { t } ^ { c } , \mathbf { s } _ { t } ^ { c } ) \forall c \}$。我们的目标是计算每个时间点姿态参数的后验分布 $p ( \pmb { \theta } _ { t } | \mathbf { Y } _ { t } , \mathbf { S } _ { t } )$，其中 $\pmb { \theta } \in \mathbb { R } ^ { 4 0 }$ 是时间 t 处的运动学关节角。

姿态参数通过两个非线性步骤来预测检测到的关键点位置，Cotton [2024] 对此进行了更深入的描述。首先，可以使用人体的正向运动学模型从姿态参数预测三维空间中的标记点位置 $\mathcal { M } _ { \beta } : \pmb { \theta }  \mathbf { x }$，其中 $\mathbf { x } \in \mathbb { R } ^ { 8 7 \times 3 }$ 是一组覆盖身体的密集虚拟标记点。个性化模型尺度为 $\beta \in \mathbb { R } ^ { 8 + J * 3 }$，其中包括 8 个身体缩放参数，且 $\mathbf { x } \in \mathbb { R } ^ { J \times 3 }$ 为 $J ^ { \bar { } } = 8 7$ 个预测的标记点位置。

接下来，使用校准后的相机模型（包含完整的透视和畸变参数）将这些标记点位置投影到图像平面上，$\Pi _ { c } : \mathbf { x }  \hat { \mathbf { y } } ^ { c }$。在整篇论文中，我们将使用符号 $\hat { \mathbf { y } } ^ { c }$ 来区分标记点位置的假设预测值与从图像中检测到的实际关键点 $\mathbf { y } ^ { c }$。

原则上，我们可以使用贝叶斯法则（Bayes’ rule）在给定观测值的情况下计算姿态轨迹的后验概率：$\begin{array} { r } { p (  { \boldsymbol { \dot { \theta _ { t } } } } | \mathbf { Y } _ { t } , \mathbf { \dot { S } } _ { t } ) = \frac { p ( \mathbf { Y } _ { t } , \mathbf { S } _ { t } | \mathbf { \theta } _ { t } ) p (  { \mathbf { \hat { \theta } } } _ { t } ) } { p ( \mathbf { Y } _ { t } , \mathbf { S } _ { t } ) } } \end{array}$。然而，这是具有挑战性的，因为我们既没有归一化因子 $p ( \mathbf { Y } _ { t } , \mathbf { S } _ { t } )$，也无法通过对高维姿态参数进行边际化来可行地获得它。另一个挑战是似然函数 $p ( \check { \mathbf Y } _ { t } , \mathbf S _ { t } | \check { \pmb \theta } _ { t } )$ 无法直接获取。尽管我们可以假设真实关键点在图像平面上的可能位置 $\hat { \mathbf { y } _ { t } ^ { c } } = \Pi _ { c } \mathcal { M } _ { \beta } \pmb { \theta } _ { t }$，但我们没有关于检测位置和置信度得分的似然函数 $p ( \mathbf { y } _ { t } ^ { c } , \mathbf { s } _ { t } ^ { c } | \hat { \mathbf { y } _ { t } ^ { c } } )$。尤其是，大多数算法的关键点置信度得分并未经过校准，无法参数化此类似然函数。

## 2.1.2 变分近似

尽管归一化项难以计算，我们仍采用通用的变分推断（variational inference）方法来估计后验分布。具体而言，我们用高斯分布 $q ( \pmb \theta _ { t } )$ 来近似后验分布，然后最小化该近似分布与真实后验分布之间的 Kullback-Leibler (KL) 散度：$\hat { D } _ { \mathrm { K L } } [ q ( \pmb { \theta } _ { t } ) | | p ( \pmb { \theta } _ { t } | \mathbf { Y } _ { t } , \mathbf { S } _ { t } ) ]$。虽然真实后验不可得，但最小化 KL 散度的一个界是可行的。为使符号表示更加清晰，我们省略了显式的时间标记，但需注意这是针对每个时间步进行优化的。

$$
\begin{array}{r l} & {\min D _ {K L} [ q (\pmb {\theta}) | | p (\pmb {\theta} | \mathbf {Y}, \mathbf {S}) ] = \int_ {q} q (\pmb {\theta}) \log \frac {q (\pmb {\theta})}{p (\pmb {\theta} | \mathbf {Y} , \mathbf {S})}} \\ & {\qquad = \mathbb {E} _ {q (\pmb {\theta})} \left[ \log \frac {q (\pmb {\theta})}{p (\pmb {\theta} | \mathbf {Y} , \mathbf {S})} \right]} \\ & {\qquad = \underbrace {\mathbb {E} _ {q (\pmb {\theta})} \left[ \log q (\pmb {\theta}) - \log p (\pmb {\theta} , \mathbf {Y} , \mathbf {S}) \right]} _ {- \mathrm{ELBO}} + \log p (\mathbf {Y}, \mathbf {S})} \end{array}
$$

由于 $p ( \mathbf { Y } , \mathbf { S } )$ 为常数，我们可以通过最大化证据下界（Evidence Lower Bound, ELBO）来最小化 KL 散度：

$$
\begin{array}{c} \operatorname{ELBO} (q) := \mathbb {E} _ {q (\boldsymbol {\theta})} \left[ - \log q (\boldsymbol {\theta}) + \log p (\mathbf {Y}, \mathbf {S} | \boldsymbol {\theta}) + \log p (\boldsymbol {\theta}) \right] \\ = H (q) + \mathbb {E} _ {q \sim q (\boldsymbol {\theta})} \left[ \log p (\mathbf {Y}, \mathbf {S} | \boldsymbol {\theta}) + \log p (\boldsymbol {\theta}) \right] \end{array}\tag{1}
$$

姿态先验 $p ( \pmb \theta )$ 可以通过数据学习以反映常见的人体姿态，但这会使解偏向这些常规姿态。然而，由于我们的主要目标是可能与健全人群存在运动差异的临床人群，因此我们在模型的关节限位范围内采用未归一化的均匀分布，而对于超出此范围的值则赋予极低的值。下文我们将详细阐述基于检测关键点的似然函数 $p ( \mathbf { Y } , \mathbf { S } | \mathbf { \boldsymbol { \theta } } )$ )。

因此，从宏观层面来看，显然最大化 ELBO 会倾向于增加估计的姿态后验分布的熵（即在关节角度上产生更大的不确定性），而来自检测关键点的证据则会与之抗衡以降低这种不确定性。

## 2.1.3 姿态概率分布的隐式表示

变分推断（Variational inference）需要一个可以在姿态轨迹上进行优化的概率分布表示 $q ( \pmb \theta _ { t } )$。遵循 Cotton [2024]，我们使用一个从时间映射到轨迹的隐式函数，并将其扩展为同时输出轨迹的均值和协方差：$f _ { \phi } : t \to ( \mu , \mathbf { u } ) . \ f _ { \phi }$ 使用 MLP 实现，输出向量 $\mu _ { \theta } \in \mathbb { R } ^ { 4 0 }$ 以及 $\mathbf { u } \in \mathbb { R } ^ { 4 0 \times R }$。$\mathbf{u}$ 参数化了秩为 R 的 $\Sigma _ { \theta }$ 的低秩表示。

$$
q _ {\phi} (\pmb {\theta} _ {t}) = \mathcal {N} \left(\pmb {\theta} _ {t}; \pmb {\mu} _ {\phi} (t), \Sigma_ {\phi} (t)\right)
$$

姿态的前 6 个元素是骨盆（pelvis）的位置和方向。我们有时会使用四元数表示方向的版本，但在此报告中并未采用，因为欧拉角参数化能产生更具可解释性的相关结构。其余 34 个元素由具有生物力学限制的关节组成。在计算 $\mu _ { \phi } .$ 时，我们将这 34 个元素通过 tanh 非线性函数并重新缩放，以匹配模型指定的限制。由于这仅约束了概率表示的均值位置，部分样本可能仍会超出关节限制。然而，这些样本会受到姿态先验 $p ( \pmb \theta )$ 的进一步惩罚。

## 2.1.4 似然函数

如上所述，关键点检测器不自带经校准的似然函数，而我们需要用它来计算式 (1) 中的 $p ( \mathbf { Y } , \mathbf { S } | \mathbf { \boldsymbol { \theta } } )$。我们的正向运动学模型和相机标定使我们能够预测在给定姿态下关键点被检测到的位置：$\hat { \mathbf { y } } ^ { c } = \Pi _ { c } \mathcal { M } _ { \beta } \pmb { \theta }$。此外，每个关键点都带有一个关联的标量置信度得分 $s _ { j } ^ { c } ,$，该得分应当大致预测关键点的精度。对于我们使用的关键点检测器，该得分测量的是预测噪声，且对于精度较低的关键点得分更高。我们将每个关键点的测量置信度得分视为独立于预测位置，并且检测位置的似然相对于其他关键点是条件独立的，仅取决于预测位置与检测位置之间的欧几里得空间误差 $\epsilon _ { j } ^ { c } = | | \mathbf { y } _ { j } ^ { c } - \hat { \mathbf { y } } _ { j } ^ { c } | |$ 以及置信度得分。

$$
\begin{array}{r l} & {\log p (\mathbf {Y}, \mathbf {S} | \pmb {\theta}) = \sum_ {c, j} \log p (\mathbf {y} _ {j} ^ {c}, s _ {j} ^ {c} | \hat {\mathbf {y}} _ {j} ^ {c})} \\ & {\qquad = \sum_ {c, j} \log p _ {\psi} (\mathbf {y} _ {j} ^ {c} | \hat {\mathbf {y}} _ {j} ^ {c}, s _ {j} ^ {c}) p (s _ {j} ^ {c})} \\ & {\qquad = \sum_ {c, j} \log p _ {\psi} (\epsilon_ {j} ^ {c}, | s _ {j} ^ {c}) + \log p (s _ {j} ^ {c})} \end{array}
$$

我们将误差分布的宽度参数化为置信度分数的二阶多项式，$\sigma _ { \psi } ( s ) = ( \mathrm { s o f t p l u s } ( \psi _ { 0 } ) + \mathrm { s o f t p l u s } ( \psi _ { 1 } ) s + \mathrm { s o f t p l u s } ( \psi _ { 2 } ) s ^ { 2 } )$，其中 softplus 确保了宽度保持为正，并且只会随着表示更大噪声的更高分数而增大。在下文中，我们对比了几种分布类型，发现指数分布通常表现最好，尽管半柯西分布（half-Cauchy）效果也很好。半正态分布（Half Normal distribution）较浅的尾部使得学习不稳定。由于式 $\mathrm { E q ~ ( 1 ) }$ 是针对 $\theta$ 进行优化的，因此 $p ( s _ { j } ^ { c } )$ 没有影响。因此，我们最终最大化：

$$
\operatorname{ELBO} (q) := H (q) + \mathbb {E} _ {q \sim q (\boldsymbol {\theta})} \left[ \log p (\boldsymbol {\theta}) + \sum_ {c, j} \log p _ {\psi} \left(\left| \left| \mathbf {y} _ {j} ^ {c} - \left(\Pi_ {c} \mathcal {M} _ {\beta} \boldsymbol {\theta}\right) _ {j} \right| \right| \mid \sigma \left(s _ {j} ^ {c}\right)\right) \right]
$$

在优化过程中，似然参数 $\psi$ 允许随 $\phi$ 发生变化。

## 2.1.5 实现细节

我们使用在 MuJoCo [Todorov et al., 2012] 中运行的高性能、GPU 加速且可微的生物力学模型来进行正向运动学计算，这与我们在 [Cotton, 2024] 中的前期工作类似。$p _ { \phi } ( \pmb { \theta } _ { t } )$ 是一个实现为 MLP $f _ { \phi }$ 的隐式表示，它输出每个时刻概率分布的均值和协方差。该 MLP 的隐藏层大小为 128、256、512、1024，并带有 relu 非线性激活函数。

该方法使用 Jax 和 Equinox [Kidger and Garcia, 2021] 实现。时间被缩放至不超过 $\pi$，并使用确保最小频率为 80 Hz 的编码维度进行位置编码。概率函数使用重参数化技巧（reparameterization trick）[Kingma and Welling, 2014] 进行优化，每个梯度步使用 8 个样本。我们使用 Optax 中的 AdamW 优化器 [Loshchilov and Hutter, 2019, DeepMind et al., 2020] 进行优化，设置 $\beta _ { 1 } = 0 . 8$ 且权重衰减（weight decay）为 $1 e - 5$。所使用的学习率包含指数衰减，从初始值 $1 e - 3$ 衰减至最终值 $1 e - 8$。我们进行了 30k 次优化步，并在第 2.5k 步时启用关键点似然学习，使用独立的 Adam 优化器，学习率为 $1 e - 3$。所使用的概率分布由 Tensorflow Probability [Dillon et al., 2017] 实现。

双层优化（Bilevel optimization）：除另有说明外，我们并行拟合同一参与者的多条轨迹。在这种情况下，学习了多个 $f _ { \phi }$ 来表示隐式轨迹，但仅学习单组 $\beta$ 和 $\psi$。这种在估计逆运动学的同时联合估计骨骼尺度和标记点偏移的双层优化方法，与需要静态缩放试验的传统方法形成了鲜明对比 [Werling et al., 2022, Cotton, 2024]。由于 Jax 会针对不同的输入尺寸重新编译代码，我们从每个试验中采样 100 个等间距的时间步来计算每个梯度步。与 Cotton [2024] 中类似，相机外参也可以在随后的优化过程中（10k 步后）进行精炼，我们发现这略微改善了结果。在前 7k 步中，我们还保持 $\psi$ 参数冻结。

## 2.2 指标：期望校准误差（Expected Calibration Error）

本工作的一个关键动机是为我们的姿态估计提供准确的置信区间，以指明何时以及在多大程度上可以信任我们的数据。这些置信区间必须经过良好校准（well-calibrated）。例如，如果我们估计了一个 95% 的置信区间，真实值（ground truth）应当大约有 95% 的时间落在该区间内。这可以通过期望校准误差（Expected Calibration Error, ECE）[Song et al., 2019, Pierzchlewicz et al., 2023] 来量化，它衡量了预测的置信区间与实际经验误差分布之间的一致性。然而，这需要姿态的真实值，而我们并没有这些数据。相反，我们针对检测到的关键点测量 ECE，尽管它们并非真实值。简而言之，我们将姿态空间中的后验分布转换为图像关键点空间中的后验分布。仅凭这种转换并不能计入来自关键点似然函数 $\sigma _ { \psi } ( s )$ 的期望方差。我们可以将来自学习到的似然函数的方差与投影到图像平面上的预测后验方差相加，以获得关键点的整体分布，然后类似于我们先前的研究 [Pierzchlewicz et al., 2023] 测量这些关键点的 ECE。为了使该估计更加保守，并避免将过多不确定性归因于似然函数的情况，我们进行了两项修改。首先，在将其与后验方差相加并计算 ECE 之前，我们将似然函数的宽度截断至一个最大值 $\sigma = \operatorname* { m i n } ( \sigma _ { \psi } ( s )$ , σ )，我们将其记作 $\operatorname { E C E } _ { \sigma _ { \mathrm { E } C E } }$。其次，我们仅使用置信度得分最高的前 5% 的关键点作为伪真实值（pseudo-ground truth）。这应当具有最小的测量噪声，并为校准提供最佳的评估。

## 3 实验

## 3.1 合成问题与方法验证

尽管由于篇幅限制我们在此未包含具体结果，但我们针对该问题构建了一个合成玩具示例（synthetic toy example），该示例使用了通过仿射变换测量的单轴上的多个关键点。这些测量具有由置信度得分指示的不同程度的噪声。这些合成实验确保了将后验的变分近似与似然函数参数的估计相结合，能够恢复出实际的似然函数。此外，估计的后验展现出了良好校准的置信区间。

这些实验还表明，生成数据时使用的仿射变换（等价于 $\Pi$）与变分近似中使用的仿射变换之间的差异，可能会导致似然函数中的 $\psi$ 参数产生正向偏差。这使得模型将过多的不确定性归因于观测值，而对后验赋予的不确定性不足，从而产生过于自信的估计。由于我们在真实数据上的结果显示 $\psi$ 值较小，且我们还对 $\Pi$ 相机模型进行了优化，因此我们认为这在实践中并不是一个显著的问题。最后，这些简单示例表明，即使存在这种模型误设（model misspecification），我们基于高置信度测量关键点来测量 ECE 的方法仍然是可靠的，这提供了额外的验证。

## 3.2 参与者

Northwestern University（西北大学）机构审查委员会批准了本研究。我们从在 Shirley Ryan AbilityLab 接受康复治疗的多元化人群（包括住院或门诊患者）中收集了数据。其中包括下肢假肢使用者、因神经系统疾病导致步态障碍的个体以及健全个体。这些数据是在多个地点收集的，使用的设备包括安装在实验室中的相机、沿走廊用三脚架临时搭建的相机，以及在康复健身房顶部呈线性模式安装的采集系统。部分数据还在学术会议上进行了收集，包括 2024 年 AOPA 会议（我们在该会议上收集了健全个体和下肢假肢使用者的数据）以及 2024 年 ASB 会议（我们在该会议上收集了健全个体的数据）。因此，在整项研究中，我们使用了多种多样的相机配置和空间尺度。这些测试主要侧重于行动能力研究，例如步行、计时起立-行走测试（Timed Up and Go）、四方步测试（Four-Square Step Test）以及功能性步态评估（Functional Gait Assessment，不包括楼梯测试）。

## 3.3 数据收集与预处理

数据的收集和预处理按照 Cotton [2024] 中所述进行。简而言之，我们使用自定义软件从 8 到 12 台 FLIR BlackFly S GigE 相机采集同步多视图视频。使用棋盘格或 ChArUco 标定板校准相机的内参和外参。使用 Easymocap 进行初始场景重建和分割 [Dong et al., 2021]，并使用自定义可视化工具对接受分析的人员进行标注。图像使用 MetrABs-ACAE 算法 [Sárándi et al., 2023] 进行处理，该算法在 3D 数据集中使用的关键点超集上进行训练，我们保留了来自 MOVI 数据集 [Ghorbani et al., 2021] 的 87 个关键点。我们先前的研究发现这些关键点非常适用于生物力学分析，对全身的密集覆盖稳定了躯干和躯体部分的估计 [Cotton et al., 2023a,b]。我们的跟踪算法有时会包含位于参与者与相机之间的人员（例如提供协助的物理治疗师）的关键点。我们对关键点采用鲁棒三角测量法来识别与这些异常值相关的相机，并将其从分析中剔除 [Cotton et al., 2023b]。

## 3.4 方法优化与验证

我们的方法中包含许多超参数。我们系统地改变了其中的几个参数，以了解它们对结果的影响。这些实验包括改变似然函数的函数形式和分布秩（distribution rank）。为了进一步验证我们的方法，我们测试了人为合成移除相机以及注入关键点噪声的影响。由于运行所有这些变体需要大量的计算时间，我们在捕获了我们应用场景中部分多样性的一组实验场次（sessions）上运行了它们。这包括不同的相机几何构型和参与者（健全人、下肢假肢使用者和中风康复者）。超参数和消融实验（lesion experiments）使用 Weights and Biases [Biewald, 2020] 进行跟踪。在这些情况下，我们仅使用了给定场次中的四个试验（trials）。

## 3.4.1 似然函数

我们比较了非负空间误差似然函数 $p \big ( \epsilon _ { j } ^ { c } \big | \sigma \big ( s _ { j } ^ { c } \big ) \big ) ;$ 的三种不同形式：半正态（Half Normal）分布、指数（Exponential）分布和半柯西（Half Cauchy）分布。这些分布的尾部逐渐变厚（重尾），这可以使结果对异常值不那么敏感。为了比较这些方法，我们使用 ELBO 作为我们的主要评估指标。这并不完美，因为它是真实似然的下界。然而，在不同模型下测量真实的对数似然在计算上是不可行的（intractable），这也促使我们采用了变分近似方法。

我们发现半正态分布（Half Normal）优化发生了发散，这可能是由于其浅尾特性在初始化期间产生了极低似然度以及不稳定的梯度。指数分布（exponential）和半柯西分布（half-Cauchy）产生了相似的 ELBO，但指数分布的 ELBO 始终略高，因此我们在后续实验中采用了指数分布。

## 3.4.2 分布的秩

我们还测试了概率分布的不同秩（specifically 0, 1, 2, 5, 10, 20, 30, and 40）。我们发现，在这些取值下，ELBO 相当接近，平均重投影误差也是如此。然而，较高秩分布的熵确实略有增加，且平均关节不确定性也相应略微增加。随着分布秩的提高，$\mathrm { E C E _ { 0 } }$ 也有轻微下降。这种效应在大约 20 秩时趋于平稳，因此我们在其余实验中均使用了秩为 20 的设置。

## 3.4.3 注入关键点噪声

为了验证我们的方法能够正确估计关键点噪声水平并测试关键点噪声的影响，我们在不改变置信度得分的情况下，人为地在关键点上注入了额外噪声。这导致了熵和中位数关节角度误差的增加。$\psi _ { 0 }$ 的值也随之增加，并紧密跟踪注入的噪声水平，由于实际噪声的存在其值略低。

## 3.4.4 减少相机数量

我们还仅使用部分相机子集（最少降至两台）对各会话进行了重新分析。为了保证该分析的内部一致性，当仅使用 2 台相机时，我们仅采用了人体在两台相机中均可见的时间点。值得注意的是，我们的方法能够处理仅有一台或没有相机观测到人体的情况，并在这些情况下适当地输出极高的不确定性，我们将在下文中展示这一点。然而，如果将这些时间点包含在内，将会掩盖增加相机所带来的影响。

正如预期所料，随着相机数量的增加，我们的方法在关节角度上表现出更窄的置信区间。在分析中位数误差时，这种影响相当小。然而，相机数量较少时，身体部位被遮挡或移出视野的时段也会增加，因此，在特定时间特定关节的不确定性将远大于该中位数值，尤其是在不仅分析我们在本分析中所采用的精心挑选的时间点时更是如此。

## 3.5 人群指标

在完成这些优化后，我们将该方法应用于数据库中来自 264 名个体在 381 次测试中的 2957 次试验。该数据集特意保持了异质性。它包含了不同数量的相机及其几何布局。人群中还包括部分健全个体（41名）以及由各种病因引起步态障碍的人群，包括假肢使用者（74名）和患有神经系统疾病的个体。除了行走之外，它还包含了各种移动能力评估，例如计时起立-行走测试（timed-up-and-go test）和四方步测试（four-square-step test）。数据采集场景各异，涵盖了从学术会议现场到门诊及住院诊所，其中包括一套集成到住院康复治疗健身房中的系统。在许多情况下，多名额外人员（如物理治疗师或助手）也处于采集视野中。正如设计预期，该方法识别出了一些由于遮挡或视角数量有限而导致跟踪质量较差的试验。它同时也表明，总体而言，我们的跟踪精度非常出色。

## 3.5.1 空间误差

我们通过在每个时间点从概率分布中抽取 250 个样本并将其输入前向运动学模型来量化空间误差。对于每个样本，我们随后计算了每个身体节段位置与几何中位数之间的欧氏距离。在每个时间点，我们计算了第 50 百分位数（中位数）和第 95 百分位数误差。随后，我们对这些身体节段随时间的变化取平均值。这些身体节段对应于我们模型中的骨骼单元，而非虚拟标记点位置。各关节的这些误差直方图如图 5 所示。在所有关节和受试者中，这些误差的第 95 百分位数约为 20mm，这与我们在先前针对仪器化步道进行的空间步态参数验证研究中所观察到的误差高度一致 [Cotton et al., 2023a, Cotton, 2024]。

为了保持可视化的尺度，我们从 2957 次试验中排除了 131 次在各关节间平均第 95 百分位数超过 1 米的试验。这些情况通常发生在存在严重遮挡或初始相机标定出现问题的情形下。

## 3.5.3 期望校准误差 (ECE)

我们还在似然宽度裁剪为 0、1 和 2 像素的情况下计算了 ECE 的总体统计数据。它们的第 50 和第 95 百分位数值分别为 (0.33, 0.43)、(0.07, 0.28) 和 (5e-4, 0.095)。这表明我们的变分后验宽度足以在仅有 1 或 2 像素检测噪声的情况下“覆盖”大多数关键点，并进一步有力地表明我们的分布得到了相当良好的校准，且不会对错误的拟合过度自信。

我们的方法还捕获了姿态不确定性的相关性结构。我们通过在时间上取平均，然后在各试验中取绝对值的中位数来对这一结构进行可视化。结果如图 7 所示。令人欣慰的是，它捕获了许多直观上符合预期的参数间相关性，例如腰部弯曲与髋部屈曲之间，或肩部屈曲与肘部屈曲之间的相关性。

## 4 讨论

我们展示了如何从多视角无标记动作捕捉中计算运动学姿态轨迹的后验概率。该方法采用姿态的隐式表示来表征均值轨迹和协方差结构，并利用变分推断对该轨迹进行优化。该优化还联合学习了关键点上的似然函数，特别是似然函数的宽度如何随关键点置信度分数缩放。从核心来看，该方法利用生物力学和多视角几何的约束，提供用于学习与测量偏差一致的置信区间的信号。

这些置信区间比我们之前使用的质量指标（例如平均重投影误差 [Cotton et al., 2023a,b, Cotton, 2024]）更为有用。它们直接反映了我们所关注的目标——我们在每个时刻追踪关节角度和身体部位位置的准确程度。传统的验证研究通常是在特定条件下（如特定的相机几何结构和临床人群）汇总比较两种模态的统计数据，与之相比，该方法能够对新的个体和相机配置评估其准确性。我们相当低的 ECE 分数表明，我们的置信区间经过了相当好的校准，这意味着在 95% 的情况下，真实值应当落在我们的 95% 置信区间内。我们的跟骨中位空间误差（通常小于 10 mm）与使用步态分析压力步道（instrumented walkway）测得的步长误差相近（通常也小于 10 mm）[Cotton, 2024]，这进一步支持了上述结论。我们的消融实验（lesion experiments）为该方法的有效性提供了额外的证据，例如能够恢复注入的关键点噪声量，以及随着相机数量的减少不确定性相应增加。

我们同样乐观地认为，该方法将成为评估 MMMC 流水线准确性的强大工具，包括测试更新的关键点检测器并确定其可靠性指标的准确程度。我们还发现一些迹象表明，与我们先前的确定性方法相比，该方法不易陷入局部极小值，表现为极高重投影误差的拟合结果更少。在这些局部极小值处出现的视角间不一致性会导致更大的不确定性，从而使变分采样能够识别出更合理的拟合。然而，我们的方法也存在局限性。优化概率表示比我们的非概率隐式表示慢数倍；例如，在 A100 上进行 10-20 次试验可能需要 1-2 小时。我们的合成测试还表明，某些建模偏差（例如标定误差）可能会因将过多的不确定性归因于似然函数而产生过度自信的结果。我们的 ECE 指标也显示后验分布并未实现完美校准。早期实验表明，可以将 ECE 纳入损失函数中以进一步防止过度自信，我们将在未来的工作中对此进行更全面的探索。

## 5 结论

利用变分推断可以从多视角无标记动作捕捉（MMMC）中重建带有置信区间的生物力学轨迹，其中跨视角或跨时间的不一致性为置信区间何时应当更宽提供了学习信号。该方法超越了传统的验证研究，传统研究仅旨在回答在验证条件下哪些指标平均表现良好。

相反，它能够针对特定的个体和相机几何结构（可能存在多重遮挡）估计关节角度和位置的置信区间。我们的置信区间为 MMMC 结果何时可信以用于进一步分析提供了关键信号，这对于推广到临床实践或大数据运动科学至关重要。

## 评估指标：预期校准误差 (Expected Calibration Error)

本项工作的一个关键动机是为我们的姿态估计提供置信区间，以表明我们的数据何时可信或不可信。这些置信区间必须经过良好校准。例如，如果我们估计一个 95% 的置信区间，真实值（ground truth）落在该区间内的概率应约为 95%。这可以通过预期校准误差（Expected Calibration Error, ECE）[Song et al., 2019, Pierzchlewicz et al., 2023] 来量化，它衡量了预测置信区间与实际经验误差分布之间的一致性。然而，我们没有真实的姿态来测量或验证这一点。获取真实值需要使用双平面透视（biplanar fluoroscopy）来实时追踪骨骼，这在大规模应用中是不切实际的。

相反，我们通过将预测的关键点分布与图像空间中检测到的关键点进行比较来评估校准。关键点分布有两个不确定性来源。首先，姿态轨迹中的认知不确定性（epistemic uncertainty）由我们的变分后验 $q ( \pmb \theta _ { t } )$ 建模，它映射为预测关键点的分布。第二个不确定性来源是来自关键点检测器的测量不确定性，该不确定性由似然函数捕获。这些来源的结合应反映关键点检测中的真实变异性。然而，如果变分后验低估了不确定性，而似然函数高估了不确定性，则会出现一种潜在的失效模式，从而产生经过校准但无法准确表示姿态不确定性的关键点置信区间。

在计算关键点的校准（calibration）时，我们通过两处微调来缓解这一失效模式。首先，我们使用检测置信度最高的前 5% 的关键点来近似真实（ground-truth）关键点。这些关键点应具有最小的测量噪声，从而可以作为评估校准的伪真实标签（pseudo-ground truth）。此外，我们独立于 $\psi$ 和 $s$ 的取值对似然函数的宽度进行截断，即 $\boldsymbol { \sigma } = \operatorname* { m i n } ( \sigma _ { \boldsymbol { \psi } } ( s ) , \sigma _ { \mathrm { E C E } } )$，以防止过多的不确定性被归因于似然函数。直观地说，在真实关键点的极限情况下，使用 $\sigma _ { \mathrm { E C E } } = 0$ 时，一个校准良好的结果将要求由后验分布 $q ^ { \hat { \mathbf { Y } _ { c } } } ( \hat { \mathbf { y } _ { c } } ) = ( \Pi _ { c } \mathbf { \mathcal { M } } _ { \beta } ) _ { * } q ( \pmb { \theta } )$ 诱导的关键点不确定性足够宽泛，以覆盖来自所有视角的全部关键点，其中 $( \mathbf { \bar { I I } } _ { c } \mathbf { \mathcal { M } } _ { \beta } )$ 是将姿态密度映射到关键点密度的推前算子（pushforward operator）。在实践中，我们监测 $\sigma _ { \mathrm { E C } E }$ 在 0 到 5 像素之间的若干取值下的 ECE。我们的实现方式是：利用推前算子的雅可比矩阵（Jacobian）构建 $q ^ { \hat { \mathbf { Y } } _ { c } } ( \hat { \mathbf { y } _ { c } } )$ 的泰勒近似（Taylor approximation），然后在最终分布中加上 $\sigma _ { \mathrm { E } C E } ^ { 2 }$ 的方差。这会产生一个具有均值位置 $\mu ,$ 和尺度 $\sigma ^ { 2 }$ 的关键点位置二维分布。尽管严格来说这可以是各向异性（anisotropic）的，但我们采用了 $x$ 和 $y$ 方向上的平均尺度。因此，对于用于计算 ECE 的每个关键点，我们都拥有一个预测分布（记为 $D _ { i }$）以及一个检测位置 $\mathbf { y } _ { i }$。

我们没有对预测误差分位数进行分箱，而是通过一种称为概率-概率（P-P）图的拟合优度检验等价形式来计算 ECE；在该图中，关键点误差的经验累积分布被绘制为预测累积分布的函数。这也可以理解为概率积分变换（Probability Integral Transform, PIT）的应用，其中随机变量 X 通过其累积分布函数 F 进行变换，生成在区间 [0,1] 上均匀分布的变换变量 $C = F ( X )$。因此，按秩排序的 C 样本应当落在对角线上。为了将其应用于 $( \mathbf { y } _ { i } , D _ { i } )$ 的样本，我们首先测量径向误差 $\mathrm { e r r } _ { i } = \lVert \mathbf { y } _ { i } - \boldsymbol { \mu } _ { i } \rVert$。各向同性 2D 高斯分布的径向距离预计服从瑞利分布（Rayleigh distribution），我们在累积分布函数（CDF）中使用该分布：$c _ { i } = F _ { \mathrm { R a y l e i g h } ( \sigma ) } ( \mathrm { e r r } _ { i } )$。然后我们将 $\left\{ c _ { i } \right\}$ 的样本按升序排序以得到 $\tilde { c } _ { 1 } \leq \cdots \leq \tilde { c } _ { N }$。最后，我们计算 $\begin{array} { r } { \mathrm { E C E } \ = \ \frac { 1 } { N } \sum _ { i = 1 } ^ { N } \left| \tilde { c } _ { i } - p _ { i } \right| } \end{array}$，其中 $\{ p _ { i } = i / N \}$ }。当明确指出用于计算 $D _ { i } .$ 的 $\sigma _ { \mathrm { E C } , E }$ 时，我们将 ECE 记作 $\mathrm { E C E } _ { \sigma _ { \mathrm { E C E } } } ^ { \cdot } .$。

$$
\hat {\mathbf {y}} _ {t} ^ {c} = g _ {c} (\pmb {\theta} _ {t}) = \Pi_ {c} \mathcal {M} _ {\beta} \pmb {\theta} _ {t}
$$

$g _ { c }$ 关于均值 $\pmb { \mu } _ { \pmb { \theta } _ { t } } = \pmb { \mu } _ { \phi } ( t )$ 的一阶泰勒展开式为：

$$
g _ {c} (\pmb {\theta} _ {t}) \approx g _ {c} (\mu_ {\pmb {\theta} _ {t}}) + J _ {g} (\pmb {\mu} _ {\pmb {\theta} _ {t}}) (\pmb {\theta} _ {t} - \pmb {\mu} _ {\pmb {\theta} _ {t}})
$$

$$
\mathrm{Cov} [ \pmb {y} _ {t} ^ {c} ] \approx \mathrm{Cov} [ g (\pmb {\theta} _ {t}) ] _ {\pmb {\theta} _ {t} \sim q (\pmb {\theta} _ {t})} \approx J _ {g} (\pmb {\mu} _ {\pmb {\theta} _ {t}}) \Sigma_ {\pmb {\theta} _ {t}} J _ {g} (\pmb {\mu} _ {\pmb {\theta} _ {t}}) ^ {\top}
$$
