# 用于人体姿态估计的渐进式方向感知姿态语法

Lu Zhou , Yingying Chen , and Jinqiao Wang , Member, IEEE

摘要—人体姿态估计受到诸多因素的挑战，例如复杂的关节活动、遮挡等。通常，人体关节点之间的信息传递在纠正由上述挑战导致的错误检测中起着重要作用。在本文中，我们提出了一种渐进式方向感知姿态语法模型，通过以一种新颖的方式构建姿态语法来进行信息传递。首先，提出了一种多尺度 Bi-C3D 姿态语法模块，以促进局部范围内人体关节点之间的信息传递。我们提出通过 3D 卷积（C3D）进行信息传递，事实证明，与其他序列建模技术相比，这种方法更为有效。为了促进信息传递，我们设计了一种新颖的自适应方向引导模块，其中嵌入了显式的方向信息。此外，我们提出利用注意力图（attention maps）融合最终结果，以充分利用双向信息，该融合可视为一个集成过程。其次，引入了一种更经济的全局区域语法来全局构建人体关节点之间的关系。这种由局部到全局的建模方案以渐进的方式促进了信息传递，并大幅提升了性能。在 MPII、LSP 和 COCO 基准数据集上均取得了极具竞争力的结果。

关键词—人体姿态估计（Human pose estimation），姿态语法（pose grammar），C3D，方向感知（direction-aware），信息传递（message passing）。

## I. 引言

人体姿态估计作为一项基础任务，旨在给定特定人体图像时定位人体关节点。它已被应用于各种视觉任务中，例如基于骨架的动作识别 [1], [2], [3]、行人重识别（person re-identification）[4] 等。

得益于卷积神经网络（CNN）的发展，该领域已取得了显著进展。然而，性能仍然面临着诸如严重遮挡、复杂的关节活动以及杂乱背景等若干障碍的挑战。由于上述挑战引起的上下文歧义，网络无法正确定位人体关节点的位置。促进人体关节点之间信息传递的关系建模在处理这些困境时被证明是有效的。通过信息传递，可以捕获人体固有的层级结构。此外，借助学习到的结构信息，可以纠正次优的人体关节点预测。基于这一观点，我们提出了一种渐进式方向感知 Bi-C3D 姿态语法模型，以一种新颖的方式进行信息传递，相比现有框架展现出了巨大的优势。我们的创新之处在于设计了合理的语法模块以提升关系建模的性能。

首先，我们提出了一种多尺度方向感知 Bi-C3D 运动学姿态语法模块，用于在局部范围内执行消息传递。其次，我们提出了一种方向感知 Bi-C3D 区域姿态语法模块，用于全局执行消息传递。上述语法的整合渐进式地进行了消息传递，从而同时构建了局部和全局关节关系。此外，这两个语法模块中还融入了基于注意力的结果融合机制，以动态结合来自两个方向的结果。而且，我们定制了一个自适应方向引导模块，为语法模块提供显式的方向信息，从而促进了消息传递过程。

为了在局部范围内进行关系建模，我们开发了 Bi-C3D 运动学姿态语法，以捕获人体关节之间的运动学关系。例如，我们可以构建一个与手腕、手肘、肩膀相关的语法子模块，并在它们之间进行消息传递。我们没有采用涉及更多参数的 Bi-LSTM（bidirectional LSTM，双向长短期记忆网络），而是利用了在时空特征学习中展现出巨大优势的 Bi-C3D，以提高关系建模的有效性。

如先前工作 [5] 所指出的，人体关节之间的消息传递不仅传递高层语义信息，而且在一定程度上还起到了空间位移和几何变换的作用。然而，由于缺乏方向信息，消息传递的有效性可能会被削弱。原始特征图包含更多的上下文信息，而忽略了位置和方向信息。在本文中，我们提出了一种方向引导机制，其中引入了 CoordConv [6] 来解决这个问题。CoordConv 为输入图像附加了额外的坐标通道，使卷积滤波器能够访问输入坐标，并且渐变的坐标图编码了显式的方向信息。在此，我们考虑将坐标通道追加到关节特征中，以向 3D 卷积滤波器提供方向信息。尽管追加坐标通道加速了语法模块的收敛和学习，然而性能并不那么令人满意。一个挑战是，尽管追加机制可以加速收敛和学习过程，但性能并非最优。这可能是因为提供恒定方向引导的固定坐标通道并不适合语法学习。此外，为了使引导更具自适应性，我们通过生成的权重图对坐标通道重新加权，这可以动态调整这些坐标通道的状态。

Bi-C3D 姿态文法模块分别在两个不同方向上进行消息传递。然而，双向特征的简单组合带来的提升微乎其微。为了克服上述挑战，我们考虑通过注意力机制融合双向热图。注意力图可以有选择地从这两个分支中提取有用信息。此外，在最终热图上进行融合可以自动排除深层特征中的大量噪声。

不同尺度的特征编码了不同层级的信息。从本质上讲，低分辨率特征编码了更多人体结构的全局上下文信息，而高分辨率特征则包含更多对精确定位至关重要的空间细节。如何增强多尺度特征的鲁棒性对姿态估计非常重要。为了实现这一目标，我们提出了一种多尺度方向感知 Bi-C3D 运动学姿态文法模块，在不同层级执行消息传递并提高每个尺度的特征质量。

为了进一步建模不同人体关节点之间的长程依赖关系，我们开发了一种 Bi-C3D 区域姿态文法以扩大消息传递的范围。具体而言，我们没有在所有人休关节点之间进行消息传递，而是在人体上半身和下半身内部独立构建全局区域文法。这种权衡节省了整体参数量和计算量，且精度仅有微小的下降。

上述所有模块构成了我们的渐进式方向感知姿态文法网络。我们的贡献可以总结如下：

• 提出了一种多尺度方向感知 Bi-C3D 运动学姿态文法模块，用于在不同尺度下的局部范围内构建人体关节点之间的关系。3D 卷积在消息传递中表现出巨大优势，显著提升了最终精度。

• 在姿态文法中引入了方向引导机制以促进消息传递过程。改进的 CoordConv 为消息传递提供了自适应的方向信息，提高了姿态文法的有效性。

• 提出了一种基于注意力的结果融合机制，以有选择地组合来自不同方向的结果。此外，这是首次尝试在热图层面上融合双向文法信息，该过程可被视为一种集成过程。

• 提出了一种在更大范围内构建关节点关系的方向感知 Bi-C3D 区域姿态文法模块，以在全局范围内进行消息传递。

本文的初步会议版本见于 [7]。与会议版本相比，本文主要在以下几个方面有所不同：(a) 提出了一种提供自适应方向信息的方向引导机制，用于指导姿态语法模块的学习。(b) 提出了一种基于注意力机制的结果融合机制，以更有效的方式融合双向信息。(c) 构建了一种更为经济的 Bi-C3D 区域姿态语法模块来构建人体关节之间的关系，与之前的版本相比大幅减少了计算量。(d) 我们在三个广泛使用的姿态基准数据集（即 MPII、LSP 和 COCO）上扩展了实验，并取得了优异的结果。

## II. 相关工作

## A. 单人姿态估计

人体检测是执行后续姿态估计的第一步。[8]、[9] 中提出的人体检测器通常用于该流程中。卷积神经网络在各种视觉任务中取得了巨大的进展。对于人体姿态估计，Deeppose [10] 首次尝试利用 ConvNets 回归人体关节的坐标。[5] 中引入了几何变换核以在人体关节之间进行信息传递。[11]、[12] 是一些使用 hourglass 作为主干网络（backbone）的典型工作。HRNet [13] 提出在所有阶段保持高分辨率特征，并取得了优良的结果。[14] 提出了 Lite-HRNet 以提高人体姿态估计模型的效率。参考文献 [15] 提出了一种在线蒸馏方案，并获得了参数量更少的学生模型。TokenPose [16] 采用 token 表示来学习约束和外观信息。TransPose [17] 采用自注意力机制来学习非局部关系。HRFormer [18] 遵循多分辨率设计，并在每个分辨率分支中采用了局部窗口自注意力机制。[19] 中提出了消除积分人体姿态估计中的潜在偏差。PoseTrans [20] 提出了一种新的数据增强方法以增加罕见姿态的多样性，并缓解了长尾问题。工作 [21] 设计了一种快速且高效的人体姿态估计 Transformer 框架。SimCC [22] 将人体关键点的预测重构为分类任务，从而减少了量化误差。HDM [23] 解决了分布匹配问题，以避免构建高斯平滑热图。在这些方法中，存在一些专注于捕获身体结构的方法。

然而，在基于 MRF 的模型 [24], [25] 中，大卷积核很难学习。对于结构化特征学习 [5]，则仅探索了局部几何约束。

对于组合模型 [12]，并没有在人体关节点之间执行显式的消息传递。在我们的方法中，我们构建了 Bi-C3D 姿态语法（Bi-C3D pose grammar）来学习结构先验。首先，该方法不涉及大卷积核。此外，我们构建了局部和全局消息传递模块，以渐进的方式促进信息流动。

## B. 语法构建

基于语法的模型已在各个领域展现出其有效性。参考文献 [26] 提出了一个随机语法模型来解决图像解析问题。[27] 中提出了一种分层属性语法网络，用于编码人体关节点之间的高阶关系。参考文献 [28] 利用两种时尚语法来编码高级人类知识，以进行时尚关键点检测。工作 [29] 采用了 [27] 中的语法设计，并提出了一种数据增强方案以提高 3D 人体姿态估计的泛化能力。GWN [30] 提出了语法诱导小波网络（Grammarinduced Wavelet Network），以利用人体结构信息进行人体解析任务。与上述方法不同，我们提出了一种渐进式方向感知姿态语法学习网络，该网络配备了 C3D，而不是大量消耗内存的 LSTM。此外，我们进一步利用注意力机制融合来自两个相反方向的热图。

## C. CoordConv

通过 CNN（卷积神经网络）学习从笛卡尔空间中的坐标 (x,y) 到独热像素空间中的坐标的映射已被证明是一项困难的任务。参考文献 [6] 提出了 CoordConv，通过在输入图像后追加额外的坐标通道，以一种优雅的方式解决了这一映射问题。这三个通道对坐标信息 (x, y) 和中心度信息 (r) 进行编码。将坐标通道与输入图像拼接后构成了最终的输入。所提出的 CoordConv 层提升了生成对抗网络（GANs）、变分自编码器（VAEs）和目标检测等各种任务的性能。参考文献 [31] 在面部关键点检测任务中采用了 CoordConv 并取得了不错的效果。在本文中，我们将额外修改后的坐标通道附加到姿态语法输入特征上，而不是输入图像上。逐渐变化的坐标为姿态语法模块提供了显式的方向信息。

## III. 方法

在本节中，我们将首先简要介绍我们提出的渐进式方向感知姿态语法网络的整体架构。随后，我们将详细阐述各个组件，以展示这些模块如何协同工作来完成这项任务。

## A. 网络结构

在本文中，我们采用堆叠沙漏模型（stacked hourglass model）作为骨干网络，为后续的文法模块提取代表性特征。该框架的示意图见 Fig. 1。我们在骨干网络的末端添加了渐进式方向感知姿态文法模块。所添加的姿态文法模块主要由以下组件构成：a) 多尺度方向感知 Bi-C3D 运动学姿态文法（multi-scale DAKPG）模块。b) 方向感知 Bi-C3D 区域姿态文法（DARPG）模块。这种局部-全局建模方案能够以渐进式的范式有效地建立不同范围的关系。

## B. 多尺度方向感知 Bi-C3D 运动学姿态文法

所提出的多尺度方向感知 Bi-C3D 运动学姿态文法（multi-scale DAKPG）描述了运动学连接的人体关节之间的约束。

文法构建：姿态文法是建立人体各部位之间关系的有效方式。为了捕获人体结构的运动学规则，在本节中，我们在 MPII、LSP 数据集上定义了 5 个运动学子文法，用于进行局部细化：

G<sup>K</sup> : r.ankle ←→ r.knee ←→ r.hip,

G<sup>K</sup><sub>2</sub> : l.ankle ←→ l.knee ←→ l.hip,

G<sup>K</sup> : r.wrist ←→ r.elbow ←→ r.shoulder,

$$
G _ {4} ^ {K}: l. w r i s t \longleftrightarrow l. e l b o w \longleftrightarrow l. s h o u l d e r,
$$

$$
G _ {5} ^ {K}: \text {   head   } \longleftrightarrow \text {   neck   } \longleftrightarrow \text {   thorax   } \longleftrightarrow \text {   pelvis.   }
$$

在视频理解领域，C3D 将时序特征 $F$ 作为输入，其中 $F \in R ^ { C \times T \times H \times W }$。与 2D 卷积不同，C3D 可以同时编码空间和时序信息。对于语法模块，可以通过沿时序维度拼接不同种类的关节特征来构建时序序列。因此，获取关节感知特征对于各种人体关节之间的信息传递具有重要意义。我们首先以单尺度的语法构建为例进行说明。在此，我们将单尺度特征 $F _ { 1 }$（如图 1 所示）划分为 $Q$ 组，其中 $Q$ 表示人体关节的数量。我们分别对划分出的 $Q$ 组特征应用 $Q$ 组 $1 \times 1$ 卷积以获得最终的热图。在这种情况下，每个划分的特征对应于一个特定的人体关节并具备关节感知能力。随后，姿态语法模块将这 $Q$ 组特征作为输入，信息传递过程由自然支持链式结构的双向（前向/后向）C3D（Bi-C3D）实现。以 $G _ { 1 } ^ { K }$ 为例，右踝、右膝、右髋的特征张量定义为 $\begin{array} { r c l c r c l } { X _ { r a n k } } & { \in } & { R ^ { N \times C _ { i n } ^ { \bf \bar { \nu } } \times H \times W } , X _ { r k n e e } } & { \in } & { R ^ { N \times \bar { C } _ { i n } \times H \times W } , X _ { r h i p } } & { \in } \end{array}$ $R ^ { N \times C _ { i n } \times H \times W }$，其中 $N$ 表示批大小，$C _ { i n } , H , W$ 分别表示对应特征张量的通道数、高度和宽度。对于前向传播，我们沿深度维度按顺序拼接 $X _ { r a n k } , X _ { r k n e e } , X _ { r h i p }$；对于后向传播，我们沿深度维度按相反顺序拼接 $X _ { r a n k } , X _ { r k n e e } , X _ { r h i p }$。拼接后的特征用作语法模块的输入源，其中包含两组 3D 卷积。

方向引导机制：通常，特征上的信息传递可以被视为空间平移操作。具有充足空间覆盖范围的连续 3D 卷积核将特征图从一个关节点平移到另一个人体关节点，为平移操作提供明确的方向信息至关重要。为实现这一目标，我们采用编码了坐标信息的 CoordConv 操作来提升信息传递的性能。具体而言，我们沿深度维度将额外的坐标通道与输入特征进行拼接。如图 3(a) 所示，Co 表示与 [6] 形式相同的额外坐标通道。$C o _ { i } , C o _ { j } , C o _ { i }$ <sub>r</sub> 分别代表 Co 的 $i , j ,$ r 通道。对于第 i 个通道 $C o _ { i }$，第一行填充 0，第二行填充 1，第三行填充 2，其余行遵循相同的填充过程；对于 j 通道 $C o _ { j } .$，第一列为 0，第二列为 1，第三列为 2，其余列遵循相同的填充技术；此外，还引入了 r 坐标通道 $C o _ { r }$，其中 $r = \sqrt { ( i - w / 2 ) ^ { 2 } + ( j - h / 2 ) ^ { 2 } }$。附加通道的具体说明可见图 3(b)。具有明显变化趋势的坐标通道 Co 提供了明确的方向信息。

M _ {r l e g f} = A M G _ {r l e g f} \big (X _ {r l e g} \big),\tag{1}
$$

其中 $A M G _ { r l e g f }$ 表示右腿的自适应掩码生成器，$M _ { r l e g f }$ 表示前向传递生成的自适应掩码。然后，我们通过以下公式利用生成的掩码修改坐标通道：

$$
C o _ {f} ^ {\prime} = M _ {r l e g f} * C o.\tag{2}
$$

修改后的坐标通道 $C o _ { f } ^ { \prime }$ 可以根据训练状态自我调整，并提供自适应的方向信息。在此，我们将修改后的坐标通道 $C o _ { f } ^ { \prime }$ 沿通道维度拼接至输入特征 $X _ { r a n k } , X _ { r k n e e } , X _ { r h i p }$，生成的输入特征表示为 $\begin{array} { r l } { X _ { r a n k f } ^ { \prime } } & { { } \in } \end{array}$ N×(C<sub>in</sub>+3) ×H×W $\begin{array} { r l r } { X _ { r k n e e f } ^ { \prime } } & { { } \in } & { R ^ { N \times ( C _ { i n } + 3 ) } } \end{array}$ ×H×W $X _ { r h i p f } ^ { \prime } \in$ $R ^ { N \times ( C _ { i n } + 3 ) } \times H \times W$。按照上述相同流程，可以获得 $X _ { r a n k b } ^ { \prime } , X _ { r k n e e b } ^ { \prime } , X _ { r h i p b } ^ { \prime }$。随后，对于前向传递，我们沿深度维度按顺序拼接 $X _ { r a n k f } ^ { \prime } , X _ { r k n e e f } ^ { \prime } , X _ { r h i p f } ^ { \prime }$；对于后向传递，我们沿深度维度按相反顺序拼接 $X _ { r a n k b } ^ { \prime } , X _ { r k n e e b } ^ { \prime } , X _ { r h i p b } ^ { \prime }$，即 $I _ { 1 f } ^ { K ^ { \prime } } \ \in \ ^ { \prime } R ^ { N \times 3 \times ( C _ { i n } + 3 ) \times H \times W } , I _ { 1 b } ^ { K ^ { \prime } } \ \in$ $R ^ { N \times 3 \times ( C _ { i n } + 3 ) \times H \times W }$。之后，修改后的双向腿部特征与两组 3D 卷积进行卷积以执行细化，输出特征可表示为 $O _ { 1 f } ^ { K } \in R ^ { N \times 3 \times C _ { o u t } \times H \times W } , O _ { 1 b } ^ { K } \in R ^ { N \times 3 \times C _ { o u t } \times H \times W }$。

我们通过沿深度维度分割输出特征 $O _ { 1 f } ^ { K } , O _ { 1 b } ^ { K }$ 来获取双向上下文丰富特征。随后，我们沿通道维度拼接所有人体的关节点特征，得到特征 $O _ { f } ^ { K } \in R ^ { N \times ( C _ { o u t } \times K ) }$ ×H×W $O _ { b } ^ { K } \in R ^ { N \times ( C _ { o u t } \times K ) } \times H \times W$，其中 K 表示人体关节点的数量。

多尺度表述：多尺度特征图编码了不同层级的上下文信息。聚合不同尺度的特征可以丰富深层特征的上下文信息。为了增强特征在不同尺度下的鲁棒性，还进行了跨多尺度特征的消息传递。遵循与 1 尺度语法构建相同的步骤，我们随后可以获得 1/2 尺度的最终双向特征 $O _ { f } ^ { \prime \breve { K } } , O _ { b } ^ { \prime K }$ 以及 1/4 尺度的 $O _ { f } ^ { \prime \prime K } , O _ { b } ^ { \prime \prime K }$。在多尺度消息传递之后，我们通过拼接（concatenation）简单地聚合来自两个方向的多尺度特征，如下所示：

$$
\begin{array}{l} \overline {{O}} _ {f} ^ {K} = \phi \Big (C a t \big (O _ {f} ^ {K}, U P _ {2} \big (O _ {f} ^ {\prime K} \big), U P _ {4} \big (O _ {f} ^ {\prime \prime K} \big) \big) \Big), \\ \overline {{O}} _ {b} ^ {K} = \phi \big (C a t \big (O _ {b} ^ {K}, U P _ {2} \big (O _ {b} ^ {\prime K} \big), U P _ {4} \big (O _ {b} ^ {\prime \prime K} \big) \big) \big), \end{array}\tag{3}
$$

其中 $\phi$ 表示相应减少通道数的 $1 \times 1$ 卷积，Cat 表示拼接操作，$U P _ { 2 } , U P _ { 4 }$ 分别表示 2 倍和 4 倍上采样操作。最终特征 $\mathit { \Pi } \overline { { O } } _ { f } ^ { K } , \overline { { O } } _ { b } ^ { \vec { K } }$ 被送入上述基于注意力的结果融合模块以获得最终结果。

基于注意力的结果融合机制：与双向特征相比，热图（heatmaps）嵌入了更清晰且信息量更丰富的信息。考虑到这一点，与以往工作中直接对前向特征和后向特征求和不同，我们提出聚合来自这两个分支的最终热图。此外，我们提出了一种注意力机制，为各个独立分支分配不同的权重，并提取更有价值的信息。该过程的具体演示见 Fig. 5。首先，通过使用 $1 \times 1$ 卷积核对 $\bar { \overline { { O } } } _ { f } ^ { K } , \overline { { O } } _ { b } ^ { K }$ 进行卷积来获得热图 $H _ { f } , H _ { b }$。此处采用分组卷积，其中组数同样设置为 Q，

$$
\begin{array}{l} H _ {f} ^ {K} = \phi \Big (\overline {{O}} _ {f} ^ {K} \Big), \\ H _ {b} ^ {K} = \phi \Big (\overline {{O}} _ {b} ^ {K} \Big), \end{array}\tag{4}
$$

其中 $\phi$ 表示 $1 \times 1$ 分组卷积操作。为了选择性地融合这两个分支，并使网络能够为这两个分支分配适当的权重，定制了一个注意力生成器来生成注意力图，公式如下：

$$
A = A G \Big (\overline {{O}} _ {f} ^ {K}, \overline {{O}} _ {b} ^ {K} \Big),\tag{5}
$$

其中 $A G$ 表示注意力生成器，它将特征 $\overline { o } _ { f } ^ { K } , \overline { o } _ { b } ^ { K }$ 作为输入。为了简化注意力生成器的架构设计，我们采用了与自适应掩码生成器相同的结构，详见 Fig. 4。唯一的区别在于卷积核的通道维度，已在图中进行了标注。这两个卷积的输出通道数分别为 256 和 1。最终的热图融合方式如下：

$$
H ^ {K} = A \odot H _ {f i} ^ {K} + (1 - A) \odot H _ {b i} ^ {K}, i = 1, \ldots , K,\tag{6}
$$

其中 $\odot$ 表示哈达玛积（Hadamard product）。尽管由于上下文信息的丰富，直接对两个反向方向的特征求和可以提升性能，但这种提升是有限的。相比之下，在热图上进行合并更为有效。代表最终预测的热图编码了更干净的上下文信息。此外，基于注意力的结果融合策略能够在这两个分支中做出更好的选择以进行最终融合。从另一个角度来看，这种可被视为集成过程的融合能够克服仅从单个回归器获得的预测噪声。

参数设置：在实际应用中，我们调整了不同尺度下的参数设置，以确保适当的空间覆盖。我们执行了三次连续的 3D 卷积，其中采用了 $3 \times 3 \times 3$ 的 C3D 卷积核。我们没有采用大卷积核来扩大相邻关节点的搜索区域，而是利用连续的空间空洞 3D 卷积来实现相同的目标。增大相邻人体关节点的感受野，以确保它们之间有充足的空间覆盖。此外，稀疏的空洞卷积核在保持相当性能的同时减少了总参数量和计算量。我们将三次连续卷积核在空间（高度和宽度）维度上的空洞率分别设置为：尺度 1 时为 {2, 4, 4}，尺度 $1 / 2$ 时为 {1, 2, 2}，尺度 $1 / 4$ 时为 {1, 1, 1}。在所有情况下，我们将深度维度上的空洞率均设置为 1。空间维度上空洞率的选择可以看作是一个排列组合问题，并不是我们工作的重点关注对象。

## C. Direction-Aware Bi-C3D Regional Pose Grammar

为了探索人体关节之间的长距离依赖关系，我们提出了一种方向感知的 Bi-C3D 区域姿态语法（DARPG），以在全局范围内关联人体关节。我们将整个人体骨架划分为两个独立的区域：上半身和下半身，从而形成了我们区域姿态语法的高级版本。在此，两个区域子语法定义如下：

$$
\begin{array}{c} G _ {1} ^ {R}: \text { rankle } \longleftrightarrow \text { rknee } \longleftrightarrow \text { rhip } \longleftrightarrow \text { lhip } \longleftrightarrow \\ \text { lknee } \longleftrightarrow \text { lankle }, \end{array}
$$

$$
\begin{array}{c} G _ {2} ^ {R}: r w r i s t \longleftrightarrow r e l b o w \longleftrightarrow r s h o \longleftrightarrow l s h o \longleftrightarrow \\ l e l b o w \longleftrightarrow l w r i s t. \end{array}
$$

具体图示可见 Fig. 2(c)(d)。

与运动学语法相比，区域语法以更长的关节序列作为输入，且 C3D 能够有效地在全局范围内构建关节关系。以下半身为例，在前向传播中，我们沿深度维度拼接下半身关节的特征。在后向传播中，我们沿深度维度按相反顺序拼接下半身关节的特征，即 $I _ { 1 f } ^ { \check { R } } \overset { ^ { \circ } } { \in } R ^ { N \times M ^ { \prime } \times } \overset { \smile } { C } _ { i n } { \times } \check { H } { \times } W , I _ { 1 b } ^ { R } \ \in$ $R ^ { N \times M ^ { \prime } \times C _ { i n } \times H \times W }$，其中 $M ^ { \prime }$ 表示区域姿态语法的关节数量。将自适应坐标通道附加到序列特征 $R _ { 1 f } ^ { R } , R _ { 1 b } ^ { R }$ 后，我们可以得到 $I _ { 1 f } ^ { R ^ { \prime } } \in$ $R ^ { N \times M ^ { \prime } \times ( C _ { i n } + 3 ) \times H \times W }$，$I _ { 1 b } ^ { R ^ { \prime } } \in R ^ { N \times \dot { M ^ { \prime } } \times ( C _ { i n } + 3 ) \times H \times W }$，其中 $I _ { 1 f } ^ { R ^ { \prime } }$ 和 $I _ { 1 b } ^ { R ^ { \prime } }$ 均编码了坐标信息。我们将这两组特征输入到方向感知的 Bi-C3D 区域姿态语法模块中进行细化。为了确保此处具有足够的空间覆盖范围，膨胀率（dilation rates）也进行了相应更改。形式上，3D 卷积重复三次，在所有迭代中，空间维度和深度维度的膨胀率分别设置为 4 和 1。我们采用了与运动学姿态语法模块相同的卷积核大小，设置为 $3 \times 3 \times 3$。最后，我们使用运动学姿态语法中所述的基于注意力的结果融合机制，融合从双向细化特征中获得的热图。

## IV. 实验

## A. MPII 人体姿态估计

数据集与设置：MPII 人体姿态数据集是最受欢迎的人体姿态估计基准之一，包含各种关节姿态。该数据集中包含约 2.5 万张图像和 4 万人。我们在包含 3000 人的验证集以及共涉及约 1.1 万个实例的测试集上汇报最终结果。在实验过程中，我们使用 RMSprop 优化器来更新整个网络的参数。学习率初始设置为 1e − 4，并在第 150、170 和 200 个 epoch 时降低 10 倍。我们共对网络进行 220 个 epoch 的训练。输入分辨率为 $2 5 6 \times 2 5 6$。在测试期间，我们采用了考虑多尺度结果融合的六尺度金字塔方案 [11], [32]。

评估指标：[35] 中提出的 PCKh（头部归一化正确关键点概率，head-normalized probability of correct keypoint）评分被采用作为 MPII 数据集的最终评估指标。当预测关节点与真实关节点（ground-truth）之间的距离处于定义为头部边界框对角线长度的 0.6$\alpha$ 阈值之内时，该关节点被判定为正确预测。最终，采用了将 $\alpha$ 设为 0.5 的 PCKh@0.5。

定量结果：MPII 数据集上的定量结果见 Table I 和 Table II。从 Table I 中我们可以发现，我们的方法在 MPII 验证集上取得了最佳性能。平均 PCKh@0.5 评分高达 90.9%。此外，我们复现了采用 8 阶堆叠 Hourglass（8-stack hourglass）模型的工作 [35]、[36]。从表中可以看出，当应用相同的骨干网络（backbone）时，语法模型（grammar model）能够取得更好的性能。对于测试集，我们的平均 PCKh@0.5 评分达到了 92.6%，与最先进的方法（SOTA）[43] 相当。与基线（即 Hourglass）相比，我们的方法实现了 1.7% 的 PCKh@0.5 评分提升，这是一个显著的进步。在困难人体关节点（例如脚踝和膝盖）上的提升是该改进的主要贡献来源。此外，我们的方法持续超越了采用 Hourglass 模型作为骨干网络的已发表算法 [11]、[32]。最后，与 HRNet [13] 相比，我们的姿态语法模型（pose grammar model）同样取得了更好的性能。与会议版本相比，主要的改进来自于膝盖、脚踝等困难关节点。

## B. LSP 人体姿态估计

数据集与设置：LSP 数据集也是常用于单人姿态估计的流行数据集。结合了原始版本和扩展版本的整个数据集包含约 11000 张用于训练的图像和 1000 张用于测试的图像。在实践中，MPII 训练划分也参与了 LSP 的训练过程，这一做法在以往的研究中被广泛采用 [11], [32]。所有的实验设置均与 MPII 人体姿态数据集相同。

评估指标：PCK（正确关键点百分比，Percentage of Correct Keypoints）被用作 LSP 数据集的最终评估指标。如果预测位置与真实位置（ground-truth）之间的距离落在预定义的阈值（定义为躯干段长度的 $\alpha$）范围内，则该关节被判定为预测正确。最终采用 $\alpha$ 设为 0.2 的 PCK@0.2。

定量结果：LSP 数据集上的定量结果如表 III 所示。我们在测试集上取得了最先进的（state-of-the-art）性能，PCK@0.2 分数达到了 94.9%。与以往的工作和会议版本相比，在困难人体关节上的进展为性能提升做出了主要贡献。

## C. COCO 数据集

数据集：COCO 数据集已应用于目标检测、图像分割等多个领域。对于人体姿态估计，它是规模最大且最具影响力的多人姿态估计基准之一。COCO train2017 用于训练过程，其中包含 57K 张图像和 150K 个人体实例。我们在 COCO val2017 和 test-dev 2017 上测试了我们的模型，分别包含 5000 张图像和 2k 张图像。

评估指标：目标关键点相似度（Object Keypoint Similarity, OKS）是 COCO 数据集的标准评估指标，其中 OKS 表示为 $\frac { \sum _ { i } e x p ( - d _ { i } ^ { 2 } / 2 s ^ { 2 } k _ { i } ^ { 2 } ) \delta ( \nu _ { i } > 0 ) } { \sum _ { i } \delta ( \nu _ { i } > 0 ) }$。$d _ { i }$ 表示预测的人体关键点与真实关键点之间的距离，$s$ 表示实例尺度因子，$k _ { i }$ 是决定衰减程度且因不同人体关键点而异的常数。遵循以往的工作，平均精度均值（AP）作为主要评估标准被报告，它对 10 个阈值（0.5, 0.55, . . . , 0.95）上的 OKS 得分取平均。在阈值 0.50 和 0.75 下计算的平均精度 $\mathsf { A P } ^ { 5 0 }$ 与 $\mathbf { A P } ^ { 7 5 }$ 也被一并报告。此外，还包含了针对中型和大型目标计算平均精度的 $\mathbf { A P } ^ { M }$ 和 $\mathsf { A P } ^ { L }$。最后，报告了平均召回率（AR）。

实验设置：在 COCO 数据集上进行实验时，我们将输入分辨率设置为 256×192。我们采用随机旋转、随机缩放、翻转和半身增强作为数据增强策略。我们将初始学习率设置为 1e-4，并在第 170 和第 190 个 epoch 时将其降低 10 倍。使用 RMSprop 优化器来更新网络。我们在第 210 个 epoch 结束训练。在测试期间，为了与以往方法进行公平比较，仅涉及翻转操作。我们使用与 [13] 相同的边界框在 val2017 和 test-dev 2017 上执行单人姿态估计。

定量结果：COCO val2017 数据集上的定量结果见 Table IV，我们的语法模型（grammar model）取得了 76.2 AP。与以 ResNet-152 为基线的 SimpleBaseline 相比，我们的方法取得了显著更优的性能。与 HRNet-W48 相比，我们的模型同样可以取得具有竞争力的性能。当输入分辨率为 $3 8 4 \times 2 8 8$ 时，我们的模型取得了与 HRNet-W48 几乎相同的性能。与基于 Transformer 的方法相比，其性能仍然具有可比性。此外，我们可以观察到我们的语法模型是一种参数高效的模型，它利用少得多的参数实现了更具竞争力的结果。test-dev 集上的结果见 Table V。我们可以发现，配备了语法模块的 Hourglass 模型与其他主流模型相比取得了具有竞争力的结果。尽管涌现出大量新算法，Hourglass 在该领域中仍然可以作为一个有效的架构。

## D. 消融实验

在本节中，我们详细介绍了消融实验，以证明各个模块的有效性。所有实验均在基于 2-stack hourglass 模型的 MPII 数据集上进行。此外，我们采用单尺度测试方案来评估各模块的性能。

多尺度方向感知 Bi-C3D 运动学姿态语法的有效性：在本节中，我们首先讨论方向感知 Bi-C3D 运动学姿态语法的单尺度版本的有效性。所提出的单尺度方向感知 Bi-C3D 运动学姿态语法的有效性见 Fig. 6(a)。单向 C3D 运动学姿态语法（‘k-s’）取得了 88.03% 的 PCKh 得分，而汇总了双向特征的 Bi-C3D 运动学姿态语法（‘k-b’）取得了 88.15% 的 PCKh 得分。当引入方向引导机制（‘k-b-d’）时，PCKh 得分为 88.29%，比（‘k-b’）提升了 0.14%。当利用注意力机制融合最终结果（‘k-b-a’）时，我们的模型比先前版本的 PCKh 得分提升了 0.17%，最终达到 88.32% 的 PCKh 得分。当编码自适应方向信息（‘k-b-a-d’）时，我们的模型可以进一步将性能提升 0.05% 的 PCKh 得分，最终达到 88.37% 的 PCKh 得分。正如 Fig. 6(a) 所示，增强的多尺度方向感知 Bi-C3D 运动学姿态语法（‘m’）取得了 88.37% 的 PCKh 得分，比单尺度 Bi-C3D 运动学姿态语法的 PCKh 得分高出 0.34%。当通过基于注意力的结果融合机制结合来自两个不同分支的结果（‘m-a’）时，我们的模型获得了 88.44% 的 PCKh 得分，并在初始版本的基础上取得了进一步的提升。当引入方向引导机制时，多尺度 Bi-C3D 运动学姿态语法（‘m-a-d’）的性能进一步提升，达到了 88.65% 的 PCKh 得分。与基线相比，我们的多尺度 Bi-C3D 姿态语法模型实现了 1.23% 的 PCKh 得分提升。

## E. 定性结果

此外，我们提供了一些姿态估计结果，以便更好地理解其有效性。图 8 显示了在 MPII 和 LSP 数据集上的一些预测姿态。我们可以观察到，我们的方法在一些极其困难的情况下表现出了极大的鲁棒性，例如遮挡、杂乱的背景和复杂的姿态。

尽管语法模型可以学习几何约束，但在出现极其复杂的姿态时，仍然难以实现精确的定位。例如，图 9 前两幅子图中的姿态在训练过程中很少见到，这些结构先验无法得到很好的学习。在其他情况下，当出现高度重叠的人体实例时，目标人物的预测可能会受到相邻人物的影响，这可以在图 9 的后三幅子图中看到。尽管最终的结构在某种程度上看起来是合理的，但目标人物的关节可能会被错误地定位在另一个人身上。主要原因可能是不同的人体无法被很好地区分。因此，在这些情况下，除了结构信息之外，学习人体外观信息和高级的人与人关系更为重要。

## F. 局限性与未来工作

在未来，当边界框中出现多个实例时，我们将更加关注人与人关系的学习。此外，由于当前模型的计算量略大，我们将设计一个更轻量级的语法模块，以加快在边缘设备上的推理速度。

此外，直接从 ChatGPT 等大语言模型（LLMs）中获取姿态语法也将被纳入考虑。LLMs 编码了包括人体上下文在内的丰富开放世界知识。利用来自 ChatGPT 的专家知识有助于开发更多描绘不同层次人体上下文的语法类型。

## V. 结论

在本文中，我们提出了一种渐进式方向感知姿态语法模型，用于在人体关节点之间进行消息传递。首先，提出了一种多尺度方向感知 Bi-C3D 运动学姿态语法模块，用于在局部范围内进行人体关节点之间的多尺度消息传递。与其他序列建模技术相比，C3D 在构建姿态语法时取得了更具前景的结果。此外，还引入了方向引导和基于注意力的结果融合机制，以进一步提升消息传递的性能。其次，提出了一种方向感知 Bi-C3D 区域姿态语法模块，用于在全局范围内进行人体关节点之间的消息传递。多尺度方向感知 Bi-C3D 运动学姿态语法模块与方向感知 Bi-C3D 区域姿态语法模块的结合，以渐进的方式促进了消息传递，与最先进的方法相比取得了具有竞争力的结果。
