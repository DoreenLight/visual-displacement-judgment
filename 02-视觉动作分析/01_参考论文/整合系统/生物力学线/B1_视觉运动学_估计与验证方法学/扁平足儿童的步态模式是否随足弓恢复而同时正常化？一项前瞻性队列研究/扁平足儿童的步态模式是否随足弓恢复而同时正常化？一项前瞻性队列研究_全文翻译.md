## A R T I C L E I N F O

关键词：儿童 柔韧性扁平足 步态模式恢复 足底压力分布 压力中心 队列研究

## A B S T R A C T

儿童期的柔韧性扁平足通常会自发恢复正常。然而，在此过程中，步态模式是否会同步调整以及这种调整的机制尚不明确。我们通过一项为期两年的随访研究，从足底负荷和步态稳定性的角度探讨了扁平足儿童自然恢复后步态模式变化的潜在机制。经过广泛的样本筛选，共有15名扁平足康复组儿童和17名正常发育的对照组儿童纳入本研究。使用 Footscan® 压力平板每隔12个月进行一次足底压力和压力中心（Center Of Pressure, COP）的数据采集，共采集三次。采用独立样本 t 检验和统计参数图（statistical parametric mapping, SPM）分析探讨恢复组与对照组在各次测量中的差异。在基线期，恢复组表现出更高的中足负荷以及更偏向外侧位移的 COP。在第12个月时，恢复组在外侧前足表现出显著更低的负荷比，但标准化最大力更高。在第24个月时，恢复组转变为在第二跖骨头下方表现出明显更高的负荷比，并伴有支撑相晚期 COP 更偏向外侧和后方的位移。在儿童期柔韧性扁平足形态恢复过程中，步态模式最终表现出显著改善，同时在不同阶段呈现出不同特征。本研究揭示了儿童扁平足自然恢复后的生物力学适应机制，有助于全面理解小儿扁平足的影响。

## 1. 引言

柔韧性扁平足（Flexible flatfoot）在儿童中较为普遍，并表现出独特的步态模式特征（Salinas-Torres et al., 2023; Xu et al., 2022）。足弓塌陷会导致异常的足底压力分布，增加拇外翻和跖骨痛等损伤的风险（Bohm ¨ et al., 2024）。众多研究已从动力学、运动学及其他相关特征的角度评估了扁平足干预方法的有效性（Kanatli, Aktas and Yetkin, 2016; Zhang et al., 2022; Cherni et al., 2022; Hu et al., 2024; Utsahachant et al., 2023; Persiane et al., 2023）。

儿童柔韧性扁平足的一个显著特征是，在大多数儿童中，足弓会随着年龄的增长而自发恢复（Yin et al., 2018）。鉴于目前的研究尚未证实干预治疗比自然矫正更有效，一些研究人员认为儿童柔韧性扁平足无需过度干预（Pfeiffer et al., 2006; Sutherland, 1977）。然而，大多数关于儿童柔韧性扁平足自发恢复的研究主要从人口统计学和放射学角度开展。鲜有研究关注该群体恢复前后步态功能和特征的变化。原因之一是在足弓恢复前很难识别出这些儿童。第二个原因源于一种普遍观念，即一旦塌陷的足弓自然恢复正常，其步态模式特征也会随之恢复，无需额外的监测和干预。然而，这种观点缺乏坚实的生物力学证据支持。对于能够自愈的儿童柔韧性扁平足，干预真的没有必要吗？足弓自然恢复后，步态模式会自动恢复正常吗？步态异常是否仍存在潜在风险？这些悬而未决的问题阻碍了儿童扁平足合理预后管理措施的制定，并可能使儿童在扁平足恢复后仍面临足部损伤的风险。

据我们所知，目前尚无研究评估柔韧性扁平足儿童康复后的步态模式。足底压力分布和压力中心（Center Of Pressure, COP）是评估扁平足步态模式和潜在损伤风险的关键指标（Panaet et al., 2023; Khan et al., 2023; Zhang et al., 2022）。因此，本研究旨在通过评估足底负荷和步态稳定性，探究扁平足儿童在为期两年的随访期内自然康复后步态模式的变化机制。我们重点关注在没有临床或物理干预的情况下，步态模式如何随着足弓随年龄自然发育而演变。了解足弓恢复后步态模式的变化，将为柔韧性扁平足儿童的生物力学适应机制提供新的见解。

## 2. 材料与方法

## 2.1. 参与者

参与者选自一项关于儿童足部生物力学的大型纵向研究，该研究已获得 Sichuan University（四川大学）伦理委员会的批准。最初从当地一所小学招募了 1285 名儿童。所有参与者均健康，年龄在 7 至 10 岁之间。对于本研究，受试者的纳入标准如下：（1）年龄为 7–8 岁；（2）健康且体重正常，无任何肌肉骨骼疾病、足部疼痛或下肢手术史；（3）在获得家长知情同意后自愿参与。具体而言，本研究包括康复组（recovery group, RG）和对照组（control group, CG）。对于 RG，采用了进一步的纳入标准：参与者在基线时表现为扁平足姿势，且在没有接受任何临床或物理干预的情况下，其足部姿势在第二次和第三次测量时均自然发育为正常足弓。关于 CG，补充纳入标准为在整个随访期内持续呈现正常足部姿势。此外，为了尽量减少潜在混杂因素的影响，我们控制了年龄、身高、体重、BMI、穿鞋习惯和身体活动水平等变量。受试者筛选流程如图 Fig. 1 所示。正常体重的定义基于 World Health Organization（世界卫生组织，World-Health-Organization, 2024）建议的 BMI 范围。扁平足的判定基于 Cavanagh 等人提出的足弓指数（Arch Index, AI）（Cavanagh and Rodgers, 1987），其中 AI 的计算公式如下：

$$
A I = \frac {\text { midfootcontactarea }}{(\text { forefoot } + \text { midfoot } + \text { rearfoot }) \text { contactarea }}
$$

具体而言，AI 值小于 0.21 表示高弓足，介于 0.21 和 0.26 之间表示正常足弓，大于 0.26 则提示扁平足。

## 2.2. 实验步骤

实验持续了两年，分别在基线、12 个月和 24 个月时进行了三次测量。在扁平足康复前的基线阶段评估了步态生物力学特征。使用 1-m Footscan® 足底压力板（RSscan International，比利时）采集受试者在赤足自然行走过程中的动态足底压力数据，采样频率为 250 Hz。该压力板嵌在一条 7 m 长的步道中央。在适应期内，指导受试者采用两步启动方案（two-step initiation protocol）（Meyers-Rice et al., 1994; Taylor, Menz and Keenan, 2004），以轻松的步速在步道上行走。凡受试者因刻意踩踏压力板而改变步态、导致临时换脚或拖步的测试，均视为无效。每位受试者需完成五次有效测试，以确保实验数据的准确性和可靠性。在首次实验前，我们向每位受试者及其家长详细解释了实验流程，并获得了知情同意。

## 2.3. 数据处理与统计分析

如图 Fig. 2 所示，在 Footscan® 软件中将足部分为十个区域：拇趾（T1）、其余脚趾（T2-5）、第 1 至第 5 跖骨（M1、M2、M3、M4、M5）、中足（MF）、足跟内侧（HM）和足跟外侧（HL）。提取了最大力、力–时间积分以及压力中心（Center Of Pressure, COP）。将最大力按体重进行归一化，作为标准化最大力（SMaxF）。相对力–时间积分（RFTI）是指各足底区域负荷占全足总负荷的比例，用于评估足底负荷分布。

对于 COP 坐标，y 轴定义为从足跟中部延伸至穿过第二跖骨中部的足前部的连线，代表前后方向。x 轴垂直于 y 轴，代表内外侧方向。x 轴和 y 轴上的正值分别代表内侧和前向。导出的 COP 坐标首先使用截止频率为 50 Hz 的四阶低通 Butterworth 滤波器进行滤波（Cheng et al., 2022）。端点通过反射技术进行填充（De Cock et al., 2008）。滤波后，使用 MATLAB 2023b（MathWorks Inc., America）通过多项式插值计算内外侧（COPx）和前后方向（COPy）的 COP 位移，所有数据均针对支撑相时间进行了归一化。COP 速度（COPvx、COPvy）通过微分计算。此外，支撑相被划分为四个子阶段：初始接触相（ICP）、前足接触相（FFCP）、平足相（FFP）和前足推蹬相（FFPOP）（Perry and Burnfield, 2011）。ICP 是从足跟初始接触到前足初始接触的时间间隔。FFCP 紧随 ICP 之后，并在整个前足与测力台接触时结束。FFP 接续 FFCP，并在足跟抬离地面时结束。FFPOP 紧随 FFP 之后，并在足部完全离地时终止。计算了各子阶段在 x 和 y 方向上的 COP 位移和速度的平均值。

每位受试者优势足的 3 次试验数据被纳入分析并取平均值。采用 Kolmogorov-Smirnov 检验验证数据的正态性。首先，使用 Pearson 相关系数检验步态动力学与足弓指数之间的关系。然后使用 $\textbf { a } 2 \times \textbf { 3 }$ 重复测量方差分析（repeated measures ANOVA）来确定组内（基线、12 个月和 24 个月的重复测量）和组间（RG 和 CG）的差异。通过在每个时间点使用独立样本 t 检验进行成对比较，以进一步探究显著的交互作用，从而评估每个测试点的组间差异。应用 Bonferroni 校正对多重比较进行调整。显著性水平设定为 $p <$ 0.05。偏 eta 方 $( \eta _ { p } ^ { 2 } )$ 用于估计所有 ANOVA 分析的效应量，并解释为小（0.01）、中（0.06）和大（0.14）（Cohen, 1988）。支撑相期间的 COP 位移曲线采用一维统计参数映射方法（SPM）进行分析，以比较康复组与对照组（Pataky, 2008）。

## 4. 讨论

本研究旨在探讨儿童柔韧性扁平足自发恢复后步态模式特征的变化。相关分析表明，足弓指数（arch index, AI）是影响儿童步态特征的关键参数。具体而言，足部不同区域的足底压力参数与 AI 呈中度至强相关，其中中足和前足区域的影响尤为显著。重复测量方差分析表明，恢复组和对照组的步态特征随时间的变化趋势不同，尤其是在拇趾、前足和中足区域。进一步的成对比较表明，在扁平足恢复后的两年内，足底负荷模式和步态稳定性得到改善并逐渐趋于正常化。然而，实验组的步态模式并未完全恢复到正常发育儿童的水平，并在不同阶段表现出不同的特征。这表明步态模式的恢复滞后于足弓结构的恢复。该纵向研究深入揭示了柔韧性扁平足儿童步态的自然恢复过程，突出了步态模式随时间的逐步适应。这些发现有助于理解步态的成熟过程及其自然演变。

在基线时，$\mathsf { R G } _ { 0 }$ 组儿童的足弓仍然扁平。$\mathsf { R G } _ { 0 }$ 组的中足负荷显著高于 $\mathbf { C G } _ { 0 }$ 组，这与我们对扁平足的常规认知相一致。此外，恢复组在 T1 区域表现出较低的峰值压力和相对负荷。相比之下，Buldt 等人（Buldt et al., 2018）研究了成年扁平足患者的足部负荷，发现 T1 区域承受的负荷明显更高，在推进阶段的贡献更大。本研究中观察到的拇趾区域负荷减少，表明其在该阶段产生的推力较小。这种减少主要归因于扁平足儿童在蹬伸阶段的功能受损（Kothari et al., 2016; Kim et al., $2 0 1 7 )$ ）。我们推测，在发生足弓塌陷时，儿童和成人在推进阶段的拇趾反应存在差异。此外，$\operatorname { R G } _ { 0 }$ 组在蹬伸阶段纵向 COP（压力中心）移动更快，且更偏向外侧（占支撑相的 60 %–80 %）。这表明扁平足儿童在足跟离地后处于不稳定状态。这一发现与 Panaet 等人（Panaet et al., 2022）的研究一致，该研究表明距下关节过度外翻会导致距骨向内侧移位，进而影响整体下肢运动学。我们的结果进一步表明，扁平足儿童在蹬伸过程中 COP 向外侧偏移是对关节对线不良的代偿性反应。

另一个意想不到的发现是，前足负荷结果与以往的研究（Pauk, Ihnatouski and Najafi, 2014; Yan et al., 2020）不同，先前的研究认为扁平足塌陷的足弓无法有效分散负荷，导致前足压力和冲量显著降低。在我们的研究中，恢复组的足弓后来恢复了正常形态，这表明在其扁平足足弓形态完全恢复之前，其负荷模式可能已经趋于正常。与忽略扁平足后续发展的横断面研究相比，本研究针对基线期扁平足儿童的步态模式提供了更具针对性和明确的见解。然而，进一步验证这些发现仍需要对扁平足儿童开展大量的数据分析。对这一特定群体的进一步研究，可为识别自发性恢复的扁平足病例提供有价值的见解。

在足弓形态恢复的第一年内，恢复组的足部负荷模式表现出显著变化，中足下方的集中压力得到有效缓解。随着足弓结构的持续恢复，足底负荷分布变得更加均匀。然而，在这一阶段，其步态特征仍类似于扁平足儿童的典型表现。值得注意的是，与 $\mathbf { C G } _ { 1 }$ 相比，$\mathsf { R G } _ { 1 }$ 前足外侧的相对负荷显著更低。这可以从两个角度来解释：从下肢适应的角度来看，这可能归因于扁平足距下关节的外旋，从而将前足负荷从外侧转移到了内侧（Buldt et al., 2018；Chuckpaiwong et al., 2008）；从近端环节适应的角度来看，青少年的腰椎前凸角往往随着足弓高度的增加而减小（Jankowicz-Szymanska et al., 2021），这可能导致前足相对负荷的降低（Zurawski et al., 2022）。需要进一步的关节运动学数据和更广泛的统计分析来评估潜在环节适应对步态特征改变的贡献。

尽管有了这些改善，

$\mathsf { R G } _ { 1 }$ 在前足外侧的标准化最大力仍显著更高。这种增加与着地时的缓冲密切相关（Perry and Burnfield, 2011）。这表明在此期间 $\mathrm { R G } _ { 1 }$ 的胫骨前肌肌力尚未恢复到正常水平。因此，前足着地过程中的显著晃动导致前足外侧受力骤增。同时，$\mathsf { R G } _ { 1 }$ 在前足接触期（FFCP）的外向 COP 速度较小。这表明 $\mathsf { R G } _ { 1 }$ 在前足着地时下意识地采取了这种运动策略，以增强步态控制能力。

到第三次测试时，RG<sub>2</sub> 的步态模式表现出显著改善，趋近于正常发育儿童中常见的水平。两组之间在标准化最大力和平均 COP 数据方面的所有差异均已完全消失。然而，仍存在一些差异性结果，特别是在相对载荷和 COP 曲线方面。研究发现，RG2 在 M2 区域具有更高的相对载荷，并在 FFPOP 中表现出更偏向外侧且向前位移较小的 COP 转移。在典型的步态周期中，足跟离地后，胫骨前肌的离心收缩促进了压力中心从前足外侧向内侧的转移，使足底筋膜紧绷并辅助向前推进 (Perry and Burnfield, 2011)。在本研究中，$\mathsf { R G } _ { 2 }$ 的 COP 特征表明其正常的前足旋前和向前推进功能受到了部分限制。因此，足底载荷似乎“滞留”在 M2 区域，而 RFTI 的显著增加支持了这一结论。由于 M2 在日常体力活动中的承重和功能中至关重要，过度重复的负荷可能会增加跖骨痛及其他相关疾病的风险 (Kaipel, Krapf and Wyss, 2011; Lee et al., 2024)。在足弓恢复的第二年，与第一年相比，步态模式持续改善，接近正常发育儿童的水平。然而，仍应关注 M2 区域冲量的分散情况，特别是在长跑和徒步等重复性活动中，载荷会随着时间的推移而累积。

本研究存在一些局限性需要予以说明。虽然我们的重点是分析扁平足恢复为正常足弓后的足底负荷和步态稳定性，但仍需要更全面地了解步态功能如何随足弓恢复而变化，特别是在肌肉活动和关节运动方面。此外，需要进行更长期的随访研究以证实本研究中提出的推测性结果。关于扁平足儿童步态运动学和动力学的系统性基础研究的缺乏，进一步凸显了开展更广泛研究的必要性。在这方面，未来结合下肢和躯干运动学分析的研究可以为代偿运动的消除提供更深入的见解，并有助于明确在恢复过程中这些调整何时完全消退。

## 5. 结论

在关键发育期，扁平足儿童的步态特征在足弓结构恢复后往往会有所改善，尽管存在一定的时间滞后性。扁平足恢复后，足部的高负荷区从足弓区域首先转移至前足外侧，随后转移至前足中央。压力中心（COP）轨迹与正常儿童存在差异，尤其是在承重反应期、支撑相末期和摆动前期。这些发现突出了扁平足恢复过程中的生物力学适应机制。未来的研究应结合全身运动学分析，为步态正常化和临床应用提供更全面的参考。
