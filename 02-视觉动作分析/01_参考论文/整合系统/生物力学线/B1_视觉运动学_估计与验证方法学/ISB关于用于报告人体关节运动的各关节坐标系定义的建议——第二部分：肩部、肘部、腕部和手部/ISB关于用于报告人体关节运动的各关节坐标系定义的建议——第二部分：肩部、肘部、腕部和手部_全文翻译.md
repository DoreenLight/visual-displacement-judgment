## 摘要

在本文中，国际生物力学学会（International Society of Biomechanics, ISB）的标准化与术语委员会（Standardization and Terminology Committee, STC）提出了肩部、肘部、腕部和手部的关节坐标系（joint coordinate system, JCS）定义。对于每个关节，均建立了各相关节段或骨骼的局部坐标轴系统标准。这些轴随后将JCS标准化。STC发布这些建议旨在鼓励其应用、促进反馈和讨论，并推动后续修订。采用这些标准将促进研究人员与临床医生之间更好的交流。© 2004 Elsevier Ltd. 保留所有权利。

关键词：关节坐标系；肩；肘；腕；手

## 1. 引言

在过去的几年中，国际生物力学学会（International Society of Biomechanics, ISB）的标准化与术语委员会（Standardization and Terminology Committee, STC）一直致力于在 Grood 和 Suntay 的膝关节关节坐标系（Joint Coordinate System, JCS）（Grood and Suntay, 1983）的基础上，提出一套用于定义各类关节坐标系（JCS）的标准。这项工作的主要目的是促进并鼓励研究人员、临床医生以及所有其他相关方之间的交流。

STC 共成立了九个小组委员会，汇集了近 30 位在关节生物力学领域具有丰富经验（包括研究或临床经验）的专家，并针对人体的九大关节制定了提案。这些关节包括：足部、踝关节、髋关节、脊柱、肩关节、肘关节、手及腕部、颞下颌关节（TMJ）以及全身。这些提案基于 Wu and Cavanagh (1995) 发表的用于报告运动学数据的 ISB 标准。针对踝关节、髋关节和脊柱的第一套标准于 2002 年 4 月发表在《Journal of Biomechanics》（Wu et al., 2002）上。针对该套标准的意见回复随后于 2003 年发表（Allard et al., 2003）。

本文中包含了针对肩关节、肘关节以及手和腕关节的拟议标准。对于每个关节，标准分为以下几个部分：(1) 引言，(2) 术语，(3) 身体节段坐标系，以及 (4) 组成关节的 JCS 与运动。随后，各研究人员需通过数字化、校准动作或基于人群的解剖关系，将标记点坐标系或其他（如电磁传感器）坐标系与已定义的解剖坐标系建立关联。

使用 Grood 和 Suntay 的 JCS 有两个主要价值：(1) 概念上的，因为使用分别固连于近端和远端节段的独立轴线，似乎更容易与临床医生交流旋转运动；(2) 包含了具有临床相关性的关节平移计算。然而，他们关于 JCS 与序列无关而欧拉角（Euler angle）或卡尔丹角（Cardan angle）表示法与序列相关的陈述引发了一些混淆。需要指出的是，在不考虑平移的情况下，Grood 和 Suntay 的约定实际上只是特定卡尔丹角序列的一种连杆机构表示法；浮动轴（floating axis）即是卡尔丹序列中的第二个轴，即旋转轴（Small et al., 1992; Li et al., 1993, Baker, 2003）。这些角度之所以“独立”，是因为序列已由该机构所定义；一旦序列确定，卡尔丹或欧拉序列同样是“独立”的。

## 2. 肩关节 JCS

关节运动的标准化对于推动运动生物力学的研究至关重要。国际肩关节学组（International Shoulder Group, ISG）支持 ISB 在此项举措上的努力，并建议作者使用相同的一组骨性标志点；使用相同的局部坐标系（Local Coordinate System, LCS）；并按照这一推荐标准报告运动数据。

肩关节标准化建议的出发点是 Van der Helm (1996) 的一篇论文。更多信息可在以下网址获取：http://www.internationalshouldergroup.org。

## 2.1. 引言

运动的标准化仅针对右肩关节进行描述。每当测量左肩时，建议将原始位置数据相对于矢状面进行镜像处理（ðz ¼  zÞ）。这样，所有针对右肩的定义均可适用。

旋转使用欧拉角（Euler angles）描述。为了更清晰地解释这些角度，建议通过引入这些坐标系的“解剖学”取向，使近端和远端身体节段的坐标系最初相互对齐。随后应相对于近端坐标系来描述远端坐标系的旋转。如果两个坐标系均对齐，则第一次旋转将围绕其中一个公共轴，第二次旋转围绕运动坐标系的（旋转后的）轴，而第三次旋转再次围绕运动坐标系的某个旋转后的轴。这最后一个轴优选与运动节段的纵轴对齐。该方法等同于 Grood and Suntay (1983) 使用浮动轴的方法。他们同样将第一次旋转描述为围绕近端坐标系的一个轴，并将最后一次旋转描述为围绕运动节段的纵轴。根据定义，第二根轴同时垂直于第一和第三旋转轴。

对于关节位移，应在近端和远端坐标系中选取一个公共点，优选为初始旋转中心（或者在铰链关节的情况下为固定旋转轴上的一个点）。对于大多数肩部运动，旋转中心只能是一个粗略的估计，因为只有盂肱关节（glenohumeral joint）类似于球窝关节。胸锁关节（sternoclavicular joint）和肩锁关节（acromioclavicular joint）的公共旋转中心的定义由研究人员自行决定。位移应相对于紧邻运动节段近端的节段坐标系轴进行描述，以表示真实的关节位移。

对于锁骨，只能识别出两个骨性标志：SC 和 AC。因此，锁骨的轴向旋转无法通过无创触诊测量来确定，但可以基于优化技术进行估计（Van der Helm and Pronk, 1995）。与 Van der Helm (1996) 相比，现在建议使用标志点 AA 代替肩锁关节（AC joint）。这种选择将减少由于万向节死锁（gimbal lock）引起并发症的发生（Groot, 1998）。严格来说，GH 并不是一个骨性标志，但需要用它来定义肱骨的纵轴。GH 可以通过回归分析（Meskers et al., 1998）或通过计算 GH 运动的瞬时螺旋轴（instantaneous helical axes, IHA）的枢轴点来估计（Stokdijk et al., 2000; Veeger et al., 1996）。优先选用 IHA 方法，因为它更精确，并且也适用于因关节面退行性变或植入物而导致 GH 发生改变的患者。在某些病理情况下，由于关节内的平移，可能无法用 IHA 方法精确估计 GH。然而，此时回归方法是否是一个可接受的替代方案，或者是否应该使用不同的方法（如 CT 或 MRI），则是一个值得探讨的问题。

## 2.4. 肩关节复合体的 JCS 及运动

在肩部，报告两种类型的旋转是有用的。一种是关节旋转（joint rotation），即某个环节相对于近端环节的旋转，包括锁骨相对于胸廓（胸锁关节/SC joint）、肩胛骨相对于锁骨（肩锁关节/AC joint）以及肱骨相对于肩胛骨（盂肱关节/GH joint）。另一种是环节旋转（segment rotation），即锁骨、肩胛骨或肱骨相对于胸廓的旋转（实际不存在的胸肱关节/thoracohumeral joint，通常被宽泛地定义为肩关节）。关节位移的定义只有在相对于近端环节定义时才是有用的。

可以采用多种旋转顺序（例如卡尔丹角中的 X–Y–Z 或欧拉角中的 $Y – Z – Y$）。我们选择旋转顺序是为了使这些角度尽可能贴近关节和环节运动的临床定义。差异是不可避免的，因为这些临床定义在三维（3-D）空间中并不一致。例如，尽管屈曲和外展在二维（2-D）中均有明确定义，但先屈曲后外展与先外展后屈曲所产生的结果并不相同（参见 Anglin and Wyss, 2000, 第 8.1 节）。

## 4. 手和腕关节的 JCS

## 4.1. 引言

已为肘关节远端的每块骨骼分别建立了坐标系，以便描述任意两个相邻骨段之间的相对运动。这些坐标系随后也可应用于整体腕关节运动，以及引起该整体运动的各个组成部分的运动。整体腕关节运动通常被视为第二和/或第三掌骨相对于桡骨的运动（此处我们采用第三掌骨），它是由腕骨相对于桡骨的运动以及八块腕骨之间众多的关节连接运动共同实现的。某些仅研究整体腕关节运动而无需研究腕骨运动的研究人员，仍可使用针对桡骨和掌骨给出的定义来描述腕关节运动。

ISB（国际生物力学学会，International Society of Biomechanics）委员会提案（Wu and Cavanagh, 1995）建议将正交三联坐标系固定在环节的质心上。在手部和手腕中，大多数环节或骨骼的质心是未知的。尸体研究中的数据确实将前臂和手的质心位置描述为各环节全长的一定比例。这些质心定义可能适用于整体手腕运动，但不能用于描述各个组成部分的运动学。指骨不能被忽视，因为许多研究人员正在研究单块腕骨的独立运动或桡骨相对于尺骨的运动。因此，对于本关节坐标系的应用，每个骨骼上正交三联坐标系的位置主要基于骨性标志，对于长骨通常位于轴向中心，对于腕骨通常位于体积形心。（CT 扫描可用于定义体积形心；然而，该方法可能并非在所有应用中都可行或必要。）

$Z _ { \mathrm { u } } \mathrm { : }$ 同时垂直于 $X _ { \mathrm { u } ^ { - } }$ 和 $Y _ { \mathrm { u ^ { - } d X i s } }$ 的公垂线。

## 4.3.3. 腕骨坐标系—— $X _ { \mathrm { { c } } } Y _ { \mathrm { { c } } } Z _ { \mathrm { { c } } }$

八块腕骨——舟骨、月骨、三角骨、豌豆骨、大多角骨、小多角骨、头状骨和钩骨——将被同时予以考虑。大多数研究人员仅报告腕骨运动的角度变化，并使用腕关节中立位作为中立参考位置。腕关节中立位是指腕关节处于中立屈/伸和中立桡偏/尺偏状态，此时第三掌骨长轴与桡骨的 $Y _ { \mathrm { r } }$ 轴平行。这些研究人员通常相对于桡骨（而非尺骨）来定义运动。因此，当手腕处于腕关节中立位时，各腕骨坐标系（Fig. 2）的朝向应与桡骨坐标系平行。因此，$Y _ { \mathrm { c a r p a l ~ b o n e } }$ 将平行于 $Y _ { \mathrm { r } }$，$X _ { \mathrm { c a r p a l ~ b o n e } }$ 和 $Z _ { \mathrm { c a r p a l ~ b o n e } } .$ 亦然。目前，大多数需要定义腕骨坐标系原点的研究人员都采用该骨的体积质心。因此建议，在必要时，腕骨坐标系的原点应位于该骨的体积质心处。

为了描述拇指腕掌关节（trapeziometacarpal joint）的运动，大多角骨（trapezium）需要一个独立的坐标系。为此将采用 Cooney et al. (1981) 定义的坐标系：“Y 轴从大多角骨鞍状关节面中央嵴的正中点延伸至大多角骨、舟骨和小多角骨交界处的中心。X 轴沿垂直于大多角骨中央嵴的线呈背侧向掌侧方向延伸，并穿过背侧表面的中点到达大多角骨结节的近端掌侧极。Z 轴垂直于 X 轴和 Y 轴，并且几乎平行于大多角骨掌骨面的中央嵴”。

## 4.3.4. 掌骨坐标系—— $- X _ { \mathrm { m } } Y _ { \mathrm { m } } Z _ { \mathrm { m } }$

五根掌骨的五个坐标系以相同的方式描述。掌骨的主要差异在于它们与腕骨“接触”的基底部形状及其相对运动能力。在这方面，第一掌骨具有非常大的活动范围。第三掌骨具有特殊意义，因为它被用于定义整体腕部运动。大多数研究人员认为第二或第三掌骨代表了手的运动。

$O _ { \mathrm { m } } \mathrm { : }$ 每个坐标系的原点位于每根掌骨基底部与骨头之间的中点。在横断面中，它大约位于管状骨的中心（在其转动惯量处）。

$Y _ { \mathrm { m } } { \mathrm { : } }$ 平行于从掌骨远端骨头中心到掌骨基底部中点连线的直线。

$X _ { \mathrm { { m } } } \colon$ $X _ { \mathrm { m } }$ 轴和 $Y _ { \mathrm { m } }$ 轴将构成一个矢状面，将掌骨分割为镜像对称的两部分。

$Z _ { \mathrm { m } } \mathrm { : }$ 垂直于 $X _ { \mathrm { m } ^ { + } }$ 轴和 $Y _ { \mathrm { m } ^ { - } \mathrm { a x i s } . }$ 的公垂线。

## 4.3.5. 指骨坐标系—— $- X _ { \mathfrak { p } } Y _ { \mathfrak { p } } Z _ { \mathfrak { p } }$

五指的 14 个指骨坐标系的描述方式与掌骨系统类似。五指的近节指骨和中节指骨在形状上相似，五根远节指骨也是如此。

## 4.4. 手和腕部的 JCS 及运动

4.4.1. 指间关节、掌指关节、腕骨间关节、桡腕关节和腕掌关节的 JCS 及运动

e1：固定于近端骨段且与近端骨段坐标系的 Z 轴重合的轴。

旋转（a）：屈曲或伸展（屈曲为正）。

位移 ðq1Þ：桡侧或尺侧平移。

e3：固定于远端节段并与远端节段坐标系 Y 轴重合的轴。

旋转 (g)：旋转（旋前–旋后）。零度旋转定义为处于前臂中立位。旋前为正向旋转。旋后为负向旋转。

位移 $( q 3 ) { \mathrm { : } }$ ：近端或远端平移。

e2：垂直于 e1 和 e3 的公垂轴。旋转 (b)：内收或外展，或桡偏或尺偏（尺偏为正）。位移 ðq2Þ：背侧或掌侧平移。

对于指间关节、第一掌指关节、腕骨间关节和桡腕关节，中立姿势定义为近端和远端节段坐标系的方向保持一致的位置。对于第二至第五掌指关节，中立姿势定义为远端节段坐标系的方向与第三掌骨坐标系方向相同的位置。当第三掌骨坐标系与腕部坐标系对齐时，第三腕掌关节处于中立位。对于第一腕掌（大多角骨-掌骨）关节，中立姿势定义为近端节段坐标系（如 Cooney 等人，1981 所定义）与远端节段坐标系的方向相同的位置。第二、第四和第五腕掌关节的中立姿势可以按类似方式定义。

## 4.4.2. 桡尺关节的 JCS 与运动

对于桡尺关节，在中立姿势下桡骨和尺骨的 Y 轴可能不平行。根据受试者的不同，它们可能仅偏离几度。桡骨和尺骨的中立位置在临床上称为前臂旋转中立位。肘关节屈曲 90<sup> </sup> 时，该位置可以形象地表现为拇指指向肩部。在标准解剖学姿势下，桡骨相对于尺骨处于旋后状态。

对于桡尺关节，我们提出了一个中间坐标系，其原点与桡骨坐标系原点重合。当前臂处于前臂旋转中立位时，该中间坐标系的方向将与尺骨坐标系对齐。随后，将使用上述屈曲/伸展、桡尺偏和旋前/旋后的定义来描述桡骨相对于尺骨的运动，但使用的是桡骨的中间坐标系和尺骨坐标系。本标准的使用者应定义中间坐标系相对于基于解剖学的桡骨坐标系的方向。

e1：固定于尺骨并与桡骨中间坐标系 Y 轴重合的轴。

旋转 ðaÞ：旋后或旋前（旋前为正）。

位移 ðq1Þ：近端或远端平移。

e3：固定于中间桡骨坐标系且与中间桡骨坐标系的 Z 轴重合的轴。

旋转 ðgÞ：屈曲–伸展（屈曲为正）。

位移 ðq3Þ：桡侧或尺侧平移。

e2：垂直于 e1 和 e3 的公垂轴：旋转 ðbÞ：桡偏–尺偏（尺偏为正）。

位移 ðq2Þ：背侧或掌侧平移。
