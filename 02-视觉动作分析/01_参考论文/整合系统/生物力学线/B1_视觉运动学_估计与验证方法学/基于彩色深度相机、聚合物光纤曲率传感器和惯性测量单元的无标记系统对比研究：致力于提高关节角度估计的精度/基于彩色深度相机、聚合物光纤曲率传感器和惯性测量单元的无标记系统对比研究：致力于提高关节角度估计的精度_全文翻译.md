摘要：本文对比了多红绿蓝深度（RGB-D）视觉系统、基于光强变化的聚合物光纤（POF）传感器以及惯性测量单元（IMUs）在人体关节角度估计和运动分析中的性能。该系统性对比旨在研究视觉系统的非侵入性特征与其在关节角度测量中相对于可穿戴技术精度的权衡。该多RGB-D视觉系统由两个基于摄像头的传感器组成，其中采用传感器融合算法来缓解此类系统中常见报告的遮挡和超出测量范围问题。采用了两种可穿戴传感器进行角度估计的对比：(i) 用于测量单自由度（1-DOF）角度的POF曲率传感器；以及 (ii) 来自Xsens的商用IMUs MTw Awinda。实施了一项评估11名健康志愿者肘关节的实验方案，并通过相关系数和均方根误差（RMSE）展示了三种系统的对比结果。此外，本文提出了一种用于无标记摄像头系统角度校正的新方法，以最小化矢状面上的误差。结果显示，传感器之间的相关系数高达0.99，RMSE为4.90<sup>◦</sup>，与未补偿的结果（10.42<sup>◦</sup>）相比降低了一半。因此，采用所提技术的RGB-D系统是用于关节角度评估的一种具有吸引力的非侵入性且低成本的选择。作者认为所提出的视觉系统是开发基于游戏的交互环境以及协助医疗专业人员在体育训练和康复治疗的运动分析过程中生成功能参数的有价值工具。

关键词：关节角度运动学；人体运动分析；RGB-D相机；聚合物光纤；惯性测量单元

## 1. 引言

开发能够系统分析人体运动的基于技术的工具正引起广泛且日益增长的关注。值得注意的是，在医疗背景下针对儿童的应用中，或在评估患病及老年人群的行动能力障碍 [1] 时，实施自动化系统来检测人体运动具有诸多优势。自动量化身体运动以在稳定性、持续时间、协调性和姿势控制等决策过程中为专家提供支持，是这些基于技术的方法所期望达到的结果 [2,3]。尽管该领域近期取得了进展，但由于无障碍障碍、依附于身体的佩戴要求以及系统成本高昂等因素，针对患有感官处理和认知障碍的儿童以及行动不便的成人的人体运动自动化量化仍面临多重挑战。

人体运动的自动分析通常涉及获取三维（3D）关节数据（如位置和方向），这些数据通过侵入式或非侵入式方法（也称为可穿戴和非可穿戴技术）以两种不同方式进行估计 [4]。可穿戴系统具有便携性，可供运动障碍人群在非结构化场景中使用 [5]。然而，非可穿戴传感技术和处理技术的进步已能够在高度结构化的环境中高精度地测量人体生物力学特征 [6]。例如，基于摄像机的无标记（markerless）系统可用于使用者无法佩戴设备来采集数据的场景 [4]。

通常，关节角度的分析是通过便携式可穿戴传感器进行的，其中包括安装在单轴上的电子测角计和电位计；然而，它们体积庞大且会限制自然的运动模式 [7]。柔性测角计能更好地适应身体部位，且对多中心关节运动引起的对准不良不敏感。此外，它们采用应变计，由于其高灵敏度，必须小心贴附在皮肤上 [8]。微机电系统（MEMs）的进步推动了新型可穿戴传感器的发展。

尽管应用广泛，但惯性测量单元（IMUs）对磁场具有高敏感性，且需要频繁校准 [9]。新型传感器技术，例如光学传感器（具有紧凑、轻量、柔韧以及对电磁干扰不敏感等优点 [10]），正通过不同方法应用于关节角度测量。这些方法包括光强变化 [11]、光纤布拉格光栅（fiber Bragg gratings）[12] 和干涉仪 [13]。考虑到低成本、信号处理简单以及便携性等优势 [14]，基于光强变化的传感器在运动分析和机器人应用中作为关节角度评估的可行替代方案脱颖而出 [15]。然而，迄今为止，基于聚合物光纤（POF）的曲率传感器与上述测角计具有相同的局限性，因为其角度评估仅局限于单一平面。

非可穿戴人体运动分析系统通常使用多个图像传感器或多个运动传感器 [16]。后者可分为基于标记（marker-based）或无标记的运动捕获 [17]。尽管商用基于标记的系统能够以高精度跟踪人体运动，但无标记系统具有诸多优势 [18]。无标记系统能够免除为具有身体或认知局限的使用者粘贴标记的困难 [19]。

然而，大多数无标记系统需要表面模型。因此，三维表面重建是无标记捕捉的先决条件 [17,20]。现成深度传感器（如 Microsoft Kinect [21]）的出现使获取深度数据变得容易。此类深度数据对姿势识别非常有益 [22]。然而，由于精度和范围的限制，使用深度传感器进行动作捕捉仍是一个具有挑战性的问题 [23]。

为了构建一个高效的系统，有必要确定其功能和要求，以切实满足用户的需求 [24]。例如，对于因身体残疾而妨碍佩戴传感器的群体，医务人员在采集其运动能力参数时会面临困难。因此，有必要提出有效且简便的方法来获取此类参数。

所提出的精度提升技术的主要假设是测量误差与用户的人体测量学参数之间存在相关性。由此获得了一个补偿方程，该方程将误差与用户的人体测量学参数关联起来。尽管所提出的方法在传感器系统应用之前需要较长的校准步骤，但与使用无标记系统进行角度分析的常规方法相比，该方法产生的误差更小。本文提出的新颖方法能够提高非穿戴式系统的精度。此外，需要强调的是，此类方法可应用于不同的系统（甚至是更精确的系统）以进一步提升其精度。而且，通过对校准步骤进行少量调整，该技术还可应用于三维动态评估。

本文展示了多红绿蓝-深度（RGB-D）视觉系统、基于光强变化的 POF 传感器以及 IMUs 之间的分析与对比，这些系统均用于人体肘关节角度评估。选择这些可穿戴传感器是因为其紧凑性，不会对无标记相机系统造成遮挡。此外，本次对比中未使用基于标记的相机系统，因为标记可能会促进或妨碍无标记系统的关节检测，从而无法代表实际应用中的条件。这一系统性对比旨在通过与用于关节角度测量的可穿戴技术进行比较，研究视觉系统的无标记特性与其精度之间的权衡。因此，本文提出了一种基于受试者人体测量数据的补偿技术，并使用 POF 曲率传感器测量值对其进行了验证。

## 2. Materials and Methods

## 2.1. RGB-D Fusion System

该系统采用开源项目 Robot Operating System (ROS，机器人操作系统) 设计为分布式和模块化架构。此处开发的架构是基于节点图方法构建的。该系统由多个用于本地视频处理的节点组成，分布在多个不同的主机上，并在运行时以对等拓扑（peer-to-peer topology）相互连接。节点间连接以握手方式实现，并通过 XML-RPC 协议（使用 XML 对其调用进行编码的远程过程调用协议）进行通信。节点结构灵活、可扩展且可动态修改，即每个节点都可以在整个实验过程中启动并保持运行，或者在运行时恢复并相互连接。

一个由非结构化且可扩展的 RGB-D 相机网络组成的计算机视觉框架被用于自动估计关节位置，该视觉传感器网络克服了遮挡和视场狭窄等典型问题。因此，该系统采用分布式架构独立处理每个传感器的视频。在该结构中，每台相机均执行一个人体分析算法。随后，来自每个传感器的数据被转换并表示在统一的共享参考坐标系下，以进行数据融合并生成全局关节位置。

视觉系统由两台 RGB-D 相机组成，如图 Figure 1 所示，每台相机均连接到一台配备 Intel Core i5 处理器和 GeForce GTX GPU 显卡（GTX960 显卡和 GTX580 显卡）的工作站，以执行本地数据处理。所有工作站通过局域网连接，使用网络时间协议（Network Time Protocol, NTP）进行同步，并通过 ROS 进行管理。数据融合估计结果被发送用于第三方软件交互，该交互在处理能力最高的工作站上执行。

具有最高处理能力的工作站同时用作系统服务器，其负责使用卡尔曼滤波器（Kalman filter）执行视觉融合过程。当服务器接收到包含客户端位置数据的消息时，会检查上一条接收消息与当前消息之间的时间间隔。如果该间隔大于 33 ms，系统将丢弃接收到的测量值，并从下一个待接收的测量值重新开始计算时间间隔。这样做是为了避免使用时间差异过大的融合数据。如果数据处于该时间间隔内，系统将客户端坐标系转换为在外参标定过程中定义的全局坐标系。随后，数据被输入到卡尔曼滤波器中。保存的数据通过低通巴特沃斯滤波器（Butterworth filter）进行处理，用于消除噪声并获得更平滑的估计（见 Figure 3）。

## 2.2. POF 传感器

本工作所使用的塑料光纤（POF）曲率传感器基于光强变化原理，若将光纤输入端连接至光源、输出端连接至光电探测器，当光纤受到弯曲时，POF 输出端的功率会发生变化。正如 Leal-Junior et al. [29] 中深入讨论的那样，该功率变化与弯曲角度成正比，且由于光纤上的某些效应（如辐射损耗、光散射和应力光学效应）而产生。为了提高传感器的线性和灵敏度并减小迟滞，在光纤上制作了一个侧向切口，去除了光纤包层和部分纤芯（考虑到常规实心光纤的芯-包层结构 [30]）。在光纤上进行的这种材料去除形成了一个所谓的敏感区，光纤在该区域对弯曲变化更加敏感。

本研究所采用的 POF 为多模 HFBR-EUS100Z POF（Broadcom Limited, Singapore），其纤芯由聚甲基丙烯酸甲酯（Polymethyl Methacrylate, PMMA）制成，直径为 980 µm，而包层厚度为 10 µm。此外，该光纤还带有一层用于机械保护的聚乙烯涂层，使该光纤的总直径达到 2.2 mm。通过磨料去除材料在光纤上制作侧向切口，敏感区的深度和长度分别约为 14 mm 和 0.6 mm。正如 Leal-Junior et al. [31] 实验证明的那样，所选取的敏感区长度和深度能够获得高灵敏度、良好线性度以及低迟滞。带有侧向切口的 POF 一端连接到中心波长为 660 nm 的发光二极管（LED）IF-E97（Industrial Fiber Optics, Tempe, AZ, USA），而另一端（输出端）连接到光电二极管 IF-D91（Industrial Fiber Optics, Tempe, AZ, USA）。POF 曲率传感器在应用于运动分析之前需要进行标定步骤，该标定是通过将 POF 传感器放置在 Figure 5 所示的实验装置上完成的。在该装置中，一台位置和角速度受控的直流电机在 0–90<sup>◦</sup> 的角度范围内对 POF 敏感区执行屈曲和伸展运动。随后，将功率衰减与电位计（同样见 Figure 5）测得的角度进行比较，并进行线性回归。

Figure 5. POF 曲率传感器标定实验装置。

为了获取用户的运动参数，将传感器放置在他们的肘关节处。由于 POF 曲率传感器的安装条件直接影响其响应（如 Leal-Junior 等人 [31] 中所讨论的），要求每位用户在矢状面上完成 90<sup>◦</sup> 角运动（在两种情况下均是如此，即传感器分别位于肘关节和膝关节处）。因此，利用矢状面上的 90<sup>◦</sup> 运动，根据传感器在每个受试者身上的放置位置对其进行校准。

## 2.3. IMU

本研究使用了两个放置在用户身体部位的无线 MTw IMU 传感器（Xsens, Enschede, The Netherlands）（重量：10 g，尺寸：$4 7 \times 3 0 \times 1 3 \mathrm { m m } )$。每个 MTw 传感器包含一个 3D 陀螺仪、一个 3D 加速度计和一个 3D 磁力计。IMU 通过专有无线通信协议以 100 Hz 的采样频率将其数据发送到工作站（Awinda, Xsens）。四元数格式的姿态数据是通过制造商开发的定制卡尔曼滤波器（Kalman filter）（XKF3-hm）[32] 估计得到的。

我们实现了一种使用两个 IMU 单元来估计肘部屈曲-伸展角度的方法。近端肢体（即上臂）上的 IMU 用作参考，以下称为 $S _ { 1 }$。位于远端肢体上的第二个 IMU 将被称为 $S _ { 2 }$。该算法在其运行中使用五个坐标系。$S _ { 1 }$ 和 $S _ { 2 }$ 是 IMU 传感器的局部坐标系，内嵌于各个传感器中。技术-解剖坐标系 $( B _ { 1 }$ 和 $B _ { 2 } )$ 对应于肢体的方向 [33]。最后，全局坐标系 $G ,$ 是由重力加速度向量和地磁北极构成的参考系。参考 IMU 传感器 $\left( S _ { 1 } \right)$ ) 与肢体保持精确对准，从而在校准时刻、处于中立站立姿势并在应用重力对齐后，通过 $S _ { 1 } \left( S _ { 2 } \right)$ 估计出 $B _ { 1 } \left( B _ { 2 } \right)$ 坐标系。

该算法旨在估计近端肢体与远端肢体方向之间的夹角。因此，肢体的方向应当投影到一个共同的坐标系（即全局坐标系）中。这是通过姿态四元数 ${ { G } _ { { \mathbf { q } } { { B } _ { 1 } } } } ( t )$ 和 ${ { \bf \Pi } ^ { G } } { \bf { q } } _ { B _ { 2 } } ( t )$ 实现的。如先前工作 [33–35] 所提出的，该估计过程预设在直立中立姿势的校准时刻，两个技术-解剖坐标系的 x 轴均与重力向量对齐。此外，肘关节被简化为单自由度（1-DOF）铰链关节。屈曲-伸展角（α）按以下步骤进行计算：

• 如 [33] 中所提议的，计算在校准时刻将 $S _ { 1 }$ 坐标系的 x 轴 $\mathbf { \boldsymbol { x } } _ { S _ { 1 } }$ 与全局坐标系中表示的重力向量 $( \mathbf { z } _ { G } )$ 对齐的旋转四元数 $\mathbf { q } _ { c }$。

应用公式 (2) 和 (3) 定义校准时刻的技术-解剖坐标系 ${ { \bf \Lambda } ^ { G } } { \bf q } _ { B _ { 1 } } ( 0 )$ 和 ${ { \bf \Sigma } ^ { G } } { \bf q } _ { B _ { 2 } } ( 0 )$。

$$
{ } ^ { G } \mathbf { q } _ { B _ { 1 } } ( 0 ) = \mathbf { q } _ { c } \otimes { } ^ { G } \bar { \mathbf { q } } _ { S _ { 1 } } ( 0 )\tag{2}
$$

$$
{ } ^ { G } \mathbf { q } _ { B _ { 1 } } ( 0 ) = { } ^ { G } \mathbf { q } _ { B _ { 2 } } ( 0 )\tag{3}
$$

其中 $\otimes$ 表示哈密顿积（Hamilton product）。请注意，由于上述假设，在校准时刻，${ { \bf \Lambda } ^ { G } } { \bf q } _ { B _ { 1 } } ( 0 )$ 与 ${ { \bf \Lambda } ^ { G } } { \bf q } _ { B _ { 2 } } ( 0 )$ 相等。这意味着在中立伸直姿势下的初始角度为零。

• 使用公式 (4) 计算传感器 $S _ { 1 } ~ ( S _ { 2 } )$ 相对于其关联身体节段 $B _ { 1 } \ ( B _ { 2 } )$ 的方向。请注意，$B _ { 1 } { \bf { q } } _ { S _ { 1 } }$ 和 $B _ { ^ 2 { \bf q } S _ { 2 } }$ 在所有时间时刻均为常数。

$$
{ } ^ { B _ { 1 } } \mathbf { q } _ { S _ { 1 } } = \left( ^ { G } \mathbf { q } _ { B _ { 1 } } ( 0 ) \right) ^ { - 1 } \otimes ^ { G } \bar { \mathbf { q } } _ { S _ { 1 } } ( 0 )\tag{4}
$$

• 使用公式 (5) 估计身体节段的方向 ${ { G } _ { { \mathbf { q } } { { B } _ { 1 } } } } ( t )$ 和 ${ { \bf \Pi } ^ { G } } { \bf { q } } _ { B _ { 2 } } ( t )$。请注意，公式 (4) 和 (5) 是用 $B _ { 1 }$ 和 $S _ { 1 . }$ 表示的，但它们同样适用于 $B _ { 2 }$ 和 $S _ { 2 }$。

$$
{ } ^ { G } \mathbf { q } _ { B _ { 1 } } ( t ) = { } ^ { G } \mathbf { q } _ { S _ { 1 } } ( t ) \otimes \left( { } ^ { B _ { 1 } } \mathbf { q } _ { S _ { 1 } } \right) ^ { - 1 }\tag{5}
$$

• 计算 ${ { G } _ { { \mathbf { q } } { { B } _ { 1 } } } } ( t )$ 与 ${ { \bf \Pi } ^ { G } } { \bf { q } } _ { B _ { 2 } } ( t )$ 之间的相对方向。通过这种方式，$\mathbf { \nabla } B _ { 1 } { } _ { \mathbf { q } _ { B _ { 2 } } } ( t )$ 随后被分解为“ZXY”欧拉角。绕 z 轴的旋转表示肘关节屈伸角度 $\alpha ,$ ，这与 ISB（国际生物力学学会）的建议 [16,36] 一致。

$$
{ } ^ { B _ { 1 } } \mathbf { q } _ { B _ { 2 } } ( t ) = \left( { } ^ { G } \mathbf { q } _ { B _ { 1 } } ( t ) \right) ^ { - 1 } \otimes { } ^ { G } \mathbf { q } _ { B _ { 2 } } ( t )\tag{6}
$$

## 3. 结果与讨论

三个系统的对比变量为：(i) 相关系数以及 (ii) RGB-D 相机、IMU 和 POF 之间的均方根误差（RMSE）。在对各传感器进行对比后，提出了一种用于无标记相机系统的角度校正新方法，并验证了其在矢状面上校正角度误差的有效性。所提出的技术基于每位受试者的人体测量数据，通过测量误差与每位受试者手臂长度（公式 (1) 中的 $( d _ { 1 } , d _ { 2 }$ 和 $d _ { 3 }$）之间的相关性，校正相机系统相较于 POF 曲率传感器和 IMU 系统的误差。通过这种方式，获得了考虑每位受试者长度 d<sub>3</sub> 的误差校正方程。

[40] 中所讨论的那样。

## 3.3. 无标记相机系统中的角度校正技术

所提出的针对基于无标记相机系统中角度误差的补偿技术，其主要假设是误差主要由遮挡引起，或是由于计算机视觉算法在追踪用于计算图 4 中参数 $d _ { 1 }$ 和 $d _ { 2 }$ 的解剖学特征点时产生的错误。如果这些参数估计不准确，就会导致角度评估中出现误差。因此，可以假设这些角度误差与每位受试者的人体测量学参数存在相关性。为了验证这一假设并开发针对该无标记系统的补偿技术，每位受试者仅在矢状面上完成了 3 次屈曲/伸展周期（见 2.5 节），并将基于无标记相机系统估计的角度与 POF（聚合物光纤）曲率传感器测量的角度进行了对比。我们使用 POF 曲率传感器来开发该补偿技术，是因为该传感器已针对电位计完成了评估，在此表征测试中表现出了较低的误差。然而，我们必须强调，其他传感器系统也可以作为所提出补偿技术的参考，包括 IMU（惯性测量单元）、基于标记的相机系统以及测角计。本文提出的技术基于这样一个基本前提：误差主要与参数 $d _ { 1 } , d _ { 2 }$ 和 $d _ { 3 }$ 的检测相关（由自身遮挡、计算机视觉算法中的数值误差等原因造成）。因此，通过考虑角度估计中使用的实际人体测量值 $( d _ { 1 }$ 和 $d _ { 2 } )$，可以将误差进行关联（并进而补偿），这些测量值可以直接在每位受试者身上测量，也可以利用受试者的身高进行估算 [41]。

为了对该技术进行初步表征，分析了五位受试者（M1、M3、M5、F2 和 F5）的屈曲/伸展周期，并针对这五位受试者分别对基于相机系统估计的角度与 POF 曲率传感器测量的角度进行了多项式回归，每个方程的形式如公式 (7) 所示：

$$
a n g _ {r e f} = a \cdot a n g _ {c a m} ^ {3} + b \cdot a n g _ {c a m} ^ {2} + c \cdot a n g _ {c a m} + d,\tag{7}
$$

其中 $a n g _ { c a m }$ 是由相机估计的角度，$a n g _ { r e f }$ 是由 POF 曲率传感器测量的角度。此外，a、b、c 和 d 是通过使用最小二乘法对两种传感器系统（即基于无标记相机和 POF 传感器）的角度响应之间进行回归实验获得的多项式回归系数。系数 d 是传感器响应上的偏移量（单位为 <sup>◦</sup>）。因此，如果传感器响应在测试开始时进行了归一化，该偏移量将为零。出于这个原因，系数 d 未用于角度误差校正系数与受试者人体测量数据之间的相关性分析。

Figure 12 展示了受试者 F5 在第三次屈曲周期（作为一个示例）中由基于相机的系统测量的角度与 POF 曲率传感器之间的回归。结果表明，使用三次多项式回归的响应之间具有高度相关性（0.998）。事实上，这种高度相关性出现在所分析的五名受试者的所有周期中，在所有情况下相关系数均高于 0.9。因此，两种传感器系统的误差之间存在相关性的假设是成立的（基于所进行的分析）。接下来的一步是将多项式系数（a、b 和 c）与每位参与者的人体测量数据进行关联。

所提出的用于无标记相机系统角度误差校正的技术，是提高此类系统角度精度的一种可行且直接的选择。该方法包含一个标定步骤，需将相机系统的响应与参考传感器系统（例如可穿戴系统或基于标记的相机系统）的响应进行对比。然后，将无标记相机系统上获得的误差与受试者的人体测量参数（本例中为手臂长度）进行比较，以获得将角度校正与每个受试者参数相关联的方程。因此，需要指出一个重要的注意事项：标定流程必须针对可靠的参考进行，并且运动应在单一平面内进行，即矢状面、额状面或水平面运动。此外，标定必须在将要进行角度分析的相同范围内进行，$\mathrm { i . e . , }$ 如果要分析 0 到 $1 6 0 ^ { \circ }$ 的角度区间，则必须在这一相同的角度范围（0 到 160<sup>◦</sup>）内进行标定。通过遵循这些步骤，便可使用无标记相机系统获得精确的单平面角度测量结果。因此，该方法的主要局限性在于，在所设想的应用中应用所提出的传感器系统之前，必须在相同的运动范围和平面内进行预先的标定阶段。然而，值得注意的是，通过相应地调整标定阶段并将误差与每位受试者的人体测量参数相关联，所提出的方法可以扩展到不同自由度的运动分析中。

## 4. 结论

本文对一种用于肘关节角度评估的无标记摄像机系统进行了分析与比较。该无标记系统采用两台 RGB-D 摄像机，以减少与自遮挡问题相关的误差和不准确性。在不同平面（矢状面、横断面和额状面）进行的屈曲/伸展运动中，将该非穿戴式系统的性能与两种可穿戴解决方案（即 POF 曲率传感器和 IMU）进行了对比。尽管所提出的无标记摄像机系统表现出的误差低于文献中提出的一些同类系统，但对于运动分析应用而言误差仍然偏高。为了解决这一局限性，对系统的全面分析表明，尽管误差较高，但无标记摄像机系统的响应与可穿戴传感器的响应具有高度相关性。这也表明了在此类系统中应用旨在减少误差的后处理技术的可能性。因此，提出了一种基于受试者人体测量数据的补偿技术，并利用 POF 曲率传感器的测量值对其进行了验证，从而使 RMSE 显著降低。

所提出的 RGB-D 视觉系统以及此处提出的新型补偿技术表明了该系统在运动分析中的适用性，因为在测试的角度范围内（即在矢状面上高达 120<sup>◦</sup>）获得的平均误差约为 4<sup>◦</sup>，这与运动分析中某些传感方法所获得的误差一致 [42]。因此，这项工作可为基于无标记摄像机系统的运动分析应用铺平道路。未来的工作包括在其他运动平面（额状面和横断面）以及 3D 运动场景中进一步研究该技术。此外，还将针对无标记摄像机系统与光纤传感器开展进一步评估并开发新的传感器融合技术。目前，在降低误差方面，本工作可被视为此类发展的基础。
