# 无标记动作捕捉与生物力学分析管线

R. James Cotton<sup>1,2,∗,</sup> , Allison DeLillo<sup>1</sup>, Anthony Cimorelli<sup>1</sup>, Kunal Shah<sup>1</sup>, J.D. Peiffer<sup>1,3,</sup> , Shawana Anarwala<sup>1</sup>, Kayan Abdou<sup>1</sup>, Tasos Karakostas<sup>1,2</sup>

摘要—基于计算机视觉和人体姿态估计（human pose estimation, HPE）的无标记动作捕捉具有扩大精准运动分析普及度的潜力。这可以通过实现更准确的疗效追踪并为研究提供更灵敏的工具，从而极大地有益于康复领域。从获取视频到提取准确的生物力学结果之间包含众多步骤，且目前指导这些管线中许多关键设计决策的研究十分有限。在这项工作中，我们分析了其中的几个步骤，包括用于检测关键点的算法和关键点集、用于生物力学逆向运动学（inverse kinematics, IK）的轨迹重建方法，以及优化 IK 过程的方法。我们发现几个重要的特性是：1）使用在多个数据集上训练的最新的算法，该算法能够生成一组受生物力学启发的密集关键点；2）使用隐式表示（implicit representation）为 IK 重建平滑且受解剖学约束的标记点轨迹；3）迭代优化生物力学模型以匹配密集标记点；4）对 IK 过程进行适当的正则化。我们的管线使得在康复医院中轻松获取准确的运动生物力学估计成为可能。

## 引言

用于常规且精准的运动分析（如步态分析）的易用工具对康复至关重要。它们能够实现对临床疗效更精确的监测，并为更灵敏的研究提供支持。临床金标准是基于标记的光学动作捕捉 [1]，但与之相关的时间和成本限制了其应用。最近，计算机视觉和人体姿态估计（HPE）[2] 的进展使得基于多台校准摄像机的无标记动作捕捉方法成为可能 [3]–[7]，从而有望扩大精准运动分析的普及度。

无标记动作捕捉通常包含两个关键步骤：（1）从多台校准并同步的摄像机的 HPE 输出中重建三维关键点（即虚拟标记点）轨迹；（2）将生物力学模型对这些轨迹进行逆向运动学（IK）拟合。IK 包括缩放个体的生物力学模型，并计算与轨迹最佳对齐的关节运动学参数。额外的步骤可能会计算动力学（kinetics），即关节力矩和地面反作用力，但我们在本工作中不予以考虑。

为了使无标记动作捕捉产生准确的关节运动学结果，三维关键点轨迹必须在身体上包含足够密集的观测点，以约束逆向运动学（IK）的结果。在公开数据集上训练的大多数人体姿态估计（HPE）算法在髋部和肩部之间不生成关键点，这限制了跟踪髋部和脊柱的准确性 [8]。一种无标记动作捕捉系统 OpenCap [4] 通过利用现有的生物力学数据集，并训练神经网络将这些稀疏关键点的轨迹映射到最可能的稠密关键点集，从而缓解了这一问题。该方法的风险在于，填补并非直接从图像中提取的关键点位置可能会使结果偏向于平均动作，且可能无法泛化到运动方式不同于训练数据集的康复患者身上。现有 HPE 数据集的另一个挑战是，标记点和关节的定义缺乏充分的生物力学依据，且彼此差异很大 [9]。最近的一项研究训练了一个自动编码器作为“罗塞塔石碑”，用于在这些不同的数据集之间进行转换，其中包括一些在基于标记的跟踪中常见的、具有密集且有生物力学依据的关键点集的数据集 [10]，并发现这种跨数据集训练带来了显著的增益 [11]。

在执行 IK 之前缩放骨骼通常需要受试者在静止站立时采集额外的数据。这可能会减慢临床工作流程，而且对于许多康复受试者来说，在无辅助的情况下直立站立可能是一项挑战。最近有一种在执行 IK 的同时对骨骼进行缩放的方法被提出 [12]。该算法使用了同一作者开发的 nimblephysics 引擎 [13]，该引擎针对生物力学扩展了 DART 物理引擎 [14]。

用于逆运动学（IK）的重建三维轨迹也应保持平滑且符合解剖学一致性。当来自人体姿态估计（HPE）的关键点存在噪声，或检测到遮挡相机的其他人时，实现这一点可能极具挑战性。此外，添加诸如时间平滑性或骨架一致性等约束可能会使优化收敛速度大大降低。我们最近比较了几种轨迹重建方法，发现使用由神经网络参数化、将时间映射到三维位置的隐式函数，能够实现既平滑又符合解剖学合理性的精确重建。该方法可生成平滑且解剖学一致的轨迹，检测到的步宽和步长与使用 GaitRite [15] 测量的结果相差在 10mm 以内。

我们的目标是确定如何最佳地组合这些组件以计算关节运动学。具体而言，我们的贡献如下：

• 我们证明了基于隐式轨迹重建的 IK 性能优于使用鲁棒三角测量（robust triangulation）。

• 我们发现使用来自 [10], [11] 的密集关键点集比更常用的 25 个关键点表现更好。

• 我们展示了在无需站立校准试验的情况下，将双层优化（bilevel optimization）[12] 用于无标记动作捕捉。

• 我们优化了生物力学模型以及 IK 算法 [12] 的超参数。

## 方法

## 参与者

本研究获得了西北大学机构审查委员会（Northwestern University Institutional Review Board）的批准。我们从 Shirley Ryan AbilityLab 的住院部和门诊部招募了 25 名参与者。其中包括有脑卒中病史者（n=8）、脊柱肿瘤患者（n=1）、创伤性脑损伤患者（n=2）、轻度足下垂患者（n=1）、膝骨关节炎患者（n=2）以及假肢使用者（n=11）。年龄分布在 27 至 78 岁之间。部分参与者使用了包括矫形器、轮式助行器或手杖在内的辅助设备，少数参与者出于安全考虑需要身边人员提供接触保护性协助。我们特意招募了具有多样化特征的康复人群，一方面是为了确保该系统针对各类患者均能得到鲁棒性验证，另一方面也因为这正是我们最终系统拟应用的目标人群。数据共包含 162 次试验，涵盖 2164 个步态周期（步数），每位参与者的步数在 44 至 154 步之间，视频帧数超过 100 万帧。

## 数据采集、视频处理与轨迹

数据采集、视频处理和轨迹重建与 [15] 中的方法类似，在此作简要总结。

数据采集：多相机数据是在一个 7.4m × 8m 的房间内使用定制系统采集的，受试者沿对角线长度（11m）行走。我们使用了 10 台 FLIR BlackFly S GigE 相机（在早期的几次实验中为 8 台），这些相机使用 IEEE1558 协议进行同步，以 30 fps 的速率采集数据，时间戳之间的典型差异小于 100µs。我们混合使用了包括 F1.4/6mm、F1.8/12m、F1.6/4.4-11mm 在内的多种镜头，镜头的选择和位置布局确保了在整个步道上至少有三台相机覆盖受试者，不过房间的几何结构限制了角落区域的覆盖范围。

采集软件是在 Python 中使用 PySpin 接口实现的。对于每次实验，使用跨越采集空间的棋盘格（110mm 方格的 7 × 5 网格）采集标定视频。使用 anipose 库 [16] 进行外参和内参标定。内参标定仅包含第一个畸变参数。足部触地（foot contact）和离地（toe-off）的时间与位置是使用横跨房间对角线的 GaitRite 步道采集的 [17], [18]。

视频处理：采集到的视频按照先前描述的方法进行分析 [15]。简而言之，视频使用 PosePipe [19] 进行处理。Easymocap [20] 用于初始的多视角关联，并用于在每个录制会话中指示感兴趣的受试者。与 [15] 相比，在本研究中，图像平面中的 2D 关键点也是使用一种最近开发的方法检测的，该方法在众多 3D 数据集上进行训练并输出所有这些格式（MeTRAbs-ACAE）[11]。具体而言，我们使用了 MOVI 数据集 [10] 的输出关键点，该数据集具有光学动作捕捉中常用的 87 个关键点位置。重要的是，这包含了骨盆和躯干周围的众多关键点，而这些在更常见的数据集中是不可用的。

默认情况下，MeTRAbs 架构 [21] 不会生成位置的置信度估计。它还会对被遮挡的关节产生最佳猜测的位置估计。尽管它能产生合理的猜测，但我们希望丢弃任何低置信度的关键点。按照作者的建议，我们通过测量从每个视频帧的 10 个不同数据增强版本估计出的每个 3D 关节位置的标准差来近似置信度。使用半极大值在 200mm 处且宽度为 50mm 的 sigmoid 函数将其转换为置信度估计。对结果的视觉检查表明，这种方法对被遮挡的关节产生了较低的置信度，而对观测到的关节产生了较高的置信度。我们还将图像边界外的任何关节的置信度设置为零。

轨迹重建：我们发现，与直接从 2D 观测中进行三角测量（使用直接线性变换或鲁棒方法）或优化每个关键点位置的显式表示 [15] 相比，使用隐式函数表示 3D 关键点轨迹能够从关键点中实现更好的重建。具体而言，该隐式表示是一个从时间映射到重建 3D 关键点位置的函数，$f _ { \theta } ~ : ~ t ~ \to ~ \mathbf { x } _ { t } ~ \in ~ \mathbb { R } ^ { J \times 3 }$。该模型通过一个具有递增隐藏单元数（128、256、512、1024、2048）的五层多层感知机（MLP）实现，每层后接层归一化（Layer Normalization）和 ReLU 非线性激活函数，最后接一个映射到输出尺寸的全连接层。我们还对 $t$ 使用了正弦位置编码 [22]，该编码在每条轨迹上从 0 缩放到 $\pi$。前四层中，时间的位置编码与每层的输出进行了拼接。

对于每条轨迹，我们优化参数 $\theta$ 以最小化损失函数，该损失函数包括 3D 关键点在图像上的重投影损失，以及捕获高频噪声和骨骼几何变化的损失项：

$$
\mathcal {L} = \mathcal {L} _ {\Pi} + \lambda_ {1} \mathcal {L} _ {\mathrm{smooth}} + \lambda_ {2} \mathcal {L} _ {\mathrm{skeleton}}
$$

。重投影损失为：

$$
\mathcal {L} _ {\Pi} = \frac {1}{T \cdot J \cdot C} \sum_ {T, J, c \in C} w _ {c, t, j} g \left(\left| \left| \Pi_ {c} \mathbf {x} _ {t, j} - y _ {t, j, c} \right| \right|\right)
$$

其中 $\Pi$ 为相机 $c$ 的投影算子，它也包含了非线性内参畸变。$y _ { t , j , c } \in \mathbb { R } ^ { 2 }$ 表示在给定时间点、关节点和相机下的检测关键点位置，$\mathbf { x } _ { t , j , c }$ 为对应的 3D 关键点。我们对 $g ( \cdot )$ 使用 Huber 损失，它在 5 个像素以内呈二次方，随后呈线性，且在误差超过 10 个像素后斜率进一步减小，从而对异常值更具鲁棒性。应用于 Huber 损失的权重 $w$ 由鲁棒三角测量算法 [15], [23] 计算得出，该算法捕获每个相机与其他相机关键点三角测量的一致性，并降低异常值的权重。我们还对比了使用鲁棒三角测量 [15], [23] 计算出的轨迹，该方法不包含任何平滑度或骨骼一致性参数。

## 基于逆运动学的生物力学分析

给定一个生物力学模型和一组标记点位置，IK 会估计关节角度 [1]。这通常需要估计三组参数：用于骨骼尺寸的人体测量参数、针对该个体的标记点偏移量以及一系列姿态。我们使用 nimblephysics 库 [13] 实现了这一过程，特别是利用了其对偶优化过程的实现，该过程可从一组动态试验中同时求解所有参数 [12]。该算法的结果是骨骼缩放参数 $S$、标记点偏移量 $\bar { \boldsymbol { \mathcal { O } } } \in \mathbb { R } ^ { 8 7 \times 3 }$，以及第 $i$ 次试验中作为关节角度轨迹的运动学参数：$\mathbf { p } _ { t } ^ { ( i ) } \in \mathbb { R } ^ { 4 0 }$。

骨骼模型提供了一个前向运动学函数，用于根据 IK 结果和校准后的模型确定预测的标记点位置：$\mathbf { x } _ { t } ^ { ( i ) } = \mathcal { M } ( p _ { t } ^ { ( i ) } , \mathcal { O } , \mathcal { S } )$。我们测量了这些基于模型的预测标记点位置与 HPE 关键点检测之间的一致性。

## 性能指标

几何一致性：我们根据重投影的基于模型的标记点与检测到的关键点之间的距离，测量了基于模型的标记点轨迹与检测到的关键点之间的几何一致性。为了量化这一点，我们在高于指定置信区间的前提下，计算了低于阈值像素数量的点所占的比例。

$$
\delta_ {t, j, c} = | | \Pi_ {c} \mathbf {x} _ {t, j} - y _ {t, j, c} | |
$$

$$
q (d, \lambda) = \frac {\sum (\delta_ {t , j , c} <   d) (w _ {t , j , c} > \lambda)}{\sum w _ {t , j , c} > \lambda}
$$

在下文中，我们汇报了 $d = 5$ 像素时的 $G C _ { d } = q ( d , 0 . 5 )$。

残差标记点误差：我们测量了从图像关键点计算出的 3D 关键点轨迹与 IK 求解后从生物力学模型计算出的标记点位置之间的平均距离。

关节极限违背：使用软性正则化的关节极限允许模型超出极限，这有时会导致异常姿态，其中关节偏移超过 $1 8 0 ^ { \circ }$。我们计算了模型拟合违背关节极限的时间比例，以及分别超出 50% 和 100% 的时间比例（分别记为 v<sub>0</sub>、v<sub>50</sub>、v<sub>100</sub>）。

姿态噪声：我们测量了 IK 结果中的高频噪声：$\begin{array} { r } { n = { \frac { 1 } { J ( T - 1 ) } } \sum _ { j } \sum _ { t = 0 } ^ { T - 1 } ( p _ { t + 1 } - \hat { p _ { t } } ) ^ { 2 } } \end{array}$

步位置误差：我们比较了 GaitRite 和 IK 结果之间由跟骨位置决定的足跟位置。我们将误差分布的宽度汇报为归一化 IQR，$\sigma _ { I Q R } = 0 . 7 4 1 3 \cdot I Q R ( x )$。

## 视频叠加

我们从不同的摄像机视角生成了视频叠加图，以确认拟合结果与实际运动的一致性。视频叠加图的生成过程为：利用 nimblephysics 模型提取每个体型和时间步长上网格到世界坐标的变换。这些数据使用 trimesh 库 [24] 组合成场景，并利用经过校准的摄像机投影矩阵通过 PyTorch3D [25] 进行渲染。由于 PyTorch3D 的透视摄像机不支持畸变系数，我们在渲染之前将摄像机畸变应用到了网格顶点上。

## 生物力学模型细化

我们的生物力学模型基于广泛使用的无肌肉 Rajagopal 模型 [26]。我们还添加了一个三自由度的颈部关节。在目视检查了大量输出后，我们手动初始化了与 MOVI 位置相对应的标记点位置。为了对其进行细化，我们执行了数次迭代：将模型拟合到整个数据集，然后通过所有受试者的平均偏移量 $O$ 来调整标记点位置。在此过程中，我们还手动细化了部分标记点位置，以确保具有可靠解剖位置的标记点不会发生漂移，例如足部、踝关节、膝关节、肘关节和腕关节。

## 超参数调优

我们手动调优了几个逆向运动学（IK）正则化超参数，包括人体测量先验、确保身体各节段具有大致一致的缩放比例、正则化解剖标记和附加跟踪标记的可调整幅度，以及超出关节极限的惩罚项。由于进行生物力学拟合所需的时间较长，且需要查看渲染效果以进行定性拟合评估，因此无法对超参数进行全面的网格搜索或运行优化算法。

## 结果

## 定性结果

该采集系统和分析软件使得对康复医院的住院和门诊受试者进行运动学分析变得容易，即使在房间内有许多其他人的情况下也是如此 [15]。检查多视角的叠加结果显示，重建的生物力学与原始图像帧之间具有良好的一致性（图 1）。该系统也足够灵敏，能够识别出具有临床意义的步态变化，如图 2 所示。这些示例采用了 MOVI 关键点，并结合了我们优化后的模型以及使用隐式轨迹表示的反向运动学（IK）超参数。接下来，我们将分析获得这些结果所至关重要的实现细节。

## 稠密标记与稀疏标记

我们最初比较了使用人体姿态估计（HPE）算法进行的生物力学分解，该算法使用了 OpenPose 以及 Halpe 和 COCO WholeBody 数据集中常见的 25 个身体关键点 [27]–[29]。这些关键点不包括髋部和肩部之间躯干或脊柱上的任何关键点。与以往的研究类似，我们发现这导致欠约束的骨盆朝向估计不稳定，并且髋关节角度也不稳定。相比之下，来自 MeTRAbs-ACAE [10], [11] 的稠密 MOVI 标记产生了稳定的结果。这在定量上体现为使用稠密标记时更低的姿态噪声水平、更低的残差标记误差以及更好的几何一致性（表 I）。

## 隐式轨迹与鲁棒三角测量

我们还比较了使用隐式轨迹与使用鲁棒三角测量的 3D 关键点位置进行 IK 拟合的效果。前者约束了平滑度和解剖学一致性，而后者则是针对每个标记和时间点独立进行估计的。我们发现隐式表示能够产生更好的拟合效果和更低的噪声（表 I）。

## 模型与超参数调优

迭代细化模型标记位置在定性上以及在我们的性能指标上均改善了结果，例如更少的关节限位违背、重投影到图像中的基于模型的标记与检测到的关键点之间更高的几何一致性，以及重建轨迹与基于模型的轨迹之间更小的残差误差。我们还发现启用软关节限位非常重要，因为硬限位会导致许多非常不合理的拟合结果（表 II）。

## 几何一致性

在我们先前的研究中，我们发现使用在 Halpe 数据集上训练的 MMPose 算法检测到的关键点并由隐式表示重建的 3D 关键点轨迹具有最高的几何一致性 [15], [28], [30]，其 $G C _ { 5 }$ 为 0.54。我们发现，使用 MOVI 关键点和 MeTRAbs-ACAE [11] 并通过隐式表示计算出的轨迹将隐式轨迹的 $G C _ { 5 }$ 大幅提升至 0.75。在执行 IK 并从模型生成预测标记位置后，该值降至 0.57，但仍高于使用 MMPose-Halpe 的轨迹。

## 空间步态参数误差

我们将基于逆向运动学（IK）结果中跟骨位置计算的步长（step length）、复步长（stride length）和步宽（step width）指标与同步的 GaitRite 记录进行了对比，结果如 Table I 所示。这些误差在 8 至 13mm 之间。

## 讨论

与先前的研究 [4] 一致，我们发现密集标记点集（尤其是躯干和骨盆区域）对于稳定的生物力学 IK 至关重要。具体而言，它将估计关节角度中的噪声降低了四分之三，极大地减少了极端关节角度越界情况，并提高了估计步态参数的准确性。MeTRAbs-ACAE [11] 能够利用多个数据集进行训练，并可以从单张图像中准确估计这些密集、受生物力学启发的标记点位置。我们的结果表明，该算法能够泛化至新的场景和图像。我们发现，MeTRAbs-ACAE 的几何一致性显著优于我们评估过的其他算法 [15]，这可能是因为相比于在 2D 图像手动标注上训练的算法，它在更多的 3D 数据上进行了训练。

相比之下，OpenCap [4] 在进行 IK 之前，利用基于先前采集的生物力学数据训练的算法，使用关键点增强器（keypoint augmenter）将稀疏标记点数据的时间序列映射为密集标记点轨迹。我们调研了使用 OpenCap [4] 的关键点增强器进行直接对比的可行性，但它并未针对我们所使用的稀疏关键点集（Halpe [28]）进行训练。我们预计，使用 MeTRAbs-ACAE 直接从图像中提取更多信息将比这种填补方法更准确，特别是对于那些运动模式未在关键点增强器训练数据中体现的受试者。

我们发现，使用隐式表示（implicit representation）来重建用于 IK 步骤的轨迹优于使用鲁棒三角测量（robust triangulation）。这使估计关节角度的噪声减半，同时也提高了结果的几何一致性。这令人欣慰，因为采用这种隐式表示的初衷之一就是为结合生物力学模型 [15] 的 IK 生成更好的轨迹。我们的基本逻辑是：在重建轨迹时考虑 HPE 的不确定性和几何结构，比尝试对带有噪声的轨迹进行后处理以用于 IK 更为有效。未来，这两个步骤可以结合起来，IK 方法也可以进一步扩展为直接在 HPE 输出上运行，在考虑其不确定性和几何结构的同时提供更精确的生物力学约束。像 nimblephysics 这样的可微物理引擎使这成为可能，尽管通过该引擎传播来自隐式表示的导数相当复杂。专为深度学习设计且直接在 GPU 上运行的可微物理模拟器（例如 Brax），可能为将 IK 与感知层更紧密地整合提供另一条途径。

优化模型的标记点位置以使其与 MOVI 标记点 [10] 更加一致，以及优化 nimblephysics [13] 中使用的 IK 超参数，对于生成稳定且准确的拟合结果同样十分重要。特别是，启用软关节限制（soft joint limits）避免了硬关节限制下出现的不稳定结果，以及在没有正则化时出现解剖学上不合理的结果。然而令人放心的是，我们发现结果对其他超参数并不十分敏感。

与原始轨迹相比，基于模型的标记点的几何一致性略有下降并不令人意外，因为基于模型的估计包含了更多的生物力学约束。然而，基于模型的 $G C _ { 5 }$ 超出了我们先前使用在 2D 数据集上训练的算法所观察到的数值 [15]。这表明用于 MeTRAbs-ACAE 的多数据集不仅能产生几何一致的关键点，还能产生保持其在骨骼上相对位置的生物力学一致的关键点。尽管每帧是独立处理的，仍然取得了这一结果。我们期望处理视频并将图像序列映射到关键点序列可以利用关于身体形态的信息，并进一步提高生物力学一致性。我们预计，将生物力学轨迹建模与在通过无标记动作捕捉获取的大型数据集上进行的自监督学习相结合，将是训练这些模型的一条富有成效的途径。

Sarandi 等人 [11] 所基于的 MeTRAbs 架构 [21] 可以从单张图像生成 2D 和 3D 关节位置。在这项工作中，除了用于估计 2D 关键点置信度之外，我们没有利用 3D 位置。这与从 2D 关键点“提升”（lift）到 3D 关键点的方法 [2] 形成对比。提升方法丢弃了大量可从图像中获取的信息，而这些信息被 [11] 保留了下来。未来的一个重要方向是比较来自类似算法的单目视频生物力学拟合的准确性和稳定性，或者寻找达到所需准确性所需的最小相机集合。我们将此留待未来的工作。

尽管 [11] 为生物力学提供了一组密集的标记点，但在手部却相当稀疏。这有时会导致手腕估计不稳定，并且无法估计手指的运动。我们已经看到使用 Halpe 关键点可以获得手部的精确 3D 重建 [15]。我们使用的生物力学模型不包含高关节自由度的手部，尽管它们作为单独的模型存在 [31]。未来，我们将融合这两种算法的 3D 关键点，并开发一个能够实现包括手部在内的全身生物力学跟踪的生物力学模型。

我们当前的方法存在一些局限性。其一是分析并非实时运行。我们也尚未结合动力学求解或纳入基于物理的约束，我们预计这将进一步提高结果的准确性。我们的超参数优化未经过交叉验证，但鉴于测试数量有限、对设置的鲁棒性以及参数的可解释性，我们预计这不会产生实质性影响。目前市面上也有商用的无标记动作捕捉系统（例如 [5]）。然而，由于该专有系统未被详细描述，我们无法直接比较我们的方法。

相比之下，我们的方法是基于公开可用的算法。

基于模型的标记点重建与检测到的关键点之间的定量一致性，以及我们对大量叠加视频审查后的定性印象均表明，我们的方法产生了精确的生物力学运动学结果。我们先前发现，这些轨迹在估计空间步态参数时的精度在 10mm 以内 [15]，并且我们在生物力学重建后获得了相近的精度。我们能够检测出行走条件之间的预期变化（例如佩戴支具或功能性电刺激），这进一步支持了该方法的灵敏度。我们期待后续研究能效仿其他无标记动作捕捉系统 [6] 的方法，通过考察无步态障碍人群运动学估计的会话间重复性（inter-session repeatability），来验证其准确性和可靠性。我们在本研究中并未尝试此项工作，因为许多参与者患有伴随步态变异性增加的步态障碍，这会掩盖实验结果。

总之，在多个数据集上训练的人体姿态估计（Human Pose Estimation, HPE）[11] 的进展为每幅图像提供了密集的标记点，这些标记点常用于基于标记的动作捕捉，且足以约束生物力学重建。对通过旨在实现平滑且解剖学一致的隐式表示（implicit representation）重建出的轨迹执行逆运动学（Inverse Kinematics, IK），可进一步提升重建结果。我们的采集硬件所采用的相机仅需以太网即可同时实现供电、数据传输和同步，便于在多个地点进行部署。我们当前在康复医院应用的无标记动作捕捉工作流，使获取运动的生物力学估计变得简便且可靠。我们希望这项技术的更广泛常规应用将有助于更好地对患者进行表型分析，监测他们对不同干预措施的反应，并最终指导更有效、更精准的康复干预。我们能够招募来自住院部和门诊部的受试者，并在通常少于 10 分钟的时间内完成包含多个试验和条件的步态分析。
