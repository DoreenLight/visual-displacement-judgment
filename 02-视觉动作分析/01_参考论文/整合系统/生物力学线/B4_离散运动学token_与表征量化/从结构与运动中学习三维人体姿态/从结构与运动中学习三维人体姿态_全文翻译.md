# 从结构与运动中学习三维人体姿态

Rishabh Dabral<sup>1</sup>, Anurag Mundhada<sup>1</sup>, Uday Kusupati<sup>1</sup>, Safeer Afaque<sup>1</sup>, Abhishek Sharma<sup>2</sup>, Arjun Jain<sup>1</sup>

<sup>1</sup>Indian Institute of Technology Bombay（印度理工学院孟买分校）, <sup>2</sup>Gobasco AI Labs {rdabral, safeer, ajain}@cse.iitb.ac.in, {anuragmundhada, kusupatiuday, abhisharayiya}@gmail.com

摘要。从单张图像进行三维人体姿态估计（3D human pose estimation）是一个极具挑战性的问题，尤其是在自然野外（in-the-wild）场景下，这主要是由于缺乏三维标注数据所致。我们提出了两种受人体解剖学启发的损失函数，并将其与 [41] 的弱监督学习框架相结合，联合利用大规模野外 2D 数据和室内/合成 3D 数据进行学习。我们还提出了一个简单的时序网络，利用预测姿态序列中存在的时序和结构线索在时间维度上协调姿态估计结果。我们通过损失曲面可视化和敏感性分析深入剖析了所提出的贡献，以便更深刻地理解其工作机制。我们的完整流程在 Human3.6M 和 MPI-INF-3DHP 数据集上分别将当前最优水平提升了 11.8% 和 12%，并且在消费级显卡上能以 30 FPS 的速度运行。

## 1 引言

从单目图像和视频中准确估计三维人体姿态，是开启机器人、人机交互、安防监控、动画制作和虚拟现实等领域诸多应用的关键。这些应用要求在服装、光照、视角、自身遮挡、动作活动、背景杂乱等具有挑战性的多变情况下，从单目图像或视频中实现准确且实时的 3D 姿态估计 [33,32]。随着深度学习、计算硬件的最新进展，以及最重要的大规模真实世界数据集（ImageNet [31]、MS COCO [20]、CityScapes [10] 等）的出现，计算机视觉系统的性能取得了显著提升。人体姿态估计同样受益于合成与真实世界数据集，例如 MS COCO [20]、MPII Pose [3]、Human3.6M [14,6]、MPI-INF-3DHP [22] 和 SURREAL [37]。尤其是 2D 姿态预测，得益于大规模野外数据集 [20,3]，取得了巨大的进步。然而，由于该问题具有严重的欠约束性，且缺乏真实世界的 3D 标注数据集，3D 姿态估计仍然极具挑战性。

大量现有技术要么直接回归 3D 关节点坐标 [17,18,34]，要么采用两阶段方法从 2D 关节点位置推断 3D 姿态 [22,24,19,43,41]。这些方法在合成 3D 基准数据集上表现良好，但由于缺乏带 3D 标注的野外（in-the-wild）数据集，其在真实世界场景中的泛化能力不足。为了缓解这一问题，一些方法采用了合成数据集 [9,37]、绿幕合成 [22,23]、域自适应 [9]、从中间 2D 姿态估计任务进行迁移学习 [22,17] 以及基于 2D 和 3D 数据的联合学习 [41,34]。值得注意的是，得益于大规模真实世界 2D 数据集，结合 2D 和 3D 数据的联合学习在野外场景中展现出了极具前景的性能。我们受到 Zhou 等人 [41] 最近发表的联合学习框架的启发，提出了一种新颖的结构感知损失函数，以促进利用 2D 和 3D 数据训练深度卷积神经网络（Deep ConvNet）架构，从而从单张 RGB 图像中准确预测 3D 姿态。所提出的损失函数在训练期间适用于 2D 图像，并确保预测的 3D 姿态不违反解剖学约束，即关节点角度限制和人体左右对称性。我们还提出了一种用于视频姿态估计的简单可学习时序姿态模型。最终系统在 Human3.6M 和 MPI-INF-3DHP 上的表现均优于已发表的最佳系统 12%，并且在通用 GPU 上以 30fps 的速度运行。

我们提出的结构感知损失灵感来源于支配人体结构和运动的解剖学约束。我们利用了某些身体关节点不能超出特定角度范围弯曲的事实；例如，膝（肘）关节不能向前（向后）弯曲。我们还利用了人体的左右对称性，并对左右骨骼长度不相等的对应骨骼对进行惩罚。最后，我们还采用了来自 [41] 的骨骼长度比例先验，该先验强制某些骨骼长度对保持恒定。需要说明的是，非法角度和左右对称性约束与骨骼长度比例先验是互补的，并且我们证明了它们的效果也更好。我们的贡献之一在于构建了一个损失函数，用于从推断出的 3D 姿态中捕捉关节点角度限制。我们展示了所提损失的损失曲面可视化，以便更深入地理解它们的作用机理。上述三种结构损失用于训练我们的 Structure-Aware PoseNet。关节点角度限制和左右对称性此前曾以优化函数的形式被使用 [1,13,4]。据我们所知，我们是首个以可微且易于处理的损失函数形式利用这两个约束来直接训练卷积神经网络（ConvNets）的团队。我们的结构感知损失函数在每关节平均位置误差（Mean-Per-Joint-Position-Error, MPJPE）方面，在 Human3.6M 和 MPI-INF-3DHP 上分别优于已发表的最先进技术 7% 和 2%。

我们进一步提出学习一个时间运动模型，以利用视频连续帧中的线索，从而获得符合解剖学结构且平滑变化的姿态，同时在不同动作间保持真实感。我们表明，一个输入前 $N$ 个姿态的滑动窗口全连接网络在从姿态序列中捕获时间以及解剖学线索方面表现得极为出色。借助精心设计的对照实验，我们展示了该模型所学习到的时间和解剖学线索，以便于更好地理解。在使用我们的时间模型后，我们在 Human3.6M 上取得了额外的 7% 提升，并展示了完整流水线在 30fps 下的实时性能。我们的最终模型在 Human3.6M [14] 和 MPI-INF-3DHP [22] 上分别将已发表的最优性能（state-of-the-art）提升了 11.8% 和 12%。

## 2 相关工作

本节从三个角度简要总结了与人体姿态估计相关的过往工作：(1) ConvNet（卷积神经网络）架构与训练策略，(2) 利用人体结构约束，以及 (3) 基于视频的 3D 姿态估计。有关详细的文献综述，读者可参阅 [32]。

ConvNet 架构：大多数现有的基于 ConvNet 的方法要么直接从输入图像回归 3D 姿态 [34,17,42,43]，要么在两阶段方法中从 2D 姿态推断 3D 姿态 [35,41,23,24,19]。一些方法利用了体积热图（volumetric-heatmaps）[27]，一些方法使用骨骼代替关节点来定义姿态 [34]，而 [23] 中的方法则直接回归 3D 位置图。2D 到 3D 流水线的使用使得利用大规模野外（in-the-wild）2D 姿态数据集 [3,20] 进行训练成为可能。少数方法使用统计先验 [43,1] 将 2D 姿态提升至 3D。Chen 等人 [7] 和 Yasin 等人 [40] 使用姿态库，在给定相应 2D 姿态预测的情况下检索最近的 3D 姿态。最近基于 ConvNet 的方法 [23,30,41,34,43,27] 通过对其 2D 预测模块进行预训练或联合训练，在真实世界场景中取得了显著改进，但这仍然是一个尚未解决的开放性问题。

利用结构信息：人体骨架的结构受到固定的骨骼长度、关节角度限制以及肢体互穿约束的制约。一些方法利用这些约束从2D关节位置推断3D姿态。Akhter和Black [1] 学习了与姿态相关的关节角度限制，以通过优化问题将2D姿态提升至3D。Ramakrishna等人 [28] 以活动相关（activity-dependent）的方式求解人体测量学约束。最近，Moreno [24] 提出使用简单的神经网络架构从2D关节间距离矩阵估计3D关节间距离矩阵。这些方法没有利用图像中存在的丰富视觉线索，而是依赖预测的2D姿态，从而导致次优的结果。Sun等人 [34] 对姿态表示进行了重新参数化，使用骨骼代替关节，并提出了一种结构感知损失（structure-aware loss）。但是，在缺乏3D真值（ground-truth）数据的情况下，他们并未显式地对推断出的3D姿态的可行性进行惩罚。Zhou等人 [41] 引入了一种弱监督框架，借助几何损失函数利用人体骨骼长度比例的一致性，对2D和3D数据进行联合训练。我们借助基于关节角度限制和左右对称性的损失函数进一步加强了这种弱监督设置，以实现更好的训练。最后，还有一些方法通过网格拟合（mesh-fitting）策略从2D图像中同时恢复体型（shape）和姿态。Bogo等人 [4] 在其用于求解基于SMPL [21] 的体型和姿态参数的目标函数中，对身体部位互穿和非法关节角度进行了惩罚。由于计算需求，这些方法本质上大多是离线运行的，而我们的方法运行速度可达30fps。

利用时序信息：从不连续的图像中直接估计 3D 姿态会导致时序上不连贯的输出，伴有明显的抖动和变化的骨骼长度。通过使用简单的滤波器或时序先验，可以改善视频中的 3D 姿态估计。Mehta 等人 [23] 提出了一种实时方法，该方法在使用 ConvNet 生成 3D 姿态候选后，在优化步骤中对加速度和深度速度施加惩罚。他们还使用针对交互系统优化的可调低通滤波器 [5] 来平滑输出姿态。Zhou 等人 [43] 在其时序优化步骤中引入了一阶平滑先验。Alldieck 等人 [2] 利用 2D 光流特征从视频中预测 3D 姿态。Wei 等人 [38] 利用基于物理的约束在视频关键帧之间真实地插值 3D 运动。此外，也有学者尝试学习运动模型。Urtasun 等人 [36] 使用线性模型学习特定活动的运动先验，而 Park 等人 [26] 则在给定一组 2D 姿态预测的情况下，使用运动库寻找最近邻运动，随后进行迭代微调。这些运动模型是特定于具体活动的，而我们的方法是通用的。最近，Lin 等人 [19] 使用循环神经网络（RNN）从其基于 ConvNet 架构的中间特征中学习时序依赖关系。在类似的尝试中，Coskun 等人 [11] 使用 LSTM 设计了一个用于学习人体运动模型的 Kalman filter。与上述方法相比，我们的时序模型简单却能有效地捕捉过去姿态的短期相互作用，并以在时序和解剖学上均一致的方式预测当前帧的姿态。该模型是通用的，无需针对特定活动环境进行训练。我们表明，它能够学习随时间变化的复杂、非线性的关节间依赖关系；例如，它学会了根据肘关节和肩关节过去的运动，来优化跟踪精度最低的手腕位置。

## 3 背景与记号

本节介绍本文中使用的符号记号，并提供关于 Zhou 等人 [41] 用于从 2D 和 3D 数据进行联合学习的弱监督框架的必要细节。

3D 人体姿态 $P = \{ p _ { 1 } , p _ { 2 } , . . . , p _ { k } \}$ 由欧几里得空间中 $k = 1 6$ 个身体关节点的位置所定义。这些关节点位置是相对于一个固定为骨盆的根关节点来定义的。姿态估计系统的输入可以是单张 RGB 图像或连续的 RGB 图像流 $I = \{ \dots , I _ { i - 1 } , I _ { i } \}$。第 $i$ 个关节点 $p _ { i }$ 是该关节在 3D 欧几里得空间中的坐标，即 $p _ { i } = ( p _ { i } ^ { x } , p _ { i } ^ { y } , p _ { i } ^ { z } )$。在整篇论文中，推断变量用 ˜∗ 表示，真实值用 ˆ∗ 表示，因此，推断出的关节点将记为 $\tilde { p }$，真实值记为 ${ \hat { p } } .$。2D 姿态可以仅用 x,y 坐标表示并记为 $\boldsymbol { p } ^ { x y } = \left( \boldsymbol { p } ^ { x } , \boldsymbol { p } ^ { y } \right)$ ）；仅包含深度的关节点位置记为 $p ^ { z } \ = \ ( p ^ { z } )$。来自 3D 标注数据集的第 $i$ 个训练数据由图像 $I _ { i }$ 以及对应的 3D 关节点位置 $\hat { P } _ { i }$ 组成。另一方面，2D 数据仅具有 2D 关节点位置 $\hat { P } _ { i } ^ { x y }$。有了这些符号表示后，我们在下文介绍来自 [41] 的用于联合学习的弱监督框架。

![](images/0df6f9436322ad3da2f6bebac03ed1f5bbc2101966c251156f0ab51868a22d5a.jpg)  
Fig. 1. 网络架构示意图。堆叠沙漏（stacked hourglass）模块使用针对真实热图的标准欧几里得损失 $\mathcal { L } _ { H M }$ 进行训练。而深度回归器模块则根据真实深度 ${ \hat { P } } ^ { z }$ 是否可用，在 $\mathcal { L } _ { 3 D } ^ { z }$ 或 $\mathcal { L } _ { 2 D } ^ { z }$ 上进行训练。

由于缺乏自然场景（in-the-wild）下的 3D 数据，使用受控或合成 3D 数据训练的姿态估计系统无法很好地泛化到自然场景设置中。因此，Zhou 等人 [41] 提出了一种弱监督框架，用于从 2D 和 3D 标注数据中进行联合学习。联合学习利用 3D 数据进行深度预测，并利用自然场景的 2D 数据以更好地泛化到真实世界场景。该框架的整体结构示意图如图 1（Fig. 1）所示。它基于用于 2D 姿态估计的堆叠沙漏网络架构（stacked hourglass architecture）[25]，并在其之上添加了一个深度回归子网络。堆叠沙漏网络通过在预测的关节点热图与真实关节点位置热图之间使用标准欧氏损失进行训练，以输出图像坐标系下的 2D 关节点位置 $\tilde { P } ^ { x y }$，更多细节请参见 [25]。深度回归子网络由一系列包含四个残差模块（residual modules）[12] 及随后的一个全连接层组成，它接收来自堆叠沙漏网络的不同特征图的组合，并输出每个关节点的深度，即 ${ \tilde { P } } ^ { z }$。对于具有 3D 标注的数据样本，使用标准欧氏损失 $\mathcal { L } _ { e } ( \tilde { P } ^ { z } , \hat { P } ^ { z } )$。另一方面，采用几何损失函数 $\bar { \mathcal { L } } _ { g } ( \tilde { P } ^ { z } , \hat { P } ^ { x y } )$ 形式的弱监督，来使用仅有 2D 标注的数据样本进行训练。几何损失充当正则化项，并惩罚违反骨骼长度比例先验一致性的姿态构型。请注意，在 $\mathcal { L } _ { g }$ 中使用了真实 xy 坐标 $\hat { P } ^ { x y }$ 与推断出的深度 ${ \tilde { P } } ^ { z }$，以简化训练。

几何损失作为联合训练的有效正则化项，提高了在受控和自然场景测试条件下的 3D 姿态估计精度，但它忽略了人体的某些其他强解剖学约束。在下一节中，我们在所讨论的弱监督框架的基础上，提出了一种新颖的结构感知损失（structure-aware loss），该损失能够捕获更丰富的解剖学约束，并提供比几何损失更强的弱监督正则化。

## 4 提出方法

本节介绍了两种新颖的解剖学损失函数，并展示了如何在弱监督设置下使用它们来利用 2D 标注数据样本进行训练。接下来，介绍了所提出损失函数的动机与推导，以及损失曲面的分析，以促进更深入的理解并突出与以往方法的差异。最后，提出了一个可学习的时序运动模型，并通过精心设计的受控实验对其进行了详细分析。

Fig. 2 展示了我们用于 3D 姿态估计的完整流程。它由以下部分组成：

1. Structure-Aware PoseNet（结构感知姿态网络）或 SAP-Net：一种基于单帧的 3D 姿态估计系统，输入单张 RGB 图像 $I _ { i }$ 并输出推断出的 3D 姿态 ${ \tilde { P } } _ { i }$。

2. Temporal PoseNet（时序姿态网络）或 TP-Net：一种学习得到的时序运动模型，能够接收推断出的 3D 姿态连续序列 $\{ \dots , \tilde { P } _ { i - 2 } , \tilde { P } _ { i - 1 } \}$ 并输出时序协调的 3D 姿态 $\bar { P } _ { i }$。

3. 骨骼拟合（Skeleton fitting）：可选步骤，如果受试者的实际骨骼信息也已知，我们可以执行一个保持骨骼向量方向的简单骨骼拟合步骤。

![](images/22c3ef697c9f98380a5df052d1364c4a2234052cebdf8096dc810dca31e89323.jpg)  
Fig. 2. 我们方法的总体流程：我们将视频帧按顺序输入到一个 ConvNet（卷积神经网络）中，该网络生成 3D 姿态输出（每次一个）。接下来，通过将过去 N 帧的上下文信息与当前帧一起输入到时序模型中，对预测结果进行时序细化。最后，根据应用需求，可选择性地执行骨骼拟合步骤。

## 4.1 Structure-Aware PoseNet 或 SAP-Net

SAP-Net 采用了 Fig. 2 所示的网络架构，该架构取自 [41]。正如第 3 节中所述，这种网络选择允许以弱监督方式联合利用 2D 和 3D 数据进行学习。带 3D 标注的数据样本提供了强监督信号，并引导推断的深度走向唯一解。另一方面，以解剖学约束形式存在的弱监督对无效解施加惩罚，从而缩小了解集空间。因此，约束集越强、越全面，解集就越小、越优。受到上述讨论的启发，我们建议在骨骼长度比例先验 [41] 的基础上，结合由关节角度限制和人体左右对称性推导出的损失函数来进行弱监督。这三项约束共同作用，比单纯依赖骨骼长度比例先验更加严格，从而能够生成更好的 3D 姿态配置。例如，在没有违背骨骼比例的情况下，骨骼长度比例先验会认为向后弯曲的手肘是有效的，但关节角度限制则会判定其无效。同样地，对称性损失消除了推断姿态中左右两侧不对称的配置。接下来，我们将针对所提出的约束描述并推导可微的损失函数。

非法角度损失 $( \pmb { \mathscr { L } _ { a } } )$：大多数身体关节被限制仅在特定的角度范围内运动。我们的非法角度损失 ${ \mathcal { L } } _ { a }$ 包含了针对膝关节和肘关节的这一约束，并限制它们弯曲超过 $1 8 0 ^ { \circ }$。对于给定的 2D 姿态 $P ^ { x y }$，存在多个可能的 3D 姿态，而 ${ \mathcal { L } } _ { a }$ 会惩罚违反膝关节或肘关节角度限制的 3D 姿态。为了利用此类约束，一些方法 [13,1,8] 使用不可微函数来推断姿态的合法性。遗憾的是，不可微性限制了它们在训练神经网络中的直接应用。其他方法则借助旋转矩阵或四元数来表示姿态以施加关节角度限制 [1,38]，从而具备可微性。然而，当采用对 ConvNets 而言更自然的关节位置来表示姿态时，施加这种约束并非易事。

![](images/22be947af7d1a3a8029ce65cbdbf038194e23409603326ff6c34a5fb38a5f407.jpg)  
Fig. 3. 非法角度损失示意图：为了使肘关节角度合法，前臂必须在 ${ \bf n _ { s } ^ { r } }$（锁骨-上臂平面的法向量）方向上投影出正分量，即 $\mathbf { n _ { s } ^ { r } } \cdot \mathbf { v _ { w e } } \geq 0$。请注意，使用这种公式表达，我们只需要 2D 标注数据即可训练我们的模型。

我们提出的用于非法角度发现的新颖公式，解决了基于 3D 关节点位置的姿态表示中区分关节内角和外角时的歧义问题。利用我们的公式并考虑到可微性要求，我们将 $\mathcal { L } _ { a }$ 构建为可直接使用的损失函数。我们借助 Fig. 3 展示我们的公式，并解释其在右肘关节处的推导过程。下标 n、s、e、w、k 分别表示颈部、肩部、肘部、手腕和膝部关节，上标 l 和 r 分别代表身体的左侧和右侧。我们将 $\mathbf { v _ { s n } ^ { r } } = P _ { s } ^ { r } - P _ { n } , \mathbf { v _ { e s } ^ { r } } = P _ { e } ^ { r } - P _ { s } ^ { r }$ 和 $\mathbf { v _ { w e } ^ { r } } = P _ { w } ^ { r } - P _ { e } ^ { r }$ 分别定义为锁骨、上臂和小臂（见 Fig. 3）。现在，$\bf { n } _ { s } ^ { r } = v _ { s n } ^ { r } \times v _ { e s } ^ { r }$ 是由锁骨和上臂所定义平面的法向量。为了使肘关节合法，${ \bf v _ { w e } ^ { r } }$ 在 $\mathbf { n _ { s } ^ { r } }$ 方向上必须具有正分量，即 $\mathbf { n } _ { \mathbf { s } } ^ { \mathbf { r } } \cdot \mathbf { v } _ { \mathbf { w e } } ^ { \mathbf { r } }$ 必须为正。当关节角度合法时，我们不施加任何惩罚，并将 $E _ { e } ^ { r } = \operatorname* { m i n } ( \mathbf { n } _ { \mathbf { s } } ^ { \mathbf { r } } \cdot \mathbf { v } _ { \mathbf { w e } } ^ { \mathbf { r } } , 0 )$ 定义为不合理性的度量。注意，对于右膝和左肘关节，情况正好相反（根据右手定则所示），在非法情况下要求 $E _ { k } ^ { r }$ 和 $E _ { e } ^ { l }$ 为正。我们对 $E$ 进行指数化处理，以强烈惩罚超出合法范围的大幅度偏差。$\mathcal { L } _ { a }$ 现在可以定义为：

$$
\mathcal {L} _ {a} = - E _ {e} ^ {r} e ^ {- E _ {e} ^ {r}} + E _ {e} ^ {l} e ^ {E _ {e} ^ {l}} + E _ {k} ^ {r} e ^ {E _ {k} ^ {r}} - E _ {k} ^ {l} e ^ {- E _ {k} ^ {l}}\tag{1}
$$

损失中的所有项都是骨骼向量的函数，而骨骼向量又根据推断出的姿态来定义。因此，$\mathcal { L } _ { a }$ 是可微的。更多细节请参阅补充材料。

对称性损失 $( \mathcal { L } _ { s } )$：它虽然简单，但能对关节深度施加强有力的约束，特别是当推断出的深度由于遮挡而存在歧义时。$\mathcal { L } _ { s }$ 被定义为左/右骨骼对之间的长度差异。设 $\mathcal{B}$ 为除躯干和头部骨骼外身体右半部分所有骨骼的集合。此外，令 $B L _ { b }$ 表示骨骼 $b$ 的骨骼长度。我们将 $\mathcal{L} _ { s }$ 定义为

$$
\mathcal {L} _ {s} = \sum_ {b \in \mathcal {B}} | | B L _ {b} - B L _ {C (b)} | | _ {2}\tag{2}
$$

其中 $C ( . )$ 表示对应的左侧骨骼。

最后，我们的结构感知损失 $\mathcal { L } _ { S A } ^ { z }$ 被定义为非法角度损失 $\mathcal { L } _ { a } ^ { z }$、对称性损失 $\mathcal { L } _ { s } ^ { z }$ 以及来自 [41] 的几何损失 $\mathcal { L } _ { g } ^ { z }$ 的加权和——

$$
\mathcal {L} _ {S A} ^ {z} (\tilde {P} ^ {z}, \hat {P} ^ {x y}) = \lambda_ {a} \mathcal {L} _ {a} (\tilde {P} ^ {z}, \hat {P} ^ {x y}) + \lambda_ {s} \mathcal {L} _ {s} (\tilde {P} ^ {z}, \hat {P} ^ {x y}) + \lambda_ {g} \mathcal {L} _ {g} (\tilde {P} ^ {z}, \hat {P} ^ {x y})\tag{3}
$$

损失曲面可视化：在此，我们借助局部损失曲面可视化来理解所提出的损失函数是如何将无效构型推向其对应的有效构型的。为了获得损失曲面，我们选取一个随机姿态 P，并在保持所有其他关节点位置固定的情况下，在 XZ 网格上改变左肘的 $( x _ { l e } , z _ { l e } )$ 坐标。接着，我们在 XZ 网格中的不同 $( x , z )$ 位置评估 $\mathcal { L } _ { S A } ^ { z }$ 以计算损失，并将其绘制为 Fig. 4 中的曲面。我们绘制了仅包含 2D 位置损失、2D 位置+对称性损失、2D 位置+对称性+非法角度损失以及基于 3D 标注的欧几里得损失的损失曲面，以展示损失曲面在不同解剖学约束下的演变过程。从图中可以清楚地看出，对称性损失和非法角度损失都重塑了损失曲面，从而有助于远离非法的关节点构型。

## 4.2 时序姿态网络或 TP-Net（Temporal PoseNet or TP-Net）

我们建议使用一个简单的两层、4096 个隐藏神经元、带有 ReLU 非线性激活的全连接网络，该网络以固定数量 N = 20 的相邻姿态作为输入，并输出所需的姿态 $\bar { P }$。相邻姿态向量被简单地展平并拼接，以形成输入到 TP-Net 的单个向量，并使用来自真实姿态的标准 $L _ { 2 }$ 损失进行训练。尽管本质上极其简单，但我们表明其性能优于像 RNN 这样更复杂的变体，见 Table 4。原因何在？我们认为这是因为复杂的人体运动随着时间窗口的增加可能产生越来越多的变化，这或许使得来自过远时间段的额外信息变得无用，或者至少难以利用。因此，具有有限上下文的密集网络可以有效地捕获有用的时序一致性和运动线索。

为了可视化 TP-Net 所利用的时间与结构信息，我们进行了一项简单的敏感性分析：随机扰动距离 TP-Net 输出 P<sup>¯</sup> 有 t 个时间步的 $P _ { t }$ 的关节位置，并在 Fig. 5(a) 中绘制了所有关节在时间步 t = −1 到 $t = - 1 9$ 上的敏感性。我们可以观察到，超过 5 个时间步（或 200ms 时间窗口）的姿态对预测姿态的影响并不大。类似地，Fig. 5(b) 展示了模型仅在当前帧内学到的结构相关性。TP-Net 学会了依赖髋部和肩部的位置来精细化调整几乎所有其他关节。我们还可以观察到子关节与父关节之间存在相关性，例如手腕与肘部强相关，肩部与颈部强相关。Fig. 5(c) 展示了对 t = -1 处输入姿态的敏感性。在此处，从过去学到的相关性较弱，但展现出更丰富的模式。子关节的敏感性在运动链（kinematic chain）中进一步向上传播，例如在 t = -1 帧中，手腕与肘部、肩部和颈部表现出更高的相关性。因此，我们可以得出结论：尽管 TP-Net 本质上非常简单，但它能够学习到复杂的结构和运动线索。我们希望这一发现对该方向未来的研究有所裨益。

由于 TP-Net 将固定数量的相邻姿态作为输入，我们可以选择获取目标姿态之前的所有相邻姿态，这被称为在线设置（online setting）；或者我们也可以选择在目标姿态的两侧各取 $N / 2 = 1 0$ 个相邻姿态，这被称为半在线设置（semi-online setting）。由于我们的整个流程以 30fps 运行，即便是半在线设置也仅会产生 10 帧的延迟。从 Fig. 5 中我们观察到，TP-Net 能够学习随时间变化的复杂非线性关节间依赖关系——例如，它能够根据肘关节和肩关节过去的运动，来精细化调整跟踪精度最低的手腕位置。

## 4.3 训练与实现细节

在训练 SAP-Net 时，来自 MPII2D 的 2D 样本与来自任一 3D 数据集的 3D 样本在每次迭代中按相等比例使用，小批量（minibatch）大小为 6。在第一阶段，我们按照 [25] 的方法，使用 SGD 在 MPII 和 Human3.6 上对 SAP-Net 的沙漏（hourglass）模块进行预训练，从而获得一个强大的 2D 姿态估计网络。由于使用弱监督损失进行训练需要热启动（warm start）[44]，因此在第二阶段，我们仅使用带有 3D 标注的数据样本对 3D 深度模块进行 240k 次迭代训练，以便在开启弱监督之前使其学会输出合理的姿态。在第三阶段，我们在学习率为 $2 . 5 e - 4$、$\lambda _ { a } = 0 . 0 3 , \lambda _ { g } = 0 . 0 3$ 的条件下，使用 $\mathcal { L } _ { g }$ 和 ${ \mathcal { L } } _ { a }$ 训练 SAP-Net 达 160k 次迭代。最后，在第四阶段，我们引入对称性损失 $\mathcal { L } _ { f }$，其中 $\lambda _ { s } = 0 . 0 5$，学习率为 $2 . 5 e \mathrm { ~ - ~ } 5$。

TP-Net 使用 Adam 优化器 [16] 训练了 30 个周期（epochs），输入为完全训练好的 SAP-Net 生成的姿态预测。在我们的实验中，我们发现上下文为 $N = 2 0$ 帧时在 MPJPE 上取得的提升最大（Fig. 5），我们在所有实验中均采用该设置。使用单张 NVIDIA 1080 Ti GPU，训练 SAP-Net 大约需要两天，训练 TP-Net 需要一小时。SAP-Net 每张图像的平均测试时间为 20ms，而 TP-Net 带来的延迟几乎可以忽略不计（<1ms）。

## 5 实验

在本节中，我们将展示消融实验、在 Human3.6M 和 MPI-INF-3DHP 数据集上的定量结果以及与先前现有技术的对比，并在 MPII 2D 和 MS COCO 数据集上展示定性结果。我们首先介绍实验中使用的数据集。

Human3.6M 包含 11 名受试者执行不同的室内动作，其真值标注是通过基于标记的动作捕捉（MoCap）系统采集的。我们遵循 [35] 的方法，在以下两种协议下评估我们的结果：1）协议 1（Protocol 1），使用关于根关节点相对姿态的每关节平均位置误差（Mean Per Joint Position Error，MPJPE）作为评估指标；2）协议 2（Protocol 2），使用普氏对齐 MPJPE（Procrustes Aligned MPJPE，PAMPJPE），即对预测姿态与真实值进行刚性对齐后计算得到的 MPJPE。

MPI-INF-3DHP（测试）数据集是最新发布的数据集，包含处于不同室内环境（绿幕和普通背景）下的 6 名测试受试者，以及 2 名在自然室外环境（in-the-wild）下表演的受试者，这使其比仅有单一室内环境的 Human3.6M 更加具有挑战性。我们遵循 [22] 中提出的评估指标，报告 150mm 范围内的正确关键点百分比（Percentage of Correct Keypoints，PCK）和曲线下面积（Area Under Curve，AUC）。与 [41] 类似，我们假设全局尺度是已知的，并在训练过程中进行骨架重定向（skeleton retargeting），以解决 Human3.6M 和 MPI-INF-3DHP 数据集之间关节点定义的差异。最后，骨架拟合（skeleton fitting）作为一个可选步骤，用于将姿态拟合到已知骨骼长度的骨架中。

## 6 结论

我们提出了两种受解剖学启发的损失函数，即非法角度损失（illegal-angle loss）和对称性损失（symmetry loss）。我们证明了它们在弱监督 ConvNet 架构训练中非常有效，可用于在自然（in-the-wild）场景下从单张 RGB 图像预测有效的 3D 姿态构型。我们分析了局部损失曲面的演变，清晰地展示了所提出损失函数的优势。我们还提出了一种简单却出奇有效的滑动窗口全连接网络，用于从相邻姿态序列中进行时序姿态建模。我们证明了它能够学习具有语义意义的短期时间与结构相关性。实验表明，该时序模型在每次推理耗时 < 1ms 的同时，显著减少了视频序列姿态预测中的抖动和噪声。我们的完整流程在 NVIDIA Titan 1080Ti GPU 上以 30fps 运行时，在 Human3.6M 和 MPI-INF-3DHP 数据集上分别将已发表的最优性能（state-of-the-art）提升了 11.8% 和 12%。
