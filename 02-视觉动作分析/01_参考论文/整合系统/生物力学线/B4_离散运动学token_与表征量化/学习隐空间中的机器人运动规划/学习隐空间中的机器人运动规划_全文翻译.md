# 学习隐空间中的机器人运动规划

Brian Ichter and Marco Pavone

摘要—本快报提出了隐空间基于采样的运动规划（latent sampling-based motion planning, L-SBMP），这是一种通过学习可规划的隐空间表示来为复杂机器人系统计算运动规划的方法。近期在机器人系统控制领域的研究已有效利用了高维动力学的局部低维嵌入。在本文中，我们将这些最新进展与基于采样的运动规划（sampling-based motion planning, SBMP）技术相结合，旨在设计一种能够为超出传统方法处理能力的高维机器人系统（例如仿人机器人，甚至是直接在视觉空间中进行规划的系统）进行规划的方法。具体而言，所学习的隐空间由自编码网络、动力学网络和碰撞检测网络构建而成，它们分别对应了 SBMP 的三个主要算法基元，即状态采样、局部导引和碰撞检测。值得注意的是，这些网络仅需通过系统状态和动作的原始数据以及一个监督碰撞检测器即可完成训练。基于这些网络，使用一种基于 RRT 的算法直接在隐空间中规划运动——我们将此探索算法称为学习隐空间 RRT（learned latent RRT）。该算法在全局范围内探索隐空间，并能够泛化到新环境中。整个方法在两个规划问题上得到了验证，即在视觉（像素）空间中进行规划的视觉规划问题，以及仿人机器人规划问题。

索引词—运动与路径规划，机器人与自动化中的深度学习。

## I. 引言

运动规划是机器人学中的一个基本问题，其目标是寻找一条连接初始状态与目标区域且避开障碍物的轨迹。随着系统维度的增加和动力学复杂性的提高，该问题的难度迅速上升 [1]。对于某些高维系统，甚至是具有微分约束的系统，基于采样的运动规划（SBMP）技术已成为一种特别有效的方法。SBMP 避免了显式构建状态空间，而是通过三个算法基元来维护其隐式表示：对状态空间进行采样、导引（或连接）到附近的采样状态，以及对这些连接进行碰撞检测 [1], [2]。这种隐式表示是全局的，并且随着样本的增加而越来越精确。然而，对于具有极高维状态或足够复杂动力学的机器人系统，SBMP 可能会变得难以处理 [1]。这就阻碍了其直接应用于例如从视觉输入计算规划 [3], [4]，或者动力学维度极高且复杂的仿人机器人系统 [5] 等情况。

近期基于学习的控制方面的工作为解决这一挑战提供了一种极具前景的解决方案，这些工作利用了嵌入在状态空间内的习得低维流形，而机器人系统的动力学主要受限于这些流形 [3], [6]–[8]。例如，双足仿人行走机器人通常处于步态和直立状态，而机器人的视觉表征具有“真实的”底层低维动力学表征。然而，这些工作主要仅关注局部区域，不能直接用于计算需要对状态空间进行全局探索的运动规划。我们将这些技术扩展到机器人运动规划的核心见解在于，利用低维隐空间表征（latent representations）的局部有效性来学习一个可以直接使用基于采样的运动规划（Sampling-based Motion Planning, SBMP）的隐空间（latent space）。换言之，该思想是通过仅使用局部连接来构建隐空间的全局隐式表征。该隐空间通过自编码网络、动力学网络和碰撞检测网络构建，分别对应了前述 SBMP 的三个算法原语，即状态采样、局部转向和碰撞检测。具体而言，该空间通过具有习得隐式动力学的自编码网络进行学习，从而提供了对隐空间进行采样并通过动力学可行轨迹连接局部状态的能力。值得注意的是，该网络仅需要系统状态和控制输入的原始数据即可进行训练。另外，碰撞检测网络经过训练，能够在给定特定问题环境的情况下高效预测两个隐状态之间的轨迹是否无碰撞。总的来说，这些网络提供了一种在隐空间中进行全局搜索的方法（在我们的方案中，通过基于 RRT 的算法），该方法能很好地泛化到新环境，并具有足够的通用性以适用于广泛的问题类别，包括视觉规划和复杂动力学问题。随后，最终轨迹可以通过自编码网络投影到全状态空间，并与上述局部控制方法结合使用，以沿着规划轨迹有效地控制机器人系统。我们将其称为隐式基于采样的运动规划（Latent Sampling-based Motion Planning, L-SBMP）。

相关工作：表征学习（representation learning）领域旨在学习数据表征，以便为分类器或其他预测器提取有用信息 [9]–[11]。这通常采取流形学习的形式，即学习嵌入在高维数据中的低维流形。表征学习已应用于整个机器人技术栈——从感知 [12]，到决策与规划 [13], [14]，再到控制与动力学 [3], [6], [7], [15]。最近，这些方法在控制领域取得了特别显著的成功。Embed to

Control [3] 与 Robust Locally-Linear Controllable Embeddings（鲁棒局部线性可控嵌入）[6] 提出了直接从原始图像中学习控制机器人系统的方法。这两种方法都通过变分自编码器（variational autoencoder）学习局部线性嵌入，并直接在隐空间（latent space）上执行随机最优控制。[4] 学习预测视觉空间中动作的结果，并利用模型预测控制（model-predictive control）来规划局部的机械臂动作。相比之下，本快报学习非线性隐动力学（使其能够泛化到更复杂的系统）以及碰撞检测网络（使其能够泛化到新环境）。

在机器人运动规划的背景下，Universal Planning Networks（通用规划网络，UPN）[8] 学习了一种可规划的隐表示，在此表示中可以通过梯度下降计算出最小化模仿损失（从专家规划器中学习）的规划方案。我们的方法 L-SBMP 学习了一个与 UPN 相似的隐空间（通过在隐空间中施加动力学约束），但在隐空间中执行全局搜索以寻找运动规划。此外，L-SBMP 不依赖专家规划器，而在许多问题中专家规划器往往是不可用的。[16] 使用高斯过程隐变量模型来学习低维表示，随后通过基于粒子的方法利用推理来解决规划问题。与 L-SBMP 相比，该隐变量模型必须经过良好初始化，且使用推理无法对隐空间进行全局搜索。Motion Planning Networks（运动规划网络，MPNet）[17] 学习障碍物空间的低维表示，并在给定初始状态、目标状态和障碍物表示的情况下，使用前馈神经网络预测最优规划器将采取的下一步动作（通过渐近最优规划器训练）。MPNet 旨在加速解决那些可以通过示范提供类似问题解的规划问题，而本快报则尝试解决以往难以处理的规划问题。最后，在基于采样的规划中，学习已被用于替代算法栈的某些部分，例如碰撞检测器 [18] 或采样分布 [19]。L-SBMP 同样学习了一个碰撞检测网络（尽管是直接在隐空间中），并且在某种程度上，通过直接从编码的训练状态中为探索算法选取样本，学习了在何处进行采样。

值得注意的是，在实践中，L-SBMP 方法可以且应当与上述许多方法相结合。在许多情况下，L-SBMP 可以作为 [3]、[6]、[8] 中隐空间的初始化。此外，这些方法可用于改进 L-SBMP 生成的轨迹，并沿着该轨迹进行控制。

贡献陈述：本快报（Letter）的贡献包含三个方面。首先，我们提出了隐空间基于采样的运动规划（Latent Sampling-based Motion Planning，L-SBMP）方法，该方法由自编码网络、动力学网络和碰撞检测网络组成，以实现在隐空间中进行规划。这些网络仅通过系统状态和控制输入的原始数据以及起监督作用的碰撞检测器即可完成训练。其次，在 L-SBMP 的基础上，我们提出了一种基于 RRT 的算法，称为学习隐空间快速探索随机树（Learned Latent Rapidly-exploring Random Trees，L2RRT），用于直接在隐空间中规划运动。L2RRT 通过维护该空间的隐式表示来高效且全局地探索学习到的流形，该表示是通过对编码状态进行采样并在树中动态传播邻近轨迹（在碰撞检测网络的监督下）形成的。最终的隐空间轨迹随后通过自编码网络投影回全状态空间。第三，我们在两个远超出标准 SBMP 能力范围的规划问题上验证了我们的方法，即在视觉（像素）空间中进行规划的视觉规划问题，以及仿人机器人规划问题。

## II. 问题陈述

在本节中，我们对所要解决的运动规划问题进行公式化描述。随后，我们简要回顾基于采样的运动规划算法，以提供必要的背景并阐明我们方法的动机。最后，我们提出了学习可规划隐空间的问题。

## A. 机器人运动规划问题

令 $\mathcal { X } \subseteq \mathbb { R } ^ { d _ { x } }$ 和 $\mathcal { U } \subseteq \mathbb { R } ^ { d _ { u } }$ 分别表示机器人系统的状态空间和控制输入空间。机器人的动力学定义为

$$
\dot {\mathbf {x}} (\tau) = f _ {\chi} ^ {(c)} (\mathbf {x} (\tau), \mathbf {u} (\tau)),\tag{1}
$$

其中 $\mathbf { x } ( \tau ) \in \mathcal { X }$ 和 $\mathbf { u } ( \tau ) \in \mathcal { U }$ 分别表示系统在时间 $\tau$ 时的状态和控制输入，$f _ { \chi } ^ { \mathrm { ( c ) } }$ 表示连续时间系统动力学。为了使动力学学习问题易于处理，我们考虑离散时间形式。然而需要注意的是，我们仍然考虑连续时间底层动力学来确定碰撞。机器人的离散时间动力学定义为

$$
\mathbf {x} _ {t + 1} = f _ {\mathcal {X}} (\mathbf {x} _ {t}, \mathbf {u} _ {t}),\tag{2}
$$

其中 $\mathbf { x } _ { t } \in \mathcal { X }$ 和 $\mathbf { u } _ { t } \in \mathcal { U }$ 分别表示系统在时间步 $t$ 时的状态和控制输入，$f _ { \mathcal { X } }$ 表示离散时间系统动力学。

设 $\mathcal { X } _ { \mathrm { f r e e } } \subseteq \mathcal { X }$ 定义机器人的无碰撞状态空间（free state space），且设 ${ \mathcal { X } } _ { \mathrm { o b s } } \subset { \mathcal { X } }$ 定义障碍物空间，使得 ${ \mathcal { X } } _ { \mathrm { f r e e } } = { \mathcal { X } } \setminus { \mathcal { X } } _ { \mathrm { o b s } } .$ 给定一个初始状态 $\mathbf { x } _ { \mathrm { i n i t } } \in \mathcal { X } _ { \mathrm { f r e e } }$ 和目标区域 $\chi _ { \mathrm { g o a l } } \subset \mathcal { X } _ { \mathrm { f r e e } \cdot } ^ { - } \mathrm { A }$ 机器人的轨迹 $\pi$ 被定义为一系列状态和控制输入 $\left( \mathbf { x } _ { 0 } , \mathbf { u } _ { 0 } , \ldots , \mathbf { x } _ { T } , \mathbf { u } _ { T } \right)$，其中 $T$ 为轨迹中的时间步数。此外，设 $\overline { { \mathbf { x } _ { 0 } , \ldots , \mathbf { x } _ { T } } }$ 表示机器人轨迹所描绘的连续曲线（连接 $\mathbf { x } _ { 0 } , \ldots , \mathbf { x } _ { T } )$。我们在此做出这一区分，是为了明确碰撞检测应当沿着连接离散状态的连续轨迹进行。若满足 $\begin{array} { r } { \overline { { \mathbf { x } _ { 0 } , \ldots , \mathbf { x } _ { T } } } \cap \mathcal { X } _ { \mathrm { o b s } } = \emptyset . } \end{array}$，则称该轨迹是无碰撞的。如果一条轨迹连接了初始状态和目标区域，即 ${ \bf x } _ { 0 } = { \bf x } _ { \mathrm { i n i t } }$ 且 ${ \bf x } _ { T } \in \mathcal { X } _ { \mathrm { g o a l } } ,$，且是无碰撞的，并且满足动力学可行性，即对 $t = 1 , \dots , T$ 均有 $\mathrm { i . e . , } \mathbf { x } _ { t } = f _ { \mathcal { X } } ( \mathbf { \bar { x } } _ { t - 1 } , \mathbf { u } _ { t - 1 } )$，则称该轨迹是可行的。在本文中，我们关注以下问题：

问题 1（运动规划问题）：给定一个运动规划问题 $( \mathbf { x } _ { \mathrm { i n i t } } , { \mathcal { X } } _ { \mathrm { g o a l } } , { \mathcal { X } } _ { \mathrm { f r e e } } )$，寻找一条可行轨迹 $\pi$。如果不存在此类轨迹，则报告失败。

## B. 基于采样的运动规划

基于采样的运动规划（Sampling-Based Motion Planning, SBMP）已成为解决复杂运动规划问题的一种极为有效的算法范式。SBMP 避免了对状态空间的显式构建，而是维护一个隐式的、可搜索的表示。该表示由一组探测样本构成，这些样本在局部连接并通过一个“黑盒”碰撞检测模块进行验证 [1]。这种方法实现了全局搜索，并保证了概率完备性以及通常的渐近最优性 [20], [21]。

一类特别成功的基于采样的运动规划（sampling-based motion planning，SBMP）算法是快速探索随机树（rapidly-exploring random tree，RRT）[2]。鉴于我们的探索算法是基于此构建的，我们现在对 RRT 进行概述，以明确各个算法原语（algorithmic primitive）。该算法首先以初始状态 $\mathbf { x } _ { \mathrm { i n i t } } .$ 初始化一棵树 $\tau$，随后通过状态空间迭代构建该树。在每次迭代中，在自由状态空间中采样一个状态，$\mathbf { x } _ { \mathrm { s a m p l e } } \in \mathcal { X } _ { \mathrm { f r e e } }$。树中距离 $\mathbf { x } _ { \mathrm { s a m p l e } }$ 最近的节点被选为扩展节点 $\mathbf { x } _ { \mathrm { e x p a n d } }$。然后朝向 $\mathbf { x } _ { \mathrm { s a m p l e } }$ 扩展该节点，形成一个新的样本 $\mathbf { x } _ { \mathrm { n e w } } .$。如果连接 x<sub>expand</sub> 与 $\mathbf { x } _ { \mathrm { n e w } }$ 的轨迹不与 ${ \mathcal { X } } _ { \mathrm { o b s } } .$ 相交（即无碰撞），则将 $\mathbf { x } _ { \mathrm { n e w } }$ 作为一个节点添加到树中。这一过程持续进行，直到耗尽设定时间或达到预定的采样数量。该方法仅通过三个算法原语就能够全局搜索状态空间：(1) 采样，(2) 局部连接，以及 (3) 碰撞检测。本快报（letter）的核心思想是，通过确保这些算法原语中的每一个都能应用于代表机器人系统的已学习低维潜空间（latent space），我们可以直接使用 SBMP 来计算针对全状态空间的规划。

## C. 可规划潜空间

我们在本文中考虑的机器人系统可能具有复杂的动力学特性和高维状态空间。例如，它们可能是机器人和环境的像素表征，也可能是高动态、高维的机器人。在这些情况下，解决运动规划问题的标准方法在计算上是难以处理的。即使是最初针对高维系统设计的 SBMP 等方法，对于维度足够高或动力学极其复杂的机器人来说，也可能会变得难以处理 [1]。

我们的目标是通过学习一个低维隐空间（latent space）模型来寻找该问题的潜在流形，并在该隐空间中执行基于采样的运动规划（Sampling-Based Motion Planning, SBMP）。由于系统的复杂性，该空间应仅通过机器人运行中的状态与控制输入序列以及一个单独的局部碰撞检测器来进行学习。收集这些数据应完全覆盖机器人的运行工况，因为所学习的隐空间以及随后的运动规划均受限于训练数据附近的区域。令 $\mathcal { Z } \subseteq \mathbb { R } ^ { d _ { z } }$ 表示学习到的隐空间，$\mathbf { z } _ { t } \in \mathcal { Z }$ 表示时间步 t 处的隐状态。我们旨在学习一个从 X 到 $\mathcal { Z }$ 的映射 m 和一个从 $\mathcal { Z }$ 到 X 的映射 n，并在 $\mathcal { Z }$ 上施加隐动力学 $f _ { \mathcal { Z } }$。我们进一步在隐空间中学习一个“黑盒”碰撞检测函数 g。因此，我们希望学习以下内容：

$$
\begin{array}{l}m: \mathcal {X} \rightarrow \mathcal {Z}, \quad n: \mathcal {Z} \rightarrow \mathcal {X}, \quad \mathbf {z} _ {t + 1} = f _ {\mathcal {Z}} (\mathbf {z} _ {t}, \mathbf {u} _ {t}),\\g (\mathbf {z} _ {t}, \mathbf {z} _ {t + 1}, \mathcal {X} _ {\mathrm{obs}}) = \{1 \text {   if   } \overline {{\mathbf {x} _ {t} , \mathbf {x} _ {t + 1}}} \cap \mathcal {X} _ {\mathrm{obs}} = \emptyset , 0 \text {   otherwise } \}.\end{array}\tag {3}
$$

## III. 学习用于机器人运动规划的隐空间

为了在低维隐空间模型上进行规划，需要具备以下性质：(1) 隐空间可以被采样，(2) 动力学是已知的，以便连接相邻的隐状态，以及 (3) 局部隐轨迹可以被分类为无碰撞。此外，还希望在找到解后能够将隐样本映射回全空间，以便机器人系统能够执行该运动规划。最后，我们不假设能够获取真实的系统动力学 $f _ { \mathcal { X } } ,$，即仅能获取随时间变化的状态与动作观测值以及碰撞检测结果。

隐空间基于采样的运动规划（Latent Sampling-based Motion Planning, L-SBMP）架构（Fig. 1）由三个网络组成：(1) 自编码器，(2) 隐空间局部动力学模型，以及 (3) 碰撞分类器。自编码器将高维全状态 $\left( \mathbf { x } _ { t } \right)$ 投影到较低维度的隐状态 $\left( \mathbf { z } _ { t } \right)$，并允许解码以形成后续控制器的输入。动力学模型在编码后的隐空间上施加局部动力学约束，并允许动力学进行传播。最后，碰撞分类器识别在给定问题环境下两个相邻隐状态之间的连接是否可行。隐空间是通过运行中的机器人系统的一系列轨迹进行训练的；即一系列状态 $\mathbf { x } _ { t }$ 和动作 $\mathbf { u } _ { t }$。碰撞检测网络则是通过相邻状态的数据集以及表示连接轨迹是否发生碰撞的标签来进行训练的。

## A. 学习隐空间与动力学

我们架构中的第一个网络遵循自编码器的标准处理方法。给定状态为 $\mathbf { x } _ { t }$ 且隐状态为 $\mathbf { z } _ { t }$ 的机器人系统，我们定义编码网络 $h _ { \phi } ^ { \mathrm { e n c } } ( \mathbf { x } _ { t } )$ 和解码网络 $h _ { \theta } ^ { \mathrm { d e c } } ( \mathbf { z } _ { t } )$，其参数分别为 $\phi$ 和 $\theta$。这些网络将全状态投影到低维隐空间中，随后重构全状态。根据机器人系统的不同，此类网络可以是卷积网络或全连接网络。在本快报中，我们使用 $\ell _ { 2 }$ 重构损失。

我们架构中的第二个网络在隐空间中学习并随后施加局部动力学。设 $h _ { \psi } ^ { \mathrm { d y n } } ( \mathbf { z } _ { t } , \mathbf { u } _ { t } )$ 表示动力学网络，$\psi$ 为其参数。该网络预测隐空间中的下一个状态 $\hat { \mathbf { z } } _ { t + 1 }$。该预测的准确性通过两个损失来保证。首先，对预测值进行解码 $h _ { \theta } ^ { \mathrm { d e c } } ( \hat { \mathbf { z } } _ { t + 1 } )$，并利用 $\ell _ { 2 }$ 重构损失将其与全状态 $\mathbf { x } _ { t + 1 }$ 进行比较。其次，在隐空间中将预测值与下一个编码状态 ${ \bf z } _ { t + 1 } = h _ { \phi } ^ { \mathrm { e n c } } ( { \bf x } _ { t + 1 } )$ 进行比较。为了使这第二个损失具备动力学一致性，我们在 $\mathbf { z } _ { t }$ 和 $\mathbf { u } _ { t }$ 附近对动力学进行线性化，并计算加权可控性格拉姆矩阵 $G _ { t }$（weighted controllability Gramian，也称为可达性格拉姆矩阵 / reachability Gramian）为

$$
A _ {t} = \frac {\partial h _ {\psi} ^ {\mathrm{dyn}}}{\partial \mathbf {z}} (\mathbf {z} _ {t}, \mathbf {u} _ {t}), B _ {t} = \frac {\partial h _ {\psi} ^ {\mathrm{dyn}}}{\partial \mathbf {u}} (\mathbf {z} _ {t}, \mathbf {u} _ {t}), G _ {t} = A _ {t} B _ {t} B _ {t} ^ {\top} A _ {t} ^ {\top}. \tag {4}\tag{4}
$$

然后，将损失计算为预测值与真实下一隐状态之间的最小能量，即 $\mathcal { L } _ { t } ^ { \mathrm { d y n } } = ( \mathbf { z } _ { t + 1 } -$ $\hat { \mathbf { z } } _ { t + 1 } \big ) ^ { \top } G _ { t } ^ { - 1 } \big ( \mathbf { z } _ { t + 1 } - \hat { \mathbf { z } } _ { t + 1 } \big )$。从本质上讲，这确保了预测损失能够体现系统的动力学特性，例如（$\mathrm { e . g . }$），对于汽车而言，前后方向上的隐状态预测偏差相比左右方向上的偏差次要。然而需要注意的是，在动力学网络训练之初，公式 (4) 中的加权可控性格拉姆矩阵（controllability Gramian）可能是病态的。因此，我们从 $\ell _ { 2 }$ 范数开始，逐渐过渡到 $G _ { t } ^ { - 1 }$ 范数。我们还在 $G _ { t }$ 的对角线上添加了一个较小的正项，以确保其可逆性。

随后，通过一个组合损失函数将编码器、解码器和动力学网络一起进行训练，该损失函数计算为 $\mathcal { L } _ { t } ^ { \mathrm { d y n } }$ 与 $\mathbf { x } _ { t }$ 和 $\mathbf { x } _ { t + 1 }$ 的 $\ell _ { 2 }$ 重建误差之和。

## B. 学习碰撞检测器

我们架构中的第三个网络用于学习识别两个隐状态之间的连续轨迹是否会发生碰撞；我们将该网络表示为 $h _ { \zeta } ^ { \mathrm { c c } } ( \mathbf { z } _ { t } , \mathbf { z } _ { t + 1 } , \mathcal { X } _ { \mathrm { o b s } } )$，由 $\zeta$ 参数化。这是一个包含二分类的监督学习过程；这意味着，我们假设在全状态空间中拥有一个能够报告轨迹是否发生碰撞的碰撞检测器——可以说，这是一个非常温和的假设。在编码器和动力学学习完成之后，碰撞检测网络会被单独进行训练。该网络能够泛化到新环境中，允许在无需获取真实状态和障碍物的情况下进行碰撞检测，并能高效地识别碰撞。

我们在本处指出，我们将 $\mathcal { X } _ { \mathrm { o b s } }$ 用作网络的输入。在基于采样的运动规划（SBMP）中，$\mathcal { X } _ { \mathrm { o b s } }$ 通常仅通过碰撞检测器进行隐式定义。我们在此使用它来表示状态空间碰撞检测器可获取的任何环境信息。这种表示可以非常通用，因为神经网络架构有能力根据需要任意投影这些信息。理想的表示形式应当紧凑并包含完整的障碍物信息；例如，这可以是障碍物的工作空间坐标、占用网格（occupancy grid）或问题的图像。我们注意到，尽管本快报考虑的是由两个状态之间不可行的连接导致的碰撞，但该网络也可以训练用于识别机器人在单个时间步何时与障碍物发生接触，这类数据可能更容易收集。通过识别依赖于环境且在状态空间中极少或从未连接的区域，也有可能通过无监督学习来训练该网络。我们将此留待未来的工作中研究。

## IV. PLANNING IN THE LATENT SPACE

我们现在介绍学习隐空间快速探索随机树（Learned Latent Rapidly-exploring Random Trees, L2RRT）算法，用于对第 III 节中所描述的学习到的隐空间进行全局搜索。L2RRT 是一种属于快速探索随机树（RRT）算法家族的 SBMP 算法 [2]。该算法概述于 Alg. 1 中，并在 Fig. 2 中进行了可视化展示。简而言之，该算法通过从学习到的流形中采样隐空间样本，并在碰撞检测网络的监督下从附近的树节点传播动力学，从而在隐空间中构建一棵树 $\tau ,$ 。由于学习到的动力学可能相当复杂，该算法必须依靠动力学传播策略而非转向函数（steering function）来连接局部隐状态。

L2RRT 算法与文献 [22] 中提出的 RRT-BestNear 算法类似，其采样限制在隐空间内，且动力学传播通过隐空间动力学进行。该算法接收全状态空间中的规划问题作为输入：障碍物表示 $\mathcal { X } _ { \mathrm { o b s } }$ 、初始状态 $\mathbf { x } _ { \mathrm { i n i t } }$ 以及目标区域 $\mathcal { X } _ { \mathrm { g o a l } }$ 。再次需要说明的是，我们在此滥用了记号 ${ \mathcal { X } } _ { \mathrm { o b s } } .$ 。尽管传统上在 SBMP 中，$\mathcal { X } _ { \mathrm { o b s } }$ 仅通过碰撞检测器进行隐式定义，但我们在此用它来指代用于状态空间碰撞检测器的任何环境信息。

我们简要讨论如何选择该算法的参数值。$\delta _ { G _ { t } ^ { - } }$ −1 球半径代表在利用良好轨迹与通过新轨迹进行探索之间的权衡。该值应根据系统本身以及 [22] 中的讨论进行调整。最大动力学传播时间 $T _ { \mathrm { m a x } }$ 大致控制了边的长度。对于后续结果，该参数大致设置为：在最优控制下，机器人可在 $4 T _ { \mathrm { m a x } }$ 内遍历整个状态空间。$\alpha$ 的值反映了碰撞检测网络所需的安全性水平。我们发现大多数碰撞分类得出的概率小于 1% 或大于 99%，然而，对于后续结果，该阈值被设定为 $\alpha = 0 . 9$。最后，我们还使用了一种称为目标偏置（goal-biasing）的技术，即加大在目标区域内的采样权重。对于后续结果，我们在 10% 的采样时间中从目标区域内抽取状态。

由于学习到的潜在空间具有近似性质，L2RRT 不具备形式上的完备性或最优性保证。未来研究的一个有趣方向是探讨在何种条件下可以推导出 L2RRT 的理论保证。

## V. 实验结果

在本节中，我们展示了我们的方法在两个规划问题上的有效性，这两个问题来自于传统运动规划方法难以处理的领域。我们表明，该方法能够泛化到未见过的新问题，并在无法获取真实机器人状态或训练专家策略（training oracle）的情况下找到解。第一个是视觉规划问题，涉及一个具有单积分器动力学（single integrator dynamics）的点机器人根据视觉输入在复杂环境中导航。第二个是人形机器人规划问题，人形机器人必须在障碍物之间进行机动。该方法使用 Python 和 Tensorflow [23] 实现。所有数据均在配备 3.4 GHz CPU 和 NVIDIA GeForce GTX 1080 Ti GPU 的 Unix 系统上收集。示例代码可在 github.com/StanfordASL/LSBMP 找到，更多细节请参见附录（Appendix）。

## A. 视觉规划问题

我们考虑一个类似于 [3] 中概述的视觉空间平面问题，但具有更复杂的障碍物空间。该设置使我们能够证明 L-SBMP 方法通过利用将碰撞检测与动力学传播过程分离的算法先验，泛化到新环境的性能。由于我们能够获取真实的底层状态，且底层规划问题相对简单，因此该问题使我们能够将我们的方法与可以访问系统真实状态的基于采样的运动规划算法进行对比。

视觉问题的完整状态是在 MuJoCo 中渲染的 $3 2 \times 3 2$ 像素图像，显示场景中的机器人和障碍物。机器人是具有单积分器动力学的点机器人。障碍物是数量随机的圆形和正方形，具有随机生成的位置和大小。示例问题的初始状态和目标状态如图 Figs. 3a–3b 所示。自动编码器和动力学网络的训练数据包含 10,000 个环境，每个环境具有包含 10 个连续状态和控制输入的轨迹。碰撞检测网络的训练数据包含 25,000 个环境，同样每个环境具有 10 对状态和一个碰撞标签。

完整状态被投影到二维潜空间（latent space）中。将该方法应用于基于图像的系统需要进行一些架构上的修改，以使学习问题更容易处理。编码器网络 $h _ { \phi } ^ { \mathrm { e n c } }$ 是一个深度空间自动编码器（deep-spatial autoencoder）[7]，它通过使用卷积神经网络后接空间 soft arg-max 来促进重要视觉特征的学习。为了创建完整状态的准确重构，除了潜状态之外，解码器网络还接收一张环境图像作为输入。该附加输入图像可以是未出现机器人的环境，也可以是来自不同时间步的包含机器人的图像（例如，规划问题的初始状态）。

图 3c 展示了图 3a–3b 中问题所学习到的潜在空间（latent space）。该方法学习到了一个能够捕捉机器人位置并有效去除障碍物内部潜在区域的潜在空间，尽管该障碍物集合此前从未被见过。图 3d 展示了潜在空间中的加权可控性格拉姆矩阵（controllability Gramian）的逆。由于真实系统动力学在整个状态空间中是一致的，这为评估加权损失函数提供了机会。正如预期的那样，在状态空间中更为分散的区域（即相同的控制输入允许更大的移动量），误差受到的惩罚较小。

## VI. 结论

我们提出了基于采样的隐空间运动规划（Latent Sampling-based Motion Planning，L-SBMP）方法，该方法结合了机器人系统局部隐式表征的有效性与基于采样的运动规划（Sampling-based Motion Planning，SBMP）技术，用于计算高维复杂系统的运动规划。具体而言，该隐空间是通过一个自编码器、一个动力学网络和一个独立的碰撞检测网络学习得到的，它们分别在隐空间上强制施加了 SBMP 的主要算法原语（采样、局部连接和碰撞检测）。在此隐空间的基础上，我们使用学习型隐空间 RRT（Learned Latent RRT，L2RRT）算法对隐空间进行全局探索，并直接在其中计算运动规划。通过两组实验（一组在视觉空间内进行规划，另一组使用人形机器人进行规划），我们展示了该方法的整体通用性以及泛化到新环境的能力。

本快报（letter）为未来的工作留下了几个方向。首先，我们计划研究学习存在转向函数（steering function）的更受限的动力学类别，例如局部线性动力学。这将允许采用更优的隐空间探索技术。其次，我们计划研究利用无监督学习来训练碰撞检测网络。第三，我们计划研究隐空间的拓扑结构依赖于特定规划问题的环境和障碍物集合的规划问题，例如人形机器人涉及楼梯的情况。第四，我们计划通过在全状态空间中进行状态增广，将类似的方法应用于任务与运动规划框架中。第五，我们计划研究能够推导出 L2RRT 理论保证的条件。第六，我们计划研究 L-SBMP 如何解决其解显著超出训练分布范围的规划问题。最后，我们计划研究 L-SBMP 能够有效进行规划的部分可观测性极限。除 L-SBMP 之外，通过强制施加算法原语来学习可规划隐空间的方法是非常强大的。我们相信类似的方法可用于直接为轨迹优化学习一个空间，或者针对低维问题用于组合运动规划。
