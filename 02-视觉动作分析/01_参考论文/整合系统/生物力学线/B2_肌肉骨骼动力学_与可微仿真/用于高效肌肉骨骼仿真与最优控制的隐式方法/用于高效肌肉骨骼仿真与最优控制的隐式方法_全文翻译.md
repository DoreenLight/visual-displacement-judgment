## 摘要

肌骨动力学的常微分方程通常具有数值刚性和高度非线性。因此，模拟需要极小的时间步长，且最优控制问题求解缓慢、收敛性较差。在本文中，我们提出了肌骨动力学的一种隐式表述形式，从而衍生出用于模拟和最优控制的新数值方法，期望以此缓解部分上述问题。我们开发了一种一阶 Rosenbrock 方法，用于利用该隐式表述求解前向动力学问题。该方法被用于对具有极高动力学刚度的复杂肩臂系统进行实时动力学模拟。在以实时速度运行时，模拟的关节角度均方根（RMS）误差仅为 0.11 度。针对肌骨系统的最优控制，我们针对隐式表述模型开发了一种直接配置法（direct collocation method）。该方法被应用于预测使用假肢足踝系统的步态。求解在远少于一小时的计算时间内完成，并展示了患者如何调整步态以代偿特定假肢设计的局限性。该最优控制方法还被应用于运动生物力学中的状态估计问题，即从含有噪声且不完整的运动学数据中估计滑雪过程中的受力。使用完整的肌骨动力学模型进行状态估计还具有额外优势：可以使用相同的隐式表述模型进行前向动力学模拟，以模拟损伤和扰动响应。尽管这些方法功能强大且能够解决以往难以处理的问题，但仍存在相当大的数值挑战，尤其是与基于梯度的求解器的收敛性相关的挑战。

## 1. 引言

肌肉骨骼建模已成为人体运动研究中的重要工具。长期以来，多体模型一直被用于解决人类步态的逆动力学问题 [1]，随后引入的肌肉骨骼解剖模型使得估计关节及骨科植入物中的受力成为可能 [2]。然而，这些逆动力学方法需要在人体受试者进行目标运动时采集数据。与此同时，肌肉驱动的正向动力学方法也得到了发展，这些方法能够对全新的以及假设性的运动进行仿真。Hatze [3] 在肌肉骨骼动力学模型以及仿真和最优控制方法方面开展了开创性的工作。随后的应用包括康复 [4] 和运动控制的基础研究 [5]，在这些领域中仿真可用于检验通用假设。正向动力学还被应用于骨科学和运动医学中，用以研究神经肌肉控制对损伤的影响 [6,7]，并设计旨在减轻骨关节炎患者关节负荷的神经肌肉策略 [8]。

尽管具有广泛且潜在重要的应用前景，肌肉骨骼建模（musculoskeletal modeling）的应用并没有像我们预期的那样广泛。部分原因在于缺乏用户友好的软件工具，目前 Stanford University 的 Opensim 团队正在改善这一现状 [9]。但即便有了可用软件，仿真所需的计算时间也可能成为一大障碍。肌肉骨骼动力学的微分方程通常具有刚性（stiff），这要求标准的 ODE 求解器采用许多微小的时间步长。例如，在一项行走的马的模型中，这种刚性就是一个问题，原因在于几乎无质量的马蹄与高刚性的地面接触之间的相互作用 [10]。在 25 MHz 的 M68000 处理器上，1 秒的仿真需要 10 小时的计算。在人体运动中，该问题没有那么极端，但在必须执行大量仿真以求解最优控制问题时，它再次成为一个瓶颈。Anderson 和 Pandy [11] 分配在 Cray T3E 并行超级计算机的各个节点上，耗费了约 10,000 小时的计算时间，才求得半个步态周期的最优控制。十年后，这仍然是利用完整 3D 肌肉骨骼模型进行步态最优控制已发表的最佳解。在我们自己关于运动损伤的研究中，我们通过执行数十万次仿真找到了合理的最优控制解，这需要数天的计算时间，但这些运动并不要求具有周期性，持续时间仅为 200 ms，且优化利用了人体采集的运动学数据 [7,12]。然而，数天的计算时间对于研究中模型的有效交互式使用来说仍然过长，并且对于临床应用也是不可接受的。

近年来，肌肉骨骼动力学的应用再次转向求解神经肌肉控制的逆问题，该问题可以通过测量的运动学和地面反作用力非常高效且动力学一致地求解 [13]。不幸的是，这种方法不允许使用接触模型来替代测量的地面反作用力，从而排除了一些既具有科学意义又具有临床相关性的应用，例如主动运动中与冲击相关的损伤仿真，以及基于最优控制的预测性仿真。

在本文中，我们将首先回顾肌肉骨骼动力学的要素，特别关注传统求解方法中数值问题的潜在原因。然后，我们提出一种隐式列式（implicit formulation），它减少了模型动力学的计算时间，并旨在改善模型方程的数值条件。本文提出了正向动力学仿真和最优控制的求解方法，前者将在 3D 手臂和肩部模型上进行演示，后者将在行走假肢设计和滑雪状态估计问题上进行演示。

## 2. 肌肉骨骼动力学

## 2.1. 多体动力学

肌肉骨骼系统的骨骼部分采用由关节连接的刚体进行建模，这些关节对多体系统施加运动学约束。我们使用广义坐标 $\mathbf{q}$ 来建立多体动力学方程：

$$
\mathbf {M} (\mathbf {q}) \cdot \ddot {\mathbf {q}} + \mathbf {B} (\mathbf {q}, \dot {\mathbf {q}}) - \boldsymbol {\tau} = 0,\tag{1}
$$

其中 $\mathbf{M}(\mathbf{q})$ 为质量矩阵，Ĳ 为广义力向量，$\mathbf { B } ( \mathbf { q } , { \dot { \mathbf { q } } } )$ 包含重力、离心力和科里奥利（Coriolis）效应，以及其他表现为广义坐标及其速度函数的被动力（例如接触力）。向量 Ĳ 包含广义力，这些广义力对于未驱动自由度为零，或者由肌肉根据第 2.2、2.3 和 2.4 节中介绍的模型产生。后者被称为关节力矩。公式 (1) 的表述形式并非唯一的，因为它可以左乘任何非奇异矩阵。然而，当按照 (1) 进行表述时，很容易看出，当多体系统具有树状结构时，运动方程中的各项可以在 $O ( N )$ 时间内计算出来，其中 $N$ 为模型中身体链段的数量。例如，可以通过正向运动学计算牛顿-欧拉（Newton-Euler）方程中的惯性项，随后采用传统的递归逆动力学方法根据运动学和外力求解关节力矩和残余载荷 [1]。

对于正向动力学仿真，必须针对广义加速度求解方程 (1) 或其等价形式：

$$
\ddot {\mathbf {q}} = \mathbf {M} (\mathbf {q}) ^ {- 1} \left(\boldsymbol {\tau} - \mathbf {B} (\mathbf {q}, \dot {\mathbf {q}})\right).\tag{2}
$$

随后使用标准的微分方程求解器对该方程进行积分并模拟运动。

甚至在引入肌肉之前，我们就可以指出，如果质量矩阵 $\mathbf{M}$ 是奇异的，仿真将无法进行。在肌肉骨骼系统中，质量矩阵接近奇异是非常普遍的，因为某些身体链段的质量和转动惯量极小。$\mathbf{B}$ 中具有高刚度和高阻尼特性的项进一步加剧了这一问题。此时，(2) 式右侧的雅可比矩阵将具有很大的特征值，表明该微分方程具有刚性（stiff），采用显式方法求解时将需要极小的时间步长。例如，这在行走马的模型中表现得尤为明显，该模型中细小的蹄段与坚硬的路面之间存在弹性接触 [10]。数值刚性的另一个来源是可能短而僵硬的韧带。

在机械模型中，高刚度元件与低刚度元件之间通常有明确的区分。此时，可以通过将高刚度元件替换为运动学约束（实际上具有无限大刚度）来避免刚性微分方程（stiff differential equations），同时消除了自由度。经过一些额外的数据记录与状态管理，这种方法也可以应用于刚体之间的接触，其中的约束是在仿真过程中可以激活和去激活的互补约束（complementarity constraints）。然而，在生物力学建模中，运动学元件与产生力的元件之间往往没有明确的界限，用硬约束替代高刚度力元件并不总是合理或可取的。例如，我们将无法再通过改变地面接触特性来模拟在沙地与硬化路面上行走的差异，或者运动鞋对跑步表现的影响。对于高刚度韧带，有时可以用关节中的运动学约束来替代，例如，通常将膝关节运动限制为单个旋转自由度。然而，如果我们想要模拟膝关节松弛度变化对运动过程中损伤风险的影响，这种做法是不可取的。另一个例子是人手模型，其中极小的手指质量与高刚度肌腱相耦合。通过将肌腱建模为无限刚性，可以消除这种数值刚性。这适用于模拟无负载运动（例如手语交流），但不适用于物体操控，因为在物体操控中肌腱顺应性至关重要。问题的根源可能在于韧带和肌腱具有高度非线性的力学特性：在未受载时刚度几乎为零，而在最大受载时刚度极高。遗憾的是，在肌肉骨骼动力学模型中，刚性微分方程是不可避免的。

并联弹性元件（PEE，parallel elastic element）代表包绕肌纤维的被动弹性组织。文献中已广泛描述了这些元件的特性（例如 [14]），在此我们仅作简要概述，并给出我们在本文所展示的应用中所采用的模型方程的具体实现。

根据肌肉生理学，我们可以将收缩元件（CE，contractile element）建模为产生力 $F _ { \mathrm { C E } }$，该力取决于最大等长肌力 $F _ { \mathrm { m a x } }$、激活度 $^ { a , }$、肌纤维长度 $\left( L _ { \mathrm { C E } } \right)$ 以及肌纤维拉长速度 $( \dot { L } _ { \mathrm { C E } } )$。与其他学者所做的一致 [14,15]，我们假设这些效应之间呈乘性相互作用：

$$
F _ {C E} = a \cdot F _ {\max} \cdot f _ {F L} (L _ {C E}) \cdot f _ {F V} (\dot {L} _ {C E}).\tag{3}
$$

函数 $f _ { \mathrm { F L } }$ 和 $f _ { \mathrm { F V } }$ 为无量纲的力-长关系和力-速关系 [14,15]。典型示例如 Fig. 2 所示。弹性元件由各自独立的被动力-长关系 $f _ { \mathrm { S E F } }$ 和 $f _ { \mathrm { P E E } }$ 表示。肌肉的状态方程即为该三元件结构的力量平衡方程：

$$
\left[ a \cdot F _ {\max} \cdot f _ {F L} (L _ {C E}) \cdot f _ {F V} (\dot {L} _ {C E}) + f _ {P E E} (L _ {C E}) \right] \cos \phi - f _ {S E E} (L _ {M} - L _ {C E} \cos \phi) = 0.\tag{4}
$$

羽状角 $\phi$ 通过恒定体积假设 [16] 从模型中消去：

$$
L _ {\mathrm{CE}} \sin \phi = L _ {\mathrm{CEref}} \sin \phi_ {\mathrm{ref}},\tag{5}
$$

其中等式右侧是一个由在某一特定状态下（例如尸体标本的死后测量）测得的参考肌纤维长度和参考羽状角导出的常数。此类肌构型参数以及骨骼上的肌肉附着点已被测量用于多种肌肉 [17,18]，并已被纳入商业和开源软件系统所包含的模型中 [9]。对于肌肉收缩动力学，肌肉激活度 a 和肌肉长度 $L _ { \mathrm { M } }$ 是外部输入，我们将在第 2.3 节和第 2.4 节中对其建模。方程 $( 4 )$ 现在是状态变量 $L _ { \mathrm { C E } }$ 的微分方程。状态方程 $( 4 )$ 通常通过求解 $\dot { L } _ { \mathrm { C E } }$ 转化为显式，但存在若干潜在的奇异点。首先，力-速度关系 $f _ { \mathrm { F V } }$ 是不可逆的，因为它既有最小力（零）也有最大力。其次，当肌肉未被激活 $( a ~ = ~ 0 )$ 时会出现除以零的情况。第三，当肌纤维缩短至以下长度时，肌肉将被卡死：

$L _ { \mathrm { C E r e f } } \sin \phi _ { \mathrm { r e f } }$ 。在典型的软件实现中，这些奇异点会被较好近似真实肌肉特性的近奇异点所替代 [12]，但会导致数值刚性并降低微分方程求解器的求解速度。

为消除羽状角奇异性，我们转而采用 $s = L _ { \mathrm { C E } } \cos \phi ( \mathrm { F i g . ~ } 1 )$ 作为状态变量，由此肌纤维长度和羽状角的余弦值始终可以无奇异性地求解：

$$
\begin{array}{c} L _ {\mathrm{CE}} = \sqrt {s ^ {2} + \left(L _ {\mathrm{CEref}} \sin \phi_ {\mathrm{ref}}\right) ^ {2}} \\ \cos \phi = \frac {s}{L _ {\mathrm{CE}}} \end{array}\tag{6}
$$

将这些代入状态方程 (4) 中，我们获得了关于状态变量 s 的一阶隐式微分方程。该方程在所有情况下仍然无法显式解出 s，因此我们目前将其保留为隐式微分方程。

## 2.3. 肌肉激活动力学

肌肉的激活度 a（也称为激活状态）不能由神经系统直接控制，因为它是相对缓慢的电化学过程的结果。神经系统向肌肉发送控制信号 u(t)（也称为神经兴奋），通过一阶非线性激活-去激活过程引起激活度的改变。激活过程比去激活过程更快，通常建模为 [19]：

$$
\dot {a} = (u - a) (c _ {1} u + c _ {2}),\tag{7}
$$

其中 $c _ { 1 } { + } c _ { 2 }$ 是激活速率常数，$c _ { 2 }$ 是去激活速率常数，通常在 $2 0 { - } 5 0 \ \mathrm { s } ^ { - 1 }$ 的范围内，具体取决于肌纤维类型 [17,19]。

## 2.4. 肌肉-骨骼耦合

肌肉的端点附着在骨骼上，这意味着每根肌肉的长度都是骨骼姿态的函数：

$$
L _ {\mathrm{M}} = L _ {\mathrm{M}} (\mathbf {q})\tag{8}
$$

肌肉长度与关节角度之间的关系可以通过几何方法建模，例如使用直线或包裹在下层解剖结构周围的更真实的肌肉路径 [9]。该关系也可以直接测量，例如在活体中通过成像技术测量，或在死后通过肌腱位移法（tendon travel method）[20] 测量。一旦已知该长度-角度关系并建立可微分的模型，肌肉 i 在关节 j 处产生的关节力矩 $\tau _ { i j }$ 就可以利用虚功原理 [21] 推导出来，并写为状态变量 q 和 $L _ { \mathrm { C E } }$ 的函数：

$$
\tau_ {i j} = - \frac {\partial L _ {\mathrm{M} , i}}{\partial q _ {j}} f _ {S E E, i} \left(L _ {\mathrm{M}, i} (\mathbf {q}) - L _ {\mathrm{CE}, i}\right)\tag{9}
$$

该方程中的偏导数即为肌肉 i 在关节 j 处的力臂。负号源于肌肉缩短（即 $L _ { \mathrm { M } }$ 减小）时做正功这一事实。此时将式 (9) 中的关节力矩代入运动方程 (1)，即可完成肌肉-骨骼的耦合。

在我们自己的工作中，我们通常使用 Opensim 软件（[9]，http://www.simtk.org/home/opensim）通过运动学仿真获取大量姿态 q 下的力臂。然后生成一个多项式长度-角度关系，该关系求导后能以足够的精度拟合这些力臂数据 [7,22]。一旦完成该预处理，多项式的计算和求导速度远快于基于几何的肌肉路径，这有助于加快仿真的运行速度。这类多项式中最简单的是线性的：

$$
L _ {\mathrm{M}} (\mathbf {q}) = L _ {0} + d _ {1} q _ {1} + d _ {2} q _ {2} + \dots\tag{10}
$$

这意味着肌肉在每个关节处具有恒定的力臂，或者从几何意义上讲，包裹在以关节旋转轴为中心的圆柱体上。这对于平面模型通常是足够的，但在 3D 模型中，姿势通常会对力臂产生关键影响，因此需要更通用的高阶多项式：

$$
L _ {\mathrm{M}} (\mathbf {q}) = \sum_ {i = 1} ^ {N} c _ {i} \prod_ {j = 1} ^ {M} q _ {j} ^ {e _ {i j}},\tag{11}
$$

其中 N 是多项式项数，M 是肌肉跨越的运动学自由度数。模型参数为 N 个系数 $c _ { i }$ 以及 NM 个非负整数指数 $e _ { i j } .$

## 2.5. 肌骨动力学的隐式状态方程

在回顾了肌骨模型的各个要素之后，我们将使用状态向量 x 来构建组合系统的动力学方程：

$$
\mathbf {x} = (\mathbf {q}, \dot {\mathbf {q}}, \mathbf {s}, \mathbf {a}) ^ {T}\tag{12}
$$

每个运动学自由度包含两个状态变量 $( q$ 和 $\dot { q } )$，每块肌肉包含两个状态变量（s 和 a）。动力学平衡方程 $( 1 )$ 和 (4) 现在可以与激活模型 (7) 合并为一个如下形式的隐式状态方程：

$$
\mathbf {f} (\mathbf {x}, \dot {\mathbf {x}}, \mathbf {u}) = 0\tag{13}
$$

其中 $\mathbf{u}$ 包含所有肌肉的神经兴奋。常规仿真方法需要针对 $\mathbf{x}$ 求解该方程以获得常微分方程（ODE），但正如上文所述，这会导致数值刚性并需要极小的仿真时间步长。一种可能的补救方法是使用隐式 ODE 求解器 [23]，但数值估计 ODE 的雅可比矩阵的计算成本通常高于使用更小时间步长的显式求解器的成本。然而，如果我们将微分方程保留为其隐式形式 (13)，它具有更简单的符号内部结构，并且能够获取精确的解析雅可比矩阵 $\hat { \ b { \mathrm { o } } } \mathbf { f } / \hat { c } \mathbf { x }$、ww xf 以及 ${ \partial \mathbf { f } } / { \partial \mathbf { u } }$。

在本文的研究中，我们使用 Autolev (Symbolic Dynamics Inc., Sunnyvale, CA) 来生成 $\mathbf{f}$ 中的多体方程 (1) 及其对 $\mathbf { q } , { \dot { \mathbf { q } } }$ 和 $\ddot { \bf q }$ 的导数的符号表达式和 C 代码。肌肉动力学方程及其导数则是用 C 语言手动编写的。随后，将每个模型合并后的 C 源代码封装在 Matlab (Mathworks, Inc., Natick, MA) 的 MEX 函数接口中，以便能够在 Matlab 平台上开发应用程序，并充分利用 Matlab 的绘图功能和强大的稀疏线性代数计算能力。

得益于隐式形式，雅可比矩阵 $\hat { \alpha } \mathbf { f } / \hat { \alpha } \mathbf { x } , \hat { \alpha } \mathbf { f } / \hat { \alpha } \dot { \mathbf { x } }$ 和 ${ \partial \mathbf { f } } / { \partial \mathbf { u } }$ 不仅易于计算而且具有稀疏性，从而提高了用于仿真和最优控制的求解器中线性代数运算的效率。一个具有 50 个状态变量和 16 个控制量的二维步态模型 [24] 的稀疏结构如图 3（Fig. 3）所示。

## 3. 仿真

## 3.1. 方法

肌肉骨骼系统模型的仿真涉及在给定初始状态 $\mathbf { x } ( 0 )$ 以及作为时间及/或状态函数的控制变量 u 的情况下求解状态轨迹 $\mathbf { x } ( t ) .$。当 ${ \partial \mathbf { f } } / { \partial \dot { \mathbf { x } } }$ 非奇异时，方程 (13) 是一个指标为 0 的微分代数方程（DAE）。这意味着 x 可以被求解和积分，但我们也允许该矩阵为奇异的情况，这可能是由质量矩阵奇异或肌肉激活度为零所导致的。在这些情况下，DAE 的指标为 1。求解指标为 0 或 1 的 DAE 的数值方法已广为人知，通常基于后向微分公式 [23]。介绍其中一种方法——隐式中点欧拉（Midpoint Euler, ME）方法，将具有启发性。我们在此仅考虑开环控制的情况，其中 u 是时间的函数。ME 方法通过在动力学方程的中点处求解 ${ \bf X } _ { n + 1 }$，将系统从时间 t 的状态 ${ \bf { X } } _ { n }$ 推进到时间 $t { + } h ,$ 的新状态 ${ \bf X } _ { n + 1 }$：

$$
\mathbf {f} \left(\frac {1}{2} (\mathbf {x} _ {n} + \mathbf {x} _ {n + 1}), \frac {1}{h} (\mathbf {x} _ {n + 1} - \mathbf {x} _ {n}), \frac {1}{2} (\mathbf {u} _ {n} + \mathbf {u} _ {n + 1})\right) = 0.\tag{14}
$$

ME 是一种无数值阻尼伪影的二阶方法。它是 A-稳定的（A-stable），但不是 L-稳定的（L-stable）。非线性方程 (14) 必须使用牛顿法（Newton’s method）的某种变体来求解，这会导出一个迭代过程：

$$
\mathbf {x} _ {n + 1} ^ {(k + 1)} = \mathbf {x} _ {n + 1} ^ {(k)} - \left(\frac {1}{2} \frac {\partial \mathbf {f}}{\partial \mathbf {x}} + \frac {1}{h} \frac {\partial \mathbf {f}}{\partial \dot {\mathbf {x}}}\right) ^ {- 1} \mathbf {f} \left(\frac {1}{2} (\mathbf {x} _ {n} + \mathbf {x} _ {n + 1} ^ {(k)}), \frac {1}{h} (\mathbf {x} _ {n + 1} ^ {(k)} - \mathbf {x} _ {n}), \frac {1}{2} (\mathbf {u} _ {n} + \mathbf {u} _ {n + 1})\right).\tag{15}
$$

可解性的要求显而易见。我们并不要求可大致称为“质量矩阵”的 ${ \cal \hat { o } } { \bf f } / { \cal \hat { o } } { \bf \dot { x } }$ 是可逆的，而是要求它与“刚度矩阵” $\hat { \ b { \mathrm { o } } } \mathbf { f } / \hat { c } \mathbf { x }$ 的线性组合是可逆的。因此，在没有质量的地方我们必须具备刚度，而在没有刚度的地方必须具备质量。同样的推理也适用于我们前面指出的近奇异性。如果在状态空间中存在具有高刚度和低质量的扰动方向，这对于求解显式表述的模型 (2) 来说是一种劣势，但对于应用于隐式表述模型的隐式求解方法而言，实际上是一个优势。质量与刚度之间的这种互补性通常已经是肌肉骨骼模型的固有天然特征，其中较小的质量（足部、肩胛骨、手指）通常与刚性组织元件发生相互作用。当时间步长 h 趋于无穷大时，ME 方法会给出静态平衡状态，而这要求刚度矩阵是可逆的。我们确实已经验证，即使质量矩阵是奇异的且肌肉激活度为零，应用于隐式模型表述的 ME 方法也是稳定的。

ME 方法对于实时仿真而言并不理想，因为研究发现，即使雅可比矩阵是精确的，所需的牛顿迭代次数在不同时间步之间也会发生变化，因而计算时间是不可预测的。因此，对于实时仿真，我们使用 Rosenbrock 方法，该方法属于线性隐式方法。Rosenbrock 方法在每个时间步中仅执行一次牛顿迭代，但需要精确的雅可比矩阵，而我们恰好具备该条件。具有误差控制且适用于指标为 1 或 0 的微分代数方程（DAE）系统的高阶 Rosenbrock 方法已由 Roche [25] 阐述。对于我们的需求，实现具有恒定步长 h 的一阶方法就足够了：

$$
\begin{array}{l} \Delta \mathbf {x} = \left(\frac {\partial \mathbf {f}}{\partial \mathbf {x}} + \frac {1}{h} \frac {\partial \mathbf {f}}{\partial \dot {\mathbf {x}}}\right) ^ {- 1} \left(\frac {\partial \mathbf {f}}{\partial \dot {\mathbf {x}}} \dot {\mathbf {x}} _ {n} - \mathbf {f} (\mathbf {x} _ {n}, \dot {\mathbf {x}} _ {n}, \mathbf {u} _ {n}) - \frac {\partial \mathbf {f}}{\partial \mathbf {u}} \cdot (\mathbf {u} _ {n + 1} - \mathbf {u} _ {n})\right) \\ \mathbf {x} _ {n + 1} = \mathbf {x} _ {n} + \Delta \mathbf {x} \\ \dot {\mathbf {x}} _ {n + 1} = \Delta \mathbf {x} / h \end{array} .\tag{16}
$$

公式 (16) 的完整推导见附录 A。请注意，质量矩阵与刚度矩阵之间具有互补性的可解性要求与 ME 方法相同。

## 3.2. 手臂-肩部模型的实时仿真

肌肉的功能性电刺激（Functional Electrical Stimulation, FES）可以恢复脊髓损伤患者的功能。这项工作的一大挑战是开发智能控制器和自然的指令接口。为了在有人类用户在回路中的情况下测试控制器和指令接口，开发了一种虚拟手臂，即动态手臂模拟器（Dynamic Arm Simulator, DAS）。DAS 允许用户在可预测的动力学系统上练习使用指令接口，并允许在引入生物肌肉骨骼系统的不可预测性之前进行控制系统和人机交互的研究。由于人类用户处于控制回路中，动力学仿真必须实时进行。DAS 第 2 版见于 [22]，由相对于固定的肩胛骨运动的手臂组成。它被公式化为 ODE，并采用 $4 ^ { \mathrm { t h } }$ 阶显式 Runge-Kutta（RK）方法以 1 ms 的固定时间步长进行仿真。下一版本（DAS3）包括肩胛骨和锁骨的运动，它们的质量较小，并在大而刚硬的发力结构之间保持平衡。DAS3 的 ODE 公式化初始实验表明，显式方法需要极小的时间步长，且无法实时运行。

DAS3 模型是基于 [26] 中描述的通用模型结构开发的。该模型由一个固定在地面上的胸廓，以及由锁骨、肩胛骨、肱骨、尺骨、桡骨和手组成的运动学链构成。腕关节被固定，共有 11 个运动学自由度。肩胛骨与胸廓之间的滑动接触采用刚度为 20 kN/m 的弹性模型实现。该模型在 SIMM（Musculographics Inc., Santa Rosa, CA）中实现，并基于 Klein Breteler 等人 [18] 的数据添加了 138 个肌肉单元。在 SIMM 中进行了运动学仿真，以获得肌肉路径的多项式模型 (11)。该模型被导入 OpenSim [9] 中进行可视化（Fig. 4）。该模型具有 $2 \mathrm { x } 1 1 + 2 \mathrm { x } 1 3 8 = 2 9 8$ 个状态变量。

该模型以隐式形式 (13) 构建，并作为 Matlab MEX 函数实现，用于计算动力学残差 f 及其三个雅可比矩阵（Jacobians）。在 2.4 GHz 的 Intel i5-450M 处理器上，该 MEX 函数的执行时间为 1.2 ms。实现了一阶 Rosenbrock 方法，并发现每个时间步求解线性系统 (16) 需要额外的 1.5 ms。这意味着实时仿真必须采用 2.7 ms 或更大的时间步长进行。进行了测试仿真，其中系统从其被动平衡状态（手臂自然下垂）开始。所有肌肉中的神经兴奋呈线性递增，在 $t = 0 . 2$ 秒时达到最大值，随后保持恒定直到 $t = 2 . 0$，之后关闭兴奋。仿真持续到 t $= 4 . 0 \ \mathrm { s . \ A }$ 二阶显式 RK 方法（Matlab ODE23）采用默认容差设置，以首先确立“正确”的结果。在每次 ODE 求解计算中，利用牛顿法（Newton’s method）从 (13) 求解 x，f 的范数容差设为 $1 0 ^ { - 8 }$。ODE23 进行仿真时所需的平均步长约为 2 微秒，这证实了该 ODE 形式具有极高的刚性（stiffness）。造成这种刚性的主要（但非唯一）原因是短而刚硬的锥状韧带（conoid ligament），该韧带连接肩胛骨的喙突与锁骨，并控制转动惯量极低的锁骨的轴向旋转。

仿真运动如图 5a 所示。肌肉使关节迅速移动到一个新的平衡位置。在最后两秒钟，当肌肉放松时，出现阻尼振荡，此时手臂的作用类似于钟摆。随后使用 Rosenbrock 方法 (16) 进行了不同时间步长（最大达 6 ms，此时该方法变得不稳定）的仿真（图 5b）。在小步长下，误差与步长成正比，这证实了这是一阶方法。在可实时完成的 3 ms 步长下，关节角度的 RMS 误差仅为 0.11 度，这意味着在所有实际应用中，该结果与正确结果（图 5a）完全一致。考虑到该仿真的时间步长比 RK 方法大了 1500 倍，这达到了显著的精度水平。

## 4. 最优控制

## 4.1. 问题陈述与相关工作

最优控制问题出现在肌肉骨骼建模的许多应用中。通常，我们希望确定能够在某种意义上产生“最优”运动的控制量 u(t)。在完全预测性仿真中，不使用关于人体的观测数据，最优性被定义为最大性能，或在给定的次最大负荷任务下的最小发力。此类优化可用于设计最优运动技术，或检验有关人体运动控制的假设 [3,24]。在其他应用中，我们希望找到使系统重现实际观测到的人体运动的控制量 u(t)。随后，由这些控制量驱动的仿真可用于模拟新的运动，例如对可能导致损伤的扰动作出反应 [7]。无论最优控制问题的性质如何，它始终可以表述如下：

$$
\begin{array}{l l} \text {Find state trajectories \mathbf {x} (t) and control trajectories \mathbf {u} (t)} \\ \text {Which minimize a cost functional:} \\ \mathcal {F} (\mathbf {x} (t), \mathbf {u} (t)) \\ \text {And satisfy these constraints:} \\ \mathbf {f} (\mathbf {x}, \dot {\mathbf {x}}, \mathbf {u}) = 0 & \text {(system dynamics)} \\ \mathbf {u} _ {L} \leq \mathbf {u} \leq \mathbf {u} _ {U} & \text {(bounds on controls)} \\ \mathcal {T} _ {i} (\mathbf {x} (t), \mathbf {u} (t)) = 0 & \text {(task requirements)} \end{array}\tag{17}
$$

代价泛函的典型示例包括：能量消耗、与参考轨迹的距离，或性能变量的负值（例如跑步速度和跳跃高度）。这些也可以组合为加权和以进行多目标优化。任务约束可以有任意数量，也可以完全没有。任务约束的一些典型示例包括：初始状态、终止状态、周期性或步行速度。

求解肌肉骨骼最优控制问题的方法随着时间的推移有了长足的发展。针对相对较小的肌肉骨骼模型的早期研究采用了间接法，例如微分动态规划（differential dynamic programming）[3]。这些方法无法很好地推广到更复杂的 3D 全身模型，因而被直接打靶法（direct shooting methods）所取代。在直接打靶法中，控制轨迹被参数化，并通过重复的正向动力学仿真在参数空间中搜索最优控制。研究发现参数空间中基于梯度的搜索非常耗时 [11] 且容易陷入局部极值 [27]，目前已大多被模拟退火（simulated annealing）[7,12,27] 和遗传算法（genetic algorithms）[28] 等启发式方法所取代。

最近，配点算法（collocation algorithms）得到了广泛应用，该算法将状态和控制轨迹在时间网格上同时进行离散化，从而转化为由 (17) 描述的大规模约束优化问题。这些方法最早应用于计算机动画领域 [29]，催生了著名的皮克斯（Pixar）跳跃的小台灯（Luxo lamp）动画。同样的方法在航天轨迹优化中也非常成功 [30]。配点法似乎特别适用于任务约束施加在仿真末期的最优控制问题。在打靶法中，最终状态对初始条件和控制可能过于敏感，特别是对于像双足人类这样本质上不稳定的系统。配点法已成为人体运动最优控制中日益流行的工具 [24,31-33]。我们曾广泛评估了利用显式（ODE）形式的肌骨动力学进行对称双足运动预测仿真的直接配点法。通过逐次网格细化，确定在半个步态周期采用 50 个节点的空间分辨率下，解就具有足够的精度 [24,34,35]。我们也发现了一些重大挑战。即使有良好的初始猜测，计算时间对于有效的研究来说仍然过长，从 30 分钟（平面模型）到一周（3D 模型）不等 [35]。大部分计算时间都消耗在利用有限差分计算 ODE 的雅可比矩阵上。此外，除非有良好的初始猜测，否则收敛性仍是一个棘手的问题，而获取良好的初始猜测可能需要数天或数周的实验摸索。如果将显式 ODE 形式替换为本文介绍的隐式公式，我们有望克服其中的一些挑战。

## 4.2. 求解方法

结合我们提出的肌骨动力学隐式表述，最优控制的直接配点法相对容易实现。我们将未知的状态和控制轨迹在时间节点 $t _ { 1 } , t _ { 2 } , \ldots t _ { \mathrm { N } }$ 上进行离散化，得到未知量 $\mathbf { X } _ { 1 } , \mathbf { X } _ { 2 } . . . \mathbf { X } _ { \mathrm { N } }$ 和 $\mathbf { u } _ { 1 } , \mathbf { u } _ { 2 } , . . . \mathbf { u } _ { \mathrm { N } } 。$ 此时代价泛函 $\mathcal { F }$ 便转化为这些未知量的函数 $F$。通过用有限差分近似替代状态导数 $\dot { \mathbf { x } }$，系统动力学约束被转换为一系列代数约束。在本研究中，我们采用中点法则，从而得出以下 N - 1 个约束：

$$
\mathbf {C} _ {i} \equiv \mathbf {f} \left(\frac {\mathbf {x} _ {i + 1} + \mathbf {x} _ {i}}{2}, \frac {\mathbf {x} _ {i + 1} - \mathbf {x} _ {i}}{t _ {i + 1} - t _ {i}}, \frac {\mathbf {u} _ {i + 1} + \mathbf {u} _ {i}}{2}\right) = 0 \qquad f o r i = 1 \dots N - 1\tag{18}
$$

这些约束中的每一个都具有 f 的维度，即状态变量的数量。对于步态的预测模拟，我们还定义了速度和周期性的额外任务约束：

$$
\mathbf {x} _ {N} = \mathbf {x} _ {1} + v T \hat {\mathbf {x}},\tag{19}
$$

其中 v 是步行速度，T 是步态周期的持续时间，$\hat { \bf x }$ 是状态空间中沿纯向前平移方向的单位向量。速度和持续时间既可以预先指定，也可以与最优控制和状态轨迹一起进行优化。原本的最优控制问题现已转化为一个大规模约束优化问题，即非线性规划（NLP）。我们将所有未知量（离散化的状态和控制轨迹，以及任何必须求解的额外未知量）汇总为一个大型向量 X，并在满足来自 (18) 和 (19) 的等式约束 $\mathbf { C } _ { i } ( \mathbf { X } ) { = } 0$ 以及边界 $\mathbf { L } \leq \mathbf { X } \leq \mathbf { U }$ 的前提下，最小化函数 $F ( \mathbf { X } )$。

可以使用标准的大规模 NLP 求解器来解决此类问题。我们在使用基于有效集法（active set method）的 SNOPT [36] 和基于内点法（interior point method）的 IPOPT [37] 方面有很好的经验。两者均适用于 Matlab 平台，并在本文呈现的工作中得到了应用。根据我们的经验（这与 Betts [30] 的建议一致），在没有良好初始猜测值时，优先选择内点法；而在求解一系列相关问题且初始猜测值已接近解时，有效集法更佳。所有 NLP 求解器都需要代价函数 $F$ 的梯度以及约束 C 相对于未知量 X 的雅可比矩阵（Jacobian）。代价函数通常是状态和控制的简单函数，可以生成解析导数。约束的雅可比矩阵是稀疏的，因为每个约束 (18) 仅涉及两个相邻节点处的状态和控制。(18) 式关于任一节点的状态和控制的导数很容易计算，因为如第 2.5 节所述，函数 f 的雅可比矩阵已经是可用的。约束雅可比矩阵中的非零块由“质量”和“刚度”矩阵 ${ \partial \mathbf { f } } / { \partial \dot { \mathbf { x } } }$ 与 $\hat { \ b { \mathrm { o } } } \mathbf { f } / \hat { c } \mathbf { x }$ 的线性组合构成，因此适用与第 3.1 节中介绍的前向动力学模拟方法相同的可解性条件。

## 4.3. 假肢步态的预测模拟

假肢或其他辅助设备以及人机系统的设计，是一个非常适合采用肌肉骨骼最优控制方法的问题。在机械设备的原型制造出来之前，通常会建立计算模型以对其功能进行初步测试并优化设计。然而，当设备与人体产生机械耦合，且其特定目的是为了影响人体运动时，这一过程就变得不再简单。人体运动会通过机械效应受到直接影响，或者在使用者调整其神经肌肉控制以更好地利用该设备时受到间接影响。因此，如果计算模型不包含肌肉骨骼动力学和适应性人类行为，就无法很好地预测设备的性能。

为了展示这种应用，我们将尝试预测假肢脚对经胫骨截肢者（transtibial amputee，小腿截肢者）步态的影响。我们采用了 [24] 中描述的平面肌肉骨骼模型，该模型包含 9 个运动学自由度和 16 块肌肉，共计 50 个状态变量和 16 个控制变量。地面接触通过脚跟和脚尖处带摩擦的单向粘弹性单元来表示。我们模拟了规定速度为 1.1 m/s、步态周期持续时间为 1.28 s 的周期性步态。该问题在一个完整的步态周期内被时间离散化为 100 个节点，产生了总计 6600 个未知数。动力学和周期性通过公式 (18) 和 (19) 的 5000 个约束条件来表示。优化采用如下加权代价函数进行：

$$
F (\mathbf {x} (t), \mathbf {u} (t)) = \frac {1}{T} \int_ {0} ^ {T} \left[ \frac {1}{1 0} \sum_ {i = 1} ^ {1 0} \left(\frac {s _ {i} (\mathbf {x} (t)) - m _ {i} (t)}{\sigma_ {i}}\right) ^ {2} + \frac {W}{1 6} \sum_ {i = 1} ^ {1 6} u _ {i} (t) ^ {2} \right] d t\tag{20}
$$

其中 $m _ { i } ( \mathrm { t } )$ 是十个变量的参考轨迹：双肢各三个关节角度以及水平和垂直地面反作用力，测量自健全人步态 [1]。模型中对应的变量为 $s _ { i } ,$，它们要么是状态变量，要么是系统状态的函数。模拟变量与测量变量之间的差异通过人体标准差 $\sigma _ { i }$ 进行了归一化，使其成为无量纲量。式 (20) 中的第一项即“跟踪”（tracking）项将促使模型保持接近正常步态，第二项即“努力”（effort）项将促使其高效利用肌肉。权重 W 设为 100，这意味着肌肉完全激活 $\scriptstyle ( u = 1 )$ 的代价等于十个标准差跟踪误差的代价。我们并不知道这是否是支配人类行为的实际代价函数，但研究发现它能产生合理的预测，且这些预测对权重 W 并不过度敏感。尽管如此，仍必须通过人体受试者实验对这些理论代价函数进行严格验证。

最优控制模型首先在原始模型上求解，得到的代价函数值为 2.04，其中跟踪项贡献为 0.49，努力项贡献为 1.55。运动和地面反作用力平均在正常步态的半个标准差以内，肌肉活动呈现相位性且与正常 EMG（肌电图）模式一致。仿真生成的关节角度和地面反作用力（与正常均值和标准差的对比），以及肌肉力和肌肉兴奋度如图 Fig. 6a 所示。

## 4.4. 基于噪声测量的状态估计

肌肉骨骼系统并非完全可观测。某些状态变量（如骨骼旋转和平移）可以直接测量，而其他变量（如肌肉激活度和肌纤维长度）只能间接获取。在康复和运动生物力学中，通常需要估计关节力矩或肌肉力，因为这些与损伤密切相关。传统方法基于逆向动力学 [1,38]，但这需要对所有运动学变量和外力进行全方位且高精度的测量，而这只有在配备光学运动捕捉和测力台的实验室环境中才可能实现。在实验室之外，测量通常伴有噪声且可能不完整。在此类条件下，通常使用卡尔曼滤波（Kalman filters）结合动力学模型进行实时状态估计 [39]，但在面对复杂肌肉骨骼系统模型的高维状态空间和强非线性时，预计其表现并不理想。此外，卡尔曼滤波在用于离线数据处理时也是次优的，因为它们仅利用过去的数据，而没有利用未来的数据。

然而，我们可以利用卡尔曼滤波（Kalman filtering）的基本概念，即最优估计建立在两个相互冲突的目标之间的权衡之上：一是与测量数据的一致性，二是与系统被动动力学模型的一致性。令人惊奇的是，这一概念等价于一个最优控制问题，其代价函数正如前文公式 (20) 中所使用的：

$$
F (\mathbf {x} (t), \mathbf {u} (t)) = \frac {1}{T} \int_ {0} ^ {T} \left[ \frac {1}{N _ {\text { sensors }}} \sum_ {i = 1} ^ {N _ {\text { sensors }}} \left(\frac {s _ {i} (\mathbf {x} (t)) - m _ {i} (t)}{\sigma_ {i}}\right) ^ {2} + \frac {W}{N _ {\text { muscles }}} \sum_ {i = 1} ^ {N _ {\text { muscles }}} u _ {i} (t) ^ {2} \right] d t\tag{21}
$$

代价函数中的第二项对肌骨骼系统偏离其被动动力学的行为进行惩罚。当赋予适当的权重时，该项将防止模型试图去拟合测量数据中的噪声，因为带噪运动具有较高的加速度，这需要较大的肌肉力量，从而会受到优化的惩罚。这产生了一种类似于卡尔曼滤波器的平滑效果。代价函数中的第一项可以包含任何可用的数据，传感器集合可以是过完备的或不完备的，甚至可以随时间变化，只要我们能够计算出测量值与肌骨骼模型中对应变量之间的差异即可。传感器信号可以包括来自光学运动捕捉和称重传感器的数据，但也可以从佩戴在身体上的传感器获取，例如量角器、MEMS 加速度计和陀螺仪、磁力计等。所有这些传感器目前都在以低成本普及，我们预计，基于肌骨骼动力学模型的状态估计技术将成为处理此类数据的强大工具，从而有效地利用该模型融合来自不同数据源的信息，并强制使其符合已知的物理学和肌肉生理学定律。

我们将这一概念应用于高山速降滑雪（downhill skiing），在该场景下很难获取精确数据。速降滑雪者的运动速度非常快，这要求摄像机要么具有非常大的视野（从而导致空间分辨率较差），要么通过平移和缩放来跟踪滑雪者（这需要逐帧校准并引入大量噪声）。此外，在比赛期间无法安装力传感器等仪器。在 1994 年挪威利勒哈默尔（Lillehammer）冬奥会速降比赛期间，曾采用平移和缩放技术采集视频数据 [40]。从这些数据中，我们提取了一名选手进行着陆动作时以 180 帧/秒采集的 1 秒数据片段。身体各点的三维坐标被转换为平面（矢状面）关节角度以及躯干的绝对位置和方向。数据中包含明显的噪声，但在用于代价函数 (21) 之前并未进行平滑处理。建立了一个平面肌肉骨骼模型，其骨骼和肌肉与步态模拟中的相同。通过添加空气动力学力、可变形滑雪板以及接近无摩擦且倾斜的地面接触表面，使该模型适用于滑雪模拟。模型中未使用任务约束，动力学约束则如公式 (18) 所示采用中点法则（midpoint rule）实现。

## 5. 讨论

采用基于关节力矩 (1) 和肌肉力 (4) 的力平衡方程的肌肉骨骼动力学隐式表述，使得为前向动力学仿真和最优控制实现高效的隐式求解方法成为可能。这些新方法产生的结果与传统方法完全一致，但计算速度更快，有时甚至快几个数量级，并将有助于克服肌肉骨骼建模在某些应用中存在的计算瓶颈。尽管本文展示的工作证明了这些方法的潜力，但仍存在相当大的挑战。传统方法虽然较慢，但稳健且易于使用，只要给予足够的计算时间总能得出结果。而新方法在使用上则更具挑战性。

采用隐式 Rosenbrock 方法进行的正向动力学仿真，必须使求解器从满足隐式动力学方程的一致初始状态 $\left( \mathbf { \delta X } , \dot { \mathbf { X } } , \mathbf { u } \right)$ 开始。常规的显式方法仅需要初始状态 x。我们使用被动平衡状态 $\mathbf { x } _ { e q }$ 作为初始条件，它是 $\mathbf { f } ( \mathbf { x } _ { e q } , 0 , 0 ) = 0$ 的解。该平衡状态比预期的更难寻找，可能是由于接触及类接触单元的存在。我们使用了 Levenberg-Marquardt 方法，它比 Newton 法更鲁棒，但仍需要多次尝试才能找到能够导致收敛的初始猜测值。幸运的是，对于我们的应用而言，这只需要执行一次，因为我们的手臂仿真器始终从相同的初始状态启动。在其他应用中，仿真前需要寻找一致初始条件的要求可能是一个显著的局限性。此外还应指出，我们的仿真方法目前采用固定时间步长，因此精度和稳定性必须通过实验来确定，正如我们在 Fig. 5b 中所做的那样。未来或许可以加入误差控制和变步长，以使方法更加鲁棒。我们在实时仿真中使用固定步长，是因为这能保持计算时间的可预测性。

新型最优控制方法同样具有挑战性：当它们起作用时效果很好，但有时却无法得出解。其计算速度非常出色。对于步态优化问题，IPOPT 每秒可生成解 X 的数次迭代，而 SNOPT 具有更多的内部开销，每秒大约生成一次迭代。另一方面，当有良好的初始猜测值可用时，SNOPT 往往需要大约 100 次迭代，而 IPOPT 则需要大约 1000 次。收敛性极大地依赖于是否具有良好的初始猜测值。当存在良好的初始猜测值时，SNOPT 快速且鲁棒，而 IPOPT 即使在有良好初始猜测值的情况下偶尔也会失去收敛性。当没有良好的初始猜测值时，SNOPT 从未收敛，但如果网格节点较少，IPOPT 通常能找到一个良好的解。随后即可利用 SNOPT 进行逐次网格细化来求精解。在使用特定模型求解了第一个问题之后，新问题总可以转化为一系列优化问题来求解，从而使每个问题的初始猜测值都足够好以保证收敛。

这些实际困难表明，这些方法可能尚未准备好供非专业人员使用，因为对他们而言数值方法的求解失败是不可接受的。在合理进行更广泛的推广应用之前，算法和模型构建形式仍需要进一步改进。然而，只要有足够的耐心和细心，这些新方法已经能够求解以往无法解决的问题。

## 附录 A. 用于模拟隐式模型的一阶 Rosenbrock 方法

一阶 Rosenbrock 方法将时间 $t$ 处的状态 x 推进到 $t + h$ 处的状态 $\mathbf { x } + \Delta \mathbf { x }$，同时控制变量从 u 变为 $\mathbf { u } + \Delta \mathbf { u }$。如果我们用后向 Euler 公式近似状态导数，并尝试在 $t + h$ 处满足隐式状态方程 (13)，可得：

$$
\mathbf {f} (\mathbf {x} + \Delta \mathbf {x}, \frac {\Delta \mathbf {x}}{h}, \mathbf {u} + \Delta \mathbf {u}) = 0.\tag{A1}
$$

我们对此进行改写，使函数自变量表示为相对于前一时刻 $t$ 处的状态 x、状态导数 x 以及控制变量 u 的变化量：

$$
\mathbf {f} (\mathbf {x} + \Delta \mathbf {x}, \dot {\mathbf {x}} + \frac {\Delta \mathbf {x}}{h} - \dot {\mathbf {x}}, \mathbf {u} + \Delta \mathbf {u}) = 0.\tag{A2}
$$

一阶 Taylor 展开得到：

$$
\mathbf {f} (\mathbf {x}, \dot {\mathbf {x}}, \mathbf {u}) + \frac {\partial \mathbf {f}}{\partial \mathbf {x}} \Delta \mathbf {x} + \frac {\partial \mathbf {f}}{\partial \dot {\mathbf {x}}} \left(\frac {\Delta \mathbf {x}}{h} - \dot {\mathbf {x}}\right) + \frac {\partial \mathbf {f}}{\partial \mathbf {u}} \Delta \mathbf {u} = 0\tag{A3}
$$

这是关于 'x 的线性方程：

$$
\left(\frac {\partial \mathbf {f}}{\partial \mathbf {x}} + \frac {1}{h} \frac {\partial \mathbf {f}}{\partial \dot {\mathbf {x}}}\right) \Delta \mathbf {x} = \frac {\partial \mathbf {f}}{\partial \dot {\mathbf {x}}} \dot {\mathbf {x}} - \mathbf {f} (\mathbf {x}, \dot {\mathbf {x}}, \mathbf {u}) - \frac {\partial \mathbf {f}}{\partial \mathbf {u}} \Delta \mathbf {u}.\tag{A4}
$$

求解 'x 即可得到算法 (15)。该算法不仅必须在内存中存储状态 x，还必须存储状态导数 x 和控制变量 u，因为执行一个时间步需要这三者以及 f 的三个雅可比矩阵（Jacobians）。在 $\mathrm { A t } ~ t = 0$ 时，必须给出状态、状态导数和控制变量作为初始条件，且这些初始条件必须满足状态方程 (13)。

虽然未进行精度和稳定性的形式化分析，但该方法应为一阶的（这已由图 5b 中的结果证实），且由于它是使用后向 Euler 公式推导的，因此应是 L-稳定的（L-stable）。
