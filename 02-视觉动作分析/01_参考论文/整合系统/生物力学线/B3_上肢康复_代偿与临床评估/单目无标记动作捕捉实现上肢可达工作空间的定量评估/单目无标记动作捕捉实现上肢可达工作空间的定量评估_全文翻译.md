# 单目无标记动作捕捉实现上肢可达工作空间的定量评估

Seth Donahue, J.D. Peiffer, R. Tyler Richardson, Yishan Zhong, Shaun Q. Y. Tan, Graduate Student Member, IEEE, Benoit Marteau, Graduate Student Member, IEEE, Stephanie R. Russo, May D. Wang, Fellow, IEEE, R. James Cotton, Ross Chafetz

摘要— 目的：验证一种在临床上易于推广的方法，即利用单目（单相机）相机和人工智能（AI）驱动的无标记动作捕捉（Markerless Motion Capture, MMC）进行生物力学分析，以量化上肢可达工作空间（Upper Extremity Reachable Workspace, UERW）。针对特定临床任务对这些技术进行客观评估和验证，对于其在临床运动分析中的应用至关重要。AI 驱动的单目 MMC 降低了临床采用的门槛，并有望减少这一常见临床评估的分析开销。方法：9 名无功能障碍的成年受试者完成了标准化的 UERW 任务，该任务要求触及分布在以躯干为中心的虚拟球体上的目标，目标显示在 VR 头显中。动作由基于标记的动作捕捉系统和一组 8 台 FLIR 相机同时采集。我们对其中两段视频进行了单目视频分析，以比较正面和偏置相机配置。通过比较六个工作空间卦限内达到的目标百分比，以及系统之间的卦限一致性，来评估 MMC 与基于标记的系统之间的一致性。结果：正面相机朝向与基于标记的参考系统表现出高度一致性，每卦限达到的可达空间平均偏差极小，为 0.61 ± 0.12 %（均值 ± 标准差）。相比之下，偏置相机视角低估了达到的工作空间百分比（−5.66 ± 0.45 %）。正面配置中与深度相关的误差主要局限于后部卦限，而偏置视角在对侧和后部卦限中均表现出不准确性。结论：研究结果支持了采用正面单目相机配置进行 UERW 评估的可行性，尤其是在与基于标记的动作捕捉一致性最高的前部工作空间评估中。尽管后部工作空间的精度仍受到深度估计和解剖遮挡误差的限制，但整体表现展示了其在实用的单相机临床评估中的潜力。意义：本研究首次验证了用于 UERW 任务评估的单目 MMC 系统。通过降低技术复杂性和设备需求，该方法使得定量上肢活动度评估能够在临床和居家康复环境中得到更广泛的应用。

索引词— 可达工作空间（Reachable Workspace），无标记动作捕捉（Markerless Motion Capture），单目相机（Monocular Camera），临床可行性（Clinical Feasibility），人工智能（Artificial Intelligence）

## I. 引言

人体运动的定量追踪对于临床评估至关重要，它能够识别生物力学表型，以补充主观评估和患者报告结局（Patient-Reported Outcomes, PROs）[12], [25], [33], [36]。传统上，这种追踪是使用基于标记点的动作捕捉来执行的，该技术被认为是生物力学分析的金标准。基于标记点的系统利用反光标记点追踪解剖学标志点，并已被广泛用于评估上肢（Upper Extremity, UE）功能 [14], [33], [36], [38]。

在过去的二十年中，UE 运动评估已从主观评分发展为使用基于标记点系统的客观量化 [1], [23], [30], [36]。然而，许多分析仅集中于有限的一组动作或静态姿态 [26], [35], [37]。相比之下，上肢可达工作空间（Upper Extremity Reachable Workspace, UERW）通过量化手部所能触及的空间区域，提供了对全局 UE 活动度的整体评估 [14]。该版本的 UERW 任务涉及患者伸手触及显示在其周围的虚拟目标，为其可达工作空间提供了定量且由生物反馈驱动的度量 [33]。UERW 任务的评估是通过已触及的目标数量与该卦限中可供触及的目标总数之比来计算的，并以百分比形式表示。先前的文献已证实 UERW 是一项有效、客观且具有临床相关性的指标，可用于区分患者群体与健康对照组，并随时间追踪康复进展 [7], [15], [16], [33]。尽管基于标记点的系统精度高且具有临床价值，但它们也带来了一些实际挑战，导致难以常规应用。这包括对专用实验室空间、多台摄像机、精细校准以及搭建和操作所需专业技术知识的需求。此外，患者通常需要较长的准备时间，且数据处理也较为耗费人力。这些因素共同导致将动作捕捉整合到日常临床工作流程中面临挑战，限制了其对许多患者和临床医生的可及性。

作为基于标记的动作捕捉（marker-based motion capture）的替代方案，无标记动作捕捉（Markerless Motion Capture, MMC）已成为一种极具前景的选择。该领域的早期工作包括简单的基于视频的客观运动分析方法，通常由工程师或临床团队成员逐帧对患者的关节和肢体节段进行手动标注 [6], [19], [27]。然而，这些手动方法耗时耗力，且需要兼具临床和技术两方面的专业知识。人工智能（Artificial Intelligence, AI）、计算机视觉和人体姿态估计的发展，如今为克服这些局限性提供了一条途径。多摄像机系统（如 Theia3D、OpenCap 和开源生物力学框架）已在多种运动任务中展示了高精度的关节定位和角度估计能力 [4], [17], [18], [42], [47]。尽管这些多摄像机 MMC 系统在上肢（Upper Extremity, UE）评估中通常较为准确，但由于需要同步摄像机设置、外参标定以及系统整体的复杂性，它们在临床环境中的应用仍存在局限性 [13], [17], [43], [45]。

鉴于多摄像机系统在实际应用中的诸多挑战，单摄像机（单目）MMC 为床旁（point-of-care）生物力学重建与分析提供了一种更简单、更具可扩展性的方法。近期的研究表明，尽管存在遮挡、深度估计误差和关键点检测噪声等固有挑战，基于 MMC 的单目生物力学重建仍取得了与基于标记和多摄像机无标记重建相当的高精度表现 [5], [22]。虽然单目动作捕捉有潜力成为临床评估和全身追踪的有力工具，但深度估计仍是此类系统在测量临床相关变量时公认的潜在问题 [29], [32]。其他使用关键点或将关键点与机器学习输出相结合的数据驱动技术虽然准确，但尚未具备必要的生物力学建模和相关的临床有效性指标来指导临床决策 [21], [24], [28], [41]。尽管这些系统已被证明具有一定的临床有效性，但它们纯粹由数据驱动，缺乏临床决策所必需的生物力学约束。最近的研究将解剖学精准的全身追踪、人体姿态估计以及高精度的 MuJoCo 模型相结合，在临床人群中仅使用单部智能手机即可实现相关分析 [31]。尽管这是一个极具前景的大规模人体运动评估优秀工具，但除步态分析外，其在特定任务或临床评估中的有效性仍有待进一步验证。为了填补这一空白，本研究验证了一种基于单目摄像机的系统，用于对执行 UERW 任务的受试者进行运动分析和评分。

据我们所知，这是首个评估用于 UERW（上肢可达工作空间）任务的单目 MMC（无标记动作捕捉），并将多相机配置与临床金标准（基于标记的动作捕捉）进行对比的研究。我们验证了基于两种独立相机配置（正向和偏移）对 UERW 进行单相机生物力学重建的应用。我们假设正向配置的表现将优于偏移视角，并在全部八个 UERW 卦限（octants）中表现出更好的一致性，这是由于偏移相机会带来深度感知差异。从技术角度来看，本研究所选的任务显著更具挑战性，因为 UERW 评估具有高度动态性且包含多平面运动，从而为当前最先进的 AI 驱动单目系统提供了稳健的评估。

## II. 方法

## A. 参与者

九名无运动障碍的成年人（5 名男性，4 名女性；身高：$1 . 6 9 \pm 0 . 0 9 \mathrm { m } .$ ，体重：70.56 ± 19.05 kg）参与了本研究。所有参与者均无影响上肢活动能力的潜在疾病，且在过去一年内无神经损伤史。无论利手为何，均仅评估右臂的 UERW。

## B. 数据收集

对于每位参与者，通过 Vicon Nexus 同时使用 12 台相机的基于标记的动作捕捉系统（Vicon Industries, Hauppauge, NY）和 8 台相机的视频记录系统（Blackfly S 前视红外或 FLIR, Teledyne, Thousand Oaks, CA）采集数据，采样频率为 60 Hz。使用具有透视（pass-through）功能的虚拟现实（VR）头显 Meta Quest 3（Meta, Menlo Park, CA）呈现游戏化的 UERW 实时反馈 [40]。参与者观察一组虚拟目标，这些目标放置在 VR 系统估计的一臂距离处，共有 800 个目标叠加在透视 VR 视野中，并被指示用右手触及这些目标。当手部移动至距离虚拟目标 5 cm 以内时，目标消失 [40]。参与者持续进行触及，直到达成所有目标或无法触及更多目标为止 [34], [40]。

本研究中所呈现的分析，是对最初八台 FLIR 视频摄像机中独立分析的两个单视角进行的事后评估。正向摄像机位于参与者的前上方，而偏置视角摄像机位于前、上及外侧，大约在正向摄像机右侧 $4 5 ^ { \circ }$ 处（Fig. 1）。反光标记点使用粘性魔术贴圆片固定在参与者的皮肤上；所有标记点均由同一位经过培训的研究人员放置以确保一致性。标记点贴在右手腕的桡骨茎突和尺骨茎突、右侧肩胛骨肩峰、T1 和 T8 棘突以及胸骨切迹处（Fig. 1）。随后在 Vicon Nexus 中记录了一次静态试验，以配准标记集并计算每位参与者的最大触及范围。

## C. 运动学处理

1) 基于标记的处理：局部躯干坐标系的原点定义为胸骨切迹与 T1 之间的中点，垂直向量 V 从 T1 延伸至 T8。定义了从 T8 指向胸骨切迹的前后（AP）方向临时占位向量 AP<sub>temp</sub>。内外侧（ML）向量 ML 计算为 $\mathbf { A P _ { \mathrm { t e m p } } }$ 与 V 的叉积：$\mathbf { M } \mathbf { L } = \mathbf { A } \mathbf { P } _ { \mathrm { t e m p } } \times \mathbf { V }$。最终的 AP 向量计算为 $\mathbf { A P } = \mathbf { V } \times \mathbf { M L }$，从而形成一个右手解剖学躯干坐标系。手腕处的末端执行器定义为内侧和外侧手腕标记点之间的中点。这与以往使用第二指上的标记点作为末端执行器的 UERW 研究不同 [15], [33]。目标被定义为手腕距离局部躯干坐标系原点的最大距离。分析在所有六个卦限中进行：上前同侧（Sup. Ant. Ipsil.）、上前对侧（Sup. Ant. Contra.）、下前对侧（Inf. Ant. Contra.）、下前同侧（Inf. Ant. Ipsil.）、下后同侧（Inf. Post. Ipsil.）和上后同侧（Sup. Post. Ipsil.）。

2) 无标记处理：来自两种摄像机配置的视频数据首先使用 PosePipe [3] 进行处理。我们使用 MeTRAbs-ACAE 提取了 2D 和 3D 关键点，该算法输出解剖标志点的超集。从该集合中，我们使用了 87 个 MoVi 关键点，这些关键点为与生物力学重建相关的解剖标志点提供了稳健的覆盖 [4], [11], [39]。这种配置使该系统成为一个纯单目视频系统，即：单目摄像机的生物力学重建完全基于单台视频摄像机的 2-D 和 3-D 数据。人体检测和身份关联使用 mmdetDeepSort [2] 进行。

生成的关键点位置。MuJoCo 的 GPU 加速引擎可实现并行化的正向运动学求值。每个试验的运动学轨迹表示为一个学习到的隐式函数 $f _ { \phi } ,$，通过带有正弦时间编码的多层感知机实现 [44]：

$$
f _ {\phi}: t \mapsto \theta (t)\tag{2}
$$

旋转输出通过 tanh 非线性函数并线性缩放至生物力学关节极限范围，然后由公式 1 中的正向运动学模型进行评估。每个试验都关联一个专用的隐式函数，并且我们遵循 [46] 的双层优化方法，将所有试验特定参数 $\dot { \{ \phi _ { i } \} } _ { i = 0 } ^ { N - 1 }$ 与共享的缩放和偏移参数 $\beta ,$ 一起进行联合优化。在每个优化步骤中，每个试验评估 300 个时间样本以生成预测的关节角度 ${ \hat { \theta } } ( t )$，随后进行 GPU 加速的正向运动学评估 $\hat { x } = M ( \hat { \theta } ( t ) , \hat { \beta } )$。3D 损失定义为：

$$
L _ {\mathrm{3D}} = \frac {1}{J} \sum_ {j \in J} c (j) g \big (\| \hat {x} _ {n} - x _ {c} \| _ {2} \big),\tag{3}
$$

其中 $\hat { x } _ { n }$ 是在每个优化步骤中从模型测量的 3D 关键点，$x _ { c }$ 是从视频中提取的 3D 关键点，$c ( j )$ 是每个关键点的置信度得分，而 $g ( \cdot )$ 是 Huber 损失（在 10 cm 范围内为二次型）。

使用标定的相机内参和投影模型 $\Pi$，2D 损失比较了投影的模型关键点与检测到的 2D 关键点 $u$：

$$
L _ {\mathrm{2D}} = \frac {1}{J} \sum_ {j \in J} c (j) g \big (\| \Pi (\hat {x} _ {n}) - u \| _ {2} \big),\tag{4}
$$

其中 Huber 损失采用 5 像素的二次区域。

尽管最初的流程设计用于带有惯性损失项的移动设备，但由于本工作中的相机是静止的，我们省略了该项。因此，完整的物项目标为：

$$
L = \lambda_ {1} L _ {\mathrm{3D}} + \lambda_ {2} L _ {\mathrm{2D}},\tag{5}
$$

其中 $( \lambda _ { 1 } , \lambda _ { 2 } ) = ( 1 , 1 0 ^ { - 1 } )$。训练使用 Equinox、JAX 和 Adam 优化器，学习率从 $1 0 ^ { - 3 }$ 衰减至 $1 0 ^ { - 6 }$，权重衰减为 $1 0 ^ { - 5 }$ [8], [20]。模型训练在配备 64 GB RAM 和 NVIDIA RTX A6000 GPU（16 GB VRAM）的工作站上使用 JAX 0.6.0 完成 [4], [31]。

所有对参与者运动的评估均在事后进行。由于 MoVi 关键点位置与基于标记的系统的解剖位置高度匹配，因此从 MMC 数据派生的坐标系与基于标记的坐标系进行了对齐（图 1）。MMC 坐标系的原点定义为“锁骨”（clavicle）和“颈后”（backneck）关键点之间的中点，大致对应于基于标记系统中的胸骨切迹和 T1 标记。垂直向量 $\mathbf{V}$ 从“上背部”（upper back）关键点（大致为 T8）延伸至“颈后”关键点（大致为 T1）。占位 AP（前后）向量 $\mathbf { A P _ { \mathrm { t e m p } } }$ 定义为从“上背部”到“锁骨”。ML（内外侧）向量计算为 $\bf { M L } = \bf { A P } _ { t e m p } \times \bf { V }$，最终的 AP 向量为 $\mathbf { A P } = \mathbf { V } \times \mathbf { M L }$，从而形成一个右手解剖坐标系。最大伸展距离的计算与基于标记的系统中所使用的计算相同。

## D. 统计分析

我们使用三项度量评估了单目 MMC 在整个上肢（UE）工作空间中的性能：(1) 每种相机配置下基于标记与单目 MMC 之间的峰值伸展距离差异；(2) 由单目 MMC 导出的工作空间达到百分比（UERW 任务的主要临床度量指标）的有效性；以及 (3) 基于标记和单目 MMC 系统在每个时间点上各个卦象（octant）中的一致性。

首先，我们评估了峰值伸展距离的差异，该距离测量为单帧中从躯干坐标系原点到手腕的距离。该值决定了事后分析中虚拟目标的位置。随后，我们计算了基于标记系统和两种 MMC 配置下在每个卦象中达到的工作空间百分比。

其次，为了评估不同系统和象限之间在达到的可及工作空间（reachable workspace accessed）方面的统计学差异，我们使用了双因素重复测量方差分析（Analysis of Variance, ANOVA）。当违反球形假设时应用 Greenhouse–Geisser 校正，并在事后比较中使用 Bonferroni 校正。被试内因素“系统”（system）包含三个水平：基于标记（marker-based）、正向（frontal）和偏置（offset）。被试内因素“象限”（octant）包含六个水平：上前同侧（Superior Anterior Ipsilateral，Sup. Ant. Ipsil.）、上前对侧（Superior Anterior Contralateral，Sup. Ant. Con.）、上后同侧（Superior Posterior Ipsilateral，Sup. Post. Ipsil.）、下前同侧（Inferior Anterior Ipsilateral，Inf. Ant. Ipsil.）、下前对侧（Inferior Anterior Contralateral，Inf. Ant. Con.）以及下后同侧（Inferior Posterior Ipsilateral，Inf. Post. Ipsil.）。因变量为每个象限中达到的工作空间百分比。显著性水平设为 $\alpha \ = \ 0 . 0 5 .$，所有分析均在 Python 中使用 Pingouin 工具包（v0.5.5）进行。

最后，我们评估了基于标记的系统和 MMC 系统在每个时间点上对末端执行器所处象限的判断是否一致。一致率计算为两个系统将手腕分配到同一象限的时间点百分比：

$$
\text { Agreement   Rate } = \frac {\text { Total   Agreements }}{\text { Total   Time   Points   in   Octant }} \times 100 \% .
$$

当发生不一致时，确定不一致的方向，并按如下公式计算方向误差率：

$$
\text { Directional   Error   Rate } = \frac {\text { Total   Disagreements   in   a   Direction }}{\text { Total   Time   Points   in   Octant }} \times 100 \% .
$$

例如，如果在同一时间点，基于标记的系统测得末端执行器处于 Sup. Post. Ipsil. 象限，而单目 MMC 系统将其置于 Sup. Ant. Ipsil. 象限，则该帧将被记录为 Sup. Post. Ipsil. 象限的一次不一致。因此，在计算方向误差率时，误差方向将被确定为前后（AP）方向。

## IV. 讨论

本研究表明，单相机（单目）MMC 方法可以准确量化健康成年人在 UERW 任务期间达到的目标百分比。使用冠状面相机系统获得的 UERW 测量结果与传统基于标记的动作捕捉系统的测量结果具有可比性，从而支持了单目 MMC 用于多平面、临床相关评估的可行性。据我们所知，这是首次证明单目系统在评估上肢活动度的临床应用中能够达到与基于标记的参考系统相似的性能，而以往的工作仅使用多相机系统验证了此类方法以及系统的测量精度，并未涉及临床输出 [17], [43]。其他单目方法如 [24], [28], [41] 因缺乏用于临床决策的解剖学精确模型而受到限制，但尽管如此，它们已被证明是使用单目相机评估上肢（UE）任务的有效工具。通过降低技术复杂性、设备要求和准备时间，单目 MMC 为小型临床团队或即时检验（point-of-care）环境中实施定量上肢活动度评估提供了一种实用的解决方案，从而有望提高客观运动分析在常规实践中的可及性和采纳率。

本分析中的一个重要考量是峰值触及距离（peak reach distance）的定义，该参数是事后（post hoc）分别通过 MMC 和基于标记的重构计算得出的。该参数决定了每位参与者在事后分析中的虚拟目标位置，且与参与者在头显中看到的 VR 目标放置位置略有不同。我们观察到两套系统在峰值触及距离上的差异很小（两种朝向下均为 0.04 ± 0.03 m），这很可能是由关键点定位中的系统性偏差所致。由于检测到的关键点并非刚性固定在解剖标志点上，检测中的微小偏移会在整个重构流程中传播。尽管如此，鉴于峰值触及距离的差异极小，后续 UERW 的差异主要由相机朝向引起。

两套系统的误差在很大程度上源于测量不在单目视频视野法向平面的运动所固有的难度。正面相机在后侧八分区域表现出最差的一致性，其中的深度模糊性导致了前后（AP）方向误差升高（Fig. 3）。偏置相机表现出类似的趋势，在后侧八分区域存在显著的 AP 方向误差，并在对侧八分区域存在内外侧（ML）方向误差。这些模式证实了先前的研究，即在与相机视角对齐的解剖平面内测量最为准确 [31]。误差集中在后侧和对侧八分区域表明其对透视投影约束具有敏感性。具体而言，当运动矢量与相机的光轴对齐时，由此产生的透视缩短降低了二维关键点位移的信噪比。这使得系统依赖于生物力学模型的深度估计启发式算法，而正如我们的 AP 方向误差率所证明的那样，该算法在缺乏双目或多视角一致性的情况下难以解决深度模糊性问题。

然而总体而言，正向相机朝向（frontal camera orientation）与基于标记点的评估之间未显示出统计学上的显著差异，可作为评估 UERW（特别是前部工作空间）的可行临床解决方案。每个卦限的偏差通常少于 5 个目标，远低于在上肢临床人群中观察到的功能缺损——例如在小儿臂丛神经麻痹（Brachial Plexus Palsy）患者中，患肢与健肢之间达到的目标差异在每个卦限可高达 35 个，仅 Inf. Ant. Ipsil. 和 Contra. 卦限除外，其差异小于每个卦限 10 个目标 [34]。在我们的队列中，这一差异远低于在临床人群中观察到的差异。对于伸向需要肩部抬高（这一功能在脑卒中康复者和臂丛神经麻痹患儿等患者群体中常受损）的上前卦限，正向相机配置表现良好，在四个前部卦限中的任何一个都与基于标记点的动作捕捉没有显著差异 [9], [10], [35]。这与先前在同一工作空间内执行任务的研究结果一致 [17], [43]。

相比之下，偏置相机朝向（offset camera orientation）显著低估了在几个关键区域达到的目标数量，包括上-前-对侧、下-前-对侧和下-后-同侧卦限 (Fig. 2)。这些差异突显了单目动作捕捉中基于视角的深度分辨率与解剖学遮挡之间的一个基本权衡。尽管我们的研究结果支持了单相机系统的总体可行性，但也强调了目前没有任何单一视角对于需要与相机光轴平行的动态多平面运动的任务是最优的。例如，偏置相机在上-前-对侧卦限中的一致性低于 40%，表现出较大的 ML 误差。从机制上看，这种较差的表现是由跨躯干运动引起的，在此类运动中，躯干或伸展的手臂本身会在物理上遮挡相机对手和手腕的视线。在这些遮挡期间，MMC 算法必须“推断”远端关节位置，从而导致不准确的深度估计。这与 Inf. Ant. Ipsil. 卦限形成了鲜明对比，在该卦限中，两种相机朝向都实现了较高的一致性率（> 95%）。在该区域内，运动主要发生在相机的最佳视野平面内，从而最大限度地减少了遮挡和投影缩短。因此，正向相机表现出极小的偏差（平均差异为 1.22%），而偏置相机在其他区域的持续低估则反映了当肢体的运动向量与相机镜头平行时，当前算法在解析深度方面的困难。

虽然本研究证明了单目 MMC 的可行性，但仍必须解决若干局限性以确保其临床实用性。首先，这些研究结果的泛化性受到研究队列同质性的限制，该队列完全由健康成年人组成。临床人群（例如脑卒中患者或臂丛神经麻痹儿童）通常表现出非典型的运动学特征，包括震颤、速度变慢或躯干代偿运动。目前的检测算法在面对这些神经运动病理时是否能保持其精度水平仍有待确定，因为在此处观察到的“可忽略”的误差（每个八分区域少于五个目标）在患者中可能会产生更大的功能性影响。例如，在严重的臂丛神经损伤中，患者可能仅能触及工作空间的内侧边缘，微小的深度估计误差就可能成为判定目标是否被归类为“已触及”的决定性因素。

此外，当前的分析是事后进行的，这限制了其在临床诊疗现场的即时实用性。为了将单目 MMC 纳入常规临床工作流程，从数据采集到生成可行报告的过程必须进一步简化。在解释这些结果时应当保持审慎，特别是对于局部区域的分析，因为在对侧八分区域中平均百分比误差高达 15.45%（正面 Frontal）和 50.21%（偏移 Offset）。这种高度的区域变异性表明，尽管该系统可能适用于评估总可达工作空间，但它缺乏对特定上方或对侧八分区域进行精确测量所需的一致性。未来的迭代应侧重于集成实时反馈，并利用移动平台在评估过程中提供即时生物反馈。这些改进将进一步降低技术开销，使客观运动分析在繁忙的临床环境和居家康复环境中均可普及。尽管存在这些挑战，单相机方法仍显著减少了与传统基于标记点的系统相关的设备需求和设置时间。通过解决这些空间和算法上的局限性，单目 MMC 为在多样化的临床环境中扩展客观运动分析的应用范围提供了一种可扩展的解决方案。

据我们所知，这是首项评估单目基于视频的系统在临床环境下分析上肢可及工作空间（UERW）可行性的研究。我们的结果表明，正向摄像头朝向提供的 UERW 测量结果与金标准基于标记点的动作捕捉相当，尤其是在前侧八分圆（anterior octants）区域内。通过将单摄像头配置确立为复杂多摄像头阵列的可靠替代方案，该方法显著降低了客观运动分析的技术门槛。最终，本研究为常见临床评估的自动化奠定了基础，为将定量上肢指标整合到常规即时诊疗（point-of-care）工作流程中提供了一条切实可行的途径。
