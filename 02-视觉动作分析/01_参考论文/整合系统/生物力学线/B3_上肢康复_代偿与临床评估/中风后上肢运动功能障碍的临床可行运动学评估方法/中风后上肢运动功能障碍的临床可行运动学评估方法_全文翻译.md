## 摘 要

开发针对中风后上肢运动功能障碍的可行运动学评估方法，在物理治疗和康复工程领域具有极其重要的临床意义。Microsoft Kinect 具备成为用于基于临床的中风后上肢运动功能评估的低成本、紧凑型解决方案的潜力。然而，Microsoft Kinect 在上肢运动功能评估中的可靠性尚未完全确立。因此，在将 Microsoft Kinect 用于临床应用时仍存在疑虑。通常期望任何测量程序都具备区分病理表现与正常表现的能力。另一方面，识别出能够最佳评估上肢运动功能障碍的运动学指标是任何测量方案的核心问题。本研究的主要目的是通过区分病理表现与健康表现，并确定最能评估该损伤的运动学指标，从而证明 Microsoft Kinect 在中风患者运动表现运动学分析中的稳健性/可用性。我们基于主成分分析（Principal Component Analysis, PCA），对从 Microsoft Kinect 记录的三名中风患者和两名健康受试者向前伸手动作的运动学指标进行了对比。在本研究中，除了文献中先前定义并用于量化上肢障碍的其他指标外，我们还基于 PCA 定义了一种新的关节间协调指数（inter-joint coordination index, IJCI），以捕捉伸手动作的关节间协调动态特征。我们观察到，IJCI 在检测向前伸手任务中的上肢运动功能障碍以及区分中风患者与健康对照方面具有显著的重要性。

我们希望本文能够促进客观运动学分析被常规康复实践所接纳。

## 1. 引言

最常用于偏瘫上肢运动功能的临床测量方法（如 Wolf Motor Function Test (WMFT，沃尔夫运动功能测试)）可被视为主观评价，因为它们依赖于对医师观察所获取数据的评估。这些评估方法不够灵敏，无法检测出复杂上肢运动功能缓慢改善的迹象。同时，它们也无法解释运动功能障碍潜在的生物力学特征 [1]。此外，它们主要关注给定功能性任务的完成情况，而缺乏检测任务执行方式有所改善的能力 [2]。

通过使用动作捕捉技术实现的运动学分析能够最大程度减少医师的观察误差，并通过提供客观和定量的参数，使对上肢运动功能进行客观、特异且循证的评估成为可能。运动学分析致力于基于动作捕捉系统在受试者执行特定任务期间采集的某些身体部位的 3D（三维）位置数据来实现客观评估。上肢运动功能的运动学分析取决于四个主要因素：采集受试者部分环节 3D 位置数据的动作捕捉系统（Motion capture systems）、要求受试者完成的动作类别（Movement Category）、从 3D 位置数据中提取的运动学指标（Kinematic Metrics），以及对运动学指标的解释（Interpretation of the kinematic metrics）。

基于视觉标记物的传感器（基于主动或被动标记物的光电系统）[3]、机器人设备 [4]、电磁传感器以及初始传感器 [5] 已被用作动作捕捉系统，用于与运动障碍相关的神经系统疾病的运动学分析。每种动作追踪技术都有其各自的优缺点 [6]。传感器的准确性、可靠性、紧凑性和成本，对于将运动学分析纳入常规康复治疗以及在临床和家庭环境中实施的灵活性而言至关重要。事实上，为了减轻医疗保健服务的负担和国家卫生体系的支出，对居家康复方案以及评估上肢运动功能的临床可行方法的需求日益增加 [7]。基于视觉标记物的传感器因其高准确性和高可靠性，作为运动学分析中的黄金标准得到了最广泛的应用。然而，由于运输、校准和标记物放置的困难，加上所需搭建空间大以及成本高昂，基于视觉标记物的传感器使得运动学分析的实施仅局限于研究实验室中。由于其成本低廉、结构紧凑且具备无标记骨骼追踪能力，Kinect 自 2010 年由 Microsoft 首次发布以来，日益受到康复医学领域的关注。Kinect 已被应用于老年人护理以及神经系统疾病的康复中。在文献中，已有数位研究人员探讨了通过 Kinect 与基于视觉标记物的传感器对比所获得的数据在神经系统疾病相关诊断中的潜力 [8,9]。Chang et al. 仅表明，当 Kinect 放置在受试者正前方时，从 Kinect 和 Opti-Track 获得的肘部和肩部角度变化曲线足够接近 [10]。Clark et al. 表明，与从基于视觉标记物的动作追踪系统（VICON）获得的数据相比，Microsoft Kinect 提供的解剖标志点位移和躯干角度数据具有极佳的同期效度。同时该研究还指出，Microsoft Kinect 可在广泛患者群体的临床应用中使用 [11]。Olesh et al. 表明，通过 Kinect 和基于视觉标记物的传感器获得的上肢关节角度具有相关性 [12]。以往研究的结果前景良好，表明 Kinect 能够提供可靠的工具来客观评估脑卒中后的上肢运动功能。因此，我们无需将 Microsoft Kinect 获取的数据与基于视觉标记物的动作追踪系统获取的数据进行对比。

一个亟待解决的重要问题是：确定能够最佳评估脑卒中患者上肢运动功能损伤的运动学指标，并结合治疗效果对这些指标进行解释 [13]。目前，关于上肢的运动学指标仍然较为匮乏 [14]。然而，关于如何解读这些复杂数据的信息依然缺失 [15]。每个指标都评估了上肢运动的某一特定特征。因此，指标的选择取决于要求受试者完成的运动类别。运动学分析中的运动类别包括伸展动作（点到点伸展）、路径绘制以及日常生活活动（ADL）。然而，大多数脑卒中幸存者由于手部抓握功能受损，往往难以完成任何 ADL（例如拿杯子）[16]。上肢点到点伸展动作相关的运动学指标可分为两类：末端（手部）运动学指标和关节运动学指标 [17]。末端运动学指标通常仅通过手腕上单个标记点的三维笛卡尔坐标进行计算。手腕位移的峰值速度、运动平滑度、运动直线度属于末端运动学，而关节间协调性和关节活动度则属于关节运动学。用于量化代偿策略的躯干位移也可以被归入关节运动学中。末端运动学可被视为运动表现（motor performance），而关节运动学和躯干运动则可被视为运动质量（movement quality）[18]。Subramanian 等人 [18] 指出，在伸手抓握任务中，躯干位移是唯一能够区分脑卒中患者不同损伤程度的变量，并提出运动质量变量在识别上肢功能缺陷方面更为敏感。van Dokkum 等人 [19] 则认为，在伸手抓握任务中，运动表现运动学指标（运动时间、轨迹长度、直接度、平滑度、手部的平均速度和最大速度）对时间变化具有敏感性，并能够区分偏瘫侧肢体、非偏瘫侧肢体和健康肢体的运动。Murphy 等人 [13] 称，在伸展以及从水杯喝水的动作中，运动单元数量（运动平滑度）、总运动时间、速度以及肘关节峰值角速度能够最有效地将健康受试者与脑卒中患者区分开来，并能有效区分中度与轻度手臂损伤患者。因此，显然这些指标的响应在不同试验之间存在差异，并且可能取决于脑卒中人群的人口统计学特征以及受试者在测量过程中被要求执行的功能性任务。同样值得强调的是，上述所有针对脑卒中患者上肢运动缺陷的运动学分析研究均采用了基于光学标记的传感器，而这类传感器可能并不非常适用于临床或家庭环境。

脑卒中患者的伸手动作以病理性协同作用为特征，表现为被称为伸肌协同模式（肩部伸展和内收结合肘部伸展）的粗大伸肌运动障碍，或被称为屈肌协同模式（肩部屈曲和外展结合肘部屈曲）的粗大屈肌运动障碍 [20]。然而，许多关于脑卒中患者上肢运动缺陷运动学分析的报道研究均未包含任何用于量化关节间动力学的指标。Cirstea 等人 [21] 描述了一种基于相图（运动速度作为位移的函数）和关节间相对相位关系的技术。然而，该技术没有单一的指数。相反，该技术（时间协调（TC）指数）由四个运动片段组成，并结合了每个片段的幅度和持续时间数值。因此，我们认为 TC 指数计算量大且不易于解释。此外，相图对原始数据的滤波很敏感，尤其是以 30 fps（每秒帧数）由单个 Kinect 记录的数据。另一种量化关节间协调性的替代方法是主成分分析（PCA），更具体地说是协方差矩阵的特征值 [22,23]。利用 PCA 的特征值，可以比时间协调（TC）指数以更紧凑的方式量化关节间协调性。

本研究的主要目的是展示 Microsoft Kinect 在临床应用中对脑卒中患者上肢运动缺陷进行运动学分析的稳健性/可靠性。将脑卒中患者的病理表现与健康受试者区分开来，并确定最能评估上肢运动功能障碍的运动学指标，对于任何基于运动学分析的评估方法而言都是非常重要的特征。通过证明使用 Microsoft Kinect 的运动学分析具备这些特征，我们证明了 Microsoft Kinect 是一种高度可靠且易于应用的运动捕捉系统，可用于临床中脑卒中患者的运动学分析。

## 2.3. 传感器与预处理

本文采用 Microsoft Kinect 作为动作捕捉技术。于 2010 年发布的 Microsoft Kinect v1，旨在通过基于手势的自然用户界面使用户能够与游戏互动，从而无需触碰游戏控制器。然而，由于其低成本但高技术的深度传感器技术，它迅速被“破解”并广泛应用于从医疗领域到机器人技术的各种应用中。Kinect 包含一个深度传感器、一个彩色相机（RGB 相机）和一个四麦克风阵列 [25]。骨骼上某些点的 3D 位置数据的提取依赖于 Kinect 上的深度传感器。深度传感器由红外（IR）投影仪和 IR 相机组成。深度传感器能够像 RGB 相机一样生成图像，但每个像素值对应的不是颜色，而是到该点的距离。深度传感器的基本工作原理即结构光技术，是通过其 IR 投影仪投射出红外光图案，并通过其 IR 相机根据光的反射来估计深度 [26]。作为 Kinect v1 改进版本的 Kinect v2 于 2014 年实现商业化发布，可提供高分辨率深度图像、30 fps 的彩色图像以及人体追踪能力（见 Table 2）。Kinect v2 的深度传感器基于 TOF（飞行时间，time of flight）原理工作 [27–29]。配合 Microsoft Kinect SDK（软件开发工具包，Software Development Kit）2.0 的 Kinect v2 能够提供人体上 25 个关节的实时 3D 位置坐标（见 Fig. 2）。在我们的研究中，使用了配合 SDK 2.0 的 Microsoft Kinect v2。

用于人体运动学分析的各种运动捕捉传感器都会产生测量误差，这些误差在记录的运动学信号中表现为噪声。记录的原始数据中的噪声会严重影响上肢运动功能的运动学分析。因此，在进行运动学分析之前，应当对记录的原始信号进行滤波。奇异谱分析（Singular spectrum analysis, SSA）

在本研究中被用作滤波技术。在平滑原始运动学信号方面，SSA 的性能优于文献 [31] 中报道的滤波技术，如数字巴特沃斯滤波器、样条函数、离散小波变换和维格纳分布函数。

SSA 的目标是将原始序列分解为少数几个独立成分的和，例如缓慢波动的趋势项、振荡成分以及无结构噪声 [32]。在此简要介绍 SSA 算法。考虑代表含噪信号的长度为 N 的时间序列 $Y = ( y _ { 0 } , y _ { 1 } , \dots , y _ { N - 1 } )$。

步骤 1（嵌入）：第一步是通过滑动一个短于原始信号长度的窗口，从时间序列中生成一个汉克尔（Hankel）矩阵。加窗处理生成多维序列 $X _ { 1 } , \ldots , X _ { k }$，其向量为 $X _ { i } = ( y _ { i } , \ldots , y _ { i + L - 1 } ) ^ { T }$，其中 $K = N - L + 1$。该步骤的结果是汉克尔矩阵，亦即所谓的轨迹矩阵 $\mathbf { X } = [ X _ { 1 } , \ldots , X _ { K } ]$。

步骤 2（矩阵 $X X ^ { T }$ 的奇异值分解）：计算矩阵 $\mathsf { X X } ^ { T }$ 的特征值和特征向量，使得 $\lambda _ { 1 } \geqslant \lambda _ { 2 } \geqslant \dots \lambda _ { L } \geqslant 0$ 为降序排列的特征值，而 $U _ { 1 } , U _ { 2 } , \dots , U _ { L }$ 为 $X X ^ { T }$ 对应的特征向量。然后，汉克尔矩阵 X 可以写成 $X = E _ { 1 } + E _ { 2 } + \cdots + E _ { L } $ 的形式，其中 $E _ { i } = \sqrt { \lambda _ { i } } U _ { i } V _ { i } ^ { T }$ 且 $V _ { i } = X ^ { T } U _ { i } / \sqrt { \lambda _ { i } }$<sub>。初等矩阵 E 的范数等于</sub> $\sqrt { \lambda _ { i } } .$ <sub>因此，初等矩阵的贡献</sub>对应于较大的特征值，对……的范数做出贡献

远高于较小者，且对应于较小特征值的基本矩阵很可能代表信号中的噪声。

步骤 3（分组）：分组是将对应于较大特征值的前 $r$ 个基本矩阵相加。随后，得到轨迹矩阵 $X$ 的近似矩阵 ${ \overline { { X } } } = X _ { 1 } + \cdots + X _ { i }$。

步骤 4（重构）：通过计算近似矩阵 $X$ 的对角线平均值，恢复出代表含噪信号的原始时间序列 $Y$ 的近似时间序列。

SSA 算法取决于两个参数：窗口长度 $L$ 以及从轨迹矩阵近似中计算出的最大特征值数量 $r$。SSA 算法的缺点在于没有通用的规则来选择它们。参数的选择取决于对信号的预期。在我们的研究中，我们尝试对朝向桌子的伸手动作进行量化。手腕（或手）在动作前（当手处于等待开始伸手动作状态时）和动作后（当手放置在桌面上时）的运动速度应近似为零。伸手动作期间的速度应呈现出良好的钟形。轨迹矩阵是通过滑动一个长度为 15 个元素的窗口生成的。窗口长度是通过试验确定的。第一个特征值占所有特征值总和的 99.96%（见 Fig. 3）。因此，仅使用对应于最大特征值（$r = 1$）的单个基本信号即可重构信号。Fig. 4 显示了 SSA 算法的结果。正如所预期的，在等待和伸手动作完成后，速度近似为零。此外，健康受试者在伸手动作期间的速度呈现出良好的钟形。

## 2.4. 记录方法与数据分析

运动学指标在上肢的末端/任务空间（末端运动学或动作表现运动学）或关节空间（关节运动学或动作质量指标）中进行定义。速度曲线被认为与运动控制的有效性相关 [19]。健康的点对点伸展运动具有平滑且呈良好钟形的末端速度曲线。为量化末端速度的平滑度，迄今为止已使用了各种指标，例如归一化平均绝对加加速度（normalized mean absolute jerk）、速度曲线中的峰值数量以及归一化平均速度 [33,34]。在本研究中，基于傅里叶幅度谱的谱弧长（spectral arc-length）指标被用于量化点对点伸展运动过程中末端的平滑度。Balasubramanian 等人 [35] 测试并将谱弧长指标与其他平滑度指标进行了对比，得出结论认为该指标在对运动行为改变的敏感性以及对测量噪声的鲁棒性方面均优于其他指标。

在任务空间中定义的其他指标包括末端最大速度，以及使用曲率指数（Index of Curvature, IC）估计的末端直线度，该指数定义为路径长度与初始末端位置至最终末端位置之间的视线距离之比 [36]。在脑卒中患者的伸展运动过程中，运动代偿可包括过度躯干位移以及肩部和肘部角度之间关节间协调性的破坏 [37]。为量化运动代偿，本研究检测了伸展运动过程中的躯干位移以及肩部屈曲/伸展与肘部屈曲/伸展之间的关节间协调性。关节间协调性曾通过时间协调（Temporal Coordination, TC）指数 [21] 和主成分分析（Principal Component Analysis, PCA）[22] 进行评估。在本研究中，采用 PCA 来测量上肢的关节间协调性。

为了构建末端空间中的运动学指标，我们计算了记录的手腕点笛卡尔坐标的欧几里得范数：$W _ { i } =$ ${ \sqrt { x _ { i } ^ { 2 } + y _ { i } ^ { 2 } + z _ { i } ^ { 2 } } } , i = 1 \cdots n$，其中 $( x _ { i } , y _ { i } , z _ { i } )$ 是从 Kinect 记录的手腕笛卡尔 3D 坐标，n 为记录的总帧数。对 $W _ { i }$ 进行逐帧微分得到速度，速度的绝对值即为速率。动作的起始点和终止点被确定为速率超过或低于手腕最大峰值速率 10% 的帧。曲率指数（IC）也是通过使用 $W _ { i } .$ 来定义的。躯干位移是根据脊柱肩部（spine shoulder）的 3D 坐标计算得出的。

## 2.5. 主成分分析（PCA）

主成分分析（Principal Component Analysis, PCA）将若干可能相关的变量转换为较少数量的变量，这些变量称为主成分，它们互不相关且按顺序排列，使得前几个主成分保留了所有原始变量的大部分变异 [38]。PCA 的核心思想是使转换后数据中的变量尽可能互不相关。PCA 使得更容易发现数据中存在的趋势和模式 [39]。

此处包含了主成分分析（PCA）的简要技术细节。设 $X$ 为一个 $m \times n$ 矩阵，其中 $n$ 列为样本，$m$ 行为变量。为确保每一行的均值为零，从每个元素中减去对应的行均值。构建协方差矩阵 $\begin{array} { r } { C _ { X } = ( 1 / ( n - 1 ) ) X X ^ { T } } \end{array}$。然后，对协方差矩阵进行奇异值分解（SVD），$\boldsymbol { C _ { X } } = \boldsymbol { U } \boldsymbol { \Sigma } \boldsymbol { V } ^ { T }$。最后，将原始数据集 $X$ 转换为新数据集 $\boldsymbol { Y } = \boldsymbol { V } ^ { T } \boldsymbol { X } .$。结果表明，对于 $k = 1 \cdots m ,$，第 $k$ 个主成分（PC）由 $y _ { k } = \alpha _ { k } ^ { T } X$ 给出，其中 $\alpha _ { k }$ 是 $C _ { X }$ 对应于其第 $k$ 大特征值 $\lambda _ { k } .$ 的特征向量。此外，$y _ { k }$ 的方差等于 $\lambda _ { k } .$。PCA 的目标是通过在少数几个主成分中最大化方差来降低数据维度。对应于最大特征值的主成分解释了原始数据中存在的最大方差，因此是对原始数据集的良好表征。

## 2.6. 关节间协调指数（IJCI）

关节间协调指数基于 PCA 进行评估。对关节角度进行标准化处理，使其具有零均值和单位方差（标准分或 z-score）。设 $S = \left( s _ { 1 } , \ldots , s _ { n } \right) ^ { T }$ 和 $\boldsymbol { E } = ( e _ { 1 } , \ldots , e _ { n } ) ^ { T }$ 分别为肩关节和肘关节角度的标准分。随后，基于 $n \times 2$ 矩阵 $X = [ S E ]$（其中 2 列为观测值（关节角度），$n$ 行为变量（帧））执行 PCA。用于解释数据集中最大方差的最大特征值被用来评估关节间协调。

## 3. 结果

在物理治疗和康复工程中，开发卒中后上肢运动功能障碍的可行运动学评估方法具有极其重要的临床意义。

在健康受试者和患者受试者中，手腕速度（手部速度）曲线均平滑且呈钟形（参见 Fig. 6）。因此，在各个患者组和健康组中，平滑度指标（谱弧长指标）和曲率指数（Index of Curvature）彼此接近（参见 Table 3）。先前的研究报道，在患者受试者中，末端（手部）速度曲线并不平滑，速度曲线具有多个峰值。这种情况表明他们的手在完成伸触任务之前改变了方向，并且该任务是通过一系列连续的微小运动来完成的 [13,19,21]。在本研究中，我们的结果与先前的研究相悖。我们推测，各研究之间在平滑度和曲率指数上的差异与要求受试者完成的不同运动任务有关。在这项工作中，我们没有指定要到达的具体目标点，而是要求受试者将手放置在桌子上的任意位置。与每位健康受试者相比，每位患者受试者的最大速度均较低（参见 Fig. 6 和 Table 3）。与每位健康受试者相比，患者的躯干位移更大（参见 Table 3）。在健康受试者和患者受试者中，肩关节角度均呈单调增加（Fig. 6）。然而，实际的差异表现在肘关节角度曲线上。肘部运动比肩部运动更为复杂，由最初的屈曲运动继以伸展运动组成。患者受试者在屈曲后的肘关节伸展并未像健康受试者那样完成（参见 Fig. 6）。这种未完全完成的运动是指关节间协调受损的一个指标。与每位健康受试者相比，所有患者的关节间协调指数均更高。高关节间协调指数意味着（肩关节和肘关节角度标准分之间的）高方差，表明关节间协调受损。较小的特征值（或方差）意味着关节角度的标准分往往彼此非常接近，而较大的特征值则意味着关节角度的标准分彼此分散较大（参见 Fig. 7）。

## 4. 讨论与结论

定量检测上肢运动功能障碍的改善水平是非常必要的。为此，确定能够以最佳方式定义改善水平的参数/特征至关重要。期望任何测量程序都具备区分病理表现与正常表现的能力 [40]。本研究实现了这一点。

本研究的结果表明，前向伸展运动表现中的病理性改变主要出现在关节空间，而非末端空间。显而易见，关节间协调性的量化将在物理治疗医师的临床应用中发挥重要作用。然而，已有报道的大多数运动学测量方案均未包含用于量化关节间协调性的指标。Cirstea 等人 [21] 描述了一种基于相图（运动速度作为位移的函数）以及关节间相对相位关系的技术。然而，该技术并未提供单一指标。相反，时间协调（Temporal Coordination, TC）指数技术由四个运动阶段组成，并结合了每个阶段的振幅和持续时间数值。但是，TC 指数计算量大且不易于解释。此外，TCI 需要绘制速度-角度图。因此，该指数对平滑技术十分敏感，并且在使用 Microsoft Kinect v2 捕捉脑卒中患者的关节间协调紊乱时可能需要更多的计算工作量。在本研究中，我们提出了一种基于 PCA（主成分分析）的更为紧凑且简单的方法，仅使用单个参数来量化关节间协调性。我们推测，在端点空间中定义的指标缺乏区分性是由于运动表现任务所致。在该研究中，受试者被要求将手放置在桌面上的任意位置。对于点对点伸展或目标导向任务，躯干位移、最大速度和关节间协调指数等所有参数/特征也可以在上肢运动功能表现测量中发挥重要作用。在本研究中，我们将关节间协调指数（IJCI）定义为肩关节和肘关节伸展/屈曲角度的 PCA 最大方差。我们表明，IJCI 在区分脑卒中患者与健康受试者的病理性表现方面具有极其显著的效果。

脑卒中康复的主要目的之一是恢复日常生活活动（ADL）的功能独立性。由于伸展动作是实现许多日常生活任务的关键运动功能，许多脑卒中患者即使在慢性期也无法恢复其 ADL 的独立性 [41]。因此，上肢运动功能的恢复是脑卒中幸存者的主要目标 [42]。脑卒中幸存者康复的第一阶段是评估，这需要对损伤、患者需求、残疾、残障以及医疗问题进行识别、测量和记录 [43]。识别限制正常运动的损伤是评估受累上肢的关键因素。运动损伤评估得出的结果可引导临床医生制定治疗方案，并为康复进程做出贡献 [44]。

在脑卒中（中风）患者的运动学运动分析中，基于视觉标记的传感器由于其高精度和可靠性，曾作为金标准被最广泛地应用。因此，用于脑卒中患者运动学分析的测量流程和运动学指标大多是依据基于视觉标记的传感器来设计和构建的。尽管临床医生被鼓励评估患者的功能状态，但一些报告指出，他们在常规操作中并没有这样做 [45]。如果采用合适的方法，Microsoft Kinect 也可以作为一种替代方案，应用于临床中脑卒中幸存者的运动学分析。

根据 Table 3 中参数的测量结果，健康受试者和患者受试者的最大速度（Maximum Speed, MS）参数均值分别为 0.64 和 0.48。这两个数值之间的较小差异表明，随着患者康复程度的进展，该参数值的变化非常小。对于患者和健康个体，曲率指数（Index of Curvature, IC）和谱弧长（Spectral Arc-length, SA）的数值彼此非常接近。这种情况归因于本研究所考察的特定伸展动作。因为每位患者在进行日常活动时所遇到的身体困难可能各不相同。在不同任务的表现测量中，这些参数被认为是区分健康受试者和患者受试者的一个显著特征。躯干位移（Trunk Displacement, TD）参数在健康受试者中的均值为 0.02，而在患者个体中处于（0.14–0.29）的范围内。该参数对于监测上肢运动功能障碍患者的康复程度具有高度显著性。在常规临床实践中，该参数值的降低将表明患者康复水平的提高。关节间协调指数（inter-joint coordination index, IJCI）参数完全有资格成为文献中的一种替代指标。它是本研究中获得的最重要特征之一。健康受试者和患者受试者的 IJCI 均值分别为 6.36 和 11.00。患者之间的 IJCI 值彼此非常接近，且与健康个体的均值相差甚远。如图 Fig. 9 所示，该参数起到了区分健康受试者和患者受试者的分类器作用。此外，患者的康复程度将与该参数值的下降成比例。

在本研究中，所提出的参数为在上肢运动功能运动学评估中检测患者和健康个体的改善程度提供了极其重要的契机。我们相信，本研究将通过消除评估方法的使用障碍，促进运动学分析被常规临床方案所采纳，并助力脑卒中幸存者的康复。
