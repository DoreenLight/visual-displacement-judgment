# 基于运动表现的绳驱动上肢康复机器人混合控制

Xianming Li , Qianqian Yang , and Rong Song , Senior Member, IEEE

摘要—中风后患者由于残疾程度不同，可能具有不同的康复需求。为了满足这些需求，本文针对绳驱动上肢康复机器人（CDULRR）提出了一种基于运动表现的混合控制方法。该控制器包含三种工作模式，即阻力模式、助力模式和限制模式；由于跟踪误差是表征运动表现的常用指标，模式之间通过跟踪误差进行切换。在阻力模式下，为受试者提供与实际速度方向相反的适当阻尼力。在助力模式下，采用模糊逻辑调节刚度系数的方法，以提供适度的助力来协助受试者。在限制模式下，再次施加阻尼力以限制运动并确保安全。为了验证控制器的有效性，十名健康受试者进行了具有不同干扰的面向任务的实验。实验结果表明，控制器能够根据受试者的运动表现调整工作模式。研究发现，随着干扰增加导致运动表现下降，机器人在训练中提供了更多助力。阻尼力和刚度系数的自适应调节使控制器能够激发更多的主动参与度。

索引术语—中风，上肢康复，绳驱动机器人，按需辅助控制。

## I. 引言

三分之二的患者存在影响日常生活活动（ADL）的不同程度运动障碍。康复训练可以通过在细致指导下进行充分的重复练习来帮助患者恢复运动功能 [2]。传统的康复治疗属于劳动密集型，而康复机器人可以提供高度聚焦且重复的训练。此外，基于临床结果已证明，机器人辅助康复训练对恢复运动功能具有积极效果 [3], [4]。

机械结构在机器人辅助康复训练中起着重要作用。在过去的几十年中，大量具有不同机械结构类型的机器人被应用于上肢康复训练，它们可分为具有单一连杆和驱动关节序列的串联机器人，以及具有多条运动链连接末端执行器的并联机器人 [5]。在串联机器人中，一些末端执行器型机器人（如 MIT-MANUS [6]、MIME [7] 和 ARC-MIME [8]）已成功应用于临床上肢治疗。此外，外骨骼机器人（如 ARMin [9]、RUPERT [10] 和 CADEN-7 [11]）被开发用于辅助上肢关节。这些串联机器人可以为患者提供充分的支撑。在现有的并联机器人中，CUBE [12]、PARM [13] 以及一种并联肩部外骨骼机器人 [14] 被设计用于康复训练。相比于串联机器人，并联机器人具有一些优势，例如运动控制精度高以及结构简单。

绳驱动康复机器人（Cable-driven rehabilitation robots, CDRR）作为一种并联机器人，由缆绳驱动并将电机置于远离末端执行器的位置 [15]。这类机器人具有工作空间大、惯量低和柔顺结构等先进特性。NeReBot 采用三根缆绳开发，用于脑卒中后上肢康复 [16]。Sophia-3 是一种平面绳驱动装置，其特点是带有一个移动滑轮组，使机器人能够实现显著的力输出能力 [17]。D. Cafolla 等人设计了一种用于临床和家庭训练的绳驱动并联机器人 CUBE [12]。此类末端执行器结构具有易于设置且适用于不同患者的优点，但对上肢关节的控制有限。为了辅助整个手臂，目前已设计出一些绳驱动手臂外骨骼机器人，例如 CAREX [18] 和 CAREX-7 [19]。

康复机器人的控制策略对其性能也起着至关重要的作用。一些控制器（如阻抗控制 [6]、比例-积分-微分（PID）控制 [20]、滑模控制器 [21]）已被用于康复机器人，以辅助肢体并使患者在或多或少的被动模式下完成预定轨迹。根据感觉运动整合理论，患者的主动参与被认为是促进运动功能康复的关键因素 [22]。按需辅助（assist-as-needed, AAN）控制策略可以激发患者的主动努力，机器人仅在患者需要时才提供辅助 [23]。Teramae 等人设计了一种基于 EMG 的模型预测控制的新型 AAN 控制器 [24]，其中 EMG 信号用于估计人体主动力矩。因此，可以保证完成任务所需的力，并且跟踪误差最终可稳定在相对较低的值，但这可能会导致训练松懈，尤其是对于轻度或中度功能障碍的患者。

需要指出的是，训练误差可能是影响人体运动学习的关键因素。Patton 等人在涉及 18 名中风幸存者的实验中发现，与帮助受试者减少误差的疗法相比，误差增强疗法恢复了显著的后效（after-effects）[25]。因此，控制器应能够容忍一定程度的训练误差，以促进患者的运动再学习。Wu 等人提出了一种基于最小干预的固定参数导纳控制器，其中包括基于跟踪误差的三种控制模式 [26]。然而，固定的机器人辅助水平无法适用于所有患者，控制器应能够根据患者的运动表现来调整辅助水平。此外，基于表现的控制器在绳索驱动康复机器人（CDRR）中的应用较少。由于处于不同运动障碍程度和康复阶段的患者需要针对个体特定的训练任务和积极的主动参与，本研究提出了一种基于表现的混合控制方法，用于绳索驱动上肢康复机器人（CDULRR）根据患者的运动表现切换训练模式，以激发患者自身的努力。此外，在辅助模式下设计了一种新型自适应模糊逻辑调节器，用于自适应且动态地调整机器人辅助水平，以避免患者对机器人辅助产生依赖。

本文的组织结构如下：首先，介绍了 CDULRR 的结构、运动学、动力学和工作空间分析。其次，提出了一种基于表现的混合控制方法。第三，通过 10 名健康受试者的实验对控制器的性能进行了评估。最后，给出了本研究的讨论和结论。

## II. 材料与方法

## B. 控制律

图 4（Fig. 4）展示了基于性能的混合控制策略的总体结构。具有不同训练需求的患者需要不同的训练模式。因此，有必要设计合理有效的模式来促进康复训练。

共有三种模式通过轨迹跟踪误差进行切换 [26]，如图 5（Fig. 5）所示。当跟踪误差较小时，机器人工作在阻力模式。在该模式下，受试者被认为具有完成任务的充足能力。此时机器人施加阻力以增加训练难度，这要求受试者在训练中付出努力。当跟踪误差较大时，选择助力模式。在这种情况下，受试者无法完成任务。因此，有必要提供一些积极的助力，以防止受试者因表现不佳而失去信心。然而，在某些情况下，如果误差变得过大，机器人将工作在限制模式。在这些情况下，应考虑采取一些措施以保护受试者免受伤害。

在训练中，受试者可以对末端执行器施加主动力 $\mathbf { } F _ { h }$ 以完成轨迹跟踪。考虑到末端执行器的质量和加速度较小，参考公式 (2)，$\mathbf { } F _ { h }$ 计算为 $- \mathbf { { \cal F } } _ { c }$。轨迹跟踪误差 $e$ 可利用动作捕捉系统计算。基于该跟踪误差，控制器将选择适当的模式以在末端执行器上提供机器人作用力 $\boldsymbol { F } _ { r }$。然后，末端执行器的期望位置 $P _ { d }$ 可以通过导纳控制推导如下：

$$
\boldsymbol {P} _ {d} = \left(\boldsymbol {F} _ {h} + \boldsymbol {F} _ {r}\right) \cdot \left(M _ {d} s ^ {2} + B _ {d} s + D _ {d}\right) ^ {- 1},\tag{7}
$$

其中 $M _ { d } , B _ { d }$ 和 ${ \cal D } _ { d } ~ \in ~ { \cal R } ^ { 3 }$ 分别为导纳滤波器的惯性矩阵、阻尼矩阵和刚度矩阵。换言之，机器人作用力和人力根据导纳关系共同决定 $P _ { d }$。最后，采用比例微分（PD）控制来跟踪 $P _ { d }$。此外，模式设计的细节将在接下来的三个小节中给出。

1) 阻力模式：轨迹跟踪误差 e 可定义为

$$
e = \left\| \boldsymbol {P} _ {\boldsymbol {t}} - \boldsymbol {P} _ {\boldsymbol {a}} \right\| _ {2},\tag{8}
$$

其中 $P _ { a }$ 为末端执行器的实际位置，$P _ { t }$ 为末端执行器的期望训练位置。当 $e \in [ 0 , r _ { R } ]$ 时，CDULRR 工作在阻力模式。阻力定义为与末端执行器实际速度 $V _ { a }$ 方向相反的阻尼力 $\mathbf { \nabla } _ { F _ { d } }$。此外，助力定义为从实际位置指向期望训练位置方向的刚度力 ${ \boldsymbol { F } } _ { s }$。在阻力模式下，${ \boldsymbol { F } } _ { s }$ 和 $\mathbf { \nabla } _ { F _ { d } }$ 可通过下式计算：

$$
\left\{ \begin{array}{l} \boldsymbol {F} _ {d} = - \frac {\boldsymbol {K} _ {d} \cdot (\boldsymbol {r} _ {R} - e)}{\boldsymbol {r} _ {R}} \cdot \boldsymbol {V} _ {a}, \text {   if   } \mathbf {e} \in [ 0, \boldsymbol {r} _ {R} ], \\ \boldsymbol {F} _ {s} = 0 \end{array} \right.\tag{9}
$$

其中 $K _ { d }$ 为 $\phantom { - } 1 3 \times 3$ 正对角阻尼矩阵。值得注意的是，在相同速度下，阻尼力随着误差的增大而减小，这表明当受试者的运动表现下降时，所受到的阻力会减小。

2) 助力模式：在偏差持续增大且 $e \in ( r _ { R } , r _ { A } ]$ 的情况下，采用助力模式。我们可以将阻尼力和助力定义如下：

$$
\left\{ \begin{array}{l} \boldsymbol {F} _ {d} = 0 \\ \boldsymbol {F} _ {s} = \boldsymbol {K} _ {s} \cdot (\boldsymbol {e} - \boldsymbol {r} _ {R}) \cdot \boldsymbol {n} \end{array} , \text {   if   } \mathbf {e} \in [ \boldsymbol {r} _ {R}, \boldsymbol {r} _ {A} ], \right.\tag{10}
$$

$$
n = \frac {P _ {t} - P _ {a}}{e},\tag{11}
$$

在相同的误差水平下，较大的刚度系数可以提供较高的 $\boldsymbol { F } _ { s }$ 值。然而，采用固定参数无法满足根据不同情况进行个性化调整的需求。在本研究中，采用双输入单输出模糊逻辑整定器来调整刚度系数，该整定器能够有效应对系统的不确定性和时变特性。误差 e 及其变化率 ec 作为输入，刚度系数增量 $\Delta K _ { s } ,$ 作为输出。模糊集通过三角隶属度函数定义，包括 NB（负大）、NM（负中）、NS（负小）、ZO（零）、PS（正小）、PM（正中）和 PB（正大）。根据实验的先验经验制定推理规则，如 Table II 所示。我们在辅助模式下对跟踪性能与受试者的主动努力进行了权衡。如果误差趋于减小，则应采用较小的刚度系数，以引导受试者做出这种主动且正确的努力。反之，随着误差趋于增大，则应采用较大的刚度系数，以帮助受试者有效减小跟踪误差。在解模糊过程中，$\Delta K _ { s }$ 通过面积中心法（center-of-area, COA）计算。最后，刚度系数矩阵 $\pmb { K } _ { s }$ 更新如下：

3) 限制模式：当误差大于 $r _ { A } .$ 时，选择限制模式。如果受试者在机器人的辅助下仍无法减小跟踪误差，我们认为训练难度过大，应停止并调整训练。

$$

通常情况下，健康受试者在此类训练中表现良好，机器人几乎完全在阻力模式下工作。为了验证控制器不同工作模式的效果，在训练期间对受试者施加了不同程度的扰动，以降低其运动表现。在本研究中，设计了具有不同扰动力的四类任务，如表 IV 所示。在每个任务中，以 1 HZ 的频率沿 X 轴和 Z 轴施加扰动力，其幅值设置为不同的随机值。

在实验前，受试者可以完成一些简单的任务，直至熟悉 CDULRR 的使用。实验开始后，任务被随机分配给受试者，即 D0、D1、D2、D3。受试者被要求尽全力跟随目标，且未被告知他们正在完成哪一组实验。在每项任务结束时，参与者将休息 2 分钟。软件中的力保护算法用于将线缆张力限制在安全范围内。在紧急情况下，可以通过急停按钮立即停止整个系统以确保安全。

在实验中，采集了末端执行器的运动学数据和四根线缆的张力。为了评估运动表现，计算了实际位置与目标位置之间的平均绝对误差（MAE），其定义如下：

$$
M A E = \frac {1}{N} \sum_ {j = 1} ^ {N} \| P _ {a} (j) - P _ {t} (j) \| _ {2},\tag{15}
$$

为了分析来自 CDULRR 的助力，平均助力（AAF）定义如下：

$$
\boldsymbol {A} \boldsymbol {A} \boldsymbol {F} = \frac {1}{N} \sum_ {j = 1} ^ {N} \left(\| \boldsymbol {F} _ {\boldsymbol {s}} (\boldsymbol {j}) \| _ {2} - \| \boldsymbol {F} _ {\boldsymbol {d}} (\boldsymbol {j}) \| _ {2}\right).\tag{16}
$$

在此我们将阻尼力的值定义为负，刚度力的值定义为正。负的 AAF 表明机器人施加的力更多以阻尼力的形式存在，而正值则表明该力更多以刚度力的形式存在。AAF 越小，受试者的运动表现越好。

为了确定四种扰动力设置对十名受试者的平均 MAE 和 AAF 的影响，鉴于样本量较小，采用了 Kruskal-Wallis 检验。显著性水平设置为 $\mathrm { P } < 0 . 0 5$。若主效应显著，我们使用 Wilcoxon 符号秩检验作为事后检验，以进行 D0-D3 之间的多重比较。采用 Bonferroni 校正来调整显著性水平，将其除以进行的 6 次检验 $( \mathrm { P } < 0 . 0 0 8 )$。

## V. 讨论

针对上肢康复训练设计了一种具有四绳结构的 CDULRR。本研究提出的基于运动表现的混合控制包含三种不同的训练模式，通过跟踪误差进行切换，以在确保安全的同时激发受试者的主动参与。利用该 CDULRR 进行了一系列扰动实验，以验证该控制策略的性能。

使用绳索驱动机器人进行上肢康复训练的研究此前已有报道 [16], [34]，且采用了由三根绳索组成的绳索悬吊式结构。基于一个 $n$-DOF 绳索驱动平台至少需要 $n + 1$ 根绳索才能完全约束系统 [17], [27]，此类悬吊结构属于欠约束结构，必须依赖上肢的重力来维持所有绳索中的正张力，特别是在向上运动期间 [35]。我们的 CDULRR 通过增加一根朝下的绳索构成四绳完全约束结构改善了这些限制，该结构可以利用冗余绳索在各绳索中设定所需的正张力分布 [36]。另一种采用八根绳索的 6-DOF CDRR 则需要复杂的控制器来分配期望张力 [37]，且绳索干涉往往会阻碍康复训练中的有效工作空间。在我们的 CDULRR 中，这种四绳结构在降低控制复杂性与获取大工作空间之间实现了权衡。

传统的 AAN 控制器具有减小运动误差的效果，但可能会导致患者产生惰性，特别是对于轻度或中度功能障碍的患者 [23], [24]。运动学习方面的研究强调，误差是康复训练中驱动人类运动再学习的关键信号 [25], [38]。在本研究中，当误差小于 $r _ { R }$ 时，表明受试者能够较好地完成任务，机器人工作在阻力模式而非辅助模式，以提供阻尼力来增加训练难度并避免产生惰性。许多研究报告表明，这种抗阻型训练可以帮助中风后患者改善运动功能 [39]–[41]。此外，所提出的控制器采用模糊逻辑整定器（fuzzy logic tuner）来调整辅助模式下的刚度系数，这与以往研究中具有固定刚度系数的刚度力不同 [26], [42], [43]。由于患者的功能障碍程度因人而异，固定系数无法满足康复训练的实际需求，而我们的控制器可以通过模糊逻辑整定器根据误差及其变化率来调整刚度系数。模糊逻辑整定器无需建立精确的数学模型，可以利用人类的实践经验和类人的模糊推理能力作为机器人控制的智能调节方法 [44]。它已被广泛应用于康复机器人的控制中 [45]–[47]，但其中大部分仅旨在提高受外部扰动时的轨迹跟踪能力。与以往设计的模糊逻辑整定器不同，本研究在辅助模式下设计了一种新型模糊逻辑整定器，自适应且动态地调整机器人辅助水平，以避免患者对机器人辅助产生依赖。一旦跟踪误差及其变化率减小，系统就会选择较小的刚度系数来降低辅助水平，从而引导受试者做出这种积极且正确的努力。

为了评估控制器的性能，施加了不同程度的额外扰动来模拟具有不同运动功能障碍程度的患者。随着扰动的增加，AAF 和辅助模式下的训练时间的增加表明功能障碍更严重的患者需要机器人提供更多的辅助。当患者恢复了部分运动功能并在训练中表现良好时，机器人可以从辅助模式切换到阻力模式，并提供更大的阻力以避免训练懈怠。当运动超出预定义范围时，机器人切换到限制模式以确保安全。此外，MAE、AAF 和训练时间可用于运动功能恢复的临床评估。

在本研究中，存在一些未来需要改进的局限性。本研究所使用的绳索驱动机器人（cable-driven robot）的缺点包括缆绳变形可能导致的末端执行器精度不足，以及工作空间内的缆绳干涉问题，这些分别应通过采用高刚度缆绳和优化缆绳布局来加以改进。此外，人体主动力的测量应通过在末端执行器上加装三维力传感器来进一步完善。针对使用随机扰动模拟中风损伤的情况，应当设计更合理的模拟方案，例如在跟踪圆形轨迹时模拟手部在某些特定方向上无法发力的状态。此外，为了进一步推进所研发机器人及其控制器的临床应用，后续应开展基于患者的长期实验研究。

## VI. 结论

脑卒中患者在不同的康复阶段具有多样的康复需求。为了满足这些需求并促进主动康复，本文将基于表现的混合控制应用于具有四绳柔顺结构的绳索驱动机器人中。实验结果表明，该控制器能够根据受试者的运动表现自适应调节训练模式。在阻力模式下，当受试者在任务中表现良好时，控制器可以提供适当的阻尼力以防止患者产生怠惰（slacking）；在助力模式下，设计了模糊逻辑整定器以自适应、动态地调节机器人助力水平，从而避免患者对机器人辅助产生依赖；此外，限制模式可以防止受试者因运动误差过大而受伤。CDULRR 及其评估参数在临床康复训练中展现出了巨大的应用潜力。
