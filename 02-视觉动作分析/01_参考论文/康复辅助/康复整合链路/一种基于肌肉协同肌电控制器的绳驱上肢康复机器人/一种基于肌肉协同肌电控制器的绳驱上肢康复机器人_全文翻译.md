# 一种基于肌肉协同肌电控制器的绳驱上肢康复机器人

Chenglin Xie , Graduate Student Member, IEEE, Yueling Lyu, Guoxin Li , Member, IEEE,

Raymond Kai-Yu Tong , Senior Member, IEEE, Haisheng Xia , Member, IEEE,

Rong Song , Senior Member, IEEE, and Zhijun Li , Fellow, IEEE

摘要—表面肌电（sEMG）信号已应用于上肢康复机器人（ULRR）。然而，现有的基于肌电控制器的 ULRR 在估计三维（3-D）运动意图时的泛化能力有限。本文提出了一种受肌肉协同启发的方法，以增强绳驱 ULRR 肌电控制器的泛化能力。基于肌电-肌肉激活模型和非负矩阵分解，从 sEMG 信号中提取低维指令。提取的指令用于估计三维人体力。选取两个不同的轨迹跟踪任务来测试泛化能力。系统基于参与者执行其中一个任务的训练集进行训练。然后，使用参与者执行另一个任务的测试集对系统进行测试。最后，在实时机器人控制实验中对系统进行了验证。结果表明，与不考虑肌肉协同的肌电控制器相比，所提出的控制器实现了更高的力估计精度、更优的轨迹跟踪精度以及更低的交互力，这意味着所提出的控制器具有更好的泛化性能。

## I. 引言

脑卒中是导致死亡和长期残障的主要原因之一 [1], [2]。据估计，超过 80% 的脑卒中幸存者会出现不同程度的上肢运动功能障碍，这不仅影响了患者的日常生活活动，也给卒中后护理带来了巨大负担 [3]。随着全球每年新增脑卒中病例超过 1500 万例 [4]，由于物理治疗师数量有限且工作负荷沉重，传统的康复治疗已难以满足需求 [5]。机器人辅助康复具有提供高强度和定量化治疗的优势 [6]。近年来，上肢康复机器人（upper limb rehabilitation robots, ULRR）已成为以治疗师为主导的卒中患者上肢康复治疗的有益补充 [7]。

机器人辅助康复的有效性在很大程度上取决于控制策略。为满足康复训练的要求，已有多种控制策略被提出/采用。传统上，通常采用被动控制策略来确保跟踪给定轨迹的精度，并提供被动康复训练 [8]。为了提高康复过程中人机交互的顺应性，阻抗控制已被用于调节交互力与位置之间的动态关系 [9], [10], [11]。由于主动参与对于促进脑卒中后患者运动功能的恢复至关重要 [12]，旨在实现以人为主导的康复训练的主动控制策略受到了越来越多的关注 [13], [14], [15]。Saglia 等人 [13] 构建了一种导纳控制策略，以交互力作为输入为机器人生成期望位置。表面肌电（sEMG）信号与运动意图相关，因此也可作为康复机器人的输入以实现主动控制 [15], [16], [17], [18], [19], [20]。sEMG 信号先于人体主动力量产生，这为补偿受试者主动力量与机器人响应之间的时间延迟提供了可能，从而增强了人机之间的同步性 [21]。Zhuang 等人 [21] 基于 Hill 型肌肉骨骼模型（HMM），为踝关节康复机器人开发了一种基于 sEMG 的导纳控制策略。Fleischer 和 Hommel [22] 提出了一种基于 sEMG 的力矩控制策略，该策略同样基于 HMM。尽管 HMM 已被用于连续估计一维（1-D）力，但由于三维上肢运动的高度复杂性，它很难用于三维空间中的上肢末端力/位置估计 [23], [24]。状态空间模型已被用于通过 sEMG 信号连续估计上肢的三维末端力，并赋予了上肢康复机器人（ULRR）提供特定任务运动辅助的能力 [25], [26]。

肌肉协同（Muscle synergy）是一种利用协同原理来提取运动意图的生物学理论 [27], [28], [29]。神经生理学研究表明，中枢神经系统（central nervous system, CNS）可能通过肌肉协同来简化运动的神经控制，即 CNS 利用较低维度的指令来招募较多数目的肌肉 [28], [30], [31]。Berniker 等人 [28] 基于肌肉协同理论建立了一个低维控制器，以重建青蛙后肢的自然运动轨迹。Saito 等人 [32] 提供了证据，证明在复杂的手臂运动中存在人体上肢肌肉协同的基础单元。Muceli 等人 [33] 证明，从三个充分分离方向的运动期间的肌肉激活中所提取的肌肉协同，可以描述所有其他方向运动时的肌肉激活。为了提取肌肉协同，许多算法已被采用：主成分分析（principle component analysis, PCA）[34]、独立成分分析（independent component analysis, ICA）[35]、神经网络（neural network）[36] 以及非负矩阵分解（non-negative matrix factorization, NNMF）[27], [28], [37], [38]。其中，NNMF 可用于将肌肉激活矩阵分解为两个非负部分：肌肉协同矩阵和低维指令 [28]。NNMF 算法引起了特别关注，因为它可以提取非负特征，这与神经肌肉激活非负的物理约束相契合 [36], [39]。

大多数现有的基于肌肉协同的方法已被应用于离线分析 [40], [41], [42]，或假肢手 [29] 与虚拟手 [43] 的离散控制，尚未涉及基于 sEMG 的物理人机交互（physical human–robot interaction, pHRI），例如在机器人辅助康复训练中，特别是在三维（3-D）空间中。此类环境中的 pHRI 是复杂且连续的，因此将基于肌肉协同的方法与肌电控制器相结合以提升泛化能力是非常必要但目前仍属空白的。在本文中，部分基于以往文章 [25] 的一种基于末端执行器的绳驱动上肢康复机器人（cable-driven upper limb rehabilitation robot, CDULRR）被用于辅助上肢大范围粗大运动。采用肌电-肌肉激活度模型和实时 NNMF 算法从八块上肢肌肉的 sEMG 信号中提取 6-D 指令。基于状态空间模型和导纳控制器，提取的指令用于实时控制末端执行器。本文考虑了两种轨迹跟踪任务：类三角形和类矩形轨迹任务。对于每位参与者，其中一种轨迹任务用于模型训练，而另一种则用于模型测试和在线验证（即跨任务）。我们假设，肌肉协同理论不仅能像 [32]、[33] 和 [37] 中所证实的那样用于在伸展任务中重构 sEMG 信号，而且还可能有助于在跨任务的康复训练期间提升上肢 3-D 力估计和运动辅助方面的泛化性能。据我们所知，我们首次将基于肌肉协同的肌电控制器应用于 ULRR，以在不同轨迹跟踪任务中实现 3-D 连续运动辅助，并在 pHRI 条件下对比了考虑与不考虑肌肉协同的连续肌电控制器的泛化性能。

## II. 方法

## A. CDULRR 平台

CDULRR 平台如图 1（Fig. 1）所示，由一个末端执行器、四台电机（DM1B-045G，Yokogawa Co.）、四个相机（OptiTrack-2，NaturalPoint Co.）、一个显示屏以及一个名为 dSpace（RTI-1202，dSpace Co.）的实时操作系统组成。末端执行器由四根线缆驱动，这些线缆由四台电机以 100 Hz 的控制频率驱动。末端执行器上安装了三个光学标记点。每个标记点的位置可由运动捕捉系统的四个相机以 100 Hz 的频率获取。三个标记点的中心被视为末端执行器的实际位置。受试者握住末端执行器，并用魔术贴（Velcro）绑带缠绕固定在手上。受试者前方的显示屏提供视觉反馈，其中虚拟黑色光标代表参考位置，橙色光标代表末端执行器的实际位置。四个压力传感器（HSTLBLSM，BHX. Tech. Dev. Co.）测量四根线缆的张力。八对 AgCl 电极以 1 kHz 的采样频率测量八块肌肉（列于 Table I）的 sEMG（表面肌电）信号，用作输入信号。与先前文献 [25] 中的硬件不同，我们在末端执行器中内置了一个六维力传感器（D45MM-F400N）以测量人机交互力，并将基于 PC-NI 系列的控制卡升级为基于 dSpace RTI-1202 的嵌入式实时操作系统。dSpace 操作系统实时处理输入信号并控制四台电机。CDULRR 系统能够在 3-D 工作空间内提供康复任务，因而适用于广泛的日常活动。由于电机远离末端执行器，这种绳驱动并联机器人具有顺应性好、重量轻、惯性低和安全性高等优点。

## B. 基于肌肉协同的肌电控制器

在 dSpace 操作系统中实现的整体控制框架如图 2 所示。采用肌电-肌肉激活（EMG-muscle activation）模型计算肌肉激活向量 $\pmb { v } \in \mathbf { R } ^ { m \times 1 }$，其中 $\textit { m } = \textit { 8 }$ 为肌肉数量。接着，提取出 $n$ $( n < m )$ 维非负指令向量 $\hat { h } \in { \bf R } ^ { n \times 1 }$，随后由力估计模型估算出三维人体力 $\pmb { f } _ { h } \in \mathbf { R } ^ { 3 \times 1 }$。之后，导纳滤波器根据 $f _ { h }$ 生成末端执行器的初始期望位置 $P _ { d } \in \mathbf { R } ^ { 3 \times 1 }$。$P _ { d }$ 被限制在 CDULRR 的工作空间内，形成期望位置 $P _ { d } ^ { * }$。绳索轨迹规划器和 PID 回路与先前文献 [25] 中所描述的一致。

1) 肌电至肌肉激活模型（EMG-to-Muscle Activation Model）：测得的 sEMG 信号经全波整流后，通过截止频率为 4 Hz 的四阶低通滤波器。随后，信号通过最大自主等长收缩（MVC）进行归一化，形成 $e _ { j } ( t )$。关于 MVC 测量的详细信息可在文末附录中找到。之后，采用二阶线性模型计算第 $j$ 块肌肉在时间 $t$ 时的神经激活度

$$
n _ {j} (t) = \alpha e _ {j} (t - d) - \beta_ {1} n _ {j} (t - 1) - \beta_ {2} n _ {j} (t - 2)\tag{1}
$$

其中 $d = 100\text{ ms}$，$\alpha = 0.95$，$\beta_1 = 0.05$，以及 $\beta _ { 2 } = 0 . 0 0 0 6$ [25]。

采用文献 [44] 中的模型计算肌肉激活度 $v _ { j } ( t )$

$$
v _ {j} (t) = \left\{ \begin{array}{l l} \gamma \ln (\delta n _ {j} (t) + 1), & 0 \leq n _ {j} (t) <   n _ {0} \\ m n _ {j} (t) + c, & n _ {0} \leq n _ {j} (t) \leq 1 \end{array} \right.\tag{2}
$$

其中 $n _ { 0 } = ~ 0 . 2 5 , ~ \delta ~ = ~ 1 0 . 4 8 , ~ \gamma ~ = ~ 0 . 2 9 , m ~ = ~ 0 . 8 4 ,$ 且 $c = 0 . 1 6 .$

2) 非负矩阵分解（Non-Negative Matrix Factorization, NNMF）：给定由来自数据集的八通道时间序列肌肉激活度构成的矩阵 $V \in \mathbf { R } ^ { m \times T }$，可使用 NNMF 将肌肉激活矩阵 $V$ 分解为两个非负部分

$$
\boldsymbol {V} _ {(m \times T)} \approx \boldsymbol {W} _ {(m \times n)} \boldsymbol {H} _ {(n \times T)}\tag{3}
$$

其中 $T$ 是数据集中的采样时间点数，$V = [ v _ { 1 } [ 1 ] , v _ { 1 } [ 2 ] \ldots v _ { 1 } [ T ] ; \ldots ; v _ { m } [ 1 ] , v _ { m } [ 2 ] \ldots v _ { m } [ T ] ] \in \mathbf { R } ^ { m \times T }$，${ \cal W } \in { \bf { R } } ^ { m \times n }$ 为肌肉协同矩阵，$H \in \mathbf { R } ^ { n \times T }$ 为低维非负指令矩阵，而 $n$ 为肌肉协同的数量。

采用交替最小二乘（ALS）算法来实现 NNMF [45]，NNMF 的目标是最小化分解残差的均方根

$$
\text { minimize }: \varepsilon = \frac {\| \boldsymbol {V} _ {(m \times T)} - \boldsymbol {W} _ {(m \times n)} \boldsymbol {H} _ {(n \times T)} \|}{\sqrt {m \times T}}.\tag{4}
$$

3) 非负指令提取：基于奇异值分解（SVD）方法可获得肌肉协同矩阵的伪逆 $W ^ { + } \in \mathbf { R } ^ { n \times m }$（伪逆 $W ^ { + }$ 的证明见附录 B），并用于从预先记录的数据集中提取非负指令 $\hat { H } \in \mathbf { R } ^ { n \times T }$

$$
\hat {\boldsymbol {H}} _ {(n \times T)} = \boldsymbol {W} _ {(n \times m)} ^ {+} \boldsymbol {V} _ {(m \times T)}.\tag{5}
$$

4) 传递函数：采用传递函数模型来描述数据集中 $\hat { H }$ 与三维人体力 $F _ { h } \in \mathbf { R } ^ { 3 \times T }$ 之间的关系

$$
G (s) = \frac {F _ {h} (s)}{\hat {H} (s)} = \frac {N (s)}{D (s)}.\tag{6}
$$

分子系数向量 $N ( s )$ 和分母系数向量 $D ( s )$ 可通过工具变量算法辨识得到 [46]。

5) 实时非负指令提取模型：出于人机交互中实时响应能力的需求，我们将 NNMF 技术与基于 SVD 的伪逆矩阵计算相结合，以连续处理 sEMG 信号并提取中枢神经系统（CNS）指令，而非对某一时段的数据进行单次 [40], [41] 或间歇性 [29] NNMF。在人机交互的每个时刻，当给定肌肉激活向量 $\pmb { v } \in \mathbf { R } ^ { m \times 1 }$ 时，利用 $W ^ { + }$ 即可获得实时非负指令 $\hat { h } \in { \mathbf { R } } ^ { n \times 1 }$

$$
\hat {\boldsymbol {h}} _ {(n \times 1)} = \boldsymbol {W} _ {(n \times m)} ^ {+} \boldsymbol {v} _ {(m \times 1)}.\tag{7}
$$

6) 力估计模型：辨识出的传递函数模型可转化为具有已辨识系数矩阵 A、B、C、D 和 x[0] 的状态空间模型。状态空间模型可以方便地实现实时力估计

$$
\left\{ \begin{array}{l} x [ k + 1 ] = A x [ k ] + B \hat {\boldsymbol {h}} [ k ] \\ \boldsymbol {f} _ {\boldsymbol {h}} [ k ] = C x [ k ] + D \hat {\boldsymbol {h}} [ k ] \end{array} \right.\tag{8}
$$

其中 ${ \pmb x } [ k ]$ 是第 $k$ 个采样时刻的隐藏状态向量，$\hat { h }$ 是输入向量（即实时非负指令），$f _ { h }$ 是输出向量（即估计的三维人体力），A 代表表示状态 x 动态行为的系统矩阵，B 代表将输入信号引入状态 $^ { x , }$ 的输入矩阵，$C$ 和 D 是表示状态 x 和输入 $\hat { h }$ 如何决定输出向量的矩阵。

7) 导纳滤波器（Admittance Filter）：应用导纳滤波器根据 $f _ { h }$ 生成末端执行器的初始期望位置 $P _ { d }$

$$
\boldsymbol {P} _ {d} = \boldsymbol {P} + \boldsymbol {f} _ {h} \big (\boldsymbol {M} _ {h} s ^ {2} + \boldsymbol {B} _ {h} s + \boldsymbol {K} _ {h} \big) ^ {- 1}\tag{9}
$$

其中 $P \in \mathbf { R } ^ { 3 \times 1 }$ 为实际位置向量；$M _ { h } \in { \bf R } ^ { 3 \times 3 }$、$B _ { h } \in { \bf R } ^ { 3 \times 3 }$ 和 ${ \pmb K } _ { h } \in { \bf R } ^ { 3 \times 3 }$ 分别为质量、阻尼和刚度矩阵。由于在康复过程中手臂的加速度较小，质量项 $M _ { h } s ^ { 2 }$ 可以忽略 [13]。

8) 工作空间限制：为防止末端执行器与人体交互时发生潜在危险，加入了工作空间限制以确保末端执行器的位置在以下范围 U 内工作：

$$
\left\{(x, y, z) \mid \sqrt {(x - x _ {s}) ^ {2} + (y - y _ {s}) ^ {2} + (z - z _ {s}) ^ {2}} \leq r \right\}\tag{10}
$$

其中 $r = 0 . 2 5 m , x _ { s } = 0 m , y _ { s } = 1 m$ 且 $z _ { s } = - 0 . 6 5 m$。如果 $P _ { d }$ 超出范围 U，则期望位置 $P _ { d } ^ { * }$ 将等于实际位置

$$
\boldsymbol {P} _ {d} ^ {*} = \left\{ \begin{array}{l} \boldsymbol {P} _ {d},   \boldsymbol {P} _ {d} \in U \\ P,   \boldsymbol {P} _ {d} \notin U \end{array} \right.\tag{11}
$$

9) 索轨迹规划器：随后，索轨迹规划器将 $P _ { d } ^ { * }$ 转换为三根上部线索的期望长度 $( P _ { l d } )$

$$
\left\{ \begin{array}{l} \boldsymbol {P} _ {l d} = [ P _ {l d, 1}, P _ {l d, 2}, P _ {l d, 3} ] ^ {T} \\ P _ {l d, i} = \| \boldsymbol {P} _ {d} ^ {*} - \boldsymbol {C} _ {i} \| \end{array} \right.\tag{12}
$$

其中 $C _ { i }$ 表示第 $i$ 个滑轮的三维位置。

10) PID 控制器与索张力控制器：应用 PID 控制器控制三根上部线索的驱动力，以确保末端执行器跟踪期望位置。第 $i$ 根 $( i = 1 , 2 , 3 )$ 线索的驱动力确定如下：

$$
\begin{array}{l} F _ {l, i} = K _ {p} (P _ {l d, i} - P _ {l, i}) + K _ {i} \int_ {1} ^ {t} (P _ {l d, i} - P _ {l, i}) d t \\ \qquad + K _ {d} \frac {d (P _ {l d , i} - P _ {l , i})}{d t} \end{array}\tag{13}
$$

其中 $P _ { l , v }$ <sub>i</sub> 是关节空间中第 $i$ 根线缆的实际位置；$K _ { p } , K _ { i }$ 和 $K _ { d }$ 为 PID 系数。

为了保持线缆的张力，使用了一个线缆张力控制器，根据测得的线缆张力来控制下部线缆的驱动力

$$
F _ {l 4} = \left\{ \begin{array}{l} - 2 7 \left(f _ {\min} - f _ {l 4}\right), f _ {l 4} <   7 N \\ 0, 7 N \leq f _ {l 4} \leq 1 0 N \\ 2 7 \left(f _ {l 4} - f _ {\max}\right), f _ {l 4} > 1 0 N \end{array} \right.\tag{14}
$$

其中 $f _ { l 4 }$ 是测得的下部线缆张力。

## C. 实验设置

本研究招募了八名健康受试者（四名男性和四名女性；年龄：24–29 岁）以验证所提出的控制器。受试者被随机分配到两组（Group1 和 Group2），并满足每组包含两名男性和两名女性的规则。在每组中，一种轨迹任务用于模型训练，而另一种任务则同时用于模型测试和在线验证，以检验控制器在不同任务间的泛化能力。

数据集是通过记录所有参与者的 sEMG 信号和三维人体末端力获得的。数据记录的细节与前文所述相同（请参考 [25]）。参与者被要求坐在椅子上，坐标系定义为：x 轴垂直于矢状面，y 轴垂直于水平面，z 轴垂直于冠状面。每位参与者在没有 CDULRR 辅助的情况下，重复追踪类三角形轨迹和类矩形轨迹各九次。sEMG 信号用于通过 (1) 和 (2) 计算肌肉激活矩阵 V。接着，进行 NNMF，并根据 (3)–(5) 通过分解训练集中的 V 获得肌肉协同矩阵的伪逆 $W ^ { + }$ 和非负指令 H<sup>ˆ</sup>。由动作捕捉系统（在第 II-A 节中描述，精度为 0.1 mm）记录的末端执行器三维位置数据被输入到 (9) 中以推导出估计的三维力 $f _ { h } ,$，该力作为传递函数模型的参考/观测输出。在 Group1 中，来自类三角形轨迹任务的数据集用于训练阶段，来自类矩形轨迹任务的数据集用于测试阶段。在 Group2 中，来自类矩形轨迹任务的数据集用于训练阶段，而来自类三角形轨迹任务的数据集用于测试阶段。在训练阶段，辨识传递函数模型以拟合输入数据 $\hat { H }$ 与输出数据 $\mathbf { } F _ { h }$ 之间的关系，然后将其转换为状态空间模型。在测试阶段，根据训练阶段预训练的 $W ^ { \bar { + } }$ 推导出非负指令 $\hat { H }$，随后使用状态空间模型估计三维人体力。最后，将估计的三维人体力数据与实际数据进行对比。

在在线验证中，Group1 中的每位参与者在 CDULRR 的辅助下重复追踪类矩形轨迹九次，而 Group2 中的每位参与者则追踪类三角形轨迹。末端执行器由参与者的 sEMG 信号进行实时控制。为了进行对比，每位参与者还进行了九次未考虑肌肉协同的肌电控制器实验（即肌肉激活向量直接作为力估计模型的输入，参见 [25]）。在该控制器中，使用肌肉激活矩阵 V 代替非负指令 H<sup>ˆ</sup> 来训练传递函数模型，并应用实时肌肉激活向量 v 代替 h<sup>ˆ</sup> 进行实时机器人控制。选取两种控制器的追踪误差和交互力作为性能对比指标。

为了简化上述描述，Group1 进行的实验被命名为“三角形到矩形”，而由 Group2 操作的实验被称为“矩形到三角形”。这两种运动与进食和物体操作等日常活动相关。

## D. 信号处理与统计分析

重建质量是 NNMF 的一个重要指标。重建矩阵 $\tilde { V }$ 可以通过将 W 与 $\hat { H }$ 相乘计算得出

$$
\tilde {\pmb {V}} _ {(m \times T)} = \pmb {W} _ {(m \times n)} \hat {\pmb {H}} _ {(n \times T)}.\tag{15}
$$

重建误差被用作重建质量的指标之一

$$
\mathrm{RMSE} = \| \boldsymbol {V} - \tilde {\boldsymbol {V}} \|.\tag{16}
$$

重建肌肉激活度与原始肌肉激活度之间的 Pearson 相关系数被用作重建质量的另一个指标。

计算力估计误差以评估数据集中基于 sEMG 的力估计性能

$$
f _ {\text { RMSE } i} = \sqrt {\frac {1}{T} \sum_ {k = 1} ^ {T} \left(\boldsymbol {f} _ {\text { actual }} [ i , k ] - \boldsymbol {f} _ {\text { estimate }} [ i , k ]\right) ^ {2}}\tag{17}
$$

其中 $i = 1 , 2 , 3$ 分别代表 $x , y , z$ 轴上的数据。

计算机器人与人之间绝对交互力的积分，以评估在线肌电控制任务的性能

$$
f _ {\text { int   3D }} = \sqrt {\frac {1}{T} \sum_ {k = 1} ^ {T} \| \boldsymbol {f} _ {\text { int }} [ k ] \| ^ {2}}\tag{18}
$$

其中 $f _ { \mathrm { \ i n t } }$ 是由内置在末端执行器中的力传感器测量的交互力。

同时计算跟踪误差以评估在线肌电控制任务的跟踪性能

$$
P _ {\text { RMSE } i} = \sqrt {\frac {1}{T} \sum_ {k = 1} ^ {T} \left(\boldsymbol {P} _ {\text { reference }} [ i , k ] - \boldsymbol {P} _ {\text { actual }} [ i , k ]\right) ^ {2}}\tag{19}
$$

$$
P _ {\text { RMSE   3D }} = \sqrt {\frac {1}{T} \sum_ {k = 1} ^ {T} P _ {\text { reference }} [ k ] - P _ {\text { actual }} [ k ] ^ {2}}.\tag{20}
$$

按轴评估方法有助于分析手臂运动在 3-D 发力特性中的表现，并评估人机耦合系统在 3-D 空间中的性能。

## III. 结果

## A. 肌肉协同提取

一名代表性受试者数据集中重构肌肉激活度与原始肌肉激活度之间的皮尔逊相关系数矩阵（亦称混淆矩阵）如图 3(a)–(g) 所示。在每个矩阵中，列和行分别对应原始肌肉激活度向量和重构结果。图 3(a)–(g) 分别展示了使用 $n = 1 { - } 7$ 个肌肉协同时的混淆矩阵。结果显示，随着 n 的增加，当 $n \leq 6 .$ 时，重构肌肉激活度与对应的原始肌肉激活度之间的皮尔逊相关系数（混淆矩阵对角线上的像素）增加，而 $n = 6$ 与 $n = 7 .$ 之间差异极小。图 3(h) 展示了使用不同数量 MS 时，测试集中的九次试验（九条不同颜色的实线）和训练集中（虚线）的重构误差。结果表明，随着 n 的增加，当 $n \leq 6$ 时重构误差减小，而 $n = 6$ 与 $n = 7$ 之间几乎没有差异。当使用六个肌肉协同数量时，重构误差非常小 $( \mathrm { R M S E } _ { } = 0 . 0 0 1 3 \mathrm { - } 0 . 0 0 1 7 )$。这意味着在执行上肢粗大动作时，$n = 6$ 已足以描述/重构八块肌肉的肌肉激活度。因此，我们选择 $n = 6$ 进行肌肉协同提取，并进一步用于三维人体力估计和在线机器人控制。

## IV. 讨论

## A. 开发基于肌肉协同的肌电控制器的动机

估计 3-D 上肢运动意图是肌电控制器面临的一项挑战 [47]。由于 3-D 上肢运动非常复杂，对神经肌肉骨骼系统进行建模十分困难 [23], [24]。以往的研究训练了一个状态空间模型来描述肌肉激活程度与上肢 3-D 末端力之间的关系 [25]。然而，此类未考虑生理机制的方法具有任务特异性（task-specific），泛化性能较差 [48]。神经生理学研究表明，中枢神经系统（CNS）似乎利用肌肉协同作用（muscle synergies）通过耦合肌肉激活来简化神经控制 [28], [32], [33], [49]。肌肉协同可作为运动评估的指标，并已被应用于离线分析 [40], [41], [42]，这为深入理解人体运动功能以及进行全面准确的评估提供了支持。在本文中，受 CNS 以及“从三个充分分离的方向运动中提取的肌肉协同可用于描述所有其他方向运动”这一证据的启发 [33]，利用肌肉协同矩阵获得的低维非负控制指令似乎与 3-D 上肢力具有直观且密切的相关性。例如，非负指令矩阵的第六行 [$H _ { 6 }$ in Fig. 4(b)] 与人体力的 z 轴分量 [$F _ { h , z }$ in Fig. 4(d)] 之间存在相关性。同理，$H _ { 2 }$ 与 $F _ { h , y } .$ 亦是如此。这些直观且相关的联系可能有助于提高力估计模型的辨识性能，从而改善控制器的泛化能力。这一现象与刺激青蛙 CNS 中的特定模块化结构时会产生一组特定力方向的发现类似 [50]。除 NNMF 外，还存在其他降维技术，例如 PCA 和 ICA。尽管 NNMF 的谱不如 PCA 紧凑，且相比于其他降维技术，NNMF 具备的稀疏性和基于局部的表示优势是以更高的复杂度为代价的 [51], [52]，但我们仍采用 NNMF 进行肌肉协同提取，因为它能够提取具有物理意义的非负特征，并符合神经肌肉激活非负的物理约束 [36], [39], [53]。在机器人辅助康复中，复杂的人机交互需要人的主动参与 [54] 并依赖 CNS 调控 [55]。所提出的基于肌肉协同的肌电控制器是一种模拟 CNS 调控的仿生方法，能够促进人体 CNS 控制，从而提升肌电控制的性能。此外，我们的 CDULRR 所具有的低惯性和柔性驱动特性可以减轻机器人对 pHRI 的不利影响。

## B. 肌肉协同提取的参数确定

肌肉协同提取需要确定肌肉协同的数量 $n$。Valk 等人 [37] 的相关研究表明，3–5 个肌肉协同可以描述某些受限的动作集，并指出当考虑更广泛的动作集时需要 6–8 个肌肉协同。因此，$n \geq 6$ 适用于 3-D 任务中的上肢运动。由于当 $n \geq 6$ 时，在训练集和测试集中均未观察到重构误差的下降 [Fig. 3(h)]，因此本文选择了 $n = 6$。尽管低维输入可能会导致信息丢失，但本文中的 NNMF 考虑了来自所有肌肉激活通道的信息，且 ALS 算法最小化了分解残差的均方根 [45]。关键信息将得以保留，当 $n = 6$ 时重构矩阵与原始矩阵高度相关且重构误差足够小，这一证据可以证明这一点。由于 CNS（中枢神经系统）通过耦合有限的肌肉激活集来调节肌肉骨骼系统中存在的冗余 [56]，因此可以在不丢失关键信息的情况下实现低维指令提取。

## C. 基于肌肉协同的肌电控制器的泛化能力

尽管如以往文献 [25]、[26] 所述，状态空间模型可用于根据肌肉激活程度连续估计上肢的三维自主肌力，并提供特定任务的运动辅助，但当其应用于之前未曾训练过的新任务时，其性能会有所下降。相比之下，采用受肌肉协同启发的方法提高了三维力估计的泛化能力（图 5、6、10 和 11）。轨迹跟踪误差和交互力的减小反映了参与者的自然控制，这与以往的研究文献 [21]、[57] 一致。本文中准确的力估计、较低的轨迹跟踪误差以及较低的人机交互力证明了 MS 控制器的泛化性能。其原因在于低维非负指令与三维力之间的直观且相关的关联性有助于力估计模型的辨识。此外，肌肉协同提取降低了力估计模型输入的维度，从而使模型训练更加便捷。已有其他研究采用切换模型来适应不同任务，其中分别训练了几个子模型，并针对特定任务选择特定的子模型 [23]、[26]、[58]。然而，切换模型仍需将每个任务中记录的数据都纳入训练集。与子模型训练方法不同，本文中基于肌肉协同的肌电控制器仅使用来自一个任务的数据进行训练，随后即可直接应用于另一个不同的任务（无论在测试集还是在线验证中）而无需重新训练，这体现了泛化能力的提升。

## D. 局限性与未来工作

1) 已有一项神经生理学研究探讨了青蛙肢体空间导航与网格细胞激活之间的关系 [59]。揭示肢体的空间导航（或网格细胞的激活）似乎有助于以更便捷的方式估计肢体三维力或肢体三维运动。基于肌肉协同的肌电控制器是否模拟了网格细胞的激活目前尚不明确。未来的研究可以通过脑电图（electroencephalography）定位被激活的网格细胞，从而深入探究肌肉协同与网格细胞之间的关系。

2) 搭载所提出控制器的 CDULRR 已在八名健康参与者身上进行了测试，本文仅进行了 144 次试验。然而，患者的肌肉协同可能与健康受试者有所不同。未来的研究应招募包括脑卒中后患者在内的更多参与者，并开展更多具有针对性临床获益的运动测试。

3) 在整个康复过程中，患者中枢神经系统（CNS）内的运动技能和运动模式表征可能会发生改变。然而，这些变化通常以相对缓慢的速度发生，因此，系统的再训练周期可能跨越数周至数月。未来的文章将探索一种用于全周期康复训练的更具鲁棒性的系统，包括整合远程呈现（telepresence）技术。

## V. 结论

本文开发了一种基于肌肉协同的肌电控制器，用于连续估计三维上肢力，并在绳驱动康复机器人上进行了验证。选取了两种不同的轨迹跟踪任务来测试控制器的泛化能力。其中一个任务用于模型训练，而另一个任务则同时用于模型测试和在线验证。与未考虑肌肉协同的肌电控制器相比，所提出的控制器在跨任务康复训练中展现出了更优越的泛化性能。
