# 基于肌电导纳控制器的混合式臂-手康复机器人

Chenglin Xie , Qianqian Yang , Member, IEEE, Yao Huang, Graduate Student Member, IEEE, Steven W. Su , Senior Member, IEEE, Ting Xu, and Rong Song , Senior Member, IEEE

摘要—伸手抓握（Reach-and-grasp）是日常生活中最基本的活动之一，然而鲜有康复机器人能为中风后患者提供手臂和手部的整合式主动训练以改善其运动能力。在本研究中，针对伸手抓握任务研制了一种新型混合式臂-手康复机器人（HAHRR）。该混合结构由用于手臂三维运动的线驱动模块和用于手部运动的外骨骼组成，能够同时辅助手臂和手部。为了实现主动顺应性控制，将基于肌电（EMG）的导纳控制器应用于 HAHRR。实验结果表明，配备基于 EMG 导纳控制器的 HAHRR 不仅能辅助受试者完成伸手抓握任务，且与基于力传感的导纳控制器相比能产生更平滑的轨迹。这些发现还表明，所提出的方法可能适用于中风后臂-手康复训练。

关键词—康复机器人，伸手抓握，混合结构，线驱动并联机构，手部外骨骼，EMG，导纳控制。

## I. 引言

大约三分之二的中风后患者饱受残疾困扰，需要高强度的康复治疗 [1], [2]。随着每年新增中风病例超过 1500 万例，由于物理治疗师数量不足且工作负荷巨大，传统康复训练难以轻易普及 [3], [4]。近年来，康复机器人已成为传统康复治疗的有益补充 [5], [6]。机器人辅助运动训练可以为患者提供可持续且高强度的康复治疗，并帮助他们恢复运动功能 [7]。

康复机器人的机械结构通常针对特定的训练任务进行设计。现有的上肢康复机器人种类繁多，大致可分为外骨骼式和末端执行器式机器人。包括 CADEN-7 [8]、RUPERT IV [9]、BRAVO [2] 和 Hand of Hope [10] 在内的外骨骼机器人与人体肢体的解剖结构相似，适用于辅助手部抓握等精细运动功能。这些外骨骼的关节可以单独控制，从而降低了下达控制指令的复杂性 [11]。末端执行器式机器人（包括 MIT-MANUS [12]、NeReBot [13]、GENTLE/s [14]、Sophia-3 [15]、MIME [16]、CASIA-ARM [17] 和 EULRR [18]）的工作方式是将人体肢体的特定部位固定在其末端执行器上，常用于辅助粗大动作 [19]。具体而言，这类机器人在改善上肢近端的伸展动作方面展现出了潜力 [19], [20]。近年来，绳驱动并联机构作为一种柔性驱动方式引起了广泛关注 [21]，例如 NeReBot [13], [22] 和 Sophia-3 [15] 中的3绳驱动方法。在绳驱动机器人中，电机远离末端执行器，这赋予了机器人良好的顺应性、低惯量、轻量化以及大工作空间等优势 [23]。

控制策略在康复机器人的效果中起着关键作用。比例-积分-微分（PID）控制器常用于跟踪参考轨迹 [24], [25]。Hogan 提出了阻抗控制器，使机器人与环境之间的交互力能够调节参考轨迹，从而实现一定程度的顺应性控制 [26]。随后，Saglia 等人采用导纳控制器，基于交互力生成期望轨迹，而不受参考轨迹的限制 [27]，从而实现了主动顺应性控制并鼓励了患者的主动参与 [28]。然而，当使用力传感器感知人体运动意图时，人体主动发力与机器人响应之间存在延迟 [29], [30]。为了克服这一缺点，Zhuang 等人利用 Hill 型肌肉骨骼模型，为一维踝关节康复机器人开发了一种基于肌电（EMG）的导纳控制器，与基于力矩/力传感的控制器相比，该控制器获得了更好的人机同步性和轨迹平滑度 [30]。Durandau 等人基于 Hill 型肌肉骨骼模型开发了一种 EMG 驱动的下肢外骨骼 [31]。EMG 信号与人体主动发力之间的机电延迟，使得补偿人体主动发力与机器人响应之间的时间延迟成为可能 [32]。也有研究基于 EMG 信号构建状态空间模型，用于机械臂的多维控制 [33], [34]。Hill 型肌肉骨骼模型常用于一维运动估计，但由于存在大量未知参数，很难应用于多维情况 [34], [35]；而状态空间模型作为多输入多输出（MIMO）系统，适用于多维运动估计 [33]。

伸手抓握（Reach-and-grasp）是我们日常生活中的一项基本活动，需要手臂与手部的协同配合。研究表明，对于脑卒中后患者，手部和手臂的一体化训练比分别单独训练具有更优的效果 [36]，然而目前用于伸手抓握训练的手臂-手部混合康复机器人（hybrid arm-hand rehabilitation robots, HAHRR）却很少。Artemiadis 等人开发了一种基于 EMG 的状态空间模型来估计上肢的三维运动 [33]；然而，它仅用于拟人机械臂的远程操作，并未应用于康复机器人。在本研究中，我们构建了一种 HAHRR，该系统由用于手臂三维运动的绳驱模块和用于手部运动的外骨骼组成。为了实现主动顺应性控制、人机同步、平滑轨迹以及三维运动估计，采用了一种基于 EMG 信号和状态空间模型的导纳控制器。

本研究的主要贡献如下：1）构建了一种新型手臂-手部混合康复机器人（HAHRR），以实现手臂和手部在伸展-抓取任务中的连续主动一体化训练。2）采用基于肌电（EMG）的导纳控制器，实现了具有连续多维手臂-手部自主参与的主动控制。

## II. 方法

## A. HAHRR 的机械结构

HAHRR 由自主设计的手部外骨骼和线驱动模块组成（Fig. 1）。手部外骨骼固定在线驱动模块的末端执行器（O点）上，该模块由四根绳索驱动（OA、OB 和 OC 表示三根上部绳索，OD 表示下部绳索）。每根绳索由一台电机（DM1B-045G, Yokogawa, 日本）驱动，每根绳索的张力由一个力传感器（HSTL-BLSM, 北京华控兴业科技发展有限公司, 中国）测量。末端执行器的位置通过动作捕捉系统（OptiTrack 2, NaturalPoint, 美国）获取。手部外骨骼在 Solid-Works 2019 中设计，随后采用光固化立体造型术（SLA）技术制造。手部外骨骼包含一个手-前臂托架和一个五指机构，其中拇指部分和四指部分由两个线性执行器（L12-30-100-12-I, Actuonix-Miniature Linear Motion Series, 加拿大）独立驱动。线性执行器的行程随螺杆端部的位置变化，行程长度为 0.03 m。五指机构的长度可调节以适应不同尺寸的手，这依赖于每个连杆中螺旋结构的旋转 [37]。手部外骨骼中的力传感器（S15-45N, Single Tact, 美国）位于受试者食指指尖与手指外骨骼之间。所有数据均基于具有 16 位模数转换（ADC）的 I/O 设备（PXI-6225, National Instruments, 美国）进行实时采集。

## B. HAHRR 的控制框架

HAHRR 的控制系统由手部运动辅助系统和手臂运动辅助系统组成，两者均包含基于肌电（EMG）的导纳控制器（Fig. 2）。基于 EMG 的导纳控制器用于生成期望轨迹（手臂为 $( P _ { a d }$，手部为 $P _ { h d }$），这些轨迹将由 HAHRR 的相应部件（线驱动模块的末端执行器和手部外骨骼的杆端）进行跟踪。基于 EMG 的导纳控制器的轨迹生成方法如下：首先使用 EMG-to-MuscleActivation 模型估计手臂的三维力和手部的一维力，随后引入导纳控制器根据估计的力生成末端执行器和杆端的期望位置。手部运动辅助系统中的轨迹跟踪控制由 PID 控制器实现，手臂运动辅助系统中则由 PID 控制器和绳索张力控制器实现。

![](images/92f0cde2628c2e96ad4d68ceba26ffe8037750e4e46399442b04bc5c987b544a.jpg)  
Fig. 2. HAHRR 的控制框架。当 S 切换到 F1 时，控制框架为基于 EMG 的导纳控制（本研究所提出的方法）：从人体表面实时测量八块肌肉的 EMG 信号，以计算八个肌肉激活度 $( a _ { 1 } \sim a _ { 8 } )$。随后估计手臂的三维力 $( F _ { a } )$ 和手部的一维力 $( \pmb { F } _ { h } )$。接着，通过导纳控制器利用估计力 $( F _ { a d } = F _ { a } + F _ { f }$ 和 $\boldsymbol { F } _ { h d } = \boldsymbol { F } _ { h } )$ 生成期望位置（$P _ { a d }$ 为线驱动模块中末端执行器的期望位置，$P _ { h d }$ 为手部外骨骼连杆末端的期望位置）。在手部运动辅助系统中，采用 PID 控制器输出手部外骨骼线性执行器跟踪期望位置所需的一维力 $( \boldsymbol { F } _ { h } )$。在手臂运动辅助系统中，绳索轨迹规划器用于根据 $P _ { a d }$ 确定上方三根绳索的期望长度 $( P _ { l d } )$；采用 PID 控制器输出上方三根绳索跟踪期望位置所需的力向量 $( \boldsymbol { F } _ { l } ^ { \prime } \doteq [ \boldsymbol { F } _ { l 1 } , \dot { \boldsymbol { F } _ { l 2 } } , \boldsymbol { F } _ { l 3 } ] ^ { T } )$，且下方绳索力 $( F _ { l 4 } )$ 由绳索张力控制器根据绳索张力 $( \dot { f } _ { l 4 } )$ 进行控制；引入人工力场以将末端执行器限制在安全运动范围内。当 S 切换到 F2 时，控制框架为基于力传感的导纳控制（对照组），其中 ${ \pmb F } _ { a }$ 和 ${ \pmb F } _ { h }$ 由力传感器测量。

1) 肌电到肌肉激活度模型（EMG-to-MuscleActivation Model）：在本研究中，肌电（EMG）信号采集自手臂的八块肌肉：肱二头肌（Biceps brachii, BIC）、肱三头肌（Triceps, TRI）、三角肌前束（Anterior of Deltoid, DA）、三角肌中束（Medial of Deltoid, DM）、三角肌后束（Posterior of Deltoid, DP）、肱桡肌（Brachioradialis, BR）、指总伸肌（Extensor Digitorum, ED）以及屈指肌（Flexor Digitorum, FD）。前六块肌肉的信号用于控制绳驱模块，ED 和 FD 的信号则应用于手部外骨骼。EMG 信号通过贴在体表的八组 AgCl 电极采集，采样频率为 1000 Hz，放大倍数为 5000 倍。放大器配有带通滤波器（20-450 Hz）和陷波滤波器（50 Hz）。随后，信号经全波整流，并通过截止频率为 4 Hz 的 4 阶巴特沃斯（Butterworth）滤波器进行低通滤波 [33], [38]。之后，利用最大自主等长收缩（MVC）将其归一化为 $e _ { i } ( t )$ [38], [39]。从所有上述肌肉获取 MVC 的方法与以往研究相同（ED 和 FD 请参见 [40]，其余六块肌肉请参见 [38], [39]）。

在下一步中，采用二阶离散时间线性模型计算第 i 块肌肉在时间 t 的神经激活度 $n _ { i } ( t )$ [41]：

$$
n _ {i} (t) = \alpha e _ {i} (t - d) - \beta_ {1} n _ {i} (t - 1) - \beta_ {2} n _ {i} (t - 2)\tag{1}
$$

其中系数 $\alpha ~ = ~ 0 . 9 4 8 6 3$、$\beta _ { 1 } = \ - 0 . 0 5 2 0 0$、$\beta _ { 2 } =$ 0.00063，以及机电延迟 $d { = } 1 0 0$ ms 均由经验确定 [38]。

根据以往的研究，第 i 块肌肉的肌肉激活度 $a _ { i } ( t )$ 与其神经激活度 $n _ { i } ( t )$ 之间的关系可近似表示如下 [42]：

$$
a _ {i} \left(t\right) = \left\{ \begin{array}{l l} \gamma \ln \left(\delta n _ {i} \left(t\right) + 1\right), & 0 \leq n _ {i} \left(t\right) <   n _ {0} \\ m n _ {i} \left(t\right) + c, & n _ {0} \leq n _ {i} \left(t\right) \leq 1 \end{array} \right.\tag{2}
$$

其中系数 $\gamma = 0 . 2 8 8 1 9$、$\delta = 1 0 . 4 7 6 0 0$、$m = 0 . 8 3 9 1 0$、$c = 0 . 1 6 0 9 0$ 和 $n _ { 0 } = 0 . 2 4 8 0 0$ 是使用基于牛顿-拉夫逊（Newton-Raphson）方法的单参数模型确定的。

b) 肌肉激活度-手部力模型

手部的一维力通过 ED 和 FD 的激活度估计如下：

$$
\varepsilon (t) = a _ {8} (t) - a _ {7} (t) + r\tag{5}
$$

$$
F _ {h} \left(t\right) = \left\{ \begin{array}{l} p \varepsilon \left(t\right) + q, \varepsilon \left(t\right) <   - q / p \\ 0, - q / p \leq \varepsilon \left(t\right) \leq q / p \\ p \varepsilon \left(t\right) - q, \varepsilon \left(t\right) > q / p \end{array} \right.\tag{6}
$$

其中 $\varepsilon ( t )$ 为激活度指数；$r , p ,$ 和 q 为模型参数，需根据经验预先确定；当 $\varepsilon ( t ) > q / p$ 时，$F _ { h } ( t )$ 为正，手部力以抓握力为主；当 $\varepsilon ( t ) < - q / p$ 时，$F _ { h } ( t )$ 为负，手部力以伸展力为主；当 $- q / p \leq \varepsilon ( t ) \leq$ $q / p$ 时，$F _ { h } ( t )$ 为零，手部既不抓握也不伸展（Fig. 3）。

从生理学角度来看，手的抓握和伸展主要依赖于 ED（指总伸肌）和 FD（屈指肌），这可以通过一个相对简单的模型来描述。死区 $( - q / p \leq \varepsilon ( t ) \leq q / p )$ 的目的是提高估计力的稳定性，从而避免由高变异性 EMG 信号引起的震颤。

3) 导纳控制器：线驱动模块末端执行器以及手部外骨骼杆端的期望位置由估计力通过导纳控制器生成 [27], [30]：

$$
\left\{ \begin{array}{l} \boldsymbol {P} _ {d} = \left[ \boldsymbol {P} _ {a d} ^ {T}, \boldsymbol {P} _ {h d} \right] ^ {T} \\ \boldsymbol {F} _ {d} = \left[ \boldsymbol {F} _ {a} ^ {T}, \boldsymbol {F} _ {h} \right] ^ {T} \\ \boldsymbol {P} _ {d} = \boldsymbol {P} + \boldsymbol {F} _ {d} \big (\boldsymbol {M} _ {h} s ^ {2} + \boldsymbol {B} _ {h} s + \boldsymbol {K} _ {h} \big) ^ {- 1} \end{array} \right.\tag{7}
$$

式中，$P _ { d }$ 为期望位置向量；$\boldsymbol { F } _ { d }$ 为估计力向量；P 为实际位置向量；$M _ { h } \in { \bf R } ^ { 4 \times 4 }$、${ \cal K } _ { h } \in { \bf R } ^ { 4 \times 4 }$ 和 $B _ { h } \in { \bf R } ^ { 4 \times \bar { 4 } }$ 分别为质量、刚度和阻尼矩阵。在康复训练中，由于人体肢体的加速度较小，可以忽略 $M _ { h } s ^ { 2 }$ 项 [27], [44]。

为确保杆端在安全范围内运动，$P _ { h d }$ 的上限设定为 0.018 m。

4) 手臂运动辅助：在手臂运动辅助系统中，笛卡尔坐标系下末端执行器的期望位置 $( P _ { a d } )$ 随后通过线缆轨迹规划器转换为三根上线缆的期望长度 $( P _ { l d } )$：

$$
\left\{ \begin{array}{l} \boldsymbol {P} _ {l d} = [ P _ {l d, 1}, P _ {l d, 2}, P _ {l d, 3} ] ^ {T} \\ \boldsymbol {P} _ {a d} = [ P _ {a d, x}, P _ {a d, y}, P _ {a d, z} ] ^ {T} \\ \boldsymbol {C} _ {j} = [ c _ {j, x}, c _ {j, y}, c _ {j, z} ] ^ {T} \\ P _ {l d, j} = \sqrt {(P _ {a d , x} - c _ {j , x}) ^ {2} + (P _ {a d , y} - c _ {j , y}) ^ {2} + (P _ {a d , z} - c _ {j , z}) ^ {2}} \end{array} \right.\tag{8}
$$

式中，$C _ { j }$ 为第 j 个滑轮的位置（在图 1(a) 中表示为 A、B 或 C）。

采用 PID 控制器控制线驱动模块三根上线缆的驱动力，使末端执行器能够跟踪期望位置：

$$
\left\{ \begin{array}{l} \boldsymbol {F} _ {\boldsymbol {l}} = \boldsymbol {K} _ {p l} \left(\boldsymbol {P} _ {l d} - \boldsymbol {P} _ {l}\right) + \boldsymbol {K} _ {i l} \int_ {1} ^ {t} \left(\boldsymbol {P} _ {l d} - \boldsymbol {P} _ {l}\right) d t + \\ \boldsymbol {K} _ {d l} \left(\dot {\boldsymbol {P}} _ {l d} - \dot {\boldsymbol {P}} _ {l}\right) \\ \boldsymbol {F} _ {\boldsymbol {l}} = [ F _ {l 1}, F _ {l 2}, F _ {l 3} ] ^ {T} \end{array} \right.\tag{9}
$$

式中，${ { F } _ { l } }$ 为驱动力向量；$P _ { l d }$ 为关节空间中的期望位置向量；$P _ { l }$ 为关节空间中的实际位置向量；$K _ { p l } , K _ { i l }$ 与 $\pmb { K } _ { d l }$ 均为 $\mathbf { R } ^ { 3 \times 3 }$ 对角矩阵。

绳驱模块下方绳索的驱动力由绳索张力控制器根据绳索张力进行控制：

$$
F _ {l 4} = \left\{ \begin{array}{l l} - 2 7 \left(f _ {m i n} - f _ {l 4}\right), & f _ {l 4} <   f _ {m i n} \\ 0, & f _ {m i n} \leq f _ {l 4} \leq f _ {m a x} \\ 2 7 \left(f _ {l 4} - f _ {m a x}\right), & f _ {l 4} > f _ {m a x} \end{array} \right.\tag{10}
$$

式中，$f _ { l 4 }$ 为下方绳索张力；$f _ { m i n }$ 和 $f _ { m a x }$ 分别设置为 7 N 和 10 N。

为下方绳索增加绳索张力控制器的目的在于使上方三根绳索产生正张力分布，从而形成四绳驱动全约束并联结构 [45]。

为确保实验期间受试者的安全，在手臂运动辅助系统中引入了人工力场。若绳驱模块末端执行器的期望位置处于安全范围内，则允许其自由运动而无阻力：

$$
\left\{(x, y, z) \mid \sqrt {(x - x _ {s}) ^ {2} + (y - y _ {s}) ^ {2} + (z - z _ {s}) ^ {2}} \leq r, z <   z _ {s} \right\}\tag{11}
$$

式中，$( x , y , z )$ 为笛卡尔坐标系中的位置；$( x _ { s } , y _ { s } , z _ { s } )$ 为受试者肩部的位置；r 为安全半径，该值应小于受试者手臂的长度。

一旦末端执行器的期望位置超出安全范围，机器人便会对其实施阻力：

$$
\boldsymbol {F} _ {f} = \left\{ \begin{array}{l} K \boldsymbol {d} _ {1}, i f b e y o n d t h e s a f e t y r a n g e \\ 0, o t h e r w i s e \end{array} \right.\tag{12}
$$

式中，K 为虚拟刚度；$d _ { 1 } > 0$ 为末端执行器期望位置偏离安全范围的偏差量。

5) 手部运动辅助：在手部运动辅助系统中，采用 PID 控制器控制手部外骨骼的线性致动器，以使杆端能够跟踪

期望位置：

$$
\begin{array}{l} \boldsymbol {F} _ {h} = \boldsymbol {K} _ {p h} \left(\boldsymbol {P} _ {h d} - \boldsymbol {P} _ {h}\right) + \boldsymbol {K} _ {i h} \int_ {1} ^ {t} \left(\boldsymbol {P} _ {h d} - \boldsymbol {P} _ {h}\right) d t \\ \quad + \boldsymbol {K} _ {d h} \left(\dot {\boldsymbol {P}} _ {h d} - \dot {\boldsymbol {P}} _ {h}\right) \end{array}\tag{13}
$$

其中 ${ \mathbf { } } F _ { h }$ 为驱动力向量；$P _ { h d }$ 为关节空间中的期望位置向量；$P _ { h }$ 为关节空间中的实际位置向量；$K _ { p h } , K _ { i h }$ 和 $K _ { d h }$ 为 PID 系数。

## C. 实验

上述控制系统采用 VC++ 6.0 进行编程。随后招募了一名健康受试者（年龄：23 岁；身高：171 cm；体重：76 kg）参与实验，该实验已获得广东省工伤康复中心（Guangdong work Injury Rehabilitation Center）伦理委员会的批准（AF/SC-07/2017）。实验分为两个阶段：拟合状态空间模型和验证 HAHRR 系统。

拟合状态空间模型可分为训练阶段和测试阶段。这两个阶段中使用的数据采集自受试者重复 20 次伸手触碰其前方圆柱形物体的过程。在此过程中，受试者坐在椅子上，未获得来自绳索驱动模块的辅助。同时且连续地记录 BIC、TRI、DA、DM、DP 和 BR 的 EMG 信号以及末端执行器的位置。将 EMG 信号代入 (1 3) 计算肌肉激活度 $( { \pmb u } _ { a } )$，作为状态空间模型的输入。将位置数据代入 (7) 计算估计的手臂力 $( F _ { a } )$，作为状态空间模型的输出。在 20 次试验数据中，随机抽取 10 次用于训练，其余 10 次用于测试。在训练阶段，利用 N4SID 方法逐一辨识一阶至十阶状态空间模型，以寻找模型的最佳拟合。在测试阶段，利用已辨识的状态空间参数（A、B、C 和 x[0]），根据肌肉激活度 $( { \pmb u } _ { a } )$ 估计手臂力 $( F _ { a } )$。随后将估计的手臂力 $( F _ { a } )$ 代入 (7)，从而获得手腕（绳索驱动模块的末端执行器固定在手臂上的位置）的期望位置。最后，将估计的手臂力和期望位置与实测数据进行对比，以确定最佳的模型阶数。

在验证 HAHRR 系统时，受试者重复伸手抓取其前方圆柱形物体的动作五次（Fig. 1(c)）。在此过程中，受试者的手臂由绳驱模块辅助，手部由手部外骨骼辅助。为了进行对比，在控制系统中采用基于力传感的导纳控制器替代基于 EMG 的导纳控制器进行了另外五次实验。相应地，导纳控制器的输入 $( F _ { a }$ 和 $F _ { h } )$ 转变为由力传感器测量的人机交互力。绳驱模块中的力传感器测量绳索拉力，该拉力将转换为受试者手部与机器人之间的交互力 [46]。手部外骨骼中的两个力传感器用于测量手部力量 $( F _ { h } = F _ { h 2 } - F _ { h 1 } , \mathrm { F i g . ~ 1 ( b ) } )$ ）。

## D. 信号处理与统计分析

手臂力的均方根误差（RMSE）用于评估状态空间模型的拟合结果：

$$
F _ {R M S E} = \sqrt {\frac {1}{T} \int_ {0} ^ {T} \| \boldsymbol {F} _ {e s t i m a t e} (t) - \boldsymbol {F} _ {m e a s u r e} (t) \| ^ {2} d t}\tag{14}
$$

其中 $T$ 为每次试验的持续时间；$F _ { e s t i m a t e }$ 为估计的手臂力；$F _ { m e a s u r e }$ 为测量得到的手臂力。

手腕位置的 RMSE 值也用于评估状态空间模型的拟合结果：

$$
P _ {R M S E} = \sqrt {\frac {1}{T} \int_ {0} ^ {T} \| \boldsymbol {P} _ {e s t i m a t e} (t) - \boldsymbol {P} _ {m e a s u r e} (t) \| ^ {2} d t}\tag{15}
$$

其中 $P _ { e s t i m a t e }$ 为估计的手腕位置；P <sub>measure</sub> 为测量得到的手腕位置。

为了比较所提出的基于 EMG 的导纳控制器与基于力传感的导纳控制器的轨迹平滑度，计算了 RMS 加加速度（RMS Jerk）：

$$
R M S J e r k = \sqrt {\frac {1}{T} \int_ {0} ^ {T} \| \ddot {\boldsymbol {P}} _ {m e a s u r e} (t) \| ^ {2} d t}\tag{16}
$$

其中，$\ddot { P } _ { m e a s u r e }$ 是线驱动模块末端执行器或手部外骨骼杆端位置的三阶导数。

计算了手臂和手部估计力的过零率（FZCRs），以检验所提出的基于 EMG 的导纳控制器比基于力传感的导纳控制器表现更自然、因而能够产生更平滑轨迹的假设。

采用配对 t 检验来检测基于 EMG 与基于力传感的导纳控制器之间的差异。统计检验通过统计分析软件（SPSS 24, SPSS Inc., USA）进行，显著性水平设定为 0.05。

## IV. DISCUSSION

在本研究中，构建了一台混合手臂-手部康复机器人（HAHRR），以实现手臂和手部在触及-抓握任务中的连续主动一体化训练。

## A. EMG-Based Controller

已有研究使用分类器来实现基于 EMG 的控制 [47]–[49]。然而，分类器只能识别有限数量的离散运动类型 [50]。因此，分类器适用于手势识别的应用，例如参考文献 [47]，但不适用于连续的三维手臂力估计。在本研究中，利用状态空间模型（一种 MIMO 系统）从六块肌肉的激活度中估计三维手臂力。目前，三维连续运动估计仍然是一个挑战。尽管 Hill 型肌肉骨骼模型被广泛用于根据表面 EMG 信号估计一维连续运动 [31], [51], [52]，但由于该任务的高度复杂性，它很难实时应用于三维上肢运动估计 [34], [35]。

确定模型阶数是状态空间模型的关键。一阶和二阶状态空间模型结构简单，对扰动具有鲁棒性，但无法反映上肢运动特征的细节。四阶及更高阶的状态空间模型往往能拟合出包含更多细节的实际手臂力，但结构复杂，对扰动敏感，且具有更大的随机性。因此，在模型细节和鲁棒性之间存在权衡。通过在手臂力的均方根误差 $( F _ { R M S E } )$ 和手腕位置的均方根误差 $( P _ { R M S E } )$ 方面对 1 阶到 10 阶进行比较，将 3 阶确定为最优模型阶数。3 阶模型在训练集和测试集中均获得了最小的 $F _ { R M S E }$ 和 $P _ { R M S E }$。这与先前的研究一致，即 3 阶状态空间模型的表现优于 6 阶和 10 阶模型 [38]。

运动学控制的平滑度对于康复机器人而言至关重要 [53]。末端执行器的抖动轨迹不仅会让受试者感到不适，还可能对患者造成危险。实验结果表明，基于 EMG 的导纳控制器在力和轨迹两方面均比基于力感知的控制器实现了更好的平滑度。我们将这种现象归因于基于 EMG 的运动意图感知的时延补偿效应。在基于力感知的运动意图感知中，机器人的响应时间导致机器人根据先前测得的力而非当前的实际力做出动作。如图 Fig. 8 所示，这可能导致力的振荡（TABLE I 中的大 FZCR 值）和颠簸的轨迹（Fig. 7 中的大 RMS Jerk）。而在采用基于 EMG 的运动意图感知时，观察到了力的平滑变化（较小的 FZCR 值）和平滑的轨迹（较小的 RMS Jerk）。EMG 信号先于人体主动力产生 [38]，可用于补偿人体主动力与机器人响应之间的时延，从而提高人机同步性 [30]。

## B. 用于伸展-抓握任务的混合康复机器人

本研究中的混合康复机器人是专门针对伸展-抓握（reach-and-grasp）任务而设计的。现有的康复机器人要么主要侧重于手臂运动（如 RUPERT IV [9]、NeReBot [13]、GENTLE/s [14]、Sophia-3 [15]、MIME [16]、CASIA-ARM [17] 和 EULRR [18]），要么侧重于手部运动（如 HERO [54]、iSAFER [55]、HEXOES [56]、RML Glove [57]、BRAVO [2] 和 Hand of Hope [10]）[58]。然而，没有手部运动，人们就无法进食、饮水、书写或打字。没有手臂运动，人们就无法举起或拿取抓取的任何物品。鉴于伸展-抓握任务在整个运动过程中需要手臂与手部的协调配合 [59]，该机器人的机械结构采用了绳驱动模块与手部外骨骼的混合设计，控制策略则基于连续 EMG 控制。绳驱动并联机构具有柔顺结构、低运动质量、轻量化结构以及大工作空间等优点 [23]，因此适合用于辅助手臂的伸展运动。手部外骨骼尺寸可调且符合人体手部解剖结构，因此适用于辅助不同受试者的手部抓握。在连续 EMG 控制中，人体的运动意图通过 EMG 信号被连续感知，并转化为给机器人的控制指令，从而将受试者的持续主动参与融入到机器人控制中 [35]。

## C. 局限性与未来工作

1) 状态空间模型的训练时间约为 20 分钟，这可能是所提出的基于 EMG 的控制器的一个局限，因为需要为每位受试者单独准备。2) 所提出的 HAHRR 系统目前阶段仅在健康受试者身上进行了测试。尽管患者的 EMG 激活模式与健康受试者不同，但测试集和验证实验可能会缓解患者与健康受试者之间 EMG 激活模式的差异。未来将通过具有残余 EMG 活动的脑卒中后患者对所提出的 HAHRR 系统进行进一步验证。3) 本研究提出了一种康复机器人及其基于 EMG 的控制器，用于手臂和手部的一体化主动训练。未来需要进一步研究控制策略以整合手臂和手部控制器，并应对臂手协调性进行定量评估以验证训练效果。

## V. 结论

本研究提出了一种配备基于肌电（EMG）导纳控制器的混合臂-手康复机器人（HAHRR）。实验结果表明，该机器人能够根据人体运动意图连续生成平滑轨迹，并辅助受试者完成伸展与抓握任务。

Su（IEEE 高级会员）于1968年出生于中国。他于2003年5月在澳大利亚首都领地堪培拉的澳大利亚国立大学（Australian National University）系统信息工程研究院（RSISE）获得控制工程博士学位。随后在澳大利亚新南威尔士州悉尼的新南威尔士大学（University of New South Wales）工程学院担任了近四年的研究员（Research Fellow）。他目前是悉尼科技大学（UTS）工程与信息技术学院的副教授，也是健康技术中心（Center for Health Technologies）和全球大数据技术中心（Centre for Global Big Data Technologies Centre）的核心成员。他拥有超过20年的

康复工程、生物医学仪器、生理系统建模、数据采集与分发、系统控制以及参数辨识领域的研究经验，在这些领域出版了1部专著并发表了270余篇同行评议的研究论文。作为电子鼻（Nos.e）的主要技术贡献者之一，他获得了2020年新南威尔士州 iAwards（商业与工业解决方案 iAward NSW）。其团队研发的 AI 外骨骼获得了 Techcelerator 颁发的2020年度最具创新原型奖（Most Innovative Prototype Award 2020）。

Ting Xu 出生于中国。她于2011年在中国济南山东大学（Shandong University）获得自动化专业学士学位，并于2020年在香港城市大学（City University of Hong Kong）获得生物医学工程博士学位。她目前是广东省中山大学（Sun Yat-sen University）生物医学工程学院的副教授。她的研究方向包括人工智能、生物医学信号处理以及机器人辅助中风康复。

Rong Song（IEEE 高级会员）于1975年出生于中国湖北。他于1999年在中国北京清华大学（Tsinghua University）获得电气工程学士学位，2002年在汕头大学（Shantou University）获得电子工程硕士学位，2006年在香港理工大学（Hong Kong Polytechnic University）获得生物医学工程博士学位。他目前是广东省中山大学（Sun Yat-sen University）生物医学工程学院的教授。他的研究方向包括肌肉骨骼建模、生物医学信号

处理、人体运动分析以及机器人辅助中风康复。
