# 基于高斯混合模型的上肢绳驱动康复机器人肌电控制

Jianlin Zheng, Zhijun Li, Ting Xu, and Rong Song\*

基于手臂力量的肌电（Electromyographic, EMG）导纳控制可在机器人辅助康复中提供连续的运动控制。利用基于肌电的智能接口实现自然且复杂的人机物理交互，需要建立三维主动力的计算估计模型。现有的计算模型很少直接对三维手臂力量在空间各维度分量之间的相互联系进行编码，并且在基于肌电的控制中会因肌肉疲劳等混杂变量而出现性能退化。针对这一挑战，本文提出了一种基于高斯混合模型（Gaussian Mixture Model, GMM）的计算模型，该模型仅需通过增量 GMM 方法进行便于用户使用的校准，即可减小肌肉疲劳的影响。GMM 旨在通过联合概率密度分布来编码肌电与主动力之间的多变量关联。基于肌电的控制系统利用高斯混合回归（Gaussian Mixture Regression），根据 GMM 在给定肌电的情况下检索估计的主动力。在此，通过在诱发疲劳实验前后进行的轨迹跟踪实验，测试了所提出的基于 GMM 的肌电导纳控制的性能。实验包括八名健康受试者。实验结果表明，采用校准后 GMM 的肌电控制在跟踪精度和运动顺应性上分别提高了 23.66% 和 8.17%，展现出在涉及人机物理交互的各个领域的潜在应用价值。

## 1. 引言

脑卒中可导致运动功能障碍，并影响卒中幸存者的生活质量。康复训练在恢复受损的运动神经通路<sup>[1]</sup>和提高患者的日常功能性运动能力<sup>[2]</sup>方面起着至关重要的作用。然而，物理治疗师资源匮乏，且其治疗质量可能会因疲劳而受到影响。由于康复机器人能够不知疲倦地提供一致的治疗并促进运动功能的恢复，机器人辅助康复正成为一个备受关注的研究课题。<sup>[3]</sup>

参与度会影响机器人辅助康复，而控制策略则直接影响人体的参与程度。康复机器人的核心组成部分之一在于控制策略。被动控制方案协助运动功能严重受损的患者在机器人主导的模式下完成康复训练，例如 MIT-MANUS、<sup>[4]</sup> MIME <sup>[5]</sup> 和 ARMin <sup>[6]</sup> 中的被动模式。鼓励主动参与对于提高康复疗效至关重要，<sup>[7]</sup> 尤其是对于损伤程度较轻的患者。主动阻抗控制策略可以通过促进患者的自主参与来促进肌肉恢复。<sup>[8,9]</sup> 肌电（EMG）信号直接反映了运动意图，并且在动作发生之前即已产生。<sup>[10]</sup> 采用 EMG 作为控制源可以使机器人感知并解码运动意图，并促进人机运动同步，从而提高主动参与水平。<sup>[11,12]</sup>

现有的基于 EMG 的控制策略通常通过模式识别进行离散运动控制，例如线性判别分析（linear discriminant analysis）<sup>[13]</sup>和支持向量机（support vector machines）。<sup>[14]</sup> 然而，人手臂与智能康复机器人之间的物理交互对于机器人辅助康复至关重要。<sup>[15,16]</sup> 通过手臂力量控制末端执行器涉及力量在方向和大小上的连续变化，这意味着提取自主力量意图需要一种连续估计方法。<sup>[17]</sup> 例如，Louis 等人通过 Hill-type 模型实现了单维度的力估计，并完成了伸展任务。<sup>[18]</sup> Xiong 等人开发了一种具有小输入维度的人工神经网络<sup>[19]</sup>以及一种跨尺度特征解码网络，<sup>[20]</sup>以从 EMG 中提取连续的关节力矩。Xie 等人应用状态空间模型来解码用于伸展任务的三维自主受力。<sup>[21]</sup> 近年来，康复机器人领域采用了仿生策略来提升基于 EMG 控制的智能水平，促进了物理人机交互（pHRI）中的仿生特性（如自适应能力）。<sup>[22]</sup> 例如，Zeng 等人采用高斯过程（Gaussian process）来学习和预测基于 EMG 的连续运动意图。<sup>[17]</sup>

能够解码三维随意力的计算模型有助于在基于智能肌电（EMG）接口下实现自然且复杂的物理人机交互（pHRI）。Hill型模型可以实现单维度的力估计<sup>[18]</sup>，但仅限于低维力或关节力矩的估计。<sup>[23]</sup>Zhang 等人采用三个平行的长短期记忆网络（LSTM）分别估计三个一维力的方向和强度，避免了直接建立三维手臂随意力与 EMG 信号之间关系所需的网络模型复杂性。<sup>[24]</sup>Su 等人根据三个空间维度对力进行划分，应用深度卷积神经网络进行估计，并对其进行了独立校准。<sup>[15]</sup>一些方法对三维手臂力在空间维度分量之间的相互关联进行了编码。Zhang 等人通过分层神经网络对 EMG 与三维手臂力之间的关系进行建模，该网络包含一个底层共享特征提取器和三个平行的高层维度特定微调器。<sup>[16]</sup>直接对随意力的三维分量进行编码的计算模型可以减少因建模假设导致的误差。Wu 等人采用广义回归神经网络（GRNN）来估计三维推拉力，但必须依赖原始数据的可获取性。<sup>[25]</sup>Huang 等人利用状态空间模型从 EMG 信号中解码三维力。<sup>[26]</sup>然而，该方法局限于特定任务，且仅适用于直线轨迹任务的简单组合。Xie 等人提出了一种利用带有三维输出回归层的深度 LSTM，但在实验开始前需要进行耗时的静态-动态校准。<sup>[27]</sup>

尽管基于肌电（EMG）的控制领域取得了进展，但现有的肌电-力计算模型与人类用户的匹配度不足，且通常在未考虑内在和外在因素影响的情况下考量其性能。<sup>[28,29]</sup>此外，由于人类的上肢运动本质上涉及三个维度，<sup>[30]</sup>利用智能肌电接口实现自然且复杂的物理人机交互（pHRI）需要一种能够对三维自主力进行编码的计算模型。在本研究中，我们提出使用高斯混合模型（GMM）来学习 EMG 与三维力之间的非线性关系，以用于上肢绳驱康复机器人（ULCDRR）的肌电控制。GMM 可以通过高斯混合回归（GMR）在无需原始训练数据的情况下，实时实现快速的三维自主力输出。<sup>[31]</sup>GMM 可被视为一种仿生方法，因为它模拟了人脑所执行的概率建模和推理过程，<sup>[32,33]</sup>其中这种与人类匹配的模型可能有助于在 pHRI 运动过程中促进人机同步。现有基于 GMM 的研究主要集中在模式识别<sup>[34–36]</sup>和模仿学习，<sup>[37,38]</sup>缺乏在基于智能 EMG 的机器人系统中进行三维连续运动控制的研究。对足够强度治疗的需求常常导致中风患者出现肌肉疲劳，<sup>[39]</sup>这会影响基于 EMG 控制方案的性能，包括力估计的准确性<sup>[40,41]</sup>和控制顺应性。<sup>[42]</sup>因此，我们基于增量 GMM 方法对训练好的 GMM 进行校准，以减少肌肉疲劳对采用智能 EMG 接口的机器人辅助康复的一致性和精度的影响。<sup>[24,43]</sup>为了实现顺应性控制，我们将估计的力作为基于 EMG 的导纳控制器的输入。

本文的主要贡献如下：1）我们提出了一种基于 GMM 的 EMG 导纳控制，并实现了实时三维运动控制。2）我们开发了一种增量 GMM 技术来校准 GMM，并将其嵌入硬件中以便便捷快速地进行校准。3）我们设计了一项诱发疲劳的实验，并通过轨迹跟踪实验验证了所提方法在肌肉疲劳情况下的性能。

## 2. 系统描述

我们开发了一款上肢线驱动康复机器人（ULCDRR）<sup>[21,44]</sup>（Figure 1）。机器人的末端执行器通过四根线缆与四台电机（DM1B-045G，Yokogawa，日本）相连，每根线缆的张力由一个力传感器（HSTL-BLSM，北京华控兴业科技发展有限公司，中国）进行测量。动作捕捉系统（OptiTrack 2，NaturalPoint，美国）用于采集末端执行器的位置信息。集成在末端执行器上的六轴力传感器（SRI-V-210105-G）用于测量人机物理交互（pHRI）力。采用 dSPACE MicroLabBox 1202 平台（dSPACE，Paderborn，德国）结合 MATLAB R2019b 软件（The Mathworks Inc.，MA，美国）来记录实时信号并生成控制指令。此外，我们使用 dSPACE ControlDesk 7.2 软件设计了人机交互界面，受试者可以通过面前的电脑屏幕获取其运动表现的视觉反馈。

## 3. 实验部分

## 3.1. ULCDRR 控制框架

ULCDRR 的控制框架包括两个基本阶段（Figure 2）：学习阶段和任务阶段。在学习阶段，我们通过 GMM 建立了处理后的 EMG 信号 ${ \pmb \xi } _ { s }$ 与力信号 $\pmb { \xi } _ { f }$ 之间的联合概率密度。增量 GMM 方法用于校准已训练的 GMM $\{ \pi _ { j } , \pmb { \mu } _ { j } , \pmb { \Sigma } _ { j } \} _ { j = 1 } ^ { K }$。在任务阶段，GMR 基于 $\{ \pi _ { j } , \pmb { \mu } _ { j } , \pmb { \Sigma } _ { j } \} _ { j = 1 } ^ { K }$ 利用新输入的 ${ \pmb \xi } _ { s }$ 来估计三维力 $\hat { \pmb { \xi } } _ { f }$。所需的估计主动力 $\hat { F }$ 是 $\hat { \pmb { \xi } } _ { f } .$ 的反归一化结果。最后，底层控制器将 $\hat { F }$ 转换为 ULCDRR 的四根线缆拉力 $\mathbf { F } _ { 1 }$，从而驱动末端执行器到达目标位置。

## 3.1.1. GMM

在本研究中，我们通过 GMM 建立了 ${ \pmb \xi } _ { s }$ 与 $\pmb { \xi } _ { f }$ 之间的联合概率密度分布。GMM 是一种由 K 个高斯分量组成的概率模型，用于对分类或回归的特征进行编码。<sup>[45]</sup> 联合概率密度函数 $\mathcal { P }$ 可表示为

$$
\mathcal {P} \left(\boldsymbol {\xi} _ {s}, \boldsymbol {\xi} _ {f}\right) = \sum_ {j = 1} ^ {K} \pi_ {j} \mathcal {N} \left(\boldsymbol {\xi} _ {s}, \boldsymbol {\xi} _ {f} \mid \boldsymbol {\mu} _ {j}, \boldsymbol {\Sigma} _ {j}\right)\tag{1}
$$

其中

$$
\boldsymbol {\mu} _ {j} = \left[ \begin{array}{c} \boldsymbol {\mu} _ {s, j} \\ \boldsymbol {\mu} _ {f, j} \end{array} \right], \quad \boldsymbol {\Sigma} _ {j} = \left[ \begin{array}{c c} \boldsymbol {\Sigma} _ {s s, j} & \boldsymbol {\Sigma} _ {s f, j} \\ \boldsymbol {\Sigma} _ {f s, j} & \boldsymbol {\Sigma} _ {f f, j} \end{array} \right]\tag{2}
$$

其中，$\pmb { \xi } _ { s } \in \mathbb { R } ^ { D _ { s } \times N _ { 0 } }$ 是经过主成分分析（PCA）处理后的 $D _ { \mathrm { s } } .$ 维特征向量，${ \pmb { \xi } } _ { f } \in \mathbb { R } ^ { D _ { f } \times N _ { 0 } }$ 是通过最小–最大（min–max）方法归一化后的 $D _ { \mathrm { f } }$ 维力向量。$N _ { 0 }$ 表示训练数据的数量。此处的 PCA 可以缓解在 GMM 训练过程中由于输入特征之间的线性相关性而可能出现的协方差矩阵奇异或病态问题。

我们采用了共享协方差（shared covariance）这一参数共享技术，以降低过拟合风险并减小初始化方法的影响。共享协方差定义为

$$
\pmb {\Sigma} _ {1} = \pmb {\Sigma} _ {2} = \dots = \pmb {\Sigma} _ {K} = \pmb {\Sigma} ^ {\prime} = \frac {\sum_ {j = 1} ^ {K} \pi_ {j} \pmb {\Sigma} _ {j}}{\sum_ {j = 1} ^ {K} \pi_ {j}}\tag{3}
$$

每个高斯分量的参数 $\boldsymbol \theta _ { j } = \left\{ \pi _ { j } , \mu _ { j } , \pmb { \Sigma } _ { j } \right\}$ 始于通过 k-means++ 分割得到的粗略估计。随后，初始 GMM $\pmb \theta = \{ \theta _ { j } \} _ { j = 1 } ^ { K }$（Initial-GMM）通过标准期望最大化（EM）算法进行离线训练。高斯分量的数量 K 通过五折交叉验证（fivefold cross-validation）方法确定。

## 3.1.2. 增量 GMM（Incremental GMM）

在本研究中，我们通过增量 GMM 方法对 Initial-GMM 进行了校准。该技术假设在利用新数据 $\{ \pmb { \xi } _ { m } \} _ { m = 1 } ^ { N _ { n } }$ 校准模型时，后验概率 $\mathscr { P } ( \pmb { \theta } | \pmb { \xi } _ { m } )$ 保持不变。<sup>[46]</sup> $N _ { n }$ 表示与第 n 次 EM 迭代相关的记录样本数量。在第 n 次 EM 迭代的第 g 次 EM 步中，期望步（E-step）为

$$
\left\{ \begin{array}{c} \mathcal {P} \Big (\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m} \Big) = \frac {\pi_ {j} ^ {(g)} \mathcal {N} \Big (\boldsymbol {\xi} _ {m} | \boldsymbol {\mu} _ {j} ^ {(g)} , \boldsymbol {\Sigma} _ {j} ^ {(g)} \Big)}{\sum_ {i = 1} ^ {K} \pi_ {i} ^ {(g)} \mathcal {N} \Big (\boldsymbol {\xi} _ {m} | \boldsymbol {\mu} _ {i} ^ {(g)} , \boldsymbol {\Sigma} _ {i} ^ {(g)} \Big)} \\ E _ {j} ^ {(g + 1)} = \sum_ {m = 1} ^ {N _ {n}} \mathcal {P} \Big (\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m} \Big) \end{array} \right.\tag{4}
$$

随后，最大化步（M-step）为

$$
\left\{ \begin{array}{l} \pi_ {j} ^ {(g + 1)} = \frac {E _ {j} ^ {(0)} + E _ {j} ^ {(g + 1)}}{N _ {0} + N _ {n}} \\ \boldsymbol {\mu} _ {j} ^ {(g + 1)} = \frac {E _ {j} ^ {(0)} \boldsymbol {\mu} _ {j} ^ {(0)} + \sum_ {m = 1} ^ {N _ {n}} \mathcal {P} \left(\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}\right) \boldsymbol {\xi} _ {m}}{E _ {j} ^ {(0)} + E _ {j} ^ {(g + 1)}} \\ \boldsymbol {\Sigma} _ {j} ^ {(g + 1)} = \frac {E _ {j} ^ {(0)} \left(\boldsymbol {\Sigma} _ {j} ^ {(0)} + \left(\boldsymbol {\mu} _ {j} ^ {(0)} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) \left(\boldsymbol {\mu} _ {j} ^ {(0)} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) ^ {T}\right)}{E _ {j} ^ {(0)} + E _ {j} ^ {(g + 1)}} \\ + \frac {\sum_ {m = 1} ^ {N _ {n}} \mathcal {P} \left(\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}\right) \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) ^ {T}}{E _ {j} ^ {(0)} + E _ {j} ^ {(g + 1)}} \end{array} \right.\tag{5}
$$

在本研究中，我们将完整参数集 $\mathbf { \Theta } _ { \mathbf { \Theta } } \Theta$ 定义为 $\{ ( \pmb \theta _ { j } , E _ { j } ) \} _ { j = 1 } ^ { K } ,$ 其中 $\begin{array} { r } { E _ { j } = \sum _ { m = 1 } ^ { N _ { n } } \mathcal { P } \big ( \pmb { \theta } _ { j } | \pmb { \xi } _ { m } \big ) } \end{array}$。在第一次 EM 迭代开始时，$\mathbf { \delta } _ { \mathbf { \Theta } } \mathbf { \Theta } \Theta _ { 0 }$（Initial-GMM）被设置为初始值，即 $\left\{ \pmb { \theta } _ { j } ^ { ( 0 ) } , E _ { j } ^ { ( 0 ) } \right\} _ { i = 1 } ^ { K } = \pmb { \Theta } _ { 0 } ,$。在 Calinon 等人<sup>[46]</sup>提出的增量 GMM 中，他们利用平均对数似然在 M 步后进行收敛性评估。平均对数似然为

$$
\mathcal {L} = \frac {1}{N _ {n}} \sum_ {m = 1} ^ {N _ {n}} \log \left(\sum_ {j = 1} ^ {K} \pi_ {j} \mathcal {P} (\boldsymbol {\xi} _ {m} | \boldsymbol {\theta} _ {j})\right)\tag{6}
$$

其判据为

$$
\frac {\mathcal {L} ^ {(g + 1)}}{\mathcal {L} ^ {(g)}} <   1 + \varepsilon\tag{7}
$$

其中 $\mathcal { L } ^ { \left( g \right) }$ 和 $\mathcal { L } ^ { ( g + 1 ) }$ 分别基于 $\mathbf { \Theta } \Theta ^ { ( g ) }$ 和 $\mathbf { \Theta } \Theta ^ { ( g + 1 ) }$。如果 (7) 式返回为真，则第一次 EM 迭代将停止，且 $\mathbf { \Theta _ { 6 } } =$ $\mathbf { \Theta } \Theta ^ { ( g + 1 ) }$ 将作为校准后的结果。当第 n 次 EM 迭代完成时，$\left\{ \pmb { \theta } _ { j } ^ { ( 0 ) } , E _ { j } ^ { ( 0 ) } \right\} _ { j = 1 } ^ { K }$ 将被替换为 $\mathbf { \Theta } _ { \mathbf { e } }$，且 $N _ { 0 }$ 将增加 $N _ { n }$，以准备进行第 (n 1) 次 EM 迭代。在本研究中，设置容差 $\varepsilon = 1 \times 1 0 ^ { - 6 }$。bl 展示了参数符号的定义。

我们在 dSPACE 控制器上实现了增量 GMM（高斯混合模型）。在校准实验中，dSPACE 可以利用收集到的新输入数据自动校准模型，无需人工干预。数据采集和模型校准程序作为两个独立的线程运行，其中采集的采样率为 1 kHz，校准程序中任务调度的时钟频率为 100 Hz。数据采集器会记录每个窗口数据（包括 EMG 和力）的均值特征，我们在单次 30 s 的数据采集周期内等间隔安排了 128 个窗口的数据采集，每个窗口宽度为 8 ms。

## 3.1.3. GMR

我们采用 GMR（高斯混合回归）技术，基于 (1) 中描述的联合分布来获取给定 $\boldsymbol{\xi}$ 条件下 $\pmb { \xi } _ { f }$ 的条件期望。GMR 提供了一种快速回归方法，用于在线计算多元输出。<sup>[31]</sup> 因此，预测任务可定义为

$$
\mathcal {P} \left(\boldsymbol {\xi} _ {f} \mid \boldsymbol {\xi} _ {s}\right) = \sum_ {j = 1} ^ {K} \beta_ {j} \mathcal {N} \left(\boldsymbol {\xi} _ {f} \mid \widehat {\boldsymbol {\mu}} _ {f | s, j}, \widehat {\boldsymbol {\Sigma}} _ {f | s, j}\right)\tag{8}
$$

其中

$$
\beta_ {j} = \frac {\pi_ {j} \mathcal {N} (\boldsymbol {\xi} _ {s} | \boldsymbol {\mu} _ {s , j} , \boldsymbol {\Sigma} _ {s s , j})}{\sum_ {i = 1} ^ {K} \pi_ {i} \mathcal {N} (\boldsymbol {\xi} _ {s} | \boldsymbol {\mu} _ {s , i} , \boldsymbol {\Sigma} _ {s s , i})}\tag{9}
$$

且

$$
\left\{ \begin{array}{l} \hat {\boldsymbol {\mu}} _ {f | s, j} = \boldsymbol {\mu} _ {f, j} + \boldsymbol {\Sigma} _ {f s, j} \big (\boldsymbol {\Sigma} _ {s s, j} \big) ^ {- 1} \big (\boldsymbol {\xi} _ {s} - \boldsymbol {\mu} _ {s, j} \big) \\ \hat {\boldsymbol {\Sigma}} _ {f | s, j} = \boldsymbol {\Sigma} _ {f f, j} - \boldsymbol {\Sigma} _ {f s, j} \big (\boldsymbol {\Sigma} _ {s s, j} \big) ^ {- 1} \boldsymbol {\Sigma} _ {s f, j} \end{array} \right.\tag{10}
$$

式中 $\beta _ { j }$ 为每个条件概率密度分布对新输入的预测变量 $\boldsymbol{\xi}$ 的响应度。条件期望的估计值 $E \big [ \mathcal { P } \big ( \pmb { \xi } _ { f } | \pmb { \xi } _ { s } \big ) \big ]$ 为

$$
\widehat {\boldsymbol {\xi}} _ {f} = \sum_ {j = 1} ^ {K} \beta_ {j} \widehat {\boldsymbol {\mu}} _ {f | s, j}, \quad \widehat {\boldsymbol {\Sigma}} _ {f} = \sum_ {j = 1} ^ {K} \beta_ {j} ^ {2} \widehat {\boldsymbol {\Sigma}} _ {f | s, j}\tag{11}
$$

min–max 方法的反归一化形式为

$$
\hat {\boldsymbol {F}} = (b - a) \hat {\boldsymbol {\xi}} _ {f} + a\tag{12}
$$

其中最小值因子 $a$ 和最大值因子 $b$ 凭经验分别设置为 $[ - 3 5 , - 5 5 , - 4 5 ]$ 和 $[35, 55, 45]$。最后，估计的三维自主力 $\hat { \boldsymbol{F} }$ 为 $\widehat { \pmb { \xi } } _ { f }$ 的反归一化结果。$\widehat { \pmb { \Sigma } } _ { f }$ 是从示教中提取的变异性。<sup>[47]</sup>

## 3.1.4. 底层控制器

在我们先前的研究中，<sup>[21]</sup> 我们提出了一种底层控制器，负责将接收到的估计力 $\hat { F }$ 转换为 ULCDRR 的四根绳索拉力 $F _ { 1 }$，从而促使末端执行器移动至目标位置。

末端执行器的期望位置 $\pmb { x } _ { \mathrm { d } }$ 通过基于肌电（EMG）的导纳控制器生成

$$
- M _ {\mathrm{h}} \ddot {x} _ {\mathrm{c}} - C _ {\mathrm{h}} \dot {x} _ {\mathrm{c}} + K _ {\mathrm{h}} (x _ {\mathrm{d}} - x _ {\mathrm{c}}) = F\tag{13}
$$

其中 $M _ { \mathrm { h } } , \thinspace C _ { \mathrm { h } } ,$ 和 $K _ { \mathrm { h } }$ 分别为质量、阻尼和刚度矩阵。在本文中，我们采用了简化导纳模型 $\cdot 1 ^ { \left[ 4 8 \right] }$，重写为

$$
- \boldsymbol {C} _ {\mathrm{h}} \dot {\boldsymbol {x}} _ {\mathrm{c}} + \boldsymbol {K} _ {\mathrm{h}} (\boldsymbol {x} _ {\mathrm{d}} - \boldsymbol {x} _ {\mathrm{c}}) = \boldsymbol {F}\tag{14}
$$

其中 $\pmb { x } _ { \mathrm { c } }$ 为末端执行器的当前位置。因此，我们得到以下期望位置

$$
\boldsymbol {x} _ {\mathrm{d}} = \boldsymbol {K} _ {\mathrm{h}} ^ {- 1} (\boldsymbol {F} + \boldsymbol {C} _ {\mathrm{h}} \dot {\boldsymbol {x}} _ {\mathrm{c}}) + \boldsymbol {x} _ {\mathrm{c}}\tag{15}
$$

随后，利用绳索规划器将末端执行器的期望位置 $\pmb { x } _ { \mathrm { d } }$ 转换为三根上层绳索的期望长度 $\pmb { p } _ { \mathrm { d } , 1 }$

$$
p _ {\mathrm{d}, \mathrm{l} _ {i}} = \sqrt {\left\| \boldsymbol {x} _ {\mathrm{d}} - \boldsymbol {c} _ {\mathrm{l} _ {i}} \right\| ^ {2}}, (i = 1, 2, 3)\tag{16}
$$

其中 $p _ { \mathrm { d } , \mathrm { l } _ { i } }$ 为第 $l _ { i }$ 根绳索的期望长度，$c _ { \mathrm { l _ { i } } }$ 为第 $l _ { i }$ 个滑轮在笛卡尔坐标系中的位置。此外，采用比例-积分-微分（PID）控制器驱动 ULCDRR 的绳索，使末端执行器能够跟踪期望位置

$$
\boldsymbol {F} _ {l} = \boldsymbol {K} _ {P} (\boldsymbol {p} _ {d, l} - \boldsymbol {p} _ {c, l}) + \boldsymbol {K} _ {I} \int_ {1} ^ {t} (\boldsymbol {p} _ {d, l} - \boldsymbol {p} _ {c, l}) d t + \boldsymbol {K} _ {D} (\dot {\boldsymbol {p}} _ {d, l} - \dot {\boldsymbol {p}} _ {c, l})\tag{17}
$$

其中 $\boldsymbol { F } _ { \mathrm { l } } = \left[ F _ { \mathrm { l } _ { 1 } } , F _ { \mathrm { l } _ { 2 } } , F _ { \mathrm { l } _ { 3 } } \right] ^ { \mathrm { T } }$ 为拉索力矢量（Figure 1），$\pmb { p } _ { \mathrm { d } , \mathrm { l } }$ 与 $\pmb { p } _ { \mathrm { c , l } }$ 分别为关节空间中的期望位置矢量和实际位置矢量。$K _ { \mathrm { P } }$、$K _ { \mathrm { I } }$ 和 $K _ { \mathrm { D } }$ 为对角矩阵。下部拉索 $f _ { \mathrm { l } _ { 4 } }$ 的驱动力 $F _ { \mathrm { l _ { 4 } } }$ 由拉索张力控制器控制，旨在使上部三根拉索建立正向张力分布

$$
F _ {l _ {4}} = \left\{ \begin{array}{l l} - 2 7 \Big (\min - f _ {l _ {4}} \Big) , & f _ {l _ {4}} <   f _ {\min} \\ 0 & , f _ {\min} \leq f _ {l _ {4}} \leq f _ {\max} \\ 2 7 \Big (f _ {l _ {4}} - f _ {\max} \Big) & , f _ {l _ {4}} > f _ {\max} \end{array} \right.\tag{18}
$$

其中 $f _ { \mathrm { l _ { 4 } } }$ 为拉索力测量值，且 $f _ { \mathrm { m i n } }$ 和 $f _ { \mathrm { m a x } }$ 分别设定为 7 和 10 N。

## 3.1.5. 信号处理

在本研究中，我们以 1000 Hz 的采样频率记录了原始肌电（EMG）信号。采集到的 EMG 信号经过 50 Hz 陷波滤波器和 20–450 Hz 带通滤波器的滤波处理。处理后的 EMG 信号经过全波整流，并由截止频率为 4 Hz 的四阶巴特沃斯（Butterworth）低通滤波器进一步滤波，从而提取幅度包络。幅度信号基于最大自主等长收缩 $\mathrm { ( M V C ) , } ^ { [ 4 9 ] }$ 进行归一化，并将 MVC 归一化因子合并到程序中。利用 300 ms 的滑动窗口从归一化信号中提取均方根（RMS）特征 $\pmb { e } ( t ) \in \mathbb { R } ^ { D _ { \mathrm { c h s } } \times \cdot }$，<sup>[50]</sup> 其中 $D _ { \mathrm { c h s } }$ 表示 EMG 信号的通道数，$\cdot$ 表示采样数据点数。

MATLAB 2019b 中的 pca 函数利用奇异值分解算法计算得到主成分系数 $\boldsymbol { C } \in \mathbb { R } ^ { n _ { \mathrm { p } } \times D _ { \mathrm { c h s } } }$ 和估计的中心化均值 $\pmb { \nu } \in \mathbb { R } ^ { D _ { \mathrm { c h s } } \times 1 }$。所需主成分数量 $n _ { \mathrm { p } }$ 的确定方法是：按降序依次累加 PCA 主成分的方差贡献率，直至累积和达到 99%。将 C 与 ν 的系数嵌入到 dSPACE 控制器中，并执行 ${ \pmb \xi } _ { s } = { \bf C } \times ( { \pmb e } ( t ) - { \pmb \nu } )$，以在实时控制中获取预测变量 ξ。

由六轴力传感器测量的 3D 主动力通过 5 ms 滑动窗口的中值滤波进行处理。随后，通过最小-最大（min–max）方法将力归一化到 0–1 范围，得到 $\pmb { \xi } _ { f }$ 。

## 4. 实验方案

在本研究中，实验方案主要包括三个部分：1）数据采集实验，2）校准与轨迹跟踪实验，以及 3）疲劳诱发实验。我们通过在受试者左臂布置八组 AgCl 电极实时记录肌电信号（EMG）：肱二头肌（BIC）、肱三头肌长头（TRI-LO）、肱三头肌内侧头（TRI-ME）、肱三头肌外侧头（TRI-LA）、三角肌前束（DA）、三角肌中束（DM）、三角肌后束（DP）以及肱桡肌（BR）。三维主动力数据由集成在末端执行器中的六轴力传感器采集。在数据采集实验中，我们获取了用于训练初始模型（Initial-GMM）的训练数据（包括 EMG 和力）。单次试验遵循以下流程：首先，我们通过增量 GMM 方法校准 Initial-GMM 以获得校准模型（CA-GMM）。然后，我们分别使用 Initial-GMM 和 CA-GMM 进行轨迹跟踪实验。随后，我们进行了疲劳诱发实验。最后，我们校准 Initial-GMM 以获得新的 CA-GMM，并在肌肉疲劳下重复了相同的轨迹跟踪实验。我们招募了八名健康受试者（三名女性，五名男性，年龄 $2 3 . 9 \pm 2 . 8$ 岁）参与实验。其中一人为左撇子，其余受试者均为右撇子。所有受试者均按照上述实验流程进行了两次试验。本研究已获得中山大学医学院伦理审查委员会（School of Medicine, Sun Yat-sen University Institutional Review Board）批准，伦理批准文件编号为 Medical Ethics 2021 No. 14。所有受试者均签署了书面知情同意书。

## 4.1. 数据采集实验

在数据采集实验中，我们获取了 Initial-GMM 的训练数据，包括 EMG 和力。我们在视觉反馈屏幕上设计了一个虚拟滑块跟踪任务，以指导该数据采集实验。虚拟任务的设置包括一个参考滑块和一个受控滑块（Figure 3a）。参考滑块的单次完整运动任务是在笛卡尔坐标系中完成设计的 30 s 运动，对应一个周期的数据采集。沿 X、Y 和 Z 轴的终点位置大小通过经验分别确定为 [35, 55, 45]。具体而言，运动从原点开始，前进至 $+ X ,$ 的末端，返回原点，行进至 $\operatorname { o f } - X ,$ 的末端并返回原点，接着在 Z 方向上执行，最后在 Y 方向上执行。参考滑块的运动方向和位置引导了受试者施加力的方向和大小。受控滑块的位置反映了受试者施加力的方向和大小，其中力到滑块的映射是通过集成在末端执行器中的六轴力传感器实现的。

在本研究中，我们通过静态等长收缩实验采集了训练数据，其中末端执行器被四根线缆约束在原点。实验包括肌肉放松示范和施力示范。在肌肉放松示范过程中，参与者抬起左臂，不对末端执行器施加力。在施力示范中，参与者通过对末端执行器施加力，控制受控滑块跟踪参考滑块的运动。我们采集了 20 个周期的训练数据，包括来自肌肉放松示范的 2 个周期数据和来自施力示范的 18 个周期数据。完成数据采集后，我们通过五折交叉验证方法确定了每位受试者 Initial-GMM 的高斯分量数量。<sup>[51]</sup>

## 4.2. 校准与轨迹跟踪实验

在校准实验中，我们设计了一个包含六次 EM 迭代的示范任务来校准 Initial-GMM。本实验中的示范与数据采集实验中执行的施力示范相同。

在轨迹跟踪实验中，我们在视觉反馈屏幕上设计了一个虚拟 3D 任务空间，包括一个红色参考滑块和一条圆角矩形轨迹（Figure 3b）。受试者跟踪红色参考滑块的运动，使用基于 EMG 的控制绘制所需轨迹。我们为轨迹跟踪任务设计了两个区块。每个区块包括两种基于 EMG 的控制方案：一种基于 Initial-GMM $( \mathbf { \Theta } _ { \mathbf { 0 } } )$，另一种基于 CA-GMM $( \Theta _ { n } )$。每种控制方案在每个区块中执行一个轨迹跟踪周期。控制方案的选择是随机的，受试者不知道当前的方案。

我们在诱发疲劳实验之前和之后均进行了校准与轨迹跟踪实验，其中获得的 CA-GMM 均由 Initial-GMM 迭代得到。此外，紧随诱发疲劳实验之后的校准和轨迹跟踪实验是立即进行的，没有任何休息时间。在正式实验之前，参与者使用基于 Initial-GMM 的方案进行了四到五次跟踪练习。

## 4.3. 疲劳诱导实验

在疲劳诱导实验中，我们设计了一个等长收缩任务来诱发肌肉疲劳。我们在视觉反馈屏幕上的虚拟空间中采用了一个目标逼近任务，其中包括一个固定的红色目标滑块和一个绿色的被控滑块（Figure 3c）。末端执行器通过四根线缆被约束在原点，并将受试者施加的力转换为被控滑块的位置。被控滑块作为力的测量指标，反映了力的大小和方向。该设置遵循了 Tkach 等人<sup>[52]</sup>的实验方案，参与者在力测量指示的引导下通过静态等长收缩进行疲劳诱导实验。参与者控制被控滑块向目标滑块移动，并尽最大努力保持目标滑块所设定的发力水平。在疲劳诱导实验过程中，我们鼓励参与者坚持。如果受试者表示过于疲劳无法继续，实验则停止。疲劳诱导实验之后的校准和轨迹跟踪实验立即进行。中途不安排休息时间，以防止肌肉疲劳恢复。其假设是，在疲劳诱导实验后的校准和轨迹跟踪实验中，肌肉疲劳保持在相同水平。<sup>[53]</sup>

## 5. 结果

如图 Figure 4 所示，在疲劳诱导实验之前，基于 Initial-GMM 和 CA-GMM 的 3D 主动发力估计的平均 RMSE 低于实验之后。随着校准实验中 EM 迭代次数的增加，基于 CA-GMM 的平均 RMSE 单调递减。在疲劳诱导实验之前，尽管 CA-GMM 的平均 RMSE 高于 Initial-GMM，但随着 EM 迭代次数的增加，CA-GMM 与 Initial-GMM 之间平均 RMSE 的差距逐渐缩小。在疲劳诱导实验之后，在前四次 EM 迭代中，CA-GMM 的平均 RMSE 结果高于 Initial-GMM。然而，从第五次 EM 迭代开始，CA-GMM 的 RMSE 结果低于 Initial-GMM，表明其在 3D 力估计精度方面具有更好的性能。

## 6. 讨论

本研究提出了一种基于肌电（EMG）的控制模型，该模型采用高斯混合模型（GMM）来估计三维连续力，其中连续意图有助于促进与被试无关的控制任务。<sup>[11]</sup> Chao 等人在关于三维手指力的研究中强调了考虑各维度分量耦合的重要性。<sup>[54]</sup> 与 Hill 型模型<sup>[18]</sup>和并行一维力估计方法<sup>[15,24]</sup>相比，GMM 通过建立联合概率密度分布，直接对肌电与三维力之间包含不确定性的关联进行编码。具体而言，GMM 协方差矩阵的互相关系数对三维分量之间的相互联系以及力与肌电信号之间的关系进行了编码。Zhang 等人提出了一个建模假设，即肌电与三维力之间的关系包含共享特征和维度特定特征。<sup>[16]</sup> Hogan 等人提出高斯分布可以对肌肉收缩与肌电活动之间的关系进行建模。<sup>[55]</sup> GMM 的每个高斯分量都可以体现对这种单一事件的提取，而它们加权组合形成的 GMM 则可对应宏观肌肉活动的构成。GMM 通过调整高斯分量的数量，可以灵活处理具有不同复杂度的肌电–力关系的模型学习。与 Zhang 等人<sup>[16]</sup>相比，具有多个高斯分量的 GMM 可能更适合利用多通道肌电信号进行三维手臂力的估计。

智能肌电接口中的嵌入式计算模型应考虑计算成本和泛化能力。与基于核的多输出方法（如 GRNN<sup>[25]</sup> 和多输出支持向量回归<sup>[56]</sup>）相比，GMM 可以通过高斯混合回归（GMR）实现快速的三维自主力输出，在预测期间无需访问源数据即可执行实时的基于肌电的控制。<sup>[31]</sup> 与需要专门结构设计的模型<sup>[15,16,24,26,27]</sup>相比，GMM 仅需确定高斯分量的数量。针对肌电的时变性<sup>[42]</sup>以及肌肉疲劳导致的发力变异性增加<sup>[57]</sup>，由 GMM 协方差编码的肌电–力关系的变异性有助于在涉及不确定性的环境变化影响下进行概率推理。在本研究中，我们还共享了 GMM 中每个分量的协方差参数（即共享协方差），以提高归纳偏置下的泛化性能。<sup>[58]</sup>

GMM（高斯混合模型）与 GMR（高斯混合回归）相结合可被视为一种仿生技术，因为它模拟了人脑进行概率建模和推理的过程。<sup>[32,33]</sup> 复杂的人机交互需要人的参与<sup>[15,59]</sup>，并依赖于基于人类中枢神经系统的调控。<sup>[60]</sup> 仿生模型能够促进人类中枢神经系统的控制，从而提升基于 EMG（肌电信号）的物理人机交互性能。<sup>[22,61]</sup>

由于肌肉疲劳引起的肌电–力关系（EMG–force relationship）改变，基于肌电（EMG）的导纳控制性能可能会发生退化。针对肌肉疲劳的影响，我们将基于增量高斯混合模型（incremental GMM）的校准算法集成到了 dSPACE 控制器中。如图 Figure 4 所示，在肌肉疲劳状态下，经过五次 EM 迭代后，使用 CA-GMM 的手臂力估计精度即可超过 Initial-GMM。该结果表明，基于 EMG 的计算模型如果每次仅进行单次校准，可能无法实现性能补偿。基于增量学习的校准可以通过持续积累经验来促进模型与受试者之间的匹配，从而有望改善采用基于 EMG 界面的机器人辅助康复。如图 Figure 7 所示，在肌肉疲劳的影响下，基于 CA-GMM 的 EMG 控制提高了跟踪精度，增强了控制顺应性并降低了 IF。结果表明，当采用合适的 EMG 解码器模型时，基于智能 EMG 的人机交互界面受到的影响较小。这种改善主要归因于两个因素：首先，不准确的均值向量直接反映了分布偏移，而对均值向量的校准使 GMM 与 EMG–力关系得以重新匹配。其次，协方差矩阵的校准适应了肌肉疲劳引起的 EMG–力关系不确定性的增加。在存在肌肉疲劳的情况下，使用 CA-GMM 的基于 EMG 的控制提高了跟踪精度，且无需以额外的顺应性损失和 IF 增加为代价。这种成本的降低表明，所提出的方法可以提高基于 EMG 的控制系统的舒适度与安全性，从而在保持一致训练强度的同时，潜在地促进参与者持续投入训练。在诱发疲劳实验之前，基于 CA-GMM 的 EMG 控制并未取得更高的跟踪精度，这可能是因为在六次 EM 迭代中，CA-GMM 的估计性能相比 Initial-GMM 仍显不足（如图 Figure 4 所示）。然而，统计结果显示出相似的跟踪性能，这表明人类的运动适应能力可以应对基于 EMG 的控制模型中的某些差异。<sup>[62]</sup> 但是，在基于 EMG 的物理人机交互（pHRI）过程中，这种运动适应能力在应对肌肉疲劳时可能并不充分，因此需要所提出的利用增量 GMM 的机器智能自适应校准。

本研究存在两点局限性。首先，本研究仅纳入了健康受试者。我们在后续工作中将招募合适的患者参与者。其次，所提出的技术在不同平台上可能存在性能差异，因此需要进一步的研究。

## 7. 结论

本文提出了一种改进的 GMM 来估计三维主动力，并在 ULCDRR 平台上实现了基于 EMG 的导纳控制。实验结果表明，所提出的采用 GMM 的基于 EMG 的导纳控制能够提高物理人机交互过程中的控制精度与顺应性。校准后的 GMM 的应用降低了基于 EMG 控制过程中肌肉疲劳的影响。因此，所提出的方法在基于 EMG 的机器人辅助康复以及涉及物理人机交互的其他领域具有潜在的应用价值。未来的工作可以在不同的参与者群体上评估所提方法的性能。

## A1. GMM 中的公式推导

求解 GMM 的极大似然估计在求偏导时存在困难；因此，通常采用 EM 算法。

$$
\boldsymbol {\theta} ^ {(g + 1)} = \arg \max \underbrace {\mathbb {E} _ {z | \boldsymbol {\xi} , \boldsymbol {\theta} ^ {(g)}} [ \log \mathcal {P} (\boldsymbol {\xi} , z | \boldsymbol {\theta}) ]} _ {\mathcal {Q} (\boldsymbol {\theta}, \boldsymbol {\theta} ^ {(g)})}\tag{A1}
$$

其中 $Q \big ( \pmb \theta , \pmb \theta ^ { ( g ) } \big )$ 是 EM 算法的目标函数，$z \in \{ z _ { m } = j | j = 1 , \ \cdot \ \cdot \ , K \}$ 是隐变量。

$$
\begin{array}{l} Q \big (\boldsymbol {\theta}, \boldsymbol {\theta} ^ {(g)} \big) = \int_ {Z} \log \mathcal {P} (\boldsymbol {\xi}, Z | \boldsymbol {\theta}) \times \mathcal {P} \big (Z | \boldsymbol {\xi}, \boldsymbol {\theta} ^ {(g)} \big) d Z \\ = \sum_ {z _ {1}, \dots , z _ {N}} \left\{\left[ \sum_ {m = 1} ^ {N} \log \mathcal {P} (\boldsymbol {\xi} _ {m}, z _ {m} | \boldsymbol {\theta}) \right] \prod_ {m = 1} ^ {N} \mathcal {P} \big (z _ {m} | \boldsymbol {\xi} _ {m}, \boldsymbol {\theta} ^ {(g)} \big) \right\} \\ = \sum_ {m = 1} ^ {N} \sum_ {z _ {m} = 1} ^ {K} \log \mathcal {P} (\boldsymbol {\xi} _ {m}, z _ {m} | \boldsymbol {\theta}) \times \mathcal {P} \big (z _ {m} | \boldsymbol {\xi} _ {m}, \boldsymbol {\theta} ^ {(g)} \big) \end{array}\tag{A2}
$$

根据贝叶斯法则，有

$$
\mathcal {P} (\boldsymbol {\xi}, \boldsymbol {z} | \boldsymbol {\theta}) = \mathcal {P} (\boldsymbol {z} | \boldsymbol {\theta}) \mathcal {P} (\boldsymbol {\xi} | \boldsymbol {z}, \boldsymbol {\theta})\tag{A3}
$$

$$
\mathcal {P} \big (z | \boldsymbol {\xi}, \boldsymbol {\theta} ^ {(g)} \big) = \frac {\mathcal {P} (\boldsymbol {\xi} , z | \boldsymbol {\theta})}{\mathcal {P} \big (\boldsymbol {\xi} | \boldsymbol {\theta} ^ {(g)} \big)}\tag{A4}
$$

将 (A3) 和 (A4) 代入 (A2)，可推导出

$$
\begin{array}{l} Q (\boldsymbol {\theta}, \boldsymbol {\theta} ^ {(g)}) = \sum_ {j = 1} ^ {K} \sum_ {m = 1} ^ {N} \log \mathcal {P} (\boldsymbol {\xi} _ {m}, \boldsymbol {\theta} _ {j}) \times \mathcal {P} (\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}) \\ = \sum_ {j = 1} ^ {K} \sum_ {m = 1} ^ {N} \log \left(\pi_ {j} \mathcal {N} (\boldsymbol {\xi} _ {m} | \boldsymbol {\mu} _ {j}, \boldsymbol {\Sigma} _ {j})\right) \times \frac {\pi_ {j} ^ {(g)} \mathcal {N} (\boldsymbol {\xi} _ {m} | \boldsymbol {\mu} _ {j} ^ {(g)} , \boldsymbol {\Sigma} _ {j} ^ {(g)})}{\sum_ {i = 1} ^ {K} \pi_ {i} ^ {(g)} \mathcal {N} (\boldsymbol {\xi} _ {m} | \boldsymbol {\mu} _ {i} ^ {(g)} , \boldsymbol {\Sigma} _ {i} ^ {(g)})} \end{array}\tag{A5}
$$

为了求解 $\pi _ { j } { \mathrm { : } }$ 的偏导数，我们可以将式 (A5) 重写为

$$
G (\pi , \lambda) = \sum_ {j = 1} ^ {K} \sum_ {m = 1} ^ {N} \log \pi_ {j} \times \mathcal {P} \left(\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}\right) + \lambda \left(\sum_ {j = 1} ^ {K} \pi_ {j} - 1\right)\tag{A6}
$$

其中 λ 为拉格朗日乘子（Lagrange multiplier）。为了求解 $\pmb { \mu } _ { j }$ 和 $\Sigma _ { j }$ 的偏导数，我们可以将式 (A5) 简化为

$$
G (\boldsymbol {\mu}, \boldsymbol {\Sigma}) = \sum_ {j = 1} ^ {K} \sum_ {m = 1} ^ {N} \log \mathcal {N} \left(\boldsymbol {\xi} _ {m} | \boldsymbol {\mu} _ {j}, \boldsymbol {\Sigma} _ {j}\right) \times \mathcal {P} \left(\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}\right)\tag{A7}
$$

通过计算式 (A6) 和 (A7) 中的偏导数，我们可以得到 EM 算法中 M 步（M-step）的迭代公式：

$$
\left\{ \begin{array}{l} \pi_ {j} ^ {(g + 1)} = \frac {1}{N} \sum_ {m = 1} ^ {N} \mathcal {P} \left(\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}\right) \\ \boldsymbol {\mu} _ {j} ^ {(g + 1)} = \frac {\sum_ {m = 1} ^ {N} \mathcal {P} \left(\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}\right) \boldsymbol {\xi} _ {m}}{\sum_ {m = 1} ^ {N} \mathcal {P} \left(\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}\right)} \\ \boldsymbol {\Sigma} _ {j} ^ {(g + 1)} = \frac {\sum_ {m = 1} ^ {N} \mathcal {P} \left(\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}\right) \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) ^ {T}}{\sum_ {m = 1} ^ {N} \mathcal {P} \left(\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}\right)} \end{array} \right.\tag{A8}
$$

因此，GMM（高斯混合模型）的 E 步仅需计算

$$
\mathcal {P} \left(\boldsymbol {\theta} _ {j} ^ {(g)} | \boldsymbol {\xi} _ {m}\right) = \frac {\pi_ {j} ^ {(g)} \mathcal {N} \left(\boldsymbol {\xi} _ {m} | \boldsymbol {\mu} _ {j} ^ {(g)} , \boldsymbol {\Sigma} _ {j} ^ {(g)}\right)}{\sum_ {i = 1} ^ {K} \pi_ {i} ^ {(g)} \mathcal {N} \left(\boldsymbol {\xi} _ {m} | \boldsymbol {\mu} _ {i} ^ {(g)} , \boldsymbol {\Sigma} _ {i} ^ {(g)}\right)} = \gamma_ {m, j} ^ {(g + 1)}\tag{A9}
$$

以及 $\begin{array} { r } { E _ { j } ^ { ( g + 1 ) } = \sum _ { m = 1 } ^ { N } \gamma _ { m , j } ^ { ( g + 1 ) } } \end{array}$，而不是整个 Q 函数。

增量 GMM 算法的结果已在研究<sup>[46]</sup>中给出。基于 (A8) 的直接法的推导技巧是将与初始数据集 $\left\{ \pmb { \xi } _ { m } \right\} _ { m = 1 } ^ { N _ { 0 } }$ 相关的部分与对应于当前采样数据集 $\{ \pmb { \xi } _ { m } \} _ { m = 1 } ^ { N _ { n } }$ 的部分分离开来。因此，我们有

$$
\pi_ {j} ^ {(g + 1)} = \frac {\sum_ {m = 1} ^ {N _ {0}} \gamma_ {m , j} ^ {(0)} + \sum_ {m = N _ {0} + 1} ^ {N _ {0} + N _ {n}} \gamma_ {m , j} ^ {(g + 1)}}{N _ {0} + N _ {n}} = \frac {E _ {j} ^ {(0)} + E _ {j} ^ {(g + 1)}}{N _ {0} + N _ {n}}\tag{A10}
$$

其中 $\gamma _ { m , j } ^ { ( 0 ) } = \mathcal { P } \Big ( \pmb { \theta } _ { j } ^ { ( 0 ) } | \pmb { \xi } _ { m } \Big )$ 且 $\begin{array} { r } { E _ { j } ^ { ( 0 ) } = \sum _ { m = 1 } ^ { N _ { 0 } } \gamma _ { m , j } ^ { ( 0 ) } } \end{array}$。$\pmb { \mu } _ { j } ^ { ( g + 1 ) }$ 和 $\pmb { \Sigma } _ { j } ^ { ( g + 1 ) }$ 的推导为

$$
\begin{array}{c} \boldsymbol {\mu} _ {j} ^ {(g + 1)} = \frac {\sum_ {m = 1} ^ {N _ {0}} \gamma_ {m , j} ^ {(0)} \boldsymbol {\xi} _ {m} + \sum_ {m = N _ {0} + 1} ^ {N _ {0} + N _ {n}} \gamma_ {m , j} ^ {(g + 1)} \boldsymbol {\xi} _ {m}}{\sum_ {m = 1} ^ {N _ {0}} \gamma_ {m , j} ^ {(0)} + \sum_ {m = N _ {0} + 1} ^ {N _ {0} + N _ {n}} \gamma_ {m , j} ^ {(g + 1)}} \\ = \frac {E _ {j} ^ {(0)} \boldsymbol {\mu} _ {j} ^ {(0)} + \sum_ {m = 1} ^ {N _ {n}} \gamma_ {m , j} ^ {(g + 1)} \boldsymbol {\xi} _ {m}}{E _ {j} ^ {(0)} + E _ {j} ^ {(g + 1)}} \end{array}\tag{A11}
$$

以及

$$
\begin{array}{l} \boldsymbol {\Sigma} _ {j} ^ {(g + 1)} = \frac {\sum_ {m = 1} ^ {N _ {0}} \gamma_ {m , j} ^ {(0)} \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) ^ {T}}{\sum_ {m = 1} ^ {N _ {0}} \gamma_ {m , j} ^ {(0)} + \sum_ {m = N _ {0} + 1} ^ {N _ {0} + N _ {n}} \gamma_ {m , j} ^ {(g + 1)}} \\ + \frac {\sum_ {m = N _ {0} + 1} ^ {N _ {0} + N _ {n}} \gamma_ {m , j} ^ {(g + 1)} \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) ^ {T}}{\sum_ {m = 1} ^ {N _ {0}} \gamma_ {m , j} ^ {(0)}   +   \sum_ {m = N _ {0} + 1} ^ {N _ {0} + N _ {n}} \gamma_ {m , j} ^ {(g + 1)}} \end{array}
$$

(A12)

$$
\begin{array}{l} \sum_ {m = 1} ^ {N _ {0}} \gamma_ {m, j} ^ {(0)} \times \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) ^ {\mathrm{T}} \\ = \sum_ {m = 1} ^ {N _ {0}} \gamma_ {m, j} ^ {(0)} \times \left(\boldsymbol {\xi} _ {m} \boldsymbol {\xi} _ {m} ^ {\mathrm{T}} - \boldsymbol {\mu} _ {j} ^ {(0)} \boldsymbol {\mu} _ {j} ^ {(0), \mathrm{T}} - \boldsymbol {\xi} _ {m} \boldsymbol {\mu} _ {j} ^ {(g + 1), T} - \boldsymbol {\mu} _ {j} ^ {(g + 1)} \boldsymbol {\xi} _ {m} ^ {\mathrm{T}} + \boldsymbol {\mu} _ {j} ^ {(g + 1)} \boldsymbol {\mu} _ {j} ^ {(g + 1), \mathrm{T}}\right) \\ = \sum_ {m = 1} ^ {N _ {0}} \gamma_ {m, i j} ^ {(0)} \left(\boldsymbol {\xi} _ {m} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) ^ {\mathrm{T}} \\ + \sum_ {m = 1} ^ {N _ {0}} \gamma_ {m, j} ^ {(0)} \left(\boldsymbol {\mu} _ {j} ^ {(g + 1)} \boldsymbol {\mu} _ {j} ^ {(g + 1), \mathrm{T}} - \boldsymbol {\mu} _ {j} ^ {(0)} \boldsymbol {\mu} _ {j} ^ {(0), \mathrm{T}}\right) + \sum_ {m = 1} ^ {N _ {0}} \gamma_ {m, j} ^ {(0)} \left(\boldsymbol {\mu} _ {j} ^ {(0)} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) \boldsymbol {\xi}. \\ = E _ {j} ^ {(0)} \boldsymbol {\Sigma} _ {j} ^ {(0)} + E _ {j} ^ {(0)} \boldsymbol {\mu} _ {j} ^ {(0)} \left(\boldsymbol {\mu} _ {j} ^ {(0)} - \boldsymbol {\mu} _ {j} ^ {(g + 1)}\right) ^ {\mathrm{T}} \\ + E _ {j} ^ {(0)} \left(\boldsymbol {\mu} _ {j} ^ {(g + 1)} \boldsymbol {\mu} _ {j} ^ {(g + 1), \mathrm{T}} - \boldsymbol {\mu} _ {j} ^ {(0)} \boldsymbol {\mu} _ {j} ^ {(0), \mathrm{T}}\right) + (\boldsymbol {\mu} - $$

$$
