## 摘要 [原文]

> 基于视觉的人体关节角度估计对于**远程与连续的健康监测**至关重要。大多数基于视觉的角度估计方法，使用的是通过**光学动作相机、深度相机或人体姿态估计模型**提取的人体关节位置。本研究旨在提出一种**可靠且直接**的方法，使用**深度学习网络**从 **RGB 视频**中估计**膝与肘的屈伸角度（flexion/extension angle）**。本研究招募了**十五名健康受试者**完成**四种日常活动**。实验使用了**四种不同的深度学习网络**，网络以**九个连续帧**作为输入，输出为**每一帧**由**光学动作捕捉系统**提取的膝与肘关节角度。**基于 BiLSTM 网络的关节角度估计器能够估计两个关节的角度，膝关节相关系数为 0.955、肘关节为 0.917，且不受相机视角影响。**

## 一、方法骨架 [原文]

```
输入：9 个连续帧（nine subsequent frames）+ 人体边界框真值
        │
        ▼
   预处理：按边界框裁剪 → 左右补边成正方形 → resize 至 448×448
        │
        ▼
┌──────────────────────────────────────────────────────────┐
│ 四种深度学习网络对比：                                    │
│   ① BiLSTM（主方案，最优）                                │
│   ② LSTM（单向）                                          │
│   ③ ResNet18_SF（单帧训练）                               │
│   ④ ResNet18_MF（9 帧堆叠训练）                            │
└──────────────────────────────────────────────────────────┘
        │
        ▼
输出：右/左膝 + 右/左肘 屈伸角度（每一帧 4 个角度）
        │
  真值：光学动作捕捉系统（6 相机）
```

### 1.1 BiLSTM 网络结构 [原文]

| 项 | 值 |
|---|---|
| 结构 | **4 层双向 LSTM（four bidirectional LSTM layers）** |
| 后续 | **2 个全连接层（FC）**，激活函数 **ReLU** |
| 输出层 | **4 个神经元** —— 对应**右/左膝**屈伸与**右/左肘**屈伸 |
| 对比网络的处理 | ResNet18_SF / ResNet18_MF / LSTM 均**移除原最后一层 FC，并新增一层 FC** 以适配本任务的输出 |

### 1.2 四个对比网络的含义 [原文]

| 网络 | 含义 |
|---|---|
| **BiLSTM** | 双向 LSTM（**本文最优**） |
| **LSTM** | **单向** LSTM |
| **ResNet18_SF** | ResNet18，**单帧（single frame）**训练 |
| **ResNet18_MF** | ResNet18，**9 帧堆叠（multi-frame）**训练 |

> 💡 **设计意图**：这是一组**消融式对比**——用 ResNet18_SF vs ResNet18_MF 隔离**时序信息的价值**；
> 用 LSTM vs BiLSTM 隔离**双向机制的价值**。

## 二、数据与协议 [原文]

### 2.1 受试者与伦理

| 项 | 值 |
|---|---|
| 受试者 | **15 名**（**12 男 / 3 女**） |
| 筛选 | 无神经系统疾病者参与 |
| 所有参与者 | 均签署知情同意 |

### 2.2 采集设备 [原文]

| 项 | 值 |
|---|---|
| 光学动捕 | **6 台光学动作捕捉相机**（真值） |
| RGB 相机 | **4 台 RGB 相机** |
| RGB 分辨率 / 帧率 | **Full HD（1920×1080）/ 60 Hz** |
| 同步方法 | **闪光同步（flash-based synchronization）**：在光学相机录制时**产生 100 ms 脉冲**，数字相机捕获闪光瞬间；用这些闪光信号对每位受试者、每个动作试验做同步 |
| 标记点位置 | 覆盖受试者**双膝与双肘** |

### 2.3 四种日常活动协议 [原文]

| 活动 | 英文 | 协议 |
|---|---|---|
| **深蹲** | **Squat** | 受试者**持续深蹲 30 秒** |
| **原地踏步** | **Walking in Place (WIP)** | 以**自选速度原地行走** |
| **单腿站立** | **One Leg Stand (OLS)** | 单腿站立并抬起另一条腿，**两侧交替重复** |
| **手臂运动** | **Arm** | 双臂与地面平行并屈肘 → 向体侧伸展 → 回到初始姿势 → 向前推臂 → 返回。**保持直立，重复 1 分钟** |

### 2.4 数据集规模 [原文]

| 项 | 值 |
|---|---|
| **总帧数** | **1,290,000 帧（1.29 M）** |
| **降采样** | 视频与动捕数据均**降采样至 30 Hz** |
| 标注内容 | 每帧提供**人体边界框** + **四个角度**（右/左膝屈伸、右/左肘屈伸） |
| 真值 | 由光学动捕数据计算 | 

### 2.5 输入预处理 [原文]

按**真值人体边界框**裁剪 → **左右补边（pad left and right）成正方形** → **resize 至 448 × 448**。

> 💡 **与竞品的一致性**：KIST 在这篇（2022）用 **448×448**，在 **EMBC 2023**（`Jamsrandorj_2023_..._全文翻译.md`）也用 **448×448**，
> 在 **Chao 2026 Measurement** 用 **224×224**。**448×448 是该团队的早期标准配置**。

## 三、结果（完整数值表）[原文]

### 3.1 Table II — 四个网络的 MAE 与 PCC

| 模型 | 右膝 | 左膝 | 右肘 | 左肘 |
|---|---|---|---|---|
| **MAE (°)** | | | | |
| ResNet18_SF | 8.29 | 7.83 | 15.37 | 16.07 |
| ResNet18_MF | 10.17 | 9.34 | 14.64 | 14.28 |
| LSTM | **8.24** | 8.32 | 15.37 | 16.59 |
| **BiLSTM** | 8.67 | **7.73** | **9.80** | **10.29** |
| **PCC** | | | | |
| ResNet18_SF | **0.975** | 0.975 | 0.887 | 0.902 |
| ResNet18_MF | 0.974 | 0.968 | 0.882 | 0.900 |
| LSTM | 0.973 | 0.955 | 0.890 | 0.901 |
| **BiLSTM** | **0.975** | **0.976** | **0.917** | **0.922** |

### 3.2 关键发现 [原文]

| # | 发现 |
|---|---|
| 1 | **右膝**最高 PCC 为 **0.975**，由 **ResNet18_SF 与 BiLSTM** 共同取得 |
| 2 | **左膝 / 右肘 / 左肘** 最高 PCC 分别为 **0.976 / 0.917 / 0.922**，**均由 BiLSTM 取得** |
| 3 | **BiLSTM 的肘部 MAE（9.80 / 10.29）显著优于其他三个网络（14.28–16.59）** —— 差距接近一倍 |
| 4 | **右膝最小 MAE 8.24 由 LSTM 取得**（BiLSTM 为 8.67）—— 说明 BiLSTM **并非在所有指标上都最优** |
| 5 | **BiLSTM 最小 MAE**：左膝 **7.73**、右肘 **9.80**、左肘 **10.29** |
| 6 | **肘角估计的 MAE 系统性高于膝角**（约 10 vs 约 8） |

> 🔴 **第 4 条是重要的诚实细节**：**右膝上 LSTM（8.24）优于 BiLSTM（8.67）**。
> 故「BiLSTM 最优」的结论**只在 PCC 与肘部 MAE 上成立**，不是全面占优。

### 3.3 相机视角的影响 [原文]

- 分析了不同相机视角对**肘**屈伸角度估计的影响（Table VI）
- 原文指出：深度学习网络估计肘关节角度时具有**更高的 MAE**，且**相机视角会影响肘部估计**

> ⚠️ 原文在此处**把「肘部 MAE 更高」与「视角影响»并置讨论**，
> 但**未给出「视角差异导致 MAE 上升多少」的量化分离**。

## 四、与 ViKiT（我方）的差异

**这篇是"历史基线"，不是直接竞品**——它是同一 KIST 团队 4 年前的工作，但**它定义了该团队的方法起点**。

| 维度 | Jamsrandorj 2022 EMBC（原文实测） | ViKiT（我方） |
|---|---|---|
| **输入窗口** | **9 帧 = 0.3 s @30 Hz（极短上下文）** | **长序列（81 帧 ≈ 2.7 s）** |
| **时序模型** | **4 层双向 LSTM + 2 FC** | 分解式时空 Transformer + cross-attention |
| **输出表征** | 连续角度向量（**逐帧独立回归**） | **Kinematic tokens + vocabulary** |
| **任务定义** | 角度**回归** | 生物力学语言**翻译**（Seq2Seq） |
| **输出结构** | **每帧独立输出 4 个角度** | **一次性翻译出一整段运动学序列** |
| **物理约束** | **无**（未提任何 grammar/ROM/FK 约束） | **6 项 grammar loss** |
| **关节** | 膝 / 肘（下肢+上肢混合） | 腕 / 肘 / 肩（上肢代偿协同） |
| **视角鲁棒性** | ✅ 已做（4 台相机；**view-independent 是卖点**） | 规划中（作为**必备门槛**） |
| **提前预测** | ❌ 无 | ✅ 100 / 200 / 300 ms |
| **数据规模** | **1.29 M 帧 / 15 受试者 / 4 活动** | 规划用公开数据 |
| **背景表示** | **真值人体边界框**（非检测器输出！） | 需自检人体检测 |

### 4.1 三条对本库有价值的推论

1. **9 帧窗口是"短上下文"路线的代表。**
   我方主打长序列 + 时序一致性，**必须**在 `04_实验设计/对比方案.md` 中把
   「短窗 BiLSTM」列为 Pipeline / Direct-Regression 类基线，并明确论证"长上下文带来什么增益"。

2. **"view-independent" 在 2022 年就已是卖点。**
   我方不能把跨视角鲁棒性当创新，只能当**必备门槛**。
   这与 Chao 2026（4 个 Region）的结论一致。

3. **它的输出是逐帧独立角度而非序列。**
   这与我方的"序列到序列翻译"在**输出结构上**就不同——**这是一条不需要实验结果就能成立的结构差异**。

### 4.2 🔴 一条重要的协议差异（我方需注意）

> 原文明确：输入使用的是**「真值人体边界框（ground truth human bounding boxes）」**，
> 即**边界框来自人工标注，而不是检测器输出**。

**含义**：
- 该工作的精度**不包含人体检测误差** —— 这是一个**乐观设定**
- 对比之下，**Chao 2026 使用 YOLOv8（检测器）生成边界框**，更接近实际部署
- **我方若用检测器，则与本文不可直接比较**；若要用真值框以对齐，必须**明确声明该设定**
