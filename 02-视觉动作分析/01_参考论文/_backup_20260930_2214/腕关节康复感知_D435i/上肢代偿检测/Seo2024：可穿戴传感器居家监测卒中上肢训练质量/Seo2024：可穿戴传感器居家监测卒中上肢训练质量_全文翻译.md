## 摘要（中文译文）

> **许多卒中幸存者存在持续的上肢功能损害，限制了其日常生活活动能力。**
> **上肢恢复需要高重复次数的任务特异训练。** 卒中幸存者常被处方在**家中**进行任务训练，以补充康复治疗。
> **训练质量不佳——例如使用代偿性运动模式——会导致适应不良的神经可塑性（maladaptive neuroplasticity）与次优的运动恢复。**
> **目前缺乏一种用于远程监测卒中幸存者居家任务训练运动质量的工具。**
>
> 本研究的目的是**评估使用可穿戴 IMU 在家中对运动质量进行分类的可行性**。
> **19 名卒中幸存者**在**患侧腕部佩戴一个 IMU 传感器**，在**实验室完成四项功能性上肢任务**，
> **随后在家完成并要求自行录像**。实验室数据作为**参考数据**，
> 使用**动态时间规整（dynamic time warping, DTW）**对居家运动质量进行分类。
>
> （结果）……**运动质量分类准确率为 92%，F1 分数为 0.95**（所有任务合并）。
> 研究进一步考察了**导致误分类的运动类型**。**结果支持「居家运动质量监测系统辅助卒中后上肢康复」的可行性。**

## 一、方法骨架

```
19 名卒中幸存者
        │
        ▼
患侧腕部佩戴 1 个 IMU
        │
        ├──────────────────────┬──────────────────────┐
        ▼                      ▼
实验室完成 4 项功能性任务        在家完成同样 4 项任务
（作为参考数据 reference）        （并要求自行录像）
        │                              │
        │                              ▼
        │                      录像人工复核 → 居家数据的
        │                      真值标签（ground truth）
        │                              │
        └──────────┬───────────────────┘
                   ▼
        DTW（动态时间规整）
        ★ 个体化建模（person-specific modeling）
                   │
                   ▼
        输出：居家每次试验的「运动质量」正确/不正确
```

### 1.1 ★ 核心方法选择：为什么用 DTW + 个体化建模（原文理由，可直接引用）

> **① 个体化建模（person-specific）** 用于**容纳卒中幸存者之间高度异质的运动模式**，
> 并**聚焦于每个个体幸存者自身的代偿运动模式**去做检测。
>
> **② 每个受试者的实验室数据被用作参考**，来分类**他自己的**居家数据。
>
> **③ DTW 适合**：它**能适应试验的不同时长**，并能实现**患者特异（patient-specific）**的算法。

> 💡 **这是一条重要的方法论决策**：**不做跨被试的通用分类器，而做被试自身的基线对照。**
> **优点**：回避了跨被试异质性（这正是 Wang 2022 指出该领域 ML 方法「异质」的根源）。
> **代价**：每位患者需要先采一次实验室基线 —— 部署成本更高。

### 1.2 四项功能性任务 [原文 Table 3]

| # | 任务 | 描述 |
|---|---|---|
| **1** | **Cup to shelf**（杯子上架） | 从身前桌面抓取杯子 → 举到桌面上的架子上 → 松开 → 手回到桌面 |
| **2** | **Cup to mouth**（杯子到嘴） | 从身前桌面抓取杯子 → 举到嘴边 → 杯子放回桌面，**模拟饮水动作** |
| **3** | **Tongs use**（使用夹子） | [原文 Table 3 第 3 行] |

**原文核验结果**：

  **输出不含「哪个关节代偿」的信息**。这一点在本库中的表述**准确**。

### 2.2 ⚠️ 一处需要补充的限定条件（本库原有表述未含）

> **92% / F1 0.95 是在「个体化建模（用本人的实验室数据做参考）」条件下取得的**，
> **不是**「拿一个通用模型直接测任意患者」。

**这意味着**：
- 该数字**不能**被解读为「单腕 IMU 通用分类器的性能」
- 若本库设想**不采基线直接部署**，则**不能引用这个 92%**
- 部署流程包含**一次实验室基线采集** → 这是**成本与可行性的关键约束**

→ **已登记为 §四 待办第 1 项。**

### 2.3 误分类的运动类型 [原文举例]

原文举例的误分类情形涉及：**躯干屈曲（trunk flexion）** 与 **前臂异常旋前（abnormal forearm supination）**。

> 💡 **对本库的价值**：这给出了「**单腕 IMU 难以捕捉的代偿类型**」的具体线索 ——
> **躯干代偿**与**前臂旋转**。而这两类恰好需要**腕以外的传感器或视觉视角**才能观测。
> → **这是「单腕 IMU 的盲区清单」的实证起点**，直接支撑本库「为什么需要视觉方案」的论证。

## 三、对本库（D435i 四问 / ViKiT）的意义

| # | 用途 |
|---|---|
| 1 | **「单腕 IMU 能力上限」的实证基准**：92% / F1 0.95 —— 但**附带「需个体基线」的前提** |
| 2 | **「单腕 IMU 盲区」的线索**：躯干屈曲、前臂旋前等代偿难以由腕部单点捕捉 → **支撑视觉/多模态方案的必要性** |
| 3 | **居家场景的可行性证明**：19 名卒中患者在**真实家中**完成任务并自行录像 → **居家数据采集是可行的** |
| 4 | **代偿的临床危害表述**（可直接引用）：**代偿性运动模式 → 适应不良的神经可塑性 → 次优的运动恢复** |
| 5 | **方法论模板**：**个体化基线 + DTW** 是应对跨被试异质性的实用方案 |
| 6 | ⚠️ **对比警示**：若本库的 D435i 方案**精度达不到 92% 级**，需说明「但提供了解剖归因能力」（单腕 IMU 做不到的事）——**这是差异化而非劣势** |

### 3.1 与本库「代偿不能只做二分类」主张的关系

**本研究的输出是二分类（运动质量正确 / 不正确）**，且**不做解剖归因**。
而本库的目标是**腕/肘/肩的多关节代偿定位与量化** —— **输出维度更高**。

> **这是一条不需要新实验就能确立的结构性差异**：
> **本文证明「能判对错」，但明确不回答「哪里在代偿」；本库要回答的正是后者。**
