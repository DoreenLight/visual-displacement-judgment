# 一种用于人机交互的改进腕部运动学模型

Ningbo Yu<sup>1</sup> and Chang Xu<sup>2</sup>

摘要——人体运动学对于与人体进行物理交互的康复和辅助机器人系统而言具有根本性的重要意义。腕部在灵巧的人机交互中扮演着关键角色，但其传统的运动学模型过于简化，存在固有的不准确性，而其生物力学模型又过于复杂，不适用于机器人应用。本研究中，我们建立了一个改进的腕部运动学模型。通过无创、无标记的光学追踪方法对腕部的在体运动学行为进行了研究。数据分析表明腕骨旋转中存在可测量的动态轴，证实了若采用传统腕部模型，腕部与机器人表示之间必然存在错位问题。随后提出了一种新颖的腕部运动学模型，将刚体变换与一个变化的移动副项相融合，以指示动态轴的位置。通过非线性回归将耦合的腕部角度用于该移动副项的精确实时估计。所提模型不仅准确，而且便于应用，可将解剖学行为转化为机器人实现与功能评估，从而实现精确且灵巧的人机交互。

## I. 引言

神经康复治疗能够在中枢或周围神经系统损伤后，促进上肢功能的部分或完全恢复 [1]、[2]。与传统的约束诱导治疗方法相比，机器人辅助治疗在适应性参与、康复过程的定量评估以及临床评价等方面展现出潜在优势 [3]、[4]、[5]。此外，在康复和辅助应用中的人机物理交互方面，人体运动学具有根本性的重要意义。

运动跟踪与运动学分析始终贯穿于机器人神经康复治疗以及人机交互过程中[6], [7]。在笛卡尔空间和关节空间中对上肢运动学的评估，以及机器人外骨骼的人因工程设计，根本上都依赖于精确的骨骼建模[8], [9]。具体而言，由于八块腕骨的关节连接以及腕部内部的解剖学变异性，手腕运动学的建模与量化颇具挑战。传统模型将骨骼结构近似为连接上肢刚性段的万向节（universal joint）[3], [10]。然而，由于假设腕关节仅存在旋转运动，并将上肢解耦为相互独立的节段，机器人装置与人体关节之间不可避免地会出现不良错位，且在求解参数化运动学时也会产生偏差[7]。上肢复杂的耦合机制及灵巧运动无法通过过于简化的传统运动学模型得到充分的研究与解释。因此，手腕的功能评估以及康复器械的机械实现将在运动学分析和生物力学评估方面存在不足。

不同于传统运动学模型，一些研究已对耦合肢体生物力学进行了定量研究。通过肌肉共收缩下的惯性、阻尼和刚度等动态特性，对耦合手臂阻抗进行了表征和估计[11]。远端手臂的灵活运动对于灵巧操作至关重要，这些耦合关节的被动刚度也得到了定量估计[12]。

除机器人康复研究之外，手腕与前臂的生物力学研究为关节运动学提供了详尽的描述性数据与合理的估计。一种改进的前臂弹性运动学模型被提出，该模型论证了近端桡尺关节中前臂骨之间的相对运动（即位移），而非将桡尺关节简单描述为万向节[13]。关于腕部运动过程中腕骨运动学的体外（in vitro）和体内（in vivo）研究均表明，腕关节旋转不存在固定的瞬时螺旋轴；由于腕骨之间存在明显的平移，复杂的腕骨关节不能简化为万向节[14], [15]。为评估腕关节的运动学与动力学特性，主要腕骨的旋转行为得到了定量描述，并定义了更为真实的坐标系[16], [17]。

然而，生物力学研究中呈现的解剖学特征和运动学行为主要针对单个腕骨，所采用的专用坐标系并不适用于机器人神经康复中的功能评估。人机交互涉及末端执行器和远端关节的整体运动。这些生物力学坐标系过于复杂，以至于针对机器人评估的运动学分析难以从不同腕骨的独立行为中得出结论。

为解决上述过度简化和不适用的情况，基于远端手臂耦合关节的解剖学研究与生物力学行为，本研究的目的在于建立一个更为精确的腕关节运动学模型，该模型更适合于将解剖学行为转化为机器人实现以及基于精确灵巧的人机交互进行功能评估。通过无创无标记光学追踪方法，对腕关节在屈伸（FE）过程中的体内运动学行为进行了研究。通过25名健康未受伤受试者的实验，验证了该改进运动学模型的可行性与精确性，并通过非线性回归定量地为旋转轴的平移提供了依据。

## II. 方法

## A. 上肢传统模型

基于人体骨骼由刚性骨段组成、并通过无摩擦的万向关节相互连接的假设，传统上肢运动学模型被提出，用于以运动范围（ROMs）和自由度（DOFs）来近似描述人体运动。

上肢包括三个刚性骨段，解剖学上分别描述为上臂、前臂和手（视为单一骨段）。三个万向关节连接这些骨段，分别为肩关节、肘关节和腕关节 [10]。在这些关节中仅发生旋转运动的假设下，可以建立力学平衡方程，并提出具有总共7个自由度的上肢传统运动学模型，如图1所示。传统坐标系 {0} 的原点位于两肩之间，三个坐标系位于复合肩关节中心。人腕关节被视为具有2个自由度的万向关节：外展-内收（桡尺偏，RUD） $( X _ { 6 } Y _ { 6 } Z _ { 6 } )$ 和屈伸（FE） $( X _ { 7 } Y _ { 7 } Z _ { 7 } )$。末端执行器坐标系 {8} 位于伸展的指尖处，如图1所示。因此，末端执行器（人手）的位置和姿态可以通过正向运动学计算得出，关节空间中的角运动可通过逆向运动学近似求得。

## B. 腕部运动中的腕骨运动学行为

腕部区域由八块形态灵巧且形状复杂的腕骨（carpal bones）组成，它们彼此之间形成复杂的关节，并与掌骨（metacarpal bones）及桡尺远侧关节（distal radio-ulnar joint）相互作用。如图 2 所示，从左手腕的掌侧视图可见，这些腕骨排列为近侧列（proximal row）和远侧列（distal row）。从近侧列的前面观，舟骨（scaphoid）、月骨（lunate）、三角骨（triquetrum）和豌豆骨（pisiform）由外侧向内侧依次排列。大多角骨（trapezium）、小多角骨（trapezoid）、头状骨（capitate）和钩骨（hamate）由外侧向内侧依次组成远侧列 [19]。

受腕骨韧带的约束并结合独特的几何关节结构，每块腕骨具有六个自由度（DOFs），从而使腕部运动几乎能覆盖半球范围，并带来腕骨运动学的复杂性。因此，难以基于单块腕骨的运动学行为精确描述完整的腕部运动 [17]。根据临床实践的解剖学基础，桡腕关节、腕骨间关节（包括近侧列关节、中腕关节和远侧列关节）以及腕掌关节共同构成腕部的整体关节 [18]。已有研究阐明了将腕部运动简化为桡腕关节和中腕关节处运动的原理，其依据是将腕骨近侧列和远侧列视为刚性紧密结构 [19]、[20]。桡腕关节是典型的髁状关节，由近侧列与桡骨远端之间形成两个运动轴，允许屈伸（FE）和外展-内收（abduction-adduction）以及环转（circumduction）的双轴运动。同一腕列内的腕骨由韧带加强，呈现一致的运动学行为，因此近侧和远侧关节处实际上无相对运动 [20]。因此，腕骨间关节的运动与桡腕关节一起由同一肌肉驱动，并被限制在中腕关节内。基于腕骨的解剖学特征以及合理的腕骨简化分段，复杂的腕部运动可被描述为额状面内的屈伸（FE）、矢状面内的桡尺偏（RUD）以及环转运动，这些运动主要发生在桡腕关节和中腕关节的组合运动中。

此外，头状骨被称为远侧列腕骨的关键石（keystone），且头状骨与远端的第三掌骨之间存在相对较小的运动。头状骨在近端也与手舟骨（scaphoid）和月骨（lunate）形成关节连接 [20]。从临床功能和生物力学角度来看，头状骨因其突出的位置而体现腕部运动，因此在腕部屈伸和桡尺偏过程中将旋转轴定位于头状骨内是合理的。

根据传统模型，坐标系被建模为一个具有 2 个自由度的万向节。该模型仅能描述绕枢轴点的旋转运动，而沿各轴的线性位移则被排除在传统运动学模型之外。然而，关于腕部运动期间腕骨运动学的体外和体内研究均表明，腕骨旋转中心并非固定在头状骨近端极点。已有研究报道了枢轴点位置的变化以及腕骨中明显可测量的平移[14]、[15]。人体腕部的屈伸（FE）和桡尺偏（RUD）运动学远比传统模型所描述的更为复杂，并表现出独特的腕骨机制，而非像上肢的传统模型那样被简化为一个固定的铰链或简单关节。

## C. Improved Kinematic Model of Wrist Motion（腕部运动的改进运动学模型）

与上肢的传统模型（见图 1）——该模型表明腕骨旋转发生在单一枢轴点附近，且腕关节的作用类似于万向节——相比，所提出的改进模型（见图 3）引入了一个移动副（prismatic joint）以结合两个旋转自由度的关节，能够更精确地定位旋转中心并描述各轴的平移行为。该改进模型为腕骨行为提供了符合生物力学的合理描述，并可对腕部运动学及上肢运动中末端执行器（指尖）的位置与姿态进行更准确的估计。

根据 Denavit-Hartenberg (D-H) 约定 [21]，改进坐标系的原点位于桡腕关节内，即桡骨近端月状关节面（如图 3 所示）。正 $X _ { 0 }$ 轴平行于桡骨长轴并指向远端。正 $Y _ { 0 }$ 轴沿桡骨茎突方向指向尺侧，并垂直于 $X _ { 0 }$ 轴。坐标系 {1} 与 {0} 共享同一原点，并根据右手定则从 $\{ 0 \}$ 绕 $Z _ { 1 }$ 轴旋转 $9 0 °$。坐标系 {2}、{3} 和 {4} 的共同原点位于头状骨内，处于初始构型（即屈伸 (FE) 或桡尺偏 (RUD) 无运动时），作为腕关节整体运动中心的标志。由于第三掌骨与头状骨之间的相对运动在临床上可忽略，且安装夹具将中指与手掌刚性约束在一起（如图 1 所示），$X _ { 3 , 4 , 5 }$ 和 $Z _ { 2 }$ 轴与从 $O _ { 2 }$ 到中指指尖 $O _ { 5 }$ 的远端直线重合。沿 $Z _ { 2 }$ 轴的平移记为 $d _ { 2 }$，表示腕关节整体运动旋转中心位置的变化。正 $X _ { 2 }$ 和 $Y _ { 3 }$ 轴初始时与 $Y _ { 0 }$ 重合。正 $Z _ { 3 }$ 轴表示腕桡尺偏 (RUD) 的旋转轴，沿掌侧方向。RUD 的角度 $\beta _ { 3 }$（尺偏为正）由绕 $Z _ { 3 }$ 轴的旋转 $\theta _ { 3 }$ 推导得出（如表 I 所示）。坐标系 {4} 从 {3} 绕 $X _ { 3 }$ 轴旋转 $9 0 °$。正 $Z _ { 4 }$ 轴表示屈伸 (FE) 的旋转轴，沿桡侧方向；$\theta _ \ { 4 }$ 等于 $\beta _ { 4 }$，屈曲时为正。坐标系 {5} 位于由食指、中指和无名指指尖所定义的平面内，由于约束夹具的作用，该平面与掌侧平面重合。它表示末端执行器的位置和姿态。

3) 耦合关节拟合：沿腕骨轴线的明显平移与耦合的腕骨旋转密切相关。已有研究表明，不同受试者之间存在统计上较为一致的腕骨运动学行为 [20]。因此，本文进行了模型参数拟合过程，以建立手腕旋转中心（由棱柱关节中的 $d _ { 2 }$ 描述）与耦合腕骨角运动（RUD 中的 $\beta _ { 3 }$ 和 FE 中的 $\beta _ { 4 }$）之间的精确数值方程。建立非线性回归模型，将观测数据集点 $( x _ { i } , y _ { \mathrm { i } } , z _ { i } )$（其中 $( x , y , z )$ 表示 $( \beta _ { 3 } , \beta _ { 4 } , d _ { 2 } )$，$i = 1 , 2 , \dots , N$）拟合到由下式描述的二元二次多项式非线性函数：

$$
{ \hat { z } } = { \frac { a _ { 1 } + a _ { 3 } x + a _ { 5 } y + a _ { 7 } x ^ { 2 } + a _ { 9 } y ^ { 2 } + a _ { 1 1 } x y } { 1 + a _ { 2 } x + a _ { 4 } y + a _ { 6 } x ^ { 2 } + a _ { 8 } y ^ { 2 } + a _ { 1 0 } x y } }\tag{9}
$$

其中未知参数 $a _ { j } \ ( j = 1 , \ldots , 1 0 )$ 通过简单遗传算法（Simple Genetic Algorithm，SGA）进行优化，以最小化观测与估计数据集之间的误差平方和（Sum of Square Error，SSE）

$$
S S E = \sum _ { i = 1 } ^ { N } \varepsilon _ { i } ^ { 2 } = \sum _ { i = 1 } ^ { N } \left[ w _ { i } ( z _ { i } - \hat { z } _ { i } ) ^ { 2 } \right]\tag{10}
$$

其中 $\varepsilon _ { i }$ 为残差项，$w _ { i }$ 为权重（设为 1）。$a _ { j }$ 的候选解通过实数编码向量编码为染色体，初始种群规模依据经验设为 20。父代染色体通过随机选择进行交配，交叉算子采用均匀交叉方法，交叉概率依据经验设为 0.85。变异概率通常设为 0.005，这一较低的值是为了综合考虑收敛速度与计算成本以获得最佳的算法整体性能。

采用拟合优度度量来评估估计参数 $a _ { j }$ 与观测值之间的拟合程度。标准化残差 $r _ { i }$ 由 $\varepsilon _ { i }$ 与平均残差 ε¯ 派生得到

$$
r _ { i } = \frac { \varepsilon _ { i } } { \sqrt { \frac { 1 } { N - 1 } \displaystyle \sum _ { i = 1 } ^ { N } \left( \varepsilon _ { i } - \bar { \varepsilon } \right) ^ { 2 } } }\tag{11}
$$

均方根误差（Root Mean Square Error，RMSE）表示估计值与观测值之间的偏差，通常被视为一种尺度依赖的残差度量指标

$$
\begin{array} { r } { \displaystyle R M S E = \sqrt { M S E } = \sqrt { S S E / N } } \\ { = \sqrt { \frac { 1 } { N } \displaystyle \sum _ { i = 1 } ^ { N } \left[ w _ { i } ( z _ { i } - \hat { z } _ { i } ) ^ { 2 } \right] } } \end{array}\tag{12}
$$

决定系数（coefficient of determination）记为 $R ^ { 2 }$，用于反映估计对观测值变异的拟合优度，通过估计值与观测值之间相关系数的平方进行计算

$$
\begin{array} { r l r } { R ^ { 2 } = \frac { S S R } { S S T } = 1 - \frac { S S E } { S S T } } \\ { \underset { = } { \overset { N } { \sum } } \left[ w _ { i } ( \hat { z } _ { i } - \bar { z } _ { i } ) ^ { 2 } \right] } & { = 1 - \frac { \underset { i = 1 } { \overset { N } { \sum } } \left[ w _ { i } ( z _ { i } - \hat { z } _ { i } ) ^ { 2 } \right] } { \underset { i = 1 } { \overset { N } { \sum } } \left[ w _ { i } ( z _ { i } - \bar { z } _ { i } ) ^ { 2 } \right] } } \end{array}\tag{13}

SSR 表示回归平方和。SST 表示总平方和，与数据的方差成正比。$R^{2}$ 在统计学上的取值范围为 0 到 1，$R^{2}$ 为 1 表示估计结果与观测数据完全吻合。

## E. 受试者与实验流程

为追踪人体上肢运动并验证所提出的改进运动学模型，设计并开展了相关实验。在获得知情同意后，招募了 25 名健康的青年受试者，年龄 21 至 27 岁（其中女性 4 名，年龄 $22.8 \pm 1.3$ 岁；男性 21 名，年龄 $24.6 \pm 1.2$ 岁）参与本次实验。所有受试者均无影像学证据或既往病史表明其上肢存在可能影响前臂运动的病变或慢性疾病。本研究中对每位受试者右手腕的运动进行了光学传感器追踪。所有受试者均依据爱丁堡利手量表（Edinburgh-handedness inventory）[22] 显示为右利手。本研究无需伦理审批。

通过 Leap Motion 传感器记录了每位受试者腕部屈伸（FE）运动期间的前臂运动。Leap Motion 传感器为追踪人手及手指运动提供了新颖的解决方案，能够在近距离操作空间内记录前臂的离散位置与手势[23]、[24]、[25]。针对该光学设备的追踪精度与鲁棒性的研究表明，其在静态与动态测量中均达到了 0.7 mm 的总体平均精度。在实验条件下，期望位置与测量位置之间的偏差小于 0.2 mm，且与测量轴无关[26]。另一项研究指出，所得标准差介于 0.0081 mm 至 0.49 mm 之间[27]。这表明 Leap Motion 传感器是一个精度与可靠性均较为理想的专用追踪系统，可用于检测人手的运动。

如图 5 所示，所有志愿者坐在实验桌旁，将前臂放置于轴向静态横梁上，平行于横梁的长轴，肘关节屈曲约 $90°$，肩关节外展约 $45°$。前臂通过定制护腿进行约束并始终固定在静态横梁上，从而前臂不产生旋前-旋后（PS）运动。定制的手指伸展矫形器固定在受试者的手掌上，约束食指、中指和无名指的指间关节、掌指关节和腕掌关节的相对运动，这些手指在手掌的掌侧平面内伸展并对齐。中指沿桡骨长轴方向在远端被专门固定，确保中指与根据 ISB 推荐 [28] 定义的头状骨 $Y$ 轴共线。手腕相对于桡骨的功能中立位根据 ISB 推荐定义，前臂的中立位定义为 PS 中立位。除中立位外，受试者被指示在 $30°$ 屈曲至 $10°$ 伸展范围内平滑旋转手腕。跟踪手部的轨迹由可视化应用程序同时显示。受试者被指示在 40 秒内缓慢完成 10 个 FE 运动周期，以确保精确跟踪。一个典型的周期运动包括从中立位移动到伸展位，然后到屈曲位，最后回到中立位。

## III. 结果

提取实验数据并加以展示，以验证改进模型的可行性和准确性。如图 6 所示，平移参数 $d_2$ 表明腕关节旋转轴的位置并非固定于单一点。$d_2$ 的值在一个 FE 运动周期内变化明显。与 FE 中的角度相比，腕关节伸展期间旋转轴的更远端位置（由较大的 $d_2$ 表示）比腕关节屈曲期间的位置更靠近远端。对 FE 中 $d_2$ 与 $\beta_4$ 之间进行了线性回归分析。Spearman 秩相关系数为 $-0.97 \ (p = 6.1e^{-205})$，表明 $d_2$ 与 $\beta_4$ 之间存在统计学上的高相关性，负相关表明当 $\beta_4$ 增加时 $d_2$ 趋于减小。可以得出结论，腕骨关节不能简单地建模为简单关节，腕骨旋转轴在腕关节伸展期间向远端移动，在腕关节屈曲期间向近端移动。这些结果与之前的生物力学研究 [20] 一致。

## IV. 讨论（DISCUSSION）

## A. 手腕生物力学的一致性（Consistency of Wrist Biomechanics）

实验招募了 25 名无前臂远端病变的健康受试者，其中女性 4 名，男性 21 名。已有研究表明，未受伤受试者之间的腕骨运动学表现出高度的一致性。不同受试者间体内腕骨行为和前臂远端生物力学的差异在统计学上可以忽略不计，且左右手腕之间的差异并不明显 [20]。此外，男性与女性之间旋转轴位置的差异与受试者的解剖学尺寸相关 [17]。研究表明，手腕运动参数与性别无关，浮动轴的位置与腕骨体积和中性质心位置相关 [15]、[20]。因此，基于先前研究中关于个体腕骨运动学一致性的证据，按照所述的受试者招募标准开展验证实验是合理的。

## C. 机器人神经康复的实现原理

神经康复中的功能评估以及机器人康复设备的机械实现，根本上依赖于基于生物力学原理的人体运动学模型 [6]、[7]。在假设解耦的腕关节中仅存在旋转运动的前提下，传统上肢运动学模型无法精确估计末端执行器和腕关节的姿态。这一不可避免的局限性，以及关节运动学与机器人评估之间的不良对位偏差，将为康复评估在关节空间内提供不可靠的参数。所提出的改进腕关节运动学模型已证实腕部旋转中存在可测量的非固定轴，并基于耦合的腕部角度提供了精确的轴位置估计。因此，基于精确模型在关节空间内对远端手臂进行运动学评估是可行且有效的，为神经康复提供了客观且定量的测量手段。此外，D-H 参数表示法是一种通用且标准化的机器人表示法 [8]。所提出的腕关节运动学模型可直接应用于机器人领域，对于外骨骼的机器人实现以及机器人神经康复评估至关重要。

## V. 结论

对上肢运动学的精确评估是更好地理解人-机器人物理交互、为机器人神经康复与辅助提供支持的关键。具体而言，建立真实的人体腕关节生物力学模型对于辅助外骨骼的人体工程学设计以及人-机器人协作至关重要。在本研究中，所提出的改进运动学模型证明了腕骨旋转中存在可测量的非固定轴，印证了先前研究的观点，即机器人的关节表示与人体关节之间不可避免地会出现偏差和过度简化。通过将腕关节角度耦合并进行非线性回归，实现了对轴位置的精确估计。在未受伤受试者上进行的实验，通过光学追踪方法和基于机器人运动学模型的数值优化，验证了该改进模型的有效性。因此，基于该改进模型在关节空间内对远端手臂进行运动学评估是可行且有效的，为人-机器人物理交互及机器人神经康复的量化实施提供了支撑。
