# 基于自适应学习的协作机器人上肢康复训练系统

Jun Hong Lim、Kaibo He、Zeji Yi、Chen Hou、Chen Zhang、Yanan Sui、Luming Li

摘要—运动功能障碍患者的康复训练通常需要在康复中心使用专门的设备。基于家庭的多用途训练将显著提高治疗的可及性并降低医疗成本。虽然在家中配备一套康复机器人不太现实，但我们研究了使用通用协作机器人进行康复治疗的可行性。在本研究中，我们开发了一种新的系统，使用通用机器人手臂结合人体运动反馈和偏好来进行多用途上肢康复训练。我们将表面肌电信号、力/扭矩传感器、RGB-D 相机和机器人控制器与机器人操作系统（Robot Operating System）集成，以实现系统的传感、通信和控制。该系统采用模仿学习方法，模仿专家提供的训练轨迹，这些轨迹能够适应患者能力，从而促进家庭训练。我们的康复系统能够使用基于夹爪的末端执行器进行粗大运动功能和精细运动技能训练。我们在 Gazebo 中仿真了系统控制，在 OpenSim 中仿真了训练效果（肌肉激活水平），并通过人体受试者评估了其实际性能。对于所有入组的受试者，在相同条件下，我们的系统相比专家辅助康复取得了更好的训练效果。我们的工作展示了利用协作机器人进行家庭运动康复训练的潜力。

临床相关性—该协作机器人系统能够提供安全有效的训练，其效果可与专用康复机器人相媲美，为实现便捷的家庭康复训练提供了可能性。

## I. 引言

康复训练对于运动功能障碍患者的恢复至关重要。患者需要在配备专用设备的康复中心，由经验丰富的治疗师进行密集且重复的训练，以增强肌肉力量和神经可塑性。这是他们恢复运动功能、重返正常生活的主要途径。对于患有中风等神经性疾病和损伤的患者来说，上肢运动障碍是常见的后遗症。一旦患者病情稳定并能确定康复目标，就应立即开始训练。这有助于增强薄弱肌肉以防止肌肉萎缩并恢复运动功能，避免因缺乏运动而导致的手部水肿或肩关节半脱位。

机器人系统，包括专用机器人和通用机器人，由于能够一致地执行重复性任务，已被广泛用于康复训练。专用机器人通常被设计用于训练某一特定任务，而通用机器人可应用于多种场景，相比专用系统具有更高的自由度，并且更具成本效益。

在过去的几十年里，已经开发出多种专用机器人康复设备和用于上肢康复的控制系统 [2]、[11]、[12]。这些康复机器人和辅助控制系统可以在有或没有治疗师监督的情况下引导患者完成训练过程。它们还可以帮助收集训练数据，以便治疗师评估患者的当前状况。

关于将通用协作机器人应用于康复任务的研究尝试较少。协作机器人（Cobots）能够与人类协同工作，并且通常符合安全标准，展现出部署于康复流程的潜力。Kyrkjebø 等人 [3] 尝试通过限制工作空间来补充内置安全机制，从而提高协作机器人的安全性。他们的研究结果表明，使用协作机器人辅助康复训练是可行的。Nielsen 等人将动态运动基元与力反馈相结合，预录制并学习康复任务，以适应不同的手臂长度 [4]。文献 [5] 中的另一项工作使用了具有 7 自由度（7-DOF）的 KUKA 机械臂。该机械臂结合了按需辅助（assist-as-needed）原则，以针对不同辅助水平的患者进行激励。上述所有方法均提出了一种实现重复性任务的主要方式，并且患者能够相当独立地练习日常活动，减少对监督的需求。

获取康复中心服务的过程耗时且费用高昂，加之资源有限地区的人手短缺，可能会延缓患者的康复阶段。解决该问题的一种可能方式是采用远程训练系统，该系统能够提供可比的训练效果。在本工作中，我们提出了一种基于协作机器人的远程自适应上肢训练系统。该系统将协作机器人、摄像头、运动传感器、治疗师和受试者集成于一个平台之上。它能够执行不同类型的训练，并达到与常见康复机器人相当的训练效果，展示了将通用协作机器人部署于家庭以实现个性化康复训练、减少频繁前往康复中心的可行性。

## II. 方法

我们提出了一种新的用于辅助康复训练的远程系统，并与 ROS（Robot Operating System，机器人操作系统）平台集成，以实现一组硬件之间的通信（如图 2 所示）。该系统采用了基于夹爪的末端执行器，用于引导先前末端执行器方法无法完成的精细运动任务。由于受试者可能因力量不足而无法握持夹爪，因此我们在医生和治疗师的协助下开发了该康复任务，这对于脑卒中早期康复训练非常重要。所提出的系统通过 Gazebo 和 OpenSim 仿真进行了验证。我们通过表面肌电（sEMG）信号并与经验丰富的训练师进行对比来检验训练效果，通过实验揭示其在多用途康复中的可行性。

受试者由协作机器人（Cobot）的末端执行器引导完成训练。运动、手势和康复持续时间依据脑卒中指南设计[1]、[16]，用于急性期患者的护理，并由经验丰富的医师和治疗师提供指导、修正和建议。本文提出了两项任务：一项为粗大层面的上肢康复，另一项为精细层面的手部康复。对于上肢康复，我们选择了基本的日常生活活动（ADL）任务，这是日常生活中必不可少的。对于手部康复，我们选择了手指训练任务，以促进手指灵活性。在握拳和张开拳头的过程中，可激活整手及前臂肌肉。因此，它能为急性期患者提供更好的训练效率，帮助他们建立肌肉力量。受试者的前臂佩戴了一件辅助设备（如图 7(e) 和 (f) 所示），其握持位置可由 Kinect 相机通过计算机视觉方法[8]实时识别。

按图 3(a) 所示构建了一个 Gazebo 仿真环境。相机被设置为能够清晰观察工作空间，RGB-D 图像被传输到我们的系统中进行识别，并识别出受试者辅助设备的抓握点。由于身体限制（例如运动范围）所产生的抵抗力由力/扭矩传感器进行跟踪，同时上报给控制器进行分析。我们设定了紧急情况下的阻力阈值，当 $\begin{array} { r } { \textbf { \textit { F } } \ge \ \boldsymbol { F _ { s a f \epsilon } } } \end{array}$（45N）时，协作机器人触发紧急停止，因为进一步的动作可能会导致额外的伤害。我们根据视觉识别为每位受试者确定了起始点。该仿真被用于验证任务可行性，模仿学习智能体也利用该环境学习使用通用专家数据的自适应控制策略。专家轨迹和模仿轨迹在 Gazebo 和 OpenSim 仿真器中进行了仿真，以确保其安全性并评估相应的肌肉激活率，以便按照第 II 节所述优化任务。

安全是我们对丰富人机交互任务的首要关注点。在工厂默认安全配置的基础上，协作机器人的安全配置分为三个阶段，根据受试者的身体能力、康复臂的运动范围（ROM）及其康复阶段确定。它们在工作空间确定、训练过程中施加的加速度和速度方面有所不同。

OpenSim[6] 是一个开源的基于模型的生物力学仿真软件。它被广泛用于人体运动学和动力学分析。我们在 OpenSim 中构建了两个肌肉骨骼模型，以验证目标肌肉可被有效激活。如图 3 所示，对于手臂康复（Arm Rehabilitation），我们基于文献 [7] 构建了上半身模型。该模型主要包括手、手臂和肩部的骨骼和肌肉。对于手部康复（Hand Rehabilitation），我们构建了一个上肢模型，其中包含手部和前臂的详细而精确的骨骼和肌肉。

在仿真中，我们从 Gazebo 仿真中获得了协作机器人末端执行器的初始轨迹（即初始夹持器轨迹）。然后，我们使用该轨迹驱动肌肉骨骼模型，并计算肌肉激活情况。根据肌肉激活结果，我们与临床专家讨论以调整任务，生成新的轨迹，并再次驱动模型以计算肌肉激活结果。经过多次调整，我们获得了合适的任务并验证了其有效性。

模仿学习使智能体能够从专家示范中学习策略/轨迹。它在康复机器人领域具有巨大的应用潜力。对于远程训练，治疗师不在现场指导协作机器人完成康复任务。相反，他们可以提供总体上适合受试者的轨迹。这充当了专家标注的参考。学习智能体通过模仿学习在受试者侧执行该参考，并根据身体状况和个人偏好进行调整。

与自动驾驶车辆不同，康复训练中没有轨道边界来限制智能体。每位受试者由于其生理条件不同而具有不同的边界。在我们的方法中，如图 1 所示，当轨迹对受试者而言过于困难时，受试者可以按下"停止"按钮。这类似于自动驾驶中违反轨道边界。基于这一原理，我们采用了受 HG-DAgger [17] 启发的模仿方法，并进行了修改以适应我们的问题。

在我们的系统中，所提供的专家轨迹将被部署，直到受试者标记了负面反馈，然后训练任务由专家进行调整。停止状态将被标记为不良状态。之前的状态被视为可接受状态。然后，专家将提供一条调整后的后续轨迹，并从该状态使用调整后的轨迹继续训练。该过程将重复进行，直到受试者接受整个轨迹。最终的轨迹将被训练并导出针对该受试者个性化的策略。

从训练模型为新的专家数据测试集执行的实际轨迹如图 4 所示。该模型通过 RMSE 进行评估，计算预测轨迹 $(x_g, y_g, z_g)$ 与原始专家轨迹 $(x_i, y_i, z_i)$ 之间的距离。

从受试者角度获得的反馈也是有价值的，因为它直接反映了训练期间与协作臂交互的感受。为了接收和研究这些反馈，我们设计了一份调查问卷，以获取他们在使用我们的康复系统训练后对手部和手臂锻炼程度、所采取的安全措施以及对整个任务的综合评分的看法。

我们将 Cobot 引导下的肌肉激活率与由治疗师辅助的训练（与受试者使用相同的贴合点、运动轨迹与指令）进行比较。为使 sEMG 值便于比较进行归一化处理，我们在相同的姿势与条件下记录了每位受试者的最大自主等长收缩（Maximum Voluntarily Isometric Contraction，MVIC），并将其作为分母去除测得的 sEMG 值。MVIC 是衡量人体肌肉力量的一种常用标准化方法 [13], [14], [15]。我们对所有受试者的数值取平均，结果如图 6 所示。实验结果清楚地表明，相较于由治疗师辅助的训练，在我们的系统上进行训练能够显著提高 MVIC。

与由治疗师辅助康复训练时的肌肉激活率相比，Cobot 辅助康复任务中的每块目标肌肉都表现出更高的激活量。在粗粒度训练（gross-level training）中，目标肌肉平均增加了 11.6(±5.9)%；在细粒度训练（fine-level training）中，目标肌肉平均增加了 14.6(±5.3)%。

实验结果反映出，在所设计的训练动作中存在清晰的肌肉激活过程，握持任务能够有效地激活训练过程中整个前臂的肌肉。在两项任务中，由 Cobot 辅助的受试者的激活程度均显著高于由治疗师辅助的受试者。可能的原因主要包括以下几点：1. 受试者的运动范围更大，使 Cobot 能够在每个训练周期中充分拉伸前臂。因此，运动表现更为稳定。2. Cobot 施加的力大于治疗师施加的力。由于新受试者的身体特性未知，治疗师可能会有所保留。而 Cobot 配备有自适应方法，能够主动调整所施加的力度，使受试者达到其极限。3. 末端执行器使训练过程更为高效。末端执行器提供了更好的支撑与包裹，使受力更加均匀，并能够施加更大的合力。

除上述要点之外，在实际临床中还存在其他可能影响治疗师训练表现的因素。在我们的实验设置中，我们为治疗师在每个任务之间提供了充足的休息时间，并将训练时长固定为 10 分钟。然而，真实治疗师的工作负荷远高于此，疲劳在所难免。在所提出的任务之间交替进行，甚至将其结合，将有助于训练整个上肢肌肉。因此，我们所提出的系统是可行的，能够在康复早期——受试者可能难以主动完成标准动作的阶段——为增强肌肉力量、预防上肢挛缩与畸形提供一种高效的方法。

此外，我们在实验后对受试者进行了训练效果的问卷调查。如图 8 所示，采用 1–10 分量表，分值越大表示效果越好。从受试者的主观感受来看，这进一步支持了所设计的任务对肌肉激活的训练效果。受试者对训练的安全性、手臂与手部训练效果均给出了较高的评分。所有受试者均表示如有需要，愿意推荐使用我们所设计的构型与任务进行训练。

## IV. 结论

我们提出了一种新颖的协作机器人辅助自适应康复训练系统，该系统集成了相机、力传感器和机器人控制器。我们对两类具有代表性的任务进行了验证：粗大运动训练任务与精细运动训练任务。在每项任务中，智能体从专家示教中习得策略，并可根据受试者的身体能力进行调整。本工作提供了一个一体化平台，验证了针对运动功能障碍人群、利用通用机器人开发可在家中个性化执行的远程上肢训练系统的可行性。
