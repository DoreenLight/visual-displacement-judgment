# 通过分类和平滑度分析简化自动神经康复

Asma Bensalah<sup>1[0000−0002−2405−9811]</sup>、Alicia Forn´es<sup>1[0000−0002−9692−5336]</sup>、Cristina Carmona-Duarte<sup>2[0000−0002−4441−6652]</sup>、Josep Llad´os<sup>1[0000−0002−4533−4739]</sup>

<sup>1</sup> 西班牙 巴塞罗那自治大学 计算机科学系 计算机视觉中心 {abensalah, afornes, josep}@cvc.uab.es 2 西班牙 大加那利拉斯帕尔马斯大学 {cristina.carmona}@ulpgc.es

摘要. 在中风患者的康复阶段评估其动作质量至关重要，因为目前并不存在适用于所有患者的标准中风康复方案。事实上，康复方案主要取决于患者的功能独立性及其在各个康复疗程中的进展情况。为应对该问题并使神经康复更加灵活高效，本文提出了一套自动评估流程：首先通过一个轻量级深度学习架构识别患者的动作，然后利用 jerk 度量及相关指标衡量动作质量。本研究的一个特点是所使用的数据集具有临床相关性，因为它包含的动作灵感来源于 Fugl-Meyer 评分——一种广泛应用于中风患者的上肢临床评估量表。我们证明，不仅可以从平滑度角度检测健康人与患者动作之间的差异，还可以就患者在康复疗程中的进展情况得出与临床医生对每例患者的研究发现相符的结论。

关键词：神经康复 · 上肢 · 动作分类 · 动作平滑度 · 深度学习 · 加加速度（jerk）。

## 1 引言

神经系统疾病会导致认知和运动功能的损伤。尤其是脑卒中（中风）幸存者，可能会面临身体一侧的运动功能缺陷。这些功能缺陷通过康复训练来部分或完全恢复患者的功能独立性[1]。在这一阶段的核心挑战之一是评估患者的康复进程。本质上，脑卒中后患者的显著进步通常发生在最初几周内，即神经可塑性增强的关键窗口期[2]。之后，非线性的恢复曲线将达到渐近水平。鉴于以上所有原因，应当优化关键时间窗口内的康复时机和治疗强度。因此，必须持续且准确地监测患者的康复进展，以便在关键窗口期结束时最大限度地促进患者的康复。多年来，常规做法一直是使用特定的临床量表[3]。在实践中，患者的运动功能评估每十天仅进行一至两次。因此，这种方法的缺点在于，当患者离开康复室时，无法对其康复进程进行评估。事实上，正是患者的日常活动表现最能反映其功能独立性。

应对这一局限性的一种途径是实现评估的自动化，以帮助临床医生高效地评估患者。在自动化过程中会出现许多问题：首先，需要在长达数小时的连续记录中确定运动的性质；其次，需要找出哪些指标能够最佳地描述运动质量。

为应对前述问题，我们提出了一个用于自动评估患者运动的框架。该框架包含两个部分：

– 第一部分通过一个浅层深度学习架构，将运动分类为四个关键运动类别；

第二部分是基于 jerk（加加速度）指标的评估模块，用于确定患者与健康个体信号之间的差异，并估计患者在不同康复训练阶段的康复进程。与其他需要更多内存空间和计算资源（由于运动学参数数量较多）的现有关节运动学算法[4]相比，jerk 更易于在嵌入式设备中实现。

在本文的后续部分中，我们在第 2 节给出相关工作的概述，然后在第 3 节描述我们的分类深度学习架构。在第 4 节中，我们概述运动平滑度的测量方法。接下来，我们在第 5 节描述我们的实验装置。然后，在第 6 节中给出我们的结果与发现。

## 2 相关工作

在信号中定位一段序列的目的是检索出与给定查询相关的信号或其部分。根据查询的性质，会产生许多序列定位任务 [5][6][7]。如果信号是由一种或多种不同模态组成的序列，而查询是一个动作、活动、运动或手势，那么我们所处理的就是一项人体活动识别（Human Activity Recognition，HAR）任务。

HAR 极大地受益于深度学习的浪潮。HAR 已使用不同模态完成：RGB 图像 [8]、骨骼数据 [9]、加速度 [10]、WiFi [11]……

加速度是一种被广泛利用的模态用于动作识别，原因在于它是一种非侵入式的感知方法，因此不存在隐私约束问题。通过加速度进行 HAR 是可行的，因为人类通常以相同的方式定性执行某个动作 [12]。HAR 既可以使用传统学习算法来完成，例如支持向量机 [13]、k 近邻 [14]，也可以使用深度学习模型，例如卷积神经网络（Convolutional Neural Networks，CNN）[15]、循环神经网络（Recurrent Neural Networks，RNNs）[16] 或长短期记忆网络（Long short-term memory，LSTM）[17]。根据文献 [18]，22% 的 HAR 研究工作致力于健康应用。

另一方面，为了评估识别出的运动，尤其是针对中风患者的运动，如何获得一个运动平滑度指标或何种指标能最佳地描述它，目前尚无普遍共识 [19]。原因之一是对运动质量背后的神经生理学认识模糊，上肢运动的情况就是如此 [20]。根据文献 [21]，关于中风患者平滑度测量的研究工作主要分为五类：与轨迹相关的指标 [22]、与速度相关的指标 [23][24]、与加速度相关的指标 [25][26]、与加加速度（jerk）相关的指标 [27] 以及其他指标 [28]。如上所述，HAR 任务已经以多种方式被处理，运动质量的评估问题亦是如此。在我们的工作中，考虑到可用数据较少，我们选择了一种浅层深度学习架构用于 HAR；此外，我们探索了使用加加速度（jerk）测度来评估患者运动质量的方法。

## 3 运动分类

我们的灵感来自 Supratak 的模型 [29]，该模型旨在应对多导睡眠图（Polysomnography）挑战，这也是评估睡眠质量的方法之一 [30]。传统上，多导睡眠图由一组专家使用睡眠阶段评分对记录的数据进行标注。

为了缓解上述限制，该架构实现了一个数据增强模块，并在流水线中减少了信号处理步骤。

## 3.1 架构

模型以我们原始加速度信号的各个 epoch（时间段）作为输入（见图 1）。我们将运动划分为四个关键运动类别之一：M1、M2、M3、M4。模型的第一个组件由四层 CNN 组成，旨在从原始信号中提取时间不变特征。如图 2 所示，在第一层 CNN 之后和最后一层 CNN 之后分别引入了一个最大池化层（max-pool）和一个 dropout 层。第二个组件设计用于学习原始信号的时间依赖性（序列学习）。这通过一个 LSTM 层后接一个 dropout 层实现，二者共同构成一个单向 RNN（循环神经网络）。该单向 RNN 用于学习时间转移规则。LSTM 的单向性省去了前向传递过程，从而减少了超参数的数量和计算资源消耗。

由于我们的数据集是平衡的，因此所有类别的加权交叉熵损失均设为 1。此外，为应对数据稀缺的问题，我们在每个训练 epoch 对原始数据进行数据增强。数据增强通过沿时间轴平移信号实现，平移范围为 epoch 时长的某一特定区间。模型使用 Sleep-EDF 数据集 [31] 进行预训练。

## 4 运动平滑度

在介绍完分类架构的描述之后，接下来我们介绍运动的平滑度测量方法。量化运动质量可以通过多种方式进行，测量位置随时间的变化就是其中一种方式。速度 $\overrightarrow { v }$（公式1）、加速度 $\scriptstyle { \overrightarrow { a } }$（公式2）、加加速度 $\vec { j }$（公式3）和急跃度 $\vec { s }$（公式 $^ { 4 ) }$）分别是轨迹 $\vec { x }$ 对时间的一阶、二阶、三阶和四阶导数，是应用最为广泛的测量量 [32]。这些也是人体用于维持平衡所使用的相同度量。更具体地说，这由前庭系统的感觉功能负责处理，该系统提供诸如身体位置及重力方向等信息 [33]。如果物体处于运动状态，则具有速度。当速度不是恒定的时，则称该物体具有非零的加速度。如果加速度随时间变化，则会产生运动不平滑的感觉。自从文献 [34] 重新关注加加速度以来，它已在科学和技术领域有了许多应用 [35] [36] [37]。当发生振动时，以及任何突然转变发生时，都应始终考虑加加速度 [35]。例如，在铁路设计中需要考虑加加速度，以确保列车从直线过渡到曲线时的运动平滑；同样，在确保工业工具不会因加速度的快速变化而过早失效时也需要考虑它。

当通过加速度来分析人体运动时，它是依赖于坐标轴方向的。在记录数据时手腕的微小旋转都会导致某个坐标轴加速度产生大量噪声。因此，在本工作中，我们聚焦于加加速度作为运动质量的度量指标，特别是作为平滑度指标。最重要的是，与其他因运动学参数数量较多而需要更多存储空间的现有运动学算法相比，加加速度更容易在嵌入式设备中实现。

$$
{ \vec { v } } ( t ) = { \frac { \mathrm { d } { \vec { x } } ( t ) } { \mathrm { d } t } }\tag{1}
$$

$$
{ \vec { \alpha } } ( t ) = { \frac { \mathrm { d } { \vec { v } } ( t ) } { \mathrm { d } t } }\tag{2}
$$

$$
{ \vec { j } } ^ { } ( t ) = { \frac { \mathrm { d } { \vec { a } } ( t ) } { \mathrm { d } t } }\tag{3}
$$

$$
{ \vec { s } } ( t ) = { \frac { \mathrm { d } { \vec { j } } ( t ) } { \mathrm { d } t } }\tag{4}
$$

## 5 实验设置

## 5.1 数据集

数据集是作为远程患者监测三维运动学（RPM3D, 3D kinematics for remote patient monitoring）项目<sup>3</sup>的一部分录制的，旨在为中风患者构建一个自动化流程。已发表了一份针对中风患者与健康受试者的数据集及分类基线 [38]。患者与健康个体在每只手上各佩戴一个智能手表。健康个体记录一次，而患者则在四个不同的会话中进行记录。患者各会话之间的时间间隔为一到两周。最初，为了评估中风患者的上肢运动功能，每周或每十天进行一次评估。用于评估中风患者感觉运动障碍的最知名量表是 Fugl-Meyer 评估量表（Fugl-Meyer Assessment）[39]。基于此，作者从 Fugl-Meyer 动作中汲取灵感，设计了如下的关键动作集 $\mathcal{M}_{i}, i \in [1, 4]$：

– 动作 $\mathcal{M}_{1}$：肩部伸展/屈曲。

– 动作 $\mathcal{M}_{2}$：肩部外展。

– 动作 $\mathcal{M}_{3}$：肩部外旋/内旋。

– 动作 $\mathcal{M}_{4}$：肘部屈曲/伸展。

场景 实验在两种不同的设置下进行：约束场景 L1 和非约束场景 L2。描述如下：

– 场景 L1：表示约束场景，其中个体分别用优势手、非优势手以及双手依次执行四个关键动作 $\mathcal{M}_{i}$。

– 场景 L2：表示非约束场景，由一系列关键动作 $\mathcal{M}_{i}$ 以及一组其他非目标动作 $\mathcal{R}_{j}, j \in [1, 19]$ 组成。$\mathcal{R}_{i}$ 动作为一系列常见的日常活动，例如：喝水、坐在椅子上等。动作以随机顺序执行。

## 5.2 流程

我们首先将动作分类为四个主要类别：M1、M2、M3、M4（肩部伸展/屈曲、肩部外展、肩部外旋/内旋、肘部屈曲/伸展）。然后，我们针对表示某动作多次执行的信号计算急动度（jerk）值，如图 3 所示，以检查某动作的整体加速度模式。

## 6 结果

以下结果与 L1 动作的分类及其平滑度分析有关。

## 6.1 分类

在实验中，数据按 80% 用于训练、20% 用于测试进行划分。测试准确率平均达到 77.01%。在某些训练轮次中，我们观察到准确率有所下降，我们认为这是由于训练数据集规模较小所引起的。

## 6.2 平滑性

在表 1 中，我们给出了健康个体与患者在 x 轴上良好分割的运动 jerk（加加速度）值信息。理论上，与患者相比，健康个体的 jerk 值应该更低，因为他们的运动能力更强，能够以更平滑的方式完成动作，所以他们的运动更不急促（见图 4）[21]。

图 4：患者与健康个体执行同一运动时的 jerk 值。

如表 1 所观察到的，M2、M3、M4 的情况正是如此。例如，对于运动 M3，患者的 jerk 均值绝对值是健康受试者 jerk 均值绝对值的 0.7 倍。同时，表 1 中的趋势表明，在 M1、M2、M3 和 M4 这四个运动中，健康人群的 jerk 最大值都大于患者的 jerk 最大值。jerk 表示加速度的变化。从这个意义上讲，为了更好地理解运动的平滑性，我们采用了基于 jerk 绝对值计算的 jerk 相关度量。在本工作中，我们重点关注 jerk 平方度量。表 2 给出了 jerk 平方度量的均值、最大值和最小值。请注意，表 1 的趋势是健康个体的 jerk 均值较低，这与理论前提相对应：运动越急促且越不平稳，jerk 值就越高。因此，患者的 jerk 值应该更高。然而，对于 jerk 平方均值来说，情况并非如此。表 2 的一般规律是健康人群的 jerk 平方均值高于患者。我们认为这可能与以下事实有关：患者的信号比健康个体的信号噪声更大，因为患者的动作更慢，所以患者的信号具有更多的峰值和更多的累积噪声（见图 5）。

加加速度作为平滑性指标的优劣如何？总体而言，由于患者完成运动的方式差异，将健康个体的加加速度值与患者的加加速度值进行比较并非易事。特别是，当患者难以以一致的方式完成运动时，简单的健康运动加加速度值与患者运动加加速度值之间的比较并不总能得出明确结论。例如，在运动 M1 的情况下，健康样本的加加速度均值高于患者样本。尽管如此，加加速度平方均值仍为观察患者在四次疗程中的演变提供了有价值的参考。我们的结论与临床医生的判断一致：与首次疗程相比，大多数患者的运动平滑性有所改善。此外，对于在疗程中表现出较多运动功能障碍的患者 101，其加加速度平方均值的改善程度最小。

## 7 结论

本文提出了一套全自动的中风患者评估流程，结合了深度学习模型和基于 jerk 指标的平滑度质量模块，其运动方式借鉴了有效的临床功能 Fugl-Meyer 量表。即使在数据集较小的情况下，运动分类仍取得了良好的准确率，这可能得益于对原始信号进行的数据增强。与健康受试者相比，jerk 已被证明是中风患者评估中一种有前景的指标，而平方 jerk 则能较好地反映患者跨会话表现的变化。

与所有非图像或自然语言处理（NLP）相关的视觉和机器学习任务类似，本任务可用的数据较少。因此，未来的工作将致力于扩充可用数据，并探索更稳健的平滑度评估指标。
