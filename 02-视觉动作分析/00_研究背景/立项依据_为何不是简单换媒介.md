# 立项依据：为什么"换媒介"不够新

> **一句话**：5 条独立路线已经覆盖了你的原始 formulation。我们只能通过"结构化翻译"的升级来拉开差距。

---

## 1. 已经做了「RGB → joint angle」的 4 批工作

### 1.1 2022 — Jamsrandorj et al., EMBC

| 项 | 值 |
|---|---|
| 标题 | Deep Learning Networks for View-independent Knee and Elbow Joint Angle Estimation |
| 输入 | 连续 9 帧 RGB |
| 输出 | knee + elbow joint angle |
| 方法 | CNN / BiLSTM 等多种网络对比 |
| 最佳结果 | 膝 r ≈ 0.955，肘 r ≈ 0.917 |
| DOI | `10.1109/EMBC48229.2022.9871106` |

→ **2022 年就有人把 RGB 直接映射到关节角**。比 Transformer 还早。

### 1.2 2022 — Kumar et al., EMBC（同团队）

| 项 | 值 |
|---|---|
| 标题 | Prediction of lower limb kinematics from vision-based system using deep learning approaches |
| 输入 | RGB 视频 |
| 输出 | hip/knee/ankle angular **velocity** |
| 方法 | CNN + BiLSTM / GRU |

→ **连 angular velocity 都做过了**。

### 1.3 2026 — Chao et al., Measurement（**直接竞品**）

| 项 | 值 |
|---|---|
| 标题 | Lower limb joint angle estimation using a single RGB camera |
| 输入 | 单目 RGB 视频 |
| 输出 | hip/knee/ankle angle（end-to-end，无 IK 中介）|
| 方法 | RGB |
| 关键 | `L = L_angle + λ L_angular_velocity`，跨视角/速度/异常步态 ICC > 0.92 |
| DOI | `10.1016/j.measurement.2026.120772` |

→ **直接对标**：单目 RGB + Transformer + 角度回归。审稿人 100% 会拿这篇比。

### 1.4 2024 — HMR 2.0 + TokenHMR（ICCV 2023 / CVPR 2024）

| 项 | HMR 2.0 | TokenHMR |
|---|---|---|
| 标题 | Humans in 4D | TokenHMR: Advancing Human Mesh Recovery with a Tokenized Pose Representation |
| 输入 | RGB 图像 | RGB 图像 |
| 输出 | SMPL pose/shape | discrete **pose tokens** |
| 方法 | ViT + Transformer Decoder（SMPL query）| Encoder 把 pose 映射到 discrete pose tokens + token prediction |

→ **图像 → 姿态 token 已经存在**，且 TokenHMR 把这件事做成了「token prediction」——比"回归"更接近"翻译"。

## 2. 已经做了「2D pose → 3D pose」的 4 篇工作

虽然不是端到端 RGB → angle，但 Transformer 在 2D→3D pose 提升上已经成熟：

| 论文 | 年份 | 关键 |
|---|---|---|
| PoseFormer | ICCV 2021 | Spatial + Temporal Transformer |
| PoseFormerV2 | CVPR 2023 | 加频域 |
| MotionBERT | ICCV 2023 | DSTformer，学到的表征含 **geometric + kinematic + physical** 知识 |
| MotionAGFormer | WACV 2024 | Transformer + GCN |

特别是 **MotionBERT 明确指出学到的 representation 包含 kinematic 知识**——这给我们的「kinematic language」提供了强先验。

## 3. 已经做了「传统生物力学 pipeline」的 OpenCap 系列

```
RGB → 2D keypoints → 3D keypoints → IK → joint angles
```

| 论文/工具 | 精度 |
|---|---|
| OpenCap (Uhlrich 2023, PLOS) | MAE ≈ 4.5° |
| OpenCap ACL 康复验证 (2024) | MAE ≈ 3.85°, RMSE ≈ 4.34° |
| 2026 markerless motion capture 综述 | 综述明确说绝大多数走 2D → IK |

→ 这是**临床/工程基线**，我们必须跑过这个数。

## 4. 你的原始创新点写法（风险版）

如果论文创新写成：

> **Innovation 1：首次将视觉图像到关节角度预测定义为一种语言翻译问题，并使用 Vision Transformer 从视觉表征翻译为运动学表征。**

**风险评估：🔴 高**

审稿人会拿：
- Chao 2026（你换了媒介但人家也有 Transformer）
- HMR 2.0（你换了输出但人家也是 ViT → 姿态参数）
- TokenHMR（你换了 token 但人家已经做了 pose vocabulary + token prediction）
- PoseFormer / MotionBERT（2D→3D 早就被 Transformer 统治了）

然后问：

> "除了把 regression 称为 translation，方法上的新东西是什么？"

## 5. 升级版创新点（推荐）

不是：

> ❌ "Vision Transformer for Joint Angle Estimation"

而是：

> ✅ **An Anatomy- and Biomechanics-Informed Visual-to-Kinematic Sequence Translation Framework for Continuous Joint Kinematics Estimation**

模型名：**ViKiT — Visual-to-Kinematic Translator**

### 5.1 核心命题

$$\text{Visual Language} \rightarrow \text{Kinematic Language}$$

这里的"language"必须不只是一个比喻，要真的构造两套 token 系统。

### 5.2 三个可站住的创新

1. **Visual–Kinematic Translation** — 不是普通回归，而是跨表征 Seq2Seq translation（结构差异：cross-attention + 两套 token 系统）
2. **Anatomy-aware Tokenization** — 视觉 token 按人体解剖 / 运动链组织（结构差异：token 怎么切分）
3. **Biomechanical Grammar** — 把 ROM、joint hierarchy、velocity、acceleration、FK 写进训练目标（结构差异：loss 不只是 L_angle）

### 5.3 加分项

4. **Causal Future Kinematic Translation** — `Visual_{t-k:t} → Kinematics_{t:t+h}`（任务差异：从"现在"翻译到"未来"）

## 6. 我们的模型与 Chao 2026 的结构性差异

| 维度 | Chao 2026 | ViKiT (我们) |
|---|---|---|
| 输入表征 | CNN 全局特征 | **Anatomy-aware visual tokens**（按解剖切分）|
| 序列建模 | 单层 Transformer（时间动态）| **Spatio-temporal Transformer** + **cross-modal cross-attention**（视觉 sentence → 运动学 sentence）|
| 输出 | 连续角度向量 | **Kinematic tokens**（离散 + VQ 可恢复连续）|
| 损失函数 | `L_angle + λ L_velocity` | 加上 `L_acceleration + L_ROM + L_FK + L_temporal` |
| 任务 | 同步估计 | **可选 forecasting**：`V_{t-k:t} → A_{t:t+h}` |
| 评估 | MAE / RMSE / ICC | 加上 **ROM violation rate / FK consistency / temporal jerk** |

**关键**：每条差异都对应一个 ablation，能在实验里证明"切掉哪一块就不 work"。

## 7. 结论

- **「视觉替代 sEMG + Transformer」**：❌ 不够新（5 条独立路线已覆盖）
- **「结构化翻译 + anatomy-aware + grammar + forecasting」**：✅ 有空间（未见完全相同组合）
