阶段时间线

每个阶段回答一个问题：这一阶段 Transformer 解决或暴露了什么，以及对康复的直接含义。

  1. S0奠基期 2017-2018（原始架构与通用化）

    原始架构给了「编码器–解码器 + 交叉注意力」的骨架，这正是「源语言→目标语言」翻译范式的原型。

    → 康复含义：ViKiT 的「翻译」比喻在此有出处；康复领域至今少有真正的 encoder–decoder 结构，多为单塔回归。

    本阶段入库 5 篇：Layer Normalization、Attention Is All You Need、Universal Transformers、World Models、PartNet: A Recursive Part Decompositio

  2. S1效率与规模化 2019-2020（预训练语言模型 + 稀疏/线性注意力）

    预训练 + 稀疏/线性注意力：模型开始能吃长序列，注意力不再是平方级瓶颈。

    → 康复含义：长时程 sEMG 窗口与长视频段成为可建模对象；但稀疏化会丢细节，正是 Wei 2026 批评 Informer 的点。

    本阶段入库 22 篇：BERT: Pre-training of Deep Bidirection、Exploring the Limits of Transfer Learn、RoBERTa: A Robustly Optimized BERT Pre、Generating Long Sequences with Sparse 、Transformer-XL: Attentive Language Mod、ZeRO: Memory Optimizations Toward Trai …

  3. S2多模态与长序列 2021-2022（视觉/语言多模态 + 长上下文外推 + 视频）

    位置编码（RoPE/ALiBi）与视频、多模态成型；「空间注意力 + 时间注意力分解」成为人体姿态标准做法。

    → 康复含义：ViKiT 时空 encoder 的直接蓝本；RoPE 对角度序列的长度外推友好，可缓解「训练 27 帧、测试 81 帧」。

    本阶段入库 24 篇：LoRA: Low-Rank Adaptation of Large Lan、TokenLearner: What Can 8 Learned Token、RoFormer: Enhanced Transformer with Ro、Train Short, Test Long: Attention with、3D Human Pose Estimation with Spatial 、Is Space-Time Attention All You Need f …

  4. S3生成式与效率革命 2023（动作生成扩散 + 状态空间模型兴起）

    离散动作 token（T2M-GPT / MotionGPT）与状态空间模型（Mamba）同时爆发：一头是「可翻译」，一头是「可长跑」。

    → 康复含义：离散 kinematic vocabulary 有现成范式；Mamba 线性时间对康复实时闭环是硬需求。

    本阶段入库 23 篇：PhysDiff: Physics-Guided Human Motion 、Efficient Memory Management for Large 、FlashAttention-2: Faster Attention wit、Ring Attention with Blockwise Transfor、BLIP-2: Bootstrapping Language-Image P、DINOv2: Learning Robust Visual Feature …

  5. S4具身·世界模型·物理 2024-2025（物理约束人体运动 + 世界模型）

    物理先验注入人体运动（PhysPT / PHC）与测试时记忆（Titans）：开始处理「不满足物理规律的输出」。

    → 康复含义：biomechanical grammar 从「手写 loss」升级为「可学习/可约束的先验」；个体化在线校准有了架构答案。

    本阶段入库 8 篇：SAM 2: Segment Anything in Images and 、TokenHMR: Advancing Human Mesh Recover、Pre-Trained Video Generative Models as、Upper-Limb Rehabilitation with a Dual-、Byte Latent Transformer: Patches Scale、Gated Delta Networks: Improving Mamba2 …

  6. S5混合架构与测试时学习 2025-2026（线性注意力复兴 + 测试时记忆）

    线性注意力与混合架构复兴（delta rule 等），注意力不再是唯一解。

    → 康复含义：算力受限的康复端侧部署有了新选项；也提醒我们别把「Transformer」当成唯一范式押注。

线程分布与迁移密度

论文数不等于价值。真正要看的是「高迁移价值」的密度 —— 它决定了康复方向的优先级。

读法：条长 = 该线程总篇数；「高」= 其中康复迁移价值高的篇数。T5（动作生成与离散 token）与 T6（物理约束）在康复领域几乎未被占用，是创新密度最高的洼地。

推演：Transformer 已解决 → 康复可用的三个缺口

以下为推断，不是既有事实。每条都标注了它在语料中的证据来源，以及需要用实验证伪的判据。

D1 · 证据线程 T5

离散 kinematic token 取代连续角度回归

语料证据：T2M-GPT / MotionGPT 已把连续运动量化成离散 token 再用自回归建模；TokenHMR 已把姿态做成词表。

可做什么：ViKiT 现有 256 桶 bucketize 仍是<b>硬量化</b>，会丢分辨率且训练/推理不匹配。可改用<b>残差 VQ-VAE + EMA 码本更新 + 死码复活</b>，与 T2M-GPT 的 VQ 方案对齐。

证伪判据：判据：同参数量下，VQ 版本 MAE 必须低于 bucketize；且码本利用率（非零码字占比）需 &gt; 80%。

D2 · 证据线程 T7

长时序实时预测：线性/混合架构替代纯注意力

语料证据：Mamba 证明选择性状态空间可线性时间建模长序列；2025 的 delta rule 复兴说明注意力不再是唯一解。

可做什么：康复端侧算力受限（Wei 2026 用 Tesla T4 训练 &lt;2 分钟），300 ms 提前预测 + 长窗口在纯注意力下成本高。可做<b>注意力/SSM 混合编码器</b>，前段注意力抓局部关节耦合、后段 SSM 抓长时程。

证伪判据：判据：同等 MAE 下参数量与推理延迟显著低于纯 Transformer；且延迟抖动（jitter）必须下降。

D3 · 证据线程 T6

物理约束从「手写 loss」升级为「可学习先验」

语料证据：PhysPT / PHC 把物理一致性作为预训练约束而非纯后处理；章隆彬团队 NMS+ML 混合已在康复侧验证过物理+学习路线。

可做什么：ViKiT 现有 6 项 grammar loss 是手写标量惩罚。可升级为<b>能量/约束模型 + projection 投影解码</b>：训练期学约束强度，推理期把预测投影回可行域（ROM + FK），得到<b>硬保证</b>而非软惩罚。

证伪判据：判据：ROM violation rate 必须<b>恒等于 0</b>（硬约束定义），且 MAE 相对软 loss 的退化需在统计显著范围内可接受。

D4 · 证据线程 T3

位置编码与长度外推：解决训练/测试窗口不一致

语料证据：RoPE 通过旋转把相对位置编码进注意力，长度外推能力远好于绝对位置编码；ALiBi 走另一条外推路线。

可做什么：康复数据采集窗口常变（250 ms / 150 ms / 不等），且跨速度、跨被试长度不一致。引入 RoPE 可让模型在<b>未见过的窗口长度</b>上直接推理。

证伪判据：判据：在训练未出现过的窗口长度上，MAE 相对 baseline 劣化 &lt; 10%。

D5 · 证据线程 T4

多模态融合：RGB-D + IMU + sEMG 的统一 token 系统

语料证据：Flamingo 的交错块注意力证明「冻结专家 + 轻量适配」可在异构模态间传信息，且不破坏预训练权重。

可做什么：本项目 D435i（RGB-D + 内置 IMU）与章隆彬团队 sEMG 天然是异构模态。可用<b>各自编码器 + 交错块 cross-attention</b>，先单模态可用，再逐步融合 —— 避免一开始就因多模态对齐失败而全盘皆输。

证伪判据：判据：单模态子模型各自可用；融合后至少不比单模态最差者差。

D6 · 证据线程 T4

个体化：测试时记忆 / 参数高效适配

语料证据：LoRA 与 Titans（测试时记忆）提供了「少量样本快速个性化」的架构路径，而非全量重训。

可做什么：康复个体差异极大（章隆彬路线也强调跨被试迁移难）。可把 anatomy tokenizer + kinematic codebook 用 LoRA 冻结大部分预训练权重，逐个被试用极少数据适配。

证伪判据：判据：每被试 ≤1 分钟适配数据即可显著降低误差，且原始权重不被污染。
