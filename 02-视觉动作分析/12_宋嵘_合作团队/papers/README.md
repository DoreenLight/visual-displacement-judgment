```
papers/
├── 运动理解/    6 篇   意图解码、力矩与肌骨建模
```

单篇文件夹命名：`<作者姓><年>-<刊>：<中文题名>/`，内含：

| 文件 | 说明 |
|---|---|
| `<名>.pdf` | 原件 |
| `<名>_抽取_en.md` | MinerU 英文抽取稿（**未翻译**），含表格与公式 |
| `<名>_证据卡.md` | 仅 `背景资料/` 的 5 篇有，来自既有原件核验 |
| `images/` | md 中引用的图块 |
| `原文图像/` | 逐页整页图 `page-001.jpg`… |

## 重要提示

**`<名>_抽取_en.md` 内的图片引用是 `images/xxx.jpg`。** 若把该 md **单独**拷到别处，图片会断链——须与 `images/` 同级整体移动。
