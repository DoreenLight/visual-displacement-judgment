# 基于肌肉协同肌电控制器的绳索驱动上肢康复机器人

Chenglin Xie , Graduate Student Member, IEEE, Yueling Lyu, Guoxin Li , Member, IEEE,

Raymond Kai-Yu Tong , Senior Member, IEEE, Haisheng Xia , Member, IEEE,

Rong Song , Senior Member, IEEE, and Zhijun Li , Fellow, IEEE

摘要—表面肌电（sEMG）信号已应用于上肢康复机器人（ULRR）。然而，现有的基于肌电控制器的 ULRR 在估计三维（3-D）运动意图时的泛化能力有限。本文提出了一种受肌肉协同启发的方法，以增强绳索驱动 ULRR 肌电控制器的泛化能力。基于肌电-肌肉激活度模型和非负矩阵分解（non-negative matrix factorization），从 sEMG 信号中提取低维控制指令。所提取的指令用于估计三维人体力。选取两种不同的轨迹跟踪任务来测试泛化能力。系统基于参与者执行其中一项任务的训练集进行训练。然后使用参与者执行另一项任务的测试集对系统进行测试。最后，在实时机器人控制实验中对该系统进行了验证。结果表明，与未考虑肌肉协同的肌电控制器相比，所提出的控制器获得了更好的力估计精度、更好的轨迹跟踪精度以及更低的交互力，这意味着所提出的控制器具有更好的泛化性能。

## I. 引言

脑卒中是导致死亡和长期残疾的主要原因之一 [1], [2]。据估计，超过 80% 的脑卒中幸存者会出现一定程度的上肢运动功能障碍，这影响了患者的日常生活活动，并给卒中后的照护带来了巨大负担 [3]。随着全球每年新增脑卒中病例超过 1500 万例 [4]，由于物理治疗师数量有限且工作繁重，传统的康复治疗手段已显不足 [5]。机器人辅助康复具有提供高强度和定量化治疗的优势 [6]。近年来，上肢康复机器人（upper limb rehabilitation robots, ULRRs）已成为治疗师主导的卒中患者上肢康复治疗的有益补充 [7]。

机器人辅助康复的有效性在很大程度上取决于控制策略。为了满足康复训练的需求，学者们提出/采用了各种控制策略。传统上，被动控制策略被用于确保跟踪给定轨迹的准确性，并提供被动康复训练 [8]。为了提高康复中人机交互的顺应性，阻抗控制被用于调节交互力与位置之间的动态关系 [9], [10], [11]。由于主动参与对于促进脑卒中后患者运动功能的恢复至关重要 [12]，主动控制策略在实现以人为主导的康复训练方面受到了越来越多的关注 [13], [14], [15]。Saglia 等人 [13] 构建了一种导纳控制策略，以交互力作为输入为机器人生成期望位置。表面肌电（surface electromyography, sEMG）信号与运动意图相关，因此也可以用作康复机器人的输入以实现主动控制 [15], [16], [17], [18], [19], [20]。sEMG 信号产生于人体自主发力之前，这为补偿受试者自主发力与机器人响应之间的时间延迟提供了契机，从而增强了人机同步性 [21]。Zhuang 等人 [21] 利用希尔型肌肉骨骼模型（Hill-type musculoskeletal model, HMM）为踝关节康复机器人开发了一种基于 sEMG 的导纳控制策略。Fleischer 和 Hommel [22] 提出了一种基于 sEMG 的力矩控制策略，该策略同样基于 HMM。尽管 HMM 已被用于连续估计一维（1-D）力，但由于三维上肢运动的高度复杂性，它很难用于 3-D 空间中的上肢末端力/位置估计 [23], [24]。状态空间模型已被用于通过 sEMG 信号连续估计上肢的 3-D 末端力，并赋予了上肢康复机器人（ULRR）提供特定任务运动辅助的能力 [25], [26]。

肌肉协同（muscle synergy）是一种利用协同原理来提取运动意图的生物学理论 [27], [28], [29]。神经生理学研究表明，中枢神经系统（central nervous system, CNS）可以通过肌肉协同来简化运动的神经控制，其中 CNS 利用较低维度的指令来招募较多数目的肌肉 [28], [30], [31]。Berniker 等人 [28] 基于肌肉协同理论建立了一个低维控制器，用以重建青蛙后肢的自然运动轨迹。Saito 等人 [32] 提供了证据，证明在复杂的手臂运动中存在人类上肢肌肉协同的基本单元。Muceli 等人 [33] 证明，从三个充分分离的方向运动期间的肌肉激活中所提取的肌肉协同，能够描述在所有其他方向运动期间的肌肉激活。为了提取肌肉协同，已有许多算法被采用：主成分分析（principle component analysis, PCA）[34]、独立成分分析（independent component analysis, ICA）[35]、神经网络 [36] 以及非负矩阵分解（non-negative matrix factorization, NNMF）[27], [28], [37], [38]。其中，NNMF 可用于将肌肉激活矩阵分解为两个非负部分：肌肉协同矩阵和低维指令 [28]。NNMF 算法引起了特别的关注，因为它能够提取出符合神经肌肉非负激活物理约束的非负特征 [36], [39]。

大多数现有的基于肌肉协同（muscle synergy）的方法已被应用于离线分析 [40], [41], [42]，或假手 [29] 与虚拟手 [43] 的离散控制，尚未涉及基于表面肌电（sEMG）的物理人机交互（physical human–robot interaction, pHRI），例如在机器人辅助康复训练中，特别是在 3-D 空间中。这种环境下的 pHRI 是复杂且连续的，因此需要将基于肌肉协同的方法与肌电控制器相结合以提高泛化能力，但目前这方面研究仍处于空白状态。在本文中，采用了一种部分基于先前研究 [25] 的末端执行器式绳索驱动上肢康复机器人（cable-driven upper limb rehabilitation robot, CDULRR）来辅助上肢粗大运动。应用肌电-肌肉激活模型与实时 NNMF（非负矩阵分解）算法，从八块上肢肌肉的 sEMG 信号中提取 6-D 指令。提取的指令基于状态空间模型和导纳控制器用于实时控制末端执行器。本文考虑了两种轨迹跟踪任务：类三角形和类矩形轨迹任务。对于每位参与者，其中一种轨迹任务用于模型训练，而另一种任务则用于模型测试和在线验证（即跨任务）。我们假设肌肉协同理论不仅可以如 [32]、[33] 和 [37] 中所证实的那样用于在伸展任务中重构 sEMG 信号，而且可能有助于在上肢 3-D 力估计以及跨任务康复训练的运动辅助中取得更好的泛化性能。据我们所知，我们首次将基于肌肉协同的肌电控制器应用于 ULRR，以在不同轨迹跟踪任务中实现 3-D 连续运动辅助，并比较了在 pHRI 下考虑与不考虑肌肉协同的连续肌电控制器的泛化性能。

## II. 方法

## A. CDULRR 平台

CDULRR 平台如图 1（Fig. 1）所示，该平台由一个末端执行器、四台电机（DM1B-045G，Yokogawa Co.）、四台相机（OptiTrack-2，NaturalPoint Co.）、一个屏幕以及一个名为 dSpace（RTI-1202，dSpace Co.）的实时操作系统组成。末端执行器由四根线缆驱动，这些线缆由四台电机以 100 Hz 的控制频率驱动。末端执行器上安装了三个光学标记点。运动捕捉系统的四台相机能够以 100 Hz 的频率获取每个标记点的位置。三个标记点的中心被视为末端执行器的实际位置。受试者握住末端执行器，末端执行器上有缠绕在手上的魔术贴绑带。受试者前方的屏幕提供视觉反馈，其中虚拟黑色光标代表参考位置，而橙色光标代表末端执行器的实际位置。四个压力传感器（HSTLBLSM，BHX. Tech. Dev. Co.）用于测量四根线缆的张力。八对 AgCl 电极以 1 kHz 的采样频率测量八块肌肉（列于表 I（Table I））的表面肌电（sEMG）信号，作为输入信号。与先前文献 [25] 中的硬件不同，我们在末端执行器中内置了一个六维力传感器（D45MM-F400N）以测量人机交互力，并将基于 PC-NI 系列的控制卡升级为基于 dSpace RTI-1202 的嵌入式实时操作系统。dSpace 操作系统实时处理输入信号并控制四台电机。CDULRR 系统能够在三维（3-D）工作空间内提供康复训练任务，使其适用于广泛的日常活动。由于电机远离末端执行器，这种线驱动并联机器人具有良好的柔顺性、重量轻、低惯量以及高安全性等优势。

## B. 基于肌肉协同的肌电控制器

在 dSpace 操作系统中实现的整体控制框架如图 2（Fig. 2）所示。使用肌电-肌肉激活度模型计算肌肉激活度向量 $\pmb { v } \in \mathbf { R } ^ { m \times 1 }$，其中 $\textit { m } = \textit { 8 }$ 为肌肉数量。接着，提取 $n$ $( n < m )$ 维非负指令向量 $\hat { h } \in { \bf R } ^ { n \times 1 }$，然后通过力估计模型估计三维人体力 $\pmb { f } _ { h } \in \mathbf { R } ^ { 3 \times 1 }$。随后，导纳滤波器根据 $f _ { h }$ 生成末端执行器的原始期望位置 $P _ { d } \in \mathbf { R } ^ { 3 \times 1 }$。$P _ { d }$ 被限制在 CDULRR 的工作空间内，形成期望位置 $P _ { d } ^ { * }$。绳索轨迹规划器和 PID 环路与先前文献 [25] 中描述的相同。

1) 肌电至肌肉激活度模型（EMG-to-Muscle Activation Model）：测得的 sEMG 信号经过全波整流，然后通过截止频率为 4 Hz 的四阶低通滤波器。接下来，通过最大等长自主收缩（MVC）对信号进行归一化，形成 $e _ { j } ( t )$。有关 MVC 测量的详细信息见文末附录。随后，利用二阶线性模型计算时间 $t$ 处第 $j$ 条肌肉的神经激活度

$$
n _ {j} (t) = \alpha e _ {j} (t - d) - \beta_ {1} n _ {j} (t - 1) - \beta_ {2} n _ {j} (t - 2)\tag{1}
$$

其中 $d = 100\text{ ms}$，$\alpha = 0.95$，$\beta = 0.05$，且 $\beta _ { 2 } = 0 . 0 0 0 6$ [25]。

采用文献 [44] 中的模型计算肌肉激活度 $v _ { j } ( t )$

$$
v _ {j} (t) = \left\{ \begin{array}{l l} \gamma \ln (\delta n _ {j} (t) + 1), & 0 \leq n _ {j} (t) <   n _ {0} \\ m n _ {j} (t) + c, & n _ {0} \leq n _ {j} (t) \leq 1 \end{array} \right.\tag{2}
$$

其中 $n _ { 0 } = ~ 0 . 2 5 , ~ \delta ~ = ~ 1 0 . 4 8 , ~ \gamma ~ = ~ 0 . 2 9 , m ~ = ~ 0 . 8 4 ,$ ，且 $c = 0 . 1 6 .$。

2) 非负矩阵分解（Non-Negative Matrix Factorization）：给定由数据集中八通道时序肌肉激活度组成的矩阵 $V \in$ $\mathbf { R } ^ { m \times T }$，可以使用 NNMF 将肌肉激活度矩阵 $V$ 分解为两个非负部分

$$
\boldsymbol {V} _ {(m \times T)} \approx \boldsymbol {W} _ {(m \times n)} \boldsymbol {H} _ {(n \times T)}\tag{3}
$$

其中 $T$ 是数据集中的采样时间点数，$V =$ $[ v _ { 1 } [ 1 ] , v _ { 1 } [ 2 ] \ldots v _ { 1 } [ T ] ; \ldots ; v _ { m } [ 1 ] , v _ { m } [ 2 ] \ldots v _ { m } [ T ] ] \in \mathbf { R } ^ { m \times T }$，${ \cal W } \in { \bf { R } } ^ { m \times n }$ 是肌肉协同矩阵，$H \in \mathbf { R } ^ { n \times T }$ 是低维非负指令矩阵，$n$ 是肌肉协同数量。

采用交替最小二乘（ALS）算法实现 NNMF [45]，NNMF 的目标是最小化分解残差的均方根

$$
\text { minimize }: \varepsilon = \frac {\| \boldsymbol {V} _ {(m \times T)} - \boldsymbol {W} _ {(m \times n)} \boldsymbol {H} _ {(n \times T)} \|}{\sqrt {m \times T}}.\tag{4}
$$

3) 非负指令提取：基于奇异值分解（SVD）方法可获得肌肉协同矩阵的伪逆 $W ^ { + } \in \mathbf { R } ^ { n \times m }$（伪逆 $W ^ { + }$ 的证明见附录 B），并用于从预先记录的数据集中提取非负指令 $\hat { H } \in \mathbf { R } ^ { n \times T }$

$$
\hat {\boldsymbol {H}} _ {(n \times T)} = \boldsymbol {W} _ {(n \times m)} ^ {+} \boldsymbol {V} _ {(m \times T)}.\tag{5}
$$

4) 传递函数：采用传递函数模型来描述数据集中 $\hat { H }$ 与三维人体力 $F _ { h } \in \mathbf { R } ^ { 3 \times T }$ 之间的关系

$$
G (s) = \frac {F _ {h} (s)}{\hat {H} (s)} = \frac {N (s)}{D (s)}.\tag{6}
$$

分子系数向量 $N ( s )$ 和分母系数向量 $D ( s )$ 可以使用工具变量（instrument variable）算法 [46] 进行辨识。

5) 实时非负指令提取模型：出于人机交互中实时响应性的需求，我们将 NNMF 技术与基于 SVD 的伪逆矩阵计算相结合，以连续处理 sEMG 信号并提取中枢神经系统（CNS）指令，而不是对一段数据进行一次性 [40], [41] 或间歇性 [29] NNMF。在人机交互的每个时刻，给定肌肉激活向量 $\pmb { v } \in \mathbf { R } ^ { m \times 1 }$ 时，可通过使用 $W ^ { + }$ 获得实时非负指令 $\hat { h } \in { \mathbf { R } } ^ { n \times 1 }$

$$
\hat {\boldsymbol {h}} _ {(n \times 1)} = \boldsymbol {W} _ {(n \times m)} ^ {+} \boldsymbol {v} _ {(m \times 1)}.\tag{7}
$$

6) 力估计模型：辨识出的传递函数模型可以转换为具有辨识系数矩阵 A、B、C、D 以及 x[0] 的状态空间模型。该状态空间模型能够方便地实现实时力估计

$$
\left\{ \begin{array}{l} x [ k + 1 ] = A x [ k ] + B \hat {\boldsymbol {h}} [ k ] \\ \boldsymbol {f} _ {\boldsymbol {h}} [ k ] = C x [ k ] + D \hat {\boldsymbol {h}} [ k ] \end{array} \right.\tag{8}
$$

其中 ${ \pmb x } [ k ]$ 是第 $k$ 个采样时刻的隐状态向量，$\hat { h }$ 是输入向量（即实时非负指令），$f _ { h }$ 是输出向量（即估计的三维人体力），$A$ 表示表示状态 $x$ 动态特性的系统矩阵，$B$ 表示将输入信号引入状态 $x$ 的输入矩阵，而 $C$ 和 $D$ 则是展示状态 $x$ 和输入 $\hat { h }$ 如何决定输出向量的矩阵。

7) 导纳滤波器：应用导纳滤波器根据 $f _ { h }$ 生成末端执行器的原始期望位置 $P _ { d }$

$$
\boldsymbol {P} _ {d} = \boldsymbol {P} + \boldsymbol {f} _ {h} \big (\boldsymbol {M} _ {h} s ^ {2} + \boldsymbol {B} _ {h} s + \boldsymbol {K} _ {h} \big) ^ {- 1}\tag{9}
$$

其中 $P \in \mathbf { R } ^ { 3 \times 1 }$ 为实际位置向量；$M _ { h } \in { \bf R } ^ { 3 \times 3 }$、$B _ { h } \in { \bf R } ^ { 3 \times 3 }$ 以及 ${ \pmb K } _ { h } \in { \bf R } ^ { 3 \times 3 }$ 分别为质量、阻尼和刚度矩阵。由于在康复训练中手臂的加速度较小，质量项 $M _ { h } s ^ { 2 }$ 可以忽略 [13]。

8) 工作空间限制：为防止末端执行器与人体交互时发生潜在危险，添加了工作空间限制以确保末端执行器的位置在以下范围 $U$ 内工作：

$$
\left\{(x, y, z) \mid \sqrt {(x - x _ {s}) ^ {2} + (y - y _ {s}) ^ {2} + (z - z _ {s}) ^ {2}} \leq r \right\}\tag{10}
$$

其中 $r = 0 . 2 5 m , x _ { s } = 0 m , y _ { s } = 1 m$ 且 $z _ { s } = - 0 . 6 5 m$。若 $P _ { d }$ 超出范围 $U$，则期望位置 $P _ { d } ^ { * }$ 将等于实际位置

$$
\boldsymbol {P} _ {d} ^ {*} = \left\{ \begin{array}{l} \boldsymbol {P} _ {d},   \boldsymbol {P} _ {d} \in U \\ P,   \boldsymbol {P} _ {d} \notin U \end{array} \right.\tag{11}
$$

9) 绳索轨迹规划器：随后，绳索轨迹规划器将 $P _ { d } ^ { * }$ 转换为三根上部绳索的期望长度 $( P _ { l d } )$

$$
\left\{ \begin{array}{l} \boldsymbol {P} _ {l d} = [ P _ {l d, 1}, P _ {l d, 2}, P _ {l d, 3} ] ^ {T} \\ P _ {l d, i} = \| \boldsymbol {P} _ {d} ^ {*} - \boldsymbol {C} _ {i} \| \end{array} \right.\tag{12}
$$

其中 $C _ { i }$ 表示第 $i$ 个滑轮的三维位置。

10) PID 控制器与绳索张力控制器：应用 PID 控制器控制三根上部绳索的驱动力，确保末端执行器跟踪期望位置。第 $i$ 根 $( i = 1 , 2 , 3 )$ 绳索的驱动力确定如下：

$$
\begin{array}{l} F _ {l, i} = K _ {p} (P _ {l d, i} - P _ {l, i}) + K _ {i} \int_ {1} ^ {t} (P _ {l d, i} - P _ {l, i}) d t \\ \qquad + K _ {d} \frac {d (P _ {l d , i} - P _ {l , i})}{d t} \end{array}\tag{13}
$$

其中 $P _ { l , v }$ <sub>i</sub> 为第 $i$ 根绳索在关节空间中的实际位置；$K _ { p }$、$K _ { i }$ 和 $K _ { d }$ 为 PID 系数。

为了保持绳索张力，采用了一个绳索张力控制器，根据测得的绳索张力来控制下部绳索的驱动力

$$
F _ {l 4} = \left\{ \begin{array}{l} - 2 7 \left(f _ {\min} - f _ {l 4}\right), f _ {l 4} <   7 N \\ 0, 7 N \leq f _ {l 4} \leq 1 0 N \\ 2 7 \left(f _ {l 4} - f _ {\max}\right), f _ {l 4} > 1 0 N \end{array} \right.\tag{14}
$$

其中 $f _ { l 4 }$ 为测得的下部绳索张力。

## C. 实验设置

本研究招募了八名健康受试者（四名男性和四名女性；年龄：24–29 岁）以验证所提出的控制器。受试者被随机分配到两组（Group1 和 Group2），并满足每组均包含两名男性和两名女性的规则。在每一组中，一种轨迹任务用于模型训练，而另一种任务则用于模型测试和在线验证，以检验控制器在不同任务间的泛化能力。

数据集通过记录所有参与者的 sEMG 信号和三维人体末端力获得。数据记录的详细信息与前文所述相同（请参阅 [25]）。参与者被要求坐在椅子上，坐标系的定义为：x 轴垂直于矢状面，y 轴垂直于水平面，z 轴垂直于冠状面。每位参与者在没有 CDULRR 辅助的情况下，重复跟踪类三角形轨迹和类矩形轨迹各九次。利用 sEMG 信号通过 (1) 和 (2) 计算肌肉激活矩阵 V。接着进行 NNMF（非负矩阵分解），根据 (3)–(5) 对训练集中的 V 进行分解，获得肌肉协同矩阵的伪逆 $W ^ { + }$ 以及非负指令 H<sup>ˆ</sup>。动作捕捉系统（见 II-A 节所述，精度为 0.1 mm）记录的末端执行器三维位置数据被输入到 (9) 中，以推导出估计的三维力 $f _ { h } ,$，该力作为传递函数模型的参考/观测输出。在 Group1 中，类三角形轨迹任务的数据集用于训练阶段，类矩形轨迹任务的数据集用于测试阶段。在 Group2 中，类矩形轨迹任务的数据集用于训练阶段，而类三角形轨迹任务的数据集用于测试阶段。在训练阶段，辨识传递函数模型以拟合输入数据 $\hat { H }$ 与输出数据 $\mathbf { } F _ { h }$ 之间的关系，随后将其转换为状态空间模型。在测试阶段，根据训练阶段预训练的 $W ^ { \bar { + } }$ 推导出非负指令 $\hat { H }$，然后利用状态空间模型估计三维人体力。最后，将估计的三维人体力数据与实际数据进行对比。

在在线验证中，Group1 中的每位参与者在 CDULRR 的辅助下重复跟踪类矩形轨迹九次，而 Group2 中的每位参与者跟踪类三角形轨迹。末端执行器由参与者的 sEMG 信号进行实时控制。为了进行对比，每位参与者还使用不考虑肌肉协同的肌电控制器（即肌肉激活向量直接作为力估计模型的输入，参见 [25]）进行了九次实验。在该控制器中，使用肌肉激活矩阵 V 代替非负指令 H<sup>ˆ</sup> 来训练传递函数模型，并应用实时肌肉激活向量 v 代替 h<sup>ˆ</sup> 进行实时机器人控制。选取两个控制器的跟踪误差和交互力作为性能对比指标。

为简化上述描述，Group1 进行的实验被命名为“三角形到矩形”（triangle-to-rectangle），而 Group2 执行的实验被称为“矩形到三角形”（rectangle-to-triangle）。这两个动作与进食和物体操控等日常活动相关。

## D. 信号处理与统计分析

重建质量是评估 NNMF（非负矩阵分解）的重要指标。重建矩阵 $\tilde { V }$ 可以通过 W 与 $\hat { H }$ 相乘计算得出

$$
\tilde {\pmb {V}} _ {(m \times T)} = \pmb {W} _ {(m \times n)} \hat {\pmb {H}} _ {(n \times T)}.\tag{15}
$$

重建误差被用作衡量重建质量的一个指标

$$
\mathrm{RMSE} = \| \boldsymbol {V} - \tilde {\boldsymbol {V}} \|.\tag{16}
$$

重建肌肉激活度与原始肌肉激活度之间的 Pearson 相关系数被用作衡量重建质量的另一个指标。

计算力估计误差以评估数据集上基于 sEMG 的力估计性能

$$
f _ {\text { RMSE } i} = \sqrt {\frac {1}{T} \sum_ {k = 1} ^ {T} \left(\boldsymbol {f} _ {\text { actual }} [ i , k ] - \boldsymbol {f} _ {\text { estimate }} [ i , k ]\right) ^ {2}}\tag{17}
$$

其中 $i = 1 , 2 , 3$ 分别代表 $x , y , z$ 轴上的数据。

计算机器人与人之间绝对交互力的积分，以评估在线肌电控制任务的性能

$$
f _ {\text { int   3D }} = \sqrt {\frac {1}{T} \sum_ {k = 1} ^ {T} \| \boldsymbol {f} _ {\text { int }} [ k ] \| ^ {2}}\tag{18}
$$

其中 $f _ { \mathrm { \ i n t } }$ 是由内置在末端执行器中的力传感器测得的交互力。

同时也计算了跟踪误差，以评估在线肌电控制任务的跟踪性能

$$
P _ {\text { RMSE } i} = \sqrt {\frac {1}{T} \sum_ {k = 1} ^ {T} \left(\boldsymbol {P} _ {\text { reference }} [ i , k ] - \boldsymbol {P} _ {\text { actual }} [ i , k ]\right) ^ {2}}\tag{19}
$$

$$
P _ {\text { RMSE   3D }} = \sqrt {\frac {1}{T} \sum_ {k = 1} ^ {T} P _ {\text { reference }} [ k ] - P _ {\text { actual }} [ k ] ^ {2}}.\tag{20}
$$

按轴评估方法有助于分析三维用力特征中的手臂运动，并评估人机耦合系统在三维空间中的性能。

## III. 结果

## A. 肌肉协同提取

一名代表性参与者数据集中重构肌肉激活与原始肌肉激活之间的皮尔逊相关系数矩阵（也称为混淆矩阵）如图 3(a)–(g) 所示。在每个矩阵中，列和行分别对应原始肌肉激活向量和重构结果。图 3(a)–(g) 分别展示了使用 $n = 1 { - } 7$ 个肌肉协同时的混淆矩阵。结果表明，随着 n 的增加，当 $n \leq 6 .$ 时，重构肌肉激活与相应原始肌肉激活之间的皮尔逊相关系数（混淆矩阵对角线上的像素）增大，而 $n = 6$ 和 $n = 7 .$ 之间差异很小。图 3(h) 显示了在使用不同数量的 MS 时，测试集中九次试验（九条不同颜色的实线）和训练集中（虚线）的重构误差。结果表明，随着 n 的增加，当 $n \leq 6$ 时重构误差减小，而 $n = 6$ 和 $n = 7$ 之间几乎没有差异。使用六个肌肉协同时的重构误差非常小 $( \mathrm { R M S E } _ { } = 0 . 0 0 1 3 \mathrm { - } 0 . 0 0 1 7 )$ 。这意味着在执行上肢粗大动作时，$n = 6$ 足以描述/重构八块肌肉的肌肉激活。因此，我们选择 $n = 6$ 进行肌肉协同提取，并进一步用于三维人体力估计和在线机器人控制。

## IV. 讨论

## A. 开发基于肌肉协同的肌电控制器的动机

估计三维（3-D）上肢运动意图是肌电控制器面临的一项挑战 [47]。由于三维上肢运动非常复杂，建立神经肌肉骨骼系统模型十分困难 [23], [24]。先前的文章训练了一个状态空间模型来描述肌肉激活度与上肢三维末端力之间的关系 [25]。然而，此类未考虑生理机制的方法具有任务特异性，且泛化性能较差 [48]。神经生理学研究表明，中枢神经系统（CNS）似乎通过耦合肌肉激活来利用肌肉协同（muscle synergies）简化神经控制 [28], [32], [33], [49]。肌肉协同可用作运动评估的指标，并已应用于离线分析 [40], [41], [42]，这为深入理解人体运动功能以及进行全面准确的评估提供了支持。在本文中，受 CNS 以及从三个充分分离方向的运动中提取的肌肉协同可用于描述所有其他方向运动这一证据的启发 [33]，利用肌肉协同矩阵获得的低维非负控制指令似乎与三维上肢力具有直观且相关的联系。例如，非负指令矩阵的第六行[$H _ { 6 }$ 在 Fig. 4(b) 中]与人体力的 z 轴[$F _ { h , z }$ 在 Fig. 4(d) 中]相关。同样，$H _ { 2 }$ 与 $F _ { h , y } .$ 相关。这些直观且相关的联系可能有助于提升力估计模型的辨识性能，从而改善控制器的泛化能力。这种现象类似于刺激青蛙 CNS 中的特定模块化组织时会产生一组特定力方向的发现 [50]。除了 NNMF（非负矩阵分解），还有其他降维技术，如 PCA（主成分分析）和 ICA（独立成分分析）。尽管 NNMF 的谱无法像 PCA 那样紧凑，且与其他降维技术相比，NNMF 的稀疏性和基于部分的表示优势是以更高的复杂度为代价的 [51], [52]，但我们仍采用 NNMF 进行肌肉协同提取，因为它能够提取具有物理意义的非负特征，并符合神经肌肉激活非负的物理约束 [36], [39], [53]。在机器人辅助康复中，复杂的人机交互需要人类参与 [54] 并依赖 CNS 的调控 [55]。所提出的基于肌肉协同的肌电控制器是一种模仿 CNS 调控的仿生方法，能够促进人类 CNS 控制，从而提升肌电控制的性能。此外，我们的 CDULRR 具有低惯性和柔性驱动特性，可减少机器人对 pHRI（物理人机交互）的影响。

## B. 肌肉协同提取的参数确定

肌肉协同（MS）提取需要确定肌肉协同的数量 $n$。Valk 等人 [37] 的相关研究表明，3–5 个肌肉协同可以描述某些受限的动作集，并指出在考虑更广泛的动作集时需要 6–8 个肌肉协同。因此，$n \geq 6$ 适用于三维（3-D）任务中的上肢运动。由于在训练集和测试集中，当 $n \geq 6$ 时均未观察到重建误差的下降 [Fig. 3(h)]，因此本文选择了 $n = 6$。尽管低维输入可能会导致信息丢失，但本文中的非负矩阵分解（NNMF）考虑了来自所有肌肉激活通道的信息，并且交替最小二乘（ALS）算法最小化了分解残差的均方根 [45]。关键信息将得以保留，这可以通过当 $n = 6$ 时重建矩阵与原始矩阵高度相关且重建误差足够小这一证据来说明。由于中枢神经系统（CNS）通过耦合有限的肌肉激活集来调节肌肉骨骼系统中存在的冗余 [56]，因此在不丢失关键信息的情况下实现低维指令提取是可行的。

## C. 基于肌肉协同的肌电控制器的泛化能力

尽管如先前的文献 [25], [26] 所述，状态空间模型可用于根据肌肉激活程度连续估计上肢的三维自主力并提供特定任务的运动辅助，但当应用于此前未经训练的新任务时，其性能会有所下降。相比之下，采用受肌肉协同启发的方法提高了三维力估计的泛化能力（图 5、6、10 和 11）。轨迹跟踪误差和交互力的降低反映了参与者的自然控制，这与先前的文献 [21], [57] 一致。本文中准确的力估计、较低的轨迹跟踪误差以及较低的人机交互力证明了 MS 控制器的泛化性能。其原因在于，低维非负指令与三维力之间直观且相关的联系有助于力估计模型的辨识。此外，肌肉协同提取降低了力估计模型输入的维度，这使得模型的训练更加便捷。还有其他研究采用切换模型来适应不同的任务，其中分别训练了几个子模型，并针对特定任务选择特定子模型 [23], [26], [58]。然而，切换模型仍需将每个任务中记录的数据纳入训练集。与子模型训练方法相比，本文中基于肌肉协同的肌电控制器仅使用来自一个任务的数据进行训练，随后即可直接应用于另一个不同的任务（无论在测试集还是在线验证中）而无需重新训练，这体现了泛化能力的提升。

## D. 局限性与未来工作

1) 已有一项神经生理学研究探讨了青蛙肢体的空间导航与网格细胞激活之间的关系 [59]。揭示肢体的空间导航（或网格细胞的激活）似乎有助于以更便捷的方式估计三维肢体力或三维肢体运动。基于肌肉协同的肌电控制器是否模拟了网格细胞的激活仍尚不明确。未来的研究可以通过使用脑电图（electroencephalography）定位被激活的网格细胞，进一步探究肌肉协同与网格细胞之间的关系。

2) 搭载所提出控制器的 CDULRR 已在八名健康受试者上进行了测试，且本文仅开展了 144 次试验。然而，患者的肌肉协同可能与健康人存在差异。在未来的研究中，应招募包括中风后患者在内的更多受试者，并开展更多具有针对性临床益处的运动测试。

3) 在整个康复过程中，患者 CNS（中枢神经系统）内的运动技能和运动模式表征可能会发生改变。然而，这些变化通常以相对缓慢的速度发生，因此，系统的重训练周期可能会持续数周至数月。未来的文章将探索用于全周期康复训练的更具鲁棒性的系统，包括融合远程呈现技术。

## V. 结论

本文开发了一种基于肌肉协同的肌电控制器，用于连续估计 3-D 上肢力，并在绳索驱动康复机器人上进行了验证。选取了两种不同的轨迹跟踪任务来测试控制器的泛化能力。其中一项任务用于模型训练，而另一项任务则同时用于模型测试和在线验证。与不考虑肌肉协同的肌电控制器相比，所提出的控制器在跨任务康复训练中展现出更好的泛化性能。
