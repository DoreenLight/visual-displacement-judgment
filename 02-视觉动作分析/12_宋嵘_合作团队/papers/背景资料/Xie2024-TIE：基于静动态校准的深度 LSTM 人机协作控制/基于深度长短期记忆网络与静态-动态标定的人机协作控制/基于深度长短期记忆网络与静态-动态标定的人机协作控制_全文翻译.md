# 基于深度长短期记忆网络与静态-动态标定的人机协作控制

Chenglin Xie，IEEE学生会员，Zhijun Li，IEEE会士，以及 Rong Song，IEEE高级会员

摘要—利用肌电（EMG）信号估计人体三维（3-D）上肢运动意图是人机协作系统中的一项极具前景的技术。由于3-D上肢神经肌骨骼系统内的非线性成分以及人机耦合系统中复杂的动态在线环境，该技术极具挑战性。在本文中，提出了一种深度长短期记忆（Deep-LSTM）网络，用于为上肢绳驱机器人（UL-CDR）建立非线性EMG到3-D力的映射模型。为了增强模型对动态环境的适应性，我们提出了一种静态-动态标定方法，该方法首先利用静态测量数据训练网络，随后利用动态数据对其进行微调。招募了受试者在UL-CDR的辅助下进行160次试验以跟踪参考轨迹。结果表明，与仅采用静态标定的方法相比，所提出的方法获得了更好的跟踪精度，证明了该方法在静态与动态环境之间过渡的有效性，并有望提升人机协作的性能。

## I. 引言

人机协作是一个快速发展的领域，它彻底改变了人类与机器人交互和协作的方式。人机协作中的一个关键要素是机器人理解和响应人体运动意图的能力 [1]。通过准确且连续地感知人体运动意图，机器人可以与人类实现无缝协作。与人类并肩工作的机器人能够利用人类指导者的技能，从而提高灵活性、安全性和生产力 [2]。人机协作的潜力和重要性使其在制造业 [2]、假肢技术 [3]、辅助技术 [4] 以及康复领域 [5]、[6] 等多个领域得到了广泛应用。

由肌肉细胞产生的肌电（Electromyography, EMG）信号与人体运动意图相关，因此可应用于上述人机协作系统中 [2]、[3]、[7]、[8]。在过去的几十年中，EMG 与人体运动/力之间的关系得到了深入探索。许多研究人员专注于利用 EMG 模式识别技术进行离散运动控制，例如支持向量机（Support Vector Machine, SVM）[9]、线性判别分析（Linear Discriminant Analysis, LDA）[10] 和深度学习（Deep Learning, DL）[11]。连续运动控制是肌电控制中的另一个研究热点 [1]。基于 Hill 的肌骨模型已被广泛应用于机器人控制中，以利用 EMG 信号连续获取人体运动意图 [12]、[13]。然而，该模型实际上局限于低维力或关节力矩的估计 [14]，并且由于涉及运动的复杂性，在估计复杂的上肢三维末端力时面临挑战 [15]、[16]。先前的研究探讨了使用线性状态空间模型（State Space Model, SSM）连续估计上肢三维末端力作为上肢康复机器人输入的可行性，并完成了如伸手抓取等简单的人机协作任务 [17]。

为了在更复杂的人机协作任务中实现肌电控制，研究人员探索了具有非线性拟合能力的方法。Aung 和 Al-Jumaily 建立了反向传播神经网络（BPNN），利用 EMG 信号预测上肢关节角度 [18]。Zhang 等人训练了一个人工神经网络（ANN）来构建 EMG 到关节角度的模型 [19]。Ding 等人提出了一种非线性状态空间模型来描述 EMG 与关节角速度之间的关系，其中状态模型为自回归网络，测量模型为 BPNN [16]。近年来，深度学习（DL）由于在处理复杂非线性问题方面的优越性以及相比传统机器学习方法更好的泛化能力而受到越来越多的关注 [20]。Nahid 等人采用 AlexNet 对手势进行分类，并将其应用于假肢手 [11]。Ozdemir 等人研究了几种深度网络，发现 ResNet-50 取得了最高的精度 [21]。Nasr 等人探索了包括 CNN、RNN、ANN 和 RCNN 在内的深度网络，用于映射 EMG 与关节角度、速度、加速度和扭矩之间的关系 [22]。长短期记忆网络（LSTM）利用隐藏状态和记忆状态分别形成短期和长期记忆 [23]，因此 LSTM 可能是处理诸如 EMG 这类序列数据的潜在模型 [24]。在我们之前的会议论文中，建立了一种基于深度 LSTM 网络（DLN）的 EMG 到三维力模型，且该模型仅使用静态测量数据进行训练 [25]。然而，当将其应用于人机协作系统以跟踪参考轨迹时，尽管在静态测量数据集上的估计精度足够高，但在动态环境中观察到了不可忽略的跟踪误差。这一现象表明，仅使用静态测量数据训练的模型无法有效适应在线动态环境。

尽管肌电控制领域已经取得了进展，但现有的非线性肌电信号到三维力（EMG-to-3-D-force）研究通常是在静态固定姿态约束下 [25], [26], [27], [28] 或未与机器人交互的离线数据集 [16], [18], [19], [22] 上进行标定/训练的，这在应用于人机耦合系统中的动态在线环境时可能会导致性能欠佳。本研究提出了一种动静态标定方法，该方法首先利用静态测量数据训练基于 DLN 的三维末端力估计模型，然后利用动态数据更新网络。将训练/更新后的 DLN 模型与导纳控制器相结合，为上肢绳驱动机器人（UL-CDR）生成期望轨迹。通过采用多速率并行计算方案，将整体控制方案构建在名为 dSpace 的机器人控制平台中，从而最大化了系统的高频实时性能。研究招募了三名受试者，通过其肌电信号控制 UL-CDR 来跟踪矩形和圆形轨迹。将所提方法的跟踪误差与在动态环境中未更新 DLN 模型的方法进行了对比。我们假设，经过动静态标定的 DLN 能够适应从静态到动态环境的过渡，并获得比仅进行静态标定更好的轨迹跟踪性能。

本文的主要创新点在于：1）构建了 DLN 网络以拟合 EMG、关节角度和三维力之间的关系，并将其嵌入硬件中以实现人机协作中的高频实时肌电控制；2）证明了使用静态数据集训练 DLN 无法完美应用于动态人机交互，而解决这一问题需要所提出的动静态标定方法。

## II. 基于 DLN 控制器的 UL-CDR

实验原型如图 1 所示。该 UL-CDR 包括四台电机（DM1B045G，Yokogawa）、四根线缆、一个带有六维力传感器（D45MM-F400N，Sunrise Instruments）的末端执行器（EE）、一个配备四个摄像头的动作捕捉系统（OptiTrack2，Natural-Point）、一个实时平台（RTI1202，dSpace，搭载 2 GHz Qorl0 P5020 处理器），以及一个为轨迹跟踪提供视觉反馈的屏幕。与受试者手部进行交互的末端执行器由四根线缆驱动，每根线缆由一台电机驱动。肘部、肩部和末端执行器上固定有五个光学标记点。动作捕捉系统用于获取光学标记点的实时位置。

UL-CDR 控制框图如图 2 所示。构建了一个深度学习网络（DLN），根据八通道肌肉激活度和三个关节角信息来估计人体三维自主施力 $F _ { h }$。导纳滤波器基于 $F _ { h }$ 为末端执行器生成初步期望位置 $P _ { d }$。出于安全考虑，设计了一个工作空间限制模块来约束 $P _ { d } ,$ ，形成作为期望位置的 $\boldsymbol { P } _ { d } ^ { * }$。采用线缆轨迹规划器将任务空间中的 $\boldsymbol { P } _ { d } ^ { * }$ 转换为关节空间中四根线缆的期望长度向量 $P _ { l d }$。PID 控制器与线缆张力控制器共同决定四台电机的控制信号，驱动末端执行器跟踪期望位置 $\boldsymbol { P } _ { d } ^ { * }$。整个控制系统以多速率并行计算模式运行，从而最大化高频实时性能。肌肉激活度计算、PID 控制器和线缆张力控制器的工作控制频率为 1000 Hz，而其他组件（如计算密集型的 DLN）则在 100 Hz 下运行。

## A. 肌肉激活度计算

每个选定肌肉的表面肌电（sEMG）信号[如图 1(b) 所示]通过 Ag-AgCl 电极采集，电极按照 SENIAM [29], [30] 的建议贴附在皮肤表面。肌电信号的采样频率为 1 kHz。随后，肌电信号通过放大器放大 5000 倍，该放大器还内置了一个陷波滤波器（50 Hz）和一个带通滤波器（20–450 Hz）。滤波后的信号经过全波整流，并由截止频率为 4 Hz 的四阶低通巴特沃斯滤波器进行处理 [14]（上述 sEMG 处理的功能可参见 [31]）。对于第 $k$ 块 $( k = 1 , 2 , \ldots , 8 )$ 肌肉，处理后的信号随后采用最大自主等长收缩（MVC）方法归一化为 $X _ { k }$ [32], [33]。接着，根据二阶线性模型获得神经激活度 $N _ { k }$

$$
N _ {k} (t) = \alpha X _ {k} (t - t _ {d}) - \beta_ {1} N _ {k} (t - 1) - \beta_ {2} N _ {k} (t - 2)\tag{1}
$$

其中 $\beta _ { 1 } = - 0 . 0 5 2 0 , \beta _ { 2 } = 0 . 0 0 0 6 , \alpha = 0 . 9 4 8 6$ ，机电时间延迟 $t _ { d } = 1 0 0$ 均根据先前的研究 [17] 确定。

最后，肌肉激活度 $a _ { k } ( t )$ 根据以下模型 [34] 计算：

$$
a _ {k} (t) = \left\{ \begin{array}{l l} \tau \mathrm{ln} (\omega N _ {k} (t) + 1), & 0 \leq N _ {k} (t) <   N _ {0} \\ \varphi N _ {k} (t) + \delta , & N _ {0} \leq N _ {k} (t) \leq 1 \end{array} \right.\tag{2}
$$

其中 $\tau = 0 . 2 8 8 2 , \omega = 1 0 . 4 7 6 0 , \varphi = 0 . 8 3 9 1 , \delta = 0 . 1 6 0 9$ ，以及 $N _ { 0 } = 0 . 2 4 8 0$ 是通过带 Newton–Raphson 方法的单参数方法获得的 [17], [34]。

## B. 关节角度计算

五个光学标记点固定在上肢皮肤和末端执行器（EE）上。两个标记点贴在肘部 $( E ( x _ { E } , y _ { E } , z _ { E } ) )$ 和肩部 $( S ( x _ { S } , y _ { S } , z _ { S } ) )$ ，而另外三个标记点固定在 EE 上。EE 上标记点的中心位置代表受试者手部的位置 $( H ( x _ { H } , y _ { H } , z _ { H } ) )$ ，这也代表了 EE 的位置。这些位置可用于计算以下关节角度：

$$
\theta_ {\mathrm {S\_ {E} F}} = \arctan 2 (z _ {S} - z _ {E}, y _ {S} - y _ {E}).\tag{3}
$$

$$
\theta_ {S \_ A A} = \arctan 2 (x _ {S} - x _ {E}, y _ {S} - y _ {E}).\tag{4}
$$

$$
\theta_ {\mathrm {E\_EF}} = \arccos \left(\frac {H E ^ {2} + E S ^ {2} - H S ^ {2}}{2 H E E S}\right).\tag{5}
$$

其中 $\theta _ { \mathrm { S \_ E F } } , \quad \theta _ { S \_ A A }$ 和 $\theta _ { \mathrm { E } \_ \mathrm { E F } }$ 分别表示肩关节屈伸角、肩关节外展-内收角和肘关节屈伸角；k∙k 表示欧氏距离。

## C. DLN

在时间 $t$ ，DLN 的输入向量 $U ( t )$ 包含三个关节角度和八通道肌肉激活度，而输出向量 $F _ { h } ( t )$ 为估计的手部三维自主末端力

$$
\boldsymbol {U} (t) = [ \theta_ {\mathrm {S\_ {E} F}} (t); \theta_ {S \_ {A} A} (t); \theta_ {\mathrm {E\_ {E} F}} (t); a _ {1} (t);...; a _ {8} (t) ]\tag{6}
$$

$$
\boldsymbol {F} _ {h} (t) = \left[ F _ {h \_ x} (t); F _ {h \_ y} (t); F _ {h \_ z} (t) \right].\tag{7}
$$

DLN 原理图如图 3 所示。为了处理十一维序列输入 U，采用了一个序列输入层。随后级联了三层 LSTM。每个 LSTM 层后接一个丢弃概率为 0.50 的 dropout 层。接着是一个包含 200 个神经元的全连接层。之后，应用一个回归层来输出估计的三维力 $F _ { h } .$。对于每个 LSTM 层，构建了 200 个单元。每个单元由一个输入门 $i ,$、一个遗忘门 $f ,$、一个候选值 ${ \tilde { c } } _ { \cdot }$、一个记忆状态 $^ { c , }$、一个输出门 $^ { \bullet , }$ 以及一个隐藏状态 H 组成，如下所示：

$$
\boldsymbol {i} (t) = \sigma (\boldsymbol {Q} _ {i} \boldsymbol {U} (t) + \boldsymbol {R} _ {i} \boldsymbol {H} (t - 1) + \varepsilon_ {i})\tag{8}
$$

![](images/8d9e123ae6e08017029fc5e3329d71d9c5d0335a1ed652c32e98fc22570514e0.jpg)  
Fig. 3. DLN 架构。

$$
\boldsymbol {f} (t) = \sigma (\boldsymbol {Q} _ {f} \boldsymbol {U} (t) + \boldsymbol {R} _ {f} \boldsymbol {H} (t - 1) + \boldsymbol {\varepsilon} _ {f})\tag{9}
$$

$$
\tilde {\boldsymbol {C}} (t) = \operatorname{Tanh} \left(\boldsymbol {Q} _ {\tilde {\boldsymbol {C}}} \boldsymbol {U} (t) + \boldsymbol {R} _ {\tilde {\boldsymbol {C}}} \boldsymbol {H} (t - 1) + \varepsilon_ {\tilde {\boldsymbol {C}}}\right)\tag{10}
$$

$$
\boldsymbol {C} (t) = \boldsymbol {f} (t) \odot \boldsymbol {C} (t - 1) + \boldsymbol {i} (t) \odot \tilde {\boldsymbol {C}} (t)\tag{11}
$$

$$
\boldsymbol {o} (t) = \sigma (\boldsymbol {Q} _ {o} \boldsymbol {U} (t) + \boldsymbol {R} _ {o} \boldsymbol {H} (t - 1) + \boldsymbol {\varepsilon} _ {o})\tag{12}
$$

$$
\boldsymbol {H} (t) = \boldsymbol {o} (t) \odot \operatorname{Tanh} (\boldsymbol {C} (t))\tag{13}
$$

式中，$Q _ { i } , Q _ { f } , Q _ { \tilde { C } } , Q _ { o } , R _ { i } , R _ { f } , R _ { \tilde { C } }$ 和 $\pmb { R } _ { o }$ 为权重矩阵，$\varepsilon _ { i } , ~ \varepsilon _ { f } , ~ \varepsilon _ { \tilde { C } }$ 和 $\pmb { \varepsilon } _ { o }$ 为偏置。DLN 的详细参数见 Table I。

## D. 导纳滤波器

采用导纳滤波器根据 DLN 的输出（即估计力 $F _ { h }$）生成 EE 的初步期望位置 $P _ { d }$：

$$
\boldsymbol {P} _ {d} = \boldsymbol {P} + \boldsymbol {F} _ {h} (K + B s + M s ^ {2}) ^ {- 1}\tag{14}
$$

式中，P 为通过四个相机实时测得的实际位置；s 为拉普拉斯算子（Laplacian operator）；K、B 和 M 分别为刚度、阻尼和质量参数。

其中 x<sub>l ¼</sub> 0, y<sub>l ¼</sub> 0:99 m, $z _ { l } = - 0 . 7 6$ m, $r = 0 . 2 5$ m，且 distanceð<sub> </sub>, <sub> </sub>Þ 表示两点之间的欧几里得距离。

当超出 A 的范围时，期望位置 $P _ { d } ^ { * }$ 等于同一时刻的实际位置，否则等于导纳滤波器输出的初步期望位置 $P _ { d }$

$$
\boldsymbol {P} _ {d} ^ {*} = \left\{ \begin{array}{c} P, \boldsymbol {P} _ {d} \notin A \\ \boldsymbol {P} _ {d}, \text { otherwise. } \end{array} \right.\tag{16}
$$

## F. 绳索轨迹规划器

为了将任务空间中的期望位置转换为关节空间中上层三根绳索的期望长度，采用了绳索轨迹规划器

$$
\boldsymbol {P} _ {l d} = \left[ P _ {l d \_ 1}, P _ {l d \_ 2}, P _ {l d \_ 3} \right] ^ {T}\tag{17}
$$

$$
P _ {l d \_ j} = \text { distance } ((P _ {d \_ x} ^ {*}, P _ {d \_ y} ^ {*}, P _ {d \_ z} ^ {*}), (c _ {j \_ x}, c _ {j \_ y}, c _ {j \_ z}))\tag{18}
$$

其中 $( c _ { j \_ x } , \ c _ { j \_ y } , \ c _ { j \_ z } )$ 为第 $j$ 个滑轮的位置（参见 $[ 1 7 ]$）；$P _ { d _ { - } x } ^ { * } , P _ { d _ { - } y } ^ { * } ,$ 和 $P _ { d _ { - } } ^ { * }$ z 分别表示 $\pmb { P } _ { d } ^ { * }$ 的 $x , y ,$ 和 $z$ 分量。

## G. PID 控制器

上方三根绳索的驱动力通过 PID 控制器确定

$$
\boldsymbol {F} _ {l} = k _ {P} \left(\boldsymbol {P} _ {l d} - \boldsymbol {P} _ {l}\right) + k _ {I} \int_ {1} ^ {t} \left(\boldsymbol {P} _ {l d} - \boldsymbol {P} _ {l}\right) d t + k _ {D} \frac {d \left(\boldsymbol {P} _ {l d} - \boldsymbol {P} _ {l}\right)}{d t}\tag{19}
$$

其中 $F _ { l } = [ F _ { l 1 } , \ F _ { l 2 } , \ F _ { l 3 } ] ^ { T }$ 为驱动力向量；$k _ { P } , k _ { I }$ 和 $k _ { D }$ 为 PID 系数；$P _ { l }$ 表示三根绳索的实际长度。

## III. 静态-动态标定方法

所提出的静态-动态标定方法算法（如图 4 所示）包括静态标定步骤（DLN 训练）、动态标定步骤（DLN 更新）以及动态验证步骤。

## A. 静态标定

在静态标定步骤中，每位受试者需要在 21 次试验中向 EE（末端执行器）沿六个随机方向施加主动力。每次试验的持续时间约为 15 s。在此步骤中，UL-CDR 的电机被锁定（无法移动），从而使受试者的肢体姿态保持固定。集成在 EE 中的六轴力传感器测量并记录了机器人与受试者手部之间的静态交互力。在静态阶段，测得的交互力等于受试者施加的主动力。交互力和标记点位置的记录采样率为 100 Hz，而 EMG 信号的采样率为 1000 Hz。为防止混叠，使用 EMG 信号计算出的肌肉激活度被降采样至 100 Hz，以匹配其他信号的频率。在静态标定数据集中，输入数据 U [通过 (1)–(6) 获得] 包含肌肉激活度和关节角度信号，而输出数据 $F _ { h }$ 由三维交互力的三个分量组成（由力传感器记录，在静态阶段可视为主动力）。在 21 次试验中，9 次分配给训练集，3 次用作验证集，其余 9 次分配给测试集。来自训练集的数据用于 DLN 训练。(8)–(13) 中的网络偏置和权重矩阵采用随机数进行初始化。[36] 中描述的 ADAM 算法被选用于网络训练，参数如 Table II 的第二列所示。为了防止过拟合，我们监测验证损失，并在验证损失开始上升之前停止训练（称为早停策略）。随后，训练好的 DLN 被整合到系统中，用于在线 UL-CDR 控制。

## B. 动态校准

在动态校准步骤中，三名受试者分别与末端执行器（EE）进行交互。EE 通过受试者的肌电（EMG）信号进行控制，并在屏幕视觉反馈下跟踪形状为 $0.25 \times 0.25\text{ m}$ 矩形的参考轨迹，共进行 13 次试验 [Fig. 1(c)]。每次试验的平均持续时间约为 46 s。在该步骤中，UL-CDR 为受试者提供运动助力（称为动态环境）。系统记录了 EMG 信号、标记点位置以及 EE 与受试者手部之间的动态交互力。值得注意的是，力传感器的反馈信号在后续用于校准深度学习网络（DLN），而非控制机器人。在这 13 次试验中，7 次用作 DLN 更新的训练集，3 次分配给验证集，其余分配给测试集。输入数据仍为关节角度和肌肉激活度，而输出数据则改为估计力与动态交互力的合力（即矢量和）(Fig. 4, line 18)。式 (8)–(13) 中的初始偏置和权重矩阵设置为前一步骤中预训练 DLN 的参数。再次采用 ADAM 算法来更新 DLN。更新/重训练过程的参数如 Table II 第二列所示。该过程中同样采用了早停（early stopping）策略。随后，更新后的 DLN 被重新嵌入系统中以替代预训练的 DLN，用于动态验证。

## C. 动态验证

在动态验证步骤中，对每位受试者进行了两组实验（具有静态-动态校准的 DLN 与仅具有静态校准的 DLN）。受试者与末端执行器（EE）进行交互，EE 通过受试者的肌电（EMG）信号进行控制，以便在视觉反馈下跟踪两种参考轨迹 [图 1(c)]。对于受试者 1（subject1），两组实验各进行了 40 次（20 次用于 $0 . 2 5 \times 0 . 2 5$ m 矩形形状的参考轨迹，20 次用于直径为 0.3 m 的圆形形状的参考轨迹，每次试验平均大约 43 s），用于对比和统计分析。对于受试者 2（subject2）和受试者 3（subject3），两组实验各仅进行了 20 次（矩形形状参考轨迹 10 次，圆形形状参考轨迹 10 次）。这是因为他们要求实验不要进行太长时间，我们尊重了他们的要求。

## IV. 信号处理与分析

采用估计的三维末端力的均方根误差（RMSE）来评估 EMG 到三维力模型的估计精度

$$
F _ {\text { err } \_ j} = \sqrt {\frac {1}{T} \int_ {0} ^ {T} (F _ {h \_ \text { estimate } \_ j} - F _ {h \_ \text { actual } \_ j}) ^ {2}}\tag{21}
$$

$$
F _ {\text { err } \_ 3 D} = \sqrt {\frac {1}{T} \int_ {0} ^ {T} \| \boldsymbol {F} _ {h \_ \text { estimate }} - \boldsymbol {F} _ {h \_ \text { actual }} \| ^ {2}}\tag{22}
$$

其中 $j { = } 1 , 2 ,$ 和 3 代表 $\mathbf { X } , \ \mathbf { y } ;$ 和 z 轴的数据；T 是数据集的持续时间。

位置跟踪的 RMSE 和 RMSE 相对误差 $( \mathrm { R E _ { R M S E } } )$ 也被用来评估模型的精度和跟踪性能

$$
P _ {\text { RMSE } \_ j} = \sqrt {\frac {1}{T} \int_ {0} ^ {T} (P _ {\text { Reference } \_ j} - P _ {\text { actual } \_ j}) ^ {2}}\tag{23}
$$

$$
P _ {\text { RMSE } \_ 3 D} = \sqrt {\frac {1}{T} \int_ {0} ^ {T} \| P _ {\text { Reference }} - P _ {\text { actual }} \| ^ {2}}\tag{24}
$$

$$
P _ {\mathrm {RE\_RMSE\_j}} = \frac {P _ {\mathrm {RMSE\_j}}}{D _ {\text { Reference }}}\tag{25}
$$

其中 $D _ { \mathrm { R e f e r e n c e } }$ 是矩形/圆形参考轨迹的边长/直径。

使用 SPSS 26 软件进行配对 t 检验（paired t-tests），以检验两组实验（采用静态-动态标定的 DLN 与仅采用静态标定的 DLN）之间位置跟踪的 RMSE 和 MRE 差异。

## VI. 讨论

所提出的结合静态-动态校准方法的 DLN 不仅可以通过将关节角度作为输入来消除关节角度与人体主动力耦合效应的影响，还可以通过二次校准来补偿人机耦合系统不确定动力学特性的影响。交互力仅在静态情况下等于人体主动力。然而，在动态人机协作环境中，人体主动力并不等于动态交互力，而是机器人助力与所测得交互力的矢量和 [Fig. 8(c) 与 8(d)]。在动态校准步骤中，利用测得的动态交互力与先前的估计力的矢量和来校正从原始 DLN 模型获得的估计力，进而更新数据集以进行二次校准。还有其他一些研究试图解决 EMG-to-force（肌电-力）建模问题，其中考虑了可变关节角度的影响。Guoxin 等人通过在三维空间的 72 个位置测量沿六个方向的等长力，考虑了上肢姿势对肌电-力的影响 [37]。该方法需要耗时的过程来收集数据集（$6 \times 72 = 432$ 次测量）。与 [37] 相比，我们提出的方法更为便捷，因为利用动态交互力和估计力进行二次校准即可轻松更新 DLN。Pesenti 等人使用线性参数变化模型估计一维力，其中参数在变化的肘关节角度下进行辨识 [38]。然而，由于上肢神经肌肉骨骼系统中存在复杂的非线性特性，线性模型可能无法准确估计三维主动力。与 [38] 相比，所提出的 DLN 更适合复杂的非线性拟合，尤其是三维上肢运动解码。还有研究探讨了基于网络的非线性模型，如 CNN [22]、ANN [19]、BPNN [18]、RNN [22]、带有 BPNN 的自回归网络 [16] 以及 RCNN [22]，用于运动意图估计并在离线数据集中测试其模型。在本研究中，所提出的带有静态-动态校准方法的 DLN 被部署在机器人平台上用于实时肌电控制，其中融合了人机耦合系统的不确定动力学特性。

## VII. 结论

在本文中，提出了一种采用静态-动态标定方法的 DLN，用于为 UL-CDR 的控制系统建立非线性 EMG 到 3-D 力的映射模型。所提出的方法能够适应从静态测量数据到动态环境的变化，因此与仅进行静态标定的方法相比，在人机协作应用中获得了更高的估计精度。

采用静态-动态校准方法的 DLN 网络使机器人能够通过其 EMG 信号在线准确解码人体运动意图，具有在多个方面促进人机协作的潜力，包括：1）提高重物搬运、表面打磨和材料锯切等任务中的制造效率；2）辅助运动功能障碍人群，改善他们的生活质量并提升其能力；3）实现主动康复训练，鼓励中风后患者的主动参与。采用二次校准方法的 DLN 网络还可用于进一步解决跨受试者应用的问题。若将使用健康受试者数据训练的 DLN 网络进行再次微调校准，随后应用于中风后患者，这将是一个极具价值的研究方向。

Zhijun Li（IEEE 会士）于 2002 年在中国上海交通大学（Shanghai Jiao Tong University）获得机电一体化博士学位。

2003 年至 2006 年，他在日本东京电气通信大学（University of Electro-Communications）和新加坡国立大学（National University of Singapore）担任博士后研究员。目前，他是中国上海同济大学（Tongji University）的讲席教授，并自 2024 年起担任机械与能源工程学院院长。

Li 博士已发表论文 400 余篇，其中著名的贡献在于穿戴式机器人和生物机电一体化系统。他曾获选 IEEE 机器人与自动化学会杰出讲师（Distinguished Lecturer, RAS）、科睿唯安全球高被引科学家（Web of Science Highly Cited Researcher，2019–2023）、2018 年国家“万人计划”领军人才，以及 2016 年国家杰出青年科学基金获得者（NSFC）。他是 IEEE 和 AAIA（亚太人工智能学会）会士。他目前的研究兴趣包括穿戴式机器人、生物机电一体化系统和智能控制。

中国广东。他的研究兴趣包括肌肉骨骼建模、生物医学信号处理和康复机器人。
