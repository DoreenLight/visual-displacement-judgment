## 1. 骨段坐标系（§2.3.4 / §2.3.5 / §3.3.3 / §3.3.4 / §4.3.1 / §4.3.2）

| 坐标系 | 原点 | Y 轴 | X 轴 | Z 轴 |
|---|---|---|---|---|
| **肱骨 1st option** `X_h1 Y_h1 Z_h1`（§2.3.4） | 与 GH 同点 | 连接 GH 与 EL、EM 中点，**指向 GH** | 垂直于 EL、EM、GH 构成的平面，**指向前方** | 垂直于 `Y_h1` 与 `X_h1`，**指向右侧** |
| **肱骨 2nd option** `X_h2 Y_h2 Z_h2`（§2.3.5） | 与 GH 同点 | 连接 GH 与 EL、EM 中点，**指向 GH** | 垂直于 `Y_h2` 与前臂 `Y_f`（§2.3.6）构成的平面，**指向右侧** | 垂直于 `Z_h2` 与 `Y_h2`，**指向前方** |
| **尺骨（肘定义）** `X_u Y_u Z_u`（§3.3.3） | **US**（肘上尺神经沟） | 自 US 指向 **EM 与 EL 中点**的近侧直线 | 垂直于 US、EM、EL 构成的平面，**指向前方** | 垂直于 `X_u` 与 `Y_u`，**指向右侧** |
| **腕部桡骨** `X_r Y_r Z_r`（§4.3.1） | 桡骨远端（桡舟窝与桡月窝之间骨嵴水平）与桡骨近端（桡骨头凹陷水平）的**中点** | 自原点沿桡骨长轴，与该骨嵴相交 | 垂直于 `Y_r`，位于由**桡骨茎突尖、桡骨切迹底与原点**确定的平面 | 垂直于 `Y_r` 与 `Z_r` 的公共垂线 |
| **腕部尺骨** `X_u Y_u Z_u`（§4.3.2） | 尺骨头穹隆水平与冠突水平的**中点** | 自原点沿尺骨长轴，与尺骨头穹隆中心相交 | **前臂中立位时与 `X_r` 平行** | 垂直于 `X_u` 与 `Y_u` |

**2nd option 存在的理由（§2.3.4 注 1，原文要点）**：EL 与 EM 间距短，
用「连接 EL 与 EM 的方向」误差敏感度高，故提供由 `Y_h2` 与 `Y_f` 定义的替代方案。
§3.3.1 明确建议：**研究肘关节时用第二种定义**。

📌 **可计算性前提**：上表每一行都依赖**解剖标志点的三维位置**（GH、EL、EM、US、桡骨茎突、桡骨切迹、尺骨头穹隆、冠突）。
ViKiT 的输入是**图像**，不含这些标志点 —— **如何从图像得到这些点是 V6 未决的核心，不是抄录能解决的**（见 §5）。

## 2. 关节定义（可计算）

### 2.1 肩：盂肱关节 GH（§2.4.4，humerus 相对 scapula，**Y–X–Y 序**）

> 🚨 **原文明确警告**：GH 是**唯一**基于欧拉旋转序列的关节。
> 因 `e1` 与 `e3` **起始同向**，**Grood & Suntay 的浮动轴方程不适用**，必须用欧拉分解。

| 轴 | 定义 | 旋转变量 |
|---|---|---|
| `e1` | 固定于**肩胛**，与肩胛坐标系 `Y_s` 重合 | `γ_GH1` = **盂肱面 elevations 平面角**（plane of elevation） |
| `e2` | 固定于**肱骨**，与肱骨坐标系 `X_h` 重合 | `β_GH` = **盂肱抬高角**（elevation），**为负** |
| `e3` | 绕肱骨坐标系 **`Y_h` 轴**的轴向旋转 | `γ_GH2` = **盂肱轴向旋转**：内旋/endo 为**正**，外旋/exo 为**负** |

平移 `q`（GH 共同旋转中心相对肩胛坐标系的位移）：
`q_x` = 前=后方向平移；`q_y` = 下=上方向平移；`q_z` = 关节牵离（joint distraction）。

📌 **原文刻意不用「屈曲/外展」**：原文说明理由是「先屈曲后外展」与「先外展后屈曲」结果差异极大，
且这两个临床词只相对**胸廓**定义、不相对肩胛定义（见 §2.4.7 肱骨相对胸廓 Y–X–Y）。
为便于对照，原文给出：**屈曲 = 平行于矢状面的抬高；外展 = 冠状（额状）面内的抬高**。

### 2.2 肘

**肱尺关节（§3.4.2，ulna 相对 humerus，Z–X–Y 序）**

| 轴 | 定义 | 旋转变量 |
|---|---|---|
| `e1` | 固定于**近端段**，与肱骨坐标系 **`Z_h`** 重合（原文注：肘屈伸轴的近似） | `α_HF` = **屈曲为正、过伸为负** |
| `e2` | **浮动轴**，垂直于 `e1` 与 `e3`，即前臂坐标系旋转后的 `X_f` | `β_HF` = **携带角**（carrying angle） |
| `e3` | 固定于**远端段**，与前臂坐标系 **`Y_f`** 重合 | `γ_HF` = 前臂轴向旋转：**旋前为正、旋后为负** |

📌 `β_HF` 携带角的成因（§3.4.2 原文）：肱骨屈伸轴在肱尺关节处的**倾斜**，
**加上**尺骨自身的**成角**，两者共同产生（原文引 Anglin & Wyss 2000）。

**桡尺关节（§3.4.3，radius 相对 ulna，X–Z–Y 序）**

| 轴 | 定义 | 旋转变量 |
|---|---|---|
| `e1` | 固定于**近端段**，与尺骨坐标系 **`X_u`** 重合 | `β_UR` = 旋前/旋后轴相对尺骨的方位（**常量**） |
| `e2` | 垂直于 `e1` 与 `e3` 的公共轴，即桡骨坐标系旋转后的 `Z_r` | — |
| `e3` | 固定于**远端段**，与桡骨坐标系 **`Y_r`** 重合 | `γ_UR` = **桡骨相对尺骨的旋前旋后** |

📌 原文的隐含假设（照录）：**假定旋前/旋后轴与肘屈伸轴相交**，原文自陈「实际上并非如此」。

### 2.3 腕（§4.4.1 / §4.4.2）

**通用关节定义（§4.4.1）**，适用于指间、掌指、腕骨间、**桡腕**、腕掌关节：

| 轴 | 定义 | 旋转变量 | 平移 |
|---|---|---|---|
| `e1` | 固定于**近端段**，与近端段坐标系 `Z` 轴重合 | `α` = **屈曲为正的屈伸** | `q1` = 桡向=尺向平移 |
| `e2` | 垂直于 `e1`、`e3` 的公共轴 | `β` = 内收=外展，或**桡偏=尺偏（尺偏为正）** | `q2` = 背侧=掌侧平移 |
| `e3` | 固定于**远端段**，与远端段坐标系 `Y` 轴重合 | `γ` = 旋转（旋前—旋后）；**中立前臂位为 0°，旋前为正、旋后为负** | `q3` = 近端=远端平移 |

**中立位定义（§4.4.1 原文）**：指间、第一掌指、腕骨间、桡腕关节的中立位 =
**近端与远端两段坐标系朝向一致**。

**腕部桡尺关节（§4.4.2）** —— 这是**前臂旋前旋后在腕水平**的定义，与 §3.4.3 的肘水平**不是同一个量**：

- 原文先指出：桡骨与尺骨的 `Y` 轴在**中立位可能并不平行**，因人而异地发散**数度**。
- **中立前臂旋转**的临床定义：**肘屈 90° 时拇指指向肩**；标准解剖位下桡骨相对尺骨是**旋后**的。
- 本标准提出一个**中间（intermediate）桡骨坐标系**：原点与腕部桡骨坐标系**同点**，
  朝向在**中立前臂旋转位**时与**尺骨坐标系对齐**。
- 桡骨相对尺骨的运动用**同一个 `α/β/γ` 定义**，但作用在「中间桡骨坐标系 vs 尺骨坐标系」上：

| 轴 | 定义 | 旋转变量 |
|---|---|---|
| `e1` | 固定于**尺骨**，与**中间桡骨**坐标系的 `Y` 轴重合 | `α` = 旋后/旋前，**旋前为正** |
| `e3` | 固定于**中间桡骨**，与其 `Z` 轴重合 | `γ` = 屈伸，**屈曲为正** |

📌 **原文要求使用者自行定义中间坐标系相对解剖桡骨坐标系的朝向** —— 即这一环**标准没有钉死**。

## 3. 可执行形式（伪代码）

```text
# 输入：各解剖标志点的三维坐标 P (单位 m)；ISB 标志点见 §1
# 输出：θ_shoulder(4) / θ_elbow(3) / θ_wrist(3)，角度单位 rad 或 deg 需全局统一

segment_CS(P, kind):
    O, Y, X0 = 按 §1 表取原点、Y 轴方向、用于定 X 的第二参考点
    Yh = normalize(Y)                         # 近端指向（或按表反向）
    Xh = normalize(X0 - (X0 · Yh) Yh)         # 正交化到 Y 的正交补
    Zh = cross(Xh, Yh)                        # 或按表指定手性
    return R = [Xh Yh Zh]                     # 3×3，列向量为基

# 关节角：Grood-Suntay 浮动轴（θ、ψ、r）
gs_cardan(R_prox, R_dist, e1_ref, e3_ref):
    # ⚠️ GH 不适用本式（§2.4.4），必须走欧拉分支
    ...

# 肩：Y–X–Y 欧拉（§2.4.4）
gh_euler_xyz(R_scapula, R_humerus):
    assert angle(R_scapula @ Ŷs, R_humerus @ Ŷh) 同向起始   # 原文前提
    γ1 = 盂肱面 elevations 平面角
    β  = 盂肱抬高角（负）
    γ2 = 盂肱轴向旋转（内正外负）
    return γ1, β, γ2, q=(qx, qy, qz)
```

🚨 **实现侧必须注意的三点（均为原文约束，不是工程建议）**：

1. **GH 与肘的分解方式不同** —— GH 用欧拉、肘用浮动轴。用错会让肩的角度出现万向锁附近的跳变。
2. **`β_GH` 与 `β_HF` 的符号约定与直觉相反** —— 两者都是「负为抬高/正为携带角」，
   但成因完全不同（前者是分解约定，后者是解剖成角），**不可合并解释**。
3. **腕水平与肘水平的旋前旋后是两个不同的量**（§3.4.3 vs §4.4.2），
   且腕水平依赖**使用者自定义**的中间坐标系朝向。**把它们当成同一个「前臂旋转角」会引入系统偏差。**
