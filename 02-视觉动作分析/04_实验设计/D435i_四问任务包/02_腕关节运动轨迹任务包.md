# 任务包02：腕关节位置与角度轨迹获取

> **对应问题**：是否能够获得腕关节运动轨迹？
> **本包要给出的答案**：分别回答腕/手参考点位置轨迹与腕关节屈伸、桡偏/尺偏角度轨迹的连续性、准确性和适用边界。
> **当前状态**：任务定义完成，程序与人体实验未执行。
> **共享合同**：[总入口](README.md)；[总任务书](RealSense_D435i_腕关节康复人体运动状态感知测试任务书.md)。

## 1. 目标与非目标

### 目标

- 输出腕部与明确定义的手部参考点三维位置轨迹。
- 建立手部相对前臂的姿态，输出有正负号、明确零位和轴定义的FE/RU角度轨迹。
- 完成屈伸、桡偏/尺偏和二维周期运动的采集、分段、计数与独立误差验证。
- 明确点位获取成功但角度不可观测时的部分交付状态。

### 非目标

不以腕部单点位移代表腕ROM，不以肘到腕的前臂长度作为腕屈伸转动半径；不把机器人编码器天然视为人体真值；不负责肩肘代偿分类、主动发力判断或机器人闭环。

## 3. 测量对象与实施步骤

### W1：三类轨迹分别保存

| 轨迹 | 表示 | 解释边界 |
|---|---|---|
| 腕点位轨迹 | `P_w(t)` | 腕部点的空间移动，可能由肩肘带动 |
| 手部参考点轨迹 | `P_h(t)` | 明确的手背/掌部标记或模型点运动；记录来源类型 |
| 腕角度轨迹 | `q_w(t)=[theta_FE,theta_RU]` | 手相对前臂的运动，经解剖标定才能解释 |

纯腕屈伸时 `P_w` 可几乎不动；这不能判为未完成。肩肘带动 `P_w` 大幅移动，也不能判为腕活动度充分。

### W2：建立手部相对前臂姿态

1. 用手部非共线参考构建手部坐标系，用前臂参考构建前臂坐标系；遇到共线、遮挡或朝向翻转时判姿态无效。
2. 若使用标记簇，记录安装部位、长度与中立姿势，说明皮肤运动伪影；若使用模型，记录模型输出的来源和误差验证。
3. 定义旋转矩阵列向量和相机坐标约定。手/前臂姿态分别为 `R_h`、`R_f`，相对姿态为：

\[
R_{rel}=R_f^T R_h
\]

4. 通过冻结的解剖轴与角度分解约定得到FE/RU，规定中立位、左/右侧符号与角度单位。简单夹角不能直接区分有符号FE和RU。
5. 验证奇异姿态与跨角度边界，避免把坐标轴交换、180°翻转或姿态漂移解释成人体运动。
6. D435i内置IMU不测人体。外部佩戴传感器若获批准可作辅助，但须单独标定和同步；不得把接入相机内置IMU当作角度问题已解决。

### W3：时空参考比较

位置比较在同一坐标系中进行；角度比较使用相同自由度、零位、符号和单位。记录参考系统误差与同步残差。不能对每条测试轨迹事后任意平移时间、改变尺度或DTW对齐，再称原始测量准确。

## 4. 采集方案

先做单人连通性，再按执行前冻结的跨受试者、跨session规模正式评估；所有动作由安全范围约束。

| 动作 | 原任务的候选动作量 | 操作与记录 |
|---|---|---|
| A 屈伸FE | 约−30°～30°，10次 | 肩肘基本稳定；记录FE/RU、点位、参考及可见性 |
| B 桡偏/尺偏RU | 约−20°～20°，10次 | 检查RU及FE串扰，不以手部横移替代RU角度 |
| C 二维周期运动 | 顺时针10圈、逆时针10圈 | 执行前明确是FE/RU角度空间还是指定手部点的空间路径 |

每类至少3个重复试次；另测不同安全速度、重新摆位、握柄接触和可控遮挡。动作幅度不足或受试者不适时不强求范围，保存实际幅度与限制。

二维角度周期运动不保证腕部点画出正圆；如果采用空间圆周，必须写明被跟踪点、参考平面与目标路径。

## 5. 指标与交付物

指标分别计算，不合并为一个“轨迹准确率”：

- 三维点位RMSE/P95误差、有效率、最长连续缺失。
- FE/RU分别的MAE/RMSE、P95绝对角度误差、零位偏差、ROM差异。
- 循环计数误差、周期/幅度重复性、FE/RU串扰和相位差。
- 输入到输出延迟和参考时间同步误差。

| 编号 | 必需交付 |
|---|---|
| D1 | 手/前臂标定规程、姿态与有符号角度解算程序、环境及真实命令 |
| D2 | `wrist_kinematics.csv`，点位与角度独立有效性、run/config/标定哈希 |
| D3 | 三类动作原始/派生数据、独立参考、循环与轨迹对照；可公开图必须去标识化 |
| D4 | 角度/位置误差、动态缺失、速度/遮挡边界报告，及 `result.md` |
| D5 | 几何夹具、左右侧、单位、奇异姿态、丢点与时间对齐的正反测试 |

## 6. 验收与验证方式

以下为执行前冻结的候选工程目标，不代表现有系统已达到：

| 验收项 | 候选通过条件 | 证据 |
|---|---|---|
| 位置轨迹 | 与定义一致的独立参考3D RMSE≤10 mm | 已标定参考和逐点误差，不混用表面点与关节中心 |
| 腕角度 | FE/RU各自RMSE≤5°，绝对误差P95≤10°，ROM误差≤5° | 独立角度参考、零位/符号/同步说明 |
| 连续可用性 | 每种动作角度有效率≥95%，最大连续无效≤0.2 s | 原始有效性掩码；点位有效不能代替角度有效 |
| 计数 | 每10次/圈计数误差≤1；正反向不混淆 | 独立人工或参考计数 |
| 同步 | 参考映射残差P95≤半个实际RGB-D帧周期 | 时钟标定与残差；30 fps对应约16.7 ms |
| 几何正确性 | 合成夹具已知旋转/左右侧/角度边界均通过；无效输入不会产生伪角度 | 实际测试命令、输入哈希、输出和退出码 |

合成夹具标为 `fixture`；其正确性不代替人体误差验收。只有点位而没有可靠手/前臂姿态时，交付点位结果并将角度项记为 `BLOCKED`，不得对本问题给无条件通过结论。

## 7. 停止与降级条件

手部/前臂姿态不可观测、握柄持续遮挡、标定或参考缺失、参考与视觉不是同一自由度、同步不明、持续跳角或安全事件时停止相应测量。调整标记、布局、外部传感或参考系统必须先确认，不擅自扩大硬件方案。

## 8. 下游交接与完成标准

TP-03/TP-04获得具体run及哈希、有符号角度约定、位置/角度有效性、任务周期分段、参考误差与可支持工况。机器人侧 `q_r` 不自动与 `q_w` 等价；后续对齐由TP-04接口验证承担。

D1～D5齐全，各轨迹各动作的验收项均有 `PASS/FAIL/BLOCKED` 和复现命令，人工确认后才更新执行状态。建议工作量5～8个工作日，前提是上游、参考和采集授权就绪。
