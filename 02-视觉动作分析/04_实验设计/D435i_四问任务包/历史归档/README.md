## 已知历史错误

历史文件中的 `D450i` 是型号误写，现行在役机型为 **D435i**。原件名称和正文不修改，以免破坏版本证据。

旧论证或方案中的以下表述不得沿用：用相机内置 IMU 测人体腕部运动、把其他论文误差直接当作本机性能、以腕点移动代替腕活动度、把同单位 CI 位移比批判为必然量纲错误、笼统断言单相机只能二分类、把离线滤波等同无延迟实时滤波。

## 完整性与使用规则

- 三份原件从本次修改前的备份复制；归档后的 SHA-256 必须与备份记录逐字节一致。
- [原件哈希清单](原件哈希.sha256) 固定保存原始字节哈希，禁止重盖清单掩盖原件变化。
- 原件内相互链接指向本归档的同批历史文件，不代表现行入口。
- 新发现的问题补充在本说明或版本变更记录，不改写原件。

