# 任务包04：运动质量指标与后续康复控制接口

> **对应问题**：是否能够构建用于后续智能康复控制的人体运动质量评价指标？
> **本包要给出的答案**：能否用可靠的人体运动数据评价任务完成度、肩肘代偿、平滑性和数据质量，并提供可解释、可失效关闭的监督层输出。
> **当前状态**：任务定义完成，指标实现、人体效度验证和机器人闭环均未执行。
> **共享合同**：[总入口](README.md)；[总任务书](RealSense_D435i_腕关节康复人体运动状态感知测试任务书.md)。

## 1. 目标与非目标

### 目标

- 建立分项指标，而不是立即给出未经标定的“临床综合分数”。
- 先完成离线计算、重复性和独立判别效度，再用回放测试在线监督接口。
- 明确低幅度、静止、遮挡、低置信度、时间不同步时的不评分状态。
- 为后续与机器人编码器、六维力和P3位移对齐定义接口及安全前置条件。

### 非目标

本包不直接控制机器人，不批准患者实验，不判断主动发力或治疗效果，不将原CI作为自动增大辅助的依据；不以一个相关系数证明临床效度。

## 3. 指标字典与实施步骤

### Q1：定义四维评价向量

\[
M=[A,C,S,Q]
\]

A为任务完成度，C为肩肘代偿，S为平滑性/重复性，Q为数据可靠性。分项各自有有效状态；缺数据不是0分，也不是100分。

| 维度 | 首轮指标 | 必须说明 |
|---|---|---|
| A 完成度 | FE/RU ROM、目标范围覆盖、完成循环数、角度RMSE | 真正腕角度、目标范围与同一自由度的参考 |
| C 肩肘参与 | 肩/肘位移RMS/P95、额外肘屈伸、代偿持续比例 | 基线、任务允许范围和TP-03有效性 |
| S 平滑与一致 | 按子动作分段的SPARC、周期/幅度变异 | 分段、采样、滤波、速度信号定义与噪声影响 |
| Q 可靠性 | 真实有效比例、最长缺失、时空同步状态、输出延迟 | 不能用插值提高真实有效率 |

每项字典写明输入、公式、单位、方向、正常化方式、无效条件和适用动作。基于位置的指标与基于角度的指标分开，不能混写ROM。

### Q2：纠正原CI，不直接以它控制

历史式为：

\[
CI=(D_s+D_e)/(D_w+\epsilon)
\]

同单位且epsilon有长度单位时此式无量纲。主要缺陷是腕点在正常屈伸或周期终点可接近静止、肩肘代偿又会带动腕点，使比值不稳定或不随代偿单调变化。

首轮保留独立通道；如研究需要候选合成指标，可验证：

\[
C=\alpha r_s/d_s^{allow}+\beta r_e/d_e^{allow}
+\gamma r_{\theta_e}/\theta_e^{allow}
\]

其中r为有效训练片段相对稳定基线的RMS，允许范围是当前任务范围，不是肩/肘最大生理ROM。各项归一化后无量纲，权重须执行前冻结；检查肩部带动肘运动造成的冗余和重复计权。

该式不表示现成临床量表。完成度A必须独立满足最低活动要求；完全静止不能因C很低而得到“动作正确”的评价。

### Q3：可靠地评价平滑性

- 用可靠、统一采样后的有效速度或角速度信号计算；冻结方法和参数。
- 对FE/RU往返运动划分子动作，避免把正常反向转换的速度零点一律视为病理停顿。
- 研究SPARC，同时用可控噪声与不同速度检验稳定性。位置三阶导数jerk对噪声敏感，不直接对原始抖动轨迹计算后解释为人体不平滑。
- 离线零相位结果和在线因果结果分别验证；未来帧信息不能用于声称当前实时性能。
- Pearson/PCA/DTW可分析协同，但不直接转成代偿因果或临床等级。

## 4. 离线效度与重复性实验

1. 使用上游已冻结的独立数据：正常、肩参与、肘参与、共同参与；另包括静止/未完成、低幅度、遮挡和异常轨迹。
2. 检查完成度与代偿两个通道：正常完成且低代偿应区别于“不动但低代偿”和“大幅肩肘带动”。
3. 固定任务幅度/时长的夹具中检验更明显的参与、停顿或路径偏差能否被相应指标反映；不能让其他维度变化替代验证。
4. 同一人跨次测试、重新摆位后报告test-retest、ICC/SEM或适当的重复性指标和置信区间。不得由高相关推断低绝对误差。
5. 若提出总分/临床意义，另需患者、治疗师及临床量表的独立研究；本包工程初验不自动覆盖。

## 5. 监督层接口与机器人后续边界

### Q4：先回放，不直接驱动执行器

`quality.csv`或接口输出包括：时间/窗口、A/C/S/Q、各自有效性、肩肘状态、`unknown`/`not_completed`/`not_scorable`原因、参数版本和输出延迟。

事件只能用于离线记录或经授权的提示。低质量、无效和丢帧时应输出不评分状态；需要用定时检查处理“完全不来新帧”，不能永久保持上一帧的好成绩。

### Q5：定义人机误差，但先确认同一测量量

\[
e_q=q_h-q_r
\]

仅在人体和机器人使用相同自由度、角度单位、零位、符号与时钟映射时成立。电机角度不必等于人体关节角度，必须通过机构映射/标定验证。位置比较需要相机到机器人坐标变换，不能拿位置减角度。

六维力、P3位移分别保留原定义和同步精度；视觉轨迹不能单独说明患者主动发力。没有机器人数据时，接口规范与回放可交付，实际人机一致性项记为 `BLOCKED`。

闭环准入还需要独立的力/速度/范围限制、传感失效策略、治疗师批准与安全验收，另行授权，不属于本次四问文档更新或本包的自动执行许可。

## 7. 验收与验证方式

候选工程目标须执行前冻结；与临床效力或闭环安全分开：

| 验收项 | 候选通过条件 | 证据 |
|---|---|---|
| 指标可解释 | 全部指标有输入/公式/单位/无效条件，位置与角度不混用 | 指标字典、程序与抽样重算 |
| 数据可追溯 | 每项值可追溯到具体run、有效片段及上游版本 | 哈希、时间/窗口关联和复跑 |
| 判别力 | 候选代偿指标在独立数据上正常vs代偿AUC≥0.85，分类型报告 | 独立标签、完整样本与置信区间；不在测试集调权重 |
| 不误奖励静止 | 静止或未完成输出 `not_completed`，不能因低代偿给高质量 | 负向测试真实输出 |
| 数据质量门控 | 评分窗真实有效率≥95%、无连续缺失>0.2 s；不满足则不评分 | 全窗口有效性和超时测试，未评分覆盖率也报告 |
| 在线监督延迟 | 能完成时钟映射时采集到输出延迟P95≤200 ms | 同时钟域采集/输出证据；只测接收到输出时不宣称端到端通过 |
| 重复性 | 跨次重复性及置信区间已报告，适用限制明确 | 原始重复试次；不能以无统计依据的“稳定”代替 |
| 安全边界 | 回放/提示无机器人执行器命令；无效输入不触发增加辅助建议 | 接口检查、失效测试及记录 |

关键测试至少包括：正常完成、肩肘明显参与、完全静止、低幅度未完成、深度缺失、姿态跳变、时间错位、单位错误、持续无新帧。每项保存真实命令与退出码。软件夹具可用于数学正确性，但人体判别与重复性仍需要真实数据。

## 8. 停止与降级条件

上游角度尚未验证、缺少独立标签、任务允许范围未冻结、输入时钟/单位不一致、数据不足或试图把输出直接连执行器时停止对应阶段。可以交付指标设计或部分离线结果，但缺项必须为 `BLOCKED`，不声称智能康复控制已实现。

## 9. 交接与完成标准

交接应明确哪些指标适合当前工程监督、哪些只属探索性研究、哪些还没有临床/控制效度。人机接口未实测与离线指标验收分别列结论，不混为整体通过。

D1～D5齐全，每项有 `PASS/FAIL/BLOCKED` 和真实证据，人工确认后更新执行状态。建议工作量4～6个工作日，前提是上游结果及独立数据就绪。
