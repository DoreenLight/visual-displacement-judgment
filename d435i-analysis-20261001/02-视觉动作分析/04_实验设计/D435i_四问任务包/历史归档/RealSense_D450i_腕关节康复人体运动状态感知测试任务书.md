# 基于 Intel RealSense D450i 的腕关节康复人体运动状态感知测试任务书

## 一、实验目的

本实验利用 Intel RealSense D450i 深度相机，采集腕关节康复训练过程中人体上肢运动信息，验证深度视觉是否能够作为康复机器人中的人体状态感知传感器。

重点验证以下问题：

1. 是否能够稳定获取人体上肢关键点（三维坐标）；
2. 是否能够获得腕关节运动轨迹；
3. 是否能够识别腕关节训练过程中的肩部、肘部等代偿运动；
4. 是否能够构建用于后续智能康复控制的人体运动质量评价指标。

最终目标：

建立：

```
人体视觉状态
        ↓
运动质量评价
        ↓
自适应康复控制
```

的数据基础。

# 三、阶段1：人体关键点稳定性测试

## 3.1 实验目的

验证深度相机输出人体关键点的稳定性。

---

## 3.2 实验动作

### 状态1：自然坐姿

保持30秒。


### 状态2：康复训练姿态

手放置在机器人握柄位置。

保持30秒。


### 状态3：模拟训练状态

保持训练姿态，但不主动运动。

保持30秒。

---

## 3.3 需要采集的数据

至少保存：

- 时间戳 t；
- shoulder 三维坐标；
- elbow 三维坐标；
- wrist 三维坐标。


数据格式：

CSV：

|time|shoulder_x|shoulder_y|shoulder_z|elbow_x|elbow_y|elbow_z|wrist_x|wrist_y|wrist_z|
|-|-|-|-|-|-|-|-|-|-|

---

## 3.4 分析指标

计算静止状态下：

关键点位置波动：

\[
\sigma_x,\sigma_y,\sigma_z
\]


评价：

- 平均误差；
- 最大漂移；
- 标准差。

# 四、阶段2：正常腕关节运动轨迹采集

## 4.1 实验目的

验证视觉系统是否能够获得腕关节运动轨迹。

---

# 4.2 动作A：屈伸运动（F/E）

要求：

保持：

- 肩基本不动；
- 肘基本不动。


仅进行腕关节：

屈曲/伸展。


范围：

约：

\[
-30^\circ \sim 30^\circ
\]


次数：

10次。


---

# 4.3 动作B：桡偏/尺偏（R/U）

范围：

约：

\[
-20^\circ \sim 20^\circ
\]


次数：

10次。


---

# 4.4 动作C：二维圆周运动

模拟腕关节康复训练。

要求：

完成：

- 顺时针10圈；
- 逆时针10圈。


记录：

腕部三维轨迹。


---

# 五、阶段3：人体代偿动作检测（重点）

## 5.1 实验目的

验证视觉系统是否能够区分：

- 正常腕运动；
- 肘代偿；
- 肩代偿；
- 前臂代偿。


这是后续论文中“人体运动质量评价”的基础。

---

# 5.2 Case 1：正常腕运动

要求：

只进行腕关节运动。

保持：

肩、肘稳定。


标签：

Normal


---

# 5.3 Case 2：肘部代偿

要求：

主动增加肘部移动。

例如：

肘前后移动：

> 5 cm


同时完成腕运动。


标签：

Elbow compensation


---

# 5.4 Case 3：肩部代偿

要求：

主动抬肩或肩部前后移动。

例如：

肩移动：

> 5 cm


同时完成腕运动。


标签：

Shoulder compensation


---

# 5.5 Case 4：前臂旋转代偿

进行：

前臂旋前/旋后。


标签：

Forearm compensation


---

# 六、运动质量评价指标设计

## 6.1 关节移动距离

计算：

肩：

\[
D_s=||P_s(t)-P_s(0)||
\]


肘：

\[
D_e=||P_e(t)-P_e(0)||
\]


腕：

\[
D_w=||P_w(t)-P_w(0)||
\]


---

# 6.2 代偿指数 Compensation Index

初步定义：

\[
CI=
\frac{D_s+D_e}
{D_w+\epsilon}
\]


含义：

- CI较小：
  - 主要依靠腕关节完成运动；

- CI较大：
  - 依赖肩、肘代偿。


---

# 6.3 人体运动协调性分析

分析：

肩-肘-腕之间：

- 运动相关性；
- 时间同步关系；
- 轨迹一致性。


可尝试：

- Pearson correlation；
- PCA；
- Dynamic Time Warping。

# 十、最终希望回答的科学问题

传统康复机器人主要关注：

“机器人是否准确执行目标轨迹”。

本研究进一步关注：

“患者是否采用正确的人体运动方式完成训练”。

深度视觉的目标不是简单测量位置，而是建立：

\[
机器人状态 + 人体运动状态
\]

的双向感知，为智能康复控制提供依据。

## 附：型号勘误提示（2026-09-30 追加，不修改上文正文）

上文所称「Intel RealSense **D450i**」在 Intel 官方产品线中**不存在**。经核验官方 D400 系列数据表（Doc 337029-017, Rev 021, Oct 2025）：

- 官方 Depth Camera 型号：D401 / D405 / D415 / D435 / **D435i** / D435f / D435if / D455 / D455f / D456
- 官方 Depth Module 型号：D410 / D415 / D430 / **D450** / D401
- 数据表中「D450i」出现次数：**0**
- `D450` 的实际形态：裸深度模组（124×26×29 mm，无外壳、无 IMU、720p@30fps）

本项目的四问可行性论证按 **D435i** 撰写（`01-摄像头/` 目录已实测在役的机型）。论证文档见：
