# 任务包01：上肢关键点三维坐标获取与稳定性验证

> **对应问题**：是否能够稳定获取人体上肢关键点（三维坐标）？
> **本包要给出的答案**：在明确距离、姿态、视角与握柄条件下，肩、肘、腕能否连续测到，波动多大，参考误差多大，何时不可用。
> **当前状态**：任务定义完成，程序与人体实验未执行。
> **共享合同**：[总入口](README.md)；[总任务书](RealSense_D435i_腕关节康复人体运动状态感知测试任务书.md)。

## 1. 目标与非目标

### 目标

- 建立真实 D435i RGB-D 采集、配准、二维关键点识别及三维反投影链路。
- 输出训练侧肩、肘、腕的原始/滤波坐标、时间戳和有效性原因。
- 分开验证重复性、连续可用性和对独立参考的准确性。
- 提供可以供 TP-02、TP-03、TP-04 消费的 `wrist-rehab/v1` 数据，不把模型坐标冒充深度实测。

### 非目标

不负责腕关节角度解算、代偿分类、综合评分或机器人控制；不声称姿态模型点就是解剖旋转中心；不将近距离刚性靶标的性能外推为人体性能。

## 3. 实施步骤

### K1：先验证深度采集而非先看骨架动画

1. 启动RGB和深度流，记录实际帧率、分辨率、时间域、帧号与丢帧。
2. 保存原始深度及尺度，不只保存伪彩色视频；保留RGB和标定元数据。
3. 用固定标记检查对齐：相同像素必须对应相同目标区域，避免沿用配准前内参。
4. 对固定刚性目标做静止和已知位移测试，先确认采集/坐标链路；不能代替后续人体测试。

### K2：获得真实三维关键点

1. 在RGB中定位训练侧 shoulder/elbow/wrist，并保留模型评分与可见性。
2. 从对齐后的深度中选择属于目标部位的有效局部深度，排除桌面、握柄、机器人和背景。
3. 使用对应内参和畸变模型反投影。简化针孔公式为：

\[
X=(u-c_x)Z/f_x,\qquad Y=(v-c_y)Z/f_y
\]

4. 输出固定相机光学坐标系中的米制原始坐标。像素越界、无深度、低可见性或几何不合理时输出 `NaN` 和原因。
5. 滤波只处理有效数据；原始与滤波数据均保存。上一帧保持或插值不得进入真实有效帧计数。
6. 检查上臂/前臂长度的不合理突变，但不能强制套用“所有人的前臂都265 mm”消除真实差异。

### K3：执行静止测试

每个条件记录30秒，至少重复3次，并重新摆位检验跨次重复性：

| 状态 | 操作 | 关注问题 |
|---|---|---|
| S1 自然坐姿 | 手臂自然放置、肩肘腕可见 | 基础可见性和抖动 |
| S2 握柄姿态 | 手已放到实际握柄位置，再建立稳定基线 | 握柄/机器人遮挡 |
| S3 训练准备静止 | 保持训练姿态，不主动运动；机器人不得意外驱动 | 正式训练起始状态是否可靠 |

初始距离为1.0、1.25、1.5 m；视角从前侧方约45°开始，逐条件记录实际布置。无法看到目标时判该条件不可用，而不是强行填写满900帧有效数据。

人体存在生理微动，不能把所有波动都解释为传感器噪声。可同步跟踪固定标记或独立参考，比较人体微动与测量变化，不直接用两个标准差相减分离噪声。

### K4：补充动态可用性与边界测试

缓慢改变上肢姿态，记录关键点动态有效性；使用可控遮挡、背景近邻、握柄接触、不同衣物和视角测试失效边界。动态运动准确性由独立参考评价，不用平滑后的自身轨迹作为真值。

## 4. 指标定义

- `valid_rate_j`：每个关节真实有效的样本数/应分析的样本数；同时报告捕获帧上的有效比例、相机丢帧和连续失效时长，不能只统计成功识别帧。
- `sigma_x/y/z`：稳定片段的原始坐标标准差，另报滤波后值。
- `drift_p95/max`：相对稳定基线中位位置的位移95分位/最大值；称位置波动，不称真值误差。
- `RMSE_3D`、`error_p95`：与独立参考在同坐标、同时间下比较；写明参考测量的是表面标记还是解剖中心。
- `gap_max_s`：最长连续真实失效时间。
- `latency`：能够完成时钟映射时报告采集到输出延迟；否则只报告实际可测的接收到输出延迟，并阻塞端到端结论。

## 6. 验收与验证方式

下列数值是候选工程目标，用于首轮较大运动/代偿的可行性验证，执行前冻结，不是既有实测性能。

| 验收项 | 候选通过条件 | 验证证据 |
|---|---|---|
| 数据真实性 | `real_rgbd` 必须读取原始深度并反投影；模型估计独立标识 | 程序入口、原始帧、标定及抽样重算 |
| 静止可用性 | 每个肩/肘/腕在每个批准条件有效率≥95%，最大连续失效≤0.2 s | 原始有效性掩码与帧号 |
| 静止波动 | 原始各轴SD≤5 mm、基线位移P95≤10 mm | 各关节各条件统计；真实生理运动明确解释 |
| 位置准确性 | 对独立参考的3D RMSE≤10 mm、误差P95≤20 mm | 参考、时空标定和逐点比较；目标不能与模型点定义混用 |
| 异常处理 | 无深度/遮挡/越界/单位错误均被标记，未被零值或填充掩盖 | 负向测试的实际命令、输出和退出码 |
| 重现性 | 同一输入和配置得到相同有效性与指标；跨次结果单独报告 | 数据/配置哈希与独立复跑 |

验证命令由实施者在交付时给出真实存在的采集、离线处理和测试入口，并保存实际输出。测试夹具可以使用 `fixture`，但夹具通过不代替真实人体验收。

缺少独立参考时，稳定性项可单独给结论，准确性项必须是 `BLOCKED`，不得宣称本包全项通过。

## 7. 停止与降级条件

硬件/型号不符，时间戳或配准不明，核心关节持续不可见，原始深度未保存，参考点定义不一致，已知失效被插值掩盖，或出现安全问题时停止对应验收。允许先完成固定目标和纯软件链路，但必须标注人体能力尚未验证。

## 8. 下游交接与完成标准

向 TP-02/TP-03 提供固定版本的契约实现、标定、有效数据条件、数据run与哈希、坐标/时间定义和失效边界。下游若更换距离、视角或握柄条件，不能直接沿用本包的性能结论。

完成标准：D1～D5齐全，每个验收项有实测值及 `PASS/FAIL/BLOCKED`，适用条件可复现，人工确认后再修改执行状态。建议工作量3～5个工作日，仅在硬件、参考和采集授权就绪后估算，不含审批与采购。
