# 任务包03：腕训练中的肩部、肘部代偿识别

> **对应问题**：是否能够识别腕关节训练过程中的肩部、肘部代偿运动？
> **本包要给出的答案**：在明确要求肩肘稳定的腕训练中，能否检测可观测的额外肩/肘参与，并区分正常、肩、肘、共同参与及不可判读。
> **当前状态**：任务定义完成，分类器/规则及独立人体验证未执行。
> **共享合同**：[总入口](README.md)；[总任务书](RealSense_D435i_腕关节康复人体运动状态感知测试任务书.md)。

## 1. 目标与非目标

### 目标

- 冻结正常动作与肩、肘可疑代偿的操作定义，不把“关节动了”自动等同代偿。
- 以肩部位移/上臂方向、肘部位移/屈伸和任务上下文建立分通道检测。
- 使用独立标签验证检出、误报警、分类混淆和延迟。
- 遮挡、姿态不可靠或归因不明时输出 `unknown`，不强行赋予正常或临床严重度。

### 非目标

本版不验收前臂旋转代偿，不判断患者疼痛、主动发力、疾病机制或临床严重程度；不宣称单台相机可以观察所有肩关节旋转。也不预设单相机只能二分类或必须增设另一台相机。

## 3. 操作定义与标签

### C1：先定义任务约束

正常是“完成规定腕动作，同时肩肘变化处于当前任务允许范围”，而不是“所有关键点完全静止”。自然摆位到握柄位置的过渡不参与代偿评价；进入训练稳定状态后取一段可靠数据建立基线。

原任务中的“肩/肘移动超过5 cm”仅用来诱导明显工程样本，不是临床通用阈值。动作指令名称不是标签真值，必须检查受试者实际完成的运动。

### C2：采用分通道和组合状态

| 独立标签/输出 | 定义 |
|---|---|
| `shoulder_compensation` | 任务禁止的额外肩部参与，实际可观测并经独立标注 |
| `elbow_compensation` | 任务禁止的额外肘部参与，实际可观测并经独立标注 |
| `normal` | 有效、确实在做腕动作，两个代偿通道均不满足条件 |
| `combined` | 两个通道同时满足已冻结定义 |
| `unknown` | 观测不足、任务阶段不明或标注/归因无法可靠判断 |

肩动可能带动肘移动。必须分别保留“看到的部位运动”和“代偿标签”：不能仅凭肘点位移，就把真值标成肘关节自身的代偿。若任务只定义部位运动筛查，结果不得升级为解剖成因判定。

没有TP-02或独立动作参考时，可以评价肩肘额外运动筛查，但不能以“两通道阴性”证明腕训练已经完成。

## 4. 特征与实施步骤

### C3：计算可解释的运动学特征

- 肩部相对训练基线的位移；需要时计算相对躯干的抬高/前后变化。
- 上臂向量 `P_e-P_s` 与躯干的方向变化，说明其不能完整代表肩内外旋。
- 肘部位置、相对肩/躯干的变化及肘屈伸角。
- 数据有效性、可靠基线是否存在、当前腕任务阶段。

以伸直为0°的肘屈伸候选定义：

\[
\theta_e=\pi-\arccos\frac{(P_s-P_e)\cdot(P_w-P_e)}{\|P_s-P_e\|\|P_w-P_e\|}
\]

分母退化、点无效或角度定义与参考不同必须标记无效。坐标与长度单位遵循共用契约。

### C4：建立基线规则，再评价是否需要分类模型

1. 冻结每种任务的允许范围、数据门控、超过阈值的持续时间和恢复滞回。
2. 阈值要高于可测噪声并符合任务约束；参考噪声只能帮助设置检测限，不自动形成临床阈值。
3. 输出两个独立通道和组合状态；未知输入不会被默认转成 `normal`。
4. 如基线规则失败，再研究模型；训练/调参数据与独立测试隔离，不能用相邻帧随机划分制造高准确率。
5. 相关系数/PCA/DTW只作辅助特征；高相关不能独立证明代偿或正常协同。

## 5. 实验与独立标签

采集正常、肩参与、肘参与、肩肘共同参与四种可见工况，另设遮挡、整体姿态调整、任务开始/结束与静止负向工况。各类保持同一种腕任务，避免靠动作速度或视频背景识别标签。

- 健康工程采集先做单人连通性；正式规模与跨人/跨session划分在执行前冻结。
- 至少包含多名参与者和重新摆位；不足时报告样本限制，不能宣称临床泛化。
- 参考可利用同步视频与独立运动测量；至少两名标注者独立标注事件类别和起止时间。
- 报告标注一致性；分歧先裁定或标为不可判读，不能用算法预测反改标签。
- 固定视角首先检查真实握柄条件。核心部位持续不可见则调整布局并重新验证，不能拿不同时间的两次动作当作同一次运动的多视角真值。

## 7. 验收与验证方式

以下为明确可见的大幅代偿工程初验候选，不是临床正常值：

| 验收项 | 候选通过条件 | 验证证据 |
|---|---|---|
| 独立标签 | 类别和事件实际发生有独立依据；报告一致性与裁定 | 原始双人标签、参考和标注规范 |
| 肩通道 | 测试集敏感度≥0.90、特异度≥0.90 | 按受试者/session隔离后的原始计数和置信区间 |
| 肘通道 | 测试集敏感度≥0.90、特异度≥0.90 | 同上，不以总体准确率掩盖单通道失败 |
| 混合参与 | 单独报告combined与肩/肘互相混淆；不能强制单标签 | 多标签预测及组合混淆矩阵 |
| 延迟 | 有效可观测事件的检测延迟P95≤300 ms | 独立事件起点、时钟映射及实际输出时间 |
| 不可观测处理 | 遮挡/低质量/未建立基线正确进入unknown，不伪报正常 | 负向测试命令和真实输出 |
| 评价覆盖 | unknown和失效事件不从总样本中悄悄删除；报告可判读覆盖率，候选≥95% | 全测试样本清单及失效登记 |

precision/recall/F1与正常误报警率也必须报告。阈值改变后应使用新的独立评估数据；报告有效片段成绩，同时报告全体覆盖和缺失影响，不用“unknown”隐藏错误。

## 8. 停止与降级条件

核心点持续不可见、无法区分整体姿态与局部参与、标签冲突未裁定、任务定义不明、测试集泄漏、测量噪声大于目标代偿或出现安全问题时停止相应验收。

允许降级为“可观测部位运动提示”，但必须明确不能做可靠分类/成因归因；不可给出临床严重度或自动纠正控制。

## 9. 下游交接与完成标准

向TP-04交付两个独立通道、unknown原因、允许范围、可靠基线、事件时间与检测误差，而不是只有一列“正常/异常”。提供具体数据、配置和模型哈希，并说明是否仅为运动筛查。

D1～D5完整，各验收项有 `PASS/FAIL/BLOCKED`、原始计数和真实复现命令，人工确认后更新执行状态。建议工作量5～8个工作日，取决于标签与采集就绪程度。
