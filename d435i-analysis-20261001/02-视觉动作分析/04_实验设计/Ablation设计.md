## 0. 总览与"预设的诚实性"

**本文档的核心设计原则：每条消融都预先登记「若假设不成立怎么办」。**

> 🔴 **理由**：`README.md` 已把"避免被审稿人挑战为换名字的 regression"列为核心风险。
> 若 A1/A2/A3 的消融结果**不支持**我方主张，**必须在实验设计阶段就有预定的应对**，
> 而不是事后挑指标或隐藏结果。

| # | 消融 | 切掉什么 | 检验哪个假设 | **若证伪** |
|---|---|---|---|---|
| **A1** | 去 anatomy token | anatomy-aware 切分 → 普通 ViT patches | **H1** 解剖先验有效 | 撤回"anatomy-aware"命名，改用"structured tokenizer" |
| **A2** | 去 grammar loss | 6 项 → 只留 $L_{\text{angle}}$ | grammar 带来物理合法性 | 撤回 grammar 主张，只主张精度与结构 |
| **A3** | 去 tokenization | VQ 码本 → 连续回归 | **H3 变体**：token 化有收益 | 撤回"Kinematic Language"，降级为"多任务正则" |
| **A4** | 去 forecasting | 只做同步翻译 | forecasting 有价值 | 降级为"未来工作"，保主任务 |
| **A5** | 去 cross-attention | 视觉 memory → 自回归 target-only | **H2** 跨模态非冗余 | **全项目最大风险**：需重新定位贡献 |

## A1 · 去 Anatomy-aware Tokenization

### 假设

> **H1**：按人体运动链切分的 token 优于普通规则网格 patches。

### 实现

| 变体 | 机制 |
|---|---|
| **A1-a · 普通 ViT patches** | 标准 16×16 网格 patch，无 anatomy 语义（**主对照**） |
| **A1-b · S3 纯可学习分配** | 无关键点先验，region 归属纯端到端学习（见 `Anatomy_aware_Tokenizer.md` §2.1） |
| **A1-c · region 打乱** | 保留 token 数量但**随机打乱 region 归属**（**结构性破坏**） |
| **A1-d · 去掉 r0/r7** | 去掉躯干与全局 token（检验 `Anatomy_aware_Tokenizer.md` §2.2 的必要性） |
| **A1-e · $\tau$ 扫描** | $\tau \in \{0.01, 0.05, 0.1, 0.5\}$（$\tau\to\infty$ 退化为均匀池化） |

### 预期结论

| 指标 | 预期 | 强度 |
|---|---|---|
| MAE° | B3 优于 A1-a（**差异可能不大**） | 弱 |
| **ROM violation rate** | **B3 显著优于 A1-a** | **强**（核心论据） |
| **FK consistency** | **B3 显著优于 A1-a** | **强** |
| Temporal jerk | B3 优于 A1-a | 中 |
| A1-c（打乱） | **应显著劣化** —— 否则 region 轴未生效 | **诊断性** |
| A1-d（去 r0/r7） | 肩部相关指标显著劣化 | 中 |

### 🔴 若证伪的应对（**必须预先接受**）

| 情形 | 应对 |
|---|---|
| A1-c 打乱后**性能不变** | 说明 region 轴**实际未被使用** → 触发 `Spatio_Temporal_Encoder.md` R1。<br>**应对**：① 撤回"anatomy-aware"这一命名主张；② 把贡献重新定位为**"显式 token 化 + grammar"**（去掉"anatomy"）；③ 在论文中**如实报告该负面结果**——诚实报告一个被证伪的归纳偏置，比假装它有用更安全 |
| A1-a 与 B3 **在所有指标上都无差异** | **核心创新点 2 完全失效** → 需重新审视项目定位 |

## A2 · 去 Biomechanical Grammar Loss

### 假设

> 6 项 grammar loss 带来的**物理合法性**增益，独立于精度增益。

### 实现

| 变体 | 保留的损失项 |
|---|---|
| **A2-a · 仅 $L_{\text{angle}}$** | 只留主任务（**主对照**） |
| **A2-b · 对标 Chao 2026** | $L_{\text{angle}} + \lambda L_{\text{vel}}$（**复现竞品的约束配置**） |
| **A2-c · 逐项累加** | $L_{\text{angle}} \to +L_{\text{vel}} \to +L_{\text{acc}} \to +L_{\text{ROM}} \to +L_{\text{FK}} \to +L_{\text{temporal}}$ |
| **A2-d · 全项但作用于不同层** | 约束只在损失层 vs 同时作用于表征层（离散化） |

### 预期结论

| 指标 | 预期 | 说明 |
|---|---|---|
| MAE° | **B3 与 A2-a 差异可能很小（甚至无显著差异）** | ⚠️ **这正是要证明的：精度不是唯一目标** |
| **ROM violation rate** | **A2-d < A2-c < A2-b < A2-a**（单调） | **核心论据** |
| **FK consistency** | 同上单调 | **核心论据** |
| Temporal jerk | A2-c 最好 | 中 |
| A2-b vs A2-a | 差异小 → 说明**只有 2 项约束不足** | **直接对标 Chao 2026** |

### 🔴 若证伪的应对

| 情形 | 应对 |
|---|---|
| A2-a 与 B3 **在 ROM violation 上也无差异** | 说明真值本身未越界，模型自然学会 → **grammar 是"冗余的成功"**。<br>**应对**：① 构造**对抗性测试集**（极端姿态、快速动作）来暴露约束的价值；② 若仍无差异，**如实报告语法约束在常规数据上是冗余的**，并撤回该主张 |
| A2-c 逐项累加**没有单调性** | 说明各项约束互相干扰（`Kinematic_Tokens_与_Grammar.md` F3）→ 先修量纲归一化再重跑 |

> ⚠️ **A2-b 是对标 Chao 2026 的关键**：若 A2-b ≈ B3，则"6 项 vs 2 项"的差异论据被击穿。
> **必须诚实报告。**

## A3 · 去 Tokenization（连续回归）

### 假设

> **H3 变体**：kinematic token 的离散化带来表征层收益（平滑性 / 外推 / 组合）。

### 实现

| 变体 | 机制 |
|---|---|
| **A3-a · 连续回归** | 去掉 VQ，decoder 直接输出连续角（**主对照**） |
| **A3-b · 码本大小扫描** | $K \in \{16, 64, 256, 1024\}$（$K$ 小 → 更强离散化） |
| **A3-c · 码本初始化对比** | U1 均匀 / U2 k-means / U3 可学习（见 `Kinematic_Tokens_与_Grammar.md` §2.1.1） |

### 预期结论

| 指标 | 预期 | 强度 |
|---|---|---|
| MAE° | **A3-a 与 B3 差异不显著**（量化分辨率 0.94° ≪ 阈值 5°） | — |
| **Temporal jerk** | **B3 优于 A3-a** | **强**（`评价指标.md` §6 已指出这是最可能体现 token 化收益的指标） |
| **长序列外推** | B3 优于 A3-a（离散符号更稳定） | 中 |
| **零样本关节组合** | B3 可能优于 A3-a | 中（需专门设计实验） |
| $K$ 扫描 | 存在最优 $K$；过大则退化到 A3-a | 诊断性 |

### 🔴 若证伪的应对（**这是我方最脆弱的一环**）

> `Kinematic_Tokens_与_Grammar.md` §6 已明确警示：
> **若去 tokenization 后所有指标都不变，则"Kinematic Language"命名的必要性被击穿。**

| 情形 | 应对 |
|---|---|
| A3-a 与 B3 **在所有 8 项指标上都无差异** | **"Kinematic Language"叙事失效**。<br>**应对**：① 撤回"语言"隐喻，把 VQ 降级为**工程性的输出参数化**；② 贡献重新锚定在 **grammar 约束**与 **cross-attention** 上；③ **不得**用"命名差异"充数 |
| 只有 temporal jerk 有差异 | **仍可主张**，但必须把叙事从"语言"收窄为**"离散表征抑制高频抖动"**（一个可解释的机制，而非隐喻） |

> ⚠️ **重要纪律**：**不得为了保住"语言"叙事而在事后挑选指标**。
> A3 的全部 8 项指标必须在实验前**锁定**（本文档即为锁定记录）。

## A4 · 去 Forecasting

### 假设

> 因果未来翻译任务提供额外价值，且不与主任务冲突。

### 实现

| 变体 | 机制 |
|---|---|
| **A4-a · 仅同步翻译** | 只做 $t-k:t \to t-k:t$（**主对照**） |
| **A4-b · 视界扫描** | $h \in \{100, 200, 300\}$ ms（报告 $\Delta$MAE vs sync） |
| **A4-c · 独立 head vs 统一解码** | 见 `Forecasting_Task.md` §4（F1 vs F2） |
| **A4-d · 预测段有无 grammar** | 预测段只 $L_{\text{angle}}$ vs 全 grammar |

### 预期结论

| 指标 | 预期 |
|---|---|
| 同步 MAE° | A4-a 与 B3 **应无显著差异**（forecasting 不应拖累主任务；若拖累，见 F5） |
| **$\Delta$MAE@h** | 随 $h$ 单调增大（衰减曲线） |
| **ROB viol.@h** | A4-d 显著优于无 grammar 版（**这是"预测段也物理合法"的核心证据**） |
| **vs Persistence** | B3 必须显著优于 persistence，否则预测任务无意义 |

### 🔴 若证伪的应对

| 情形 | 应对 |
|---|---|
| **$h=300$ ms 完全做不到** | **已预先规划**（`Forecasting_Task.md` §3）：如实报告最大可达视界，并把"RGB vs sEMG 信息带宽差异导致视界缩减"**本身写成方法论贡献** |
| **被 persistence 追平** | 在快速动作段单独评估；或放弃 forecasting 并降级为"未来工作" |
| forecasting **拖累**主任务 | 按 `Forecasting_Task.md` R4：**优先保主任务**，forecasting 降级 |

> 💡 **A4 是本项目唯一可以"安全放弃"的消融**——它是"可选加分项"，不是核心创新点。

## A5 · 去 Cross-Attention ★ 最高风险

### 假设

> **H2**：跨模态 cross-attention 是必要的——视觉信息对运动学预测有不可替代的贡献。

### 实现

| 变体 | 机制 | 用途 |
|---|---|---|
| **A5-a · 视觉输入置零** | 把 visual memory 置零，只靠 target 侧生成 | **最关键诊断** |
| **A5-b · 打乱帧序** | 打乱视觉帧的时间顺序（破坏时序信息） | 诊断时序贡献 |
| **A5-c · 纯自回归（无 cross-attn）** | 移除 cross-attention，只有 target self-attention | 主对照 |
| **A5-d · 跨模态 cross-attn 换同模态** | 用 target 自身做 key/value（退化为自注意力） | 主对照 |
| **A5-e · 解剖路由打乱** | 打乱每 DOF 的允许 region 集合（见 `Cross_Modal_Decoder.md` §3.1.1） | 诊断解剖路由 |

### 预期结论

| 变体 | 预期 | 强度 |
|---|---|---|
| A5-a（置零） | **MAE° 应显著劣化** | **若不变 ⇒ H2 证伪** |
| A5-b（打乱帧序） | 劣化 | 应显著 |
| A5-c（无 cross-attn） | 劣化 | 应显著 |
| A5-e（路由打乱） | 劣化 | 中等 |

### 🔴 若证伪的应对 —— **这是全项目最重要的风险预案**

> `Cross_Modal_Decoder.md` R1 已把"Cross-attention 并非必要"标为**全项目最大单点风险**：
> 视觉消融后性能不显著下降 ⇒ **"跨模态翻译"叙事被击穿**。

| 情形 | 应对 |
|---|---|
| **A5-a 置零后性能几乎不变** | 说明**模型主要从 target 侧的先验生成角度**（角度分布本身可预测），视觉贡献边际。<br>**应对链**：<br>① **立即重新定位贡献**：从"跨模态翻译"退到**"结构化输出 + 6 项 grammar 约束"**（这两条不依赖视觉贡献度）；<br>② 把 H2 证伪**写成论文的诚实发现**（"视觉信息对腕/肘角度的边际贡献有限，因为角度分布本身强先验"）——**这是一个有价值的负面结论**；<br>③ 检查是否是真 bug（memory 未接、梯度未流）——**必须先排除实现错误** |
| 只有打乱帧序（A5-b）有影响，置零无影响 | 说明**时序结构重要但视觉内容不重要** → 贡献应转向"时序建模" |
| A5-e 打乱后无影响 | 解剖路由无效 → 简化设计，如实报告 |

> 🔴 **必须在项目早期（而非论文定稿前）执行 A5-a。**
> 若等到写完论文才发现，返工成本极高。
> **建议：A5-a 与 A1-c（region 打乱）作为"第一周就得跑"的诊断实验。**

## 6. 消融优先级与执行顺序（资源有限时）

| 顺序 | 消融 | 理由 | 成本 |
|---|---|---|---|
| **1** | **A5-a**（视觉置零） | **最高风险，最早证伪** | 低（复用已训模型） |
| **2** | **A1-c**（region 打乱） | 检验 H1，成本低 | 低 |
| **3** | **A2-a**（去 grammar） | 检验核心创新点 3 | 中 |
| **4** | **A3-a**（去 tokenization） | 检验最脆弱的"语言"叙事 | 中 |
| **5** | **A2-b**（对标 Chao 2026 的 2 项约束） | 直接对标竞品的约束配置 | 中 |
| **6** | **A4-a/b**（去 forecasting / 视界扫描） | 加分项，可延后 | 中 |
| **7** | A1-a/b/d/e、A2-c/d、A3-b/c、A4-c/d、A5-b/c/d/e | 细节扫描 | 高 |

> **执行原则**：先跑**能证伪核心假设**的低成本消融（1–2），
> 再跑**能支撑核心主张**的消融（3–5）。
> **不要先跑一大堆细节扫描**。
