# 本轮结果之后的探索顺序

1. 每次开始/重新摆位建立新的可靠静止基线，显示基线年龄和是否匹配；本轮未改实时程序。
2. 优化实时调度或记录离线帧覆盖，区分未推理与识别失败；不能用离线高覆盖声称实时已达标。
3. 用失败帧检查小手点深度窗口的目标所属，考虑边缘感知/手部ROI采样与一致性门控；改窗口须新版本验证，不默认更宽松更准确。
4. 重新设计候选角中立位与手相对前臂参考；单一肘腕轴不能补全前臂轴向旋转。先解决轴/符号/零位，再完善计数。
5. 将肩位置、上臂摆动、肘角变化分别显示，避免飞肘被通道名称解释为耸肩。提示是工程运动筛查，不是临床原因判定。
6. 在已发现的边界姿态附近小批复采：逐条件改变手朝向、握柄遮挡、视角、速度及摆位，记录实际距离/相机高度/参数。当前录像不足以估算普遍极限距离。

正式阶段再补独立位置/角度参考、双人事件标签、跨session测试与时钟映射。先做同片段前后对照；原片、实时输出和本轮结果均保留版本。
