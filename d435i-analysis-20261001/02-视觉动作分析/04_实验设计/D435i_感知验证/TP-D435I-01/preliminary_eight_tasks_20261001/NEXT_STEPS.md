# 下一步探索计划

本次只归纳进展，以下未执行；尚未修改程序、离线重推理或新采集。

1. **人工对照清晰片段**：已有数据中选静止、正常FE/RU、单独肩、单独肘和共同参与，保存run与时间段、实际动作描述；指令名称不直接当真值。
2. **已有RGB-D离线重处理**：新增版本化运行目录，保存模型/配置/代码哈希及有效性原因；实时原结果保留作对照。
3. **诊断基础异常**：优先静止combined、手部可见性及角度串扰/断续、在线计数0；区分真实混合运动与算法问题。
4. **同片段前后对照**：输出叠加画面、肩肘变化、候选角度、周期和提示状态，人工判断合理性；不得用放松正式阈值换PASS。
5. **完善探索性质量输出**：区分完成、未完成、额外参与、不可观测，缺指标不填高分。
6. **小批复采，再扩大**：先按八类复测一轮，记录距离、视角、训练侧、握柄、基线、摆位、配置、实际次数。运行合理后再扩展人/session。

探索推进条件：典型片段输出与画面相符，计数可对照人工，信息损失原因可追踪，静止和unknown不冒充正常完成。此处不是新的正式验收合同。

当前用户回转任务为顺/逆各5圈，原正式协议为各10圈；下一轮记录实际方案，避免混用。后续正式验证才补独立位置/角度参考、节段/解剖标定、双人事件标签、隔离测试集、时钟映射及原标准评价。本轮无需先新增参考设备，但不能将候选角称为已验证ROM。
