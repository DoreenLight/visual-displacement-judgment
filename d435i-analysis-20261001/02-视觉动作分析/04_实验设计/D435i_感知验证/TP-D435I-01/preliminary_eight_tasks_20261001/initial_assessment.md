# 八类任务初步工程判断

本记录采用用户指定的探索性工程标准，未改动正式验收结论。依据25个保留试次的原始清单和派生记录，并抽看每类首个试次20%、50%、80%处画面共24帧；不是完整人工视频标注。

## 结论

原始采集数据有效且值得保留，可用于离线重处理、规则调试与实际动作标注。四问中：三维点位采集已有初步证据；腕运动轨迹仅有候选证据；明显肩肘运动提示已有初步响应，分类尚不稳定；质量评价仅完成指标/拒绝评分流程，尚无有效质量判别证据。不是只差样本数量。

## 实际问题

1. FE/RU/回转存在候选角度变化；所有在线候选计数为0，RU两次离线探索计数为9，但FE离线计数为0、0、0、1。说明部分周期信号可提取，计数和角度还需调试。正式角度有效为0表示未完成姿态/解剖标定门控，不表示没有腕动作画面。
2. S1第二、第三次可判读输出均为combined，需检查静止画面、基线/阈值/坐标映射，未独立标注前不能直接定为真实代偿或确证误报。
3. 肩诱导首试次主要肩通道；其余两次主要combined。肘诱导三次也主要combined；共同诱导三次主要combined。有明显运动响应，但肩、肘归因不稳定；实际运动混合和算法混淆均需查看视频确认。
4. 当前正式A/C/S均不可用，所有整试次窗口未过正式门控。此处证明数据质量检查/拒绝评分流程，不能证明运动质量评价已有效。

## 下一步

保留原始数据，先对已有25试次离线重处理，减少未推理帧造成的信息损失；复查肩肘基线、手部可见性、有符号候选角度和周期计数。选一段清楚的正常腕动作、单独肩参与、单独肘参与、共同参与、静止进行人工对照。在这些片段上形成稳定合理的结果后再用同样八类任务扩大采集。先无需增加独立设备，但当前角度解释与人体准确性仍属探索。
