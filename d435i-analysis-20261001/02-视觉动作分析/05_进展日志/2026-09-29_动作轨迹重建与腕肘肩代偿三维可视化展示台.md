## 2. 核心技术方案与运动学建模

### 2.1 双网络时空融合与镜头透视防抖
* **双检测器协同**：针对近景手部高自由度特征与宏观躯干大关节，采用 **MediaPipe Hands (21关键点) + MediaPipe Pose (33人体关键点)** 双网络时空融合，在全视频中实现了 100% 满帧追踪。
* **背景仿射防抖补偿**：利用背景静止区域（显示屏框、白板）提取 ORB 特征点，计算帧间单应仿射变换矩阵 $M_t$，消除手持拍摄带来的镜头晃动，还原真实桌面/空间物理坐标。

### 2.2 运动学与动力学时程模型
将腕关节空间运动轨迹解耦为线性前移漂移项与周期性高阶简谐波动项：
$$W(t) = \mathbf{c}_0 + \mathbf{c}_1 t + \sum_{k=1}^K \left[ \mathbf{A}_k \cos(2\pi k f_0 t) + \mathbf{B}_k \sin(2\pi k f_0 t) \right]$$
* **实验1 基频**：$f_0 = 0.99\text{ Hz}$（周期 $1.01\text{ s}$），共 8 个完整轮替循环，峰值线速度达 $650.04\text{ mm/s}$，翻转角度跨度约 $175^\circ$。

### 2.3 腕-肘-肩代偿机制定量评估
构建多关节代偿量化评估矩阵：
1. **瞬时关节位移**：$D_j(t) = \|\mathbf{P}_j(t) - \mathbf{P}_j(0)\|$，其中 $j \in \{\text{Wrist}, \text{Elbow}, \text{Shoulder}\}$；
2. **肘代偿率 (ECR)**：$\eta_e(t) = D_{\text{elbow}}(t) / D_{\text{wrist}}(t)$；
3. **肩代偿率 (SCR)**：$\eta_s(t) = D_{\text{shoulder}}(t) / D_{\text{wrist}}(t)$；
4. **空间协同相关系数**：计算腕部与肘部在 $X$（横向外展）与 $Y$（垂直推拉）维度的皮尔逊相关度。

**实验2 判定结论**：
* 受试者在执行腕部运动时，未能维持肘部静止，肘部产生达 $55.2\text{ mm} \sim 193.9\text{ mm}$ 的显著空间游走，肘屈伸角度变幅达 $19.0^\circ \sim 70.7^\circ$；
* 腕肘位移相关系数高达 $r = 0.639 \sim 0.794$，**判定存在显著的腕肘协同代偿 (Level 3)**；
* 肩部代偿率低于 $18\%$，基本处于正常锁肩范围。
