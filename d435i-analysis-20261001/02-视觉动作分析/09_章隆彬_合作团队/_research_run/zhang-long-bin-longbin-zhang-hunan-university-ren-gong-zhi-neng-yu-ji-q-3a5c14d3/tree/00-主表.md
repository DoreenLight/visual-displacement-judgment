## 一、节点索引（Node Index）

|:---:|----------|--------------------|
| **N1** | EMG与超声驱动的个性化肌肉-肌腱参数估计 | 如何将sEMG与超声实测肌纤维长度通过直接配点最优控制整合进Hill型NMS模型，估计脑卒中偏瘫患者的受试者特异性参数（*F*ₘₐₓ、*l*_M,opt、*l*_TS、*k*_T）以解决肌肉冗余？ |
| **N2** | 物理信息混合模型驱动的下肢多关节力矩预测 | NMS solver-informed ANN/LSTM如何结合迁移学习，在inter-subject与inter-task场景下提升踝、膝、髋多自由度力矩预测的精度与泛化，并突破纯NMS耗时与深层肌EMG缺失的瓶颈？ |
| **N3** | 面向外骨骼按需辅助的自适应控制与不确定性量化 | NMS-GP / NMS-BNN等带置信度的混合模型如何为膝/踝外骨骼提供可量化预测不确定性的安全按需辅助力矩控制，实现自适应人机协同？ |
| **N4** | 无标记运动捕捉与机器学习的临床步态与平衡评估 | 多视角RGB视频+深度学习姿态估计能否替代标记式动捕，实现增强TUG自动分段、BBS评分预测及步态事件（HS/TO）检测的快速低成本临床转化？ |
| **N5** | 面向运动功能恢复的脑机接口系统 | 基于黎曼流形解码的MI-BCI如何融合视觉、听觉、FES、本体感觉多模态刺激，服务于脑卒中偏瘫患者下肢功能康复训练？ |
| **N6** | 实验室团队与国际合作网络 | 章隆彬实验室（湖南大学AI与机器人学院）联合KTH MoveAbility Lab、NTU康复研究所等机构，在康复机器人、BCI、智慧医疗、数据安全四大方向上如何支撑上述生物力学-智能可穿戴技术链条？ |

## 二、主线流程（Main Line Flow）

> **核心逻辑**：以NMS建模为生物力学内核，融合物理信息ML、无标记动捕与BCI，构建「**参数个性化 → 力矩预测 → 自适应控制 → 临床评估**」的智能可穿戴康复技术链，由多机构国际合作网络（湖大-KTH-NTU）支撑产学研闭环。

```
┌──────────────────────────────────────────────────────────────────┐
│  【底座层】  N6 实验室团队与国际合作网络                          │
│  （湖大 AI·机器人学院 ── KTH MoveAbility ── NTU 康复所）         │
│  ↑  持续供给：模型方法 · 临床数据 · 跨学科人才 · 数据合规        │
└──────────────────────────────────────────────────────────────────┘
        │
        ▼
┌──────────────────────────────────────────────────────────────────┐
│  阶段 ①   N1  个性化肌肉-肌腱参数估计                            │
│  · sEMG + 超声肌纤维长度 → 直接配点最优控制 → Hill-NMS参数       │
│  · 输出：受试者特异性 (F_max, l_M,opt, l_TS, k_T)                │
└──────────────────────────────────────────────────────────────────┘
        │  (个性化参数作为物理约束/输入)
        ▼
┌──────────────────────────────────────────────────────────────────┐
│  阶段 ②   N2  物理信息混合模型驱动的多关节力矩预测               │
│  · NMS solver + ANN/LSTM + 迁移学习                              │
│  · 解决：inter-subject变异性、inter-task泛化、深层肌EMG缺失      │
│  · 输出：踝/膝/髋多自由度力矩 + 物理一致性约束                   │
└──────────────────────────────────────────────────────────────────┘
        │  (高置信力矩预测 → 前馈/反馈信号)
        ▼
┌──────────────────────────────────────────────────────────────────┐
│  阶段 ③   N3  外骨骼按需辅助自适应控制 + 不确定性量化             │
│  · NMS-GP / NMS-BNN 提供预测置信区间                             │
│  · 安全按需辅助力矩 + 自适应人机协同                              │
│  · 与 N5 形成「中枢意图 ↔ 外周辅助」闭环                          │
└──────────────────────────────────────────────────────────────────┘
        │  (辅助下的步态/平衡数据需临床量化)
        ▼
┌──────────────────────────────────────────────────────────────────┐
│  阶段 ④   N4  无标记动捕 + ML 的临床步态与平衡评估                │
│  · 多视角RGB → 深度学习姿态估计 → TUG分段 / BBS预测 / HS·TO检测  │
│  · 形成「实验室建模 → 临床低成本验证」转化通道                    │
└──────────────────────────────────────────────────────────────────┘
        ▲
        │  (康复效果量化反馈回 N1-N3 校准)
┌──────────────────────────────────────────────────────────────────┐
│  【并行分支】  N5  MI-BCI + 多模态刺激                            │
│  · 黎曼流形EEG解码 → 运动意图识别                                │
│  · 多模态反馈（视/听/FES/本体感觉）→ 闭环康复训练                 │
│  · 与 N3 协同：神经意图驱动外周辅助                               │
│  · 与 N4 协同：BCI训练效果经步态评估验证                          │
└──────────────────────────────────────────────────────────────────┘
```

### 因果/递进说明表

| 阶段 | 因 (驱动) | 果 (产出) | 传递的关键载荷 |
|:---:|-----------|-----------|----------------|
| ①→② | 个体肌肉-肌腱几何/力学差异 | 力矩预测必须个性化 | 受试者特异性参数集 |
| ②→③ | 预测精度+置信度满足安全阈值 | 外骨骼可按需介入 | 力矩时序 + 不确定性区间 |
| ③→④ | 辅助干预产生新步态模式 | 需临床可量化的评估工具 | 外骨骼辅助下的运动学数据 |
| ④→① | 临床反馈暴露模型偏差 | 反向校准参数估计 | 真实步态偏差量 |
| N5↔N3 | 中枢运动意图可解码 | 外周辅助模式可被意图触发 | 运动意图标签 |
| N5↔N4 | 神经康复需客观量化 | BCI训练效果用步态/平衡衡量 | BBS/TUG临床评分 |
| N6→All | 单一机构资源有限 | 全链条需多机构分工协同 | 模型/数据/临床/合规资源 |

## 三、跨节点交叉关联表（Cross-Node Association Matrix）

| 关联对 | 关联类型 | 关联内容描述 | 共享方法/数据 |
|:------:|:--------:|--------------|---------------|
| **N1 ↔ N2** | 参数 → 模型 | N1估计的(*F*ₘₐₓ, *l*_M,opt, *l*_TS, *k*_T) 作为N2物理信息ANN/LSTM的输入约束与先验正则项 | Hill型NMS方程；受试者特异性参数集 |
| **N1 ↔ N4** | 数据采集互补 | N1超声肌纤维长度与N4无标记动捕的关节运动学在同一试验中同步采集，互为验证 | 同步采集协议；姿态-肌纤维配准 |
| **N2 ↔ N3** | 模型 → 控制 | N2的NMS-informed力矩（含GP/BNN置信度）作为N3外骨骼控制器的参考前馈；不确定性阈值触发辅助介入 | 力矩时序预测 + 预测方差/认知不确定性 |
| **N3 ↔ N5** | 中枢-外周闭环 | N5解码的MI运动意图作为N3外骨骼模式切换/触发信号；N3辅助效果作为N5神经反馈 | 运动意图标签；EMG/力矩触觉反馈 |
| **N3 ↔ N4** | 应用 → 验证 | N3外骨骼辅助下的步态由N4无标记系统量化（TUG、BBS、HS/TO）形成临床证据链 | 外骨骼辅助步态数据库 |
| **N2 ↔ N5** | 共同方法挑战 | 二者均面临inter-subject变异性，可共享迁移学习/领域自适应/Population NMS策略 | 跨被试泛化方法；协变量偏移处理 |
| **N5 ↔ N4** | 干预 → 评估闭环 | N5 MI-BCI+多模态刺激康复训练效果经N4 TUG自动分段与BBS预测量化 | 临床康复纵向队列 |
| **N4 ↔ N1** | 反向校准 | N4揭示的临床步态偏差回流至N1，提示参数估计需重新优化 | 步态偏差指标；模型残差分析 |
| **N6 → N1** | 资源支撑 | KTH提供Hill-NMS建模经验；NTU提供脑卒中临床数据；湖大提供超声-sEMG采集平台 | 跨机构数据共享协议 |
| **N6 → N2** | 方法支撑 | KTH MoveAbility提供OpenSim/Moco工具链；湖大提供物理信息ML算力 | 开源NMS求解器；GPU集群 |
| **N6 → N3** | 工程转化 | NTU康复所提供外骨骼临床试验场景；KTH提供控制算法基准 | 外骨骼硬件平台；IRB审批通道 |
| **N6 → N4** | 临床转化 | NTU康复科提供TUG/BBS金标准标注；湖大提供无标记动捕算法 | 临床金标准数据库 |
| **N6 → N5** | BCI专项支撑 | 合作网络提供多模态刺激硬件（FES、本体感觉装置）与EEG数据集 | BCI-2000/Lab Streaming Layer；伦理审查 |
| **N6 ↔ All** | 数据安全/合规 | 数据安全方向为N1-N5全链条的受试者数据提供隐私计算与联邦学习支撑 | 联邦学习；差分隐私；HIPAA/GDPR合规 |
