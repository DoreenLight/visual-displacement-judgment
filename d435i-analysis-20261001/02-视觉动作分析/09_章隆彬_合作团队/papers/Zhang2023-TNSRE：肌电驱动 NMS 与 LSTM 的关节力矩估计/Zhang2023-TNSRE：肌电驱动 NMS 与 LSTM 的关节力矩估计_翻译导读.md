## 一、方向判定

属于**生物力学信号 → 关节力矩**的 Seq2Seq 建模，定位为 EMG-driven NMS 物理模型与 LSTM 数据驱动模型的对比研究，处于康复外骨骼控制、按需辅助（assist-as-needed）领域。与 ViKiT 的「视觉 → 关节角」同属运动生物力学/可穿戴康复的上下游环节，但**输入模态（EMG vs RGB-D）与输出量（力矩 vs 角度）不同**。

## 二、解决什么问题

1. 面向**按需辅助外骨骼控制器**，需准确预测用户主动关节力矩，以确定外骨骼辅助水平；
2. 在**日常活动多自由度下肢（DOFs）**场景中，并行比较**基于物理的 NMS 模型**与**带时序记忆的 LSTM 网络**的力矩估计精度；
3. 验证**基于特征相似度的运动聚类**（Pooled / Individual / Clustered 三种标定/训练策略）能否在精度与实用性之间取得折中——既避免单运动标定的耗时，又避免全集 Pooled 模型的过度泛化。

## 三、使用方法

- **EMG-driven NMS 模型（CEINMS）**：四段式（肌肉激活动力学 → 肌腱运动学 → Hill 型收缩动力学 → 关节动力学）；EMG→神经激活→肌肉激活→肌腱力→关节力矩；参数经**模拟退火**标定（肌纤维长度 ±15%、形状因子 A∈(−3,0)、强度系数 0.5–2.5）。
- **LSTM 网络**：与 NMS 同输入（13 路 EMG + 4 自由度关节角），时间片→LSTM 层（50 神经元，tanh）→Dense（64）→Dropout（0.4）→输出关节力矩；**由粗到细随机搜索**调参；Early stopping + 4000 epoch 上限；Adam lr=1e−3；MSE loss。
- **聚类方法**：**t-SNE 降维 + K-means（K=3）**——按 EMG+关节角特征相似度将 10 种运动聚为 3 类（步行类 K₁；站-坐/落地/蹲 K₂；坐-站/纵跳/上下台阶 K₃）。
- **真值**：**逆动力学**（Vicon CGM2.3 + 三块 AMTI 力板，6 Hz Butterworth 低通）。
- **三种评估方案**：Pooled（10 运动合一）、Individual（单运动）、Clustered（聚类）。
- **评价指标**：NRMSE（按动作力矩观测范围归一化）；Shapiro-Wilk 正态性检验 + 配对 t / Wilcoxon + Bonferroni 校正。

## 四、核心内容概述

- **数据**：8 名健康受试者（29±4 岁）完成 10 种日常活动（步行 ×3、坐-站双向、蹲、15 cm 台阶上下、纵跳起跳与落地）各 ≥10 次；13 块表面 EMG（TA、GM、GL、SOL、PL、VM、VL、RF、BF、ST、TFL、GLME、GLMA）+ Vicon 100 Hz + 力板 1000 Hz。
- **核心结果**
  - **LSTM 三种方案均获得较高精度**，聚类对 LSTM 增益有限（基线已高）。
  - **NMS 的 Pooled 模型显著逊于 Individual / Clustered**（步行踝 D/P：p<0.01；纵跳/上台阶/下台阶/蹲差异显著），说明 NMS 对运动特异性敏感，需按聚类或单运动标定。
  - Individual ≈ Clustered（NMS 侧），聚类是**精度–实用性**的较佳折中（替代 10 个个体模型只需 3 个聚类模型）。
  - 髋关节 F/E 与 Ab/Ad 精度**系统性低于**踝 D/P 与膝 F/E（NRMSE 中位数：髋 F/E 14.4–16.1%，膝 F/E 12.2–12.7%）。
  - Pooled NMS 在步态预摆动–摆动初期**高估膝伸展力矩**，在坐起动作**低估膝伸展力矩**——暴露跨运动共享参数对相位的扭曲。
- **结论**：**对 LSTM 用 Pooled 即可（足够鲁棒）**；**对 NMS 强烈推荐 Clustered**；本研究为按需辅助控制器设计给出明确模型选择指南，可直接迁移至神经康复与运动障碍患者。

## 五、与 ViKiT（视觉位移判断）项目的关联

| 维度 | 本论文 | ViKiT |
|---|---|---|
| 输入模态 | 13 路 sEMG + 关节角（已需逆运动学） | RGB-D 视频（Intel RealSense D435i） |
| 输出量 | 关节力矩 | 关节角度 |
| 时序结构 | LSTM 时序记忆 | 因果 Seq2Seq（Visual_{t-k:t} → Kinematics_{t:t+h}） |
| 物理先验 | NMS 显式建模 Hill 肌腱动力学 | 生物力学 grammar（ROM / joint hierarchy / FK 约束）融入 decoder + loss |
| 解剖组织 | 未显式按运动链 token 化；按运动聚类 | **解剖感知 tokenizer**（按人体运动链组织视觉 token） |

**启发点**
1. **物理先验 vs 数据驱动的折中范式可借鉴**：NMS ≈ ViKiT 的「生物力学 grammar」——两者都希望把生理结构作为归纳偏置而非纯黑盒；区别在于 NMS 用 ODE/肌骨方程，ViKiT 把 ROM / FK 作为 loss / decoder 约束。
2. **聚类代替单例训练的思路可迁移**：本论文的 Clustered ≈ ViKiT 按运动类型或代偿模式分组训练，可缓解 RGB 跨动作域漂移；本研究显示 LSTM 侧 Pooled 已够好，对 ViKiT 是好消息（提示端到端可放宽对分组细度的要求）。
3. **时序记忆的容量**：本论文 LSTM 仅 50 神经元已能融合 EMG+运动学，对 ViKiT 的视觉 decoder 体量选择有参考意义（视觉 token 量更大，可考虑更深/更宽）。
4. **下游一致性**：腕关节康复场景中，ViKiT 输出角度，本论文输出力矩——可作为**康复运动分析双通道**（运动学 + 动力学）联合读出。

**差异点（直接相关度较低）**
- **输入模态根本不同**——本论文依赖 sEMG 与运动捕捉，ViKiT 目标是**无标记视觉**；不能直接搬结构。
- **因果 300ms 提前预测**：本论文为**同步估计**（同帧 EMG+运动学→力矩），未做 sEMG-style 提前；ViKiT 的 sEMG 灵感来自运动意图先于动作 ~300ms 的电生理先导，本论文不涉及此问题。
- **代偿检测**：本论文聚类以运动类型为目标，不涉及代偿模式的临床标签；ViKiT 的上肢代偿检测需另寻临床数据集。
- **D435i 采集**：本论文使用 Vicon + 力板专业设备，与 D435i 消费级 RGB-D 在精度/标定难度上不可比；D435i 路线在腕关节小关节场景下的精度上限是 ViKiT 需独立验证的问题。
- **竞品 Chao 2026**：本论文定位在 EMG+力矩赛道，与 Chao 2026（RGB 端到端角度）**不直接竞争**，但其「LSTM 三方案普适、聚类对数据驱动模型增益有限」的结论，**间接为 Chao 路线提供方法论支撑**——若视觉数据量足够，单一端到端模型即可胜任，进一步支撑 ViKiT 视觉路线的可行性。
