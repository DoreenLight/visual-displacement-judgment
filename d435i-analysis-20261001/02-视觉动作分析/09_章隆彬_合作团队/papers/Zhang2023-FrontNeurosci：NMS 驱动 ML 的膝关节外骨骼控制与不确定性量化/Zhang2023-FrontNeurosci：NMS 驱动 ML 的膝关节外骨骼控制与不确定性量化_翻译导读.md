## 一、方向判定

属于「生物力学 + 机器学习 + 康复外骨骼控制」交叉领域，以 EMG 信号 + 关节运动学为输入预测膝关节屈伸力矩，并对预测不确定性进行量化以保障人机交互安全。**与 ViKiT 的「视觉视频 → 关节角度 Seq2Seq 翻译」主路线不直接重合**，但共享「生物力学先验 + 数据驱动学习」的范式理念。

## 二、解决什么问题

膝关节外骨骼按需辅助（assist-as-needed）控制中，使用者意图驱动的关节力矩预测常因 EMG 噪声、个体差异、模型误差等因素带有不确定性，而传统 ANN / NMS 模型只能给出点估计，无法告知控制器"何时该信、该信多少"。本文旨在：

1. **构建一个带不确定性边界输出的力矩预测模型**，让外骨骼只在高置信时按预测值给辅助；
2. **比较 BNN 与 GP 两种不确定性量化方法**与 NMS 求解器耦合后的表现；
3. **形成自适应控制闭环**，通过 TCP/IP 流把"指定置信水平的预测力矩"送入外骨骼执行器。

## 三、使用方法

- **NMS-BNN（神经肌肉骨骼 - 贝叶斯神经网络）**：以 EMG 信号（7 块下肢肌群，1 kHz 采集）+ 膝关节屈伸角度 + NMS 求解器输出的肌肉力 / NMS 力矩作为 21 维输入；3 个隐藏层各 40 神经元（tanh 激活）；权重视为概率分布，用 TensorBNN + Hamiltonian Monte Carlo（HMC）采样得到后验点云。
- **NMS-GP（神经肌肉骨骼 - 高斯过程）**：同样的 21 维输入；使用 RBF / Matern / White Noise / Linear 等核函数对比；提供均值与协方差解析式。
- **EMG-driven NMS 求解器（CEINMS）**：开源肌骨模型，含 Hill 型肌肉收缩动力学、肌腱运动学、肌肉激活动力学、关节动力学四模块；参数由模拟退火标定。
- **采集与处理**：8 名健康受试者完成慢走 / 正常走 / 快走 / 坐-站 / 站-坐 5 类动作；Vicon 三维运动捕捉（100 Hz）+ AMTI 三块测力板；EMG 经 30–300 Hz 带通 → 整流 → 6 Hz 低通 → 最大值归一化。
- **不确定性驱动的控制策略**：预测力矩在指定置信水平下通过 TCP/IP 流送外骨骼执行器。

## 四、核心内容概述

**摘要要点**：
- 框架融合 EMG + 关节运动学 + NMS 求解器特征，预测膝关节 F/E 力矩并量化置信区间；
- NMS-BNN 与 NMS-GP 均以低误差优于传统 NMS 模型；
- 运动开始瞬间、自选速度步行支撑末期与摆动末期，模型不确定性较高；
- 膝关节外骨骼以低误差追踪所需辅助力矩；快走支撑末期的辅助量低于自选速度。

**方法细节**：21 维输入特征（实验 EMG/运动学 + NMS 物理特征）→ NMS-BNN/NMS-GP → 输出膝关节力矩均值与置信区间 → TCP/IP 流控制外骨骼扭矩。BNN 超参数由"由粗到细"随机搜索确定，AMSGrad 预训练后用 HMC 采样。GP 部分对比 RBF、Matern、White Noise、Linear 四种核函数组合。逆动力学 ground truth 由测力板 + 三维运动捕捉解算获得。

**意义**：把不确定性显式建模引入外骨骼辅助决策，对按需辅助（AAN）与安全人机交互具有直接价值。
