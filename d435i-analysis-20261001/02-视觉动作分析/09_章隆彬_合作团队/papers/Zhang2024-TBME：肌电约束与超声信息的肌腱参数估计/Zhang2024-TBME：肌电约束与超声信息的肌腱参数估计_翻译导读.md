## 一、方向判定

**Hill 型肌骨骼建模 + 直接配点最优控制 + EMG/超声多模态融合** 的受试者特异性参数标定工作；与 ViKiT 共享"生物力学 grammar / 解剖感知建模"的底层范式，但不涉及"视觉 → 关节角"的 Seq2Seq 翻译主线。

## 二、解决什么问题

通用人体测量缩放（anthropometric scaling）得到的肌腱参数（F_max、最优纤维长度 l_M,opt、肌腱松弛长度 l_TS、肌腱刚度 k_T）无法反映**脑卒中后踝跖屈/背屈肌群的继发性力学改变**（无力、肌腱硬化等）；已有 EMG 驱动标定（Pizzolato CEINMS）缺少**肌纤维长度**这一关键约束，Delabastita 2024 超声+EMG 方法仅在健康人中验证。本研究提出首个**面向脑卒中后患者的 EMG + 超声双约束肌肉冗余求解器**，以估计受试者特异性肌腱参数并揭示卒中后 MTU 的形态/力学改变。

## 三、使用方法

- **Hill 型肌肉模型 + 直接配点最优控制（direct collocation）**：在修改版 OpenSim gait10musc18 模型上，把多关节等长收缩试验的 EMG、肌纤维长度、关节力矩统一编入单一 OCP，状态量 = (激活 a, 肌腱力 F_T)，控制量 = (兴奋 e, 残余力矩 τ_res)。
- **多目标代价函数加权**：J_EMG（兴奋追踪）+ J_FL（纤维长度追踪）+ J_effort（正则化）+ J_res（储备执行器正则化）；权重逐受试者微调。
- **生理约束**：l_M,opt ∈ [0.4·l_max, 1.2·l_max]、GAS/SOL 共用跟腱故 k_T / l_TS / l_M,opt 与通用值的比相同、e & a ∈ [0,1]。
- **求解栈**：梯形配点（10 ms 网格）→ 大规模稀疏 NLP → IPOPT + CasADi 自动微分。
- **试验装置**：IsoMed 2000 测力仪（30° 膝屈，多角度踝位）+ Noraxon sEMG（3000 Hz）+ Mindray M9 超声（UltraTrack 自动追踪肌纤维长度）。
- **评估协议**：留一交叉验证（75% 标定 / 25% 测试）对比"通用模型 vs 个性化模型"的 RMSE；Shapiro-Wilk + 配对 t/Wilcoxon + 双样本 t/Mann-Whitney U 检验。

## 四、核心内容概述

研究纳入 7 名脑卒中后受试者（轮椅 / 拐杖 / AFO 辅助）与 7 名健康对照，执行踝背屈 / 跖屈 MVC 试验，同步采集关节力矩、表面 EMG（GAS / SOL / TA）与超声肌纤维长度。**直接配点最优控制**求解以 EMG 与肌纤维长度为硬约束的肌肉冗余问题，输出受试者特异性肌腱参数。结果显示：

1. **脑卒中组 vs 对照组**：F_max、肌腱刚度 k_T、最优纤维长度 l_M,opt 均**显著降低**；肌腱松弛长度 l_TS 无显著差异。
2. **个性化 vs 通用模型**：个性化模型在纤维长度、关节力矩、肌激活三项 RMSE 上**均显著低于**通用缩放模型，DF 工况（TA）改善最显著。
3. 肌肉冗余求解器能恢复出与实验一致的力产生行为，提示**超声纤维长度是关键正则项**——没有它，EMG 缩放会吸收掉 F_max 的不确定性。
4. 卒中后个体肌腱参数呈现"低 F_max + 高刚度比例"的特征，提示肌腱粘弹性改变与肌肉无力共存，对个体化康复方案设计有直接启示。
