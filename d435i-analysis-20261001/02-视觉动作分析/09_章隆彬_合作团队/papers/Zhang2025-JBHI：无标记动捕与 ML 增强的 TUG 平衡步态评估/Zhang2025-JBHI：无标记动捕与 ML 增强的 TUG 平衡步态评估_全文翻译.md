## 摘要 [原文]

> **平衡与步态障碍是老年人跌倒的关键因素。** 用于评估跌倒风险的传统临床量表（如 **Berg 平衡量表 BBS**）通常**主观、耗时，且不评估步态表现**。虽然存在更短的评估方式（如**计时起立-行走测试 TUG**），但**多数临床医生只看完成时间**。本研究旨在**通过无标记动作捕捉（markerless MoCap）系统与机器学习模型增强传统 TUG 测试，开发一个快速、低成本、自动化的平衡功能评估与全面步态分析框架**。我们共纳入 **70 名**按 BBS 评分划分不同跌倒风险程度的受试者的 TUG 数据集。我们使用 MoCap 系统的数据，**自动将 TUG 试验分割为五个阶段**，并从各阶段提取特征。随后对这些特征进行分析，识别出**能显著区分高、低跌倒风险组**的特征。使用这些识别出的特征，我们测试了**多种机器学习模型**来估计 BBS 评分。无标记 MoCap 系统得到的标记点被用于详细的步态分析，并将**无标记方法与有标记方法的下肢运动学进行了比较**。我们的发现表明，**跌倒高风险个体的完成时间更长、运动速度更低、下肢关节活动范围更小**。在测试的机器学习模型中，**随机森林（random forest）在预测 BBS 评分上表现最佳（RMSE: 0.98, MAE: 0.38, R²: 0.94）**。此外，我们的无标记 MoCap 系统展现出**与最先进系统相当的准确度**，**无需粘贴标记点或传感器**。本研究结果可帮助开发面向老年人的**快速且客观的平衡与步态评估工具**，为改善筛查与干预规划提供定量数据。

## 一、临床背景 [原文]

### 1.1 BBS 与 TUG

| 量表 | 结构 | 局限 |
|---|---|---|
| **BBS** | **14 个任务**，每项 **0–4 分**（0 = 无法完成，4 = 流畅完成），**总分最高 56** | **主观、耗时，且不直接评估步态表现** |
| 临床上 | **BBS < 50 视为存在跌倒风险** | — |
| **TUG** | 包含**从椅子上站起、行走、转身、坐下** | 文献中 TUG 正常范围**跨度很大（10–25 秒）**；**可靠性随临床医生的判断而变化** |

**TUG 与 BBS 的关系**（原文立论依据）：已有研究显示 **TUG 与 BBS 强相关**，
因此 **TUG 可作为预测 BBS 结果的实用代理**；且 TUG 覆盖了 BBS 的多个组成要素
（坐位平衡、坐-站、站-坐、转身），从而**弥合了纯 TUG 完成时间评估与完整 BBS 评估之间的差距**。

> 💡 **对本库的意义**：这段论证**解释了为什么用 TUG 预测 BBS 是合理的**。
> 我方的**代偿评估**可类比这条逻辑——寻找一个**低成本、可自动测量**的代理指标，
> 去逼近一个**昂贵、主观的临床金标准**。

### 1.2 无标记 MoCap 的现状 [原文]

| 系统 | 机制 | 局限 |
|---|---|---|
| **OpenPose** | 检测 **25 个 2D 人体关键点** | 对**远端关节精度有限**；**在遮挡或复杂环境下表现不佳 [26]** |
| **Theia3D** | **预测 3D 关节位置** | 依赖**专有关键点**，且**只输出**（受限的） |
| **本文系统** | **训练于 RRIS40 数据集**；**直接输出虚拟标记点（virtual marker）** | 相比 Theia3D，本文系统**直接输出虚拟标记点**，从而可使用**为有标记数据开发了数十年的成熟分析方法** |

> 🔴 **这是本文最值得学习的设计决策**：
> **不输出关节中心，而输出「虚拟标记点」** —— 因为下游的生物力学分析方法（步态事件、关节角）
> 都是围绕**标记点**发展了几十年的。**输出虚拟标记点 = 免费继承整个成熟的下游工具链。**

## 二、方法 [原文]

### 2.1 TUG 五阶段自动分割

**原文明确**：`We segmented TUG into five phases`：

| # | 阶段 | 分割依据 [原文] |
|---|---|---|
| **1** | **起立（sit-to-stand）** | 用 **C7 标记点的垂直 Z 方向位置**：当 Z 开始上升即为起立开始 |
| **2** | **前行（forward walking）** | 从椅子站起后**向前行走 3 米**；用**足跟着地/足尖离地（heel strike / toe-off）**事件分割 |
| **3** | **转身（turning）** | 身体**旋转 180 度**；以「**转身开始**」与「**转身结束**」为界 |
| **4** | **走回（return walking）** | 转身后**走回 TUG 起点 3 米**；分割方式与前行相同 |
| **5** | **坐下（stand-to-sit）** | 与起立类似；**当 Z 方向开始下降即为坐下的开始** |

**步态事件分割** [原文]：使用**右脚踝与左脚踝信号**（结合 **C7 的 Z 位置**）自动识别
**RHS（右足跟着地）/ LHS（左足跟着地）** 等事件，用于前行与走回阶段的分割。

### 2.2 特征提取（共 85 个）

| 类别 | 特征 |
|---|---|
| 时间类 | 各阶段用时 |
| 步态相位时间 | **步态周期时间、站立相时间、摆动相时间、初始双支撑时间、终末双支撑时间、总双支撑时间**，及其**占步态周期的比例** |
| 转身类 | **转身步数（turn steps）**、**转身弧长（turn arc length）**、**转身速度**（弧长 ÷ 转身时间） |
| 距离类 | **步幅长（stride length）**、**步长（step length）**、**步宽（step width）**、**转身宽度（turn width）** |
| 速度/节奏 | 各阶段速度、**步频（gait cadence）** |
| **运动学类** | 下肢关节（**髋 F/E、膝 F/E、踝 D/P**）的**最小值、最大值、活动范围（ROM）** → **18 个特征** |
| 对称性 | **步态对称比、对称指数、步宽不对称指数** |
| **合计** | **85 个特征** |

### 2.3 特征筛选 [原文]

| 步骤 | 做法 |
|---|---|
| **去冗余** | 移除**相关系数 > 90%** 的特征对 |
| **判别力筛选** | 选择在**高/低跌倒风险两组间差异最显著（即 p 值最低）**的特征 |
| **最终特征集** | **18 个特征** |

**最终入选的 18 个特征包括** [原文]：步态对称指数、步宽不对称指数、
**右髋 F/E 的 ROM**、**左/右膝 F/E 的 ROM 与最小值**、**左踝 D/P 的 ROM 与最小值**、**右踝 D/P 的最大值** 等。

### 2.4 七种机器学习模型 [原文]

$$\texttt{LR,\ Lasso,\ RF,\ GBDT,\ XGBoost,\ KNN,\ SVR}$$

| 模型 | 原文描述 |
|---|---|
| **LR** | 线性回归。原文指出它是**误差最高、解释力最低**的 |
| **Lasso** | 带 L1 正则的线性回归 |
| **RF** | 随机森林。相比单棵决策树，RF 通过**集成平均**降低过拟合、提升预测精度 |
| **GBDT** | 梯度提升决策树，同样是集成方法，基学习器**各自在随机数据子样本**上独立训练 |
| **XGBoost** | 极端梯度提升。原文给出其目标函数（含正则项 $\Omega(f_k)$） |
| **KNN** | k 近邻回归 |
| **SVR** | 支持向量回归。目标是找到**最优超平面** |

**数据划分** [原文]：**80% 训练 / 20% 测试**。

**统计方法** [原文]：正态分布数据用**双样本 t 检验**，非正态数据用 **Mann-Whitney U 检验**；
显著性水平 **p < 0.05**。

## 三、结果 [原文]

### 3.1 BBS 评分预测（Table/Fig. 4）

**整体**：所有回归模型都有较高预测精度 —— **RMSE ≤ 1.62、MAE ≤ 1.38、R² ≥ 0.82**。

| 模型 | RMSE | MAE | R² | 原文评价 |
|---|---|---|---|---|
| **RF（随机森林）** ★ | **0.98** | **0.38** | **0.94** | **所有模型中 MAE 最低** |
| GBDT | 与 RF 相近 | — | — | 预测性能与 RF 类似 |
| KNN | 低 | — | 高 | 低误差、高解释力 |
| Lasso / SVR | 中 | — | 中 | 略优于 LR |
| **LR** | **最高** | **最高** | **最低** | 误差最高、解释力最低 |
| **XGBoost** | 较高 | — | 较低 | 误差较高、解释力较低 |

**原文归因**：**RF、GBDT、KNN 表现出低预测误差与高解释力**；**LR 与 XGBoost 误差高、解释力低**。

> ⚠️ **注意**：本库的速读卡 v1 只写了「Random Forest 最佳（RMSE 0.98, R² 0.94）」，
> **遗漏了两个关键信息**：① **MAE 0.38**；② **XGBoost（一个"更强"的现代算法）反而表现较差**。
> 后者是重要发现：**在这类小样本表格特征任务上，简单集成方法胜过梯度提升。**

### 3.2 无标记 vs 有标记 MoCap 的运动学对比 [原文]

| 项 | 值 |
|---|---|
| 样本 | **18 名受试者 / 163 个步态周期** |
| **整体平均 RMSE** | **5.06°** |
| **髋 F/E** | **RMSE 9.14°**（STD 3.55°，**ICC 0.99**） |
| **膝 F/E** | **RMSE 7.72°**（STD 2.45°） |
| 踝 D/P | **RMSE 低于髋与膝**（原文以其为对比基准） |
| 与 Theia3D 对比 | 本文 **平均 RMSE 小于 9.14°，与 Theia3D 相当** |

**系统性偏差模式** [原文]：
- **髋 F/E 在整个步态周期呈现「伸展偏移（extension offset）」**
- **膝 F/E 也表现出类似的伸展偏移**
- 踝 D/P 的误差模式与髋/膝不同

> ⚠️ **重要的解读纪律**：**髋 ICC 高达 0.99，但 RMSE 仍有 9.14°。**
> 这说明 **ICC 高 ≠ 绝对误差小** —— ICC 衡量的是**一致性/相关性**，不是绝对精度。
> → **我方的 `04_实验设计/评价指标.md` 已把 M1（MAE°）列为一级、M4（ICC）列为一级，
> 本例正好证明「必须同时报告 MAE 与 ICC，不可只用 ICC 下结论」。**

### 3.3 高跌倒风险组 vs 低风险组的差异 [原文，全部含 p 值]

| 维度 | 高风险组表现 | 显著性 |
|---|---|---|
| 各步态相位用时 | **更长** | **p < 0.01** |
| 站立相 / 初始双支撑 / 终末双支撑 / 总双支撑 **占比** | **更高** | **p < 0.01** |
| 起立、转身、步态、坐下**四个阶段的速度** | **更低** | **p < 0.01** |
| **步频（cadence）** | **更低** | **p < 0.01** |
| **转身步数** | **更多** | **p < 0.01** |
| 转身宽度、转身弧长、步幅长、步长 | **更小** | **p < 0.01** |
| **步宽（step width）** | **无显著差异** | **p = 0.37** |
| 步态对称比 | **无显著差异** | — |
| 步态对称指数 | **多数显著**（**但初始/终末双支撑时间及其占比、步幅长例外**） | — |
| **下肢关节 ROM**（髋 F/E、膝 F/E、踝 D/P） | **显著更小**（最小值显著更高） | **p < 0.01** |
| **最大髋 F/E** | **无显著差异** | **左：p = 0.82** |

> 🔴 **对本库的直接价值**：上表**用严格的统计检验（含 p 值）确认了「高风险 → ROM 更小、速度更低、时间更长」**。
> 这为我在 `04_实验设计/评价指标.md` 中把 **ROM violation rate** 与 **velocity error** 设为一级指标
> 提供了**第二份独立临床证据**（第一份是 KIST EMBC 2023 的步速数据：HC 102.9 vs AD 76.2 cm/s）。
>
> ⚠️ **同时必须注意「步宽无差异（p=0.37）」与「最大髋 F/E 无差异（p=0.82）」**：
> **不是所有直觉上的"代偿指标"都有统计支撑。** 我方选指标时必须以数据为准，不能凭直觉。

## 四、与 ViKiT（我方）的差异

**这篇是「潜在合作团队的临床基线」**，不是竞品 —— 下游任务不同（临床量表 vs 关节角序列），方法也不同（经典 ML vs Transformer）。

| 维度 | Zhang 2025 JBHI（原文实测） | ViKiT（我方） |
|---|---|---|
| **输入** | **无标记 MoCap 的虚拟标记点**（直接输出 marker，非关节中心） | **RGB 视频** |
| **输出** | **BBS 评分**（标量）+ 步态分析 | **关节角序列**（高维连续时序） |
| **模型** | **随机森林** + **85 个手工特征**（筛至 18 个） | Spatio-Temporal Transformer + cross-attention |
| **表征** | **人工设计的阶段特征** | **学习得到的 anatomy-aware tokens** |
| **端到端** | ❌ **三段式**（自动分割 → 特征工程 → ML） | ✅ 端到端 Seq2Seq |
| **物理约束** | ❌ 未提（ROM 只作为**输入特征**，不是约束） | ✅ **6 项 grammar loss** |
| **可解释性** | ✅ **强**（特征重要性 + p 值统计检验） | ❌ Transformer 黑盒 |
| **数据规模** | **70 人**（+ 19 名膝 OA 外部集） | 规划用公开数据 |
| **临床落点** | 评估侧：**跌倒风险筛查** | 评估侧：**代偿与运动质量** |

### 4.1 三条对本库有价值的推论

1. **"自动分段 + 手工特征 + Random Forest" 能拿到 R² = 0.94，且 MAE 仅 0.38。**
   这既是**鼓舞**（临床可及性高），也是**警告**：
   若我方用深度模型在同一任务上做不到同级精度，审稿人会问"为什么要用复杂模型"。
   → 我方**必须**论证：我们要的输出是**关节角序列**（连续、高维、时序），
   而不是**单一量表分数**（标量）。所以复杂度是**任务要求的**，不是方法炫技。

2. **XGBoost 反而比 Random Forest 差。**
   提醒我方：**在小样本表格任务上，"更强的算法"未必更好**。这是一个反直觉但重要的先例。

3. **"输出虚拟标记点"而非关节中心，是一项高明的方法论设计。**
   → 我方 `03_方法设计/Anatomy_aware_Tokenizer.md` 的 **anatomy region 定义**可类比借鉴：
   **选择与下游成熟工具链兼容的表征，而不是"更本质"的表征。**
