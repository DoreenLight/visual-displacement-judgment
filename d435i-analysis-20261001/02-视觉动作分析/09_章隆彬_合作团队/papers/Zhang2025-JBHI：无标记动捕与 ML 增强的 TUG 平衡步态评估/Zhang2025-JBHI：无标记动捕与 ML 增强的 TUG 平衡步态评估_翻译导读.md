## 一、方向判定

**临床康复评估 × 无标记 MoCap × 经典表格 ML**：论文输入是 RRIS40 训练的无标记动捕系统输出的**虚拟标记点序列**，输出是**BBS 跌倒风险评分（标量）**与**步态指标**，方法为「自动相位分割 → 85 维手工特征 → 7 个浅层 ML 模型」三段式流水线。属于**临床生物力学**与**计算机视觉（动捕）**的交叉，**不涉及端到端深度模型**，亦**不直接预测关节角序列**。

## 二、解决什么问题

1. **BBS 量表**虽为跌倒风险金标准，但 14 题主观打分、约 15–20 分钟耗时，且**不评估步态**；
2. **TUG 测试**虽快速，但临床医生**多数只盯完成时间**，丢失相位、步态、对称性等全部运动学信息；
3. 现有基于 marker 的 3D 动捕（如 Vicon）虽准，但**贴标记、专用场地、昂贵**，无法下沉到社区筛查；
4. 现有无标记方案（OpenPose / Theia3D）要么**远端关节精度差**，要么**输出专有关键点不兼容既有生物力学工具链**。

论文目标：**用一套无标记 MoCap + 自动分段 + 经典 ML，把 TUG 从「单一计时」升级为「自动 BBS 估计 + 全量步态分析」**，且精度可与有标记系统对标。

## 三、使用方法

- **无标记 MoCap 系统**：训练于 RRIS40 数据集，**直接输出 virtual markers（虚拟标记点）而非关节中心**——关键设计决策，免费继承有标记生物力学下游工具链。
- **TUG 五阶段自动分割**：① sit-to-stand（用 **C7 标记点的垂直 Z** 上升判起立开始）；② forward walking 3 m（用**踝标记点 + heel strike / toe-off** 事件分割）；③ turning（身体旋转 180°）；④ return walking 3 m（同 ②）；⑤ stand-to-sit（C7-Z 下降判坐下开始）。
- **85 维特征提取**：时间类（各阶段用时）/ 步态相位时间（步态周期、站立相、摆动相、双支撑，占比）/ 转身类（turn steps、arc length、speed）/ 距离类（stride、step、step width、turn width）/ 速度节奏（cadence）/ **下肢运动学类**（髋 F/E、膝 F/E、踝 D/P 的 min、max、ROM，共 18 维）/ 对称性。
- **特征筛选**：① 移除 **相关系数 > 90%** 的冗余对；② 按**高/低跌倒风险组的双样本 t 检验或 Mann-Whitney U 检验 p 值**排序；最终保留 **18 维**特征（含步态对称指数、步宽不对称指数、髋膝踝 ROM 与极值）。
- **7 个 ML 模型对比**：**LR、Lasso、RF、GBDT、XGBoost、KNN、SVR**；数据划分 80/20，显著性阈值 p < 0.05。
- **运动学验证**：以 Vicon 有标记系统为参考，对 18 名受试者 163 个步态周期计算**逐关节 RMSE 与 ICC**（整体 5.06°；髋 F/E RMSE 9.14° ICC 0.99；膝 F/E RMSE 7.72°）。

## 四、核心内容概述

**摘要（精炼）**：纳入 70 名按 BBS 分层的受试者，使用 RRIS40 训练的无标记 MoCap 系统采集 TUG；自动 5 阶段分割 + 85→18 维特征筛选 + 7 模型对比；**随机森林以 RMSE 0.98、MAE 0.38、R² 0.94 取得最佳 BBS 预测精度**；**无标记系统平均 RMSE 5.06°，与 Theia3D 相当**，且无需贴标；统计检验确认**高跌倒风险组完成时间更长、各相位速度更低、cadence 更低、转身步数更多、下肢关节 ROM 显著更小**（p < 0.01），但**步宽（p=0.37）与最大髋 F/E（p=0.82）无显著差异**——说明并非所有直觉代偿指标都有统计支撑。

**关键发现**：
1. **XGBoost 表现反不如 RF**——小样本表格任务上，"更强的现代算法"未必更好；
2. **髋 ICC 高达 0.99 但 RMSE 仍有 9.14°**——ICC 衡量一致性而非绝对精度，**必须同时报告 MAE/RMSE 与 ICC**；
3. **"输出虚拟标记点而非关节中心"**是与 Theia3D 的核心方法论差异，决定了下游兼容性；
4. **伦理**：IRB-2023-02（NHG），资助方含 NTU / A*STAR / NHG / 健祥医院；外部对比集 19 名膝 OA 老人（香港理工 HSEARS20210715003-01）。
