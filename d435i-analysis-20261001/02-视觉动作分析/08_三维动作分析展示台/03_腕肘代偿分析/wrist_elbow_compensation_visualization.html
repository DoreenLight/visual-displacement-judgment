实验2：腕部-肘部运动轨迹建模与生物力学代偿判断报告

1. 动作机理与生物力学背景 (Biomechanics of Compensation)

本实验记录的是受试者在执行快速轮替前臂旋前-旋后翻转动作 (Rapid Forearm Pronation-Supination / Diadochokinesia)时的上肢运动。 在健康的孤立腕关节运动中，肘关节应保持静止锚定，完全依靠近侧和远侧桡尺关节完成旋转。 然而在本视频中，受试者表现出显著的腕-肘协同代偿 (Wrist-Elbow Synergistic Compensation)：为了辅助或替代前臂旋转活动度，受试者动用了上臂外展/内收、肘关节屈伸以及肱二头肌/肱桡肌联动，造成肘部在空间中发生大范围往复运动。

2. 动力学时程数学模型 (Harmonic Fourier Series Modeling)

将腕关节轨迹 $W(t)$ 与肘关节代偿轨迹 $E(t)$ 统一建模为宏观线性漂移项 (Linear Drift) 与周期性高阶简谐波动项 (Harmonic Oscillations)的叠加：

P(t) = c_0 + c_1 · t + ∑_{k=1}^K [ A_k · cos(2π·k·f_0·t) + B_k · sin(2π·k·f_0·t) ]
其中基频 f_0 = 1.15 Hz (动作周期 T = 0.87 s), 谐波阶数 K = 3

3. 双连杆上肢运动学几何正解 (Two-Link Serial Rig Kinematics)

肩关节锚点 S(t) = [X_s, Y_s, Z_s]^T
肘关节位姿 E(t) = S(t) + L_1 · u_upper(t),   其中上臂长 L_1 ≈ 295 mm
腕关节位姿 W(t) = E(t) + L_2 · u_forearm(t),   其中前臂长 L_2 ≈ 265 mm
肘关节屈伸角 θ_e(t) = arccos( (S - E) · (W - E) / (||S - E|| · ||W - E||) )
