## 一、方向判定

**交叉方向：上肢康复运动分析 ∩ 骨骼点序列分类。** 属于「基于骨架数据的动作识别」与「脑卒中代偿检测」的交叉任务，与 ViKiT 关注的上肢康复场景高度同源，但范式不同——本文输出是「代偿类别（NC/TLF/TR/SE）」的判别标签，而非 ViKiT 所追求的「关节角度序列」的结构化翻译。

## 二、解决什么问题

针对脑卒中患者康复训练中普遍存在的**代偿运动**（Trunk Lean-forward, Trunk Rotation, Shoulder Elevation）进行**自动检测**，以替代医生一对一人工观察，降低康复指导成本，特别支持居家康复场景下的辅助判断。

## 三、使用方法

- **多视角 Kinect 采集系统**：3 台 Azure Kinect（320×288 @ 30Hz，0.5–5.46m 范围）从不同视角同步采集三维骨骼点数据，避免单视角遮挡漏检。
- **骨骼数据预处理**：欧氏距离关键帧截取 + 滑动窗口去冗余 + 三次样条时间归一化 + Z-score 坐标归一化；选取上肢 20 个关节构成解剖学拓扑图。
- **GCN-LSTM-ATT 模型**：图卷积网络（GCN）建模关节间**空间拓扑依赖** + 长短期记忆网络（LSTM）捕获**时间动态** + 注意力机制（ATT）自适应加权重**关键帧**，三者级联构成端到端分类网络。
- **对比基线**：SVM、KNN、Random Forest 三种传统 ML 算法；并对 GCN / GCN-LSTM / GCN-LSTM-ATT 做消融实验。
- **双专家标注机制**：两位资深康复医生独立标注 + 交叉核对，FMA-UE 量表评分取均值。
- **实验范式**：15 名脑卒中患者（Brunnstrom ≥Ⅱ），每动作重复 6 次，三个标准康复动作（触摸嘴、手臂外展 90°、向后伸展 45°）对应三种代偿类别，8:2 划分训练/测试集。

## 四、核心内容概述

摘要精炼：本文提出**图卷积长短期记忆注意力网络（GCN-LSTM-ATT）**用于基于骨骼数据检测脑卒中后代偿运动。招募 16 名脑卒中患者，采用 Kinect 深度相机采集康复训练中的骨骼数据，分别用 GCN-LSTM-ATT、SVM、KNN、RF 构建检测模型。结果表明 GCN-LSTM-ATT 检测准确率达 **0.8580**，显著优于三种传统 ML 方法（SVM 最佳仅 0.7901）；消融实验验证了 GCN（基线 0.5679）、LSTM（+0.278）、ATT（+0.012）三组件的协同价值。

主要发现：
1. **GCN 是基础**：单独 GCN 在该任务上准确率仅 0.5679，说明纯空间拓扑对代偿识别远不够；
2. **LSTM 是关键增益项**：加入 LSTM 后跳升至 0.8457（+27.8pp），印证代偿识别的核心信号在**时序动力学**而非静态姿态；
3. **ATT 提供边际提升**：再叠加注意力达 0.8580（+1.2pp），主要作用是聚焦代偿发生的关键帧；
4. **临床应用意义**：提出了一种非接触、非穿戴、低成本的自动代偿检测方案，可替代人工观察并支持居家康复。

## 五、与 ViKiT（视觉位移判断）项目的关联

**直接场景关联——上肢代偿识别：**
本文核心场景正是 ViKiT 应用目标之一（上肢代偿检测），所识别的 TLF/TR/SE 三类代偿恰是腕关节/上肢康复中需要联合监测的补偿行为，可作为 ViKiT 输出角度序列之后的「高层语义判决」模块或联合训练的辅助监督。

**范式差异——分类 vs Seq2Seq 翻译：**
本文是「骨架序列 → 类别标签」的判别式分类任务，输出是离散 4 类（NC/TLF/TR/SE）；ViKiT 追求「视觉视频 → 连续关节角度序列」的结构化 Seq2Seq 翻译，输出是带解剖/物理约束的连续值。两者的解码 grammar 完全不同：本文仅需 softmax 分类头，ViKiT 则需要融入 ROM 约束、关节层级、速度约束、FK 一致性等生物力学 grammar。本文可作为 ViKiT 的**下游任务**或**后处理模块**（角度序列 → 代偿分类），但不可替代其核心翻译范式。

**数据通路差异——骨架后处理 vs 端到端视觉：**
本文依赖 Kinect SDK 提取 32 关节 → 筛 20 个上肢关节坐标，已脱离原始 RGB/Depth 信号；ViKiT 锚定 D435i 端到端 RGB-D 输入以规避「3D pose pipeline 误差累积」问题（呼应 Chao 2026 击败两阶段 pipeline 的论点）。本文两阶段路线（视觉 → 骨架 → 分类）在 Kinect 标定精度受限及遮挡场景下可能成为天花板，这恰是 Chao 2026 端到端 RGB Transformer 的论证起点。

**模型组件的启发——GCN/LSTM/ATT 三件套：**
- **GCN 部分**对应 ViKiT「解剖感知 tokenizer」的另一种实现路径：将人体运动链编码为图结构再聚合，可与 ViKiT 按人体运动链组织视觉 token 的思路互为印证，但 ViKiT 应当采用视觉 token 而非骨架 token 以保留端到端优势。
- **LSTM + ATT**对应 ViKiT decoder 的时序建模组件。本文 LSTM 带来 +27.8pp 的巨大增益，再次验证**代偿/异常动作识别高度依赖时序动力学**——这正是 ViKiT 强调「因果时序预测 Visual_{t-k:t} → Kinematics_{t:t+h}」合理性的旁证。
- **本文 ATT 仅带来 +1.2pp 边际提升**，提示 ViKiT 在注意力机制设计上需更激进（多尺度、跨关节、跨层级），不能仅做时间维度的简单加权。

**采集设备差异——Kinect 三机位 vs D435i：**
本文用 3 台 Kinect 多机位方案规避单视角遮挡；ViKiT 采用单台 D435i，更具便携性与居家康复适配性，但需在算法层补偿单视角深度歧义。本文多机位策略可作为 ViKiT 居家化部署前的**对照基线**。

**与 Chao 2026 的对比定位：**
Chao 2026 是端到端 RGB → 关节角（ICC>0.92）；本文是骨架 → 类别（Acc 0.858）。两者不在同一任务层级，但本文的代偿分类精度 0.858 表明：即使跳过角度估计、直接做高层分类，仍有 ~14% 的代偿漏检风险。ViKiT 若能给出可解释的关节角 + FK 一致性输出，将为代偿检测提供比分类标签更丰富的**几何可解释证据**（如「肩抬高 + 躯干前倾同时超过阈值」的可验证规则）。
