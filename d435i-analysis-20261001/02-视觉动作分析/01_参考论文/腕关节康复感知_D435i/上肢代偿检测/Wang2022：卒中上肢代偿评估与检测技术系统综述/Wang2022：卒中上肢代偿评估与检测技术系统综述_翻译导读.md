## 一、方向判定

**系统综述 + 临床证据评级**，交叉于「**康复工程 · 卒中代偿检测 · 传感技术选型**」。本篇不属于 Seq2Seq 方法论文，但为本项目「上肢代偿检测」子模块提供**领域级共识底座**——代偿分类学、技术路线占比、最高频观测指标、稀疏传感器布置原型均出自此处。

## 二、解决什么问题

卒中后幸存者在完成指定上肢任务时，常出现两类偏离正常运动链的现象：**患侧失用**与**替代性运动策略（即代偿）**。本研究回答：

1. 文献中存在哪些**基于技术的代偿评估方法**？技术路线如何分布？
2. 已识别的**代偿类型**有哪几种？**观测焦点**（哪些关节/节段）出现频次最高？
3. **统计方法 vs 机器学习**两种范式在代偿评估中的占比与异质性如何？
4. **稀疏多传感器布置**是否存在领域共识？

→ 为「视觉/可穿戴代偿检测」赛道提供**领域地图**，解决「该问题是否成立、有无标准观测对象、有无主流技术路线」的**前置判断**问题。

## 四、核心内容概述

> **方法**：系统检索文献，由 2 名评审者独立筛选、第三名参与仲裁解决分歧，最终纳入研究按临床证据等级评级。
>
> **结果**：共纳入 **72 项研究**。识别出 **2 种代偿类型**——（1）**患侧上肢失用（disuse）**、（2）**替代性运动策略（compensatory movement）**。
> 技术路线分布：**体佩式技术 25/72（35%）**、**无标记视觉传感器技术 16/72（22%）**（第二大路线）、其余 43%。
> 评估方法分布：**统计方法 56/72（78%）**、**机器学习算法 15/72（21%）**，原文明确指出后者"**异质**"。
>
> **结论**：本系统综述为基于技术的代偿评估与检测的未来研究提供洞见。

## 五、与 ViKiT（视觉位移判断）项目的关联

| 关联点 | 具体启发 / 差异 |
|---|---|
| **技术路线定位** | 无标记视觉 22% 为**第二大路线** → 本项目选 **D435i**（RGB-D 无标记视觉）**符合领域主流**，非小众偏门。这是对竞品锚点 **Chao 2026 Measurement**（RGB + Transformer 端到端角度）路线合法性的**独立验证**。 |
| **代偿类型学** | 提供"失用 vs 替代策略"二分法 → 可作为 ViKiT 解码输出的**类别标签层**（或辅助 head）。 |
| **观测目标优先级** | 肩抬高占 59% → 本项目「**解剖感知 tokenizer**」应**优先在肩部节点（GH joint）分配视觉 token 预算**，并把肩抬高角速度作为 decoder 强约束项之一（**生物力学 grammar** 的候选规则）。 |
| **躯干指标清单** | 5 类躯干指标（角位移/线位移/前倾/屈曲/前移）→ 可纳入 decoder 输出空间或作为**辅助损失项**。 |
| **稀疏传感器布置原型** | Miller 5 点方案 → 对照本项目纯视觉路线，可作为「**未来融合的基线**」；与「胸/肩→上臂→前臂三段」概括需核正（见阅读建议）。 |
| **方法学位置** | ML 仅 21% 且**异质** → ViKiT 用 Transformer Seq2Seq 做代偿检测**属于少数派前沿**，**定义问题而非填空**。需在论文中显式说明这一位置。 |
| **与 Chao 2026 竞品差异** | Chao 是端到端 RGB→角度（单帧/单段，ICC>0.92）；本综述表明**代偿评估需要多关节联合观测**（肩+肩带+躯干）——ViKiT 的**多节点解剖感知 tokenizer + FK 约束**在代偿检测场景下比单关节端到端更合理。 |
| **sEMG 300ms 提前预测** | 本综述未涉及生物电信号通道 → 视觉代偿检测与 sEMG 提前预测的融合**尚属开放问题**，可作为 ViKiT 的差异化卖点。 |
