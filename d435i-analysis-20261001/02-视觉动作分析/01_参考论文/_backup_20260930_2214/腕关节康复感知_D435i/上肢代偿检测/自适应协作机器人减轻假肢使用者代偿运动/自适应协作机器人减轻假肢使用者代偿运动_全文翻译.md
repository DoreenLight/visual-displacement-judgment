# 通过自适应协作机器人减轻假肢使用者的代偿性运动

Marta Lagomarsino<sup>1</sup>、Robin Arbaud<sup>1,2</sup>、Francesco Tassi<sup>1</sup> 和 Arash Ajoudani<sup>1</sup>

摘要—假肢使用者可以恢复部分肢体功能，但很少能完全恢复自然肢体的活动能力，这往往导致代偿性运动（compensatory movements），进而引发不适、效率低下以及长期的身体负担。为解决这一问题，我们提出了一种新的人机协作框架，旨在通过利用上肢假肢使用者的残余运动能力并兼顾任务需求，来减轻其代偿机制。我们的方法引入了个性化的活动能力模型（personalised mobility model），用于量化特定关节的功能性限制以及代偿性运动的代价。该模型被集成到一个约束优化框架中，该框架计算任务执行时的最优用户姿态，在功能性与舒适性之间取得平衡。该解决方案引导协作机器人重构任务环境，促进有效的交互。我们使用一种用于单指截肢的新型体动力假肢装置（body-powered prosthetic device）对框架进行了验证，该装置通过与手的协同闭合来增强抓握能力，但会对腕部施加约束。在健康受试者将该假肢作为额外手指（supernumerary finger）佩戴的初步实验中，证实了嵌入用户特异性活动能力模型的机器人助手在交接任务中优于人类伙伴，既提高了假肢使用者抓握的效率，又减少了功能关节的代偿性运动。这些结果凸显了协作机器人作为有效的工作场所和护理助手的潜力，有助于促进包容性以及将假肢装置更好地融入日常任务中。

关键词—机器人辅助活动能力；人机接口与机器人应用

## I. 引言

肢体或手指的丧失对个体的身体能力和心理健康产生深远影响。假肢装置旨在通过恢复功能并使用户重新获得日常生活和工作相关活动中的独立性来缓解这些问题。假肢可分为三类：被动式、自身动力式和外部动力式[1]。被动式装置主要侧重于恢复外观而非机械功能[2]，但它们仍有助于恢复对向抓握能力[3]。相比之下，自身动力式装置利用另一块肌肉或肢体的运动来控制假肢，提供了一种机械上简单且功能性的解决方案[4]、[1]。外部动力式装置依赖驱动器（通常为电动或气动）来恢复更精细的控制和灵活性，尽管代价是复杂性增加、对电源的依赖以及更高的费用[5]、[6]。相比较而言，自身动力式装置由于其简单性和易用性，在功能性和可用性之间取得了平衡。

尽管假肢具有诸多益处，但它们仍远未能完全复制自然肢体的全部功能[7]。它们常常对用户的身体活动能力施加限制，导致代偿机制的产生，这些代偿机制可能涉及不舒适的非人体工程学姿势或低效的运动模式[8]、[9]。对于自身动力式系统而言尤其如此，因为其设计要求某些肌肉在原有功能之外还需用于控制假肢[10]、[11]。随着时间的推移，这些代偿行为可能导致劳损、不适，甚至长期的生理问题。不幸的是，这些挑战在假肢装置的设计和评估中经常被忽视。为了弥补这一不足，研究人体运动学如何有效适应残余损伤和假肢的局限性，为提升用户舒适度、效率及整体体验提供了契机。

除了个体适应之外，假肢使用者所处的环境（如工作场所、护理机构和家庭）也可以进行改造，以支持更符合人体工学且功能更佳的交互。在此背景下，协作机器人（CoBots）构成了一种有前景的解决方案 [12]。协作机器人已展现出通过在线自适应交互姿态 [13] 或在协同搬运和协同操作任务中优化共享运动动力学 [14]、[15] 来改善物理人体工学的能力。它们还通过调整协作机器人的接近度和反应性，在安全性、用户压力与生产力之间取得平衡，从而促进认知人体工学 [16]。虽然已有一些初步尝试旨在为有运动障碍的使用者提供便利，但这些方法通常侧重于用机器人系统完全替代受损肢体的功能 [17]、[18]，或在笛卡尔空间中限制受损手臂的运动 [19]。然而，此类策略忽略了假肢使用者所经历的关节级和任务特定的细微限制。此外，这些方法未能利用活动受限使用者的残余功能，可能会加剧其无能和受挫感。

本工作朝着应对这些挑战迈出了新的一步，提出了一种人机协作框架，帮助上肢假肢使用者克服关节级限制并利用其残余运动，同时避免有害的代偿机制。我们提出了一个针对假肢使用者关节特异性功能受限的模型，并对功能正常关节中代偿机制的成本进行了量化。该模型为一个优化问题提供依据，该问题在考虑任务约束的前提下，计算出以功能性且舒适的方式执行协作任务时的最优用户姿态。该解可引导机器人重新配置任务环境，从而促进推荐姿态的采用。最后，我们展示了一种面向单指截肢者的新型体动力假肢装置，旨在通过协同手部闭合来增强抓握能力，但会对腕部运动形成约束。该装置作为验证所提方法的测试平台。

## A. 假肢使用者运动学模型

本研究通过为每个关节分配一个局部坐标系来建模假肢使用者的运动学，其中 x 轴、y 轴和 z 轴分别定义外展/内收、屈曲/伸展和内旋/外旋的旋转轴，如文献 [20] 所述。为了考虑手臂的运动学冗余，手臂被表示为一个七自由度（Degrees-of-Freedom, DoF）系统，记为 $\pmb q ^ { H } \in \mathbb { R } ^ { 7 }$，由两个刚性连杆组成：上臂 $( l _ { \mathrm { h u m e r u s } } )$ 和前臂 $(  { l _ { \mathrm { r a d i u s } } } )$ [21]。

还为第五腰椎 L5 分配了一个坐标系，以通过第一个关节角度 $q _ { 1 } ^ { H }$ 和连杆 $l _ { \mathrm { s p i n e } }$ 来表示脊柱屈曲。这一纳入反映了文献中关于躯干运动增加作为代偿机制的重要作用 [11]。所得模型呈现 M = 8 个自由度，其中尺寸相关参数可以调整以适应不同的手臂和躯干尺寸。

肩部被建模为球窝关节，提供外展/内收 $( q _ { 2 } ^ { H } )$、屈曲/伸展 $( q _ { 3 } ^ { H } )$ 和内旋/外旋 $( q _ { 4 } ^ { \bar { H } } )$。肘部由一个铰链关节和一个旋转关节组成，允许前臂屈曲/伸展 $( q _ { 5 } ^ { H } )$ 和旋前/旋后 $( q _ { 6 } ^ { H } )$。最后，腕关节被建模为髁状关节，实现手的屈曲/伸展 $( q _ { 7 } ^ { \overline { { { H } } } } )$ 和尺偏/桡偏 $( q _ { 8 } ^ { H } )$。表 I 给出了该运动学模型所使用的 Denavit-Hartenberg（DH）参数。

假肢通过恢复部分功能来协助使用者，尽管它们可能无法完全复现自然肢体的活动能力，并且可能对相邻关节施加限制。例如，佩戴部分手部假肢可能会限制腕关节活动，进而导致肘部和/或肩部的代偿运动。为了在模型中捕捉这些约束，我们定义一个对角矩阵 $\mathbf { W } _ { \mathrm { i m p a i r e d } } ^ { H } \in \mathbb { R } ^ { M \times M }$。该矩阵通过优先考虑健康关节或假肢支撑关节的运动，并减少或完全限制受损或被锁定关节的活动度，来修正运动学模型。这为建模关节的部分或完全损伤提供了灵活性。对于完全丧失功能的关节，我们设 $\mathbf { W } _ { \mathrm { i m p a i r e d } } ^ { H } ( i , i ) = \mathbf { \bar { 1 } }$，而部分受损的关节则按比例定义，以反映除非必要否则倾向于最小使用的偏好。在临床实践中，标准化的损伤指数被用于评估关节炎、损伤或神经损伤等疾病患者的关节功能 [22]。这些指数可用于在 $\mathbf { W } _ { \mathrm { i m p a i r e d } } ^ { H }$ 中定义特定的关节限制，有助于将运动学模型个性化，以适应每位假肢使用者的特殊需求和能力。

代价 $\Psi ( k ) \in \mathbb { R }$，量化了时刻 $k$ 的代偿机制的影响，计算如下：

$$
\boldsymbol { \Psi } [ k ] = \left. \left( \mathbf { I } - \mathbf { W } _ { \mathrm { i m p a i r e d } } ^ { H } \right) \left( \pmb { q } ^ { H } [ k ] - \pmb { q } _ { \mathrm { n } } ^ { H } \right) \right. ^ { 2 } ,\tag{1}
$$

其中 $\pmb { q } _ { \mathrm { n } } ^ { H }$ 表示自然姿势，代表用户中性且舒适的臂部/躯干构型。该代价衡量了功能关节相对于该自然姿势的偏差。它与文献中已建立的度量一致，例如"瞬时关节使用量"（instantaneous joints usage）或"人体工程学代价"（ergonomic cost）[23], [13]，但此处通过引入考虑每个关节期望活动度的权重来加以精炼，如矩阵 $\left( \mathbf { I } - \mathbf { W } _ { \mathrm { i m p a i r e d } } ^ { H } \right)$ 所定义。这一修改提供了对舒适且功能性姿势对齐的更精确和个性化的评估，针对用户的特定损伤和需求量身定制。

## B. 面向假肢使用者的机器人反应式辅助

机器人主动引导的目标是以更有效的方式引导假肢使用者完成交互任务，避免因假肢施加或未能完全解决的身体限制而采取的不自然姿态。为此，机器人生成旨在促进人体采用该推荐构型的运动。最优姿态可最小化部分受损关节的使用，完全限制被锁定关节的运动，并在整个交互过程中促使健康的零空间关节（null-space joints）对齐到舒适且功能性的姿态。

机器人反应行为被建模为一个在线优化问题，该问题综合考虑了使用者的受损运动能力、运动学约束、任务需求以及安全距离阈值。该优化由以下代价函数与约束条件定义：

$$
\begin{array}{rlr}
\min_{\boldsymbol{q}^{H}} & \left\| \mathbf{W}_{\mathrm{impaired}}^{H}\left(\boldsymbol{q}^{H} - \boldsymbol{q}_{\mathrm{m}}^{H}\right) \right\|^{2} + \alpha \left\| \left(\mathbf{I} - \mathbf{W}_{\mathrm{impaired}}^{H}\right)\left(\boldsymbol{q}^{H} - \boldsymbol{q}_{\mathrm{n}}^{H}\right) \right\| \\
\mathrm{s.t.} & \boldsymbol{q}^{H} \in [\boldsymbol{q}_{\mathrm{min,impaired}}^{H}, \boldsymbol{q}_{\mathrm{max,impaired}}^{H}], \\
 & x_{\mathrm{obj}}(\boldsymbol{q}^{H}) \in \chi_{\mathrm{task}}^{R}, \\
 & p_{\mathrm{obj}}(\boldsymbol{q}^{H}) = p_{\mathrm{task}}, \\
 & d_{\mathrm{obj}}^{H} \geq d_{\mathrm{safe~th}}, \\
 & d_{\mathrm{elbow}}^{H} \geq d_{\mathrm{elbow~th}},
\end{array}
$$

其中 $q _ { \mathrm { m } } ^ { H }$ 是当前测量的人体姿态，$\pmb { q } _ { \mathrm { n } } ^ { H }$ 表示健康个体的自然舒适姿态。在代价函数中，第一项旨在最小化完全或部分受损关节相对于其当前构型的偏差。这通过矩阵 $\mathbf { W } _ { \mathrm { i m p a i r e d } } ^ { H }$ 实现，该矩阵根据每个关节功能受限的严重程度对平方距离进行加权，从而有效优先考虑对受损更为严重的关节位移的最小化。第二项则最小化代偿机制的代价 $\Psi$，即功能正常关节相对于标称最舒适的手臂/躯干构型的平方距离，并按其期望运动能力进行加权。参数 $\alpha \in \mathbb{R}$ 是一个缩放因子，赋予第二项较小的权重。这反映了在优先维持受损关节当前位置的同时，微妙地促进健康且不受限关节的舒适定位。

优化约束确保关节角度 $\pmb q ^ { H }$ 保持在可行的受限范围内，该范围通过缩减标准活动范围（RoM）以考虑用户特定的损伤。对于假肢使用者，通过使用矩阵 $\mathbf { W } _ { \mathrm { i m p a i r e d } } ^ { H }$ 修改健康关节边界 $\pmb { q } _ { \mathrm { m i r } } ^ { H }$ 和 $\pmb { q } _ { \mathrm { m a x } } ^ { H }$ 来建模这种缩减，如下所示：

$$
\begin{array} { r l } & { \pmb { q } _ { \mathrm { m i n , i m p a i r e d } } ^ { H } = \pmb { q } _ { \mathrm { m i n } } ^ { H } + \pmb { \mathrm { \bf W } } _ { \mathrm { i m p a i r e d } } ^ { H } \big ( ( \pmb { q } _ { \mathrm { m } } ^ { H } - \zeta ) - \pmb { q } _ { \mathrm { m i n } } ^ { H } \big ) , } \\ & { \pmb { q } _ { \mathrm { m a x , i m p a i r e d } } ^ { H } = \pmb { q } _ { \mathrm { m a x } } ^ { H } - \pmb { \mathrm { \bf W } } _ { \mathrm { i m p a i r e d } } ^ { H } \big ( \pmb { q } _ { \mathrm { m a x } } ^ { H } - ( \pmb { q } _ { \mathrm { m } } ^ { H } + \zeta ) \big ) , } \end{array}\tag{3}
$$

其中参数 $\zeta \in \mathbb{R}$ 允许对关节角度进行微调，即使在严重受损的关节中也是如此。任务特定约束确保物体或工具的位置 $\boldsymbol{x}_{\mathrm{obj}}$（在人与环境交互过程中将位于人手中，因此 $\boldsymbol{x}_{\mathrm{obj}} = \boldsymbol{x}_{\mathrm{obj}}(\boldsymbol{q}^H)$）位于机器人的任务空间 $\dot{x}_{\mathrm{task}}^R$ 内，并满足任务目标。具体而言，我们考虑对特定笛卡尔坐标 $p_{\mathrm{obj}} = \{x_{\mathrm{obj}}; y_{\mathrm{obj}}; z_{\mathrm{obj}}\} \in \mathbb{R}$ 施加等式约束以匹配任务需求 $p_{\mathrm{task}}$。最后，物体与用户身体之间的水平距离 $d_{\mathrm{obj}}^H \in \mathbb{R}$ 必须超过安全阈值 $d_{\mathrm{safeth}}$，并且用户肘部与骨盆之间的水平距离 $d_{\mathrm{elbow}}^H$ 必须超过 $d_{\mathrm{elbowth}}$，以确保合适的肘部姿态。

## C. 手指假肢系统

在本工作中，我们提出了一种新型的体驱手指假肢装置，专为增强单指截肢患者的抓握功能而设计，具有机械耦合机制，可实现与手的协同闭合。该假肢具有一个欠驱动的 3 关节手指，其运动由单一肌腱控制。当肌腱未被主动拉动时，弹性元件将手指带回张开位置。如图 2 所示，我们围绕腕部护具构建了一个可穿戴原型，并附有一个 3D 打印部件。该部件固定一个滑轮，肌腱通过该滑轮重新布线。肌腱的另一端连接到一个戒指上，用户必须将其戴在控制假肢的手指上。弯曲该手指将拉动肌腱并使假肢弯曲。此外，导螺杆机构可用于通过改变滑轮位置来调节肌腱的预紧力。为了进行测试，我们将设计的假肢作为附加手指安装在食指附近。这种配置允许非残障人士模拟假肢用户的体验。

需要注意的是，虽然假肢增强了抓握功能，但它也对腕部的屈伸和尺偏/桡偏施加了约束。这些限制可以通过将 $\mathbf{W}_{\mathrm{impaired}}^H$ 的最后两个对角元素设置为 1 来编码，从而告知优化过程腕部处于固定状态。

## III. 实验

## A. 实验设置与流程

为评估所提方法在实现与假肢设备功能性与舒适性交互方面的有效性，实验邀请了两名健康受试者参与<sup>1</sup>。受试者包括：受试者 1，身高 1.83 m 的 29 岁男性；以及受试者 2，身高 1.58 m 的 28 岁女性。刻意选择具有不同身体特征的受试者，以验证该方法适应多样化人体测量学特征的能力。

实验任务要求受试者抓握一把位于其骨盆不同横向距离处的热熔胶枪，即 $y _ { \mathrm { t a s k } } = \{ 0 . 0 5 \mathrm { m } ; - 0 . 2 0 \mathrm { m } ; - 0 . 4 5 \mathrm { m } \}$。为模拟较为真实的假肢使用场景，受试者在执行任务时佩戴所提出的假肢设备，将其配置为额外手指（见图 2）。任务开始前，受试者进行了与假肢的熟悉阶段。实验装置包括假肢使用者前方的一张桌子，桌面上标有三条胶带线，分别表示物体可能被递送的潜在横向方向。健康关节活动范围（RoM）参考文献 [24]，名义假肢使用者姿态 ${ \boldsymbol { q } } _ { \mathrm { n } } ^ { H }$ 基于快速上肢评估（RULA）工具 [25] 定义为最符合人体工学的姿态，其中肘部弯曲 $9 0 °$，其余关节角度均设为 $0 ^ { \circ }$。参数设置如下：$\alpha = 0 . 1 0$，$\zeta = 5 ^ { \circ }$，距人体骨盆的安全距离阈值 $d _ { \mathrm { s a f e t h } } = 0 . 2 0 \mathrm { m }$，以及 $d _ { \mathrm { e l b o w \ t h } } = 0 . 2 5 \mathrm { m }$

实验包含两个环节：人工传递（HP）和机器人传递（RP）。在 HP 环节中，由人类被试将物体传递给假肢使用者，每种横向距离 $y_{\mathrm{task}}$ 传递一次，模拟工业场景中人类同事或辅助场景中护理人员参与的传统交接情境。该条件下共招募了五名健康被试（四名男性和一名女性，年龄 28.2±2.4 岁）作为物体传递者。在 RP 环节中，任务由一台 Franka Emika Panda 机械臂（以 1 kHz 频率控制）协作完成，该机械臂配备 Robotiq 2-Finger Gripper 2F-85 夹爪。机器人在线求解式 (2) 所定义的约束优化问题，优化物体交接位姿，优化过程通过 C++ 环境中 ALGLIB<sup>2</sup> 库的增广拉格朗日方法实现。为确保执行过程的平滑性，采用 B 样条轨迹生成策略以达到优化后的交接位姿，并由机器人笛卡尔阻抗控制器进行跟踪，与文献 [16] 中的方法一致。机器人在不同 $y_{\mathrm{task}}$ 下重复执行物体传递任务五次，以保证与 HP 条件的对比具有一致性。

我们使用可穿戴式 MVN Biomech 套装（Xsens Technologies B.V.），该套装配备惯性测量单元传感器，用于测量身体节段长度并自动个性化假肢使用者的运动学模型与数字人偶网格。运动捕捉系统在实验过程中持续追踪假肢使用者的动作。事后统计分析将机器人辅助（RP）条件与基线的人工传递（HP）条件进行比较，重点关注在机器人行为中嵌入用户损伤模型所产生的影响。首先，采用 Anderson-Darling 检验对采集的数据进行正态性检验。若数据满足正态分布，则进行重复测量方差分析；若不满足正态性，则采用非参数的 Friedman 检验评估显著性差异。针对假肢使用者的运动计算了三项性能指标：

• 任务时长 $(T_f)$：假肢使用者完成接近与抓取阶段所耗费的时间，从抓取主体的首次运动开始测量，直至其完全掌控物体为止；

• 功能关节使用率 $(\bar{\Psi})$：在时长 $T_f$ 内（时间采样点 $k=1,\dots,K_f$）按式 (4) 计算：

$$
\bar{\Psi} = \frac{1}{K_f} \sum_{k=1}^{K_f} \Psi[k],\tag{4}
$$

其中 $\Psi[k]$ 为功能关节执行代偿机制所产生的代价，由式 (1) 定义；

• 关节运动平滑度 $(J)$：定义为：

$$
J = \Delta t \sum_{k=1}^{K_f} \| \ddot{\boldsymbol{q}}_{\mathrm{m}}^H[k] \|^2,\tag{5}
$$

其中 $\Delta t$ 是 Xsens 系统的数据采样率，$\ddot{\pmb { q }}_{m}^{H} \in \mathbb { R } ^ { M }$ 是由关节速度测量值数值推导得到的关节急动度（jerk）向量。

## IV. 讨论与结论

在本文中，我们提出了一种新颖的在线方法，用于缓解手臂活动受限的假肢使用者的代偿运动，这是一个常被忽视的问题，可能导致长期的伤害。我们的方法包括为假肢使用者构建个性化的活动模型，并将其集成到一个有约束的优化框架中。该框架以功能性和舒适性的方式计算执行任务时的最佳使用者姿势，同时考虑任务需求，并将相关信息传递给机器人，使机器人能够相应地重新配置任务，从而促进使用者采用该姿势。借助所提出的作为额外手指（supernumerary finger）的体力驱动手指假肢，我们在健康受试者中开展了初步测试，结果表明，嵌入了使用者特定活动模型的机器人助手表现优于人类伙伴。在减少功能性关节的代偿运动以及提升假肢使用者在交接任务中的抓握效率方面，均观察到了明显的改善。这些发现对于将协作机器人引入工作场所与护理辅助场景、推动包容性，以及促进假肢装置与使用者日常生活的无缝融合具有重要意义。尽管这些结果令人鼓舞，我们也观察到使用者在解决关节使用冗余方面存在一些偏差，从而导致性能上的细微差异。未来的工作将着重于为使用者提供配置其功能性关节的指导，可能通过我们在仿真中开发的视觉反馈界面，或振动触觉反馈系统[26]来实现。此外，我们计划将该框架应用于处理更复杂截肢情况的假肢装置（例如涉及肘部的截肢），并考虑部分损伤的情况。最后，我们旨在将本框架扩展到更复杂的交互任务，进一步评估其在多样化真实场景中提升假肢装置可用性的潜力。
