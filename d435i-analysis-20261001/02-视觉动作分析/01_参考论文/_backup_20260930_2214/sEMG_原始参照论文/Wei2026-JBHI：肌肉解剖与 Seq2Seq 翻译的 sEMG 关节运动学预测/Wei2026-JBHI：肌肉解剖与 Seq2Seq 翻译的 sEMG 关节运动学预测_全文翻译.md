## 摘要 [原文]

> 在康复机器人中实现**按需助力（Assist-As-Needed, AAN）控制**的关键，在于**准确预测患者的运动意图**。本研究**首次**从**序列到序列翻译**的视角重新定义了运动意图预测——把 **sEMG 信号类比为源语言、把关节角度类比为目标语言**。所提出的 **3DCNN-TF 模型**实现了**神经控制信号到运动学表征的精确翻译**。该模型由**三个模块**构成：
>
> 1. **sEMG「句子」生成模块**：把多个 sEMG 滑动窗口编制成一个"句子"；
> 2. **基于肌肉解剖与电极布置的 3DCNN 模块**：从"句子"中的每个"词"提取**肌肉协同（muscle synergy, MS）特征**；
> 3. **Transformer（TF）模块**：**自回归**地生成下一个关节角度作为翻译结果。
>
> 实验结果表明，在**跨不同速度**连续预测**腕、膝屈伸角度**的任务上，3DCNN-TF 相比**八个基线模型及既有研究**取得**更优的整体性能**。此外，3DCNN-TF 在**预测精度与计算效率之间取得最优平衡**，并展现**卓越的鲁棒性与泛化能力**。具体而言，3DCNN-TF 在腕部与膝部数据集上分别取得平均 **nRMSE/R² = (6.2% / 95.5%) 与 (5.5% / 96.2%)**，**平均训练时间不足两分钟**。更进一步，3DCNN-TF 能够**提前最多 300 ms 预测关节角度且不牺牲精度**——这对康复机器人中的**实时 AAN 控制**至关重要。

## 一、研究定位 [原文]

论文的核心贡献声明：

> **首次从 Seq2Seq 翻译的视角重新定义运动意图预测问题。**
> 具体而言，它改进了先前 3DCNN-BM [21] 中的 BM 模块，从而完成对 CNN-BM 框架的**全面改进**。
> 通过把 sEMG 信号与关节角度分别类比为**源语言**与**目标语言**，所提 **3DCNN-TF 模型把目标肌肉的解剖先验知识与 Seq2Seq 算法整合起来**，实现了从 sEMG 信号到**腕与膝**关节角度的**精确且具有预见性的翻译**。

### 1.1 对既有方法的三条批评 [原文]

| # | 批评 | 原文要点 |
|---|---|---|
| 1 | **RNN 的固有局限** | 循环结构导致**长程上下文记忆能力有限**、存在**梯度消失/爆炸**风险、**缺乏并行计算能力** |
| 2 | **既有 Transformer 工作只用编码器** | 研究 [7][17][18] 虽采用完整的编码器-解码器框架，但**都使用 Informer（InF）模型**。而 InF 的**稀疏 MSA 与蒸馏操作可能丢失细节信息**；且 InF 的解码器**以自回归方式生成输出**，**无法动态调整输出 [20]** |
| 3 | **sEMG 的非平稳性** | sEMG 的**非平稳性质要求精确捕捉短期序列**，因此该研究认为**自回归生成可能最大化预测精度** |

## 二、方法 [原文]

### 2.1 三个模块

| 模块 | 功能 |
|---|---|
| **① sEMG「句子」生成模块** | 把每个 sEMG 滑动窗口解释为一个 **"word（词）"**，在允许的预测延迟内把多个 "word" 编制成一个 **"sentence（句子）"** |
| **② 3DCNN 模块** | 基于**目标肌肉解剖与电极布置**，从句子中的每个 "word" 提取 **MS（muscle synergy）特征** |
| **③ Transformer（TF）模块** | 基于 MS 特征间的**全局上下文依赖**生成下一个关节角度 |

### 2.2 关键洞察：为什么用「句子」而不是单窗 [原文]

> 由于**仅依赖单个 sEMG 滑动窗口**的信息不足，本研究引入了**多窗口到多角度的句子级翻译框架**。
>
> 因此，**堆叠的多帧 sEMG 视频片段代表了目标肌肉在预测延迟内的三维动态收缩过程**。

### 2.3 TF 模块的五项关键增强 [原文]

原文明确列出 **five key enhancements（五项关键增强）**：

| # | 增强 | 内容 |
|---|---|---|
| 1 | **新增一个分段（additional segment）** | 用多个 "words" 构成一个 "sentence" |
| 2 | **单层结构** | 相关结构被设计为**单层**，**显著降低计算量** |
| 3 | **用 3DCNN 替换传统嵌入层** | 3DCNN 模块**取代 TFE 中传统的 embedding layer**，以提取 MS 特征作为输入表示 |
| 4 | **严格的时间因果掩码** | 把**因果掩码（causal mask）整合进 TFD**，在自回归生成期间**严格强制时间因果性** |
| 5 | **基于 Scheduled Sampling 的训练策略** | 在自回归生成过程中采用基于 **Scheduled Sampling [22]** 的策略，使模型能在推理时**动态调整下一次预测** |

> 💡 **第 4、5 项对我方特别有价值**：
> **「严格强制时间因果性」正是我在 `03_方法设计/Forecasting_Task.md` 中列为必须单元测试的项**——
> 种子论文已把它作为核心增强，说明**因果性是该范式的公认要求**，我方必须做且必须留证。

### 2.4 3DCNN 模块细节 [原文]

| 项 | 值 |
|---|---|
| **卷积核尺寸** | **4 × 6** |
| 归一化 | **Batch Normalization（BN）**，以增强训练稳定性 |
| 结构 | **三个残差块（three residual blocks）** |
| 通道数 | **64**, … |
| 建立依据 | 基于**目标肌肉解剖 + sEMG 电极布置**；电极位置通过**触诊 + SENIAM 指南**确定；由 **Complete Anatomy 软件（3D4Medical）**获得解剖信息 |

### 2.5 滑动窗口与超参 [原文]

| 项 | 值 |
|---|---|
| **IRASS（腕）滑窗** | **250 ms** |
| **EPIC（膝）滑窗** | **150 ms** |
| 窗口选择理由 | 控制系统的预测延迟；**窗口越短越容易，但过长会因 sEMG 非平稳性而降精度** |

## 三、数据 [原文]

### 3.1 IRASS 数据集（**腕**，自采）

| 项 | 值 |
|---|---|
| 来源 | 自采（University of Leeds） |
| **伦理批号** | **MEEC 18-002**（MaPS and Engineering Joint Faculty Research Ethics Committee） |
| 受试者 | **12 名（8 男 / 4 女）**，年龄 **28.9 ± 2.8 岁** |

| 项 | 值 |
|---|---|
| 来源 | **公开数据集，EPIC Lab [23]** |

| **本研究选用** | **12 名（6 男 / 6 女）** —— 为与 IRASS 的受试者数保持一致 |
| 任务 | **平地行走（level-ground walking）** |

| 重复 | 每个速度下**顺时针与逆时针各 5 次** |

### 3.3 信号预处理 [原文]

- sEMG 有效频带为 **20–400 Hz**，该范围外的成分**主要是运动伪影与噪声 [25]**
- **20–400 Hz 带通滤波** + **50 Hz 陷波**消除工频干扰
- 电极位置**剃毛并用酒精清洁**
- 所得信号用于获得更平滑的 sEMG

## 四、实验设置 [原文]

### 4.1 八个基线模型（完整名单）

> **这是复现对照的关键信息** [原文]：

$$\texttt{3DCNN-InF,\ 3DCNN-TFE,\ 3DCNN-BM,\ TF,\ TFE,\ CNN-TFE,\ CNN-BM,\ TCN}$$

| 基线 | 含义 |
|---|---|
| **3DCNN-InF** | 3DCNN + Informer |
| **3DCNN-TFE** | 3DCNN + Transformer 编码器 |
| **3DCNN-BM** | 3DCNN + BiLSTM（原文的**主要对照**，且**3DCNN 部分沿用其先前工作 [21]**） |
| **TF** | 纯 Transformer |
| **TFE** | Transformer 编码器 |
| **CNN-TFE** | CNN + Transformer 编码器 |
| **CNN-BM** | CNN + BiLSTM（本文的**基础框架**） |
| **TCN** | 时间卷积网络 |

### 4.2 评价指标 [原文]

| 项 | 说明 |
|---|---|
| **nRMSE** | 归一化均方根误差。**因本研究涉及跨数据集比较，故选用 nRMSE 而非 RMSE** |
| **R²** | 决定系数，评估各模型的**整体拟合优度**，与 nRMSE 互补 |
| 显著性水平 | **0.05（\*\*\* p < 0.05）** |
| 额外惩罚项 | **训练时间被计入惩罚**，以反映实际应用对训练耗时的容忍度 |

### 4.3 硬件与复现 [原文]

| 项 | 值 |
|---|---|
| 计算平台 | **Google Colab** |
| GPU | **入门级 NVIDIA Tesla T4** |
| 说明 | 该选择是为了**确保可复现性与公平比较**，并贴近康复设备有限的计算资源 |

> 💡 **T4 入门级 GPU + <2 分钟训练**，这是种子论文明确主张的**效率优势**。

## 六、与 ViKiT（我方）的差异（v2 修正版）

**这篇是本知识库的种子论文**——我方整体范式的出处。差异论证的目标不是"我们不一样"，而是**"我们把它的范式迁到视觉域，并补上它缺的结构"**。

| 维度 | Wei 2026（sEMG 原型，原文实测） | ViKiT（我方） | 差异强度 |
|---|---|---|---|
| **输入模态** | sEMG（Delsys Trigno 2000 Hz / Biometrics 1000 Hz，**需贴电极**） | **RGB 视频（非接触）** | ✅ **根本差异** |
| **Seq2Seq 范式** | **首次提出（论文自称）** | 继承并迁移到视觉域 | ⚠️ **不是我方创新，必须显式承认** |
| **"词"的定义** | **滑动窗口（125–250 ms 的短时信号片段）** | **anatomy-aware 解剖单元**（运动链 token） | ✅ **我方最强切入点** |
| **解剖先验注入点** | 3DCNN 的 **4×6 卷积核**按肌肉解剖 + 电极布置组织 | **Anatomy-aware tokenizer** 按运动链切分 | ⚠️ 都做解剖感知，**注入模态不同**（肌肉 vs 关节链） |
| **时序模块** | Transformer（**单层** + 因果掩码，自回归） | 分解式时空 Transformer（6 层）+ cross-attention | ✅ 我方更深、且**双轴** |
| **物理约束** | **摘要与关键增强列表均未提** biomechanical grammar | **6 项 grammar loss** | ⚠️ **只知"未提"，不可断言它没有** |
| **提前预测** | ✅ **300 ms**（sEMG） | ✅ 100 / 200 / 300 ms（视觉） | ⚠️ **迁移，非首创** |
| **输出关节** | 腕（IRASS） / 膝（EPIC），屈伸单自由度 | 腕 / 肘 / 肩（上肢代偿，多关节协同） | ✅ 应用域差异 |
| **临床落点** | 康复机器人 **AAN 执行侧** | **评估侧**（代偿评估、运动质量） | ✅ 目标不同 |
| **训练成本** | **< 2 分钟 / Tesla T4** | 未测 | ❌ **我方需自证** |
| **跨速度验证** | ✅ 三速度（公开数据集） | 规划中 | ⚠️ 门槛 |

### 6.1 三条必须写进论文的诚实表述

1. **承认范式来源**：Seq2Seq 翻译范式由 Wei 2026 在 sEMG 域**首次**提出。我方是**跨模态迁移 + 表征层结构化**，**不是范式首创**。回避必被击穿。
2. **我方的真实新增量**：① "word" 从**时间窗**换成**有解剖语义的单元**；② 物理约束从**（可能存在的）隐含**升级为**6 项可审计的显式 grammar loss**；③ sEMG（需贴电极）→ **RGB（非接触）**，部署摩擦显著更低；④ 从**单自由度屈伸**扩展到**多关节协同代偿**。
3. **对标要公平**：必须复现它 8 个基线中的可复现者（`3DCNN-InF / 3DCNN-TFE / 3DCNN-BM / TF / TFE / CNN-TFE / CNN-BM / TCN`），否则"我们更好"无从谈起。

### 6.2 ⚠️ 必须正面处理的硬问题

> Wei 2026 的 **300 ms 提前预测 + <2 分钟训练 + R² > 95%**，是在 **sEMG** 上、用 **Tesla T4** 做到的。
> **sEMG 直接测肌肉激活（因果链上游），信息带宽远高于 RGB 视频（因果链下游）。**
>
> 因此我方若在 RGB 上达不到同级精度，**不能用"精度更高"作卖点**，
> 只能用 **"非接触 + 表征结构化 + 物理合法性"**，并**如实报告精度差距与算力差距**。
>
> → 已落到行动项：`04_实验设计/对比方案.md` 的 **V1（RGB vs sEMG 信息带宽差异）**。

### 6.3 🟢 可直接借鉴的一条方法论

**它的因果性设计**：把 **causal mask 严格整合进 TFD**，强制自回归生成期间的时间因果性，
并用 **Scheduled Sampling** 应对训练/推理分布不一致。

> **我方 `Forecasting_Task.md` 已把「因果性单元测试」列为必做交付物**——
> 种子论文的做法为此提供了**领域先例**，我方应引用它来论证该测试的必要性。
