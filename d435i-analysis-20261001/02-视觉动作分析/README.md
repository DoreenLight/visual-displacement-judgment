## 研究问题（v1）

> **Can human kinematics be treated as a structured biomechanical language, enabling visual motion sequences to be translated into temporally coherent and physically plausible joint-angle sequences through anatomy-aware sequence-to-sequence learning?**

中文版：

> **能否将人体运动学视为一种具有解剖结构和物理语法的"生物力学语言"，并通过解剖感知的 Seq2Seq Transformer，将视觉运动序列翻译为时序连续且物理合理的关节角度序列？**

完整论证见 [`00_研究背景/问题定义_视觉到关节角的翻译.md`](00_研究背景/问题定义_视觉到关节角的翻译.md)。

## 三个真正可站住的创新方向

1. **Visual–Kinematic Translation**  
   把 joint angle estimation 从「regression」升级为「跨表征 Seq2Seq translation」。

2. **Anatomy-aware Tokenization**  
   视觉 token 按人体解剖 / 运动链组织，而不是普通 image patches。

3. **Biomechanical Grammar**  
   把 ROM、joint hierarchy、velocity、acceleration、forward kinematics 等约束融入 decoder/loss，使翻译结果物理合理。

可选加分项：

4. **Causal Future Kinematic Translation**  
   `Visual_{t-k:t} → Kinematics_{t:t+h}` —— 视觉序列翻译为未来关节角度（呼应 sEMG 论文的 300 ms 提前预测）。

## 核心判断（来自前期对话）

- 「视觉替代 sEMG + Transformer」**不够新**——2026 Chao et al. 已经做了。
- 真正可做的，是把翻译范式从「命名上的比喻」升级为「结构上的实证」：两套 token system + cross-attention decoder + biomechanical grammar。
- 必读五篇（先验型）：Wei 2026 JBHI、Chao 2026 Measurement、HMR 2.0、TokenHMR、MotionBERT。
- 必须避免被审稿人挑战为「换名字的 regression」，所以 paper 里必须写出 ViKiT 与 Chao 2026 在 token / grammar / forecasting 上的**结构性差异**。
