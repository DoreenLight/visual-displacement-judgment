# 视觉位移判断

基于 RealSense D435i 深度摄像头的视觉位移 / 视觉动作分析研究项目，围绕上肢运动捕捉、腕关节康复感知与人体姿态估计展开。

> 本仓库为研究过程归档：研究笔记、方法设计、实验设计、实机验证数据与可复现脚本。

## 凭据说明

本仓库**不包含任何真实密钥**。脚本中的 API Key 一律以环境变量占位符形式引用：

- `06_附录/pdf2zh调用脚本/` 读取 `OPENROUTER_API_KEY`
- `09_章隆彬_合作团队/_research_run/config.yaml` 读取 `MINIMAX_API_KEY`

运行前请在本地导出对应环境变量；`.env` / `.secrets` / 私钥类文件已在 `.gitignore` 中防御性忽略。

## 2026-10-01 D435i 动作分析归档

最新工作入口：[`02-视觉动作分析/`](02-视觉动作分析/README.md)。包含实时反馈v5、八项训练的离线分析、轨迹稳定性探索，以及历史相机精度与个人长度角度换算。

本仓库保存代码、文档和派生数值结果。人体原始资料、实验照片/录像、Python环境、会话目录和运行日志保留在本地，不随本次分支上传。报告中的部分原始资料链接因此仅适用于本地工作目录；已有论文资料和非人体相机测试资料保留。分析结论的阶段及限制以各报告为准，不将工程探索当作正式准确性验收。
