# 常用 ROS2 配置与配方

> 解决 D435i 在 ROS2 中最常见的配置场景：深度对齐、点云、多机、回放、IMU。

## 1. 深度对齐到 RGB（align_depth）

### 1.1 场景

深度图分辨率 1280×720 但视场角 87°，RGB 视场角 69° → 不能直接对应像素。
**对齐后**：深度图被裁切到与 RGB 相同视场角，像素一一对应。

### 1.2 启动方式

```bash
ros2 launch realsense2_camera rs_launch.py \
    depth_module.depth_profile:=1280x720x30 \
    rgb_camera.color_profile:=1280x720x30 \
    align_depth.enable:=true
```

### 1.3 效果

| 没对齐 | 对齐后 |
|--------|--------|
| 深度图 1280×720 | 深度图被裁切到 1280×720 但视场角 = RGB |
| 像素坐标无法直接关联 | 像素一一对应 |

### 1.4 验证

```bash
# 看对齐后的深度话题
ros2 topic hz /camera/aligned_depth_to_color/image_raw

# 在 Rviz 里叠加 RGB + 对齐深度
# RGB 用 color_image_raw
# Depth 用 aligned_depth_to_color_camera_info 的内参
```

## 2. 点云发布

### 2.1 启动点云

```bash
ros2 launch realsense2_camera rs_launch.py \
    pointcloud.enable:=true \
    align_depth.enable:=true
```

### 2.2 两种点云

| 话题 | 来源 | 用途 |
|------|------|------|
| `/camera/depth/color/points` | 深度对齐到 RGB（XYZRGB）| 显示、可视化 |
| `/camera/depth/points` | 深度原始坐标系 | 算法后端 |

> 推荐用 `/camera/depth/color/points`，已经附色。

### 2.3 Rviz 可视化

```
Add → PointCloud2
  Topic: /camera/depth/color/points
  Color Transformer: RGB8
  Size (Pixels): 2
```

### 2.4 点云下采样

```bash
ros2 launch realsense2_camera rs_launch.py \
    pointcloud.enable:=true \
    decimation_filter.enable:=true \
    decimation_filter.magnitude:=2
```

`magnitude=2` 表示 2x4 下采样（4 个像素合并成 1），适合带宽紧的场景。

## 3. 滤波组合

### 3.1 推荐的滤波链

```bash
ros2 launch realsense2_camera rs_launch.py \
    pointcloud.enable:=true \
    spatial_filter.enable:=true \
    temporal_filter.enable:=true
```

| 滤波 | 作用 |
|------|------|
| `spatial_filter` | 空间去噪（边缘保留）|
| `temporal_filter` | 时序去闪 |
| `hole_filling_filter` | 空洞填充（最费 CPU）|
| `decimation_filter` | 下采样（降低数据量）|

### 3.2 调试参数

```bash
spatial_filter.holes_fill: 1         # 1=用左侧填充
spatial_filter.magnitude: 2          # 邻域大小
spatial_filter.smooth_alpha: 0.5     # 滤波强度
spatial_filter.smooth_delta: 20      # 深度差阈值

temporal_filter.smooth_alpha: 0.4
temporal_filter.smooth_delta: 20
temporal_filter.persistency_mode: 3  # 保留历史几帧
```

## 4. 多机配置

### 4.1 找 serial number

```bash
# 方式 1：realsense-viewer（GUI）
realsense-viewer

# 方式 2：CLI
rs-enumerate-devices -c

# 方式 3：ROS service
ros2 service call /camera/device_info \
    realsense2_camera_msgs/srv/DeviceInfo
```

### 4.2 启动多机

```bash
ros2 launch realsense2_camera rs_multi_camera_launch.py \
    camera_name1:=cam_front \
    camera_name2:=cam_back \
    camera1.serial_no:=213722067000 \
    camera2.serial_no:=213722068000
```

启动后命名空间：

```
/cam_front/camera/depth/...
/cam_back/camera/depth/...
```

### 4.3 TF 区分

```bash
# 查看完整 TF 树
ros2 run tf2_tools view_frames
```

每台相机有自己的 TF 子树：

```
world
└── cam_front/camera_link
    ├── cam_front/camera_depth_frame
    └── ...
└── cam_back/camera_link
    └── ...
```

### 4.4 多机硬件同步

```bash
ros2 launch realsense2_camera rs_multi_camera_launch_sync.py \
    camera_name1:=cam_left \
    camera_name2:=cam_right
```

注意：硬件同步需要相机间接线（SYNC 引脚），光靠软件同步做不到帧级同步。

## 5. IMU 配置

### 5.1 启用 IMU

```bash
ros2 launch realsense2_camera rs_launch.py \
    enable_gyro:=true \
    enable_accel:=true
```

### 5.2 IMU 话题

```bash
# 合并的 IMU 话题
ros2 topic echo /camera/imu

# 单独 accel
ros2 topic echo /camera/accel/sample

# 单独 gyro
ros2 topic echo /camera/gyro/sample
```

### 5.3 IMU 频率

```bash
ros2 launch realsense2_camera rs_launch.py \
    enable_gyro:=true \
    enable_accel:=true \
    imu_method:=linear_interpolation
```

D435i IMU 默认 200 Hz。SDK 不允许运行时改频率（已硬编码 200）。

### 5.4 IMU 话题合并度

```bash
# 各 IMU 组件独立话题
unite_imu_method:=copy    # accel/gyro 独立

# 合并为单一 IMU 话题
unite_imu_method:=linear_interpolation
```

## 6. Bag 回放

### 6.1 录制

```bash
# 录所有话题
ros2 bag record -a -o my_recording

# 指定话题
ros2 bag record \
    /camera/depth/image_rect_raw \
    /camera/color/image_raw \
    /camera/imu \
    -o my_recording
```

### 6.2 启动回放

```bash
# 方式 1：launch 文件
ros2 launch realsense2_camera rs_from_file.py \
    rosbag_filename:=/path/to/my_recording.mcap

# 方式 2：bag play + realsense2_camera
ros2 bag play /path/to/my_recording.mcap &
ros2 launch realsense2_camera rs_launch.py
```

### 6.3 反复回放（用于算法测试）

```bash
ros2 bag play -l /path/to/my_recording.mcap  # -l = loop
```

## 7. 调整曝光与增益

### 7.1 关闭自动曝光

```bash
ros2 launch realsense2_camera rs_launch.py \
    rgb_camera.auto_exposure:=false \
    rgb_camera.exposure:=100 \
    rgb_camera.gain:=64
```

### 7.2 关闭自动白平衡

```bash
ros2 launch realsense2_camera rs_launch.py \
    rgb_camera.auto_white_balance:=false
```

### 7.3 调试曝光问题

如果 RGB 颜色跳动，关闭 auto 后曝光更稳定。

## 8. 投射器控制

### 8.1 关闭 IR 投射器（户外用）

```bash
ros2 launch realsense2_camera rs_launch.py \
    depth_module.emitter_enabled:=0
```

注意：关闭后纯双目匹配，**低纹理场景深度会变差**。

### 8.2 交替模式（防干扰）

```bash
ros2 launch realsense2_camera rs_launch.py \
    depth_module.emitter_enabled:=2
```

`emitter_enabled=2` 表示每隔一帧切换一次投射器开关，**多机时避免红外干扰**。

## 9. URDF / TF 集成

### 9.1 安装 description 包

```bash
sudo apt install ros-<dist>-realsense2-description
```

### 9.2 在 robot_state_publisher 里用

```python
# robot_state_publisher 启动
ros2 run robot_state_publisher robot_state_publisher \
    /opt/ros/<dist>/share/realsense2_description/urdf/d435i.urdf.xacro
```

D435i 的 URDF 含物理尺寸与 TF 树。

### 9.3 校验 TF 树

```bash
# 在 Rviz 里看 TF，应看到
camera_link
├── camera_depth_frame
├── camera_color_frame
├── camera_infra1_frame
├── camera_infra2_frame
└── camera_imu_frame
```

## 10. 服务调用示例

### 10.1 读 IMU 校准参数

```bash
ros2 topic echo /camera/accel/imu_info
```

输出 JSON 含噪声密度、采样率等。

### 10.2 硬件监控

```bash
ros2 topic echo /camera/hardware_monitor
```

输出温度、功耗等指标。

## 11. 跨平台差异

| 平台 | 性能 | 注意点 |
|------|------|--------|
| Ubuntu x86_64 | ✅ 最稳定 | 推荐 |
| Ubuntu ARM (Jetson) | ✅ OK | 监控 CPU 温度 |
| Raspberry Pi 4 | ⚠️ 限制 | 降到 640×480 |
| macOS | ❌ 不支持 | libusb 兼容性问题 |

## 12. 调试清单

### 12.1 启动检查

```bash
# 1. 设备可见
ros2 topic list | grep /camera

# 2. 帧率达标
ros2 topic hz /camera/depth/image_rect_raw  # 应 30 Hz

# 3. TF 完整
ros2 run tf2_tools view_frames

# 4. IMU 频率
ros2 topic hz /camera/imu  # 应 200 Hz
```

### 12.2 性能检查

```bash
# CPU 占用
top

# 帧率
ros2 topic hz /camera/color/image_raw

# 话题带宽
ros2 topic bw /camera/depth/color/points
```

### 12.3 异常排查

| 现象 | 排查 |
|------|------|
| 启动失败 | `ros2 launch ... --log-level DEBUG` |
| 帧率掉到 < 10 | USB 带宽、CPU 饱和 |
| 点云错位 | 关闭 `align_depth` 再看 |
| IMU 没数据 | 检查 `enable_gyro/enable_accel` |
| TF 没发布 | `publish_tf:=true` |
