## 2. 核心发现：两个叠加的假噪声机制

这是本次测试最重要的技术结论。

### 2.1 现象：单像素很好，块级很差

| 目标 | 单像素时间 σ | 块级 MDR | 矛盾 |
|---|---|---|---|
| 3mm 杆 @ 228mm | **0.20 mm** ✅ | **25 mm** ❌ | 差 125 倍 |
| 桌面 @ 863mm | 4.14 mm | 1.29 mm | 正常 |

单像素读数很稳，但块级均值极差 —— 说明问题出在**聚合方式**，不是数据本身。

### 2.2 机制一：有效像素集合逐帧漂移

```
有效像素数波动: 6016 ± 125.0（范围 5615–6318）
```

细杆的深度读数**逐帧闪烁** —— 边缘像素在「有效」与「失效」之间跳变。
若逐帧用「当前帧所有有效像素」求均值：

- 这一帧可能含 5800 个杆像素 + 200 个背景像素（4000mm）
- 下一帧含 6000 个杆像素 + 0 个背景像素

**被平均的集合不同，均值就变了。** 200 个背景像素足以把 3200 像素的均值
从 228mm 拉到 250mm 以上。

**证据**：S1（裸有效均值）MDR = 199.7mm。

### 2.3 机制二：背景像素的「复活」注入远距离值

修掉集合漂移后（S3：固定像素集合），MDR 仍高达 **133mm** —— 几乎没改善。

这揭示第二个机制：**用「时间中值」填补缺失像素是错的。**

3300 个固定像素里约 1% 实际属于**背景**（读到 4000mm）。用时间中值填补，
等于让这些背景像素**持续以 4000mm 的值参与平均**。它们偶尔被正确读出时又跳回
228mm，造成巨大波动。

**证据**：S3（固定像素+中值填补）MDR = 133.0mm，与 S1 同级。

### 2.4 解法：S4 中值锚定截尾均值

```python
vv = sub[(sub > 0) & (sub < 65535)]      # 该帧所有有效像素
med_v = np.median(vv)                     # 用中值锚定（抗离群）
win = vv[np.abs(vv - med_v) <= 20.0]      # 只保留 ±20mm 窗口内的像素
result = win.mean()                       # 对窗口内求均值
```

**同时解决两个机制**：

| 机制 | S4 如何解决 |
|---|---|
| 集合漂移 | 中值锚定，窗口内的像素集合自然稳定 |
| 背景复活 | 背景像素（4000mm）落在 ±20mm 窗口外，被排除 |

**效果：MDR 从 199.7mm → 0.307mm，改善 651 倍。**

## 5. 未解决的边界（诚实声明）

### 5.1 本次只测了「静置」

本报告的全部数据是**静止**条件下的噪声底（MDR）。
**尚未测试「运动/位移」条件下的准确度** —— 即：
棍真的移动 2mm 时，读数是否也变化 2mm？

这需要精密平移台做**位移标定**（计划中的阶段 2）。

### 5.2 有效像素的边缘闪烁未被消除，只是被绕过

61% 的像素「≥90% 帧有效」，意味着 **39% 的像素不稳定**。
S4 通过中值锚定**绕过**了它们，但没解决根因。

**潜在风险**：如果杆移动较大距离（比如 20mm），中值锚定窗口（±20mm）
可能把真实位移也当作离群值排除。

**需要验证**：位移量接近窗口宽度时的行为。

### 5.3 尚未测「不同距离」对判定的影响

本次只测了 20cm。计划阶段 3 要测 150–1000mm 的完整曲线。

### 5.4 一个反直觉的观察待解释

单像素时间 σ：杆（0.20mm）比桌面（4.14mm）**好 20 倍**。

这不符合「近处更准」的直觉预期。可能原因：
- 白纸的漫反射特性优于木桌面
- 桌面的纹理对红外散斑匹配更差

**未验证**，但提示「距离不是唯一因素，表面材质影响可能更大」。

## 附：本次测试的方法论教训

1. **单像素 σ 与块级 MDR 可以相差 125 倍** —— 只看一个指标会得出完全错误的结论。
   必须同时报告：单像素时间 σ、块级 MDR、有效像素数波动。

2. **「修一个机制」不等于「问题解决」** —— S3 修了集合漂移却几乎无改善，
   因为还有第二个机制。诊断必须做到「改一处 → 看变化」，才能分离机制。

3. **抗离群统计量（中值）是对的方向，但量化损失不可接受** ——
   深度是 uint16 整数毫米，中值恒为整数，看不到亚毫米变化。
   正解是**用中值做锚点、用均值做精度**（S4）。

4. **中值填补固定像素集合是反模式** —— 它把离群值固化为常驻参与者。
