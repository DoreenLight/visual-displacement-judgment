# 多相机阵列方案

> 多 D435i 协同：立体深度、360° 环视、宽景拼接。

## 1. 为什么需要多相机

| 需求 | 单 D435i 限制 | 多机方案 |
|------|--------------|---------|
| 测距 > 3m | 最大 3m（误差大）| 双机立体 → 6m+ |
| 全覆盖 360° | 单机 FOV ~90° | 4-6 机环视 |
| 远距离三维 | 基线短（50mm）| 多机扩展基线 |
| 大场景拼接 | 单次扫描范围有限 | 多机协同扫描 |

## 2. 三种典型阵列拓扑

### 2.1 双机立体（远距离测距）

```
D435i 1 ◀──── 200-500mm ────▶ D435i 2
     │                          │
     └─── USB 3.0 HUB ──┐──────┘
                       ↓
                     PC
```

- 基线 200-500mm（远大于单机 50mm）
- 适合 5-15m 测距
- 两台相机间需要**外参标定**

### 2.2 360° 环视（室内建图）

```
            前 (Front)
              ↑
        左 ─ ─(左前)─ ─ 右 ─ ─(右后)
              ↓
            后 (Back)
```

- 4 台 D435i 装在机器人顶部
- 每台 FOV 87°，4 台拼接覆盖 360°
- 单台只跑 SLAM 自身片段，前端拼图

### 2.3 双机宽景（扩展水平 FOV）

```
     D435i 1 ◀──── 20° ────▶ D435i 2
     (偏左 30°)            (偏右 30°)
```

- 两机水平方向偏移，扩水平 FOV
- 适合机械臂顶视安装

## 3. 硬件同步方案

### 3.1 软件时间戳同步（入门）

```bash
# ROS2 multi_camera_launch.py
ros2 launch realsense2_camera rs_multi_camera_launch.py \
    camera_name1:=cam_left \
    camera_name2:=cam_right \
    camera1.serial_no:=213722067000 \
    camera2.serial_no:=213722068000
```

**原理**：依赖 host 时间戳，多台相机共享 PC 时钟。

**精度**：±5-20 ms（host 时钟抖动）

**优点**：无需接线，开箱即用

**缺点**：精度受 PC 时钟抖动影响

### 3.2 硬件触发同步（进阶）

需要拆开 D435i 主板，连 SYNC 引脚：

```
D435i Master (Cam 1)         D435i Slave (Cam 2)
┌─────────────────┐         ┌─────────────────┐
│   SYNC_OUT ──────────────▶ SYNC_IN        │
│   GND     ──────────────▶ GND             │
└─────────────────┘         └─────────────────┘
```

**原理**：主机 GPIO 输出脉冲，触发从机同步采集。

**精度**：±1 ms（硬件触发）

**实现**：

```bash
# 编译 librealsense 时启用 multi-camera 支持
cmake .. -DBUILD_TOOLS=ON

# 用 rs-set-multicam 工具
rs-set-multicam --master 1 --device 213722067000
rs-set-multicam --slave 2 --device 213722068000
```

**限制**：需要拆主板焊接，社区方案参考 librealsense issues/8558

### 3.3 双机选择

| 方案 | 适用 |
|------|------|
| 软件时间戳 | 单 PC、慢速机器人 |
| ROS2 ApproximateTime | 单 PC 多 USB |
| 硬件触发 | 多机快速同步需求 |
| 外部 NTP 触发 | 多 PC 分布式 |

### 4.2 验证同步

```bash

# 看时间戳差（用 message_filters）
```

```python
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from message_filters import Subscriber, ApproximateTimeSynchronizer

class SyncMonitor(Node):
    def __init__(self):
        super().__init__('sync_monitor')
        
        sub1 = Subscriber(self, Image, '/cam_front/camera/depth/image_rect_raw')
        sub2 = Subscriber(self, Image, '/cam_back/camera/depth/image_rect_raw')
        
        sync = ApproximateTimeSynchronizer([sub1, sub2], queue_size=10, slop=0.05)
        sync.registerCallback(self.callback)
    
    def callback(self, msg1, msg2):
        t1 = msg1.header.stamp
        t2 = msg2.header.stamp
        diff_ms = abs((t1.sec - t2.sec) * 1000 + (t1.nanosec - t2.nanosec) / 1e6)
        if diff_ms > 10:
            self.get_logger().warn(f'同步偏差 {diff_ms:.1f} ms')
```

### 5.2 双机立体深度重建

```python
import numpy as np
import cv2
from cv_bridge import CvBridge

class StereoDepth:
    def __init__(self, baseline_m=0.25, focal_px=386.738):
        self.B = baseline_m
        self.f = focal_px
        self.bridge = CvBridge()
    
    def compute_depth(self, left_img, right_img):
        """基础立体匹配"""
        # SGBM 立体匹配
        sgbm = cv2.StereoSGBM_create(
            minDisparity=0,
            numDisparities=128,
            blockSize=5
        )
        disparity = sgbm.compute(left_img, right_img).astype(np.float32) / 16.0
        
        # 视差 → 深度
        depth = np.zeros_like(disparity)
        valid = disparity > 0
        depth[valid] = (self.f * self.B) / disparity[valid]
        
        return depth  # 米
```

## 6. 环视拼接

### 6.1 4 机 360° 配置

```
              Front (cam_front)
                ↑
  Left ─── (cam_left)        (cam_right) ─── Right
                ↓
              Back (cam_back)
```

- 4 台 D435i 朝向 4 个方向
- 各 FOV 87°，相邻相机 FOV 重叠 30°+
- 用于 SLAM / 拼接 / 全覆盖监控

### 6.2 点云拼接

```python
import open3d as o3d
import numpy as np

class SurroundScanner:
    def __init__(self, extrinsics):
        """
        extrinsics: {
            'front': T_cam_to_world,
            'left': ...,
            'right': ...,
            'back': ...
        }
        """
        self.extrinsics = extrinsics
    
    def fuse(self, pointclouds):
        """4 个点云融合到世界坐标系"""
        fused = o3d.geometry.PointCloud()
        for direction, cloud in pointclouds.items():
            cloud.transform(self.extrinsics[direction])
            fused += cloud
        return fused
    
    def voxel_down(self, voxel=0.02):
        # 降采样后输出
        self.fused_dense = self.fused.voxel_down_sample(voxel)
        return self.fused_dense
```

## 7. 双机立体+RGBD 融合（高级方案）

```
D435i 1 (左)                D435i 2 (右)
  ┌──┐                       ┌──┐
  │  │  ← 基线 250mm →      │  │
  └──┘                       └──┘
    ↓                          ↓
  远距立体深度 (5-15m)         近距 RGBD (0.3-3m)
    ↓                          ↓
    └────── 融合 ──────────────┘
                  ↓
            完整深度感知 0.3-15m
```

实现思路：
1. 0.3-3m 用 RGBD 深度（高精度）
2. 3-15m 用双机立体深度
3. 在重叠区域融合

## 8. 多机带宽与算力

### 8.1 USB 带宽估算

| 配置 | 所需带宽 |
|------|---------|
| 1 × D435i @ 1280×720 depth + 1280×720 RGB | ~1.4 Gbps |
| 2 × D435i | ~2.8 Gbps |
| 4 × D435i | ~5.6 Gbps |

USB 3.0 总线带宽 5 Gbps → 4 机时接近上限，可能丢帧。

### 8.2 推荐

- **双机**：用 USB 3.0 HUB（带电源）
- **四机**：用独立 USB 3.0 端口（避免 HUB）
- **多 PC 分布式**：每 PC 接 1-2 机，NTP 同步

### 8.3 CPU 占用

| 配置 | CPU 占用 |
|------|---------|
| 单机 | ~10% (i7) |
| 双机 + 点云 | ~25% |
| 四机 + 点云 | ~50% |

Jetson Orin / AGX 可承受四机，但 Nano/PCIe 只适合双机。

## 9. 安装固定

### 9.1 机械固定

D435i 板上有 **2× M3 螺纹**，可装到固定支架：

```
        ┌──── D435i 主板 ────┐
        │   ┌─────┐  ┌─────┐ │
        │   │ IR  │  │ IR  │ │
        │   │ 左  │  │ 右  │ │
        │   └─────┘  └─────┘ │
        │                    │
       M3*2                 M3*2
        │                    │
        └────────────────────┘
```

### 9.2 推荐配件

- 1/4-20 UNC 标准三脚架适配器
- 自制 3D 打印支架
- 铝型材支架（刚性最佳）

### 9.3 减震

机器人上安装时建议加：

- 防震垫（橡胶/硅胶）
- 软性 USB 电缆
- 刚性安装面（避免柔性结构）

## 10. 应用案例

### 10.1 案例：四机环视 SLAM（移动机器人）

```
    Front
      ↑
   L ←──●──→ R
      ↓
    Back
```

- 4 台 D435i 顶部安装
- 各跑 RTAB-Map 子图
- 上层融合成全局地图

### 10.2 案例：双机立体测距（无人机）

```
   D435i 1         D435i 2
   (左倾 30°)      (右倾 30°)
       \             /
        \  ↘    ↙  /
         \  body /
        间距 200mm
```

- 无人机底部安装
- 双机立体测距 5-10m
- 用于避障

### 10.3 案例：机械臂双机协作

```
   顶视相机 D435i 1 (Eye-to-Hand)
        ↓
   ╔═══════════╗
   ║ 工作台     ║
   ║           ║
   ╚═══════════╝
        ↑
   腕部相机 D435i 2 (Eye-in-Hand)
```

- 顶视：粗略定位 → 工作空间映射
- 腕部：精细抓取 → 6DOF 位姿
