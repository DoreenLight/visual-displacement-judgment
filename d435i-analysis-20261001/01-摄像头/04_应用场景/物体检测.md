# 物体检测与机械臂视觉

> 用 D435i 做 2D 检测 + 3D 定位，再转换到机械臂坐标系做抓取。

## 1. 整体流程

```
RGB 图像 ─→ 2D 目标检测（YOLO / GroundingDINO）
                ↓ bbox (x, y, w, h)
深度图 ─→ 取 bbox 内点云 → 去噪 / 下采样
                ↓ 3D 中心点 / 6DoF 位姿
手眼标定矩阵 ─→ 转换到机械臂基坐标系
                ↓
MoveIt! 规划抓取轨迹
                ↓
机械臂执行抓取
```

ROS2 节点化：

```python
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from vision_msgs.msg import Detection2DArray
from cv_bridge import CvBridge
from ultralytics import YOLO

class YoloNode(Node):
    def __init__(self):
        super().__init__('yolo_detector')
        self.sub = self.create_subscription(
            Image, '/camera/color/image_raw',
            self.callback, 10
        )
        self.pub = self.create_publisher(Detection2DArray, '/detections', 10)
        self.model = YOLO('yolov8n.pt')
        self.bridge = CvBridge()
    
    def callback(self, msg):
        img = self.bridge.imgmsg_to_cv2(msg, 'bgr8')
        results = self.model(img, verbose=False)
        
        det_array = Detection2DArray()
        for box in results[0].boxes:
            det = Detection2D()
            det.bbox.center = [box.xywh[0][0], box.xywh[0][1]]
            det.bbox.size = [box.xywh[0][2], box.xywh[0][3]]
            det_array.detections.append(det)
        
        det_array.header = msg.header
        self.pub.publish(det_array)
```

## 3. 2D → 3D 转换

### 3.1 bbox 中心 → 3D 点

```python
import pyrealsense2 as rs
import numpy as np

def bbox_center_to_3d(depth_frame, intrinsics, bbox):
    """bbox = (x_min, y_min, x_max, y_max)"""
    cx = (bbox[0] + bbox[2]) // 2
    cy = (bbox[1] + bbox[3]) // 2
    
    # 取中心点 5x5 邻域深度均值（避免单点误差）
    h, w = depth_image.shape
    patch = depth_image[max(0, cy-2):cy+3, max(0, cx-2):cx+3]
    valid = patch[patch > 0]
    if len(valid) == 0:
        return None
    dist = valid.mean() / 1000.0  # 米
    
    pt_3d = rs.rs2_deproject_pixel_to_point(intrinsics, [cx, cy], dist)
    return pt_3d  # [X, Y, Z] 米
```

### 3.2 bbox 内点云 → 6DoF 位姿

```python
import open3d as o3d
import numpy as np

def bbox_to_object_pose(depth_frame, intrinsics, bbox, color_frame=None):
    """bbox 内点云 → 物体位姿（中心 + 主轴）"""
    x1, y1, x2, y2 = bbox
    h, w = depth_image.shape
    
    # 取 bbox 内的有效深度
    patch_depth = depth_image[y1:y2, x1:x2]
    valid_mask = patch_depth > 0
    
    # 构造 3D 点
    pts = []
    colors = []
    for j in range(y2 - y1):
        for i in range(x2 - x1):
            if valid_mask[j, i]:
                d = patch_depth[j, i] / 1000.0
                pt = rs2_deproject_pixel_to_point(intrinsics, [x1+i, y1+j], d)
                pts.append(pt)
                # 附加颜色（可选）
                # colors.append(color_image[y1+j, x1+i] / 255.0)
    
    pts = np.array(pts)
    pcd = o3d.geometry.PointCloud()
    pcd.points = o3d.utility.Vector3dVector(pts)
    
    # 中心
    center = pts.mean(axis=0)
    
    # PCA 主轴
    cov = np.cov(pts.T)
    eigvals, eigvecs = np.linalg.eigh(cov)
    main_axis = eigvecs[:, -1]  # 最大特征值对应的特征向量
    
    return {
        'center': center,        # [X, Y, Z] 米
        'axis': main_axis,        # 主方向
        'num_points': len(pts)
    }
```

## 4. 手眼标定

### 4.1 Eye-in-Hand vs Eye-to-Hand

```
Eye-in-Hand（眼在手上）：
    相机装在机械臂末端 → 相机随机械臂移动
    标定结果：相机 → 末端执行器 的变换

Eye-to-Hand（眼在手外）:
    相机装在工作台旁 → 不随臂动
    标定结果：相机 → 机械臂基座 的变换
```

D435i 在机械臂视觉中两种都用：

- Eye-in-Hand：常见于抓取相机随臂运动
- Eye-to-Hand：常见于相机固定俯瞰工作台

## 5. MoveIt! 集成

### 5.1 抓取流程（伪代码）

```python
from moveit.planning import MoveItPy

moveit = MoveItPy(node_name="moveit_py")
arm = moveit.get_planning_component("arm")
gripper = moveit.get_planning_component("gripper")

def grasp_object(object_center_in_camera):
    # 1. 相机 → 机械臂基座
    T_cam_to_base = handeye_transform  # 4x4
    T_obj_in_base = T_cam_to_base @ object_center_in_camera
    
    # 2. 接近位姿（物体上方 10cm）
    pre_grasp = T_obj_in_base.copy()
    pre_grasp[2, 3] += 0.1
    
    # 3. 抓取位姿
    grasp = T_obj_in_base.copy()
    grasp[:3, :3] = compute_grasp_orientation(object_axis)  # 旋转
    
    # 4. 规划 + 执行
    arm.set_goal_state(pose=pre_grasp)
    arm.plan() and arm.execute()
    
    arm.set_goal_state(pose=grasp)
    arm.plan() and arm.execute()
    
    # 5. 关闭夹爪
    gripper.set_goal_state("close")
    gripper.plan() and gripper.execute()
```

## 8. 检测精度优化

### 8.1 检测精度

| 改进 | 效果 |
|------|------|
| 提高 RGB 分辨率 | 小目标召回率 ↑ |
| 用语义分割（Mask R-CNN）| 边界更准 |
| 多角度融合 | 遮挡场景更鲁棒 |
| 加测距先验 | 远距离目标过滤 |

### 8.2 3D 精度

| 改进 | 效果 |
|------|------|
| 用 bbox 内深度均值而非中心 | 单点误差减小 |
| 用对齐深度（align_depth）| 像素对应准 |
| 平面拟合 | 抓取位姿更准 |
| 多帧融合 | 抖动场景稳 |
