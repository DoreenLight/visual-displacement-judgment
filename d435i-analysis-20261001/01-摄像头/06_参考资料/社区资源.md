## 8. 调试工具

### 8.1 自检工具

```bash
# realsense-viewer 可视化
realsense-viewer

# rs-enumerate-devices 设备信息
rs-enumerate-devices -c

# rs-record 录制
rs-record -f output.bag

# rs-convert 转格式
rs-convert -i output.bag -p output.ply
```

### 8.2 性能监控

```bash
# USB 带宽
lsusb -t

# CPU 占用
htop

# 帧率
ros2 topic hz /camera/depth/image_rect_raw

# 话题带宽
ros2 topic bw /camera/depth/color/points
```

## 9. 常见坑与陷阱（社区总结）

### 9.1 USB

- 必须 USB 3.0，蓝舌插口
- 不要用 USB HUB 串联多个 D435i
- 避免 USB 3.0 与 WiFi 干扰

### 9.2 IMU

- 出厂未校准，必须先跑 rs-imu-calibration
- 加速度计静止读 -9.8（不是 +9.8）

### 9.3 ROS2 时间戳

- IMU 与帧时间戳来自不同源
- 多机需 NTP 同步

### 9.4 户外

- IR 投射器在日光下失效
- 用 0 emitter 模式（关闭投射器）
